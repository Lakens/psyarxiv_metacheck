How Exact P-Values works

List any p-values reported with insufficient precision (e.g., p < .05 or p = n.s.), reported as exactly zero (e.g., p = .000), or impossible (below 0 or above 1, e.g., p = -.22).

This module uses regular expressions to identify p-values. It will flag any values reported as p > ? or p < numbers greater than .001. It will also flag p-values reported as exactly zero (e.g., p = .000, p = 0.00), which are mathematically impossible — p-values are never exactly zero and should instead be reported as p < .001.

A p-value that is not the result of a test is not flagged: a table note (“* p < .05, ** p < .01”), a figure legend (“Asterisks indicate significant differences (p < .05)”, “Values in bold are significant at p < .05”) or a stated threshold (“p < .05 was considered significant”, “thresholded at p < .001”). GROBID often puts such notes into the running text, so each p-value is judged by the words in its own clause (the text up to a “;” or a full stop), and never left out when a test statistic belongs to it (“F(1, 7) = 8.03, # p < .05”). The column not_a_test of the table says why a p-value was left out (“marker”, “threshold”, “legend” or “named”).

A p-value with the name of a correction or a test after the p (“pFWE < .05”, “padj < 0.05”, “p Wilcoxon = .02”) is flagged only when a test statistic comes before it in its clause (“t(37) = 7.17, p FWE < .05”). Without one it is mostly the rule that decided what was significant (“genes with padj < 0.05 were selected”); such a p-value is “named” in not_a_test. Notes in other forms, such as a marker after the p-value (“p < .05 (*)“), are still flagged.

A p-value below 0 or above 1 is impossible; it is listed apart and not also as imprecise. Often the statistic before it, or its minus sign, was copied into it (“t(134) = -2.32, p = -.13”, “Z = 3.091, P = 3.091”). A value above 1 is listed only after a test statistic in its clause: without one, a “P” above 1 was nearly always another quantity (a proportion, pH, a group’s mean, a model parameter). A number in scientific notation whose power of ten was lost when the PDF was read (“p = 2.4 x 10 -9” read as 2.4) is not listed. A “p” that is the subscript of another symbol (“r p = .64”, “²p = .02” for partial eta squared, “Δp = .33”), or a quantity with a unit, a logarithm or a ratio (“P = 2.9 µm”, “-log10 P = 7.5”, “Ca/P = 1.67”), is not read as a p-value at all (see extract_p_values()). Each p-value has its own row, also when the same one is written twice in a sentence.

This module sometimes flags false positives when sentences discuss how p-value thresholds were set. It can also miss an imprecise p-value that is reported against a threshold (“decreased at the p < .05 significance threshold”).

This module only checks p-values reported in the running text of the manuscript. It cannot (yet) process p-values reported only in tables (as opposed to a table’s footnote text, which the module does see and tries to exclude — see above).

How Code Check works

This module retrieves information from repositories checked by repo_check about code files (R, Python, SAS, SPSS, Stata, Mplus, MATLAB).

The Code Check module checks R (also R Markdown and Quarto), Python (also Jupyter notebooks), SAS, SPSS, Stata, Mplus, and MATLAB files, using regular expressions to check the code; JASP files are listed but not read. The language of a Quarto document or a notebook is read from the file itself (its engine or kernel), not from its extension. The regular expressions can miss information in code files, or falsely detect parts of the code as a fixed file path. Libraries/imports might be loaded in one block, even if there are more than 3 intermittent lines. The module was tried out internally on papers published in Psychological Science, but has not been formally validated. How Data Check works

This module classifies the files in a repository into semantic types (data, codebook, code, software, output, supplemental, readme, asset, other) and, for tabular data files, extracts each column’s type and summary statistics.

The Data Check module consumes the file list produced by repo_check (or any files added via local_path). Each file is classified with rule-based heuristics layered over metacheck’s file_category() and file_types: file names matching README / codebook patterns win first, then an extension crosswalk, then format-locked extension overrides. For every file classified as tabular data that is available locally, the module reads the file head, describes each column with data_col_facets() and computes summary statistics for numeric columns. Every sheet of a spreadsheet that holds a table is read: a file with several such sheets has its columns under source_file = "file.xlsx [sheet]", and the sheet column names the sheet of any spreadsheet with several sheets; a sheet of notes or a codebook is treated as documentation when the file has another table. Following DDI, a column is described by orthogonal facets rather than a single type: representation (numeric/text/datetime/code — how it is stored), measurement_level (Stevens: nominal/ordinal/interval/ratio), concept (what it measures: reaction_time/age/gender/likert/id/…), role (identifier/measure/condition/timestamp), unit, and a quality state (ok/empty/constant). Concepts are detected by name+value rules (the demographic concepts via data_check_demographic()); when llm_use(TRUE) the model fills concepts and measurement levels the rules left blank. Qualtrics survey exports are recognised (data_check_is_qualtrics()): their extra header rows are stripped so columns type correctly, and the reserved response-metadata columns (StartDate, Duration, Finished, …) are tagged.

The module defaults to rules-only when llm_use(FALSE): columns the rules cannot resolve (ambiguous 3–20-unique integers, ambiguous character columns) fall back to continuous / text respectively. When llm_use(TRUE), ambiguous columns and unresolved file types (other) are sent to llm() for optional refinement, and every file is assigned a study group (ex1, pilot2, shared, …) so that multi-study repositories can be recognised (used by psychds_check). Without an LLM the study group is left NA (unknown).

Column extraction requires files to be readable from disk. Files fetched by repo_check from OSF/GitHub/etc. without a local copy (file_location is NA) are classified but not column-extracted; pass local_path to point at a downloaded copy of the repository.

For a paper whose repository is on Dryad, this means column extraction never happens unless a Dryad API key is set: Dryad requires one to download file bytes, even from a fully public dataset (dataset listing and metadata do not need one). Without a key, every Dryad file stays classified but un-downloaded, column_n is 0, and a warning naming Dryad and ?dryad_pat/?dryad_auth is included among the download failures. A one-time session message is also shown (see repo_check) the first time a Dryad dataset is encountered with no key set.

Every downloaded text file the authors wrote (code, settings, survey definitions such as Qualtrics .qsf files, documentation, outputs) is searched for keys: API keys, access tokens and private keys, which let anyone who downloads the file use a paid service at the authors’ cost. Of a tabular data file only the column names and first 3 rows of the table as read are searched: its values come from participants, but a key the authors set for a whole survey (as embedded data in a Qualtrics survey flow) is exported in every response. The search uses the rules of the secret scanner betterleaks (https://github.com/betterleaks/betterleaks, MIT licence) of high and medium confidence. A key found turns the traffic light red; the report and the keys table give its file, line and type, and only its beginning. Other files over 25 MB and binary files are not searched. A key is never tested with its provider. Every module’s result has any whole key replaced by “keyremoved” (see module_run()).

How Reproducibility Check works

This module assesses whether a paper’s R and Python code can be run on its data. It works in two phases. The static phase (always run) collects the package dependencies the code declares, rewrites the data-file paths that do not work in the repository as the authors organised it, works out the order the scripts must run in, and diagnoses why any referenced input file is unavailable — reporting what a reproduction attempt would involve and where it is likely to break. The execution phase (opt-in, execute = TRUE) then actually runs the code: it copies the repository into a throwaway directory, optionally installs the declared dependencies into a throwaway library, runs each script in order in an isolated subprocess with a per-script timeout, and captures the outcome and full output of each run.

By default (execute = FALSE) the module does not run any code — it performs only static analysis: reading dependencies with the same extractors as code_check, finding the files the code references in the repository, and building a run-order dependency graph. It reports what would be installed and run rather than doing it.

When execute = TRUE, the module additionally runs the downloaded code on your machine — a deliberate, opt-in action gated behind that argument (callr is required for R code). Each script runs in an isolated subprocess so a crash cannot take down the R session; note this isolates crashes, not the filesystem or network. Installs (when install_missing = TRUE) and the throwaway run library never touch your main R library. Each script’s outcome is one of ran_ok, errored, timed_out, dependency_unavailable, not_parsed, run_by_source (an R script another script runs with source(), which is run only inside that script, since on its own it lacks the packages and objects the sourcing script sets up first), run_by_import (a Python file other files import, a module rather than a script, unless it has an if __name__ == "__main__": block), jags_model (a JAGS or BUGS model saved with an R extension, which another script reads) or not_r_content (a file that is not R at all, such as a JSON or HTML dump); these last two are not run and are not failures. python2 marks Python 2 code that was not run. With sandbox = "docker" such code runs with Python 2.7 (option metacheck.docker_image_py2; FALSE turns this off), which modifications records; it is never converted, since that can change results. defines_functions is a file that only defines functions, which is used, not run (table$used_by names the scripts that use it), and not_analysis is a file of software rather than of the analysis: a package’s code, tests, documentation or setup.py, a copy of a tool, a web application, a script a program wrote (table$not_analysis_why says which); neither is run or counted as a script. docker_failed means the container never started, which says nothing about the script, so it keeps the light from being green but does not make it red. needs_a_person is a script that stopped because it asks a person to choose a file or answer a question, or that starts an app, and needs_internet one that stopped because the network is off in a Docker run, or, with internet = TRUE, could not reach what it asked for; download_too_large is a script stopped for downloading more than the limits allow (see internet), and out_of_memory one that, or a program it started (such as a compiler), ran out of the memory each script may use. All four are treated the same way. not_downloaded is a script that stopped on a file the repository lists but that was not downloaded, such as one over max_file_size: it could not be tried, so it is not counted as a script that did not reproduce (summary_table$repro_not_downloaded_n counts them apart). not_read is a file metacheck could not read, so it was not run; the light is then not green, as the file may read and run on another computer, and table$error_message says why, naming a package that is installed but cannot be loaded on the computer that ran the check. empty is a file with nothing in it, which is not run or counted as a script. For a script that did not run through, table$error_message is its error, short (at most 300 characters): the error line of its output, which names a package that is not there, with the address it asked for when it needed the internet, or the time limit it reached; table$reason sorts it into a kind. A timeout means “still running at the cutoff”, not a failure, so raise timeout for legitimately long-running (e.g. Bayesian) scripts. dependency_unavailable means the script’s own package could not be installed from live CRAN, the CRAN Archive, or a named GitHub/URL source — an infrastructure limitation, not a defect in the paper’s code, so unlike errored/timed_out it does not force the traffic light red. The full stdout/stderr of every run is kept in the result’s run_results (the report shows it in per-script dropdowns, capped for readability). The traffic light reflects the STATIC readiness signals by default, but an execution error (errored/timed_out) does recolour it to red — a script that crashes on its own analysis is a genuine reproduction failure. A script that fails with could not find function is run once more with the library() calls the project’s other scripts make added at its top (or the one package that exports the function, or magrittr for %>%), and a script that then runs is reported as reproducible only after that repair.

Dependencies are reported name-only, with the source (CRAN, GitHub, or a base package already shipped with R) — static analysis of the code cannot know which version was used, and running against current package versions is itself informative: a break argues the authors should have pinned versions. When the repository does record versions, a run with recorded_versions = TRUE installs the packages the scripts load at those versions, but it does not change the R version, which remains a limitation of the check.

Run order is derived from read-after-write data dependencies (a script writing a file another reads must run first), source() edges, and numeric filename prefixes as a weak tie-breaker. Ambiguous orderings, dependency cycles, and inputs a script reads but that no earlier script produces (and that are not in the repository) are surfaced as warnings, since these are the situations most likely to make an otherwise-correct reproduction fail.

Python code (.py files, and notebooks and Quarto documents whose code is Python, from which the code is extracted first) goes through the same two phases, reported in its own “Python code” section. Each file is checked for syntax errors with Python’s own parser when a Python interpreter (python, or else python3) is available; dependencies are read from the import statements, with versions from a requirements.txt or pyproject.toml when there is one, and installed with pip; each script runs as its own python process (processx is required), so unlike R scripts, a name one script defines is not available to another. When no Python interpreter is available, the Python files are reported as not run and the R results are still returned. Statistics the Python scripts print are compared with the paper together with the R output and any self-reproducible output (JASP/jamovi, SPSS-Viewer, notebook outputs).

Abstract

Criteria-Based Content Analysis (CBCA) is used to assess the credibility of victim statements, e.g., in child sexual abuse cases. Prior work showed that contextual case information can bias both CBCA scores and the resulting credibility judgments. We examined whether sequencing case information can prevent such contextual bias. Prior research could not fully test the effectiveness of sequencing as a debiasing strategy as the bias induction was unsuccessful.

This inspired this new, improved study design. In a preregistered online experiment, 242 participants completed a CBCA training and made a credibility judgment of a victim statement based on their CBCA scoring. Participants were randomly assigned to one of three conditions that varied in the timing of contextual information. In the control condition, participants received no biasing contextual information. In the full-information condition, credibility-reducing contextual biasing information was presented before the victim statement. In the sequencing condition, biasing contextual information was presented after the CBCA rating. Bayesian analyses showed that both CBCA scores and credibility judgments were lower in the fullinformation condition than in the control condition, indicating contextual bias. Sequencing prevented bias in CBCA scores: CBCA ratings in the sequencing condition were higher than in the full-information condition and comparable to the control condition. However, sequencing did not prevent contextual bias in subsequent credibility judgments. These findings indicate that sequencing can help protect CBCA from contextual influences, but additional safeguards are needed to prevent irrelevant background case information from shaping final credibility judgments.

Introduction

Recent public debates about sexual abuse, most notably the #MeToo movement and widely publicized cases (Hörnle, 2021), show how central, contested, and consequential credibility judgments of alleged victims have become. This is especially relevant in sexual abuse cases, where physical evidence is often lacking or not discriminative between a consensual versus non-consensual scenario, and statements therefore become particularly valuable (De Jong & Rose, 1989). This highlights the need for structured methods to make credibility assessment objective and accurate. Statements are often evaluated on content criteria, such as their level of detail, to determine credibility (Verschuere et al., 2025). A prominent method to do so is the Criteria-Based Content Analysis (CBCA; Steller & Köhnken, 1989).

Criteria-Based Content Analysis

CBCA is intended as an objective method for assessing the credibility of victims' statements using 19 content criteria (Steller & Köhnken, 1989). Each criterion reflects a specific internal content feature whose presence is assumed to be more frequent in truthful than in fabricated statements (Steller & Köhnken, 1989; see Table 1). CBCA is part of Statement Validity Assessment (SVA; Steller, 1989) which also considers contextual, personal, and situational factors, in addition to the content analysis, to arrive at a credibility judgment (Volbert & Steller, 2014). Meta-analytic findings demonstrate large effect sizes for CBCA in distinguishing truthful from fabricated statements, supporting its validity (d = 0.78 in Amado et al., 2015; g = 0.86 in Oberlader et al., 2021), and recent meta-analytic evidence from field studies confirms a large effect in real forensic cases (g = 1.15 in Sporer et al., 2025). Most CBCA criteria show moderate interrater reliability, but there is considerable variation (Hauch et al., 2017). At the same time, several factors have been shown to influence the CBCA scores.

Some of these influences largely reflect characteristics of the witness and the interview. For example, age is -irrespective of credibility -positively associated with CBCA scores, with younger children scoring lower on CBCA than older children due to their memory and language proficiency still being under development (Vrij et al., 2004). SVA explicitly requires that such developmental and interview-related factors are taken into account when interpreting CBCA scores (Steller & Köhnken, 1989; Volbert & Steller, 2014). In contrast, CBCA scoring should not be affected by case-level contextual information that is external to the statement itself, such as a suspect's confession or DNA evidence. When this kind of task-irrelevant contextual information alters CBCA ratings it reflects contextual bias (Kassin et al., 2013; Dror, 2020).

Contextual Bias

Unlike standardized (e.g., IQ) tests, CBCA evaluations lack strict scoring rules but require substantial interpretation. This limited standardization allows evaluators more freedom and thus increases the potential for bias in CBCA (Oeberst & Oberlader, 2024). Bias is a systematic, often unconscious, process that systematically distorts the decision-making (Dror, 2020). Cognitive biases can affect forensic psychological decision-making at multiple stages: they shape which information is noticed, how it is interpreted, and the final judgment. Even when interpreting physical evidence like DNA mixtures, experts may reach different conclusions depending on the contextual information (Dror & Hampikian, 2011; for further examples and reviews, see Dror et al., 2006; Featherston et al., 2020; Zapf et al., 2017; Escolà-Gascón et al., 2023). Due to the nature of forensic psychological assessment, contextual bias is highly relevant (for details see Oberlader et al., 2025) and mainly refers to the influence of task-irrelevant case information on conclusions (Dror, 2020). A case in point is, Murrie et al. (2013). Offenders' risk assessments depended on which side the expert represented: prosecution or defense. Experts retained by the prosecution tended to assign higher risk scores than those retained by the defense.

Contextual bias is pervasive in forensic settings but is understudied in forensic psychological assessments. This raises the question of whether contextual information may also influence credibility judgments of victim statements in child sexual abuse cases (Cooper & Meterko, 2019). Bogaard et al. (2014) examined the influence of contextual bias on the content scoring of a statement with the CBCA as well as the final credibility judgment. They trained university students on the CBCA and then presented them with contextual information designed either to enhance or to reduce perceived victim credibility. They were then presented with victim statements and scored them on all 19 CBCA criteria. Finally, they integrated their scoring into an overall credibility judgment. The contextual information influenced the CBCA scores as well as the final credibility judgments. The effect sizes were moderate to large for both CBCA (d = 0.58; re-calculation by Von Oppen et al. 2026) and credibility judgments (d = 1.10). Although some subsequent studies failed to find contextual bias effects (Arui et al., 2025; Kemme & Posch, 2026; Schemmel et al., 2020; see also Pilot 1; Methods Section), a preregistered direct replication confirmed the contextual bias when using the materials of Bogaard et al. (2014; Von Oppen et al., 2026; CBCA: d = 0.33; final credibility judgments: d = 0.88). These findings suggest that CBCA criteria are susceptible to contextual influences, at least under certain circumstances.

Bias mitigation: Sequencing

How can we safeguard CBCA-based assessments against contextual bias? While there have been several proposals (Neal & Brodsky, 2016; Vredeveldt et al., 2024), forensic psychology currently lacks evidence-based methods to successfully mitigate bias. At the same time, forensic science has not just studied but implemented debiasing methods in practice, including the sequencing of case information (Dror, 2020; Dror & Kukucka, 2021). One prominent example is Linear Sequential Unmasking (LSU), where a case manager controls the order of information given to the forensic expert (Dror & Kukucka, 2021; Dror et al., 2015). The core idea is that one cannot be biased by information one does not know of (yet). Experts therefore first only receive the strictly necessary raw crime-scene evidence (e.g., the fingerprint, or the DNA sample) and only later any required contextual information. Sequencing helps to ensure one works from the evidence to the suspect, not the other way around. A challenge to translate the sequencing approach from the forensic sciences to legal and forensic psychology is to determine what is relevant versus irrelevant for the task at hand (Skeem et al., 1998; Gardner et al., 2019). LSU-Expanded (LSU-E) adds the criteria of biasing power, objectivity, and relevance to guide the order in which information is revealed (Dror & Kukucka, 2021). For fingerprint matching, the relevant material is the fingerprint, and all other information (e.g., the ethnic origin of the suspect, a strong alibi, or a DNA match) can be regarded as contextual.

Forensic psychologists, however, are likely to differ in opinion on what is relevant or irrelevant for credibility assessment (Neal et al., 2019; Oeberst & Oberlader, 2024). For example, is the opinion of another expert, a Rorschach test, a retracted confession, or the modus operandi in another crime relevant? Moreover, in some countries, forensic-psychological experts who assess victim statements may obtain contextual information by interacting with the victim in an interview. In sum, forensic psychology practice brings in aspects that inevitably introduce contextual information, and it can be difficult to distinguish task-relevant from irrelevant information. At the same time, there seems promise in trying to translate the established practice of sequencing case information from the forensic sciences to credibility assessment: It may help to mitigate bias in parts of the procedure and make the influence of the contextual information transparent (Kukucka & Quigley-McBride, 2025; Oberlader & Verschuere, 2025).

To date, only one study has attempted to apply sequencing of case information as a debiasing method in credibility assessment using CBCA (Arui et al., 2025). They randomly assigned 467 participants to one of three conditions: control (no contextual information), fullinformation (contextual information along with the statement) or sequencing (first statement only, contextual information only after the CBCA scoring). The contextual information concerned the opinion of a clinician that the alleged victim showed no signs of abuse. Each participant received a brief introduction to the CBCA, scored the victim statement on four CBCA criteria, and came to a final credibility assessment. Sequencing did not diminish contextual bias on the final credibility assessment, as participants who received the biasing information at any time point judged the statement as less credible than participants who received no contextual information. Yet, the brief explanation of the CBCA criteria may not have been sufficient to assure adequate scoring of the criteria. Moreover, findings regarding sequencing were inconclusive because there was no contextual bias in CBCA scores to begin with. Consequently, the effectiveness of sequencing as a debiasing method for CBCA could not be fully evaluated.

We therefore re-assess the potential of sequencing to mitigate contextual bias in CBCA-based credibility assessment.

Present study

We aim to test whether sequencing can protect CBCA ratings from contextual bias by adapting the design of Arui et al. (2025) in two important ways. First, we used contextual information that was previously shown to induce bias (a combination of multiple elements reducing credibility including a previous false accusation by the victim and the victim displaying behavioral problems; Bogaard et al., 2014; Von Oppen et al., 2026). Secondly, to ensure that participants understand and appropriately apply the CBCA criteria, we moved from a brief explanation to a more extensive CBCA training, including examples for each criterion, as well as feedback on CBCA scoring of each criterion. Participants first received said CBCA training, then were randomly assigned to one of three conditions (see Figure 1). In the control condition, participants did not receive any contextual biasing information during the experiment. They listened to and read the victim statement, rated it on the CBCA criteria, and then provided a credibility judgment. In the full-information condition, participants first received credibilityreducing contextual information, then listened to the statement, and subsequently rated the CBCA criteria and provided a credibility judgment. In the debiasing condition, participants first listened to the statement and rated the CBCA criteria; only afterward would they receive the contextual information and then provide the credibility judgment.

We will test the following hypotheses: H1. CBCA is prone to contextual bias: The CBCA score in the full-information condition will be lower than in the control condition, indicating that contextual bias affects CBCA scores (H1a); and the credibility judgment in the full-information condition will be lower than in the control condition, indicating that contextual bias affects credibility judgments (H1b).

H2. Sequencing protects against contextual bias: The CBCA score in the full-information condition will be lower than in the sequencing condition (H2a); the credibility judgment in the full-information condition will be lower than in the sequencing condition (H2b).

Methods

Transparency and Openness

This study was preregistered. The preregistration, ethics approval, materials, anonymized data and analytic scripts can be found on https://osf.io/afwc6/.

Sample characteristics

Participants were recruited via Prolific (www.prolific.com) and completed the study online through Qualtrics, in return for £8.63 per hour. They were required to be fluent in English, able to listen to an audio recording, and not to have taken part in any previous study using the same materials. The sample size was determined using a Bayesian sequential design: We decided to test 240 participants in a first batch and determine evidential strength before conducting a possible second batch of 240 participants. Because our data were conclusive after the first batch, there was no need for an extra batch (for more details, see https://aspredicted.org/ev8tn4.pdf).

The size of the initial batch (n = 240) was based on a frequentist power analysis conducted with G*Power (α = .05 and power = .90) that indicates that at least 207 participants were required to detect a medium effect (Arui et al., 2025) in an omnibus fixed-effects ANOVA. To account for potential exclusions, the first batch included 240 participants. Our final sample consisted of 242 participants.

Participants were excluded if they failed one or more of the following attention checks: One out of the four practice-statement attention checks, the victim-statement attention check, or the condition-dependent attention check. In total, 83 participants (34.3 %) failed at least one attention check (i.e., 20.7 % failed the practice-statement attention check, 0.4 % failed the victim-statement attention check, 7 % failed the control condition attention check and 12 % failed the condition-dependent attention check), resulting in a final sample of 159 participants (for sensitivity analyses without applying these preregistered exclusion criteria, see Results section). These participants were on average 34.2 years old (SD = 12.7). The sample consisted of 61 women, 97 men, and 1 participant who preferred not to disclose their sex; ethnically, 65% identified as White, 12 % as Asian, 12 % as Black, 3 % as Mixed, and 8 % as Other or unknown.

Procedure

The study was approved by the Ethics Review Board of the research institute Psychology at University of Amsterdam (FMG-19945). Participants were recruited on Prolific for a study on determining whether a victim statement is true or false, which contained a trigger warning for child sexual abuse. After providing informed consent, participants completed a CBCA training, which included one of two practice statements. After four multiple choice attention checks on the practice statements, participants were randomly assigned to the control, full-information, or sequencing condition. Participants in the full information condition first received the contextual biasing information, followed by the victim statement. They then scored the four CBCA criteria and provided an overall credibility judgment. Participants in the sequencing condition first listened to the victim statement and scored the CBCA criteria, then received the contextual biasing information and provided an overall credibility judgment. Participants in the control condition only received the victim statement, then scored the CBCA criteria and provided an overall credibility judgment (see Figure 1). For the overall credibility judgment, all participants were instructed to focus on the victim's statement and reminded that the more criteria are present, the more truthful the statement is considered (see Materials) Afterwards, they were asked to rank the order in which the four CBCA criteria or other information had determined their credibility judgment. This was followed by two attention checks, one regarding the victim statement, which was identical across all conditions (i.e., "According to the statement, what was Tina doing when Stefan first came into her room?" A. Lying on her bed, B. Sitting at her desk, C. Taking clothes out of her dresser, D. Sitting on the floor, E. On the phone with a friend), and one condition dependent attention check that asked about the task instructions (see https://osf.io/afwc6/). Finally, participants were thanked, debriefed, and paid.

Materials

We conducted a pilot study (Pilot 1), described in full on https://osf.io/afwc6/, that led to two important insights for the present study that we took into account in the design. First, in the pilot study we had taught participants the CBCA via a short instructional video on the CBCA method in general, but noticed that a substantial proportion of the participants did not apply the CBCA criteria correctly. We therefore expanded the training with additional videos for each criterion, including definitions and text examples of low and high criterion presence, and we provided feedback on the expected ratings for the practice statements. Second, in the pilot study we had induced contextual bias by mentioning that a clinical expert saw no signs of trauma in the victim (cf. Arui et al., 2025), but there was no evidence of contextual bias on the CBCA criteria. CBCA training. First, participants watched a short video (1:00 minute) explaining that they would use a method that assesses the truthfulness of a victim's statement based on content criteria. The more content criteria are present, the more truthful the statement is considered. This is followed by four short clips (total of 2:49 minutes), one for each of the four CBCA criteria. In these videos, the meaning of each criterion is explained and then demonstrated with two examples: one in which the criterion has a high presence and one in which the presence is low, to illustrate how different statements may look. Subsequently, participants were presented with one of two counterbalanced practice statements, in which two of the criteria show high presence, and two show low presence (Practice Statement 1: CBCA criteria 1 and 3 are highly present, CBCA criteria 7 and 14 are weakly present; Practice Statement 2: CBCA criteria 1 and 3 are weakly present, CBCA criteria 7 and 14 are strongly present) Participants were then asked to rate the statement on all four criteria. Afterwards, they received feedback regarding the expected rating and an explanation and answered four multiplechoice attention checks regarding the ranking of each criterion.

Contextual Bias induction.

We used the credibility-reducing bias induction by Bogaard et al. (2014; see also Von Oppen et al 2026). In essence, this contextual information provides a number of elements aimed to decrease the credibility of the victim. We adapted the materials to our case and added additional elements to strengthen the bias. We conducted a second pilot study (Pilot 2) and found moderate to strong reducing-credibility effects (see https://osf.io/afwc6/, shows the bias induction vs control context materials).

CBCA.

To keep the task feasible, we only used four CBCA criteria: logical structure,quantity of detail, unexpected complications and spontaneous corrections, see Table 2.

Each participant ranked the four criteria (see Table 2). During the rating of the statement, each of the criteria was paraphrased to ensure correct use (see https://osf.io/afwc6/). The ratings are given on a 7-point Likert scale, from strongly disagree to strongly agree.

Credibility judgment.

The instruction for the credibility judgment was "How credible do you find this statement?", with a reminder to consider the CBCA ratings, and scored on a 7point Likert scale (from not at all credible to extremely credible).

Analysis plan

Preregistration. The study hypotheses, design, and primary analysis plan were preregistered prior to data collection on AsPredicted.org, and the preregistration document is available at https://aspredicted.org/ev8tn4.pdf.

Pre-processing. Participants who did not complete the study or who met the previously mentioned exclusion criteria (failed attention checks) were excluded from further analyses. The CBCA score was calculated as the sum of the four criteria ratings. The credibility score was based on the recorded rating.

Pre-registered analyses Auxiliary hypothesis:

We conducted an independent-sample t-test comparing the sequencing to the control condition on the CBCA sum score. We used a two-tailed test because we did not expect a systematic difference in either direction.

Further preregistered analysis.

Practice statement check: We ran four one-tailed independent Bayesian t-tests comparing Practice Statement 1 and 2 (independent variable) on the score for each CBCA criterion (score on CBCA criteria 1, 3, 7 or 14 as dependent variable). We expected that participants who received Practice Statement 1 would score higher on criteria 1 and 3 than participants who received Practice Statement 2, as statements were designed as such. In addition, we expected that participants with Practice Statement 2 would score higher on criteria 7 and 14 than participants with Practice Statement 1. Therefore, the Bayesian t-tests compared models with a non-zero mean difference between practice statements to null models with equal means.

Results

Analytical framework

All Bayesian analyses were conducted in R using the BayesFactor package (Morey & Rouder, 2026). For Bayesian t-tests, ANOVAs, and linear regressions, we used the default Jeffreys-Zellner-Siow (JZS) priors with scale parameter r = 0.707 on standardized effect sizes, assuming normally distributed outcomes with equal variances across conditions. Bayesian correlation analyses used the default Jeffreys-beta* prior on the correlation coefficient ρ and a normal likelihood. Histograms and Q-Q plots of CBCA sum scores and credibility ratings indicated approximately normal distributions without severe deviations, supporting these modelling assumptions. For key pairwise comparisons, we drew 10,000 posterior samples of the standardized effect size and report posterior means and 95% credible intervals (CrIs) where relevant. We relied on these default priors and did not conduct additional formal sensitivity analyses of the Bayes factors to alternative prior specifications.

Pre-registered analysis

CBCA score. The Bayesian one-way ANOVA investigating the effect of condition on the CBCA sum score revealed strong evidence for the model including condition compared to the intercept-only model (BFM = 18.40, see Table 3 for descriptive statistics). This is in line with our prediction and indicates a difference in CBCA sum scores across the three conditions. A further Bayesian independent-samples t-test, investigating CBCA sum score across full information and control conditions, showed strong evidence that the CBCA sum scores were lower in the full information condition than in the control condition (BF10 = 40.22), and the posterior mean standardized effect size for this difference was d = 0.58 with a 95% CrI [0.21, 0.98], indicating that contextual bias was present in the CBCA sum score, which is in line with our prediction. In addition, the Bayesian independent-samples t-test investigating CBCA sum score across full information and sequencing conditions yielded strong evidence for higher CBCA sum scores in the sequencing condition than in the full-information condition (BF10 = 13.15) and the posterior mean standardized effect size was d = 0.55 with a 95% CrI [-0.93,-0.17], indicating higher CBCA scores in the sequencing condition relative to the full-information condition. Lastly, comparing the CBCA sum score across the sequencing condition and the control condition did not result in decisive evidence for either hypothesis but hints at there being no difference in CBCA between the control and sequencing condition (BF01 = 4.9). The posterior mean standardized effect size was d < 0.00 with a 95% CrI [-0.35, 0.36], indicating that any difference between sequencing and control conditions in CBCA scores is likely to be small. This is in line with our expectation, as both conditions did not receive the contextual bias information before the CBCA scoring.

Final credibility judgement.

The Bayesian one-way ANOVA investigating credibility differences across all three conditions yielded extreme evidence for the model including condition compared to an intercept-only model (BFM = 1883.68). This is in line with our expectation and indicates that at least one pair of conditions differs. Further, our planned contrasts comparing the credibility scores of the control and full-information conditions using Bayesian independent-samples t-tests yielded very strong evidence for higher credibility ratings in the control condition compared to the full-information condition (BF10 = 518.70). The posterior mean standardized effect size was d = 0.75 with a 95% CrI [0.35, 1.15]. This is in line with our prediction and indicates that contextual bias was present in the credibility scores. The Bayesian independent-samples t-tests comparing credibility scores of the full info and sequencing conditions showed a BF01 of 4.65. The posterior mean standardized effect size was d = 0.06 with a 95% CrI [-0.29, 0.42]. This indicates that the observed data are about 4.65 times more likely under the model assuming no difference in credibility between the two conditions than under the model assuming a difference, which is consistent with the conclusion that sequencing does not protect against contextual bias in the credibility judgments.

Further preregistered analysis: Correct application of CBCA scoring.

To examine whether CBCA criteria scoring was correctly applied, we did four Bayesian independent-samples t-tests to compare how people rated the two practice statements. Participants had been randomly assigned to a practice statement that was designed to score high on 2 and low on 2 other CBCA criteria (i.e., practice statement1 scored high on Logical Structure and Quantity of Details and low on Spontaneous Corrections and Unexpected Complications; practice statement1 scored high on Spontaneous Corrections and Unexpected Complications and low on Logical Structure and Quantity of Details). As expected, there is extreme evidence that practice statement 1 was rated higher on logical structure (BF10 = 1.6 × 10²³) and quantity of detail (BF10 = 8.16 × 10⁷) compared to practice statement 2), whereas spontaneous corrections (BF10 = 7.62 × 10¹⁵) and unexpected complications (BF10 = 6.57 × 10⁹) were rated higher on statement 2. These results indicate that participants were able to apply the criteria as intended for either practice statement.

Non-preregistered analyses

Practice performance does not protect against contextual bias. We were also interested in whether high practice statement performance would protect against bias in credibility judgments. Therefore, we computed a practice proficiency index and computed a credibility bias score for the sequencing and the full information condition. We then ran a Bayesian correlation analysis, which indicated that better practice performance did not systematically reduce or increase contextual bias in credibility (full information condition: r = 0.15, BF10 = 0.51; sequencing condition: r = 0.15, BF10 = 0.52); therefore, practice proficiency does not appear to protect against (or increase) contextual bias in credibility (see https://osf.io/afwc6/ for detailed analysis).

Ranking analysis. As seen in Table 4, participants reported weighing logical structure and quantity of detail particularly in their final credibility assessment. This was confirmed by Bayesian linear models with final credibility judgement as the outcome and each CBCA criterion as a predictor and then compared each model to an intercept-only model. The Single predictor models showed overwhelming evidence for quantity of detail (BF10 = 2.0 × 10 25 ) and logical structure (BF10 = 4.7 × 10 21 ) as predictors of credibility, moderate evidence for spontaneous corrections (BF10 ≈ 3.16), and evidence for the null model for unexpected complications (BF10 = 0.25) and the model including all four criteria provided extreme evidence over the intercept-only model (BF10 = 5.6 × 10 33 ). As shown in Table 5, the mean CBCA scoring for each criterion was broadly consistent with participants' importance rankings and with their predictive value for credibility.

CBCA-Credibility relationship across conditions.

We were also interested to see whether the association between CBCA scoring and credibility judgment differs by condition to see whether evaluators rely on CBCA to a different extent depending on the contextual information available in each condition. Therefore, we performed Bayesian correlation analyses where models with a non-zero correlation between CBCA and credibility were compared to null models with ρ = 0 for each condition. All three conditions yielded extreme evidence for a positive relationship between CBCA and credibility (control: BF10 = 4.6 × 10⁶, full information: BF10 = 6.9 × 10⁷, and sequencing: BF10 = 5.4 × 10⁶). We followed it up with a Bayesian regression comparison between the main effect model (credibility ~ CBCA + condition) and interaction model (credibility ~ CBCA × condition). It showed strong evidence against the interaction model (BF10 = 0.02), indicating a CBCA -credibility association of similar strength across conditions, rather than being moderated by condition (see Figure 2).

Exclusion rate.

The high exclusion rate resulted from strict exclusion criteria, particularly based on the practice statement. Sensitivity analyses with more lenient criteria showed that the main pattern of results remained highly similar to the preregistered analyses, see Table 5. Including participants who failed attention checks reduced Bayes factors, indicating that they largely added noise.

Discussion

Credibility assessment of victim statements is a crucial source of evidence in sexual abuse cases (Volbert & Steller, 2014; De Jong & Rose, 1989). A prominent tool to objectively assess credibility is the scoring of the statement content using the Criteria-Based Content Analysis (CBCA; Steller & Köhnken, 1989). While CBCA scoring of the statements should be based on the content of the statement only, Bogaard et al. (2014) showed that extraneous information can influence the scoring. Here, we sought to examine the effectiveness of sequencing as a remedy to prevent extraneous information from influencing the CBCA-based content scoring of the statement. Evidentiary independence is a crucial presumption in law, as the different pieces of evidence are interpreted as independent. Yet, this does not seem to be the case; for example, it has been shown that knowing a suspect confessed can influence eyewitnesses' subsequent identification decisions (Hasel & Kassin, 2008). Therefore, to assess all the different elements of evidence individually, we have to ensure that the assessment of each piece of evidence is not dependent on the others. Multiple key findings result from the present study: We again found that the CBCA and the subsequent credibility assessment were both prone to contextual bias. It follows that sequencing can prevent contextual bias in CBCA ratings, safeguarding the content scoring of the victim statement from extraneous influences. Lastly, despite sequencing protecting CBCA scoring, contextual information still impacted the final credibility judgments.

CBCA and credibility assessments are prone to contextual bias

The first key finding -that both CBCA scores and subsequent credibility assessments are vulnerable to contextual bias -highlights the susceptibility not only of the credibility judgment but also of the CBCA itself (Bogaard et al., 2014). With this finding, we again replicate that contextual information -here knowing the victim's history of trouble at school, including rebellious and deceitful behavior toward peers, a prior rape accusation that was later recanted, a poor relationship with her mother, and repeated theft of money, as well as the accused's denial of the accusation by providing a motive for her to lie -changes the way people score the victim statement on specific content criteria. This contextual information may have prompted prior assumptions or expectations that shaped how evaluators interpreted different aspects of the statement. Because CBCA criteria are interpretive measures, they are sensitive to such influences. The results indicate that evaluators' CBCA scores and credibility judgments are affected by what they already know about the case and the victim. This pattern is consistent with prior work in forensic decision-making demonstrating that contextual information (e.g., suspect confessions, victim characteristics, or pre-existing theories) can contaminate expert judgments and now appears to extend to CBCA scores and credibility ratings, which are frequently used in legal and clinical practice (Dror et al., 2006; Hasel & Kassin, 2008; Ask & Granhag, 2005). The shifts in judgment observed as a function of contextual information undermine their objectivity and underscore the need to interpret content scoring cautiously and to develop safeguards against contextual bias in credibility assessments.

Sequencing can prevent contextual bias in CBCA ratings

The second key finding indicates that controlling the flow of information can mitigate contextual bias in CBCA ratings. Evaluators who first assessed the victim's statement and only later received contextual information showed less bias in their CBCA scores compared to those exposed to contextual information earlier. This suggests that the order in which information is presented shapes how strongly context can affect judgments. This aligns with the linear sequential unmasking-expanded (LSU-E) approach, which proposes that experts should first examine the primary evidence in isolation and only then be exposed to case details to reduce confirmation bias (Dror & Kukucka, 2021; Dror et al., 2015). Such sequencing is intended to preserve a more bottom-up analysis of the statement, as delaying contextual information may limit the formation of strong expectations and thereby reduce confirmation bias. Indeed, the findings suggest that introducing sequencing as a tool to mitigate bias in credibility judgments can successfully protect the integrity of CBCA scores. This supports the development of protocols in which independent assessors who are not involved in the interview process are initially "blinded" to potentially biasing contextual cues (e.g., prior allegations, suspect history, or victim history) until after the content-based assessment has been completed and documented, by structuring procedures so that CBCA evaluations are conducted before, and independent from, rich contextual case information.

Despite sequencing, context still impacts final credibility judgments

The third key finding is that even when sequencing is used to protect CBCA ratings, contextual information continues to exert influence on final credibility judgments. This suggests that structured sequencing can make the CBCA assessment more robust, yet it does not fully insulate the evaluators' final credibility judgment from bias once context is introduced. Forming a credibility judgment is an integrative process that may be more vulnerable to contextual influences and intuitive, than rule-based scoring of individual criteria (Kahneman, 2011). The results, therefore, suggest that protecting the CBCA rating alone is not sufficient to protect the subsequent credibility judgment, as it remains vulnerable to contextual bias. This highlights the need for further protective measures and safeguards at the level of the subsequent credibility judgment. Additional protective measures could focus on ensuring that only relevant contextual factors, rather than irrelevant ones, influence the final judgment by structuring the subsequent credibility assessment more explicitly. One approach would be to define and empirically test the factors that should be incorporated into the final credibility assessment within SVA (Volbert & Steller, 2014). This could help ensure that final judgments are based on relevant information rather than on irrelevant contextual influences.

Limitations and generalizability

Choice of CBCA criteria. When interpreting these findings, it is important to keep in mind that we used only four of the 19 CBCA criteria, and previous research has shown that the criteria differ in predictive power (Amado et al., 2016; Hauch et al., 2017; Arui et al., 2025).

Future research should therefore examine sequencing on the full CBCA scale and test whether the observed debiasing pattern generalizes across different criterion sets.

Interview context and ecological validity.

Another important consideration is that real forensic interviews are typically interactive conversations rather than uninterrupted monologues. (Fernandes et al., 2024). In some cases, evaluators rely on written statements, but often on interviews that may vary considerably in structure and length. In addition, it is important to note that our sample consisted of lay participants rather than experts, who completed only part of the SVA, i.e., not all required steps of the assessment were included in this study.

Instructional and contextual information limitations.

In this study, participants were not explicitly instructed to refrain from using background information in their credibility judgments. They were asked to rate the statement and were reminded of the CBCA criteria.

Although they were neither encouraged nor instructed to use contextual information, it was not explicitly prohibited, so they may reasonably have treated it as evidence. In German practice, additional information is considered before a final credibility judgment is made (Griesel et al., 2012). This begs the question of which information should be considered, and which should not.

Overall, this study shows that both CBCA ratings and global credibility judgments are vulnerable to contextual bias. Sequencing case information can prevent bias in CBCA scores and make the credibility judgment process more transparent but does not equally protect the final credibility judgment. Clearer guidelines on which contextual information may be relevant, together with procedures that promote transparency (e.g., two-stage judgments) in weighing in such contextual information may improve credibility assessments.

This raises a conceptual issue: are participants truly biased, or are they simply affected by contextual information that may be considered relevant? Experts and lay people may differ in what is considered relevant (Griesel et al., 2012; Dror, 2017). We have argued that we used contextual information that is objectively irrelevant for the task at hand -the content scoring of the statement. This work should be expanded with research informing laypeople on what is (ir-)relevant and perhaps warning not to integrate contextual information. The key issue likely is not whether contextual information should be used at all, but rather which pieces of information are reliable and relevant enough to weigh into the credibility assessment.

Future directions

We think that an interesting avenue for future studies is to implement a two-stage judgment process where an independent evaluator gives judgments before and after contextual information is introduced (Dror & Kukucka, 2021; Kahneman et al., 2021). First, the evaluator would provide CBCA ratings and then make an initial credibility judgment before any additional contextual information is introduced. After this first credibility judgment, the contextual information would be presented, after which the same evaluator gives a second credibility judgment. At this second stage, the evaluator would be required to explain whether and why they change their judgment. Implementing such a procedure would make any changes in judgment more transparent to outside observers and could elicit more critical reflection, leading to more deliberate and well-justified credibility assessments than when no explanation is required (Maegherman et al., 2022).
