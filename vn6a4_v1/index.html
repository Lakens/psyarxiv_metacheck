To check Non-Significant P Value Check

What we found

We found 85 non-significant p values that should be checked for appropriate interpretation.

Show details

Meta-scientific research has shown nonsignificant p values are commonly misinterpreted. It is incorrect to infer that there is ‘no effect’, ‘no difference’, or that groups are ‘the same’ after p > 0.05.

It is possible that there is a true non-zero effect, but that the study did not detect it. Make sure your inference acknowledges that it is possible that there is a non-zero effect. It is correct to include the effect is ‘not significantly’ different, although this just restates that p > 0.05.

For an a-priori power analysis, where the sample size is determined, reporting all information would look like:

An a priori power analysis for an independent samples t-test, conducted using the pwr.t.test function from pwr (Champely, 2020), indicated that for a Cohen’s d = 0.5, an alpha level of 0.05, and a desired power level of 80% required at least 64 participants in each group.

For a sensitivity power analysis, this sentence would look like:

A sensitivity power analysis for an independent samples t-test, conducted using the pwr.t.test function from pwr (Champely, 2020), indicated that with 64 participants in each group, and an alpha level of 0.05, a desired power level of 80% was reached for an effect size of d = 0.5.

How StatCheck works

The Statcheck module runs Statcheck. Statcheck searches for regular expressions that match a predefined pattern, and identifies APA reported statistical tests. More information on the package can be found at https://github.com/cran/statcheck. The module only returns Statcheck results for t-tests and F-tests, as these are the only tests which have been validated, see https://osf.io/preprints/psyarxiv/tcxaj_v1/.

Statcheck was developed by Michèle Nuijten and Sascha Epskamp.

Statcheck considers p = 0.000 an error, as you should report p < 0.001. Furthermore, p < 0.03 is an error if the p-value was 0.031, and one should simply report exact p-values (p = 0.031). When the sentence of a test says it is one-sided (“one-tailed”, “one-sided” or “directional”), a p-value that fits a one-sided test counts as consistent (statcheck’s OneTailedTxt setting; #695). When the paper says anywhere that its tests are one-sided, a p-value that fits a one-sided test in either direction counts as consistent too: half the two-sided p, or 1 minus that half for an effect against the predicted direction. Equivalence tests (TOST) are left out, as their p-values do not test the difference. A statistic written with “<” or “>” is read as a bound, and in a sentence about equal variances an F-test’s two-sided p (twice the one-tailed p) counts as consistent. For more information, see StatCheck.

How Exact P-Values works

List any p-values reported with insufficient precision (e.g., p < .05 or p = n.s.), reported as exactly zero (e.g., p = .000), or impossible (below 0 or above 1, e.g., p = -.22).

This module uses regular expressions to identify p-values. It will flag any values reported as p > ? or p < numbers greater than .001. It will also flag p-values reported as exactly zero (e.g., p = .000, p = 0.00), which are mathematically impossible — p-values are never exactly zero and should instead be reported as p < .001.

A p-value that is not the result of a test is not flagged: a table note (“* p < .05, ** p < .01”), a figure legend (“Asterisks indicate significant differences (p < .05)”, “Values in bold are significant at p < .05”) or a stated threshold (“p < .05 was considered significant”, “thresholded at p < .001”). GROBID often puts such notes into the running text, so each p-value is judged by the words in its own clause (the text up to a “;” or a full stop), and never left out when a test statistic belongs to it (“F(1, 7) = 8.03, # p < .05”). The column not_a_test of the table says why a p-value was left out (“marker”, “threshold”, “legend” or “named”).

A p-value with the name of a correction or a test after the p (“pFWE < .05”, “padj < 0.05”, “p Wilcoxon = .02”) is flagged only when a test statistic comes before it in its clause (“t(37) = 7.17, p FWE < .05”). Without one it is mostly the rule that decided what was significant (“genes with padj < 0.05 were selected”); such a p-value is “named” in not_a_test. Notes in other forms, such as a marker after the p-value (“p < .05 (*)“), are still flagged.

A p-value below 0 or above 1 is impossible; it is listed apart and not also as imprecise. Often the statistic before it, or its minus sign, was copied into it (“t(134) = -2.32, p = -.13”, “Z = 3.091, P = 3.091”). A value above 1 is listed only after a test statistic in its clause: without one, a “P” above 1 was nearly always another quantity (a proportion, pH, a group’s mean, a model parameter). A number in scientific notation whose power of ten was lost when the PDF was read (“p = 2.4 x 10 -9” read as 2.4) is not listed. A “p” that is the subscript of another symbol (“r p = .64”, “²p = .02” for partial eta squared, “Δp = .33”), or a quantity with a unit, a logarithm or a ratio (“P = 2.9 µm”, “-log10 P = 7.5”, “Ca/P = 1.67”), is not read as a p-value at all (see extract_p_values()). Each p-value has its own row, also when the same one is written twice in a sentence.

This module sometimes flags false positives when sentences discuss how p-value thresholds were set. It can also miss an imprecise p-value that is reported against a threshold (“decreased at the p < .05 significance threshold”).

This module only checks p-values reported in the running text of the manuscript. It cannot (yet) process p-values reported only in tables (as opposed to a table’s footnote text, which the module does see and tries to exclude — see above).

How Code Check works

This module retrieves information from repositories checked by repo_check about code files (R, Python, SAS, SPSS, Stata, Mplus, MATLAB).

The Code Check module checks R (also R Markdown and Quarto), Python (also Jupyter notebooks), SAS, SPSS, Stata, Mplus, and MATLAB files, using regular expressions to check the code; JASP files are listed but not read. The language of a Quarto document or a notebook is read from the file itself (its engine or kernel), not from its extension. The regular expression search will detect the number of comments, the lines at which libraries/imports are loaded, attempts to detect absolute paths to files, setwd() and install.packages() calls, and lists files that are loaded, and checks if these files are in the repository; R code is also parsed. The regular expressions can miss information in code files, or falsely detect parts of the code as a fixed file path. Libraries/imports might be loaded in one block, even if there are more than 3 intermittent lines. The module was tried out internally on papers published in Psychological Science, but has not been formally validated. There might be valid reasons why some loaded files can’t be shared, but the module can’t evaluate these reasons, and always gives a warning.

How Data Check works

This module classifies the files in a repository into semantic types (data, codebook, code, software, output, supplemental, readme, asset, other) and, for tabular data files, extracts each column’s type and summary statistics.

The Data Check module consumes the file list produced by repo_check (or any files added via local_path). How Reproducibility Check works

This module assesses whether a paper’s R and Python code can be run on its data. It works in two phases. The static phase (always run) collects the package dependencies the code declares, rewrites the data-file paths that do not work in the repository as the authors organised it, works out the order the scripts must run in, and diagnoses why any referenced input file is unavailable — reporting what a reproduction attempt would involve and where it is likely to break. The execution phase (opt-in, execute = TRUE) then actually runs the code: it copies the repository into a throwaway directory, optionally installs the declared dependencies into a throwaway library, runs each script in order in an isolated subprocess with a per-script timeout, and captures the outcome and full output of each run.

By default (execute = FALSE) the module does not run any code — it performs only static analysis: reading dependencies with the same extractors as code_check, finding the files the code references in the repository, and building a run-order dependency graph. It reports what would be installed and run rather than doing it.

When execute = TRUE, the module additionally runs the downloaded code on your machine — a deliberate, opt-in action gated behind that argument (callr is required for R code). Each script runs in an isolated subprocess so a crash cannot take down the R session; note this isolates crashes, not the filesystem or network. Installs (when install_missing = TRUE) and the throwaway run library never touch your main R library. Each script’s outcome is one of ran_ok, errored, timed_out, dependency_unavailable, not_parsed, run_by_source (an R script another script runs with source(), which is run only inside that script, since on its own it lacks the packages and objects the sourcing script sets up first), run_by_import (a Python file other files import, a module rather than a script, unless it has an if __name__ == "__main__": block), jags_model (a JAGS or BUGS model saved with an R extension, which another script reads) or not_r_content (a file that is not R at all, such as a JSON or HTML dump); these last two are not run and are not failures. python2 marks Python 2 code that was not run. With sandbox = "docker" such code runs with Python 2.7 (option metacheck.docker_image_py2; FALSE turns this off), which modifications records; it is never converted, since that can change results. defines_functions is a file that only defines functions, which is used, not run (table$used_by names the scripts that use it), and not_analysis is a file of software rather than of the analysis: a package’s code, tests, documentation or setup.py, a copy of a tool, a web application, a script a program wrote (table$not_analysis_why says which); neither is run or counted as a script. docker_failed means the container never started, which says nothing about the script, so it keeps the light from being green but does not make it red. needs_a_person is a script that stopped because it asks a person to choose a file or answer a question, or that starts an app, and needs_internet one that stopped because the network is off in a Docker run, or, with internet = TRUE, could not reach what it asked for; download_too_large is a script stopped for downloading more than the limits allow (see internet), and out_of_memory one that, or a program it started (such as a compiler), ran out of the memory each script may use. All four are treated the same way. not_downloaded is a script that stopped on a file the repository lists but that was not downloaded, such as one over max_file_size: it could not be tried, so it is not counted as a script that did not reproduce (summary_table$repro_not_downloaded_n counts them apart). not_read is a file metacheck could not read, so it was not run; the light is then not green, as the file may read and run on another computer, and table$error_message says why, naming a package that is installed but cannot be loaded on the computer that ran the check. empty is a file with nothing in it, which is not run or counted as a script. Full text

Abstract

Despite their functional capabilities, myoelectric upper-limb prostheses still present high abandonment rates. Combining user-generated motor commands with algorithmic assistance for grasp control (shared autonomy), or providing tactile feedback about grasping force, may enhance users' sense of agency over the prosthesis, a key component of prosthesis embodiment (integration of the prosthesis into the bodily self). Understanding these effects in intended users is therefore important for developing prosthetic assistance. We investigated these effects in 58 age-and gender-matched participants: 29 without and 29 with unilateral transradial amputation. Participants performed an object-repositioning task using a physics-based virtual reality simulation of a myoelectric prosthesis under four conditions combining two motor control modes (direct user control or algorithm-assisted shared autonomy) with two vibrotactile feedback modalities (continuous or pulse-width-modulated vibration). Sense of agency was assessed through self-report ratings and a perceived temporal compression task. Additional measures included placement accuracy, gaze behaviour, embodiment, and phantom-limb experience. Shared autonomy increased self-reported agency in controls but decreased it in participants with amputation. Tactile feedback modality showed no significant effect on sense of agency measures. Greater phantom-limb control and embodiment of the phantom limb were associated with higher self-reported agency. Placement accuracy was higher in participants with amputation and under direct control. Direct control outperformed shared autonomy with continuous vibration in controls and with pulse-width-modulated vibration in participants with amputation. In controls, pulse-width-modulated vibration also yielded higher accuracy than continuous vibration under shared autonomy. These population-specific responses may partly reflect previous myoelectric-control experience. Prosthesis development therefore requires consideration of functional performance and users' perception of the device, alongside longitudinal clinical evaluation to determine how these responses change with continued use.

Introduction

Upper limbs, particularly the hands, are central to daily physical and social activities (Caldas et al., 2026; Cordella et al., 2016). Many activities of daily living, such as dressing, cooking, or manipulating objects, require coordinated use of both limbs, with each limb often performing complementary roles to ensure the stability of the object during physical manipulation (Kilbreath & Heard, 2005; Roby-Brami et al., 2021). Beyond these physical functions, upper limbs also allow us to communicate with others and express ourselves, making them a fundamental aspect of non-verbal communication (Andric & Small, 2012; Clough & Duff, 2020; Yang et al., 2015).

The upper limbs, more specifically the hand and wrist, are calculated to have 27 degrees of freedom (DoF) (Caldas et al., 2026). These DoFs can be controlled individually during precise voluntary actions or coordinated through motor synergies involving multiple joints (Santello et al., 2016). Such synergies reduce the dimensionality of motor control, and, with practice, coordinated movements involving multiple joints can also become increasingly automatic, freeing attentional resources for concurrent tasks (Favila et al., 2024; Floyer-Lea & Matthews, 2004; Mizes et al., 2023).

The sensorimotor system can also maintain stable grasps and limb postures without continuous conscious monitoring. This occurs when holding a glass of water during a conversation, where the glass remains firmly grasped despite small movements and the allocation of attentional resources toward the conversation. This ability results from the integration of tactile and proprioceptive afferent feedback with motor commands through sensorimotor control loops, which enable rapid adjustments in grip force and limb configuration with limited attentional demands (Forgaard et al., 2021; O'Shea & Redmond, 2021; Sensinger & Dosen, 2020a).

These sensorimotor loops are disrupted after amputation, impeding the normal integration of afferent and efferent signals associated with the missing limb (Raspopovic et al., 2021). Additionally, representations of the missing limb may persist, leading to the remaining perception of the missing limb in the majority of people suffering from it, also known as phantom limb sensation (Giummarra et al., 2007 (Giummarra et al., , 2010;; T. R. Makin & Flor, 2020; Stankevicius et al., 2021). Perception of phantom limb sensation as co-located with a prosthetic device has been positively associated with the successful integration of artificial prostheses into the body representation (Bekrater-Bodmann, 2022), with this perception of the phantom limb sensation being modulated by visual and multisensory feedback (Prahm et al., 2025; Ramachandran & Altschuler, 2009; Risso et al., 2022).

Upper-limb loss can also alter the body schema, the dynamic sensorimotor representation of the body's configuration and position in space that contributes to action control (Canzoneri et al., 2013; Sattin et al., 2023). These alterations occur alongside substantial changes in physical function and independence, leading to decreased physical and psychosocial well-being following upper-limb loss (Caldas et al., 2026; Jo et al., 2021).

Prosthetic devices aim to mitigate these consequences by replacing the missing limb with an artificial alternative, restoring aspects of its appearance, motor function, or both (Caldas et al., 2026; Speckman & Biggs, 2024). However, externally powered myoelectric prostheses, despite offering the potential to operate more DoF simultaneously than other alternatives, like bodypowered or cosmetic prostheses, are still associated with substantial rejection rates, particularly at more proximal amputation levels (Salminger et al., 2022). These rates have been attributed to limited dexterity during myoelectric control (Farina et al., 2014; Jiang et al., 2023), intentiondecoding errors under real-world signal variability (Alotaibi et al., 2023), limited tactile and proprioceptive feedback increasing reliance on constant visual monitoring (Cheng et al., 2023; Jiang et al., 2023), and practical constraints involving speed, intuitiveness, weight, battery life, maintenance, comfort, and robustness (Carey et al., 2015; Cordella et al., 2016).

The incorporation of artificial tactile and proprioceptive feedback has therefore been extensively proposed as a means of partially restoring the missing sensory component of the sensorimotor loop. However, translation into clinical practice remains constrained by interface complexity, calibration and training requirements, comfort, long-term reliability, integration with existing prosthetic systems, and uncertainty about whether artificial feedback provides meaningful benefits during everyday use (Jabban et al., 2022; Raspopovic et al., 2021; Sensinger & Dosen, 2020a).

Shared autonomy provides another potential means of addressing limitations in volitional prosthesis control. In these systems, the prosthesis combines the user's motor commands with contextual information from computer vision, inertial sensors, proximity sensors, or tactile sensors to infer the intended action and assist selected components of the movement (Crevillen Hernandez et al., 2026; Gardner et al., 2020; Mouchoux et al., 2021; Patwardhan et al., 2024). In practice, shared autonomy may partly reproduce the function of natural low-level sensorimotor control by allowing the prosthesis to adapt its movements according to information about the user and environment while preserving high-level volitional control. However, by transferring part of movement control to the prosthesis, shared autonomy may also alter the user's volitional sense over their actions.

However, evidence for shared autonomy in upper-limb prostheses remains limited, particularly in clinical populations. Studies have been conducted predominantly in participants without an amputation or very small samples of prosthesis users (Crevillen Hernandez et al., 2026; Gardner et al., 2020; Mouchoux et al., 2021; Patwardhan et al., 2024). More recent work has begun to provide direct evidence in people with upper-limb amputation: a recent study using 10 participants without and 4 with a transradial amputation showed that continuously shared human-machine control improved grip security and precision while reducing cognitive burden compared with myoelectric control alone (Trout et al., 2025). Validation in larger and more heterogeneous clinical samples, particularly under prolonged and everyday use, is still needed.

Beyond functional performance, prosthesis acceptance may also depend on the extent to which the device is integrated into the user's bodily self, a process referred to as prosthesis embodiment (Bekrater-Bodmann, 2021). Prosthesis embodiment encompasses the integration of sensory and motor signals with affective responses to the device (De Vignemont, 2011; Makin et al., 2017; Saetta et al., 2020). Current models describe prosthesis embodiment in terms of three interrelated dimensions: ownership or bodily integrity, anatomical plausibility, and sense of agency over the device (Bekrater-Bodmann, 2020). Of these dimensions, the sense of agency refers to the experience of controlling one's actions and, through these actions, events in the external world (Haggard, 2017). One's sense of agency can be assessed explicitly through self-report and indirectly through the intentional binding phenomenon, which is frequently used as an implicit index of the sense of agency (Caspar et al., 2015; Crevillen Hernandez et al., 2026; Haggard, 2017; Haggard et al., 2002; Zapparoli et al., 2020). Intentional binding refers to the perceived temporal attraction between a voluntary action and its consequence, resulting in a subjective compression of the action-outcome interval. In other words, the stronger the sense of agency people feel over an action, the shorter they perceive the time between that action and its consequence to be. Understanding how shared autonomy and tactile feedback influence the sense of agency is therefore important for determining whether technological assistance enhances task performance while preserving users' perceived control over prosthetic actions.

Against this background, the present study investigated whether shared autonomy and tactilefeedback modality affected sense of agency and task performance differently in participants with unilateral transradial amputation and control participants without an amputation during an object repositioning task. The study was conducted in a Virtual Reality (VR) environment that realistically simulated the physics and use dynamics of the prosthetic device. We assessed explicit and implicit agency through self-report and perceived temporal compression measurements. We also measured placement accuracy, trial duration, applied force, prosthesis embodiment, and gaze behaviour. Among participants with an amputation, we additionally examined the sense of control and embodiment over the perceived phantom limb.

Accordingly, our preregistered research questions examined whether (1) shared autonomy influences the sense of agency associated with actions performed using a virtual prosthesis, (2) tactile-feedback modality influences the sense of agency, (3) phantom limb sensation is associated with the sense of agency, (4) sense of agency is associated with gaze behaviour, and (5) shared autonomy influences object-repositioning accuracy. For shared autonomy, we preregistered competing hypotheses reflecting its potential outcomes: increased sense of agency and accuracy could result from a better correspondence between intended actions and task outcomes, whereas reduced sense of agency and accuracy could result from discrepancies between intended and prosthesis-generated movements and reduced control over fine movements. We also hypothesised that the tactile-feedback modality employed and the state of the Phantom Limb Sensation may influence the sense of agency, although these hypotheses were non-directional given the limited prior evidence. Finally, we also hypothesised that the sense of agency would be associated with reduced visual attention towards the prosthesis.

Methods

Population

A total of 79 participants took part in the study, of whom 31 suffered from a unilateral transradial amputation. Of these, 2 participants were excluded: one because he left the experiment before finishing, and another because it became apparent he could not complete the experiment without assistance from his caretaker during data acquisition. To balance each population for this study, participants with an amputation and controls without were matched on the same recorded gender category and within three years of age through a linear sum algorithm, with a maximum matched difference of 3 years across the whole sample. Matching was performed to improve demographic comparability between populations, given reported age-related differences in sense of agency (Mariano et al., 2024), prosthesis satisfaction (Resnik et al., 2020), and gender-related differences in upper-limb prosthesis preferences (Kerver et al., 2022). Unmatched participants were excluded from further analysis, leaving 2 participants with an amputation and 19 controls unmatched. This left a total of 58 participants: 29 normally limbed controls (49.56 ± 11.07, 4 female) and 29 with an amputation (50.25 ± 11.33, 4 female). Additionally, 24 participants with an amputation in this sample underwent a clinical assessment of their phantom limb sensation and prosthesis history and usage, showing a mean number of years since amputation of 21.74 ± 13.66 and habitual myoelectric prosthesis use in 23 of them. These data were used solely to describe the sample and were not included in inferential analyses. Setup and data acquisition

Data were acquired at INAIL Prosthetic Center, Virgoso di Budrio, Italy, over the span of 310 days. According to Italian regulations for research involving clinical populations, the Italian Ministry of Health (Ministero della Salute) approved the study protocol as a clinical trial under identifier CP-PAS-0124. The setup consisted of a desktop computer with a dedicated graphics processor, a monitor, a VR Headset VIVE Pro Eye (HTC Corporation, 2021) capable of eye-tracking , a VR tracker for the detection of the forearms' location and direction, two surface electromyographic (sEMG) activity Myo armband recorders (Thalmic Labs Inc.), and a custom vibrotactile armband composed of a microcontroller and a vibration motor. Additionally, the VR environment was developed inside the Unity Game engine 2022.3.19f1 (Unity Technologies, 2022) with the MuJoCo Physics engine (version 2.3.7; Todorov et al., 2012). For more details regarding the technical specifications of the simulator, please refer to (Pasquali et al., 2025).

Task

After signing the informed consent, participants were assessed against the following inclusion criteria: sufficient understanding of the Italian language, being between 18 and 65 years old, not having other upper-limb pathologies, mild pain, or other comorbidities that may affect the results, and scoring at least 24 on the Mini-Mental Evaluation (Folstein et al., 1975). Additionally, participants with an amputation had to have a unilateral transradial amputation and already use some form of prosthesis to reduce first-time exposure effects. After meeting the inclusion criteria, participants completed demographic questionnaires and measures of personality traits, cultural background, attitudes toward robots, and visuo-motor imagery.

However, the analysis of these data is beyond the scope of the present study.

In the experimental session, participants with and without an amputation were evaluated according to their experienced sense of agency while wearing an avatar of an upper-limb prosthetic device in VR. The avatar used by the participants was a virtual model of the Hannes Hand prosthetic device (Laffranchi et al., 2020). Additionally, the virtual environment presented a left area, where the task object would appear at the beginning of each trial, a right area where the object had to be repositioned, an obstacle in the middle, and a black box with a white button that the participant had to press after each trial. The virtual environment replicated the Southampton Hand Assessment Procedure (SHAP) for assessing upper limb functionality (Cole et al., 1992). Specifically, it replicated the setup for the repositioning of a heavy jar task in the category of activities of daily living. A visual representation of the environment is shown in Figure 1. During the experiment, two manipulations were made: one regarding motor control and another regarding the tactile feedback employed.

The sEMG activity of the amputated limb (the dominant limb in the case of participants without an amputation) was measured using two 8-channel wireless sEMG armbands positioned on the remaining forearm, before the participant's elbow. Intended movements were decoded from the recorded EMG signals using an incremental learning algorithm implemented in MOSAIC, which was trained for each participant at the beginning of the experiment (Braun et al., 2025). The prosthesis control system presented two variants: one in which the sEMG signal was matched with the desired movements in real time (i.e., flexion, grasping, and pronation; Full Autonomy) and another in which these detected movements were combined with the output of an intention-detection algorithm (Shared Autonomy). This intention-detection algorithm was composed of a Hidden Markov Model architecture and detected three intentions: grasping, releasing, and no intention. For more details regarding the technical specifications of the Shared Autonomy algorithm, please refer to (Bernardini et al., 2026). The aim of this second modality was to explore how sharing autonomy over the prosthesis with an intention-detection algorithm affected the user's sense of agency.

The amount of pressure exerted between the object being grasped and the fingers of the prosthesis was communicated to the user in the form of tactile vibro-feedback. This feedback was provided by a vibration motor inside an armband positioned between the participant's elbow and shoulder. The Tactile feedback was provided in two modes. In one modality, the vibration was continuous (Continuous Vibration, VC), with its intensity (vibration frequency) directly correlated with the pressure exerted on the grasped object. The other modality followed a Pulse-Width-Modulation (PWM) algorithm, in which the vibration frequency was fixed and occurred in short bursts, with the time between bursts inversely correlated with the amount of pressure exerted on the object being grasped. A graphical example of the sEMG recording bands, the VR tracker, and the armband for vibrotactile feedback is shown in Figure 2. The experimental task was adapted from a previously established sense of agency paradigm (Mariano et al., 2024; Zapparoli et al., 2020), retaining its core structure: active and passive conditions, variable action-outcome delays, temporal interval estimation, and explicit agency judgments. In the present study, the paradigm was adapted to an object-repositioning task performed using a virtual prosthesis. The task consisted of seven blocks: two for training and five for data collection. In all blocks, whether training or data collection, a sound played after a delay once the object was repositioned to the right side of the table. In the first training block, the object repositioned itself from the left area to the right area. In the second training block, the participant had to reposition the object. In the training blocks, a panel appeared after the sound was produced to indicate the delay between the object touching the area on the right and the sound being produced (1 ms, 200 ms, 400 ms, 600 ms, or 800 ms). This was done so that participants could use this feedback to improve their estimation of the delay, both independently and while performing the task.

Of the remaining five task blocks, four required participants to reposition the object themselves, whereas in the remaining block, the object repositioned itself. The order of these five blocks was randomised for each participant, and after the sound was produced, two panels appeared. The first panel asked "Quanto tempo è passato dalla fine del movimento che ha spostato l'oggetto e il suono?" (How much time elapsed between the end of the movement that moved the object and the sound?) and allowed participants to indicate their estimate of the delay (1 ms, 200 ms, 400 ms, 600 ms, or 800 ms), although the actual delays produced during these five blocks were 200 ms, 400 ms, and 600 ms (Perceived temporal compression ). The second panel asked "Quanto senti che la tua azione ha generato il suonoi?" (To what extent do you feel that your action caused the sound?) and allowed the participants to answer through a slider that snapped into 101 predefined discrete values upon release between the extremes "0 -Per niente" (0 -Not at all) and "100 -Interamente"(100 -Completely), indicating how strongly they felt that the sound had been produced by their action (Self-reported agency).

If a participant had a transradial amputation, two additional panels appeared. The first panel asked "Quanto percepisce l'arto fantasma come parte del suo corpo?" (To what extent do you perceive the phantom limb as part of your body?) that snapped into 11 predefined discrete values upon release between the extremes "0 -L'arto fantasma è estraneo al mio corpo" (0 -The phantom limb feels foreign to my body) and "10 -L'arto fantasma è una parte del mio corpo" (10 -The phantom limb is part of my body), which allowed the participant to indicate the extent to which they perceived the phantom limb as part of their body (Sense of Phantom Embodiment). The second panel asked "Quanto controllo ha sui movimenti dell'arto fantasma?" (How much control do you have over the movements of your phantom limb?), which snapped into 11 predefined discrete values upon release between the extremes "0 -Non ho alcun controllo" (0 -I have no control at all) and "10 -Ho il pieno controllo" (10 -I have full control), which allowed the participant to indicate the extent to which they perceived themselves in control of the movements of the phantom limb (Sense of Phantom Control).

Figure 3 shows a graphical summary of the experimental task. The training blocks consisted of 25 trials each with sound delays of 1, 200, 400, 600, and 800 milliseconds, and feedback on the delay was provided to the participant. The experimental blocks 24 trials with sound delays of 200, 400, and 600 milliseconds, and participants were asked for their time estimation of the delay and their sense of agency over it. Additionally, participants with an amputation were also asked for their sense of Phantom Embodiment and Phantom Control. Additionally, the questionnaire Prosthesis Embodiment Scale for Upper Limb Amputees (PEmbS-ULA) was administered after each active experimental block.

To answer these questions, participants had to direct their gaze to one of the possible options for three seconds, as it turned increasingly green. For slider questions, the slider followed their gaze when it was over it, and they had to confirm the value by keeping their gaze on a button labelled "Conferma" (Confirm). To aid participants in their selection, a translucent circle appeared over the panels to indicate the position of the participant's gaze. Figure 4 illustrates the panels, slider, gaze translucent circle, and confirmation button. After each of the four active blocks in which participants repositioned the object themselves, they were asked to look at the virtual prosthesis for 30 seconds. During this period, they could open, close, and move the virtual prosthesis without interacting with other elements of the environment. Afterwards, their VR headset was removed, and they were presented with a questionnaire concerning their sense of embodiment over the prosthetic device during the block they had just completed (Fritsch et al., 2021). They could then take a short break, if desired, before putting on the headset again and continuing with the next task block.

If the block just completed did not require participants to reposition the object themselves, the headset was still removed, and a short break was offered before the task continued to minimise procedural differences between blocks.

Open Science Statement

The data acquisition protocol, power approximation, task, hypothesis, and analysis for this study were preregistered on the OSF platform prior to data collection (https://osf.io/yu9s3/overview?view_only=c2c6d33b0e7a4b8bba42f7d21b38d6dc). However, several deviations occurred in this study. First, our power estimation targeted a sample of 54 participants across both populations, and the final analysed sample comprised 58 participants. Second, our statistical formula for RQ5 was designed to compare the interaction between tactile and motor modalities within each population, as a three-way interaction was not statistically feasible with our sample size. However, upon closer inspection of the preregistered formula, the model would explore a population effect and the average effects and interaction between tactile and motor modalities across both populations, rather than those effects within each population. To address this discrepancy, we kept the preregistered formula and fitted separate models for each population as additional exploratory analyses. Third, as indicated in the preregistration, we fitted additional analyses on trial duration, cumulative force exerted, and prosthesis embodiment while operating the object. However, since no specific hypotheses were preregistered for these analysis, they remain exploratory. Fourth, although the exclusion of interrupted trials was pre-registered, the exclusion procedure was not specified. Because some interruptions were not reliably logged, trials with durations exceeding the participant-and taskspecific mean by more than four standard deviations were excluded from further analyses.

Data preprocessing

Raw CSV files were processed at the participant, task, and trial levels in RStudio 2024.09.1. For each trial, values were recorded for the programmed sound delay, perceived delay, trial duration, accuracy (as the percentage of overlap between the base of the task object and the goal repositioning area), and the measures of Self-reported agency and Perceived temporal compression. Perceived temporal compression was calculated as perceived minus programmed delay, as in (Crevillen Hernandez et al., 2026; Zapparoli et al., 2020), with more negative values indicating stronger temporal binding. Trial Duration was calculated from the first trial timestamp to the moment the object was placed in the goal area on the right. The auditoryevent time was defined as the last timestamp at which the audio-play flag was active. Dwell time was the cumulative time spent looking at the prosthesis, cylinder, or goal before the sound was reproduced. The force outcome was the sum of thumb-force samples recorded before the auditory event in each trial, expressed in newton-seconds, as an indicator of the total force exerted during object manipulation. We recoded and transformed PEmbs-ULA sense-ofembodiment scores for the prosthesis into the RASCH scale according to the conversion table in (Bekrater-Bodmann et al., 2024). If the task object dropped and fell over or the trial was skipped without completion, it was considered a failure and excluded from posterior analysis.

The first three trials of each experimental condition, including the passive condition, were removed to decrease any familiarisation effects, as in (Crevillen Hernandez et al., 2026). Given the practical constraints of conducting research in a clinical setting, unavoidable interruptions affected a small number of trials. As these interruptions were several orders of magnitude longer than the typical task duration, trials were classified as invalid and excluded when their duration deviated by more than four standard deviations from the corresponding participantand task-specific mean (55 trials removed in total, including passive and training blocks). Additionally, 48 trials were excluded from the trial-duration analysis because a technical error prevented their start times from being recorded, making it impossible to calculate their duration. These trials were retained in all other analyses. Trials without a valid reported delay or Self-reported agency recording were classified as incomplete and removed from further analysis (one trial).

Statistical analyses

Analyses were conducted in RStudio 2024.09.1 using lme4, lmerTest, emmeans, and clue. All outcomes were analysed at the trial level with Gaussian linear mixed-effects models fitted by restricted maximum likelihood. Models included a participant-specific random intercept to account for repeated observations and individual differences in baseline outcome levels, following the preregistered model specification. Continuous predictors were entered with their original units. The preregistered confirmatory models addressed five research questions. For RQ1 and RQ2, each agency outcome was modelled using Population, Motor Control, and their interaction, or Population, Tactile Feedback, and their interaction, respectively. These separate models limited model complexity given the sample size targeted by the power estimation.

Interactions between Motor Control and Tactile Feedback were therefore not assessed for agency outcomes. For RQ3, agency outcomes were modelled as a function of Motor Control and Phantom Control or Motor Control and Phantom Embodiment in participants with amputation. For RQ4, dwell time for each area of interest was modelled separately as a function of Population and each agency measure. For RQ5, placement accuracy was modelled as a function of Population plus Motor Control and Tactile Feedback. The preregistered Gaussian linear mixed-effects models were retained as the primary analyses. Following diagnostic assessment, we conducted non-preregistered sensitivity analyses to assess dependence on response distribution, retaining the corresponding fixed-effects structure and participant random intercept. For gaze outcomes, separate models examined the probability of any dwell and dwell time conditional on positive dwell, addressing distinct estimands from overall mean dwell time. Model specifications, diagnostics, and comparisons with the primary analyses are reported in Supplementary Material B.

Because of the task and analysis performed, all analyses included trial data from the active tasks (Full Autonomy-VC, Full Autonomy-PWM, Shared Autonomy-VC, Shared Autonomy-PWM), except for the analysis of gaze behaviour, which also included data from the Passive task. This constraint arose because Motor Control and Tactile Feedback were used as predictors in all analyses except embodiment, for which data were not collected for the passive trial.

Additionally, the analysis for the sense of embodiment used fewer samples than the other models, as data for it were collected task-wise rather than trial-wise. Because data for the PEmbS-ULA questionnaire were missing for three of four active tasks for one participant with an amputation (49-year-old male) due to a technical error, this participant was excluded from this analysis only, leaving 28 participants with an amputation and 29 controls.

Fixed effects were evaluated with Type III F tests using Satterthwaite denominator degrees of freedom. Categorical predictors were treatment-coded, with controls, Full Autonomy (direct user control), and continuous vibration (VC) as the reference categories for Population, Motor Control, and Tactile Feedback, respectively. Continuous predictors were entered in their original units without centring. Estimated marginal means, simple slopes, and their contrasts were obtained with Kenward-Roger degrees of freedom. Pairwise comparisons and tests of multiple simple slopes were Holm-adjusted within each model, where applicable, to account for multiple testing. No additional multiplicity adjustment was applied across the different confirmatory models or hypotheses. For analysis concerning the Phantom Limb Sensation, Motor Control contrasts were also estimated at each integer value of Phantom Embodiment or Phantom Control score from 0 to 10; these 11 tests were Holm-adjusted within each model. All tests were two-sided with α = .05. Estimates were reported with standard errors and 95% pointwise confidence intervals.

Figures display raw observations together with model-estimated marginal means or fixed-effect trends and 95% confidence intervals from the primary models.

Sense of agency

Motor Control and Population -Preregistered Confirmatory Analysis

The pre-registered analysis of Self-reported agency showed a significant interaction between Population and Motor Control, F(1, 4513.9) = 34.08, p < .001. No significant effects were found for Population, F(1, 56.0) = 0.18, p = .671, or Motor Control, F(1, 4513.9) = 1.76, p = .185. Estimated marginal means for Control participants were 67.3 (SE = 4.16) under Full Autonomy and 69.2 (SE = 4.16) under Shared Autonomy. For participants with an amputation, the corresponding estimates were 72.3 (SE = 4.16) under Full Autonomy and 69.2 (SE = 4.16) under Shared Autonomy. Pairwise comparisons with Holm correction showed that Control participants reported higher Self-reported agency under Shared Autonomy than under Full Autonomy (Full minus Shared mean difference = -1.95, SE = 0.61, t(4513.1) = -3.20, p = .007), whereas participants with an amputation reported higher Self-reported agency under Full Autonomy than under Shared Autonomy (mean difference = 3.10, SE = 0.61, t(4514.7) = 5.05, p < .001). The between-Population difference was not significant within either Motor Control condition (both p = 1.000). The ordered-beta sensitivity analysis of Self-reported agency showed a significant interaction between Population and Motor Control, χ²(1) = 21.69, p < .001. Holm-adjusted pairwise comparisons showed higher Self-reported agency under Shared Autonomy in Controls (p = .028) and under Full Autonomy in participants with an amputation (p < .001), consistent with the primary analysis.

The pre-registered analysis of Perceived temporal compression showed a significant interaction between Population and Motor Control, F(1, 4518.1) = 4.32, p = .038. No significant effects were found for Population, F(1, 55.3) = 0.45, p = .504, or Motor Control, F(1, 4518.1) = 1.25, p = .263. Estimated marginal means for Control participants were -63.6 ms (SE = 21.7) under Full Autonomy and -83.3 ms (SE = 21.7) under Shared Autonomy. For participants with an amputation, the corresponding estimates were -56.2 ms (SE = 21.7) under Full Autonomy and -50.2 ms (SE = 21.7) under Shared Autonomy. However, none of the Holm-adjusted pairwise comparisons were significant (all p ≥ .140). Figure 5 illustrates Self-reported agency and perceived temporal compression by level of Motor Control.

Phantom-limb experience and Motor Control

Phantom Control -Preregistered Confirmatory Analysis

The pre-registered analysis of Self-reported agency showed a significant effect of Phantom Control, F(1, 2272.7) = 35.07, p < .001. No significant effect was found for Motor Control at a Phantom Control score of zero, F(1, 2247.4) = 1.16, p = .281, or for the interaction between Phantom Control and Motor Control, F(1, 2247.5) < 0.01, p = .942. Holm-adjusted simpleslope tests showed that Self-reported agency increased with Phantom Control under both Full Autonomy, b = 1.88, SE = 0.36, 95% CI [1.18, 2.58], t(2275) = 5.29, p < .001, and Shared Autonomy, b = 1.86, SE = 0.34, 95% CI [1.18, 2.53], t(2275) = 5.38, p < .001. The slopes did not differ significantly (Full minus Shared slope difference = 0.02, SE = 0.30, t(2247) = 0.07, p = .942). Holm-adjusted Motor Control comparisons evaluated at Phantom Control scores from 0 to 10 showed significantly higher Self-reported agency under Full Autonomy at scores from 6 to 10 (adjusted p ≤ .013), whereas the comparisons at scores from 0 to 5 were not significant (adjusted p ≥ .083). The ordered-beta sensitivity analysis showed that Self-reported agency increased with Phantom Control under both Motor Control conditions (both Holmadjusted p < .001). Unlike the primary analysis, the sensitivity model showed a significant interaction between Phantom Control and Motor Control, χ²(1) = 7.42, p = .006, with a steeper slope under Shared Autonomy on the logit scale.

The pre-registered analysis of Perceived temporal compression showed a significant effect of Phantom Control, F(1, 676.5) = 5.83, p = .016, with higher Phantom Control associated with more negative Perceived temporal compression scores and therefore stronger binding. No significant effects were found for Motor Control at a Phantom Control score of zero, F(1, 2251.6) = 1.81, p = .179, or the interaction between Phantom Control and Motor Control, F(1, 2252.0) = 1.56, p = .212. The Holm-adjusted slope was not significant under Full Autonomy, b = -7.20 ms per unit, SE = 4.73, 95% CI [-16.50, 2.08], t(985) = -1.52, p = .128, but was significant under Shared Autonomy, b = -12.55 ms per unit, SE = 4.58, 95% CI [-21.50, -3.56], t(944) = -2.74, p = .013. Importantly, the slopes did not differ significantly (Full minus Shared slope difference = 5.35 ms per unit, SE = 4.29, t(2253) = 1.25, p = .212).

Prosthesis Dwell Time -Preregistered Confirmatory Analysis

The pre-registered analysis of Prosthesis Dwell Time showed a significant effect of Self reported Agency, F(1, 5708.7) = 56.93, p < .001, and a significant interaction between Population and Self-reported agency, F(1, 5708.7) = 35.45, p < .001. The effect of Population was not significant at a Self-reported agency score of zero, F(1, 81.3) = 2.44, p = .122. Holmadjusted simple-slope tests showed that Self-reported agency positively predicted Prosthesis Dwell Time in Controls, b = 9.45 ms per unit, SE = 0.979, 95% CI [7.527, 11.36], t(5765.9) = 9.65, p < .001, but not in participants with an amputation, b = 1.11 ms per point, SE = 1.00, 95% CI [-0.851, 3.08], t(5614.0) = 1.11, p = .267. The Control slope was 8.33 ms per point steeper than the slope in participants with an amputation, SE = 1.40, t(5709.2) = 5.95, p < .001. The binomial and lognormal sensitivity analyses of Prosthesis Dwell Time showed significant interactions between Population and Self-reported agency for the probability of any dwell, χ²(1) = 14.46, p < .001, and dwell time conditional on positive dwell, χ²(1) = 71.35, p < .001, respectively. Higher Self-reported agency was associated with greater dwell probability and longer conditional dwell in both populations (all Holm-adjusted p < .001), with stronger associations in Controls. The primary overall-dwell analysis detected a significant association only in Controls.

The pre-registered analysis of Prosthesis Dwell Time showed a significant effect of Perceived temporal compression, F(1, 5770.2) = 20.47, p < .001. No significant effects were found for Population at a Perceived temporal compression score of zero, F(1, 56.0) = 0.74, p = .394, or the interaction between Population and Perceived temporal compression, F(1, 5770.2) = 1.83, p = .177. Holm-adjusted simple-slope tests showed that Perceived temporal compression negatively predicted Prosthesis Dwell Time in both Controls, b = -0.423 ms per millisecond, SE = 0.106, 95% CI [-0.631, -0.215], t(5775.8) = -3.98, p < .001, and participants with an amputation, b = -0.228 ms per millisecond, SE = 0.0972, 95% CI [-0.419, -0.038], t(5759.3) = -2.35, p = .019. The slopes did not differ significantly (Control minus amputation slope difference = -0.195 ms per millisecond, SE = 0.144, t(5770.2) = -1.35, p = .177). Because more negative Perceived temporal compression scores indicate stronger temporal binding, these negative slopes indicate that stronger binding was associated with longer Prosthesis Dwell Time in both populations. The binomial and lognormal sensitivity analyses of Prosthesis Dwell Time showed that stronger Perceived temporal compression was associated with greater dwell probability and longer conditional dwell, respectively, in both populations (all Holmadjusted p < .001). Neither interaction between Population and Perceived temporal compression was significant (p = .627 and .974, respectively), consistent with the primary analysis. Goal Dwell Time -Preregistered Confirmatory Analysis

Discussion

In this study, we investigated the extent to which shared autonomy influenced the sense of agency, whether the sense of agency differed according to tactile-feedback modality and phantom-limb experience, and how these measures were associated with gaze behaviour, prosthesis embodiment, and task performance among a population of upper limb amputees and matched non-amputee control participants.

The analyses of the sense of agency revealed an interaction between Population and Motor Control for Self-reported agency and Perceived temporal compression. However, pairwise comparisons identified population-specific differences only in Self-reported agency. These findings are consistent with previous evidence suggesting that explicit and implicit measurement of the Sense of Agency may be capturing related but partially distinct aspects of agency processing (Ciaunica et al., 2024; Erdoğan & Balcı, 2025; Imaizumi & Tanno, 2019; Kim & Yoshida, 2024).

The pairwise comparisons for Self-reported agency showed an increase for participants without an amputation but a decrease for participants with an amputation. Although we preregistered both hypotheses, we did not anticipate a difference between populations. The positive effect in the population without an amputation is consistent with previous work in participants without an amputation during a similar task (Crevillen Hernandez et al., 2026), where this increase was associated with a decrease in the number of failed trials. This improvement may reflect the smaller discrepancy between expected and actual outcomes for the participants without an amputation. Evidence has already shown that Shared Autonomy approaches can lead to shorter completion times, reduced volitional input, and less cognitive burden in both naive participants without and with an amputation populations (Mouchoux et al., 2021; Patwardhan et al., 2024; Trout et al., 2025). Such assistance may be particularly helpful when users have not yet developed stable predictions about the consequences of their myoelectric commands, potentially reducing discrepancies between intended actions and achieved outcomes. This provides one possible explanation for the higher Self-reported agency under Shared Autonomy in participants without an amputation.

For participants with an upper limb amputation, the higher Self-reported agency under Full Autonomy may reflect greater familiarity with direct myoelectric control and more established predictions concerning the consequences of their motor commands. This hypothesis would be supported by the prevalence of myoelectric prosthesis users in our sample, devices whose control system would resemble the Full Autonomy condition used in our experiment. Adaptive behaviours acquired through daily myoelectric prosthesis use may support more established predictions about the consequences of motor commands, consistent with evidence that such mechanisms develop through operation (Williams et al., 2021). Shared Autonomy may alter this familiar relationship, potentially reducing Self-reported agency even when assistance offers functional benefits. Together, these interpretations suggest that the effect of Shared Autonomy may depend on prior myoelectric-control experience, although its contribution could not be separated from amputation status in the present study.

The findings for the Phantom Limb Sensation would provide additional context to this interpretation and reinforce this hypothesis, with the Senses of Control and Embodiment positively contributing to the sense of agency over the device. Phantom Control positively predicted Self-reported agency under both Motor Control conditions, without evidence that the slopes differed. Phantom Embodiment also positively predicted Self-reported agency under both conditions. Although speculative, we cannot rule out the possibility that a greater sense of agency over the prosthesis may have facilitated its embodiment, given the close relationship between the sense of agency and prosthetic embodiment (Bekrater-Bodmann, 2020; Shehata et al., 2020; Zbinden et al., 2022), potentially contributing to a stronger sense of embodiment of the phantom limb (Page et al., 2018; Rognini et al., 2019).

The exploratory trial-duration, cumulative-force, and prosthesis-embodiment findings should also be interpreted in relation to this proposed mechanism. Trial duration showed an overall effect of Motor Control but no interaction between Population and Motor Control. Shared Autonomy produced longer trials in participants with an amputation, potentially indicating less task efficiency, although there was no significant comparison in participants without an amputation.

Participants without an amputation also exerted greater cumulative force than participants with an amputation, but neither Motor Control nor its interaction with Population affected it significantly. The effect of Population on cumulative force, with lower forces in participants with an amputation, may therefore indicate more precise control of the force exerted during object manipulation. More accurate grasp-force control has previously been associated with a greater Sense of Agency (Nataraj & Sanford, 2021), while shared prosthetic control can improve grip-force regulation while reducing the physical and cognitive effort required for object manipulation (Trout et al., 2025).

Lastly, the higher Prosthesis Embodiment scores observed in participants with an amputation may also reflect their greater familiarity with prosthetic devices through everyday use, as habitual prosthesis use has previously been associated with greater incorporation of the device into the user's body representation (Bekrater-Bodmann et al., 2021; Engdahl et al., 2020).

However, we cannot discard the attribution of this phenomenon to an existing discrepancy between populations or our implementation. As Trout et al. (2025) propose, the effects of Shared Autonomy in longitudinal studies and across different levels and populations still need exploration. Further studies should address this by using longitudinal designs that can mitigate potential bias between naive and experienced populations in myocontrolled prosthesis use.

No significant effects of the Tactile Feedback modality used were found for Self-reported agency or Perceived temporal compression. This result may reflect the simplicity of the task or the limited time available to learn and integrate the two feedback mappings (Jabban et al., 2022; Sensinger & Dosen, 2020a). Tactile Feedback also showed no overall main effect on placement accuracy. However, Motor Control and Tactile Feedback showed a significant interaction, indicating marginal gains as a function of the type of Motor Control used, with more continuous feedback favouring direct control and discrete feedback sharing it with an automatic algorithm, with evidence of the latter in the literature (Aboseria et al., 2018).

The gaze findings provided only partial support for the preregistered hypothesis. Self-reported agency was associated with longer Prosthesis and Cylinder Dwell times in participants without an amputation, while being associated with lower Goal Dwell times for both populations. Stronger Perceived temporal compression was also associated with longer prosthesis dwell time in both populations. Therefore, the increased attention directed toward the prosthesis was contrary to the prediction that greater sense of agency would reduce the need to monitor the device, whereas the reduction in goal dwell time was consistent with the predicted direction. However, these findings are consistent with evidence indicating a tendency in participants with an amputation to focus their visual attention towards the prosthesis rather than towards the object being manipulated (Cheng et al., 2023).

Limitations

It is important to acknowledge the limitations of the current findings when interpreting these results. First, the experiment was conducted during a single session. The results therefore represent participants' initial responses to the experimental shared-control and tactile-feedback mappings rather than their responses after extended use. This design did not allow us to determine the extent to which (and how rapidly) training might change the perception and effect of Shared Autonomy or how participants interpreted and integrated both Tactile Feedback modalities.

Second, the populations differed not only in limb status but also potentially in previous prosthesis experience, myoelectric-control expertise, expectations, and compensatory strategies. These factors were inseparable from the population in the present design, as habitual myoelectric prosthesis use was common among participants with amputation. Experienced users may have perceived shared autonomy as interfering with familiar control strategies, whereas participants without amputation may have found it helpful while learning to control the device. This difference could partly explain why shared autonomy decreased self-reported agency in participants with an amputation but increased it in participants without an amputation, limiting the extent to which these findings can be attributed to limb status alone.

Third, this experiment was performed inside a physics-based virtual environment rather than with a physical prosthesis. Although the simulation reproduced relevant functional interactions, it could not reproduce all the mechanical, inertial, cutaneous, proprioceptive, and incidental auditory cues naturally occurring when operating a physical device, which can provide useful information about device state and contribute to the development of internal control models (Sensinger & Dosen, 2020b; Wilke et al., 2019). Additionally, we cannot exclude the possibility that participants adopted control strategies in the virtual environment that differed from those they would use when operating a physical prosthesis. Despite the increased realism of simulations, differences between virtual and physical environments in visual and other sensory information, spatial perception, and interaction dynamics can alter motor behaviour, including movement timing, velocity, and body posture (Arlati et al., 2022; Brock et al., 2023; Ida et al., 2022), potentially limiting generalisability of our findings to physical prosthesis use.

Fourth, we analysed gaze using absolute Dwell time, as pre-registered. Because longer trials provide more opportunity to accumulate gaze time, the observed relationships may partly reflect differences in trial duration. Moreover, Dwell times across the Prosthesis, Cylinder, and Goal were not independent because allocating more time to one area necessarily reduced the time available for other areas. Future analyses could account for trial duration as a covariate, or examine dwell time as a proportion of total trial duration. These approaches could help disentangle differences in gaze allocation from differences in the overall time available to look at each region of interest, providing a more detailed understanding of gaze behaviour.

Future studies should address these issues and further expand knowledge about the potential usefulness of Shared Autonomy algorithms and Tactile Feedback modalities in physical, longitudinal studies with naive, clinical populations.

Conclusion

Taken together, Shared Autonomy did not uniformly increase or decrease the sense of agency, but its relationship with Self-reported agency depended on amputation status, with Shared Autonomy increasing Self-reported agency in Participants without an amputation and decreasing it in participants with an amputation. Evidence from perceived temporal compression was less conclusive at the pairwise-comparison level compared to Self-reported agency. Phantom-limb experience was primarily associated with Self-reported agency, and Tactile Feedback modality did not show a direct association with either sense of agency measure. The gaze findings and exploratory analysis of trial duration, cumulative force, and prosthesis embodiment contributed to identifying possible explanatory factors but do not establish the mechanisms responsible for the population-specific response to Shared Autonomy. Future research should examine these effects longitudinally using larger and more heterogeneous clinical samples, while measuring and accounting for previous myoelectriccontrol experience. Longer training periods and comparable exposure to the control system across populations will be necessary to determine whether the observed differences persist or change as users become familiar with Shared Autonomy and Tactile Feedback modalities.
