How Power Analysis Check works

This module uses regular expressions to identify sentences that contain a statistical power analysis. If specified by the user, it also uses a large language model (LLM) to extract information reported in power analyses, including the statistical test, sample size, alpha level, desired level of power, and magnitude and type of effect size.

The Power Analysis Check module uses regular expressions to identify sentences that contain a statistical power analysis. Without the use of an LLM, the module uses regular expressions to classify the power analysis as a-priori, sensitivity or post-hoc. With the use of an LLM, it checks if the power analysis is reported with all required information.

The regular expressions can miss power analyses, or fail to classify them correctly. The type of power analysis is often difficult to classify, which can easily be solved by explicitly specifying the type of power analysis as ‘a-priori’, ‘sensitivity’, or ‘post-hoc’. Note that ‘post-hoc’ or ‘observed’ power is rarely useful. The LLM can fail to identify information in the paper, and will not have access to information in paragraphs in the paper other than those that contain the word ‘power’. How StatCheck works

Check consistency of p-values and test statistics

The Statcheck module runs Statcheck. Statcheck searches for regular expressions that match a predefined pattern, and identifies APA reported statistical tests. More information on the package can be found at https://github.com/cran/statcheck. The module only returns Statcheck results for t-tests and F-tests, as these are the only tests which have been validated, see https://osf.io/preprints/psyarxiv/tcxaj_v1/.

Statcheck was developed by Michèle Nuijten and Sascha Epskamp.

Statcheck considers p = 0.000 an error, as you should report p < 0.001. Furthermore, p < 0.03 is an error if the p-value was 0.031, and one should simply report exact p-values (p = 0.031). When the sentence of a test says it is one-sided (“one-tailed”, “one-sided” or “directional”), a p-value that fits a one-sided test counts as consistent (statcheck’s OneTailedTxt setting; #695). When the paper says anywhere that its tests are one-sided, a p-value that fits a one-sided test in either direction counts as consistent too: half the two-sided p, or 1 minus that half for an effect against the predicted direction. Equivalence tests (TOST) are left out, as their p-values do not test the difference. A statistic written with “<” or “>” is read as a bound, and in a sentence about equal variances an F-test’s two-sided p (twice the one-tailed p) counts as consistent. For more information, see StatCheck.

This module only checks statistical results reported in the running text of the manuscript. It cannot (yet) process statistics reported only in tables.

How Exact P-Values works

List any p-values reported with insufficient precision (e.g., p < .05 or p = n.s.), reported as exactly zero (e.g., p = .000), or impossible (below 0 or above 1, e.g., p = -.22).

This module uses regular expressions to identify p-values. It will flag any values reported as p > ? or p < numbers greater than .001. It will also flag p-values reported as exactly zero (e.g., p = .000, p = 0.00), which are mathematically impossible — p-values are never exactly zero and should instead be reported as p < .001.

A p-value that is not the result of a test is not flagged: a table note (“* p < .05, ** p < .01”), a figure legend (“Asterisks indicate significant differences (p < .05)”, “Values in bold are significant at p < .05”) or a stated threshold (“p < .05 was considered significant”, “thresholded at p < .001”). GROBID often puts such notes into the running text, so each p-value is judged by the words in its own clause (the text up to a “;” or a full stop), and never left out when a test statistic belongs to it (“F(1, 7) = 8.03, # p < .05”). The column not_a_test of the table says why a p-value was left out (“marker”, “threshold”, “legend” or “named”).

A p-value with the name of a correction or a test after the p (“pFWE < .05”, “padj < 0.05”, “p Wilcoxon = .02”) is flagged only when a test statistic comes before it in its clause (“t(37) = 7.17, p FWE < .05”). Without one it is mostly the rule that decided what was significant (“genes with padj < 0.05 were selected”); such a p-value is “named” in not_a_test. Notes in other forms, such as a marker after the p-value (“p < .05 (*)“), are still flagged.

A p-value below 0 or above 1 is impossible; it is listed apart and not also as imprecise. Often the statistic before it, or its minus sign, was copied into it (“t(134) = -2.32, p = -.13”, “Z = 3.091, P = 3.091”). A value above 1 is listed only after a test statistic in its clause: without one, a “P” above 1 was nearly always another quantity (a proportion, pH, a group’s mean, a model parameter). A number in scientific notation whose power of ten was lost when the PDF was read (“p = 2.4 x 10 -9” read as 2.4) is not listed. A “p” that is the subscript of another symbol (“r p = .64”, “²p = .02” for partial eta squared, “Δp = .33”), or a quantity with a unit, a logarithm or a ratio (“P = 2.9 µm”, “-log10 P = 7.5”, “Ca/P = 1.67”), is not read as a p-value at all (see extract_p_values()). Each p-value has its own row, also when the same one is written twice in a sentence.

This module sometimes flags false positives when sentences discuss how p-value thresholds were set. It can also miss an imprecise p-value that is reported against a threshold (“decreased at the p < .05 significance threshold”).

This module only checks p-values reported in the running text of the manuscript. It cannot (yet) process p-values reported only in tables (as opposed to a table’s footnote text, which the module does see and tries to exclude — see above).

This module was developed by Lisa DeBruine and Daniel Lakens

Read more in the metacheck manual.

Version 0.4.4.3 reported 419 p-values as imprecise, 388 of them correctly (93%), and missed 50 (89% found). How Repository Check works

This module retrieves information from repositories.

The Repository Check module lists files on the OSF, GitHub, ResearchBox, DSpace (PsychArchives and other legacy- and DSpace 7-based installations), Zenodo, Dataverse, Figshare, Dryad, ReShare, 4TU.ResearchData, Mendeley Data, DataONE (Arctic Data Center, KNB, and other member nodes), and LDbase based on links in the manuscript.

A link to a file-sharing service (Google Drive, Dropbox, OneDrive, Box, WeTransfer, MEGA, iCloud Drive, Baidu Netdisk, SURFdrive; see [file_share_links()]) gets a warning and makes the light yellow: such services are not repositories, as files can be changed or deleted at any time, get no DOI, and the link stops working when the account is closed. The report advises a stable repository such as Zenodo instead. Their files are not read, and summary_table$file_share_n counts the links.

Deposits in archives for sequence and expression data (GEO, the INSDC archives BioProject, SRA, ENA and DDBJ, and ArrayExpress; see [seq_archive_links()]), mostly named by accession number, are read for whose deposit they are. The authors’ own are listed with what they hold ([seq_archive_size()]) and are not downloaded or checked as data and code; summary_table$archive_own_n counts them.

R packages on CRAN ([cran_links()], [cran_info()]) are the paper’s own when a paper author is a package author and the paper presents the package; the paper’s own are listed with their version and not checked (summary_table$cran_own_n). A Handle link (hdl.handle.net/...) that leads to a repository read here is checked as a link to that repository ([handle_links()]).

Listing a repository’s files never requires an API key, but some hosts answer faster or more completely with one: OSF allows 100 requests/hour unauthenticated versus 10,000/day with a token (see [osf_pat()]), and Dryad enforces a strict per-IP daily quota on repeated listing (see cache below). Dryad is a special case beyond rate limits: listing a Dryad dataset’s files works without a key, but actually downloading file CONTENTS from Dryad fails with HTTP 401 unless a key is set, even for a fully public dataset (see [dryad_pat()] or [dryad_auth()]). Since this module only lists files and never downloads their contents itself, that limitation applies to data_check and code_check (which do download content), not here – see their own documentation.

When a linked OSF page is a registration, its registered_from project (the one it was registered from, which the manuscript itself may never link directly) is also checked: if that project is public its files are listed under its own URL, and if it is closed or otherwise inaccessible the report flags it explicitly, since some registrations only describe their content rather than mirroring it.

Whose deposit is each link? The ownership table gives, for every repository linked in the text and (with references = TRUE) every deposit cited in the reference list, one of six labels: own_this (made by the authors for this paper), own_earlier_data or own_earlier_code (the authors’ own, from earlier work), others_data or others_code (made by other people, reused here), or not_data (a publication such as a preprint, not a deposit), with ownership_group (“own”, “others”, “not_data”) and the reason. It is decided without a language model, from the sentence or reference that cites the link, the paper’s authors (names, ORCID iDs, affiliations), and what the deposit’s own record and files say (who made it, what it names, when, whether it is a software package; for an OSF project cited only in the reference list, its record alone). How Code Check works

This module retrieves information from repositories checked by repo_check about code files (R, Python, SAS, SPSS, Stata, Mplus, MATLAB).

The Code Check module checks R (also R Markdown and Quarto), Python (also Jupyter notebooks), SAS, SPSS, Stata, Mplus, and MATLAB files, using regular expressions to check the code; JASP files are listed but not read. The language of a Quarto document or a notebook is read from the file itself (its engine or kernel), not from its extension. The regular expression search will detect the number of comments, the lines at which libraries/imports are loaded, attempts to detect absolute paths to files, setwd() and install.packages() calls, and lists files that are loaded, and checks if these files are in the repository; R code is also parsed. The regular expressions can miss information in code files, or falsely detect parts of the code as a fixed file path. Libraries/imports might be loaded in one block, even if there are more than 3 intermittent lines. The module was tried out internally on papers published in Psychological Science, but has not been formally validated. There might be valid reasons why some loaded files can’t be shared, but the module can’t evaluate these reasons, and always gives a warning.

This module classifies the files in a repository into semantic types (data, codebook, code, software, output, supplemental, readme, asset, other) and, for tabular data files, extracts each column’s type and summary statistics.

Following DDI, a column is described by orthogonal facets rather than a single type: representation (numeric/text/datetime/code — how it is stored), measurement_level (Stevens: nominal/ordinal/interval/ratio), concept (what it measures: reaction_time/age/gender/likert/id/…), role (identifier/measure/condition/timestamp), unit, and a quality state (ok/empty/constant). How Reproducibility Check works

This module assesses whether a paper’s R and Python code can be run on its data. It works in two phases. The static phase (always run) collects the package dependencies the code declares, rewrites the data-file paths that do not work in the repository as the authors organised it, works out the order the scripts must run in, and diagnoses why any referenced input file is unavailable — reporting what a reproduction attempt would involve and where it is likely to break. The execution phase (opt-in, execute = TRUE) then actually runs the code: it copies the repository into a throwaway directory, optionally installs the declared dependencies into a throwaway library, runs each script in order in an isolated subprocess with a per-script timeout, and captures the outcome and full output of each run.

By default (execute = FALSE) the module does not run any code — it performs only static analysis: reading dependencies with the same extractors as code_check, finding the files the code references in the repository, and building a run-order dependency graph. It reports what would be installed and run rather than doing it.

When execute = TRUE, the module additionally runs the downloaded code on your machine — a deliberate, opt-in action gated behind that argument (callr is required for R code). Each script runs in an isolated subprocess so a crash cannot take down the R session; note this isolates crashes, not the filesystem or network. Installs (when install_missing = TRUE) and the throwaway run library never touch your main R library. Each script’s outcome is one of ran_ok, errored, timed_out, dependency_unavailable, not_parsed, run_by_source (an R script another script runs with source(), which is run only inside that script, since on its own it lacks the packages and objects the sourcing script sets up first), run_by_import (a Python file other files import, a module rather than a script, unless it has an if __name__ == "__main__": block), jags_model (a JAGS or BUGS model saved with an R extension, which another script reads) or not_r_content (a file that is not R at all, such as a JSON or HTML dump); these last two are not run and are not failures. python2 marks Python 2 code that was not run. With sandbox = "docker" such code runs with Python 2.7 (option metacheck.docker_image_py2; FALSE turns this off), which modifications records; it is never converted, since that can change results. defines_functions is a file that only defines functions, which is used, not run (table$used_by names the scripts that use it), and not_analysis is a file of software rather than of the analysis: a package’s code, tests, documentation or setup.py, a copy of a tool, a web application, a script a program wrote (table$not_analysis_why says which); neither is run or counted as a script. docker_failed means the container never started, which says nothing about the script, so it keeps the light from being green but does not make it red. needs_a_person is a script that stopped because it asks a person to choose a file or answer a question, or that starts an app, and needs_internet one that stopped because the network is off in a Docker run, or, with internet = TRUE, could not reach what it asked for; download_too_large is a script stopped for downloading more than the limits allow (see internet), and out_of_memory one that, or a program it started (such as a compiler), ran out of the memory each script may use. All four are treated the same way. not_downloaded is a script that stopped on a file the repository lists but that was not downloaded, such as one over max_file_size: it could not be tried, so it is not counted as a script that did not reproduce (summary_table$repro_not_downloaded_n counts them apart). not_read is a file metacheck could not read, so it was not run; the light is then not green, as the file may read and run on another computer, and table$error_message says why, naming a package that is installed but cannot be loaded on the computer that ran the check. empty is a file with nothing in it, which is not run or counted as a script. For a script that did not run through, table$error_message is its error, short (at most 300 characters): the error line of its output, which names a package that is not there, with the address it asked for when it needed the internet, or the time limit it reached; table$reason sorts it into a kind. A timeout means “still running at the cutoff”, not a failure, so raise timeout for legitimately long-running (e.g. Bayesian) scripts. dependency_unavailable means the script’s own package could not be installed from live CRAN, the CRAN Archive, or a named GitHub/URL source — an infrastructure limitation, not a defect in the paper’s code. The full stdout/stderr of every run is kept in the result’s run_results (the report shows it in per-script dropdowns, capped for readability).

Provenance, kept so that a TRACE Research Object (TRO) declaration of the run can be written later from a stored result (metacheck #404; the helpers are in R/provenance.R). Only when code was run (execute = TRUE): * run_results$started_at, run_results$ended_at: when each run of a script started and ended (ISO 8601, UTC, milliseconds); NA for a script that was not started. A script run again in a later pass has the times of its last run. A TRO uses them for each trov:TransparentResearchPerformance. * run_results$exit_status: the exit status of the process that ran the script (0 = ended normally); NA when the process did not report one (a time limit, or Docker failing to start the container). * artifacts: one row per file, with stage (deposit: as downloaded from the repository, hashed from the downloaded file; before_run: the run folder just before the first script ran, after metacheck’s own changes, such as rewritten paths and unpacked archives; after_run: only the files the scripts made (status new), changed (changed) or removed (removed), as an unchanged file is the one listed before the run), path (relative to the run folder, as valid UTF-8, a byte of another encoding written as <xx>), size (bytes), sha256, mime_type (by extension, NA when unknown), source (the file’s address in the repository, for deposit). The package libraries metacheck installs in the run folder are left out, as are metacheck’s own files there (a script’s runner, and the statistical output it writes in statistical_output/). Files metacheck itself copied or made between passes (see modifications, output_copied, file_placed) show in after_run too. A TRO uses the rows as trov:ResearchArtifacts and each stage as a trov:ArtifactArrangement. * modifications$sha256_before, modifications$sha256_after: the hash of the changed script as downloaded and as it ran; NA when the script is not at the same path in both (a script made from an R Markdown file). * environment: the system that ran the code (trov:TransparentResearchSystem in a TRO): metacheck_version, started_at, ended_at, host (R version, platform, operating system), sandbox, network_isolated (TRUE only when every Docker run had --network none; the process sandbox does not stop the network), internet, timeout_per_script, total_timeout, python_local (the Python run outside Docker and its version), and docker: runs (for each kind of run, r_run, r_install, python_run, python_install, the image and the docker run arguments, such as --network none, --read-only, --cap-drop ALL, no-new-privileges, the process limit and the memory and processor limits) and images (for each image, its ID and digests from docker image inspect, its creation time and the R and Python versions its environment declares).

It is NA for files run inside another script, files that are not an analysis, files not read, and a Docker failure. summary_table counts each group (repro_ran_n, repro_code_error_n, repro_dependency_n, repro_time_n, repro_not_checkable_n), and the report’s first sentence gives them. The traffic light reflects the static readiness signals by default; a script in code_error that stopped with an error makes it red, as a script that crashes on its own analysis is a genuine reproduction failure, and a script in one of the other three groups keeps it from being green. Calls that need a screen, which the run does not have (dev.print(), dev.copy2pdf(), dev.copy2eps(), savePlot(), windows(), win.graph(), x11(), quartz(), View()), are replaced before the run by calls that need none, which modifications records as screen_call_replaced. A script that fails with could not find function is run once more with the library() calls the project’s other scripts make added at its top (or the one package that exports the function, or magrittr for %>%), and a script that then runs is reported as reproducible only after that repair.

Dependencies are reported name-only, with the source (CRAN, GitHub, or a base package already shipped with R) — static analysis of the code cannot know which version was used, and running against current package versions is itself informative: a break argues the authors should have pinned versions. When the repository does record versions, a run with recorded_versions = TRUE installs the packages the scripts load at those versions, but it does not change the R version, which remains a limitation of the check.

Ambiguous orderings, dependency cycles, and inputs a script reads but that no earlier script produces (and that are not in the repository) are surfaced as warnings, since these are the situations most likely to make an otherwise-correct reproduction fail.

When no Python interpreter is available, the Python files are reported as not run and the R results are still returned. Abstract

This study aims to detect polarization of moral sentiment based on ideology in United States left-and right-wing media through moral sentiment analysis and topic modeling in the context of the Israel-Hezbollah (Lebanon) conflict. Moral sentiment analysis was conducted using the extended Moral Foundation Dictionary, followed by a two-tailed independent samples t-test to examine moral sentiment differences between the two media groups. Additionally, topic modeling was employed to explore dominant themes across the articles. The findings indicate that both groups of media exhibit negative moral sentiment toward the conflict; however, left-wing outlets demonstrate a higher degree of negative moral sentiment compared to their right-wing counterparts. Additionally, distinct topical patterns emerged, including themes related to refugees, ceasefire, and terrorist threat. These results provide empirical evidence of moral judgement polarization in US media coverage, particularly in moral sentiment expression and topic framing, as shaped by ideological orientation.

1. Introduction

The conflict in the Middle East represents a prolonged and complex arena of geopolitical tensions. One of the prominent and enduring conflicts is the Israel-Lebanon conflict, which began in 1982. Unlike the Israeli-Palestinian conflict, the Israel-Lebanon conflict is primarily driven by territorial disputes. It originated from hostilities between Hezbollah and Israel over the Shebaa Farms, a contested area claimed by Israel, Lebanon, and Syria. Over time, the conflict escalated as Hezbollah allied with Hamas and other Palestinian resistance groups, culminating in the October 7, 2023, attack in southern Israel (Britannica, 2024).

Hezbollah is a Lebanese militant organization and political party established to resist the Israeli invasion of Lebanon in 1982. It later evolved with the objective of establishing an Islamic republic (Britannica, 2024). The resistance persisted until Israel withdrew from Lebanon in the early 2000s. However, Hezbollah continued its guerrilla operations against Israel, aiming to secure the release of Lebanese detainees held by Israel, an effort that resulted in Israeli casualties and provoked retaliatory strikes from the Israeli side.

The confrontation escalated into a full-scale war in mid-2006, lasting for 34 days and subsequently referred to as the "34-Day War." More recent incidents have drawn global attention, notably the Pager Attack on 17 September 2024 and the bombing in Beirut in late September 2024, both of which marked a significant escalation. The Pager Attack was an Israeli-engineered operation involving an explosive device hidden in a Hezbollah communication device. The blast killed eleven individuals, including three civilians, and injured approximately 2,750 others (Al-Jazeera, 2024). The escalation of this conflict has drawn particular attention from various international media outlets.

1.1 Left-Right Wing Ideology

Ideological polarization may be rooted in particular psychological dispositions. In the context of violence and conflict, empathy plays a central role (Waytz et al., 2016). In the United States, for instance, polarization is often reflected in how leftists accuse rightists of lacking concern for oppressed groups, particularly when such groups are perceived as out-groups. This divergence can be explained by differing emphatic priorities: leftists tend to direct their empathy toward out-groups, whereas rightists are more focused on the well-being of their in-group. Pliskin et al. (2017) demonstrate that leftists exhibit stronger negative emotional reactions when exposed to violence against out-groups, whereas rightists display stronger negative emotional responses when confronted with violence targeting their in-group. Bar-Tal et al. (2009) further emphasize that ideology plays a crucial role in shaping major intergroup conflicts, as it determines how individuals interpret events through the lens of their ideological orientations.

Beyond empathy dispositions, attributional tendencies in perceiving the causes of social problems and issues also serve as key dispositions underlying ideological polarization between the left and the right (Skitka & Washburn, 2016). Leftists are more inclined to emphasize systemic and external factors when explaining the causes of social problems. They tend to attribute issues such as social injustice, law enforcement failures, LGBT rights, Islamophobia, genocide, and war to broader structural inequities. In contrast, rightists are more likely to focus on internal and micro-level factors, attributing social problems to personal dispositions such as laziness, lack of discipline, or immorality. Personality traits may also predispose individuals toward certain ideological orientations. A meta-analysis by Jost et al. (2003) demonstrates that conservatives, or those on the right, are characterized by higher needs for order, closure, and structure, as well as lower levels of openness to experience. Individuals with right-wing ideologies also tend to exhibit stronger disgust sensitivity (Dodd et al., 2012), which may render them less receptive to issues perceived as unfamiliar or unconventional. Conversely, leftists are generally higher in openness to experience, making them more receptive to diversity and change. This openness, in turn, informs their support for progressive policies and political reforms (Graham et al., 2013). Haidt and Joseph (2004) examined the concept of virtue across cultures, drawing insights not only from psychology but also from anthropology, evolutionary theory, and sociology (Graham et al., 2009). From this interdisciplinary inquiry, they introduced the Moral Foundations Theory (MFT) as a framework that could provide a cross-culturally relevant account of moral reasoning. MFT is defined as the set of innate moral foundations that serve as the basis for individuals' moral justification toward specific situations or issues (Haidt & Joseph, 2004). The theory posits five dimensions: care/harm, fairness/cheating, loyalty/betrayal, authority/subversion, and sanctity/degradation (Graham et al., 2013). Building on this framework, Graham et al. (2009) further demonstrated that MFT helps explain ideological polarization in moral judgment. Their findings consistently reveal that liberals or left-wing individuals place greater emphasis on the moral foundations of care and fairness, whereas conservatives or right-wing individuals prioritize authority, loyalty, and sanctity.

1.2 Moral Foundation Theory

The care/harm foundation is rooted in individuals' multisensory perceptions of a given phenomenon, action, or issue, which are then associated with personal attitudes and beliefs in relation to cultural norms (Graham et al., 2013). This process is not inherently private; individuals may acquire information about others' actions or issues indirectly, for instance through gossip (Dunbar, 1996), social media, or mass media reporting. The care/harm dimension is also inseparable from emotional processes. Landmann and Hess (2017) demonstrated that the care/harm foundation is closely tied to emotions such as disgust and compassion, particularly in the context of violence. The fairness/cheating dimension, in turn, rests upon the principle of reciprocity. Its primary trigger concerns the extent to which parties engaged in cooperation or social relationships provide equitable and reciprocal exchanges (Graham et al., 2013). When such exchanges are perceived as equal and mutually beneficial, the resulting moral framing tends toward virtue, whereas violations lead to judgments of vice. In the context of conflict, fairness/cheating may be tied to power asymmetries, such as the disproportionate number of casualties borne by one side. Argüello-Gutiérrez et al. (2023) further showed that stronger endorsement of the fairness foundation is associated with reduced anti-immigrant attitudes and increased willingness to pursue conflict resolution with minority groups.

Within the loyalty/betrayal dimension, evolutionary perspectives are particularly important as they provide the initial motivation for loyalty or betrayal. Both animals and early humans fought alongside their groups to defend territory (Graham et al., 2013). At the same time, they also engaged in within-group competition to gain power (de Waal, 1982; Graham et al., 2013) and to exert influence in political arenas. Over time, the range of variables at stake has expanded, prompting intra-group competition over resources such as technology, natural assets, and human capital. Consequently, what was once primarily intergroup competition for survival could also shift into intragroup rivalry (Graham et al., 2013). In the realm of conflict, however, moral within this dimension largely depends on individuals' ideology. For example, right-wing or conservative groups tend to prioritize loyalty to the nation, even when the state engages in ethnic violence framed as an expression of national identity (Caprara, 2020).

The authority/subversion dimension, meanwhile, refers to individuals' moral evaluations of the extent to which others comply with authority (Graham & Joseph, 2004). These evaluations are shaped by cultural and ideological orientations. In more conservative societies, obedience to authority is generally evaluated positively, while collectivistic cultures with higher power distance, as outlined in Hofstede's cultural dimensions, similarly place high value on deference to authority (Hofstede, 2011). In contrast, liberal societies tend to take a neutral stance or even issue negative sentiment toward such behaviors (Frimer et al., 2013). Finally, the sanctity/degradation dimension pertains to moral evaluations surrounding purity, hygiene, cleanliness, and sacredness. At the everyday level, for example, individuals may issue virtue-based sentiments toward those who wash their hands before eating. At a broader social level, this dimension becomes relevant in contexts such as overpopulation, where risks of disease or social disorder may arise. Consequently, sanctity/degradation is often linked to the behavioral immune system (Schaller & Park, 2011; Graham et al., 2013). Affectively, moral within this dimension are strongly mediated by disgust (Oaten et al., 2009).

1.3 The U.S. Media Role and Coverage in Conflict Issue

From a geopolitical perspective, the United States holds a dominant position on the global stage. Beyond its military power, the U.S. also exerts significant influence through mass media, particularly in shaping discourses on conflict and war. One of the earliest instances of U.S. media asserting influence in the international arena was its framing of the Gulf War (Hackett & Zhao, 1994). Since this war, the U.S. government began embedding journalists within war zones to cover unfolding events (Calabrese, 2005). Prominent U.S. media outlets with global reach, such as CNN, Times, and Fox News, played a crucial role in constructing frames that shaped world opinion in favor of U.S. dominance and victory (Carol et al., 2008). This was achieved through both narrative and visual strategies. Visually, U.S. media disseminated images and video footage designed to reinforce perceptions of U.S. supremacy, such as the televised destruction of Saddam Hussein's statue in Iraq (Aday et al., 2005; Carol et al., 2008). Narratively, U.S. media have long relied on a recurring 'master narrative' depicting the United States as a heroic force that eliminates rebels and enemies in the Middle East (Hackett & Zhao, 1994). Through such strategies, outlets like CNN and Fox News not only shaped global perceptions but also bolstered their domestic popularity by securing higher ratings and public trust among U.S. citizens (Calabrese, 2005).

Framing strategies in media coverage have also been applied to other conflicts involving U.S. geopolitical interests. However, anti-war sentiments began to emerge alongside the increasing prominence of human rights discourse, particularly among liberal or left-wing groups in the United States. Distinct narratives can be observed between pro-war and anti-war positions. Pro-war narratives frequently emphasized the fear of threats posed by terrorist groups, while anti-war narratives foregrounded peace and the protection of human rights for war victims (Luther & Miller, 2005). Supporters of the pro-war stance often argued that allowing adversaries to remain in peace would only give them time to strengthen and prepare for future attacks against the U.S. (Luther & Miller, 2005). This line of reasoning aligns with right-wing ideology, which tends to endorse militaristic approaches to conflict resolution (Vignoli & Baraldi, 2023). Conversely, anti-war groups highlighted more substantive and fact-based considerations, such as viewing U.S. involvement in Middle Eastern wars-particularly in Iraq as an effort to secure control over oil resources. Moreover, anti-war narratives often adopted a more inclusive perspective by taking into account global public opinion when formulating their stance (Luther & Miller, 2005).

Polarization in media coverage often stems from the ideological positions held by authors, reporters, or media outlets, or from collaborations between these parties (Lazaridou et al., 2017). In the context of conflict, leftists are more likely to advocate for ceasefires, whereas rightists tend to support warfare as a means to resolve conflict and preserve group existence (Chakma, 2024). These ideological orientations are conveyed not only through actions but also through texts. Dijk (2007) argues that discourse within a text plays a significant role in promoting ideology within society. Claramonte (2003) further asserts that language is a powerful tool for expressing thought. Boyd and Schwartz (2021) also emphasize that language is inherently social in nature, with text being one of its primary forms. Therefore, texts serve as important mediums for conveying individual thought, including ideological perspectives. In media studies, sentiment analysis is frequently employed to examine bias in media coverage, particularly concerning political issues. Lin et al. (2006) conducted an analysis of the use of political perspectives in articles discussing the Israel-Palestine conflict, both at the sentence level and holistically across the document, utilizing support vector machines and Naïve Bayes methods. Additionally, reporters and news writers do not merely report facts but often inject their personal perspectives into news articles. This is particularly evident in political topics such as conflicts, presidential elections, refugees, and public policy, where authors' commentary or writing frequently reveals their political affiliations or ideological stances (Lazaridou et al., 2017).

In previous studies, studies regarding the polarization and bias in media highly relied on single facet spectrum: negative/neutral/positive, which is not deeply captured the context and media framing. Additionally, research examining ideological polarization in moral sentiment and framing through text analysis remains relatively scarce. Therefore, this study aims to examine the polarization of sentiment and framing in U.S. media coverage, specifically within the context of the Israel-Hezbollah conflict. This study seeks to analyze sentiment polarization in media coverage through the lens of ideology, employing MFT as a more fundamental and multifaceted framework. In addition, the study concentrates on examining the sentiments expressed in U.S. media coverage of the Israel-Hezbollah conflict (negative vs. positive. Furthermore, this study also aims to investigate the topics emerging in U.S. media coverage across ideological orientations in order to provide a deeper understanding of the media framing

2. Method

This research consists of two research questions. First, what is the level of moral sentiment in the two groups of U.S. media when reporting on the Israel-Hezbollah conflict? Second, what topics emerge in the two groups of U.S. media when covering the Israel-Hezbollah conflict? In order to answer the research questions, this study employs two approaches. First, The Authors performed an analysis of moral sentiment found in US Media news articles. The moral sentiment as dependent variable whereas the conflict of Israel-Hezbollah as independent variable. The moral sentiments examined include care/harm, fairness/cheating, loyalty/betrayal, authority/subversion, and sanctity/degradation. The moral sentiment scores were then compared between left-wing and right-wing media groups using an inferential statistical test: the Independent Samples t-test. The Authors hypothesized that there would be a significant difference in the levels of moral sentiment responses between left-and right-wing articles in reporting the Israel-Hezbollah conflict. Then, the Authors explored the dominant topics that emerged across the articles in order to answer the second research questions. An unsupervised machine learning approach was employed using Latent Dirichlet Allocation (LDA) topic modeling.

2.1. Research Data

The Authors utilized data in the form of online news articles. The media sources were categorized based on their ideological orientation (left-right), referring to the assessments provided by AllSides. AllSides employs a structured ideological assessment process, involving multiple reviewers from diverse ideological backgrounds who assess media articles in a blind review. AllSides also considers community feedback from the general public in the United States, as well as third-party data such as empirical research, including correlations with data from the PEW Research Center (Kulkarni et al., 2018).

The Authors employed Web Scraper to efficiently collect a large number of articles. Web Scraper operates through an Application Programming Interface (API), making the data collection process both legal and secure. The Authors used the keywords "Israel," "Lebanon," "Hezbollah," and "Beirut" as search queries for each news outlet. The selected keywords were determined based on the central focus areas of the conflict from the early 2000s to the present. Adding other keywords, such as 'Tel Aviv' or 'Pager Attack', might risk obscuring the broader scope or narrowing the range of retrieved news coverage. Nevertheless, the researcher manually screened the collected articles to ensure contextual relevance. Finally, after data selection process, A total of 721 articles were collected from left-wing media outlets (Democracy Now, The Intercept, The New Yorker, AP News, Axios, CNBC, and CBS) and 773 articles from right-wing media outlets (Breitbart, American Spectator, American Conservative, OAN, Just The News, Newsmax, Washington Times, Freebeacon, and New York Post). The authors selected these media outlets as the data source because they are indexed by AllSides, which provides a validated procedure for classifying outlets as either left-or right-wing media. In addition, considerations of open access were also taken into account, as these outlets are freely accessible without subscription, thereby ensuring greater ethical compliance in the research process.. All articles underwent a selection process based on inclusion and exclusion criteria. To be included, articles had to (1) contain themes related to the Israel-Hezbollah conflict, (2) be written in English, and (3) be in textual format and focus on international article straight news.

2.2 Sentiment Analysis using LIWC-22 2.2.1 Extended Moral Foundations Dictionary

This study employs an external custom dictionary, the Extended Moral Foundations Dictionary (eMFD), which is incorporated in LIWC-22. The dictionary was developed by Hopp et al. (2021) and is designed to measure moral sentiments expressed in a text concerning a particular issue, situation, or action. Hopp et al. (2021) constructed the dictionary based on MFT as its theoretical foundation. In the process of validation and development, Hopp et al. (2021) emphasized universality by involving hundreds of individuals across countries and cultures to assess the dictionary. In addition to universality, crowd rating was conducted to examine the reliability of the dictionary. The eMFD is employed in this study because it has been contextualized for textual analysis, including in news media that are polarized along left-and right-wing ideological lines.

The eMFD employs a spectrum-based scoring system ranging from negative to positive. For instance, if the care/harm score for a news article about an Israeli attack on Beirut is -2.5, it indicates that the author assigns a negative moral sentiment to the issue, implying opposition to the action. This highlights the critical importance of applying a clear contextual framework when conducting textual analysis of this kind. Hopp et al. (2021) emphasize that the Sentiment Score is not solely based on word frequency but also on word weighting, a technique that assigns greater weight to words that are more morally relevant in context. For example, in the sentence "500 people killed in Israel-Hezbollah War Zone," the word killed would receive a higher weight than "in" or "500". The descriptive statistical results indicate that both left-wing and right-wing media exhibit negative sentiment across all moral dimensions. This finding suggests a general stance of rejecting the conflict. More specifically, both media groups perceive the conflict as threatening and degrading to all five moral foundations. These results imply that both groups demonstrate negative moral sentiments, regardless of their ideological orientation. Nonetheless, there are variations in the degree of negativity expressed. However, to establish the statistical significance of sentiment polarization, comparative testing is required.

2.3 Topic Exploration using Unsupervised Machine Learning

2.3.1 Topic Modelling: Latent Dirichlet Allocation

LDA is widely applied in political communication studies and allows comparability across prior works. LDA excels at detecting latent themes within large-scale textual data and effectively discover topic in article type document. Moreover, this model can be applied across various types of text analysis and offers a comparatively straightforward interpretative framework

2.3.2 Data Preprocessing and Analysis

Before analysis could be conducted, the Authors performed data preprocessing to ensure that the data were structured and to enhance the accuracy of the results. Three main preprocessing steps were applied: tokenization, lemmatization, and stopword removal. These steps are essential in natural language processing, as they significantly influence the quality of the output. Tokenization refers to the process of breaking down text into smaller units called tokens, which can be words, subwords, or even characters. This step employed the SpaCy module with the en_core_web_lg (large English language model), which provides higher accuracy and better handling of larger and more complex text. Lemmatization is the process of reducing words to their base or dictionary form (lemma) while considering the contextual meaning of each word. In this study, lemmatization was conducted using the Natural Language Toolkit (NLTK) module. Finally, stopword removal was carried out to eliminate words considered uninformative or potentially noisy for topic modeling, such as conjunctions, pronouns, and overly frequent keywords directly related to the main topic such as "Israel," "Hezbollah," "Lebanon," "war," and "conflict." These words were excluded because, without removal, they would dominate the model output. As a metaphor, such terms can be seen as the "outer layer" of the text, which must be peeled away in order to uncover the deeper thematic content within.

Once the data were prepared, topic modeling analysis was conducted using the Latent Dirichlet Allocation (LDA) model. This model is used for discovering hidden topics in a collection of documents and is commonly applied for text clustering, summarization, and feature extraction. LDA enables researchers to categorize a large corpus of articles into specific thematic topics. The outputs generated by LDA include dominant topics, word counts, and keywords constructed from the most important words within each topic. These outputs assist researchers in labeling the topics and identifying essential words associated with each. Researchers also have the flexibility to determine the number of topics to be extracted. This number is typically based on the volume of data available. Given that each ideological group contained approximately 700 articles, the Authors decided to extract five topics for each media group. This takes into account both the volume of data and the metrics derived from the topic modeling analysis. Finally, the Authors created word cloud visualizations using the Matplotlib module to display the most frequently occurring words. All analyses for Study 2 were conducted using Google Colab. Table 4 presents the dominant topics that emerged from the articles. The topical patterns in left-wing media tend to focus on attacks carried out by both parties, including the resulting consequences whether by Israel or Hezbollah. Topic LW4 clearly indicates that left-wing media also highlight the impact on civilians, particularly the displacement and forced evacuation from their homes. In addition, Topic LW5 discusses efforts toward a ceasefire. However, these ceasefire attempts ultimately failed due to continued retaliatory attacks from both sides, which escalated the conflict. This escalation is further connected to Topic LW2, which reflects growing security concerns in parallel with the intensifying hostilities initiated by both parties. Themes related to ceasefire and displacement are characteristic of left-wing media, as they ideologically prioritize equality, peace, and human rights. For instance, news excerpts from Democracy Now state: "Over the past 14 months, Israel has killed over 3,800 people in Lebanon and displaced more than a million" and "A ceasefire between Israel and Hezbollah has begun. Under the deal, Israel will withdraw troops from south Lebanon over a 60-day period, while Hezbollah will move its fighters and weapons to north of the Litani River." These examples underscore that left-wing media highlight issues of displacement and civilian casualties. This indicates the primary focus of left-wing media on the individualizing moral foundations, care and fairness. Left-wing media also addressed international public protests, as well as the affiliation of Hezbollah's leader, Hassan Nasrallah, with Shiite groups and political figures across Arab Gulf countries, particularly Syria (Topic LW1). The presence of these themes also suggests that left-wing media adopt a more inclusive perspective toward public opinion, which is closely associated with the openness characteristic of leftist ideology.

2.3.3. Result

The topics that emerged in right-wing media differ considerably from those found in left-wing outlets. One prominent theme is the strong emphasis on the role of terrorist organizations in the conflict (RW1). Upon manual review of several sample articles, the Authors found that right-wing media explicitly classify Hezbollah as one of the terrorist organizations, for example, a news article from Breitbart stated "Israel Kills Ibrahim Aqil, Hezbollah Terrorist Wanted for 1983 U.S. Marines Barracks Bombing in barracks in Beirut". This finding is particularly noteworthy, as it highlights the ideological framing adopted by right-wing media. This is also supported by Figure 1, which shows that the word "terrorist" is among the most frequently used terms by right-wing sources when reporting on the Israel-Hezbollah conflict. In Topic RW3, right-wing media focus heavily on the casualties caused by the war, with vivid field reports documenting the losses "An IDF soldier who witnessed the drone strike told Ynet that he had just finished eating when the drone exploded in the mess hall". This theme corresponds to theme RW1, in which right-wing media frame Hezbollah as a terrorist organization carrying out acts of terror against Israeli civilians. This also demonstrates that right-wing media emphasize the binding moral foundation of authority, particularly in relation to threats against national security at the macro level. In contrast, left-wing media place greater focus on individuallevel elements.

The results of the word cloud analysis (Figure 1) support the findings from the sentiment analysis. The most frequently occurring words in both media groups tend to carry negative connotations. However, word frequencies alone cannot justify differences in framing within the news articles. Although the most frequent words appear similar across both media groups, this is not an error in the modeling process but rather a characteristic of LDA topic modeling. This modeling approach allows for overlap in frequently occurring words, yet it does not primarily focus on word frequencies. Instead, LDA emphasizes the weighting of word importance and word co-occurence, which is reflected in the keywords presented in Table 4. Consequently, despite similarities in frequently occurring words, the topic modeling analysis reveals more diverse and distinctive keywords.

3. Discussion

The thematic patterns in left-wing media tend to emphasize conflict escalation, civilian displacement, and the failure of ceasefire efforts indicating a general opposition to war or armed conflict. Historically and ideologically, the left-wing is known for its opposition to militarism and warfare (Musto, 2022). Leftists often perceive violent actions such as war as closely linked to imperialism and exploitation, which they fundamentally oppose. Left-wing media also frequently discuss security threats (LW2), which aligns with the leftist ideological emphasis on peace, conflict resolution, and human security (Chakma, 2024). These values reflect their broader commitment to upholding human rights (Vignoli and Baraldi, 2023). On the other hand, right-wing ideology places greater emphasis on military action as a means of resolving conflict (Vignoli & Baraldi, 2023). This stance is rooted in adherence to traditional, conservative values and long-standing doctrines. Rightists tend to support the use of military force and prioritize the exclusivity of their ingroup or allied groups (Boussius and Cole, 2010).

Previous studies have shown that U.S. media exhibit certain distinctive patterns in reporting conflicts in the Middle East. For instance, in the conflict in Afghanistan involving the Taliban, U.S. media tended to frame the Taliban as a terrorist group threatening the security of local residents (Aksar et al., 2025). Moreover, the strategies employed by U.S. media were also relatively similar, namely providing continuous exposure to news aspects considered capable of shaping public opinion that a terrorist group posed a threat. Some of these strategies included, for example, exposing footage of panic within conflict zones and the cries of victims (Zappetini & Rezazadah, 2024).

Media framing is often employed as a government strategy. A study conducted by Ko et al. (2025) found that the narrative structure of media, particularly conservative outlets, aligns closely with government documents. This is also reflected in the findings of moral sentiment. In the authority/subversion dimension, right-wing media show relatively lower levels, although the sentiment remains negative. This suggests that right-wing U.S. media tend to evaluate the Israel-Hezbollah conflict as a violation of authority, but only to a limited degree. This may be linked to the diplomatic relationship between Israel and the U.S., in addition to the U.S.'s track record of framing militant groups in the Middle East. Such a tendency is also relevant to the strength of national identity. Conservatism is associated with a strong national identity, characterized by an emphasis on in-group supremacy (Osborne et al., 2017). By contrast, left-wing ideology is by nature negatively associated with authority (Graham et al., 2013). This helps explain why left-wing media demonstrate a high level of negative sentiment of authority, despite the conflict issue.

Moral sentiment in this issue is complex, as it involves several intersecting aspects. Graham et al. (2009) explain that left-wing ideology places greater endorsement on care and fairness, whereas right-wing ideology emphasizes authority, loyalty, and sanctity. Furthermore, MFT distinguishes between two types of moral typology: individualizing (care and fairness) and binding (authority, loyalty, and sanctity) (Graham et al., 2013). This framework helps explain the polarization observed in the present study. Left-wing media tend to focus more on personal issues, such as civilian casualties and displaced persons, while right-wing media emphasize more macro-level concerns, such as stability in the face of terrorist threats. The context of the conflict must also be taken into account. The Israel-Hezbollah conflict often occurs in areas around Lebanon and has resulted in civilian casualties, such as the Beirut bombings and the Pager Attack in September 2024. This is further connected to the power asymmetry between Israel and Hezbollah (Al-Jazeera, 2024). Against this backdrop, it becomes clearer why left-wing media express stronger negative sentiments in the domains of care and fairness, as the scale of civilian casualties is substantial (Argüello-Gutiérrez et. al., 2023). Conversely, from a macro perspective, the conflict does not pose an immediate threat to U.S. security, particularly in the right-wing media's framing. Nonetheless, concerns about war escalation are evident across both media groups.

The differences in topical patterns suggest the presence of coverage bias, which is defined as the tendency of media outlets to report selectively on aspects of an event that align with their own interests or agendas (Baum & Zhukov, 2015). This tendency is influenced by the values and ideological orientations held by the media. As a result, news outlets may downplay or exaggerate certain aspects of an event, especially those that support their ideological stance or favored group. For example, a study by Major (2016) found that American media often downplayed human rights issues in conflict coverage such as wars in the Middle East in order to legitimize national identity narratives. These findings stand in contrast to those of Al-Sarraj and Lubbad (2018), who argue that Western media frequently exhibits a pro-Israel bias in coverage of the Israel-Palestine conflict. This bias has historical roots, particularly through the support of territorial claims via instruments such as the Balfour Declaration. Such historical context contributes to heightened anxieties about potential escalation and the emergence of a new conflict bloc between Israel and Lebanon concerns that may, in fact, be overstated.

The dimension of sanctity presents a particularly complex case. The moral sentiment analysis indicates that right-wing media exhibit lower levels of negative sentiment on sanctity compared to left-wing media in this conflict. This discrepancy may be linked to broader societal dynamics. As previously noted, sanctity belongs to the category of binding moral foundations (Graham et al., 2013), and the Israel-Hezbollah conflict is not perceived as threatening the purity of the broader in-group. Dawson et al. (2021) further explain that sanctity is negatively associated with perspective-taking in terms of empathizing with victims, instead prioritizing symbolic considerations. This pattern also extends to other binding foundations, particularly authority (Dawson et al., 2021). Moreover, Potocka (2021) demonstrates that authority positively predicts acceptance or the drive to engage in violence, whereas care negatively predicts it. Differences in the level of moral sentiment may therefore be explained by ideological tolerance toward violence and civilian casualties. Rightists tend to show greater tolerance for violence and for civilian deaths as collateral effects of war, whether in fictional or real contexts. Conversely, leftists demonstrate greater concern for civilian safety, even when casualties occur as collateral effects (Elad-Strenger et al., 2025).

The finding that all moral dimensions exhibit negative sentiment is particularly noteworthy. In general, both media groups morally evaluate this issue in a negative light. Several factors may account for this outcome. First, concerns regarding human rights may play a role, as contemporary developments in human rights discourse can serve as an additional predisposition in moral sentiment and framing regardless of the ideological stance (Stolerman & Lagnado, 2018). Contextual factors also contribute. Blumenau and Lauderdale (2024) demonstrate that moral sentiment and framing between left-and rightwing groups tend to converge when the issue stimulus is more concrete, regardless of ideology. This implies that the clearer and more tangible the issue and its consequences are, the more similar the resulting moral sentiments become. Another determinant lies in considerations of audience engagement. As institutions dependent on readership, media outlets inevitably adopt strategies to capture readers' attention. On sensitive and controversial issues such as armed conflict, media sources often employ language associated with negative affect regardless of ideology (Mejova et al., 2025), which in turn amplifies the levels of negative moral sentiment. Moreover, high-arousal negative affect positively increases the likelihood of individuals reposting and sharing news content, particularly from biased media sources (Knutson et al., 2024).

4. Conclusion

This study demonstrates that moral sentiment polarization emerges between left-and right-wing U.S. media in reporting on the Israel-Hezbollah conflict. The moral sentiment analysis revealed that both groups share an overall negative orientation, but differ in the moral foundations emphasized: left-wing outlets foreground individualizing values by highlighting civilian suffering and human rights, whereas right-wing outlets stress binding values, framing Hezbollah as a security threat and emphasizing loyalty to Israel and the United States. These findings extend the application of Moral Foundations Theory to large-scale textual data, showing that ideological orientations can be detected not only in individual attitudes but also in media discourse. Practically, the results illustrate how news framing contributes to the reproduction of moral divides in public debates on international conflict. Nevertheless, the study is limited to U.S. media and relies on computational text analysis, which cannot fully capture narrative nuance. Future research could compare coverage across different national contexts or triangulate computational analysis with qualitative approaches. Overall, the study underscores the value of moral sentiment analysis for understanding how ideology shapes media portrayals of conflict, highlighting the intersection of political psychology and media studies.
