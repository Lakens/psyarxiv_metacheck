To check Non-Significant P Value Check

What we found

We found 26 non-significant p values that should be checked for appropriate interpretation.

Show details

Meta-scientific research has shown nonsignificant p values are commonly misinterpreted. It is incorrect to infer that there is ‘no effect’, ‘no difference’, or that groups are ‘the same’ after p > 0.05.

It is possible that there is a true non-zero effect, but that the study did not detect it. Make sure your inference acknowledges that it is possible that there is a non-zero effect. It is correct to include the effect is ‘not significantly’ different, although this just restates that p > 0.05.

How Exact P-Values works

List any p-values reported with insufficient precision (e.g., p < .05 or p = n.s.) or reported as exactly zero (e.g., p = .000).

This module uses regular expressions to identify p-values. It will flag any values reported as p > ? or p < numbers greater than .001. It will also flag p-values reported as exactly zero (e.g., p = .000, p = 0.00), which are mathematically impossible — p-values are never exactly zero and should instead be reported as p < .001.

A p-value that is not the result of a test is not flagged: a table note (“* p < .05, ** p < .01”), a figure legend (“Asterisks indicate significant differences (p < .05)”, “Values in bold are significant at p < .05”) or a stated threshold (“p < .05 was considered significant”, “thresholded at p < .001”). GROBID often puts such notes into the running text, so each p-value is judged by the words in its own clause (the text up to a “;” or a full stop), and never left out when a test statistic belongs to it (“F(1, 7) = 8.03, # p < .05”). The column not_a_test of the table says why a p-value was left out (“marker”, “threshold”, “legend” or “named”).

A p-value with the name of a correction or a test after the p (“pFWE < .05”, “padj < 0.05”, “p Wilcoxon = .02”) is flagged only when a test statistic comes before it in its clause (“t(37) = 7.17, p FWE < .05”). Without one it is mostly the rule that decided what was significant (“genes with padj < 0.05 were selected”); such a p-value is “named” in not_a_test. Notes in other forms, such as a marker after the p-value (“p < .05 (*)“), are still flagged.

This module sometimes flags false positives when sentences discuss how p-value thresholds were set. It can also miss an imprecise p-value that is reported against a threshold (“decreased at the p < .05 significance threshold”).

This module only checks p-values reported in the running text of the manuscript. It cannot (yet) process p-values reported only in tables (as opposed to a table’s footnote text, which the module does see and tries to exclude — see above).

How Data Check works

This module classifies the files in a repository into semantic types (data, codebook, code, software, output, supplemental, readme, asset, other) and, for tabular data files, extracts each column’s type and summary statistics.

The Data Check module consumes the file list produced by repo_check (or any files added via local_path). Each file is classified with rule-based heuristics layered over metacheck’s file_category() and file_types: file names matching README / codebook patterns win first, then an extension crosswalk, then format-locked extension overrides. For every file classified as tabular data that is available locally, the module reads the file head, describes each column with data_col_facets() and computes summary statistics for numeric columns. Every sheet of a spreadsheet that holds a table is read: a file with several such sheets has its columns under source_file = "file.xlsx [sheet]", and the sheet column names the sheet of any spreadsheet with several sheets; a sheet of notes or a codebook is treated as documentation when the file has another table. Following DDI, a column is described by orthogonal facets rather than a single type: representation (numeric/text/datetime/code — how it is stored), measurement_level (Stevens: nominal/ordinal/interval/ratio), concept (what it measures: reaction_time/age/gender/likert/id/…), role (identifier/measure/condition/timestamp), unit, and a quality state (ok/empty/constant). The module defaults to rules-only when llm_use(FALSE): columns the rules cannot resolve (ambiguous 3–20-unique integers, ambiguous character columns) fall back to continuous / text respectively. How Reproducibility Check works

This module assesses whether a paper’s R and Python code can be run on its data. It works in two phases. The static phase (always run) collects the package dependencies the code declares, rewrites the data-file paths that do not work in the repository as the authors organised it, works out the order the scripts must run in, and diagnoses why any referenced input file is unavailable — reporting what a reproduction attempt would involve and where it is likely to break. The execution phase (opt-in, execute = TRUE) then actually runs the code: it copies the repository into a throwaway directory, optionally installs the declared dependencies into a throwaway library, runs each script in order in an isolated subprocess with a per-script timeout, and captures the outcome and full output of each run.

By default (execute = FALSE) the module does not run any code — it performs only static analysis: reading dependencies with the same extractors as code_check, finding the files the code references in the repository, and building a run-order dependency graph. It reports what would be installed and run rather than doing it.

When execute = TRUE, the module additionally runs the downloaded code on your machine — a deliberate, opt-in action gated behind that argument (callr is required for R code). Each script runs in an isolated subprocess so a crash cannot take down the R session; note this isolates crashes, not the filesystem or network. Installs (when install_missing = TRUE) and the throwaway run library never touch your main R library. Each script’s outcome is one of ran_ok, errored, timed_out, dependency_unavailable, not_parsed, run_by_source (an R script another script runs with source(), which is run only inside that script, since on its own it lacks the packages and objects the sourcing script sets up first), run_by_import (a Python file other files import, a module rather than a script, unless it has an if __name__ == "__main__": block), jags_model (a JAGS or BUGS model saved with an R extension, which another script reads) or not_r_content (a file that is not R at all, such as a JSON or HTML dump); these last two are not run and are not failures. python2 marks Python 2 code that was not run. With sandbox = "docker" such code runs with Python 2.7 (option metacheck.docker_image_py2; FALSE turns this off), which modifications records; it is never converted, since that can change results. defines_functions is a file that only defines functions, which is used, not run (table$used_by names the scripts that use it), and not_analysis is a file of software rather than of the analysis: a package’s code, tests, documentation or setup.py, a copy of a tool, a web application, a script a program wrote (table$not_analysis_why says which); neither is run or counted as a script. docker_failed means the container never started, which says nothing about the script, so it keeps the light from being green but does not make it red. needs_a_person is a script that stopped because it asks a person to choose a file or answer a question, or that starts an app, and needs_internet one that stopped because the network is off in a Docker run, or, with internet = TRUE, could not reach what it asked for; download_too_large is a script stopped for downloading more than the limits allow (see internet), and out_of_memory one that, or a program it started (such as a compiler), ran out of the memory each script may use. Full text

Abstract

Equanimity, a regulatory quality cultivated through mindfulness practices, refers to the capacity to maintain a balanced mental stance toward pleasant and unpleasant experiences without being automatically driven toward attachment or avoidance. Although theoretically expected to weaken the influence of evaluation on behavior, empirical evidence linking equanimity to observable behavioral dynamics remains limited. The present study examined associations between equanimity, eating-disorder vulnerability, and automatic approach-avoidance tendencies toward food cues. Participants (N = 215) completed self-report measures of equanimity, eating-disorder risk, mindful eating, self-compassion, experiential avoidance, and body acceptance. A subset of 183 participants additionally completed a food-specific approach/avoidance task using stimuli varying in hedonic value. At the dispositional level, equanimity was associated with lower eating-disorder vulnerability and experiential avoidance, and greater self-compassion, body acceptance, and mindful eating. These associations were largely driven by the even-minded state of mind facet of equanimity, whereas hedonic independence showed weaker, more circumscribed relationships with eating-and body-related variables. Behavioral analyses revealed faster avoidance of low-hedonic than high-hedonic food cues, but neither equanimity nor its facets predicted reaction times or moderated hedonic effects on approach/avoidance dynamics. These findings suggest that while equanimity is associated with reduced eating-disorder vulnerability at the trait level, its regulatory role may not manifest in the earliest motor expressions of food-related action tendencies. Instead, equanimity may primarily influence later stages of regulation, such as the interpretation, tolerance, or behavioral management of emerging impulses. However, this interpretation warrants further exploration in experienced meditators, as equanimity in the general population may differ from that cultivated through prolonged contemplative practice.

INTRODUCTION

Beyond Non-Judgment: Equanimity as Decoupling of Evaluation and Action

Mindfulness-based approaches have attracted considerable research interest for their effects on affective functioning, stress-related processes, and self-regulatory behavior (Baer, 2009; Dahl et al., 2015; Dambrun & Ricard, 2011; Eberth & Sedlmeier, 2012; Eberth et al., 2019; Garland et al., 2015; Gu et al., 2015; Khoury et al., 2015; Lutz et al., 2008; Sedlmeier et al., 2012; Stinus & Berjot, 2026). Despite mounting evidence for these benefits, a central challenge remains to identify which qualities cultivated through mindfulness account for its effects and how these can be captured using behavioral measures rather than relying exclusively on self-report. Mindfulness is characterized by present-centered awareness, attentional stability, and an open, non-reactive orientation toward experience (Bishop et al., 2004; Kabat-Zinn, 2003; Shapiro et al., 2006). Though these defining characteristics place equanimity at the very core of mindfulness and its beneficial effects, equanimity remains underexplored (Desbordes et al., 2015; Eberth et al., 2019; Hadash et al., 2016).

Originating in Buddhist philosophy under the term upekkhā (Pāli; upekṣā in Sanskrit), equanimity refers to an even-minded stance toward pleasant, unpleasant, or neutral experiences, maintaining mental balance without attachment or aversion (Desbordes et al., 2015). Far from implying indifference, apathy, or emotional suppression, equanimity preserves the informational content of emotional experiences while weakening their capacity to dictate behavior, a regulatory quality associated with improved well-being and psychological resilience (Desbordes et al., 2015; Eberth et al., 2019; Hadash et al., 2016; Juneau et al., 2020a Juneau et al., , 2020b Juneau et al., , 2021)). Emotional blunting, by contrast, is associated with reduced well-being, impaired functioning, and poorer treatment outcomes (Christensen et al., 2022; Duek et al., 2023; Kikuchi et al., 2025; Ma et al., 2021; Sampson et al., 2024). This distinction maps cleanly onto contemporary clinical perspectives emphasizing that mental health depends less on eliminating internal experiences than on changing how we respond to them (Bishop et al., 2004; Dambrun & Ricard, 2011; Shapiro et al., 2006; Stinus & Berjot, 2024).

Beyond acceptance or non-judgment, equanimity encompasses a broader pattern of emotional and motivational regulation, yet remains relatively underexplored in contemplative science (Desbordes et al., 2015; Eberth et al., 2019; Hadash et al., 2016; Juneau et al., 2020a Juneau et al., , 2020b Juneau et al., , 2021;; Vago & Silbersweig, 2012). The decoupling model of equanimity conceptualizes this regulation as a weakening of the automatic link between affective and cognitive evaluations and the impulse to act upon them (Hadash et al., 2016). Thus, experiences may still be evaluated as pleasant or unpleasant, but their hedonic tone exerts less immediate influence over behavior.

Recent models distinguish between two complementary facets of equanimity (Juneau et al., 2020a). The first facet, coined 'even-minded state of mind' (EMSM), refers to emotional stability and reduced volatility in various forms of affective contexts (e.g., maintaining balance in the face of criticism, praise, or unexpected situations). The second facet, 'hedonic independence' (HI), refers more specifically to the diminished translation of pleasurable or displeasing evaluations into approach or avoidance motivations, respectively.

Equanimity, Reactivity, and Eating Disorder Risk

Eating disorders are increasingly understood as disorders of self-regulation rather than of eating behavior alone (Dingemans et al., 2009 (Dingemans et al., , 2017;; Lavender et al., 2015; Leehr et al., 2015).

Transdiagnostic approaches highlight the role of heightened sensitivity to food, body, and control-related cues, which are associated with rigid and repetitive patterns of experiential avoidance, restriction, and compulsive engagement (Fairburn et al., 2003; Harrison et al., 2010 Harrison et al., , 2011;; Haynos & Fruzzetti, 2011; Hyde-Smith et al., 2024; Lampard et al., 2011; Treasure et al., 2012; Wildes et al., 2010). These patterns are further maintained by amplified affective responses and difficulties disengaging from evaluative thoughts, such as self-critical, bodyrelated, or control cognitions (Rawal et al., 2010; Vitousek et al., 1998; Williamson et al., 2004).

In this sense, eating disorder risk reflects a broader vulnerability to reactivity and inflexibility when processing emotionally salient stimuli.

Consistent with this view, eating disorder symptomatology has been linked to psychological processes that stand in conceptual opposition to equanimity, including experiential avoidance, heightened self-judgment, body preoccupation, and reduced self-compassion (Ferreira et al., 2013; Lavender et al., 2015; Rawal et al., 2010; Schoenefeld & Webb, 2013). Individuals at higher risk tend to report greater difficulty tolerating unpleasant internal experiences and a greater reliance on control-oriented strategies to manage affect (Dingemans et al., 2009; McLean et al., 2007; Vuillier et al., 2021; Wildes et al., 2010). Such strategies not only sustain disordered eating patterns but also undermine psychological adjustment and treatment outcomes, reinforcing the importance of how one relates to internal experiences rather than their mere presence (Aldao, 2010; Brockmeyer et al., 2018; Stinus & Berjot, 2024).

Equanimity offers a theoretically coherent lens through which to integrate these findings. By supporting a balanced, non-reactive stance toward cognitive and affective experiences, equanimity can weaken the translation of food-, body-, and self-related evaluations into rigid avoidance or compulsive action (Desbordes et al., 2015; Hadash et al., 2016; Juneau et al., 2020a). This offers a natural bridge between contemplative theories of regulation and contemporary models emphasizing flexibility and reduced automatic reactivity as protective factors in mental health (Eberth & Sedlmeier, 2012; Eberth et al., 2019; Kashdan & Rottenberg, 2010; Vago & Silbersweig, 2012). Together, these perspectives provide a theoretical rationale for examining both self-reported dispositions and observable behavioral expressions of equanimity in relation to eating disorder vulnerability.

Experimental Approach to Equanimity: the Approach-Avoidance Task

Translated into psychological terms, equanimity operates as a reduced tendency to grasp at what feels pleasant and push away what feels unpleasant, in other words, the regulation of approach/avoidance dynamics. This makes reaction-time paradigms that assess approach vs avoidance tendencies and biases at earlier stages of processing particularly relevant for empirical investigation of equanimity. The Visual Approach/Avoidance by the Self Task (VAAST, Aubé et al., 2019; Julliard et al., 2026; Rougier et al., 2018) assesses the speed of approach or avoidance responses to stimuli and typically reveals a compatibility effect: a bias in which responses are faster when movement direction aligns with stimulus evaluation (e.g., faster approach toward positive stimuli, faster avoidance of negative stimuli). These effects have been interpreted as behavioral signatures of motivational processes sensitive to individual differences and contextual factors (Papies et al., 2012; Ostafin et al., 2012). This approach is particularly relevant to eating behavior. Food cues are biologically salient, socially reinforced, and ubiquitous in our daily life, eliciting approach tendencies that can operate independently of reflective intentions or explicit goals (Berridge & Robinson, 2016; Castellanos et al., 2009; Ferriday & Brunstrom, 2011; Kelley et al., 2005; Stinus et al., 2024).

Among individuals with eating disorder vulnerability, such impulses are frequently met with heightened control efforts, avoidance, or rigid regulatory strategies, suggesting a tight coupling between evaluative responses and action tendencies (Dingemans et al., 2009; Fairburn et al., 2003; Haynos & Fruzzetti, 2011; McLean et al., 2007; Treasure et al., 2020; Vuillier et al., 2021; Wildes et al., 2010). Assessing these tendencies at early stages of processing thus provides a privileged window into regulatory mechanisms implicated in eating disorder vulnerability (Leehr et al., 2015; Veenstra & de Jong, 2012).

Within this context, the VAAST offers a suitable experimental tool to assess whether equanimity modulates approach/avoidance dynamics toward food stimuli (Aubé et al., 2019; Julliard et al., 2026; Rougier et al., 2018). From a decoupling perspective, higher equanimity should be associated with a reduced compatibility effect between low-and highly hedonic stimuli, reflecting weaker hedonic modulation of approach/avoidance biases, rather than with the absence of evaluative processing per se (Hadash et al., 2016; Desbordes et al., 2015).

The present study

Bridging contemplative, clinical, and cognitive science, the present study combines self-report measures with behavioral indices to assess equanimity's relationship to eating disorder vulnerability. To capture dispositional aspects of equanimity and eating-related self-regulation, participants completed self-report measures of equanimity, eating disorder risk, mindful eating, self-compassion, experiential avoidance, and body image concerns. Experiential avoidance, characterized by rigid attempts to escape unwanted internal or external experiences (Akbari et al., 2022; Wang et al., 2024), represents a conceptual opposite of equanimity (Juneau et al., 2021). Self-compassion (Neff, 2023) and body acceptance (Tylka & Wood-Barcalow, 2015) together reflect a softened evaluative stance toward the self and body, with reduced selfjudgment and diminished threat reactivity. Mindful eating (Mantzios, 2023; Minari et al., 2024; Tapper, 2022; Van Beekum et al., 2024) captures the application of non-reactive awareness specifically within the eating domain, where hedonic cues and control-related concerns frequently interact. Based on our theoretical framework, we hypothesize that equanimity will be associated with lower eating disorder risk and with a psychological profile characterized by reduced experiential avoidance, greater self-compassion, and healthier eating-related dispositions.

At the behavioral level, the present study uses a modified online VAAST (see Julliard et al., 2026; Pillaud et al., 2024) featuring food pictures varying in hedonic value. We hypothesize an approach-avoidance compatibility pattern, with faster approach responses to highly hedonic foods and faster avoidance responses to low-hedonic foods. Based on the decoupling model of equanimity (Hadash et al., 2016), we also hypothesize that higher equanimity will be associated with a reduced compatibility effect, reflecting weaker hedonic modulation of action tendencies.

METHOD

Participants

A total of 215 participants were included in the study. Participants were primarily university students recruited on academic campuses. Additional participants were recruited through online announcements posted on professional social networks (e.g., LinkedIn). The study consisted of a questionnaire phase and a behavioral task. All participants completed the self-report measures, while a subset of 183 participants (165 women, 18 men, MAge = 24.9, SD = 8.8) proceeded to complete the Visual Approach/Avoidance by the Self Task (VAAST).

All participants provided informed consent prior to participation. They were informed of their right to withdraw from the study at any time and that all data would be collected and stored in anonymized form. No financial compensation was provided. The study was conducted in full compliance with the Declaration of Helsinki (2008) and French regulations on research ethics. Ethical approval for this research was obtained from the Comité de déontologie et d'intégrité scientifique (CEDIS) of Nantes University (IRB No. IORG0011023; Project "MIND-EAT").

Procedure and Design

The study was implemented online using Qualtrics® and consisted of two successive phases: in the first phase, participants completed a set of self-report questionnaires, in a second phase, they proceeded to complete a modified food version of the Online Visual Approach/Avoidance by the Self Task (VAAST) using jsPsych (De Leeuw, 2015).

The procedure started with a short description of the study and its objectives. Before completing the questionnaires, participants provided demographic information (i.e., sex, age, educational level, occupational status), as well as information regarding their habits, dietary practices, and social media usage, including whether social media were used during meals.

Self-Report Measures

Validated self-report measures were administered to assess eating disorder risk, mindful eating, self-compassion, experiential avoidance, body image concerns, and equanimity.

Equanimity was measured using the EQUA-S scale (Juneau et al., 2020a), which assesses the tendency to maintain a neutral, balanced emotional stance toward stimuli of varying emotional valence, including emotional stability and stress reactivity. Both global equanimity and the EMSM and HI subscales were computed. Higher scores reflect greater equanimity.

Eating disorder risk was assessed using the SCOFF questionnaire (Luck et al., 2002), a 5-item screening tool designed to detect disordered eating behaviors (e.g., "Do you worry you have lost control over how much you eat?"). Higher SCOFF scores reflect greater risk for an eating disorder.

Mindful eating was measured using the Mind-Eat scale (Van Beekum et al., 2024), a 24-item questionnaire that captures individual differences in mindful eating across six facets, including Awareness (e.g., "When I eat, I take time to appreciate the taste of food"), Non-reactivity (e.g., "When I see a food I want, I can't help but eat it"), Openness (e.g., "I like to discover new foods"), Gratitude (e.g., "I feel gratitude for the people who prepared the food I eat"), Nonjudgment (e.g., "I blame myself when I feel like I have eaten too much"), and Hunger/Satiety (e.g., "I trust my body to know how much to eat"). Reverse-scored items were recoded prior to analysis and items were averaged to create a global score reflecting greater mindful eating.

Self-compassion was assessed using the Self-Compassion Scale -Short Form (SCS-SF, Raes et al., 2011), which evaluates self-kindness, self-judgment, common humanity, and mindfulness (e.g., "When I'm going through a very hard time, I give myself the caring and tenderness I need"). Higher scores reflect higher self-compassion.

Experiential Avoidance was measured using the Brief Experiential Avoidance Questionnaire (BEAQ, 15 items; Gámez et al., 2014), assessing tendencies to avoid aversive or distressing internal (e.g., "I make a lot of effort to avoid painful emotions") or external (e.g., "I do everything I can to avoid unpleasant situations") experiences. Higher scores reflect a greater tendency to avoid unpleasant or uncomfortable states of mind or situations.

Body Acceptance was assessed using the Body Appreciation Scale (BAS, 10 items; Tylka & Wood-Barcalow, 2015), which presents 10 items measuring individuals' acceptance, respect, and positive attitudes toward their bodies (e.g., "I feel love for my body", "I appreciate the different and unique characteristics of my body"). Higher scores reflect greater body acceptance.

The Visual Approach/Avoidance by the Self Task

Following completion of the self-report measures, a subset of 183 participants performed a modified version of the VAAST, designed to assess more automatic tendencies to approach or avoid food-related stimuli. They were then presented with images of food items and asked to indicate whether they recognize each food. During the task, food images were displayed against a city alley background and appeared either as a square or a diamond (Figure 1). Depending on the geometric shape, participants were instructed to perform either an approach movement or an avoidance movement by pressing a designated key. Approach responses required pressing a keyboard key located closer to the screen (the T key), whereas avoidance responses required pressing a keyboard key located closer to the participant (the B key), thereby increasing perceived distance from the stimulus. To control for potential confounds related to stimulus shape, task instructions were counterbalanced across participants: for half of the participants, square-shaped images required approach responses and diamond-shaped images required avoidance responses; for the other half, the mapping was reversed. Participants were instructed to respond using the index finger of their dominant hand. Dynamic visual feedback was incorporated into the task: approach responses resulted in a zoom-in effect on the stimulus along with the whole city alley environment, whereas avoidance responses triggered a zoom-out effect. In the case of incorrect responses, negative feedback was presented in the form of a red cross.

Figure 1. Trial structure of the Visual Approach/avoidance by the Self Task. Each trial began with a fixation circle displayed until participants pressed the G key, followed by a fixation cross presented for a randomly varying duration of 800-2000ms. A food stimulus then appeared in the virtual environment, requiring an approach or avoidance response. Approach responses produced a zoom-in effect, whereas avoidance responses produced a zoom-out effect. The resulting display remained visible for 650ms. Incorrect responses triggered a red cross below the stimulus, which remained until the participant provided the correct response.

Instructions were presented twice: once before a practice block to ensure task comprehension, and once again before the experimental block from which reaction times were analyzed. The practice block comprised 12 trials, using a set of images distinct from those used in the experimental phase. The experimental block consisted of 120 trials presented in random order and included the images previously rated by participants. The primary outcome measure was reaction time (RT), used to assess whether participants approached or avoided food stimuli more rapidly depending on their hedonic value, and whether this tendency was moderated by equanimity.

Data preparation and Statistical Analyses

A series of exclusion criteria were applied to ensure data quality. First, participants who failed the attention check (e.g., responding "black" or "green" instead of the target word "baguette") were removed. Second, male participants were excluded to focus on female participants, consistent with previous eating behavior research. Third, participants with a mean accuracy below 70% in the approach/avoidance task were excluded. The final sample consisted of 153 female participants (Age M = 22.6, SD = 4.75). Only trials with correct responses were included in the analyses. Trials with reaction times shorter than 250ms or longer than 1500ms were excluded. Reaction times were log-transformed prior to analysis to correct for skewness.

Repeated-measures analyses were conducted to test the effects of Movement (Approach vs. Avoidance) and Food Hedonicity (High vs. Low). Linear mixed-effects models were used for trial-level analyses, including random intercepts for participants and stimuli, and random slopes when appropriate. Pearson's correlations were computed to examine associations between behavioral indices and self-report measures.

RESULTS

Associations Between Equanimity, Eating Disorder Risk, and Regulatory Variables

Pearson's correlations were computed to examine relationships between age and self-reported psychological measures (see Table 1). Correlational analyses provided convergent support for the conceptualization of equanimity as a regulatory disposition associated with reduced reactivity and enhanced adaptive self-regulation. At the global level, equanimity was negatively associated with eating disorder symptomatology (r = -.24, p < .001) and experiential avoidance (r = -.39, p < .001), while positively associated with mindful eating (r = .23, p = .004), selfcompassion (r = .54, p < .001), and body acceptance (r = .27, p < .001). The two facets of equanimity demonstrated both strong convergence and functional differentiation. Even-minded state of mind (EMSM) was associated with a psychological profile consistent with emotional stability, including a negative association with experiential avoidance (r = -.36, p < .001), and positive associations with self-compassion (r = .61, p < .001), mindful eating (r = .33, p < .001), and body acceptance (r = .36, p < .001). In contrast, hedonic independence (HI), while moderately related to EMSM (r = .21, p = .001), displayed weaker or non-significant associations with eating-and body-related constructs. However, HI remained negatively associated with eating disorder symptomatology (r = -.15, p = .03) and experiential avoidance (r = -.23, p = .001), and positively correlated with self-compassion (r = .17, p = .01), suggesting that this facet may reflect a more specific regulatory mechanism related to the decoupling of evaluative experience from action tendencies rather than broad emotional stabilization.

Behavioral Approach-Avoidance Dynamics

Primary test of the compatibility effect in the female only sample

Moderating Role of Equanimity and Mindful Eating on Avoidance Behavior

Given that hedonic effects consistently emerged in avoidance trials but not approach responses, subsequent analyses focused specifically on avoidance trials to more directly characterize the behavioral process underlying the observed asymmetry. This analytic step allowed testing whether individual differences variables predicted the component of performance most sensitive to hedonic value, rather than the weaker and more inconsistent compatibility effect.

Linear mixed-effects models were therefore conducted on avoidance trials only, examining the effects of Hedonicity and individual-difference moderators (equanimity and mindful eating), with random intercepts for participants and stimuli and by-participant random slopes for Hedonicity.

We first examined global equanimity, which did not significantly predict avoidance response times, t(149.30) = 0.59, p = .554, nor interact with Hedonicity, t(150.80) = 0.48, p = .631. The main effect of Hedonicity was not significant in this model, t(13.72) = 1.66, p = .119. We next tested HI, the facet theoretically linked to reduced coupling between evaluation and action tendencies. Neither the main effect of HI, t(149.30) = 0.27, p = .790, nor its interaction with Hedonicity, t(151.60) = 0.92, p = .358, reached significance. Analyses examining EMSM likewise revealed no significant main effects or interactions in avoidance trials (all ps > .20).

Robustness Checks Including Male Participants

Male participants had been excluded a priori to maintain comparability with prior eatingbehavior research predominantly conducted in female samples. However, to evaluate the robustness and generalizability of the behavioral pattern, all primary analyses were therefore repeated in the full sample, excluding only one participant with task accuracy below 70%.

In this larger sample, the repeated-measures ANOVA revealed significant main effects of Movement, t(169) = 5.75, p < .001, dz = 0.44, 95% CI [0.28, 0.60], and Hedonicity, t(169) = 2.46, p = .015, dz = 0.19, 95% CI [0.04, 0.34]. Importantly however, the Movement × Hedonicity interaction (reflecting the predicted approach/avoidance compatibility effect) reached significance, t(169) = 2.12, p = .035, dz = 0.16, 95% CI [0.01, 0.31]. As in the primary analyses, hedonicity significantly influenced avoidance trials, t(169) = 3.26, p = .001, dz = 0.25, 95% CI [0.10, 0.40], but not approach trials, t(169) = 0.10, p = .920, dz = 0.01, 95% CI [-0.14, 0.16], suggesting that the compatibility effect was primarily driven by faster avoidance of lowhedonic foods.

Trial-level linear mixed-effects models showed a comparable pattern. The analysis revealed a significant main effect of Movement, t(177.38) = 5.93, p < .001, and a significant Movement × Hedonicity interaction, t(178.30) = 2.11, p = .037, while the main effect of Hedonicity remained non-significant, t(12.99) = 0.80, p = .440.

Moderation Analyses in the Full Sample

Moderation analyses were also repeated in the full sample to assess robustness of the null effects. Because the Movement × Hedonicity interaction reflecting the compatibility effect reached statistical significance when male participants were included, moderation was examined both on avoidance trials and on the full compatibility structure including Movement and Hedonicity.

However, avoidance-focused models showed the same null results as in the female-only sample.

Including male participants yielded no significant main effects of Hedonicity (global equanimity: t(13.57) = 1.57, p = .139; HI: t(13.51) = 1.57, p = .139; EMSM: t(13.56) = 1.57, p = .139; mindful eating: t(13.58) = 1.57, p = .139), no significant effects of the moderators (global equanimity: t(165.77) = 0.66, p = .513; HI: t(165.91) = 0.31, p = .761; EMSM: t(165.78) = 1.08, p = .284; mindful eating: t(166.00) = 0.53, p = .596), and no Hedonicity × Moderator interactions (all ps ≥ .135). Thus, the absence of moderation effects did not depend on sample restriction.

To ensure that the absence of moderation effects was not specific to avoidance-focused analyses, models were subsequently re-estimated using the full compatibility effect. Across models however, global equanimity, HI, and EMSM showed no significant main effects (global equanimity: t(165.59) = 1.04, p = .301; HI: t(165.66) = 0.09, p = .922; EMSM: t(165.62) = 1.31, p = .192), and did not interact with Movement or Hedonicity (all ps ≥ .13). Though, the Movement × Hedonicity interaction remained significant in all models (global equanimity: t(173.97) = 2.19, p = .030; HI: t(174.37) = 2.19, p = .030; EMSM: t(174.20) = 2.19, p = .030), no higher-order Movement × Hedonicity × Moderator interactions were observed (all ps ≥ .13).

Taken together, these supplementary analyses indicate that including male participants strengthened the overall compatibility effect, but did not alter the absence of moderation by equanimity or mindful eating.

DISCUSSION

The present study sought to investigate equanimity in the context of eating-disorder vulnerability by combining self-report indices with a behavioral measure of automatic approach/avoidance tendencies toward food cues; the Visual Approach/Avoidance by the Self Task (VAAST). Specifically, we examined whether (1) food hedonicity modulated approach and avoidance responses and (2) equanimity and its two facets, even-minded state of mind (EMSM) and hedonic independence (HI) reduced this hedonic modulation, consistent with the hypothesis that equanimity decouples evaluation from action.

Equanimity's protective role lies in even-mindedness

At the dispositional level, equanimity showed a broadly adaptive nomological network. Higher equanimity was associated with lower eating-disorder risk and experiential avoidance, and with higher mindful eating, self-compassion, and body acceptance. This convergent profile suggests that equanimity reflects a regulatory stance characterized by reduced emotional reactivity and greater flexibility to internal experiences, processes that are theoretically protective given the etiology of eating-disorder vulnerability (Aldao, 2010; Haynos & Fruzzetti, 2011; Kashdan & Rottenberg, 2010; Lavender et al., 2015). Equanimity's effects were largely carried by EMSM, whereas HI displayed a more restricted pattern, with weaker associations with experiential avoidance and self-compassion, and no meaningful relation with mindful eating or body acceptance.

Thus, equanimity's association with eating disorder vulnerability appears mainly driven by even-mindedness (the capacity to maintain balance despite emotional arousal) rather than HI.

Similarly, Juneau et al. (2020) reported weaker or absent associations between HI and positive outcomes (e.g., non-judgment, non-reactivity, acceptance, positive reappraisal, or low neuroticism), though HI was more strongly linked to reduced sensitivity to reward. One plausible interpretation is that EMSM maps onto a broader regulatory disposition relevant to eating behaviors, involving reduced affective volatility and threat-driven avoidance, alongside greater self-compassionate coping. Given the links between eating-disorders, rigid control, selfjudgment, and experiential avoidance (Rawal et al., 2010; Vitousek et al., 1998; Williamson et al., 2004), an ability to maintain emotional balance may naturally mitigate risk, whereas HI may serve a more circumscribed (e.g., situational, stimulus-driven) regulatory function. Given its association with reduced sensitivity to reward (Juneau et al., 2020), HI might instead protect against incentive-driven eating rather than hunger-driven eating. The reduced motivational capture by hedonic cues provided by HI might be especially relevant in contexts of cravings, hedonic overeating, or food-based coping strategies. Our non-clinical sample may have exaggerated the phenomenon: if HI is particularly relevant to craving-driven or reward-based coping, its effects may be more detectable in populations with heightened incentive sensitivity or binge-type vulnerabilities.

Limited behavioral regulation of equanimity on automatic approach/avoidance biases

Behavioral results were more nuanced, providing limited support for the predicted approach/avoidance compatibility effect. In the female-only sample, approach responses were faster than avoidance responses, consistent with previously reported differences of approximately 20ms (Paulus & Wentura, 2016; Wentura & Paulus, 2024). However, hedonic value did not reliably produce a symmetric compatibility pattern, as hedonic modulation emerged only for avoidance responses, with low-hedonic foods avoided faster than highly hedonic foods. Therefore, moderation analyses were also conducted specifically on avoidance responses. Neither global equanimity nor its facets, or mindful eating, predicted avoidance latencies or moderated hedonic effects. Reintroducing male participants yielded a significant compatibility effect, but equanimity and mindful eating still failed to account for variability in approach/avoidance biases.

Methodological and conceptual limitations

Several methodological and conceptual considerations warrant caution when interpreting these findings. First, the present study was conducted in a non-clinical population, limiting the generalizability of our findings to individuals with diagnosed eating disorders. This distinction is particularly relevant to the behavioral results. Approach/avoidance paradigms typically reveal their strongest effects when the motivational systems are strongly engaged. In eating behavior, such engagement is often particularly pronounced in individuals displaying heightened reward sensitivity, frequent cravings, or binge-type eating patterns (Berridge & Robinson, 2016; Ferriday & Brunstrom, 2011; Leehr et al., 2015). In a relatively healthy population, food stimuli may fail to elicit impulses sufficiently intense to reveal differences in rapid motor responses.

This possibility may partly account for the absence of behavioral moderation, although it cannot be established from the present data. Future research may therefore benefit from examining equanimity in populations with elevated eating-disorder risk, with potentially stronger foodrelated impulses.

Another conceptual limitation concerns the extent to which dispositional equanimity, as measured in a non-meditating population, captures the same 'equanimity' cultivated through contemplative practice. In Buddhist traditions, equanimity (upekkhā) is portrayed as a highly specific mental stance, cultivated over years of meditation practice, a decentered awareness of unfolding experience allowing evaluative reactions to arise without automatically generating attachment or aversion. It is plausible that self-report measures used in non-meditating populations capture functionally related tendencies (e.g., emotional balance, cognitive inhibition) that share certain features, but remain qualitatively distinct from the full phenomenological stance cultivated via long-term contemplative practice. This distinction does not invalidate the psychometric operationalization of dispositional equanimity, but questions whether the regulatory dynamics associated with contemplative training can be inferred from trait-level variability in non-meditating samples. Studies involving experienced contemplative practitioners would help clarify this issue.

Several features of the VAAST may also have limited its sensitivity to approach/avoidance tendencies. Although implemented as a reaction-time task measuring rapid, relatively automatic action tendencies, our VAAST did not impose any response-speed constraints incentivizing participants to accelerate (e.g., "TOO SLOW!" feedbacks when time exceeds a fixed threshold or 110% of participant's mean response time) other than mere instructions. In speeded categorization paradigms automatic biases often emerge under time pressure (e.g., Elimari & Lafargue, 2023 , 2024; Elimari et al., 2025; Lannoy et al., 2018 Lannoy et al., , 2020)), but when participants can respond at a comfortable pace, these millisecond-level tendencies tend to be diluted by additional processing time, potentially flattening compatibility effects and reducing the task's sensitivity to both hedonic modulation and individual differences. Furthermore, approach and avoidance responses relied on key presses that were symbolically opposed but motorically similar. Unlike paradigms involving directional movements (e.g., joystick pushing/pulling), both responses required similar finger movements. Despite zoom-in/zoom-out feedback, this motor-level symmetry may have weakened the embodiment of approach/avoidance tendencies (but see Julliard et al., 2021; Rougier et al., 2018).

Finally, the hedonic manipulation may have varied degrees of appetitiveness rather than establishing a true positive/negative contrast. In our task, low-hedonic foods (e.g., spinach, cod) were likely experienced as neutral rather than genuinely aversive, eliciting graded preferences rather than strong motivational responses.

Such distinctions may matter at a deliberative level without necessarily engaging the more automatic processes underlying rapid approach/avoidance behavior (De Neys, 2025; Elimari, 2023; Elimari & Lafargue, 2023 , 2024; Evans, 2008; Strack & Deutsch, 2004). Because approach toward food constitutes the default, highly automatic, intrinsically rewarding, motivationally salient tendency, fine-grained reflective differences may not substantially alter approach impulses. Avoidance, by contrast, is less habitual toward biologically relevant sources and may thus involve greater decisional processing (as indicated by the longer latencies in avoidance responses), allowing subjective preferences to exert greater influence. This asymmetry might explain why hedonic modulation emerged primarily in avoidance (see Clark & Elimari, 2026, for a broader discussion of asymmetries in behavioral biases). More broadly, the relatively weak hedonic contrast may have generated insufficient automatic reactivity for individual differences in equanimity to become detectable.

Future research may benefit from strengthening hedonic salience using more clearly appetitive and aversive stimuli. Directionally distinct motor responses (e.g., pushing versus pulling movements, approach-inhibition contrasts) could also strengthen embodied evaluation-action mapping, although such implementations have their own limitations (van Dantzig et al., 2008).

Finally, stricter temporal constraints or performance-contingent feedback could enhance reliance on rapid, pre-reflective processes and reduce opportunities for deliberative correction.

Together, these refinements would provide a more stringent test of whether equanimity decouples hedonic evaluation from automatic action.

Equanimity as a regulatory factor in eating-disorder vulnerability

Eating disorders are increasingly understood not as mere disturbances of dietary behavior or physiology, but as disorders of self-regulation involving heightened emotional reactivity and rigid responses to internal experiences (Dingemans et al., 2009 (Dingemans et al., , 2017;; Lavender et al., 2015; Leehr et al., 2015). Transdiagnostic models emphasize that vulnerability emerges from amplified sensitivity to body-related or food cues, alongside inflexible attempts to manage resulting distress through avoidance, restriction, or compulsive engagement (Fairburn et al., 2003; Harrison et al., 2010 Harrison et al., , 2011;; Haynos & Fruzzetti, 2011; Treasure et al., 2012). The dispositional associations observed in the present study align with this framework and previous research linking eating-disorder vulnerability to experiential avoidance, self-critical evaluation, and body-related threat sensitivity (Ferreira et al., 2013; Lavender et al., 2015; Rawal et al., 2010; Schoenefeld & Webb, 2013). They also support models of psychological flexibility emphasizing the importance of adaptive responses to internal experiences (Kashdan & Rottenberg, 2010; Vago & Silbersweig, 2012; Eberth & Sedlmeier, 2012).

Beyond the methodological explanations discussed above, the dissociation between dispositional associations and null behavioral moderation effects raises a theoretical possibility: equanimity may exert its influence at later stages of processing, such as appraisal, tolerance of internal experiences, or deliberate behavioral decision-making, rather than directly modulating early approach/avoidance tendencies. Clinical models increasingly ascribe maladaptive eating behaviors to rigid attempts to control or escape distressing internal experiences, rather than distress itself (Aldao, 2010; Brockmeyer et al., 2018; Dingemans et al., 2009; McLean et al., 2007; Vuillier et al., 2021; Wildes et al., 2010). Equanimity might therefore contribute to eatingrelated regulation by influencing how motivational impulses and emotional experiences are handled once they arise, rather than preventing their initial emergence. However, the present findings cannot establish this temporal distinction, particularly given the methodological limitations mentioned.

This raises a broader question: where in the sequence linking perception, evaluation, motivation, and action does equanimity begin to matter? Potential regulatory targets of eatingrelated vulnerability include (1) a greater capacity to remain present with cravings or bodyrelated discomfort without acting on them, (2) reduced escalation of affective responses following evaluation, (3) greater decentering from evaluative thoughts (e.g., judgments about food, weight, self-worth), or (4) increased flexibility in translating impulses and biases into action. Longitudinal and intervention studies will be necessary to test whether cultivating equanimity strengthens these regulatory capacities and reduces eating-related vulnerability.

Conclusion

Taken together, the present study offers a differentiated view of equanimity in the context of eating-related vulnerability. At the dispositional level, equanimity showed a coherent network of associations with lower eating-disorder risk and more adaptive psychological functioning, with its EMSM component emerging as the primary driver of these relationships. HI, by contrast, appeared more circumscribed, potentially reflecting a narrower role in regulating reward-driven or craving-based eating rather than broader affective stabilization. Behavioral findings, however, provided no evidence that equanimity modulated rapid approach/avoidance tendencies toward food cues. Although methodological limitations prevent firm conclusions about the absence of such effects, these findings raise the possibility that equanimity may be more relevant to downstream regulatory processes than to the initial emergence of motivational impulses. Clarifying this distinction will require paradigms capable of robustly engaging automatic motivational systems while capturing subsequent regulatory processes, particularly in populations characterized by greater eating-related vulnerability. Understanding these mechanisms will be essential for identifying potential therapeutic targets in eating disorders.
