  • Column names are matched against identifying words in English and other European languages (email, telefoonnummer, geboortedatum, …). A column called phone_number flags whether or not it holds one, and an empty or already-anonymised column flags on its name alone.
  • Values are matched against the shape of an identifier. An IP address pattern also matches a version string or a dotted numeric code; a card-number pattern requires both a real issuer prefix and a checksum, but a long numeric ID can still coincide.
  • Free text is flagged when a column holds long, mostly-distinct prose — the shape open-ended answers take. Most such columns contain no names at all.

An a priori power analysis for an independent samples t-test, conducted using the pwr.t.test function from pwr (Champely, 2020), indicated that for a Cohen’s d = 0.5, an alpha level of 0.05, and a desired power level of 80% required at least 64 participants in each group.

What we found

We found 10 non-significant p values that should be checked for appropriate interpretation.

Show details

Meta-scientific research has shown nonsignificant p values are commonly misinterpreted. It is incorrect to infer that there is ‘no effect’, ‘no difference’, or that groups are ‘the same’ after p > 0.05.

It is possible that there is a true non-zero effect, but that the study did not detect it. Make sure your inference acknowledges that it is possible that there is a non-zero effect. It is correct to include the effect is ‘not significantly’ different, although this just restates that p > 0.05.

How StatCheck works

Check consistency of p-values and test statistics

The Statcheck module runs Statcheck. Statcheck searches for regular expressions that match a predefined pattern, and identifies APA reported statistical tests. More information on the package can be found at https://github.com/cran/statcheck. The module only returns Statcheck results for t-tests and F-tests, as these are the only tests which have been validated, see https://osf.io/preprints/psyarxiv/tcxaj_v1/.

Statcheck was developed by Michèle Nuijten and Sascha Epskamp.

Statcheck considers p = 0.000 an error, as you should report p < 0.001. Furthermore, p < 0.03 is an error if the p-value was 0.031, and one should simply report exact p-values (p = 0.031). When the sentence of a test says it is one-sided (“one-tailed”, “one-sided” or “directional”), a p-value that fits a one-sided test counts as consistent (statcheck’s OneTailedTxt setting; #695). When the paper says anywhere that its tests are one-sided, a p-value that fits a one-sided test in either direction counts as consistent too: half the two-sided p, or 1 minus that half for an effect against the predicted direction. Equivalence tests (TOST) are left out, as their p-values do not test the difference. A statistic written with “<” or “>” is read as a bound, and in a sentence about equal variances an F-test’s two-sided p (twice the one-tailed p) counts as consistent. For more information, see StatCheck.

How Exact P-Values works

List any p-values reported with insufficient precision (e.g., p < .05 or p = n.s.), reported as exactly zero (e.g., p = .000), or impossible (below 0 or above 1, e.g., p = -.22).

This module uses regular expressions to identify p-values. It will flag any values reported as p > ? or p < numbers greater than .001. It will also flag p-values reported as exactly zero (e.g., p = .000, p = 0.00), which are mathematically impossible — p-values are never exactly zero and should instead be reported as p < .001.

A p-value that is not the result of a test is not flagged: a table note (“* p < .05, ** p < .01”), a figure legend (“Asterisks indicate significant differences (p < .05)”, “Values in bold are significant at p < .05”) or a stated threshold (“p < .05 was considered significant”, “thresholded at p < .001”). GROBID often puts such notes into the running text, so each p-value is judged by the words in its own clause (the text up to a “;” or a full stop), and never left out when a test statistic belongs to it (“F(1, 7) = 8.03, # p < .05”). The column not_a_test of the table says why a p-value was left out (“marker”, “threshold”, “legend” or “named”).

A p-value with the name of a correction or a test after the p (“pFWE < .05”, “padj < 0.05”, “p Wilcoxon = .02”) is flagged only when a test statistic comes before it in its clause (“t(37) = 7.17, p FWE < .05”). Without one it is mostly the rule that decided what was significant (“genes with padj < 0.05 were selected”); such a p-value is “named” in not_a_test. Notes in other forms, such as a marker after the p-value (“p < .05 (*)“), are still flagged.

A p-value below 0 or above 1 is impossible; it is listed apart and not also as imprecise. Often the statistic before it, or its minus sign, was copied into it (“t(134) = -2.32, p = -.13”, “Z = 3.091, P = 3.091”). A value above 1 is listed only after a test statistic in its clause: without one, a “P” above 1 was nearly always another quantity (a proportion, pH, a group’s mean, a model parameter). A number in scientific notation whose power of ten was lost when the PDF was read (“p = 2.4 x 10 -9” read as 2.4) is not listed. A “p” that is the subscript of another symbol (“r p = .64”, “²p = .02” for partial eta squared, “Δp = .33”), or a quantity with a unit, a logarithm or a ratio (“P = 2.9 µm”, “-log10 P = 7.5”, “Ca/P = 1.67”), is not read as a p-value at all (see extract_p_values()). Each p-value has its own row, also when the same one is written twice in a sentence.

This module sometimes flags false positives when sentences discuss how p-value thresholds were set. It can also miss an imprecise p-value that is reported against a threshold (“decreased at the p < .05 significance threshold”).

This module only checks p-values reported in the running text of the manuscript. It cannot (yet) process p-values reported only in tables (as opposed to a table’s footnote text, which the module does see and tries to exclude — see above).

How Code Check works

This module retrieves information from repositories checked by repo_check about code files (R, Python, SAS, SPSS, Stata, Mplus, MATLAB).

The Code Check module checks R (also R Markdown and Quarto), Python (also Jupyter notebooks), SAS, SPSS, Stata, Mplus, and MATLAB files, using regular expressions to check the code; JASP files are listed but not read. The language of a Quarto document or a notebook is read from the file itself (its engine or kernel), not from its extension. The regular expression search will detect the number of comments, the lines at which libraries/imports are loaded, attempts to detect absolute paths to files, setwd() and install.packages() calls, and lists files that are loaded, and checks if these files are in the repository; R code is also parsed. The module will return suggestions to improve the code if there are no comments, if libraries/imports are loaded in lines further than 4 lines apart, if files that are loaded are not in the repository, if absolute file paths, setwd() or install.packages() are found, and if R code cannot be parsed.

The regular expressions can miss information in code files, or falsely detect parts of the code as a fixed file path. Libraries/imports might be loaded in one block, even if there are more than 3 intermittent lines. The module was tried out internally on papers published in Psychological Science, but has not been formally validated. There might be valid reasons why some loaded files can’t be shared, but the module can’t evaluate these reasons, and always gives a warning.

The module also checks whether the repository pins the R/package versions the analysis actually depended on: an renv.lock file (parsed for the R version and every locked package + its version/source), a sessionInfo()/sessioninfo::session_info() text dump (matched by filename — sessionInfo.txt/session_info.txt and similar, or embedded in a README), or a groundhog::groundhog.library()/checkpoint::checkpoint() date-pin call in the code (a bare library(groundhog)/library(checkpoint) does not count — the pinning call itself must be present). When none of these is found, the report flags it as a reproducibility gap: package versions may drift between when the analysis was run and any later reproduction attempt.

Abstract

Negotiators often face a tension between claiming value and preserving the relationship with their counterpart. Rationales, the explanations negotiators attach to their offers ("I'm asking this price because…"), are assumed to ease this tension by making an assertive offer more persuasive and acceptable. The evidence is limited, however. Prior work examined a few rationales in isolation, with mixed results, and has not asked, across the rationales negotiators use, whether those that win concessions are the same ones that preserve relationships. We integrate various types of rationales in an overarching taxonomy and propose that a rationale conveys two kinds of information at once-about the negotiation (e.g., limits) and about the negotiator (e.g., motives).

This information can move economic and relational outcomes in opposite directions. Across six studies (Ntotal=2,833), we identify six types of rationales negotiators commonly use (Studies 1ac) and then test, in three preregistered experiments, how sellers' rationales affect buyers' counteroffers (Study 2), their impressions of the seller (Study 3), and why (Study 4). The most common rationale, sellers praising the product, neither helped nor hurt. Rationales citing financial constraints or appealing to sympathy won larger concessions but damaged the relationship with the counterpart. Only rationales citing market constraints appeared to avoid this trade-off. Mediation analyses indicated that economic benefits operated via limit perceptions and sympathy, whereas relational costs operated via perceived manipulativeness and disliking. Our results suggest that rationales work best when they inform counterparts about the negotiator's situation without inviting negative inferences about the negotiator's motives.

"I'm Asking This Price Because…": When Negotiation Rationales

Win Concessions but Cost the Relationship

Negotiations are a ubiquitous part of everyday private, professional, and organizational lives (Sun et al., 2026; Thompson et al., 2010). They are conceptualized as a distinct social blend of cooperation and competition that requires strategic communication to elicit concessions and to achieve beneficial outcomes (e.g., Bowles & Babcock, 2013; Lee & Ames, 2017; Schaerer et al., 2020). Claiming value and preserving the relationship, however, are often at odds. Pressing for better terms tends to strain relationships, in part because counterparts often attribute assertive bargaining to the negotiator's disposition rather than to the situation (Morris et al., 1999). These relational costs can also persist after a deal is made. Negotiators' subjective value, that is, how they feel about the negotiation and about each other afterwards, can predict satisfaction and turnover intentions more strongly than economic terms do (Curhan et al., 2006 (Curhan et al., , 2009)), and relationships can have substantial long-term economic consequences (Hart & Schweitzer, 2022).

Negotiators therefore face two questions at once: How can they effectively persuade their counterparts to concede? And do their counterparts still like and trust them afterwards?

In practice, negotiators often answer the first question by adding rationales to their offers (e.g., "I'm asking this price because…"). Prior research found that more than 95% of buyers justified their offers in this way (Lee & Ames, 2017), and practical guidebooks frequently advise managers to use rationales in negotiations (e.g., Lewicki et al., 2020; Malhotra & Bazerman, 2007). Building on this literature, we first define negotiation rationales as explicit verbal explanations that seek to legitimize a negotiator's offer or position and to influence the counterpart's response. Implicit in this definition, and in the advice to use rationales, is an assumption about what a good reason accomplishes. It makes a demanding offer harder to refuse and easier to accept, legitimizing the position while sparing the negotiator the negative attributions that assertive bargaining otherwise invites (Fisher & Ury, 2011; Lee & Ames, 2017; Shaw et al., 2003). Although adjacent work on conversational framing has shown that the way offers are described can meaningfully affect negotiation processes and outcomes (De Dreu et al., 1994; Majer et al., 2020; Schaerer et al., 2020; Trötschel et al., 2015), far less is known about which rationales deliver both of these benefits and which deliver one at the expense of the other. This is the question we address in this research.

Early research from almost five decades ago suggests that rationales do not necessarily lead to better economic outcomes for the proposer (Rubin et al., 1980), and can even backfire when counterarguments are easily available to the recipient (see also Maaravi et al., 2011). These academic findings are at odds with the applied recommendations of management guidebooks to use rationales (e.g., Malhotra & Bazerman, 2007), highlighting a persistent research-practice divide. A more recent and fine-grained investigation found that some rationales, for example, buyers stressing own constraints rather than disparaging the product, are more beneficial for claiming value (Lee & Ames, 2017), and that the same rationales left counterparts with more favorable impressions of the negotiator. These findings replicated in a real-life environment (Bhattacharya & Dugar, 2023) but not in a different setting (i.e., salary negotiations; Thorsteinson & Clark, 2024). Besides these few initial findings, negotiation rationales have not been researched extensively. More important for our question, each of these studies compared at most two rationales, and none compared economic and relational effects across the range of rationales negotiators use. Whether rationales that help on one outcome generally help on the other, or whether some common rationales win concessions at the expense of the relationship, is therefore an open question. Answering it requires comparing the economic and relational effects of the rationales negotiators actually use, rather than examining one rationale or one outcome at a time. This in turn requires knowing what those rationales are. Lee and Ames (2017) noted that they were "not attempting to provide an exhaustive taxonomy of rationale content" (p. 17).

Providing such an overview is therefore our first step.

Our research follows a three-stage process by (a) identifying the different types of rationales that are frequently used in buyer-seller negotiations (Study 1a-c) and proposing two main channels through which these rationales likely exert an effect, (b) experimentally testing whether (and which of these) rationales improve (vs. impair) economic and relational outcomes (Studies 2 and 3), and (c) uncovering which psychological mechanisms explain the respective effects (Study 4). Our central proposal is that a rationale conveys two kinds of information at once, about the negotiator's limits and about the negotiator's motives, and that these can move economic and relational outcomes in opposite directions. Consistent with this proposal, we find that the rationales that win concessions are largely not the ones that preserve the relationship, and we identify the perceptions that mediate each effect. In doing so, we advance negotiation theory by showing when and why the persuasive and relational functions of rationales diverge, and we provide a taxonomy that gives future work on strategic communication in negotiations a common empirical footing. At the same time, because the taxonomy is built from the rationales negotiators actually use, our findings translate directly into recommendations for practitioners, helping to bridge the research-practice divide on rationales.

Theoretical Background Persuasion in Negotiations

Using rationales in negotiations constitutes a form of attempted persuasion: actors hope to shape their counterpart's behavior to achieve favorable outcomes (i.e., seeking concessions; Maaravi et al., 2011; see also Walton & McKersie, 1965; Putnam & Jones, 1982). General persuasion processes have been modeled and categorized extensively by prior research (e.g., Chaiken & Ledgerwood, 2012; Cialdini, 2001 Cialdini, , 2017;; Petty & Cacioppo, 1986). However, negotiations are a unique social blend of competition and cooperation and are different from many other situations of persuasion (Lax & Sebenius, 1986). Instead of one-way message transmissions to a broad audience (e.g., political advertising), negotiations are dynamic, interdependent settings of bidirectional, mutual persuasion (Ledgerwood et al., 2014). Because the audience is a single counterpart who can push back, arguments invite counterarguments. And because that counterpart is also forming an impression of the person making the argument, what a rationale reveals about the negotiator can matter as much as what it says about the offer. The principles that govern persuasion elsewhere may therefore apply differently in negotiations. We thus turn to research on persuasion in negotiations, specifically on the use of rationales.

To the best of our knowledge, the earliest study on negotiation rationales comes from Rubin et al. (1980) and investigated so-called "my hands are tied" bargaining ploys-that is, agents claiming that they cannot concede further because their constituents would not approve further concessions. Contrary to their hypotheses, using this rationale did not lead to more, but to fewer concessions by the other party (Rubin et al., 1980; see also Friedland, 1983). Over 30 years later, Maaravi et al. (2011) found that sellers' use of rationales stressing the benefits of an object (e.g., positive aspects of an apartment for sale) reduced rather than increased economic outcomes, especially when counterarguments were easily generated. Buyers felt manipulated, argued against sellers' embellishing rationales, and ultimately paid less. By contrast, Lee and Ames (2017) found that rationales highlighting buyers' own constraints rather than disparaging the seller's product are beneficial (see also Bhattacharya & Dugar, 2023, for a replication).

Sellers took constraints, but not disparagement, as credible signals of buyers' limits, which accounted for the economic advantage, and they also judged buyers who cited constraints more favorably (Lee & Ames, 2017). A more recent study involving salary negotiations, however, found constraints to improve attributions without improving offers (Thorsteinson & Clark, 2024). We believe these seemingly inconsistent results have a common explanation, namely that what matters is less whether a rationale is offered than what it leads the counterpart to infer. The same constraint may be taken as a signal of a limit when it is believed and as a ploy when it is not. And what a rationale implies about the negotiator's situation can diverge from what it implies about the negotiator's motives, as when a constraint improves the counterpart's impression of the negotiator without improving the offer.

The existing studies cannot test this account, however. They examined one or two rationales at a time and often measured either economic or relational outcomes rather than both.

As a result, we know little about the broader set of rationales negotiators use, about whether the rationales that help on one outcome are the ones that help on the other, or about the psychological pathways through which different rationales operate. There is good reason to expect that they matter, and that they matter in two ways. Exchanging arguments is a central part of real-world bargaining, be it in bilateral negotiations, where negotiators commonly report using argument-based tactics (see Ames & Wazlawek, 2014, Study 2), or in international multilateral negotiations (Grobe et al., 2010). Adjacent research shows that the framing of proposals exerts a major impact on bargaining behavior (see Bhatia & Gunia, 2018; Bowles & Babcock, 2013; Majer et al., 2020 Majer et al., , 2022;; Trötschel et al., 2015). Outside of negotiations, explanations have also been shown to work in two distinct ways. As arguments, they increase compliance with a request, even when they add little information (Langer et al., 1978). As accounts, they make an unfavorable decision more acceptable to the person affected by it (Shaw et al., 2003). In negotiations, a rationale can serve both functions at once, arguing for the offer and accounting for the negotiator's decision to make it. Because we expect these two functions to bear on different outcomes, the framework that follows treats them separately.

An Integrating Framework: How Different Rationales Affect Different Outcomes

Our framework (see Figure 1) builds on the distinction between these two functions. It proposes that three different categories of rationales (see Study 1a-b) generally operate through two inferential channels: (1) an instrumental inference channel, through which a rationale works as an argument, and (2) a motivational inference channel, through which a rationale works as an account and shapes negotiators' beliefs about the counterpart's intent (e.g., manipulation, cooperation, insincerity). The two channels can operate at the same time, and a single rationale can therefore improve one outcome while harming the other.

Channel 1: Rationales Provide Informative Cues for Instrumental Inference

In the instrumental channel, a rationale can function as an informative cue about the bargaining situation, such as the offer maker's limits. For example, constraint rationales (e.g., "I can't pay more, my budget is capped") explicitly link the offer to the negotiator's scarce resources and is likely seen as a signal of credible limits (see Lee & Ames, 2017). These cues can thus facilitate value claiming for the offer maker via instrumental inference.

We argue that instrumental inferences can also draw on legitimacy and standards, which provide information about the object's worth. Receivers may be more willing to concede when an offer is anchored in objective criteria (e.g., market value, product characteristics) rather than sheer insistence. This logic aligns with the idea that objective criteria provide a jointly acceptable frame that can make "tough" positions easier to accept without interpreting them as purely adversarial (Fisher & Ury, 2011). For instance, rationales that highlight the objective characteristics of a product (e.g., "This smartphone has a 48-megapixel camera") might justify the magnitude of an offer and facilitate value claiming, provided evident counterarguments are not readily available (Maaravi et al., 2011). Based on this reasoning, we propose: Proposition 1: Rationales affect economic outcomes (e.g., counteroffers, deal terms) by shaping instrumental inferences (e.g., senders' limits, product characteristics, market value).

Channel 2: Rationales Provide Cues for Motivational Inference

In the motivational channel, a rationale functions as an account. It is evaluated as an attempt at persuasion and influence that prompts inferences about what the sender is trying to accomplish. These motivational inferences can either be positive (e.g., cooperate, build rapport) or negative (e.g., deceive, flatter, manipulate). Rationales that are perceived as deceptive, manipulative, or generally inappropriate likely produce negative reactions in the receiver and thus impair outcomes and relationships.

We argue that receivers' inferences about the sender's goals influence the receivers' reactions (see Persuasion Knowledge Model, Friestad & Wright, 1994). Identification of a persuasion attempt can elicit either negative or positive evaluations, contingent on the inferred underlying motives and perceived appropriateness of the tactic. For example, flattery can trigger sinister attributions about the agent's motives (Main et al., 2007), and the accessibility of ulterior motives worsens evaluations of the agent's sincerity (Campbell & Kirmani, 2000). Negotiators who recognize a counterpart's attempt to influence them (e.g., disparagement rationales: "your product isn't worth more") might thus respond more defensively and make negative attributions about the counterpart (e.g., devious, untrustworthy; Lee & Ames, 2017). In contrast, if the receiver judges the sender's underlying motive as acceptable (e.g., sincere, benevolent, transparent) and the tactic as appropriate, the knowledge of a persuasion attempt can also support positive agent evaluations (Friestad & Wright, 1994). Extending this motivational perspective, explicit appeals to sympathy (i.e., negotiators revealing vulnerability and need) can improve economic outcomes for senders, but when made by high-power negotiators they are seen as more inappropriate and manipulative and may damage relational outcomes (Shirako et al., 2015).

Based on this reasoning, we propose: Proposition 2: Rationales affect relationship outcomes (e.g., subjective value) by shaping motivational inferences (e.g., benevolence, transparency, deception, manipulation).

The framework's central implication is that the question we posed at the outset has two parts, and that they need not have the same answer. A rationale may improve the counterpart's offer because of what it leads the counterpart to believe about the bargaining situation, and at the same time worsen the counterpart's impression of the negotiator because of what it suggests about the negotiator's motives. If so, the rationales that help most economically need not be the ones that help relationally, and the two effects should work through different mechanisms, instrumental inferences for the economic effect and motivational inferences for the relational one. We test these implications in terms of rationales' main effects (Studies 2 and 3) and the underlying psychological mechanisms (Study 4).

A Taxonomy of Rationales in Buyer-Seller Negotiations

Answering our question requires knowing which rationales negotiators actually use. To identify them, we combined a systematic literature review with exploratory, bottom-up analyses of empirical data (see Study 1a-b). As a result of these data analyses and the literature review, our model differentiates three superordinate categories and six different types of rationales that plausibly differ in their instrumental versus motivational inferences. Drawing on work distinguishing process, task, and relationship concerns in conflict (Jehn & Mannix, 2001), and driven by the results of our inductive coding approach (Study 1a-b), we argue that a focal negotiator can shape a counterpart's attitudes toward the negotiation (1) object, (2) context, and (3) counterpart (i.e., rationale sender; see Figure 1).

We argue that instrumental inferences primarily trigger attitude changes related to context and object, while motivational inference primarily trigger relational attitude changes. 1

Rationales Targeting the Negotiation Object

First, rationales can contain statements about the negotiation object at hand (Figure 1.1).

These object-related rationales typically entail information about an object's positive (e.g., "This package is especially well tailored to your needs") or negative aspects (e.g., "The warranty of the car has expired two years ago"). The rationales used in Maaravi et al. (2011) as well as Lee and Ames' (2017) disparagement rationales fall into this category. Rationales Targeting the Negotiation Context

Second, rationales can contain statements about the negotiation context (e.g., the market the negotiators operate in; Figure 1.2). Typically, these situational rationales entail information about senders' alternatives (e.g., "I have another offer of $200") or about the broader contextual environment (e.g., "There are only few products left of the same quality"). By highlighting these, negotiators can increase the sense of urgency and the counterpart's perceived need to concede more (see Leib et al., 2021, for empirical data on sellers' markets). Rubin et al.'s (1980) "my hands are tied" ploys and Lee and Ames' (2017) constraint rationales fall in this category, as they refer to situational, contextual factors (e.g., acting on behalf of someone else, dealing with financial limitations). Situational rationales that refer to the sender's own circumstances, such as financial limitations, may also prompt motivational inferences, because they reveal something about the sender as well as about the situation. We predict that situational rationales generally facilitate value claiming via instrumental inference.

Rationales Targeting the Relationship

Third, rationales can contain statements about the focal negotiator (the sender) and their relationship (Figure 1.3). For example, a negotiator that compliments the counterpart (e.g., "You seem to be a nice person") might elicit positive emotions and be perceived as likable which should result in larger concessions (e.g., Mislin et al., 2015). These relationship rationales typically entail relatable information about the sender's situation (e.g., "I really need a new car to drive my kids to school") or about the relationship directly (e.g., "I can make you a special offer since you're my favorite customer"). Relationship rationales have received less attention in negotiation research than object-related or situational arguments, although the work that exists suggests they can be effective (see Shirako et al., 2015). We predict that relationship rationales generally function via motivational inference and-depending on the result of this inferencethey can either lead to better or worse economic and relational outcomes.

The Present Research

The present research implements a three-stage multi-study mixed-methods program to gather empirical evidence for the conceptual model in Figure Stage two encompasses Studies 2 and 3 and experimentally tests the effects of the identified rationale types on both economic (Study 2, N = 598) and relational (Study 3, N = 598) outcomes, focusing on sellers' rationales as received by buyers. The second stage thus serves as a first empirical test for the main effects formulated in Propositions 1 and 2 and departs from prior research that focused exclusively on buyers' rationales (e.g., Lee & Ames, 2017; Bhattacharya & Dugar, 2023).

Stage three (Study 4, N = 927) then investigates the underlying psychological mechanisms driving these relational and economic effects. It empirically tests the instrumental and motivational channels (Figure 1). Together, the three stages address the question we posed at the outset. They establish which rationales negotiators commonly use, whether the rationales that help sellers economically are the ones that help them relationally, and why. In doing so, they integrate the existing evidence on rationale effects into a single framework and give practitioners evidence on which rationales serve which goals.

Study 1a-Taxonomy and Prevalence of Negotiation Rationales

Study 1a sought to identify and quantify the many different rationales used in buyerseller negotiations, as well as to produce an empirical foundation based on which we could then develop the taxonomy presented in the introduction above. We thus conducted an exploratory bottom-up coding approach with buyer-seller interactions from the Craigslist bargaining data set (He et al., 2018). We randomly selected m = 100 transcripts, featuring dyadic negotiations between sellers and buyers over various objects such as bikes, cars, and chairs. For our coding, we first defined rationales as all statements concerning the negotiation that (a) are intended to persuade or convince the counterpart to adapt their behavior (i.e., making a larger concession or accepting an offer), and (b) explain or justify a negotiator's offer, (lack of) concession, or object valuation.

Methods

Two coders independently coded all utterances (i.e., one chat message equals one utterance; u = 762) for the presence versus absence of any kind of rationale; intercoder reliability was substantial (κ = .750, CI95%[.698, .802], p < .001). All discrepancies were discussed and resolved. A frequency analysis revealed that 87% of all negotiations contained at least one rationale by either the buyer, the seller, or both parties, yielding a total of k = 242 rationales, consistent with the pervasive use of rationales reported in prior work (Lee & Ames, 2017).

Two members of the research team subsequently reviewed all rationales and inductively created six categories for rationale classification, following established guidelines for qualitative category development (see Azungah, 2018). Two additional coders who were blind to our research goals then assigned each rationale to one of the six categories or to a "miscellaneous" category if it did not fit any of the inductively generated categories. Intercoder reliability was again substantial (κ = .726, CI95%[.659, .793], p < .001); all remaining disagreements were resolved through discussion.

Results

We clustered rationales and assigned them to the following six types (see Table 1): praising product (i.e., appreciative statements about the object or its positive features), disparaging product (i.e., depreciative statements about the object or its negative features), financial constraints (i.e., statements about personal monetary limitations), market constraints (i.e., statements about the market or the presence of other offers), emotional sympathy (i.e., statements with emotional content regarding oneself or the relationship between the parties), and counterpart affirmation (i.e., affirmative statements supporting or validating the counterpart or their position).

Interim Discussion

Study 1a and 1b created and validated a taxonomy of rationales with six types from three superordinate categories that map onto our conceptual model and target the object, situation, and relationship, respectively (Figure 1). Object-related rationales aimed either at praising one's own product (i.e., sellers highlighting product advantages to increase the sale price) or disparaging the other's product (i.e., buyers highlighting downsides to reduce the price; see Lee & Ames, 2017; Bhattacharya & Dugar, 2023). Object-related rationales were most prevalent: Praising rationales were used extensively in Study 1a and 1b (almost 50% of all rationales), whereas disparagement rationales were less frequent (< 10% of rationales in Study 1a; < 30% in Study 1b). The discrepancy in disparagement rationales between Study 1a and 1b might be explained by the more direct, interactive setting of Study 1a in which participants might have been more hesitant to pursue such a confrontational approach when negotiating with a counterpart.

Rationales from the situational category are closest to what Lee and Ames (2017) described as constraint rationales. They highlight two different types of constraints, however: senders' financial constraints (e.g., buyers arguing they only have a fixed budget available) versus market-based constraints (e.g., sellers stating that they will only accept offers that exceed previous offers from other buyers).

Both signal seemingly hard, external limits for an agreement (see instrumental inference, Figure 1), although financial constraints locate the limit in the sender's own circumstances and market constraints locate it in the market. Financial and marketbased constraints were used frequently in Studies 1a and 1b (roughly 20% to 30% of all rationales). 3Third, relational rationales can be further nuanced into counterpart-affirmation rationales (i.e., affirming the behavior or statements of the other negotiator) and emotional sympathy rationales (i.e., strategically revealing information to elicit sympathy and compassion).

Counterpart-affirmation and emotional sympathy rationales were used occasionally in Study 1a (around 15% of all rationales), but less frequently in Study 1b (roughly 2% of all rationales).

This discrepancy likely reflects the absence of a real counterpart in Study 1b: The non-interactive vignette setting may have reduced the salience of relational concerns; relational rationales were more natural and more prevalent in the interactive chat setting of Study 1a.

After establishing and corroborating this rationale taxonomy, we next aimed to generate suitable experimental stimuli for each rationale type (Study 1c). With these representative prototypes, we then experimentally tested the rationale effects on economic (Study 2) and relational outcomes (Study 3). To keep the experimental designs tractable, we focused on rationales used by sellers. All rationale types can, in principle, be used by both parties; we had no strong a priori reason to expect different effects for buyers and sellers, with one exception: object-related rationales. In Study 1a and 1b, product praising rationales were exclusively used by sellers ("my product has this benefit"), whereas disparagement rationales were exclusively used by buyers ("your product has this flaw"). We chose to focus on the seller role and product praising rationales for two reasons: (a) praising rationales have received little direct testing (but see Maaravi et al., 2011), whereas (b) disparagement rationales (from buyers) have performed worse than a no-rationale control condition, consistently on relational outcomes and in some cases on economic outcomes as well (Lee & Ames, 2017; see also Bhattacharya & Dugar, 2023).

Study 1c-Stimulus Generation for Prototypical Rationales

Studies 1a and 1b provide a wide range of exemplary rationales for each type and category (ktotal > 2,300 rationales). To examine their effects experimentally, Study 1c aimed to develop one prototypical rationale per type that scored high on (a) representativeness for the respective type and (b) perceived effectiveness for improving outcomes.

Methods

To generate candidate stimuli, we used the large-language model ChatGPT-4o, so that the candidates would be comparable in length and style across types; participants' ratings, not the model, determined which candidate was selected. For each rationale type, we supplied a brief description that had been iteratively refined and agreed upon within the author team (e.g., prompt for product praising: "In buyer-seller price negotiations (e.g., for a bike on an online marketplace), sellers frequently utilize rationales to justify their offers. For example, they might use rationales that praise the product they are selling."). We then prompted GPT-4o to generate five rationales of similar length per rationale type with a standardized opening phrase ("Please provide five rationales of this kind, all starting with 'I'm asking this price because…'").

Results

The resulting 25 rationales (five per type) were evaluated by N = 210 U.S. residents (Mage = 40.25 years, SD = 12.86; 97 males, 110 females, three diverse) recruited via Prolific in a within-subjects design. Participants first read the type descriptions and then rated for each rationale (a) how representative it was for its respective type, and (b) how effective it would be compared to other possible rationales of the same type. We computed composite score across the two items and selected, for each type, the rationale with the highest composite score as the main stimulus for the subsequent experiments. All selected stimuli (used in Study 2 below) significantly outperformed the scale midpoint on the composite score, all ts ≥ 3.63, all ps < .001, although the effectiveness rating of one stimulus fell slightly below the midpoint (see OSF for all prompts and data; Table 3 below for details).

Study 2-Sellers' Rationales Impact Economic Value Claiming

The preregistered Study 2 sought to empirically test our conceptual model with respect to the rationales' impact on negotiators' claimed value. To that end, we tested the economic effects of the most prototypical rationales from Study 1c, belonging to the three superordinate categories object-related, situational, and relational. All data are available on OSF.

Hypotheses

Based on the instrumental and motivational inferences (see conceptual model in Figure 1), as well as relevant findings and theorizing, we first developed and preregistered hypotheses.

Object-related Rationales

Strategically highlighting a product's advantages with a praising rationale should selectively increase the mental accessibility of these advantages in the counterpart's cognitions.

In line with the Selective Accessibility Model (Mussweiler & Strack, 1999), more accessible positive information should improve product evaluations, strengthen the offer's anchoring effect, and result in more favorable counteroffers (see also Klarmann & Wouters, 2023, for analogous effects in business-to-business sales). Consistent with Proposition 1, product praising rationales should function as an informative cue for receivers that ultimately improves senders' economic performance. We hypothesized:

H1a. Sellers' object-based rationales (i.e., product praising) will lead to more favorable counteroffers (i.e., greater economic value) than no rationale.

Situational Rationales

When situational constraints are deemed truthful, they should serve as reliable and transparent informational cues about the sender's limit (Proposition 1; see also Lee & Ames, 2017; Tey et al., 2021). This should result in higher counteroffers from buyers that are closer to the (perceived) limit or even the seller's initial offer (Schaerer et al., 2020). We hypothesized:

H1b. Sellers' situational rationales (i.e., financial constraints, market constraints) will lead to more favorable counteroffers (i.e., greater economic value) than no rationale.

Relational Rationales

Relational rationales may elicit larger concessions by building rapport and increasing recipients' sympathy and liking towards the sender. Improving interpersonal liking is a central element of successful persuasion attempts (Cialdini, 2001), and eliciting sympathy or compassion can trigger reciprocity and improve negotiation outcomes (Kopelman et al., 2006; Mislin et al., 2015; Shirako et al., 2015). Moreover, relational rationales can speak to recipients' self-concepts by reframing the negotiation as 'helping someone' or 'doing a good deed', thereby offering social benefits that extend beyond the immediate transaction (Young et al., 2012).

Although relational rationales might backfire when deemed manipulative (Proposition 2), we expected such backfiring effects to be limited to specific cases; on average, relational rationales should have positive effects on economic outcomes. We hypothesized:

H1c: Sellers' relational rationales (i.e., counterpart affirmation, emotional sympathy) will lead to more favorable counteroffers (i.e., greater economic value) than no rationale.

Methods

We used a 1 × 7 between-subjects design manipulating the seller's rationale (product praising vs. financial constraint vs. market constraint vs. counterpart affirmation vs. emotional sympathy vs. no rationale short vs. no rationale long). We included two control conditions, one without any accompanying rationale and one with neutral text to rule out potential text-length effects. We measured buyers' counteroffers as the economic dependent variable, with higher values reflecting better economic outcomes for the seller.

Participants

An a priori power analysis for an ANOVA F-Test with a conventionally 'small-tomoderate' effect size (f = 0.20), α = .05, and a statistical power of 1-β = .95 indicated a required sample size of N = 532 (76 per condition). In line with our preregistration (https://osf.io/fe6zb/overview?view_only=a31381edef4e4a3caa209807f5650d85), we sampled N = 630 U.S. residents via Prolific to buffer for failed checks. Participants received an hourly remuneration of £9.00. Following our preregistered criteria, we excluded n = 32 participants that failed the manipulation, sincerity, or attention check, resulting in a final sample of N = 598 (294 females, 298 males, six diverse; Mage = 39.53 years, SD = 13.41).

Procedure, Manipulations, and Measures

Participants were randomly assigned to one of the seven conditions and asked to imagine buying a bike at a flea market. They were told that they had found a bike that matched all their requirements and had asked the seller for the price. The seller's response began with "I'm offering you the bike for $180. I'm asking this price…", followed by the manipulated rationale.

We used the pretested stimuli from Study 1c: "… because it's a well-designed model from a reputable brand, built to last and perform well for years" (product praising; n = 86), "… because I'm in a tight financial spot and need the amount to make the sale worthwhile" (financial constraint; n = 87), "… because similar bikes in this condition are selling for about the same amount on this marketplace" (market constraint; n = 85), "… because I've had a medical bill come up recently, and selling this bike would help cover it" (emotional sympathy; n = 85), and "… because I see you've done your research, and I want to offer a competitive deal" (counterpart affirmation; n = 85). As control conditions, we used a no-rationale condition without additional text (n = 85) and a no-rationale condition with neutral text ("As a next step in this negotiation, please react to my first offer"; n = 85) as a conservative test to rule out mere text-length effects.

In line with our preregistration, we planned to collapse both control conditions if buyers' counteroffers did not differ between them.

Participants reported their counteroffer in U.S. dollars (M = $145.45, SD = 24.82, Min = 50.00, Max = 180.00). For planned pairwise comparisons following a significant main effect, we used Tukey-HSD-adjusted p-values to correct for multiple testing.

Hypotheses

Again, we first developed preregistered hypotheses based on the instrumental and motivational inferences (see model in Figure 1), as well as relevant findings and theorizing. For each rationale type, the framework permits both relational benefits, if the rationale is taken as informative or genuine, and relational costs, if it is taken as manipulative. Our preregistered hypotheses committed to the former, for the reasons given below.

Object-related Rationales

Product praising rationales could be perceived as manipulative via the motive-inference channel (see Proposition 2; Campbell & Kirmani, 2000; Main et al., 2007), which would predict worse relationships. At the same time, object-related rationales could also be deemed a sincere attempt to provide informative cues about the object's characteristics (Proposition 1).

Highlighting positive aspects of the object should improve the recipient's valuation (Mussweiler & Strack, 1999), make an agreement more attractive, and, upon agreement, increase satisfaction with acquiring a highly valued object. Given this logic, we hypothesized:

H2a. Sellers' object-based rationales (i.e., product praising) will lead to better relationship outcomes than no rationale.

Situational Rationales

Situational rationales primarily serve as informational cues about the market situation and sellers' limit. When such rationales are accepted as truthful, the sender's bargaining behavior (e.g., not making further concessions) is likely attributed to situational factors rather than dispositional traits (see Morris et al., 1999; Snyder & Higgins, 1988), allowing negotiators to behave assertively without incurring relational penalties (Lee & Ames, 2017). Situational rationales that refer to the sender's own circumstances could, however, also invite inferences about the sender's motives (Proposition 2). In line with the attribution logic, and the strong positive economic effects observed in Study 2, we hypothesized:

H2b. Sellers' situational rationales (i.e., financial constraints, market constraints) will lead to better relationship outcomes than no rationale.

Relational Rationales

Relational rationales primarily function via the motive-inference channel (Proposition 2).

When perceived as genuine, they should improve relationships by fostering rapport and interpersonal liking (Cialdini, 2001). If, however, the sender's motives are construed as ulterior or manipulative, relational rationales should harm relationships (Friestad & Wright, 1994; Lee & Ames, 2017). For instance, counterpart affirmation might be perceived as strategic flattery rather than an authentic appreciation and thus be seen as an attempt to elicit compliance (Danziger, 2020). Appeals to sympathy can similarly produce relational benefits when perceived as sincere, but risk being judged as inappropriate or manipulative otherwise (Shirako et al., 2015). In line with our reasoning for the other rationale types, the positive economic effects of relational rationales in Study 2 suggest a generally favorable reception (although relational outcomes may be detached from economic ones; Galinsky et al., 2002). We predicted:

H2c. Sellers' relational rationales (i.e., counterpart affirmation, emotional sympathy) will lead to better relationship outcomes than no rationale.

Methods

We again tested the five rationale types against two control conditions (no rationale with and without alternative text to control for message length; see Study 2). We used a 1 × 7 between-subjects design (seller's rationale: product praising vs. financial constraint vs. market constraint vs. counterpart affirmation vs. emotional sympathy vs. no rationale short vs. no rationale long). Buyers' ratings of the relationship served as the dependent variable.

Participants

An a priori power analysis for an ANOVA F-Test with a conventionally 'small-tomoderate' effect size (f = 0.20), α = .05, and a power of 1-β = .95 indicated a required sample size of N = 532 (76 per condition). In line with our preregistration (https://osf.io/7q4wb/overview?view_only=a3428de48cc8480e9ec025e95390c70c), we sampled N = 630 U.S. residents via Prolific to buffer for failed checks. Participants received an hourly remuneration of £9.00. Following our preregistered criteria, we excluded n = 32 participants that failed the manipulation, sincerity, or attention check, resulting in a final sample of N = 598 (287 females, 298 males, 13 diverse; Mage = 37.60 years, SD = 12.57).

Procedure, Manipulations, and Measures

Participants were randomly assigned to a condition and asked to imagine buying a laptop on an online marketplace (e.g., Craigslist). They were told that they had found a laptop that matched all their requirements and had asked the seller for the price. The seller's response began with "I would like to have $400 for it. I'm asking this price…", followed by the manipulated rationale. We again used the pretested stimuli from Study 1c: "… because it's a well-designed model from a reputable brand, built to last and perform well for years" (product praising; n = 87), "… because I'm in a tight financial spot and need the amount to make the sale worthwhile" (financial constraint; n = 90), "… because similar laptops in this condition are selling for about the same amount on this marketplace" (market constraint; n = 83), "… because I've had a medical bill come up recently, and selling this laptop would help cover it" (emotional sympathy; n = 84), and "… because I see you've done your research, and I want to offer a competitive deal" (counterpart affirmation; n = 89). The control conditions consisted of a norationale message without additional text (n = 84) and a no-rationale message with neutral text ("This is the price I'm asking for. You get the laptop for this price"; n = 85). As preregistered, we planned to collapse across both control conditions, given no significant difference.

We assessed buyers' relationship ratings with four items adapted from the Subjective Value Inventory (SVI; Curhan et al., 2006; e.g., "What kind of overall impressions did your counterpart make on you?",1 = extremely negative,7 = extremely positive; α = .94; M = 4.06, SD = 1.37). A maximum-likelihood factor analysis suggested a single-factor solution with uniformly high factor loadings of l > .86 that accounted for 79.4% of item variance. For planned pairwise comparisons after significant main effects, we report Tukey-HSD-adjusted p values.

Interim Discussion

While several rationales outperformed the no-rationale control conditions economically (Study 2), none exceeded the control condition in terms of relationship outcomes (Study 3).

Three rationales (i.e., financial constraints, counterpart affirmation, and emotional sympathy) produced relational costs of comparable magnitude. These cases are especially informative because they combine economic benefits with relational costs. In other words, buyers who received these rationales made larger economic concessions in Study 2 but also held a more negative impression of the seller in Study 3. Our preregistered hypotheses had, for each rationale type, followed the path in the framework on which a rationale is taken as informative or genuine.

For three of the five types, the data favored the other path, on which it is taken as manipulative.

The control conditions point the same way. A message that merely restated the price ("This is the price I'm asking for. You get the laptop for this price") impaired relationships as much as the costliest rationales did, which suggests that buyers read every message, rationale or not, for what it conveys about the seller. These patterns are consistent with our propositions that rationale effects operate through two distinct channels: an instrumental channel that processes informational cues and concession behavior, and a motive-inference channel that processes relational cues and shapes interpersonal evaluations. Study 4 directly investigated these channels and the psychological mechanisms behind the divergent economic versus relational effects. We sought to clarify, in a single experiment, why concession size and interpersonal perception can systematically diverge for certain rationale types.

Study 4-The Mechanisms Behind Economic Benefits and Relational Detriments

We conducted the preregistered Study 4 with a two-fold aim: First, to replicate the patterns observed in Studies 2 and 3 in a single experiment. Second, to identify the underlying psychological mechanisms. Specifically, we aimed to explain why rationales produced economic benefits versus relational detriments relative to a no-rationale control condition. All data are available on OSF.

Hypotheses

We first developed preregistered hypotheses for the economic benefits versus relational detriments based on the instrumental and motivational inferences of our model (Figure 1). We focused these hypotheses on the significant contrasts compared to the control condition as established in Study 2 and 3.

Psychological Mechanisms Driving Economic Benefits

In line with prior research and Proposition 1, we predicted that situational constraint rationales would lead to economic benefits because they are interpreted as credible signals of the sender's limit (Lee & Ames, 2017). We hypothesized:

H3a. The positive effect of sellers' situational rationales (i.e., financial constraints, market constraints) on higher counteroffers is mediated by buyers' limit perceptions.

Emotional sympathy rationales may also be seen as an indication that the seller is experiencing hardship, hence affecting economic outcomes through altered limit perceptions. In addition, relational processes such as felt sympathy are likely to contribute to larger monetary concessions (Maaravi et al., 2019). We hypothesized:

H3b. The positive effect of sellers' emotional sympathy rationales on higher counteroffers is mediated by (i) buyers' limit perceptions and (ii) sympathy towards the seller.

Finally, counterpart affirmation rationales involve compliments or acknowledgements of the buyer's expertise (e.g., "I see that you've done your research"). These statements should not convey information about the seller's limit. Instead, they may work because they make buyers feel valued and respected (Cohen, 2002). We hypothesized:

H3c. The positive effect of sellers' counterpart affirmation rationales on higher counteroffers is mediated by buyers' feelings of being respected by the seller.

Psychological Mechanisms Driving Relational Detriments

Study 3 revealed a clear divergence regarding the detrimental relational effects of rationales: While market constraints yielded relationship outcomes comparable to the control condition, financial constraints produced large relational detriments (Figure 3). In other words, claiming that other sellers are requesting similar prices (i.e., market constraint) preserved the relationship, while claiming to be in a tight financial spot and needing the money (i.e., financial constraint) damaged the relationship. The two rationales differ in where they locate the seller's limit. Market constraints place it in the market, whereas financial constraints place it in the seller's own circumstances, which invites inferences about the seller as well as about the situation. We propose that this discrepancy is driven by motive inferences (Proposition 2).

Substantiating an offer with reference to the market situation (or, for the control condition, simply presenting the offer without rationale) might be perceived as normative and sincere, whereas mentioning one's financial struggles to secure a better deal may be seen as emotional leverage, eliciting disliking and perceptions of manipulation (Bhatia & Gunia, 2018; Friestad & Wright, 1994; Lee & Ames, 2017). We hypothesized:

H4a. The negative effect of sellers' financial constraint rationales on relationships is mediated by buyers' (i) perceptions of manipulativeness and (ii) interpersonal disliking.

Relational rationales similarly showed both economic benefits and relational detriments.

This pattern aligns with work on ingratiation and strategic flattery: Positive relational language can increase compliance while simultaneously triggering skepticism (Gordon, 1996; Vonk, 2002), and even obviously insincere flattery can still influence behavior (Chan & Sengupta, 2010). Sellers who (a) appeal to emotional sympathy by mentioning a medical bill or (b) direct affirmative comments to the buyer (e.g., "I see you've done your research") may capture shortterm economic gains but incur relational costs via negative motive inferences. We predicted:

H4b. The negative effect of sellers' emotional sympathy rationales on relationships is mediated by buyers' (i) perceptions of manipulativeness and (ii) interpersonal disliking.

H4c. The negative effect of sellers' counterpart affirmation rationales on relationships is mediated by buyers' (i) perceptions of manipulativeness and (ii) interpersonal disliking.

Discussion

The present research builds on and extends prior work on negotiation rationales by asking whether the rationales that help negotiators claim value are the ones that preserve their relationships, and by answering that question across the rationales negotiators actually use.

Rather than asking whether "rationales help or hurt" negotiators in general, we show that rationales directed at the negotiation object, the situational context, and the dyadic counterpart produce divergent patterns of outcomes, and that some of the most economically effective rationales can simultaneously undermine relationship quality. This divergence between economic success and relational preservation is central for both theory and practice, as it shows that "good deals" can come at non-trivial relational costs.

Theoretical Contributions

First, we show that a rationale's economic and relational effects can diverge, and we identify why. Earlier work often did not differentiate between different types of rationales and found limited economic benefits, especially when counterarguments were easy to generate (e.g., product praising rationales in Maaravi et al., 2011). Our results show that negotiation rationales are no monolithic construct: object-related, situational, and relational rationales differ systematically in both their economic and relational effects, and these differences are traceable to distinct psychological pathways; namely limit perceptions and sympathy for economic benefits, and perceived manipulativeness and disliking for relational detriments. These are the two channels the framework anticipated. Economic benefits followed from what buyers inferred about the seller's situation, relational costs followed from what buyers inferred about the seller's motives, and the same rationale could trigger both. Our results thus suggest that whether rationales help has no single answer. Financial constraints and emotional sympathy helped sellers claim value and cost them relationally, product praising did neither, counterpart affirmation cost relationally without reliably helping, and market constraints helped without a relational cost, which we attribute to their locating the seller's limit in the market rather than in the seller.

These findings also qualify a conclusion from prior work. Lee and Ames (2017) found that buyers' constraint rationales improved both counteroffers and impressions, whereas here sellers' financial constraints improved counteroffers but damaged impressions. The stimuli and measures differed across the two programs, but one substantive explanation is role. A buyer who says "I cannot pay more" states a limit that asks nothing of the seller beyond accepting less, whereas a seller who says "I need the money" asks the buyer to pay more to relieve the seller's need, so the same disclosure may read as a limit in one role and as leverage in the other. Future research could test this possibility directly by crossing negotiator role with rationale type.

Second, the taxonomy gives this work and future work a common basis. Prior studies examined one or two rationales at a time, which made their results difficult to compare. By offering an empirically grounded taxonomy of rationale types, tracing their effects through identifiable mechanisms, and showing where economic and relational consequences diverge, we provide a framework that future work can use to classify additional rationales, specify boundary conditions, and integrate negotiation rationales with broader theories of social influence and impression management.

Third, we contribute to emerging work that treats relationship outcomes as a central consequence of negotiation (see Boothby et al., 2023; Hart, 2026; Petrowsky et al., 2025). Prior studies have shown that relationship outcomes predicts downstream satisfaction, job attitudes, and turnover intentions more strongly than immediate economic outcomes, and that the economic relevance of relational outcomes (ERRO) can determine when negotiators should prioritize relationships over "winning" the deal (Curhan et al., 2006 (Curhan et al., , 2009;; Hart, 2026; Hart & Schweitzer, 2022). Our findings locate one source of such trade-offs in the negotiation itself, namely in the rationales negotiators attach to their offers. This combination of mechanisms (i.e., perceiving an offer as constrained and fair, yet liking the sender less) illustrates how conflicting processes can unfold in parallel and points to the need for treating economic and relational success as separable but jointly important criteria for negotiation success (Hart & Schweitzer, 2022; Petrowsky et al., 2025). Understanding these trade-offs is essential for developing a nuanced theory of negotiation effectiveness that acknowledges multiple success criteria beyond simple economic maximization.

Fourth, the mediation analyses connect negotiation rationales to literatures on flattery, ingratiation, and strategic communication. Research on ingratiation and flattery shows that positive relational language can increase compliance and liking but can also trigger suspicion and "slime effects" when perceived as self-serving (Higgins et al., 2003; Vonk, 1998 Vonk, , 2002)).

Work on insincere flattery further demonstrates that even transparently motivated compliments can generate coexisting positive implicit attitudes and negative explicit evaluations toward the sender (Chan & Sengupta, 2010). Our data echo this duality: emotional sympathy, and counterpart affirmation in Study 2, elicited economic generosity, and both were also judged as more manipulative and less likeable. Relational language in negotiation can thus help and hurt at the same time.

Finally, our findings offer a theoretical refinement of dual-process models of persuasion, such as the Elaboration Likelihood Model (ELM; Petty & Cacioppo, 1986) in the bargaining context. In the ELM, central-route processing (careful scrutiny of issue-relevant arguments) and peripheral-route processing (reliance on simpler cues, including affective and relational signals) are typically conceptualized along the same continuum of elaboration: as elaboration increases, central-route processes dominate.

Our two-channel model suggests that, in negotiation, instrumental and motivational inferences are not merely points on a single elaboration continuum but can coexist and operate simultaneously. For example, buyers confronted with emotional sympathy rationales appear to engage in central-like processing of situation-relevant information, updating their perceptions of the seller's limits and adjusting their counteroffers accordingly (instrumental channel). At the same time, the very same rationales can elicit perceptions of manipulativeness and disliking (motivational channel) in the same negotiation episode, which undermine relationship quality. Rather than one route crowding out the other, instrumental and motivational processing appear to unfold in parallel, with distinct consequences for economic and relational outcomes. In this sense, our model extends dual-process perspectives by demonstrating that, in negotiation contexts, "argument strength" and "relational/motive cues" should be treated as jointly active processes that shape different facets of negotiation success, rather than as alternative routes along a single elaboration dimension.

Practical Implications

From a practical standpoint, our findings show that the choice of rationale matters and that it should follow from the negotiator's goals. Rationales can shape two things: how the counterpart thinks about the focal negotiator's limit (i.e., instrumental path), and how the counterpart thinks about the focal negotiator (i.e., motivational path). Rationales that favourably affect both paths can lead to better outcomes, whereas rationales that undermine these paths might be practically worse than using no rationale at all. Across studies, market constraint rationales that frame the offer in terms of external, normatively acceptable reference points rather than personal hardship or overt relational tactics emerged as the most advisable option (at least within the tested negotiation setting and present rationale selection); they offered economic benefits (clearly in Study 2, directionally in Study 4) without sacrificing relational quality. As such, market constraints can potentially serve as a default rationale in many everyday negotiations, especially where both economic outcomes and relationship preservation matter.

Our results also reveal a mismatch between how often rationales are used and how well they work. Praising the product, nearly half of all rationales in Studies 1a and 1b, did not help economically in Studies 2 or 4, whereas market constraints, used far less often, were the one rationale that helped without relational cost (see also Bhattacharya & Dugar, 2023; Lee & Ames, 2017; Maaravi et al., 2011). Negotiators, in other words, appear to rely most on the rationale type that does the least.

Emotional and relational rationales should be used with care. Emotional sympathy and counterpart affirmation can generate sizable concessions (and potentially even integrative gains; Shirako et al., 2015), but they also substantially increase perceptions of manipulativeness and disliking, undermining relationship quality. These approaches can be exceptionally effective in situations where relationship preservation is not paramount, such as one-shot negotiations with no expectation of future interaction. In such contexts, emotional appeals and relational framing may maximize economic outcomes without incurring the relational costs that would be problematic in ongoing relationships. However, in long-term relationships where relationship quality and trust are paramount, such approaches should be used sparingly, if at all (Hart, 2026; Hart & Schweitzer, 2022).

Our results also suggest that financial constraints should be used with particular caution.

Although financial-constraint statements reliably signal hard limits and elicit higher counteroffers, they also produce some of the strongest relational harms, being perceived as emotionally manipulative and leading to marked disliking. In practice, negotiators may wish to reframe genuine hardship information in less self-focused, more context-based terms, or to provide independent legitimacy cues (e.g., documentation, third-party validation) that validate the constraint without making it appear as a purely strategic appeal.

In all, practitioners should adopt a decision-making framework that considers (1) the negotiator's primary objective (economic concessions versus relationship preservation versus balanced outcomes), (2) the anticipated duration and importance of the relationship with the counterpart, (3) the specific negotiation context and industry norms, and (4) prior experience and domain knowledge on the likely susceptibility of the counterparty to various rationale types.

Further Research & Limitations

Like any research program, this work has limitations that open avenues for future inquiry.

First, our studies focused on aggregate effects and did not systematically model interpersonal differences in how recipients respond to specific rationale types. Persuasion research shows that traits, states, and prior experiences shape how people process and respond to influence attempts (see Teeny et al., 2021). It is plausible that recipients whose negotiation stances are affectively grounded (e.g., driven by fairness concerns or identity) might respond more strongly to sympathy-based rationales, whereas recipients with more cognitively grounded positions might be more responsive to constraint-based or object-related rationales (Fabrigar & Petty, 1999).

Future work should examine interactions between rationale type and the affective-cognitive basis of recipients' attitudes, as well as moderators such as persuasion knowledge, suspicion, and individual differences in reactance (cf. Friestad & Wright, 1994; Fabrigar & Petty, 1999; Teeny et al., 2021).

Second, our empirical context was buyer-seller negotiations over consumer goods.

Although this context captures a wide range of everyday bargaining, the generalizability of our taxonomy and mechanisms to other domains, such as salary negotiations, internal organizational bargaining, or conflict resolution, remains an open question. Existing work already suggests that some rationale effects do not readily replicate in salary settings (Thorsteinson & Clark, 2024), and it is likely that organizational hierarchies, power asymmetries, and identity concerns introduce additional mechanisms and boundary conditions. Systematic studies of rationale use in these domains could expand the taxonomy, identify domain-specific rationales (e.g., "constituent constraints" in union negotiations; see also Rubin et al., 1980), and test whether the same economic-relational trade-offs emerge. Future research should also investigate whether a combination of rationale types elicits favorable interaction effects (e.g., whether combining product praising with emotional sympathy leads to economic benefits without relational detriments).

Third, our experiments were scenario studies with one exemplar per rationale type.

Although all stimuli were rated selected from a pretested set (see Study 1c), future research should generalize our findings to a broader variety of rationales within each rationale type via stimulus sampling. The economic effects replicated across two products and negotiation settings with adapted wordings (a bike on a flea market in Study 2, a laptop on an online marketplace in Study 4), and the relational effects replicated across two samples (Studies 3 and 4), so the results remained robust across products, samples, and contexts. The effects of receiving them, however, were measured in one-shot vignettes without consequences or a responding counterpart.

Interactive or incentivized designs with several exemplars per type would show whether the same trade-offs emerge when counterparts can push back.

Fourth, our designs held offer magnitudes constant across experimental conditions. While this design choice enabled precise examination of rationale effects independent of offer size, different rationales might allow for different credible offer magnitudes. For example, marketbased rationales may require offer magnitudes that align with other competitive market offerings to maintain persuasiveness, while product praising rationales may afford greater flexibility in offer magnitude without triggering skepticism. Future research should systematically vary offer magnitudes in interaction with rationale type to further illuminate these dynamics.

Finally, the mediation results indicate that instrumental and motive inference processes are often co-activated. Because the mediators were measured rather than manipulated, these results identify plausible pathways rather than establish them causally. Situational rationales (e.g., financial constraints) and relational rationales (e.g., sympathy appeals) can simultaneously signal constraint and vulnerability, and object-focused rationales may affect relational perceptions when interpreted as arrogance or boastfulness. Future work would benefit from explicitly specifying boundary conditions, such as levels of suspicion, power asymmetries, or message timing, that determine when instrumental inference dominates motive inference and vice versa, potentially integrating our framework with dynamic models of social inference and emotion in negotiation (Van Kleef, 2009)

Conclusion

Based on a high-powered, preregistered, multi-study program, this research asks whether the rationales that help negotiators claim value are the ones that preserve their relationships. To answer this question, we developed an empirically grounded taxonomy of negotiation rationales, tested their economic and relational effects, and identified the psychological mechanisms through which they operate. Our work builds directly on prior research on negotiation rationales, framing effects, and persuasion, and integrates these strands into a unified model of rationale choice and its consequences. We show that rationales have reliably different economic and relational profiles, and that these are driven by instrumental inferences about limits and markets, affective processes of sympathy, and motive inferences about manipulativeness and liking.

Our findings show the importance of matching rationales to the negotiator's underlying goals. Market constraint rationales combine good economic and relational performance and might be a good choice for everyday negotiation situations, whereas financial constraints and relational rationales should be used with clear awareness of their relational costs. More broadly, our results show that effective negotiation requires moving beyond one-size-fits-all approaches, that negotiators often face genuine trade-offs between claiming value and preserving relationships, and that carefully chosen rationales can help them navigate, rather than ignore, these trade-offs.

We preregistered (and used) only the short no-rationale control condition because it did not differ from the long condition in terms of economic performance in Study 2 and because it produced significantly better relationship outcomes than the long no rationale condition in Study 3, making it a more conservative control condition.

We can only speculate as to why counterpart affirmation rationales produced positive economic effects in Study 2 but not in Study 4.
