Meta-scientific research has shown nonsignificant p values are commonly misinterpreted. It is incorrect to infer that there is ‘no effect’, ‘no difference’, or that groups are ‘the same’ after p > 0.05.

How Exact P-Values works

List any p-values reported with insufficient precision (e.g., p < .05 or p = n.s.), reported as exactly zero (e.g., p = .000), or impossible (below 0 or above 1, e.g., p = -.22).

This module uses regular expressions to identify p-values. It will flag any values reported as p > ? or p < numbers greater than .001. It will also flag p-values reported as exactly zero (e.g., p = .000, p = 0.00), which are mathematically impossible — p-values are never exactly zero and should instead be reported as p < .001.

A p-value that is not the result of a test is not flagged: a table note (“* p < .05, ** p < .01”), a figure legend (“Asterisks indicate significant differences (p < .05)”, “Values in bold are significant at p < .05”) or a stated threshold (“p < .05 was considered significant”, “thresholded at p < .001”). GROBID often puts such notes into the running text, so each p-value is judged by the words in its own clause (the text up to a “;” or a full stop), and never left out when a test statistic belongs to it (“F(1, 7) = 8.03, # p < .05”). The column not_a_test of the table says why a p-value was left out (“marker”, “threshold”, “legend” or “named”).

A p-value with the name of a correction or a test after the p (“pFWE < .05”, “padj < 0.05”, “p Wilcoxon = .02”) is flagged only when a test statistic comes before it in its clause (“t(37) = 7.17, p FWE < .05”). Without one it is mostly the rule that decided what was significant (“genes with padj < 0.05 were selected”); such a p-value is “named” in not_a_test. Notes in other forms, such as a marker after the p-value (“p < .05 (*)“), are still flagged.

A p-value below 0 or above 1 is impossible; it is listed apart and not also as imprecise. Often the statistic before it, or its minus sign, was copied into it (“t(134) = -2.32, p = -.13”, “Z = 3.091, P = 3.091”). A value above 1 is listed only after a test statistic in its clause: without one, a “P” above 1 was nearly always another quantity (a proportion, pH, a group’s mean, a model parameter). A number in scientific notation whose power of ten was lost when the PDF was read (“p = 2.4 x 10 -9” read as 2.4) is not listed. A “p” that is the subscript of another symbol (“r p = .64”, “²p = .02” for partial eta squared, “Δp = .33”), or a quantity with a unit, a logarithm or a ratio (“P = 2.9 µm”, “-log10 P = 7.5”, “Ca/P = 1.67”), is not read as a p-value at all (see extract_p_values()). Each p-value has its own row, also when the same one is written twice in a sentence.

This module sometimes flags false positives when sentences discuss how p-value thresholds were set. It can also miss an imprecise p-value that is reported against a threshold (“decreased at the p < .05 significance threshold”).

This module only checks p-values reported in the running text of the manuscript. It cannot (yet) process p-values reported only in tables (as opposed to a table’s footnote text, which the module does see and tries to exclude — see above).

How Data Check works

This module classifies the files in a repository into semantic types (data, codebook, code, software, output, supplemental, readme, asset, other) and, for tabular data files, extracts each column’s type and summary statistics.

The Data Check module consumes the file list produced by repo_check (or any files added via local_path). Each file is classified with rule-based heuristics layered over metacheck’s file_category() and file_types: file names matching README / codebook patterns win first, then an extension crosswalk, then format-locked extension overrides. For every file classified as tabular data that is available locally, the module reads the file head, describes each column with data_col_facets() and computes summary statistics for numeric columns. Every sheet of a spreadsheet that holds a table is read: a file with several such sheets has its columns under source_file = "file.xlsx [sheet]", and the sheet column names the sheet of any spreadsheet with several sheets; a sheet of notes or a codebook is treated as documentation when the file has another table. Following DDI, a column is described by orthogonal facets rather than a single type: representation (numeric/text/datetime/code — how it is stored), measurement_level (Stevens: nominal/ordinal/interval/ratio), concept (what it measures: reaction_time/age/gender/likert/id/…), role (identifier/measure/condition/timestamp), unit, and a quality state (ok/empty/constant). Concepts are detected by name+value rules (the demographic concepts via data_check_demographic()); when llm_use(TRUE) the model fills concepts and measurement levels the rules left blank. Qualtrics survey exports are recognised (data_check_is_qualtrics()): their extra header rows are stripped so columns type correctly, and the reserved response-metadata columns (StartDate, Duration, Finished, …) are tagged.

The module defaults to rules-only when llm_use(FALSE): columns the rules cannot resolve (ambiguous 3–20-unique integers, ambiguous character columns) fall back to continuous / text respectively. How Reproducibility Check works

This module assesses whether a paper’s R and Python code can be run on its data. It works in two phases. The static phase (always run) collects the package dependencies the code declares, rewrites the data-file paths that do not work in the repository as the authors organised it, works out the order the scripts must run in, and diagnoses why any referenced input file is unavailable — reporting what a reproduction attempt would involve and where it is likely to break. The execution phase (opt-in, execute = TRUE) then actually runs the code: it copies the repository into a throwaway directory, optionally installs the declared dependencies into a throwaway library, runs each script in order in an isolated subprocess with a per-script timeout, and captures the outcome and full output of each run.

By default (execute = FALSE) the module does not run any code — it performs only static analysis: reading dependencies with the same extractors as code_check, finding the files the code references in the repository, and building a run-order dependency graph. It reports what would be installed and run rather than doing it.

When execute = TRUE, the module additionally runs the downloaded code on your machine — a deliberate, opt-in action gated behind that argument (callr is required for R code). Each script runs in an isolated subprocess so a crash cannot take down the R session; note this isolates crashes, not the filesystem or network. Installs (when install_missing = TRUE) and the throwaway run library never touch your main R library. Each script’s outcome is one of ran_ok, errored, timed_out, dependency_unavailable, not_parsed, run_by_source (an R script another script runs with source(), which is run only inside that script, since on its own it lacks the packages and objects the sourcing script sets up first), run_by_import (a Python file other files import, a module rather than a script, unless it has an if __name__ == "__main__": block), jags_model (a JAGS or BUGS model saved with an R extension, which another script reads) or not_r_content (a file that is not R at all, such as a JSON or HTML dump); these last two are not run and are not failures. python2 marks Python 2 code that was not run. With sandbox = "docker" such code runs with Python 2.7 (option metacheck.docker_image_py2; FALSE turns this off), which modifications records; it is never converted, since that can change results. defines_functions is a file that only defines functions, which is used, not run (table$used_by names the scripts that use it), and not_analysis is a file of software rather than of the analysis: a package’s code, tests, documentation or setup.py, a copy of a tool, a web application, a script a program wrote (table$not_analysis_why says which); neither is run or counted as a script. docker_failed means the container never started, which says nothing about the script, so it keeps the light from being green but does not make it red. needs_a_person is a script that stopped because it asks a person to choose a file or answer a question, or that starts an app, and needs_internet one that stopped because the network is off in a Docker run, or, with internet = TRUE, could not reach what it asked for; download_too_large is a script stopped for downloading more than the limits allow (see internet), and out_of_memory one that, or a program it started (such as a compiler), ran out of the memory each script may use. All four are treated the same way. not_downloaded is a script that stopped on a file the repository lists but that was not downloaded, such as one over max_file_size: it could not be tried, so it is not counted as a script that did not reproduce (summary_table$repro_not_downloaded_n counts them apart). not_read is a file metacheck could not read, so it was not run; the light is then not green, as the file may read and run on another computer, and table$error_message says why, naming a package that is installed but cannot be loaded on the computer that ran the check. empty is a file with nothing in it, which is not run or counted as a script. For a script that did not run through, table$error_message is its error, short (at most 300 characters): the error line of its output, which names a package that is not there, with the address it asked for when it needed the internet, or the time limit it reached; table$reason sorts it into a kind. A timeout means “still running at the cutoff”, not a failure, so raise timeout for legitimately long-running (e.g. Bayesian) scripts. dependency_unavailable means the script’s own package could not be installed from live CRAN, the CRAN Archive, or a named GitHub/URL source — an infrastructure limitation, not a defect in the paper’s code. The full stdout/stderr of every run is kept in the result’s run_results (the report shows it in per-script dropdowns, capped for readability).

run_results$checked says what the run of each script shows about the code, in five groups, so that a script that does not reproduce is kept apart from one the check could not test: ran (it ran to the end); code_error (it did not reproduce: it stopped with an error of the code or the deposit, could not be read, or needs a file the deposit does not hold); dependency (a package or program was not available: a package that could not be installed or was not loaded, a program outside R and Python, a system library, or R crashing in a package’s compiled code); time (it did not finish within the time limit for one script, or was not started because the time for all scripts had run out); and not_checkable (it could not be checked automatically: it needs a person, the internet, a key or another setting of the authors’ computer, one platform such as Google Colab, Windows or OpenSAFELY, more memory than the run allows, a file that was not downloaded, a screen, or a program that runs it, or it is a file of a package of the code that Python runs only as a module of that package). It is NA for files run inside another script, files that are not an analysis, files not read, and a Docker failure. summary_table counts each group (repro_ran_n, repro_code_error_n, repro_dependency_n, repro_time_n, repro_not_checkable_n), and the report’s first sentence gives them. The traffic light reflects the static readiness signals by default; a script in code_error that stopped with an error makes it red, as a script that crashes on its own analysis is a genuine reproduction failure, and a script in one of the other three groups keeps it from being green. Calls that need a screen, which the run does not have (dev.print(), dev.copy2pdf(), dev.copy2eps(), savePlot(), windows(), win.graph(), x11(), quartz(), View()), are replaced before the run by calls that need none, which modifications records as screen_call_replaced. A script that fails with could not find function is run once more with the library() calls the project’s other scripts make added at its top (or the one package that exports the function, or magrittr for %>%), and a script that then runs is reported as reproducible only after that repair.

Dependencies are reported name-only, with the source (CRAN, GitHub, or a base package already shipped with R) — static analysis of the code cannot know which version was used, and running against current package versions is itself informative: a break argues the authors should have pinned versions. When the repository does record versions, a run with recorded_versions = TRUE installs the packages the scripts load at those versions, but it does not change the R version, which remains a limitation of the check.

Run order is derived from read-after-write data dependencies (a script writing a file another reads must run first), source() edges, and numeric filename prefixes as a weak tie-breaker. Ambiguous orderings, dependency cycles, and inputs a script reads but that no earlier script produces (and that are not in the repository) are surfaced as warnings, since these are the situations most likely to make an otherwise-correct reproduction fail.

Python code (.py files, and notebooks and Quarto documents whose code is Python, from which the code is extracted first) goes through the same two phases, reported in its own “Python code” section. Each file is checked for syntax errors with Python’s own parser when a Python interpreter (python, or else python3) is available; dependencies are read from the import statements, with versions from a requirements.txt or pyproject.toml when there is one, and installed with pip; each script runs as its own python process (processx is required), so unlike R scripts, a name one script defines is not available to another. When no Python interpreter is available, the Python files are reported as not run and the R results are still returned. Statistics the Python scripts print are compared with the paper together with the R output and any self-reproducible output (JASP/jamovi, SPSS-Viewer, notebook outputs).

Abstract

Society and organizations invest heavily in selecting the best leaders 1 , and existing research shows a positivity bias by focusing on the bright side of leadership [2] [3] [4] . Yet, according to Popper 5 , the central question of institutional design is not who should rule, but how to prevent bad leaders from doing too much damage. This raises the question of which approach is more consistent with human psychology: Aim for the best leaders, or avoid the worst? We provide robust evidence for an "avoid-the-worst" principle in human leadership preferences.

Although text analyses indicated that the top 100 business schools emphasize good leadership far more than the prevention of bad leadership, actual employee experiences from 9.9 million Glassdoor reviews show that people mentioned their leader 70% more often in the negative than positive section, and negative leader mentions predicted company ratings 1.5 times more strongly. Providing causal evidence, five high-powered experiments across 40 countries (N = 51,433) revealed that people were more willing to sacrifice time and money to avoid a bad leader than obtaining a good leader-across morality and competence, hypothetical and incentivized choice, ideology and culture. People care more about avoiding the worst leaders than getting the best. Society invests heavily in developing and selecting the best leaders. For instance, global estimates suggest that organizations spend over $60 billion per year on leadership training 1 , which is more than the total UN spending per year on global development and humanitarian activities combined 6 . What do they learn? As the academic starting point, the field of leadership research shows clear signs of "excessive positivity" 2 , by focusing on the constructive and so-called transformational potential of leaders far more than the destructive and harmful potential 3, 7 . Indeed, a meta-analysis of over 1200 leadership studies on job engagement and burnout found that 74% focused on constructive leadership whereas only 15% focused on destructive leadership 4 . In the popularized management literature as well, a common focus has been how leaders can go "from good to great" 8 . In contrast with this positive leaning in current leadership research, Karl Popper 5 argued in his political philosophy that the central question of institutional design is not "who should rule?", as posed by Plato, but rather: How can we prevent bad or incompetent leaders from doing too much damage? In Popper's view, the chief role of citizens and institutions is not to select the best leader, but to block or remove bad ones from power through peaceful means. This view suggests that institutions should aim to minimize tyranny from the worst leaders, rather than to maximize the gains from the best ones. Building on Popper's theory, originally focusing on political institutions and democracy, we extend it and make the same logic empirically testable in an organizational context.

These conflicting perspectives raise a fundamental question: Which approach is more consistent with human psychology? Across the world, do people lean in the positive direction by focusing mostly on obtaining the best leaders, or do they support a Popperian precautionary logic by prioritizing protection against the worst ones? We operationalize the "best" and "worst" leaders as those at the extreme ends of leadership quality (e.g., top or bottom 20%), across two broad perception dimensions that are fundamental for how people see and evaluate each other in social life: Competence and morality [9] [10] [11] [12] , sometimes described as competence and warmth, which also applies to how leaders are perceived and evaluated 13, 14 .

[div-01]

The competence dimension refers to individual traits such as being knowledgeable, efficient, and intelligent, and the morality dimension refers to individual traits such as being honest, fair, and trustworthy. Getting the best possible leader and avoiding the worst possible leader are two important goals in organizations and society. In the current research, we explore which of these goals people are more willing to incur personal costs to achieve.

While previous research has examined the associations of good leadership [15] [16] [17] [18] and bad leadership 7, 15, 19, 20 with outcomes such as job satisfaction and performance, that evidence is primarily correlational, and does not directly compare people's motivation to obtain good leaders versus avoid bad ones. Across seven studies, we examine the core motivation to avoid the worst leaders versus getting the best leaders in the first place, and provide both observational and causal evidence.

Study 1 uses text analysis of vision, mission, and core values statements from the world's top 100 business schools, to explore the relative priority of developing good leadership versus preventing bad leadership in current education programs. Study 2 examines actual employee experiences from 9.9 million Glassdoor reviews from approximately 35,500 firms, to explore how people rate and react to good and bad leaders in their work life. Five pre-registered experiments then test whether people are more willing to sacrifice time and money to avoid a bad leader than to obtain a good one, including American (Study 3) and Norwegian (Study 4) samples, separating variations in leader competence from moral character (Study 5), replicating the causal main effect across 40 countries in a cross-cultural study with broadly nationally representative samples (Study 6, N = 47,719), and finally with real monetary stakes in an incentivized choice design (Study 7).

Inspired by Popper's philosophical theory of institutional design 5 , our overarching hypothesis is that people are more motivated to avoid the worst leaders than to obtain the best leaders. Consistent with this prediction, research on the psychology of valence provides extensive evidence that "bad is stronger than good" [21] [22] [23] , as negative information, experiences, and life events tend to have a greater impact than the positive equivalents. This pattern has been found across first impressions, social relationships, personal feedback, and major life events, as well as in economic decision-making, which is referred to as 'loss aversion' 24.

Our hypothesis is also informed by the evolutionary perspective of error management. This theory suggests that when judgments are made under uncertainty and the costs of different errors are asymmetric, an adaptive cognitive system should be biased toward making the less costly mistake 25 . For instance, research on the "auditory looming bias" 26 has found that people perceive approaching sounds as closer and arriving sooner than they actually do, which is consistent with the idea that overestimating the distance to an approaching threat is a costlier mistake than underestimating it. Similarly, failing to reject a genuinely bad leader risks severe and sustained harm to oneself and the group, whereas mistakenly rejecting a genuinely good leader merely represents a lost opportunity for improvement rather than an existential threat.

There is suggestive evidence also from applied research consistent with our general hypothesis of bad-leader aversion in choice preferences. Negative information about job candidates shapes rejection decisions more than positive information shapes acceptance decisions 27 , and negative interactions with supervisors have stronger effects on employee outcomes than positive interactions 28 . Bad political candidates push voters to the opponent more than good candidates pull voters toward them 29 . In the workplace, an analysis of 50,000 employees found that replacing a toxic coworker with an average coworker had a much greater impact on performance than replacing an average coworker with a superstar 30 . In sum, there are psychological, evolutionary, and organizational bases for what we refer to as the "avoid-the-worst" principle in human leadership preferences: People might be more motivated to avoid the worst leaders than to obtain the best ones.

While we predict a dominant motivation to avoid bad leaders in both person perception domains, we expect the good-bad asymmetry to be stronger for morality than competence. Whereas competence signals a person's ability to solve problems and get things done, morality signals whether the person's intentions and goals are well-meaning and socially beneficial in the first place: Will this person help or harm me? Indeed, an immoral leader signals potential abuse, exploitation, and disregard for followers' interests, directly threatening interpersonal trust and cooperation 31, 32 . Moral character also shows greater interpersonal variation than competence 33 , and is processed faster, remembered more accurately, and prioritized over competence information in impression formation 12, [34] [35] [36].

Further, while competence matters more for positive "prestige" aspects of leadership (as opposed to dominance leadership), such that people willingly defer to highly skilled individuals they can imitate and learn from 37, 38 , an incompetent leader mostly threatens workrelated and societal effectiveness, and does not signal interpersonal harm. Followers evaluate immoral leaders more negatively than incompetent ones 14 , again suggesting people may be more averse to immoral than incompetent leaders. In the current research, we will therefore study choice preferences for good versus bad leaders in general, combining morality and competence information in the same general direction, and then specifically by varying the quality of only one of these dimensions at a time.

We will now present a series of large-scale studies using different methods and participant samples, exploring the role of good versus bad leaders in people's choice preferences, along with the impact of such leaders. Whereas Study 1 will explore the relative emphasis on developing good leadership versus preventing bad leadership in current business school education programs, Study 2 will explore the relative importance of good versus bad leaders in actual work life, based on how thousands of employees rate their organizational leadership. Studies 3-7 will then provide a causal test of our "avoid-the-worst" principle in leadership selection, in a series of five high-powered experiments across the world.

STUDY 1: LEADERSHIP EDUCATION PRIORITIES

Study 1 explored whether the official statements of the top 100 business schools per the annual Financial Times global ranking (analytic sample = 219 statements) emphasize promoting good leadership or preventing bad leadership. We analyzed a publicly available dataset from Mendeley Data 39 . These schools teach management and leadership skills on a considerable scale: Publicly verifiable, recent school-level figures for 47 schools alone total more than 250,000 currently enrolled students.

The official statements were coded with established promotion-focus and preventionfocus dictionaries 40 . Promotion focus emphasizes gains and advancement, whereas prevention focus emphasizes avoiding losses and maintaining safety and security 40 , making them useful proxies for pursuing good versus avoiding bad leadership outcomes. As a robustness test, we repeated the analyses using author-made dictionaries to compare the prevalence of aspirational-promotive language with that of precautionary-preventive language.

Results. Top business schools used positive "promotion-focused" language (e.g., "achieve", "grow", "improve") roughly seven times more often than negative "preventionfocused" language (e.g., "avoid", "prevent", "protect") in vision statements and 2.6 times more often in mission statements. A series of Wilcoxon signed-rank tests revealed a significant dominance of promotion-focused language in vision statements (promotion: M = 1.20, SD = 2.06; prevention: M = 0.16, SD = 0.68; V = 178.0, p < .001) and mission statements (promotion: M = 1.41, SD = 2.23; prevention: M = 0.55, SD = 1.56; V = 432.5, p = .002), but not in core values statements (promotion: M = 0.83, SD = 1.94; prevention: M = 1.17, SD = 3.24; V = 166.5, p = .829).

Similarly, when using our author-made dictionaries, we found a significant dominance of aspirational over precautionary language in vision statements (aspirational: M = 4.38, SD = 5.10; precautionary: M = 0.35, SD = 1.25; V = 725.0, p < .001), mission statements (aspirational: M = 4.19, SD = 4.00; precautionary: M = 0.66, SD = 1.69; V = 2136.0, p < .001), and core values statements (aspirational: M = 14.07, SD = 16.50; precautionary: M = 6.22, SD = 10.37; V = 942.0, p < .001).

In sum, these findings suggest that the world's top leadership education programs have a strong positive leaning. Despite the real-life dangers of bad leadership in organizations and society, precautionary and prevention-focused content receives modest coverage. We will now turn to the relative frequency and importance of good versus bad leadership in the workplace, when organizational leaders are judged by thousands of employees actually working for them.

STUDY 2: ACTUAL EMPLOYEE PRIORITIES

Study 2 examined how employees attend to good and bad aspects of their leaders. The leader-flagged sample contained 422,956 reviews from 4,885 firms, and the retained firms contributed 9,050,887 reviews. We analyzed an openly available dataset of Glassdoor reviews 41 written by real employees describing their actual managers. Glassdoor is the world's largest employee review database. Because reviewers use separate open-ended text fields to write positive and negative aspects of their job, we can compare how often employees mention their leader when writing about pros versus cons and use those mentions to predict their overall rating of the workplace.

Leader mention frequency.

Study 1 found that current leadership education focuses extensively on the positive aspects of good leaders. But if bad leaders are more psychologically impactful in real life, as our primary hypothesis predicts, then employees should mention their leader more often when describing negative aspects of their job than positive ones. Consistent with this prediction, 65.6% of leader-flagged reviews mentioned a leader in the negative "cons" field describing their job compared to 38.4% in the positive "pros" field, which is 1.7 times as often, reflecting a 27.2 percentage-point difference (McNemar χ²(1) = 32,662, p < .001). This asymmetry of leader mentions being more likely in the cons than pros section held in firm fixed effects models controlling for the log length of each field outside leader-mentioning chunks (OR = 1.69, 95% CI [1.63, 1.74], p < .001), employee status (OR = 1.69, p < .001), and when restricting analysis to firms with at least 25 leader-flagged reviews (OR = 1.71, p < .001).

Leader-mentioning chunk length.

Beyond whether employees mention their leader, we examined whether reviewers elaborate more when writing in a negative context. Chunks in the cons field were longer than those in the pros field (M = 17.1 words, SD = 11.9 vs. M = 12.0 words, SD = 8.4; W = 29,581,730,819, p < .001), suggesting their bad leaders play a greater role in their job experience than their good leaders. This pattern also held in models with firm fixed-effects (b = 4.95, SE = 0.05, p < .001), and when controlling for employee status (b = 4.94, SE = 0.05, p < .001).

Leader mentions predicting outcomes. To examine predictive validity, we tested whether leader mentions predicted overall company rating (1-5) and company recommendation to others (1 = positive,0 = negative), using reviews with non-missing outcomes from the retained firms and controlling for the length of each field outside leadermentioning chunks. For overall rating, a cons-field leader mention was associated with a lower rating (b = -0.843, SE = 0.009, p < .001), while a pros-field mention was associated with a higher rating (b = 0.573, SE = 0.006, p < .001). For company recommendation, a consfield leader mention was associated with a lower likelihood of a positive recommendation (b = -1.618, SE = 0.042, p < .001), while a pros-field mention was associated with a higher likelihood (b = 1.330, SE = 0.014, p < .001). The cons coefficient was significantly larger in absolute magnitude than the pros coefficient for both overall company rating (difference = 0.271, z = 28.45, p < .001) and company recommendation to others (difference = 0.288, z = 7.45, p < .001). Thus, a bad-leader mention predicted overall company rating 1.5 times as strongly and recommendation 1.2 times as strongly as a good-leader mention. The observational findings in Studies 1 and 2 suggest that in contrast with current leadership education programs, employees seem more concerned with the prevention of bad leaders and their overall negative impact than they were with the promotion of good leaders and their overall positive impact. However, these initial studies were purely observational.

Building on these correlational findings, Studies 3-7 will provide causal evidence from a series of controlled experiments on leadership choice preferences.

STUDY 3: GOOD VERSUS BAD LEADER CAUSAL EFFECT

Study 3 (N = 385 US-based Prolific participants; Mage = 35.25, SD = 13.58; 47.0% female) provides the first causal test of whether people are more motivated to avoid the worst leaders than to obtain the best ones. In a scenario-based choice experiment, the incoming candidate was said to replace the participants' current, average supervisor. The incoming leader candidate was then described as either highly moral and competent (having very high standards across both dimensions), or immoral and incompetent (having very low standards across both dimensions). Participants then made two binary choices: Whether they would spend their free time to vote in an internal election including the new leader, and whether they would sacrifice a salary increase in exchange for getting/not getting the leader in question.

Results.

Consistent with our primary hypothesis, participants were more likely to vote in an internal election to avoid a bad leader (84.9%) than to obtain a good leader (66.8%), OR = 2.79, 95% CI [1.71, 4.63], p < .001, and they were also more likely to give up a future salary increase to avoid a bad leader (46.9%) than to obtain a good leader (24.4%), OR = 2.74, 95% CI [1.78, 4.25], p < .001.

STUDY 4: REPLICATION IN NORWEGIAN STUDENT SAMPLE

STUDY 4: REPLICATION IN NORWEGIAN STUDENT SAMPLE sample from the United States, using a sample of Norwegian university students recruited from selective elite programs in economics, law, and engineering (N = 322; Mage = 23.49, SD = 2.40; 67.7% female).

Study 4 tested whether the bad-leader aversion replicates outside a general population

As in Study 3, participants read a description of an incoming leader portrayed as either very good (i.e., highly moral and competent) or very bad (i.e., highly immoral and incompetent).

Results. Norwegian students showed the same pattern of leadership preferences as the American general population sample. Consistent with our hypothesis, they were more likely to choose to vote in an internal election if it could help them avoid a bad leader (90.6%) rather than obtain a good leader (74.2%), OR = 3.33, 95% CI [1.80, 6.48], p < .001, and they were also more likely to choose sacrificing a future salary increase to avoid a bad leader (63.5%) than to obtain a good leader (40.5%), OR = 2.56, 95% CI [1.64, 4.03], p < .001. Thus, Studies 3 and 4 provide causal evidence for a general aversion to bad leaders over the attraction of good leaders, in which the competence and morality dimensions of the leader were combined and varied at the same time (high competence and morality vs. low competence and morality).

STUDY 5: COMPETENCE AND MORALITY DOMAINS

Study 5 (N = 1,955 US-based Prolific participants; Mage = 42.05, SD = 14.00; 49.1% female) examined whether the aversion to bad leaders operates similarly across the two person-perception dimensions of moral character and competence, using a factorial 2 (valence: Good vs. bad) x 2 (dimension: Competence vs. morality) between-subjects design.

To further specify what a "very good" or "very bad" leader meant and ensure a symmetric experimental manipulation, the incoming leader was described as either ranking in the top or bottom 20% of leaders, on either moral character or competence.

Results.

Our primary hypothesis of bad-leader aversion was supported across both person perception domains. Within the morality domain, participants were more likely to vote to avoid an immoral leader (82.9%) than to obtain a moral leader (75.1%), OR = 1.61, 95% CI [1.18, 2.20], p = .003, and more likely to sacrifice a future salary increase to avoid an immoral leader (50.5%) than to obtain a moral leader (28.6%), OR = 2.55, 95% CI [1.96, 3.33], p < .001. Within the competence domain as well, participants were more likely to vote to avoid an incompetent leader (79.5%) than to obtain a competent leader (63.4%), OR = 2.24, 95% CI [1.69, 2.99], p < .001, and to sacrifice a future salary increase to avoid an incompetent leader (30.1%) than to obtain a competent leader (15.6%), OR = 2.33, 95% CI [1.71, 3.19], p < .001.

The valence-by-domain interaction was not significant for either voting choice, OR = 0.72, 95% CI [0.47, 1.09], p = .123, or salary sacrifice choice, OR = 1.10, 95% CI [0.73, 1.65], p = .657. Thus, bad-leader aversion was present in both domains, but its magnitude did not differ significantly between morality and competence in the current sample.

STUDY 6: GLOBAL EVIDENCE

In Study 6, we tested whether the aversion to bad leaders over the attraction of good leaders generalizes across differences in culture, institutions, and language using nationally representative samples from 40 countries covering all world regions (N = 47,719; Mage = 42.83, SD = 15.25; 51.6% female), based on age, gender, and geographic distribution. As in Study 5, the leader was placed in either the top or bottom 20% of leaders on either moral character or general competence. Unlike previous studies, salary sacrifice was the only included choice outcome.

Results. Across all conditions in this global sample, 42.9% of participants were willing to sacrifice a 5% salary increase to influence the leader assignment in a workplace context.

Crucially, we replicated the main results from our prior studies: Participants were significantly more likely to sacrifice a future salary increase if it could help them avoid getting a bad leader (48.1%) than to obtain a good leader (37.7%), reflecting an average choice difference of 10.4 percentage points, OR = 1.60, 95% CI [1.47, 1.75], p < .001. We also explored Hofstede's cultural dimensions 43 as potential country-level moderators. STUDY 7: INCENTIVIZED CHOICE

In the final study, we tested whether people are more willing to sacrifice real money to avoid a bad leader than to obtain a good leader, using an actual monetary payment in an incentivized choice experiment rather than relying on hypothetical scenario-based choice (N = 1,052; Mage = 40.62, SD = 13.19; 48.8% female). This is an important validation test, since incentivized choice and other forms of actual behavior are surprisingly rarely studied in psychology 44, 45 , and can sometimes be only weakly linked with self-reported measures of attitudes and intentions 46.

As part of a problem-solving study, all participants were informed at the beginning of the session that ten participants would be randomly selected to receive their assigned supervisor for a follow-up task worth up to £10, and to complete the actual work task in question. This leader candidate, called Supervisor B, scored either 9 to 10 out of 10 (very good) or 0 to 1 out of 10 (very bad) on both morality and competence dimensions, compared with a default and average Supervisor A, who scored 5 out of 10 on each dimension. In a between-subjects design, participants were asked to make a choice of whether they would sacrifice some of their earnings either to obtain the good leader rather than getting the average leader, or to avoid the bad leader rather than getting the average leader, depending on condition. The leader in question would provide guidance and feedback on a relatively challenging problem-solving task. Because the supervisor would otherwise be assigned by a 50-50 lottery between the two candidates (good-medium or bad-medium), sacrificing £1 yielded the same expected gain in supervisor quality in both conditions (2.25 points on the 10point scale), matching the stakes of the two decisions in terms of magnitude.

Results. Once again, the results provided clear support for our bad-leader aversion hypothesis: Participants were significantly more likely to sacrifice real money to avoid getting a bad leader (54.5%) than to obtain a good leader (43.3%) in a future work task, OR = 1.57, 95% CI [1.23, 2.00], p < .001 (see Figure 4), reflecting an average choice difference of 11.2 percentage points. DISCUSSION

Across seven studies, we found robust evidence of aversion to bad leaders. While leadership education at the world's top 100 business schools emphasizes promoting good leadership over preventing bad leadership in vision and mission statements (Study 1), an analysis of over 9 million job reviews from 4,885 firms finds that employees writing about their own workplaces show the opposite pattern (Study 2): People wrote more often about their bad than good leaders, and mentioning a bad leader was more predictive of the overall company rating and recommendation to others than mentioning a good leader. We also found causal evidence of bad-leader aversion across five high-powered experiments: People were more willing to sacrifice time and money to avoid a bad leader than to obtain a good one, an asymmetry that replicated in US and Norwegian samples (Studies 3-4), held across variation in both leader morality and competence domains (Study 5), although it was stronger for morality (Study 6), generalized across 31 out of 40 countries with large differences in language, culture, and institutions (Study 6), and held with real monetary stakes (Study 7).

The aversion to bad leaders was a consistent effect that generalized around the world: Across experiments, people were 10 to 23 percentage points more likely to sacrifice time or money to avoid a bad leader than to obtain a good one. However, the bad-leader aversion was stronger in societies characterized by high (vs. low) electoral democracy, high (vs. low) cultural individualism, high (vs. low) GDP, and low (vs. high) power distance. These countrylevel moderators suggest that bad-leader aversion might be the strongest where people have both the norms and the channels to challenge authority. Similarly, bad-leader aversion was also stronger among relatively higher-income individuals within countries, suggesting that economic resources may shape the motivation to engage against bad leaders at both the individual and societal levels. Finally, the effect was found on both sides of the political spectrum, but was weaker among right-leaning than left-leaning participants.

These findings make at least three key contributions to advancing leadership research in psychology and social science. First, we identify bad-leader aversion as a robust and globally generalizable feature of how ordinary people approach leadership selection. While prior work has established that negative information dominates positive information in subjective experience and person perception 21, 23, 27 and that morality dominates competence in impression formation 12, 32, 34 , these findings have not been integrated or explored in human leadership preferences.

Second, we provide the first experimental test of Popper's precautionary theory of democratic institutions 5 , which we specify as an avoid-the-worst principle in leadership choice preferences. A large literature asks what makes leaders good or effective [15] [16] [17] [18] , but a much smaller one examines the existence and consequences of destructive leadership 7, 20, 47, 48.

Crucially, neither stream of research compares the motivational pull of bad versus good leaders in the first place, when it comes to people's willingness to incur personal costs to influence the leader selection process. Our main finding of bad-leader aversion aligns well with Popper's normative argument that the central function of democratic institutions should be to prevent the worst rather than select the best leaders 5 , and suggests that his precautionary view matches how everyday people actually think about leadership in the workplace, and especially among people living in well-functioning democracies rather than autocracies.

Third, when considering our observational and experimental evidence together, we identify a systematic disconnect between what educational institutions focus on and what people care most about in the workplace. It is well established that leadership research as a field has a clear positivity bias. We find a similar positivity bias in business school education programs, which focus on the positive and aspirational aspects of leadership, whereas actual employees seem to prefer the opposite focus, as they are more concerned with avoiding the worst leaders. Moreover, as reported in the Online Supplement, we also find that this educational positivity bias extends to popular science business books about leadership: Of the 72 leadership books on the New York Times monthly Business best-seller list from 2015 to 2026, twice as many books focused on good leadership as on bad leadership (64% vs. 31%).

There are some influential exceptions, like "The no asshole rule" 49 , which made an early research-based argument for better selection and removal procedures to prevent destructive employees from doing too much damage in organizations. The main emphasis in the bestselling popular science category, however, remains on the bright side of leadership.

This disconnect raises a broad question for leadership education, research, and practice: Are we training and selecting future leaders to best support the needs of the people working for them? Our research suggests the current answer is No. For organizations and institutions, the current findings are as important for selection as for training. Investments in improved research-based selection processes that filter out the worst and most destructive leader candidates, and job termination procedures that facilitate effective removal when needed, may yield substantial positive returns for employees, organizations, and society.

Our research has several limitations, which offer directions for future work. First, concerning Study 2, we note that employees who feel especially strongly about a bad leader may be more likely to write a review in the first place, and we do not have information about employees who chose not to review their employer, making our controlled experiments the stricter test of the "avoid-the-worst" principle. Second, our experiments used a binary contrast between good and bad leaders. Whether the bad-leader aversion holds when candidates are varied continuously, when good and bad qualities coexist in one candidate, or when the choice is among multiple imperfect candidates remains to be studied. Third, Study 6's global sample coverage was constrained by the global panel provider. Exploratory analyses found that democratic quality, corruption, and cultural power distance moderated the bad-leader aversion at the country level, but their cross-sectional nature cannot establish whether institutions causally shape the bad-leader aversion or result from it. Future work could examine longitudinal variation within countries and natural experiments to causally test such cultural and institutional effects. Fourth, our outcome measures focus on the willingness to sacrifice time and money. Other forms of engagement (voice, exit, collective action, national voting) may follow different dynamics, and field studies should test whether bad-leader aversion predicts these. Future work could also explore whether the avoid-the-worst principle extends beyond workplace supervisors to contexts such as political offices.

Conclusion

In the aftermath of World War 2, Karl Popper 5 argued that the central question of institutional design is not who should rule, but how to prevent bad leaders from doing too much damage. Our data suggest that people across 40 countries tend to share this priority in their leadership choices. The bad-leader aversion in human leadership preferences was robust and highly replicable across different methods and a broad range of cultural settings, and stronger where well-functioning democratic institutions and egalitarian cultural norms exist.

Yet, the leading educational institutions that train future leaders seem to emphasize the opposite. In our view, the current findings suggest that we are severely underestimating the value of avoiding bad leaders in organizations and society.

METHODS

Study 1: Leadership Education Priorities

Materials and Procedure.

We examined a publicly available dataset that contained the vision, mission, and core values statements from the 100 business schools listed in the 2020 Financial Times global MBA rankings 39 . Our analytical sample comprised a total of 219 pieces of text from 94 schools, comprising 60 vision statements, 91 mission statements, and 68 core values statements. We first performed a quantitative content analysis using established dictionaries to measure two distinct strategic orientations: Promotion and prevention focus 40 . The promotion-focused lexicon, which we take as a proxy for "focus on being good," included 25 word stems associated with actively pursuing positive outcomes and achievements (e.g., "achieve," "grow"). The prevention-focused lexicon, which we take as a proxy for "focus on not being bad," included 24 word stems associated with preventing negative outcomes and ensuring compliance (e.g., "avoid," "duty," "risk").

To test the robustness of this pattern, we conducted a second content analysis using a separate set of author-made dictionaries. The aspirational dictionary comprised 10 word stems associated with achieving positive outcomes (e.g., "innovation," "impact"). The precautionary dictionary comprised 10 word stems associated with avoiding negative outcomes (e.g., "compliance," "accountability").

Keyword counts were normalized by document length (per 100 words). Because the frequency distributions were skewed and the promotion and prevention counts are paired within document, we compared them with two-tailed Wilcoxon signed-rank tests, separately for vision, mission, and core values statements.

Study 2: Actual Employee Priorities

Materials and Procedure.

To examine whether employees are more sensitive to bad leaders than good leaders in naturalistic settings, we analyzed a publicly available dataset of Glassdoor employee reviews comprising over 9.9 million reviews from approximately 35,500 firms across a wide range of industries and countries 41 . Glassdoor is a platform where current and former employees write structured reviews of their employers, providing separate freetext fields for positive aspects of the job (pros) and negative aspects (cons), alongside numerical ratings on overall satisfaction and several sub-dimensions, including recommending the workplace to others.

We identified leadership-relevant reviews by flagging any review in which a leadership term appeared in either the pros or cons field. We matched manager, supervisor, and boss as bare terms, given their near-unambiguous reference to a direct leader in review text. For less common or more ambiguous designations, we required the possessive form, my director or my team lead, to limit false positives. Matching was case-insensitive and used word boundaries. This procedure identified 450,343 leader-flagged reviews (4.5% of the 9,901,889 reviews in the full dataset). We excluded firms with fewer than 10 leader-flagged reviews to ensure sufficient within-firm variation for fixed-effects estimation. Of the 14,890 firms with at least one flagged review, this removed 10,005 firms but only 6.1% of flagged reviews (27,387 reviews). The retained 4,885 firms contributed 422,956 leader-flagged reviews and 9,050,887 reviews in total. The primary mention models used all 9,050,887 reviews from these firms. The workplace-evaluation models used reviews with non-missing outcomes, including 9,050,730 reviews for overall company rating and 6,406,816 reviews for company recommendation. The leader-language analyses used the leader-flagged sample. In the leaderflagged sample, overall company rating had a mean of 2.95 (SD = 1.34). On the recommendation item, 185,885 reviews were negative, 156,952 were positive, and 80,119 gave no opinion. The leader-language recommendation models used the 342,837 reviews with a directional response, of which 339,959 were retained after dropping firm singletons.

Leader measures. Leader mention was coded 1 if a field contained a leader term and 0 otherwise. Leader-mentioning chunk length was the mean word count of the chunks in a field that contained a leader term, with chunks split at sentence-ending punctuation, semicolons, colons, dashes, line breaks, and commas followed by a capital letter. Leader-mention density was the number of leader terms per 100 words in a field. Each review from the 4,885 retained firms contributed one pros and one cons observation for leader mention and density, and each field with a leader-mentioning chunk contributed one observation for chunk length. All models included firm fixed effects, controlled for the log length of each field outside leadermentioning chunks where relevant, and clustered standard errors by firm. Full details are reported in the Online Supplement.

Leader language predicting outcomes. We also explored whether the content of leader-relevant language predicted overall rating (1-5) and company recommendation (1 = positive,0 = negative). To capture leader language content, we applied four keyword dictionaries distinguishing valence (good vs. bad) and domain (moral vs. competent). These are reported in detail in the Online Supplement.

Study 3: Good Versus Bad Leader Causal Effect

Participants. We recruited 400 participants from the United States via Prolific. Of them, 385 passed the attention check and made up the analytic sample (Good = 193, Bad = 192; Mage = 35.25, SD = 13.58; 47.0% female). Study 3 was non-registered, whereas for all the following experiments (4-7) in this paper the study design, measures, and planned analyses were pre-registered before each data collection.

Materials, Procedure, and Measures.

Participants were randomly assigned to one of two conditions: Good leader or bad leader. All participants imagined a scenario where their organization planned to hire a new leader to replace their current, average supervisor. In the good leader condition, the candidate was described as a moral and competent person with very high standards for both. In the bad leader condition, the candidate was described as an immoral and incompetent person with very low standards for both. As the main outcome measures, participants were asked if they would be willing to spend an hour of their free time to vote in an internal election and if they would sacrifice a 5% salary increase. In the good leader condition, the sacrifice question was framed to guarantee the leader was hired, while in the bad leader condition, it was framed to guarantee the leader was not hired.

Study 4: Replication in Norwegian Student Sample

Participants. We recruited students studying economics, law, and engineering at top universities in Norway. Of the 429 complete responses received, 322 passed the attention check and made up the analytic sample (Good = 163, Bad = 159; Mage = 23.49, SD = 2.40; 67.7% female). The study design, measures, and planned analyses were pre-registered before data collection (https://aspredicted.org/BPX_4TM).

Materials, Procedure, and Measures.

The procedure was identical to Study 3. As secondary outcome measures, participants were asked about the perceived impact of the new leader on their future happiness at work, work motivation, job task completion, and organizational trust. As the main outcome measures, participants were asked if they would be willing to spend an hour of their free time to vote and if they would sacrifice a 5% salary increase, framed identically to Study 3.

Study 5: Competence and Morality Domains

Participants. We recruited 1,955 participants (Mage = 42.05, SD = 14.00; 49.1% female) from the United States via Prolific. As a sensitivity analysis, we repeated the analyses among the 1,863 participants who passed the comprehension check and found no meaningful differences. The study design, measures, and planned analyses were pre-registered before data collection (https://aspredicted.org/p5yp-98rp.pdf).

Materials, Procedure, and Measures.

Participants were randomly assigned to one of four conditions in a 2 (valence: Good vs. bad) × 2 (domain: Morality vs. competence) between-subjects design. All participants imagined a scenario where their organization planned to hire a new leader to replace their current, average supervisor. In the good leader conditions, the candidate was described as being in the top 20% of leaders on either moral character (moral condition) or general competence (competent condition).

In the bad leader conditions, the candidate was described as being in the bottom 20% of leaders on either moral character (immoral condition) or general competence (incompetent condition). As secondary outcome measures, participants were asked how they would feel if their organization hired the leader and how much they would trust their employer. As the main outcome measures, participants were asked if they would be willing to spend an hour of their free time to vote and if they would sacrifice a 5% salary increase, framed identically to the previous experiments.

Study 6: Global Evidence

Participants. We recruited 47,719 participants (Mage = 42.83, SD = 15.25; 51.6% female), roughly 1,000 each from 40 countries, using a global data collection agency. Each country-level sub-sample was nationally representative of age, gender, and geographic distribution. Participants who failed an attention check or had missing data on the key variables were already excluded from this sample. The study design, measures, and planned analyses were pre-registered before data collection (https://aspredicted.org/cyxg-2v9w.pdf).

Materials, Procedure, and Measures.

Participants were randomly assigned to one of four conditions: Moral leader, immoral leader, competent leader, or incompetent leader.

Participants imagined a scenario where they work in an organization where the current leader is considered average, neither particularly good nor particularly bad. Their organization plans to hire a new leader, who will also be the participant's supervisor. Depending on the experimental condition, we told participants that a reliable friend, who has previously worked with this potential leader candidate, places them in the top or bottom 20% of leaders working in similar organizations, in terms of moral character or general competence.

As exploratory measures, participants were first asked how they would feel if their organization hired the leader, where they chose between "less happy at work than before", "no difference", and "more happy at work than before", and how much they would trust their employer, where they chose between "less than before", "no difference", and "more than before". Importantly, as the main outcome measure, participants were asked if they would be willing to sacrifice a 5% increase in their salary if it could guarantee that the good leader is hired (moral and competent conditions), or if it could guarantee that the bad leader is not hired (immoral and incompetent conditions).

Analytic Strategy.

To test our pre-registered hypotheses, we estimated a series of multilevel binary logistic regressions with salary sacrifice (0 = No,1 = Yes) as the outcome and random intercepts for country. For the main test of leader valence, the valence × domain interaction, the ideology models, and the country-level moderator models, we included random slopes for valence; other individual-level moderation models used random intercepts only. We tested whether the effect held within each domain by subsetting the data to the morality and competence domains, respectively. For the ideology models, we added political orientation (1 = Far left,7 = Far right; standardized) and its interaction with leader valence as predictors of the sacrifice decision. We also explored whether the bad-leader aversion varied with country-level institutional quality using multilevel binary logistic regressions with leader valence, the country-level moderator (standardized), and their interaction as fixed effects, and random intercepts and random valence slopes for country.

Study 7: Incentivized Choice

Participants. We received complete responses from 1,099 US-based participants recruited using Prolific. After excluding 37 participants who failed the visual perception bot check 50 , and 10 participants who failed the attention check by agreeing that they swim across the Atlantic Ocean to get to work, the final sample consisted of 1,052 participants (Mage = 40.62, SD = 13.19; 48.8% female). No participant failed all three comprehension checks. The study design, measures, and planned analyses were pre-registered before data collection (https://aspredicted.org/a56586.pdf).

Materials, Procedure, and Measures.

Participants were randomly assigned to one of two conditions: Good leader condition or bad leader condition. To create an incentive-compatible context, participants first completed a 10-item number series reasoning task and were told that 10 participants completing the survey would be randomly selected and invited to participate in a 30-minute group problem-solving study the following week, which would pay a £5 base payment plus the chance to earn up to £5 more based on performance.

Participants were instructed to answer all subsequent questions as though they had been selected, because there was a real chance they would be.

Participants were then informed that if selected, they would be assigned one of two pre-evaluated supervisors. Supervisor A was described as scoring 5 out of 10 on both moral character and competence (average). In the bad leader condition, Supervisor B was described as scoring 0 or 1 out of 10 on both moral character and competence, making them "generally perceived to be an immoral and incompetent person." In the good leader condition, Supervisor B was described as scoring 9 or 10 out of 10, making them "generally perceived to be a moral and competent person." In both conditions, participants were told the supervisor would be randomly selected between Supervisor A and Supervisor B with an equal 50-50 probability unless they chose to intervene.

As the main outcome measure, participants were asked whether they would sacrifice £1 from their £5 future base payment to influence their supervisor assignment. In the bad leader condition, sacrificing £1 guaranteed they would not get Supervisor B and would instead receive Supervisor A. In the good leader condition, sacrificing £1 guaranteed they would receive Supervisor B rather than Supervisor A. This design held the value of the £1 sacrifice constant across conditions. Taking the midpoints of the stated ranges (0.5 in the bad leader condition, 9.5 in the good leader condition), the 50-50 default gave an expected supervisor quality of 2.75 in the bad leader condition and 7.25 in the good leader condition, while sacrificing £1 secured a supervisor scoring 5 and 9.5, respectively. In both conditions, the £1 yielded an expected improvement of 2.25 points on the 10-point scale, so a difference in sacrifice rates between conditions cannot be attributed to unequal stakes.

Within each condition, the framing of the choice options was randomly varied between subjects while keeping the substantive content identical. In the bad leader condition, one version presented the options as "Yes: I choose to sacrifice £1 to avoid Supervisor B (getting Supervisor A)" and the other as "Yes: I choose to sacrifice £1 to get Supervisor A (avoiding Supervisor B)."

In the good leader condition, one version presented the options as "Yes: I choose to sacrifice £1 to get Supervisor B (avoiding Supervisor A)" and the other as "Yes: I choose to sacrifice £1 to avoid Supervisor A (getting Supervisor B)." In both versions, the no-sacrifice option read: "No: I choose not sacrificing £1 (random 50-50 selection proceeds between Supervisor A and B)." For all main analyses, responses were collapsed across the two framing versions. Following the sacrifice choice, participants rated how being assigned Supervisor B (rather than Supervisor A) would affect their (a) happiness and well-being, (b) trust in the leader, and (c) performance during the task, each on a 5-point scale from Much less (1) to Much more (5). We reverse-coded responses to these three rating measures for the bad leader condition so that we could compare magnitudes directly across good versus bad leader conditions.
