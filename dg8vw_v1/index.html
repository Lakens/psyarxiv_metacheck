What we found

We found 26 non-significant p values that should be checked for appropriate interpretation.

Show details

Meta-scientific research has shown nonsignificant p values are commonly misinterpreted. It is incorrect to infer that there is ‘no effect’, ‘no difference’, or that groups are ‘the same’ after p > 0.05.

It is possible that there is a true non-zero effect, but that the study did not detect it. Make sure your inference acknowledges that it is possible that there is a non-zero effect. It is correct to include the effect is ‘not significantly’ different, although this just restates that p > 0.05.

existing_data_explanation No, no data have been collected for this study yet.
research_questions We will investigate whether experiential vs. observational learning affects recognition memory differently across development. Children (8-10 years) will perform a learning task followed by a surprise recognition memory test.
The learning task consists of interleaved experiential and observational learning trials. At the beginning of a trial, participants will be informed if it’s their turn (experiential learning) or if they observe another player (observational learning). Next, a value (potential reward) is shown followed by an image. During the image display, participants must decide whether they want to gamble (play) for the value or not (pass) (experiential learning) or observe another player’s play-pass choice (observational learning). Next, the trial outcome (winning, losing, or neutral) is presented. The images are assigned to two categories (animate vs. inanimate) which reflect opposing reward probabilities that change throughout the task. After choosing play, participants are rewarded based on the reward probability. When passing, they see the hypothetical outcome. In observational trials, participants see the other player’s feedback.
In the following memory test participants see the images from the learning task interleaved with new but semantically matching images. For each image, they must state if it is old or new and rate their confidence.
Based on previous developmental studies, we expect children to show better memory performance for images seen during experiential compared to observational learning trials. In adults, we could reveal enhanced memory for experienced and observed gambling (Woitow et al., work in progress). Whether this is similar in children will be explored. Overall, we expect children in both learning conditions to remember the images reliably (above-chance level). However, compared to adults we expect children to show reduced memory accuracy. Moreover, based on previous developmental studies, we expect developmental differences between children and adults in experiential and observational learning as well as gambling behavior.
We will investigate underlying computational mechanisms during experiential and observational learning. Here, we will examine how prediction errors (PE) during learning are linked to subsequent memory and whether this differs across development. Previous research in adults showed a positive effect of PEs during experiential learning on memory. However, no study to our knowledge examined this link in children. Overall, we expect differences between children and adults in PE coding and its effect on memory due to maturational changes in involved brain regions from childhood to adulthood.
design_dependent_variables Behavioral variables: (1) Learning task. For experiential learning trials, we will record the decision (play or pass) and the decision time (reaction time). In observational learning trials, participants must press the spacebar during image display to see the other player’s choice. Here, we will record key press and reaction time. (2) Memory task. During the memory test, participants must state for each image whether it is old (seen in the learning task) or new (not seen before). Then, participants rate their confidence regarding their choice on a scale from 1 (guess) to 4 (completely certain). We will combine the two responses to one memory score ranging from 1 (new and highest confidence) to 8 (old and highest confidence) representing our key dependent variable to assess memory performance.
Computational variables: (1) We will use a Bayesian ideal observer model to calculate the expected reward probability for each trial while considering changes in the reward probability (change points, CP) (see Jang et al., 2019 for further details). The model will be given information about the true probability of the CP occurrence for each trial (hazard rate). Based on the estimated reward probability we will calculate the trial-by-trial learning rate. (2) Following Jang et al. (2019), we will calculate PEs during the value, image, and feedback phase. The value PE depends on the possible values (1, 5, 10, 20, 100) shown during each trial. The image PE is computed by calculating the PE before and after the image display (see Jang et al., 2019 for further details). We assume the reward expectation before seeing the image category to be the average across both categories. The image PE is computed as the difference between reward expectation before and after observing the image category. The feedback PE depends on the possible outcomes of a trial (winning, losing, or neutral). (3) Further, we want to investigate the effect of other computational factors like surprise and uncertainty on recognition memory. Surprise (trial-by-trial changes of CP probability) will be computed by marginalizing over expected reward probabilities. Uncertainty will be measured by calculating the entropy of the posterior probability distribution of the reward probability for each trial.
study_design_overview The study follows a within-subject design. Each participant will perform 160 learning trials (80 trials per learning condition, switch after 1-2 trials of the same condition) and 320 memory trials (interleaved 160 old and 160 new images). However, each participant performs a unique task since the reward probability can change on each trial with a probability of 0.16 to a random value between 0 and 1 (no CP during the first 20 trials of the learning task and first 15 trials after a CP occurred).
statistical_tests Our data analysis will follow the analysis from our previous study in adults (Woitow et al., work in progress) to enable comparison of results. Thus, we will use the predicted reward probability estimated by the Bayesian ideal observer model when including reward probability in the analyses. (1) Learning. To investigate the choice behavior during the learning task we will fit different reinforcement learning (RL) models to participants’ choices. Our base model contains four parameters: (1) temperature parameter, (2) value exponent term (effect of trial value on choice behavior), (3) play bias term (tendency to attribute higher values to play decisions), and (4) learning rate. This base model will be compared to additional RL models which contain the same four parameters and additional ones (e.g. surprise, uncertainty). Besides, we will determine separate learning rates for experiential and observational learning. We will compute the Bayesian information criterion (BIC) for each model and compare them. The model with the lowest BIC will then be used to simulate choice behavior to compare participants’ behavior to model-predicted behavior. (1) Memory. Memory accuracy will be first assessed by determining hit rates and false-alarm rates and comparing them between experiential and observational learning as well as between play and pass trials. To check if participants’ memory performance was better than chance, we will apply a one-sample t-test to d-prime (hit rates - false-alarm rates) values. Further, we will examine if the subjective confidence rating reflects true memory strength by testing if memory accuracy is better for higher than lower confidence. Next, we will check whether memory scores (1 to 8) differ between experiential and observational learning and between play and pass trials. (3) Learning & Memory. The link between learning-related computational factors and memory will be examined for each participant and factor. We will check for the overall effect of these factors on memory scores and compare them between learning conditions and between play and pass trials. Besides, we will model participants’ memory scores using a hierarchical regression model to examine the contribution of learning-related computational factors to subsequent memory performance.
We will compare results in children to results in adults from our previous study (Woitow et al., work in progress) and combine data from both studies for joint analyses to investigate developmental differences.

To determine the above-chance performance we will simulate random choices using the same learning task structure and compute the total score achieved. How Ethics Approval Check works

This module searches for statements of ethics approval, IRB approval, institutional review board approval, and related terms.

Patterns are designed to capture:

Human research committee names - Institutional Review Board / IRB (US standard) - Independent Ethics Committee / IEC (ICH-GCP international clinical trial term) - Ethical/Ethics Review Board (generic) - Ethics (Advisory/Review) Committee/Board/Panel/Sub-committee - Research Ethics Committee/Board/Panel (UK/Canada/Australia) - Medical Ethics Committee - Human Subjects/Research Committee / Human Research Ethics (Advisory) Panel - Committee for/on the Protection of Human Subjects - Committee on (Health) Research Ethics - Office of Research Ethics - Abbreviations: IEC, REC, REB, ERB, METC, DEC. REC/REB/ERB/DEC are short enough to collide with unrelated jargon (e.g. REC as a recognition-heuristic model abbreviation, DEC as a decision-task label, Reb as an author surname), so these four require an ethics/approval/committee/board/panel/institutional/ protocol word within ~30 characters in the same sentence. IRB and IEC are kept unconstrained as they are not observed to collide in practice. - Dutch: Medisch-ethische toetsingscommissie (METC) - French: Comité d'éthique / Comité d'Ethique

Animal research committee names - Institutional Animal Care and Use Committee / IACUC (US standard) - Any sentence containing animal(s) and committee (or board/panel) within ~5 words of each other — catches Experimental Animal Care and Use Committee, Animal Ethics Committee, Animal Welfare Board, Animal Welfare Ethical Review Body, etc. - UK: Animal Welfare Ethical Review Body / AWERB - Dutch: Dierexperimentencommissie / DEC (see DEC constraint above); Instantie voor Dierenwelzijn / IvD - German: Tierversuchskommission / TvK (advisory committee under §15 Tierschutzgesetz) - French: Comité d'éthique en expérimentation animale / CEEA; Comité d'éthique animale - Spanish: Comité de ética en experimentación animal / CEEA

Approval phrasing - Ethics/Ethical (approval|clearance) [was] (granted|obtained|received|given|secured) - Ethically approved - Approved by the (ethics|irb|institutional|independent|local|review|research) ... - This/The study/protocol/experiment/procedures/methods/research [was] (approved|reviewed) by - Study was ethically approved - (Followed|met|follow) the ethical (guidelines|standards|requirements) - In accordance with ... ethical (guidelines|standards) - Ethics protocol - Approved under (protocol|reference|number)

Waiver / exemption - Ethics/Ethical (waiver|exemption) - IRB (waiver|exemption|exempt) - Exempted from (ethics|irb|institutional review) - Waived by the (ethics|irb|institutional|review) (committee|board) - Deemed exempt

Declaration of Helsinki - Declaration of Helsinki / Helsinki Declaration

Patterns are NOT designed to capture: - General ethical considerations or ethical dilemmas in study content - Mentions of “ethics” in theoretical or philosophical contexts - Author approval of a manuscript (e.g. “all authors approved the final version”) - Ethical behaviour as a measured variable (e.g. “ethical decision-making”) - URLs containing “ethics” in path components

Live data collection is detected by the internal helper .detect_live_data(), which searches for sentences indicating that data were collected directly from human or animal participants. Papers without any live-data signal are not flagged as missing ethics approval. The helper uses conservative patterns to avoid flagging secondary data analyses, computational experiments, or economics papers that analyse existing survey data. See .detect_live_data() for the full list of patterns and intentional exclusions.

A paper that states that no human or animal subjects took part (“no human subjects were involved”, “did not involve human participants”, or people taking part “not as subjects”) is not expected to have an ethics statement, whatever participant phrase it also has (see .detect_no_participants()). A negation near a participant phrase alone (“No participants were excluded”) does not count: it reports a study with participants.

How Power Analysis Check works

This module uses regular expressions to identify sentences that contain a statistical power analysis. If specified by the user, it also uses a large language model (LLM) to extract information reported in power analyses, including the statistical test, sample size, alpha level, desired level of power, and magnitude and type of effect size.

The Power Analysis Check module uses regular expressions to identify sentences that contain a statistical power analysis. Without the use of an LLM, the module uses regular expressions to classify the power analysis as a-priori, sensitivity or post-hoc. With the use of an LLM, it checks if the power analysis is reported with all required information.

The regular expressions can miss power analyses, or fail to classify them correctly. The type of power analysis is often difficult to classify, which can easily be solved by explicitly specifying the type of power analysis as ‘a-priori’, ‘sensitivity’, or ‘post-hoc’. Note that ‘post-hoc’ or ‘observed’ power is rarely useful. The LLM can fail to identify information in the paper, and will not have access to information in paragraphs in the paper other than those that contain the word ‘power’. This package was validated by the Metacheck team on articles in Psychological Science.

How StatCheck works

Check consistency of p-values and test statistics

The Statcheck module runs Statcheck. Statcheck searches for regular expressions that match a predefined pattern, and identifies APA reported statistical tests. More information on the package can be found at https://github.com/cran/statcheck. The module only returns Statcheck results for t-tests and F-tests, as these are the only tests which have been validated, see https://osf.io/preprints/psyarxiv/tcxaj_v1/.

Statcheck was developed by Michèle Nuijten and Sascha Epskamp.

Statcheck considers p = 0.000 an error, as you should report p < 0.001. Furthermore, p < 0.03 is an error if the p-value was 0.031, and one should simply report exact p-values (p = 0.031). When the sentence of a test says it is one-sided (“one-tailed”, “one-sided” or “directional”), a p-value that fits a one-sided test counts as consistent (statcheck’s OneTailedTxt setting; #695). Statcheck might still miss one-sided tests that are described in another sentence, and falsely assume the p-value is incorrect. For more information, see StatCheck.

This module only checks statistical results reported in the running text of the manuscript. It cannot (yet) process statistics reported only in tables.

How Exact P-Values works

List any p-values reported with insufficient precision (e.g., p < .05 or p = n.s.), reported as exactly zero (e.g., p = .000), or impossible (below 0 or above 1, e.g., p = -.22).

This module uses regular expressions to identify p-values. It will flag any values reported as p > ? or p < numbers greater than .001. It will also flag p-values reported as exactly zero (e.g., p = .000, p = 0.00), which are mathematically impossible — p-values are never exactly zero and should instead be reported as p < .001.

A p-value that is not the result of a test is not flagged: a table note (“* p < .05, ** p < .01”), a figure legend (“Asterisks indicate significant differences (p < .05)”, “Values in bold are significant at p < .05”) or a stated threshold (“p < .05 was considered significant”, “thresholded at p < .001”). GROBID often puts such notes into the running text, so each p-value is judged by the words in its own clause (the text up to a “;” or a full stop), and never left out when a test statistic belongs to it (“F(1, 7) = 8.03, # p < .05”). The column not_a_test of the table says why a p-value was left out (“marker”, “threshold”, “legend” or “named”).

A p-value with the name of a correction or a test after the p (“pFWE < .05”, “padj < 0.05”, “p Wilcoxon = .02”) is flagged only when a test statistic comes before it in its clause (“t(37) = 7.17, p FWE < .05”). Without one it is mostly the rule that decided what was significant (“genes with padj < 0.05 were selected”); such a p-value is “named” in not_a_test. Notes in other forms, such as a marker after the p-value (“p < .05 (*)“), are still flagged.

A p-value below 0 or above 1 is impossible; it is listed apart and not also as imprecise. Often the statistic before it, or its minus sign, was copied into it (“t(134) = -2.32, p = -.13”, “Z = 3.091, P = 3.091”). A value above 1 is listed only after a test statistic in its clause: without one, a “P” above 1 was nearly always another quantity (a proportion, pH, a group’s mean, a model parameter). A number in scientific notation whose power of ten was lost when the PDF was read (“p = 2.4 x 10 -9” read as 2.4) is not listed. A “p” that is the subscript of another symbol (“r p = .64”, “²p = .02” for partial eta squared, “Δp = .33”), or a quantity with a unit, a logarithm or a ratio (“P = 2.9 µm”, “-log10 P = 7.5”, “Ca/P = 1.67”), is not read as a p-value at all (see extract_p_values()). Each p-value has its own row, also when the same one is written twice in a sentence.

This module sometimes flags false positives when sentences discuss how p-value thresholds were set. It can also miss an imprecise p-value that is reported against a threshold (“decreased at the p < .05 significance threshold”).

This module only checks p-values reported in the running text of the manuscript. It cannot (yet) process p-values reported only in tables (as opposed to a table’s footnote text, which the module does see and tries to exclude — see above).

This module was developed by Lisa DeBruine and Daniel Lakens

Read more in the metacheck manual.

Version 0.4.4.3 reported 419 p-values as imprecise, 388 of them correctly (93%), and missed 50 (89% found). How Non-Significant P Value Check works

This module checks for imprecisely reported p values. If p > .05 is detected, it warns for misinterpretations.

The nonsignificant p-value check searches for regular expressions that match a predefined pattern. The module identifies all p-values in a manuscript and selects those that are not reported to be smaller than or equal to 0.05. It returns all sentences containing non-significant p-values.

In the future, the Metacheck team aims to incorporate a machine learning classifier to only return sentences likely to contain misinterpretations. If you want to help to improve the module, reach out to the Metacheck development team.

A p-value in a table note (“† p < .10, * p < .05”) or a figure legend (“dashed lines indicate non-significant paths (p > .05)”) is left out, as in stat_p_exact; the column not_a_test says why. A p-value next to words that state a threshold is kept, because such sentences often report a result against that level (“not significant at the conventional threshold (p = .054)”).

How Codebook Check works

This module checks whether the data columns in a repository are documented in a codebook or README. It locates codebook/readme files, extracts the variable definitions they contain, matches those definitions against the data columns extracted by data_check, and reports documentation coverage: how many data columns are documented, and which documented variables are never used.

The Codebook Check module consumes the columns and file classification produced by data_check (and, transitively, repo_check). Files classified as codebook or readme are parsed with parse_codebook(), which reads structured tables (CSV/TSV/Excel with a variable-name column and a label column), embedded labels in haven files (SPSS/Stata/SAS), and plain text from rich-text formats (docx/pdf/rtf/odt). Embedded haven labels from data files are also harvested directly.

Each data column is then matched against the parsed variable definitions with match_column_labels(), using normalised-name matching with experiment-group scoping, haven-label priority, and rule-based label-equivalence merging.

Beyond the variable label, the module harvests the DDI-style per-variable properties a source supplies: the value labels / code list (the 1=“Strongly disagree”…5=“Strongly agree” mapping — from SPSS/Stata value labels and from a codebook “values”/“coding” column), the missing-value scheme (which codes denote missingness, from haven declared missings and labels that read as “refused”/“n/a”), and question text and columns when present. These are carried onto the matched data columns and exported into the Psych-DS variableMeasured (as a schema.org code list plus namespaced metacheck: fields).

The module defaults to rules-only when llm_use(FALSE). When llm_use(TRUE), three optional LLM tiers run: parsing unstructured codebook text that the rules could not handle, fuzzy-matching still-unlabelled columns to still-unmatched codebook variables, and merging conflicting label definitions into a single canonical label.

How Repository Check works

This module retrieves information from repositories.

The Repository Check module lists files on the OSF, GitHub, ResearchBox, DSpace (PsychArchives and other legacy- and DSpace 7-based installations), Zenodo, Dataverse, Figshare, Dryad, ReShare, 4TU.ResearchData, Mendeley Data, DataONE (Arctic Data Center, KNB, and other member nodes), and LDbase based on links in the manuscript.

A link to a file-sharing service (Google Drive, Dropbox, OneDrive, Box, WeTransfer, MEGA, iCloud Drive, Baidu Netdisk, SURFdrive; see [file_share_links()]) gets a warning and makes the light yellow: such services are not repositories, as files can be changed or deleted at any time, get no DOI, and the link stops working when the account is closed. The report advises a stable repository such as Zenodo instead. Their files are not read, and summary_table$file_share_n counts the links.

Deposits in archives for sequence and expression data (GEO, the INSDC archives BioProject, SRA, ENA and DDBJ, and ArrayExpress; see [seq_archive_links()]), mostly named by accession number, are read for whose deposit they are. The authors’ own are listed with what they hold ([seq_archive_size()]) and are not downloaded or checked as data and code; summary_table$archive_own_n counts them.

R packages on CRAN ([cran_links()], [cran_info()]) are the paper’s own when a paper author is a package author and the paper presents the package; the paper’s own are listed with their version and not checked (summary_table$cran_own_n). A Handle link (hdl.handle.net/...) that leads to a repository read here is checked as a link to that repository ([handle_links()]).

Listing a repository’s files never requires an API key, but some hosts answer faster or more completely with one: OSF allows 100 requests/hour unauthenticated versus 10,000/day with a token (see [osf_pat()]), and Dryad enforces a strict per-IP daily quota on repeated listing (see cache below). Dryad is a special case beyond rate limits: listing a Dryad dataset’s files works without a key, but actually downloading file CONTENTS from Dryad fails with HTTP 401 unless a key is set, even for a fully public dataset (see [dryad_pat()] or [dryad_auth()]). Since this module only lists files and never downloads their contents itself, that limitation applies to data_check and code_check (which do download content), not here – see their own documentation.

When a linked OSF page is a registration, its registered_from project (the one it was registered from, which the manuscript itself may never link directly) is also checked: if that project is public its files are listed under its own URL, and if it is closed or otherwise inaccessible the report flags it explicitly, since some registrations only describe their content rather than mirroring it.

Whose deposit is each link? The ownership table gives, for every repository linked in the text and (with references = TRUE) every deposit cited in the reference list, one of six labels: own_this (made by the authors for this paper), own_earlier_data or own_earlier_code (the authors’ own, from earlier work), others_data or others_code (made by other people, reused here), or not_data (a publication such as a preprint, not a deposit), with ownership_group (“own”, “others”, “not_data”) and the reason. It is decided without a language model, from the sentence or reference that cites the link, the paper’s authors (names, ORCID iDs, affiliations), and what the deposit’s own record and files say (who made it, what it names, when, whether it is a software package; for an OSF project cited only in the reference list, its record alone). On a round of labelled links the rules had not been written from, the three groups were right for 98% of links in the main text (93 of 95) and 90% in reference lists (74 of 82); the labels were made by Claude agents from each link’s evidence, and disputed ones checked against the deposits. Telling this paper’s own deposit from the authors’ earlier one is less certain.

Only the deposits that are this paper’s own are checked. A deposit linked in the text that holds other people’s work (others_data, others_code) or the authors’ earlier work (own_earlier_data, own_earlier_code) is listed in the report, with the reason, but its files are left out of table and kept in table_not_checked: they count toward nothing here (files that do not belong in a repository, naming, READMEs, studies, the traffic light), and code_check, data_check and reproducibility_check, which read table, do not check them either. reproducibility_check still puts the files of theirs that the paper’s code names in the folder the code runs in, as a re-analysis needs the data it re-analyses. When every linked deposit is set aside, the traffic light is “na”. A deposit that is the paper’s own is counted as such when its README, title or description names the paper (its title or DOI).

How Code Check works

This module retrieves information from repositories checked by repo_check about code files (R, Python, SAS, SPSS, Stata, Mplus, MATLAB).

The Code Check module checks R (also R Markdown and Quarto), Python (also Jupyter notebooks), SAS, SPSS, Stata, Mplus, and MATLAB files, using regular expressions to check the code; JASP files are listed but not read. The language of a Quarto document or a notebook is read from the file itself (its engine or kernel), not from its extension. The regular expression search will detect the number of comments, the lines at which libraries/imports are loaded, attempts to detect absolute paths to files, setwd() and install.packages() calls, and lists files that are loaded, and checks if these files are in the repository; R code is also parsed. The module will return suggestions to improve the code if there are no comments, if libraries/imports are loaded in lines further than 4 lines apart, if files that are loaded are not in the repository, if absolute file paths, setwd() or install.packages() are found, and if R code cannot be parsed.

The regular expressions can miss information in code files, or falsely detect parts of the code as a fixed file path. Libraries/imports might be loaded in one block, even if there are more than 3 intermittent lines. The module was tried out internally on papers published in Psychological Science, but has not been formally validated. There might be valid reasons why some loaded files can’t be shared, but the module can’t evaluate these reasons, and always gives a warning.

The module also checks whether the repository pins the R/package versions the analysis actually depended on: an renv.lock file (parsed for the R version and every locked package + its version/source), a sessionInfo()/sessioninfo::session_info() text dump (matched by filename — sessionInfo.txt/session_info.txt and similar, or embedded in a README), or a groundhog::groundhog.library()/checkpoint::checkpoint() date-pin call in the code (a bare library(groundhog)/library(checkpoint) does not count — the pinning call itself must be present). When none of these is found, the report flags it as a reproducibility gap: package versions may drift between when the analysis was run and any later reproduction attempt.

If you want to extend the package to perform additional checks on code files, or make the checks work on other types of code files, reach out to the Metacheck development team.

Checking code requires downloading its file contents. For a paper whose repository is on Dryad, this never succeeds unless a Dryad API key is set: Dryad requires one to download file bytes, even from a fully public dataset (listing the repository’s files does not need one). Without a key, every Dryad-hosted code file is listed but unchecked, and a warning naming Dryad and ?dryad_pat/?dryad_auth is included among the download failures recorded in the manifest.

How Data Check works

This module classifies the files in a repository into semantic types (data, codebook, code, software, output, supplemental, readme, asset, other) and, for tabular data files, extracts each column’s type and summary statistics.

The Data Check module consumes the file list produced by repo_check (or any files added via local_path). Each file is classified with rule-based heuristics layered over metacheck’s file_category() and file_types: file names matching README / codebook patterns win first, then an extension crosswalk, then format-locked extension overrides. For every file classified as tabular data that is available locally, the module reads the file head, describes each column with data_col_facets() and computes summary statistics for numeric columns. Every sheet of a spreadsheet that holds a table is read: a file with several such sheets has its columns under source_file = "file.xlsx [sheet]", and the sheet column names the sheet of any spreadsheet with several sheets; a sheet of notes or a codebook is treated as documentation when the file has another table. Following DDI, a column is described by orthogonal facets rather than a single type: representation (numeric/text/datetime/code — how it is stored), measurement_level (Stevens: nominal/ordinal/interval/ratio), concept (what it measures: reaction_time/age/gender/likert/id/…), role (identifier/measure/condition/timestamp), unit, and a quality state (ok/empty/constant). Concepts are detected by name+value rules (the demographic concepts via data_check_demographic()); when llm_use(TRUE) the model fills concepts and measurement levels the rules left blank. Qualtrics survey exports are recognised (data_check_is_qualtrics()): their extra header rows are stripped so columns type correctly, and the reserved response-metadata columns (StartDate, Duration, Finished, …) are tagged.

The module defaults to rules-only when llm_use(FALSE): columns the rules cannot resolve (ambiguous 3–20-unique integers, ambiguous character columns) fall back to continuous / text respectively. When llm_use(TRUE), ambiguous columns and unresolved file types (other) are sent to llm() for optional refinement, and every file is assigned a study group (ex1, pilot2, shared, …) so that multi-study repositories can be recognised (used by psychds_check). Without an LLM the study group is left NA (unknown).

Column extraction requires files to be readable from disk. Files fetched by repo_check from OSF/GitHub/etc. without a local copy (file_location is NA) are classified but not column-extracted; pass local_path to point at a downloaded copy of the repository.

For a paper whose repository is on Dryad, this means column extraction never happens unless a Dryad API key is set: Dryad requires one to download file bytes, even from a fully public dataset (dataset listing and metadata do not need one). Without a key, every Dryad file stays classified but un-downloaded, column_n is 0, and a warning naming Dryad and ?dryad_pat/?dryad_auth is included among the download failures. A one-time session message is also shown (see repo_check) the first time a Dryad dataset is encountered with no key set.

Every downloaded text file the authors wrote (code, settings, survey definitions such as Qualtrics .qsf files, documentation, outputs) is searched for keys: API keys, access tokens and private keys, which let anyone who downloads the file use a paid service at the authors’ cost. Of a tabular data file only the column names and first 3 rows of the table as read are searched: its values come from participants, but a key the authors set for a whole survey (as embedded data in a Qualtrics survey flow) is exported in every response. The search uses the rules of the secret scanner betterleaks (https://github.com/betterleaks/betterleaks, MIT licence) of high and medium confidence. A key found turns the traffic light red; the report and the keys table give its file, line and type, and only its beginning. Other files over 25 MB and binary files are not searched. A key is never tested with its provider. Every module’s result has any whole key replaced by “keyremoved” (see module_run()).

How Reproducibility Check works

This module assesses whether a paper’s R and Python code can be run on its data. It works in two phases. The static phase (always run) collects the package dependencies the code declares, rewrites the data-file paths that do not work in the repository as the authors organised it, works out the order the scripts must run in, and diagnoses why any referenced input file is unavailable — reporting what a reproduction attempt would involve and where it is likely to break. The execution phase (opt-in, execute = TRUE) then actually runs the code: it copies the repository into a throwaway directory, optionally installs the declared dependencies into a throwaway library, runs each script in order in an isolated subprocess with a per-script timeout, and captures the outcome and full output of each run.

Full text

Abstract

Children's ability to learn and form memories through direct experience and observation increases with age. However, the development of the underlying mechanisms, particularly prediction errors (PEs), through which both learning modes influence memory, remains unclear. Using an incidental memory paradigm, we compared children (8-10 years) and adults (18-30 years) in how reward PEs (RPEs) during experiential and observational reinforcement learning affect episodic memory. Although children showed weaker learning performance, both age groups remembered images better after experiential than after observational learning, and they did not differ in recognition accuracy. However, adults showed greater memory strength and remembered images better when they or another player gambled for rewards, especially when associated with positive RPEs. In contrast, children recognized images better when they rejected gambles, and exploratory analyses linked better memory to larger unsigned RPEs when they accepted gambles. These findings suggest age differences in how one's own and observed decisions, and potentially associated reward predictions, shape episodic memory.

Introduction

Observational learning plays a crucial role in cognitive and socio-emotional development (Bandura, 1977; Ishikawa & Itakura, 2024; Meltzoff, 2013; Waismeyer & Meltzoff, 2017) and is central to educational practice (Groenendijk et al., 2013). Nonetheless, even young children show better memory after active, self-guided (i.e., experiential) learning than after passive observation (Markant et al., 2016; Ruggeri et al., 2025). Developmental research has demonstrated that active control over the learning process (e.g., by controlling the order and pacing of information) enhances object recognition compared to observation in children aged six and older (Ruggeri et al., 2019). Similar benefits of active learning have been reported for category learning (Sim et al., 2015), learning novel object-word associations (Partridge et al., 2015), and spatial memory (McComas et al., 1997).

The ability to learn and form memories through direct experience and observation continues to improve during middle childhood and adolescence (Ghetti & Bunge, 2012; Ofen, 2012; Westhoff et al., 2021; Xia et al., 2021). These improvements are associated with more efficient use of learning strategies, better monitoring and control of memory (Ghetti & Bunge, 2012), and with memories becoming richer in detail (Ofen, 2012). Compared with adults, older children still learn more slowly and less efficiently from both direct experience and observation (Hämmerer et al., 2011; Rodriguez Buritica et al., 2018 , 2024) and show lower memory performance across learning contexts (Cycowicz et al., 2001; DeMaster et al., 2014; Ghetti & Bunge, 2012; Mecklinger et al., 2011).

Moreover, although children are more sensitive to external feedback than adults, they struggle to extract task-relevant information from it (Eppinger et al., 2009; Hämmerer et al., 2011; Hämmerer & Eppinger, 2012; van den Bos et al., 2012). Learning from feedback requires individuals to evaluate outcomes and to update behavior accordingly. This process is realized by prediction errors (PEs), defined as the difference between expected and received outcomes (Rescorla & Wagner, 1972; Sutton & Barto, 1998). PEs signal whether outcomes are better or worse than expected and are thought to be coded by midbrain dopamine neurons (Schultz, 2024; Schultz et al., 1997), which interact with a distributed network throughout the brain, including the striatum, anterior cingulate cortex, dorsolateral prefrontal cortex, and orbitofrontal cortex (Balleine et al., 2007; Behrens et al., 2007; Joiner et al., 2017; Schultz & Dickinson, 2000). As these regions undergo maturational changes during childhood and adolescence (Christakou et al., 2011; Crone et al., 2008), age differences in PE signaling are expected. However, empirical findings on PE signaling across development are mixed. While some studies reported heightened neural PE signals in adolescents (Cohen et al., 2010; Davidow et al., 2016; Galvan et al., 2006), others found comparable PE-related neural activity across age groups (Rodriguez Buritica et al., 2024; van den Bos et al., 2012). Nonetheless, computational research suggests that PEs drive both experiential and observational learning in adults and children (Burke et al., 2010; Joiner et al., 2017; Olsson et al., 2020; Rodriguez Buritica et al., 2024).

In adults, PEs during experiential learning have been shown to affect memory formation (Ergo et al., 2020; Pupillo & Bruckner, 2023), with most studies reporting encoding benefits of positive PEs (Calderon et al., 2021; De Loof et al., 2018; Jang et al., 2019; Rouhani et al., 2018; Rouhani & Niv, 2021). Our previous work further suggests that both experienced and vicarious positive PEs enhance memory strength (Woitow et al., 2026). In contrast, few studies have investigated mnemonic effects of PEs across development, and findings are mixed, including positive effects of PEs (Breitwieser & Brod, 2021; Davidow et al., 2016), a Ushaped relation (Brod et al., 2022; Ortiz-Tudela et al., 2024), and no effects of PEs (Nolden et al., 2025). Although PEs often appear to enhance memory from late childhood onward, it remains unclear whether this benefit is comparable to that observed in adults (for a review, see Shing et al., 2023), and whether it generalizes to observational learning. Moreover, recent computational research in adults showed that positive experienced and vicarious PEs elicited at the reward-predictive cue enhanced encoding, whereas outcome-related PEs did not (Jang et al., 2019; Woitow et al., 2026). As prior developmental work has focused on outcome-related PEs, it is unknown whether PEs at the reward-predictive cue play a comparable role in memory formation in children.

Taken together, the processes underlying the integration of information learned through experience and observation into episodic memories in middle childhood remain unclear. To address this gap, the present study investigated how experiential and observational learning shape recognition memory in children aged 8-10 years compared with adults, focusing on the role of experienced and vicarious PEs. We employed an incidental memory paradigm (Woitow et al., 2026) consisting of a learning task with interleaved experiential and observational trials, followed by an unexpected memory test for images shown in each learning condition (Figure 1a-b). In the learning task, participants learned reward probabilities for two image categories from trial-to-trial feedback. On each trial, they either accepted or rejected the opportunity to gamble (experiential learning) or observed such a choice made by another player (observational learning). To capture developmental differences, we compared data from the present study with those of our previous study, which used the same paradigm in young adults (18-30 years; Woitow et al., 2026).

We expected higher recognition accuracy following experiential learning (Ruggeri et al., 2019) and overall lower accuracy in children than in adults. We further predicted age differences in choice behavior during learning, with better performance in adults (Rodriguez Buritica et al., 2018 , 2024; Topel et al., 2023). Finally, to link learning and memory, we computed reward PEs (RPEs) during image and feedback presentation and analyzed their effects on memory. In line with prior research, we expected children to learn from experienced and vicarious RPEs (Rodriguez Buritica et al., 2024). Because brain regions involved in RPE coding and memory formation are still maturing (e.g., Crone et al., 2008; Ghetti & Bunge, 2012), we expected age differences in the effects of experienced and vicarious RPEs on memory formation. However, given the mixed findings on the mnemonic effects of PEs in childhood (e.g., Nolden et al., 2025; Shing et al., 2023) and the lack of research on vicarious RPEs, we made no specific predictions regarding these differences.

Methods

Participants

We collected data from 86 children (46 girls) aged 8-10 years. Children of this age still differ considerably from adults in how they use RPE signals during learning (e.g., van den Bos et al., 2012; van Duijvenvoorde et al., 2008), likely reflecting ongoing maturation of cortical and subcortical brain regions involved in RPE signaling and learning (Casey et al., 2005; Crone et al., 2008; Gogtay et al., 2004). Further, testing 8-to 10year-olds allowed us to use the same experimental design as in our previous study in adults (Woitow et al., 2026), while focusing on RPE processing before the changes in reward learning (Rosenbaum et al., 2022) and in mnemonic effects of RPEs (Davidow et al., 2016) that characterize adolescence.

The sample size was determined by the adult study (n = 86; 18-30 years) to allow for direct comparisons of results (Woitow et al., 2026). In the adult sample, seven participants were excluded (for details, see Woitow et al., 2026), resulting in a final sample of 79 adults (52 women; M = 23.80 years, SD = 4.12). This sample consisted mostly of university students and was collected in Berlin, Germany. In the child sample, six participants were excluded due to an excessive number of missing responses in the learning and memory tasks (> 3 SDs above the group mean). Following our adult study, we further assessed whether each participant's learning task performance exceeded chance level by simulating random choices using the same learning task structure and calculating the total score achieved. This procedure was repeated 5,000 times. All participants' scores were greater than 5% of the simulated score distribution. Thus, the final sample consisted of 80 children (43 girls; M = 9.14 years, SD = 0.67), who were native German speakers recruited from urban and suburban populations in Greifswald, Germany, via the local population register (Melderegister MV) and local schools.

The adult study was approved by the Ethics Committee of the Institute of Psychology at Humboldt-Universität zu Berlin (2022-65) and the child study by the Ethics Committee of the Institute of Psychology at the University of Greifswald (BB 166/23). All participants had normal or corrected-to-normal vision, and children had no history of developmental disorders. Written informed consent was obtained from adult participants and from children's parents, and children gave their assent before participation. All participants completed the same experimental conditions in one session lasting approximately 70-80 minutes and were compensated with €10 per hour plus a bonus (€2 for adults, small gift for children).

The study design, hypotheses, and planned analyses were preregistered (AsPredicted; #178674, https://aspredicted.org/qhs5-84qp.pdf). All deviations from the preregistered analyses are noted in the Methods and Results sections. Experimental procedure

The experiment consisted of a learning task followed by a memory test (Figure 1a-b). After a short practice round, participants performed the learning task, in which they learned from their own choices and those of another player. They were told that the observed choices were the recorded behavior of a previous participant who had completed the same task. In fact, these choices were computer-generated, using the same reinforcement learning model as in the adult study, to ensure comparability across participants (Woitow et al., 2026; for details, see Supporting Information: Simulation of observed choice behavior). This deception was resolved at the end of the experiment. Following the learning task, participants completed a surprise recognition memory test for images encountered during learning. In both tasks, participants were instructed to collect as many points as possible and were told that the bonus depended on their performance. In fact, all participants received the bonus. Learning task

The learning task comprised 160 interleaved experiential (EL) and observational (OL) learning trials (80 trials per condition, with no more than two consecutive trials of the same condition). On each trial, participants accepted or rejected the opportunity to gamble for a probabilistic reward (EL) or observed such a choice made by another player (OL). To maximize points, participants had to learn the changing reward probabilities and adjust their choices accordingly.

Each trial consisted of a player, value, image, and feedback phase, separated by 0.5-s blank screens (Figure 1a). First, the current player was cued ("You" for EL, "Other" for OL), followed by the trial value (i.e., reward magnitude; sampled equally from 1, 5, 10, 20, and 100). Then, a unique image belonging to one of two possible categories -animate (animals) or inanimate (objects) -was shown with the options "Play" and "Pass" for 3 s. Trial values and images were presented in pseudorandomized order, with animate and inanimate images occurring equally often in each learning condition and with each trial value. The two image categories were associated with oppositely linked reward probabilities (e.g., 80% vs. 20%).

To accept or reject the gamble, participants chose "Play" or "Pass" within the 3-s window by pressing the left or right arrow key (positions randomized across participants). To ensure attention, participants had to press the spacebar in OL trials to see the other player's choice. Selected options were highlighted in black. If no response was given, "Too slow" appeared, and the next trial started.

After the image phase, the feedback was shown for 1.5 s. The current player was rewarded according to the trial's assigned reward probability. Reward probabilities could change throughout the task to a random value between 0 and 1 with a likelihood of 0.16, while always remaining oppositely linked. To enable learning, no changes occurred during the first 20 trials of the task or within 15 trials following a change (across EL and OL trials). If the current player chose "Play" and the trial was rewarding, they received the points shown in the value phase. If the trial was not rewarding, they always lost 10 points. After passing, no points were won or lost, but the hypothetical outcome (i.e., the outcome for a play choice) was shown in brackets. Notably, choices and feedback in OL trials did not affect the participant's score. Finally, the current player's cumulative score was shown for 1 s.

Task instructions were read aloud to children, with examples of each trial phase and possible outcome (for the original German instructions, see Supporting Information: Task instructions). Participants were introduced to the two image categories and shown example images for each. An example task structure illustrated how the reward probabilities of the two image categories were related and how they changed across the task. Additionally, participants were advised to attend to trial values and images throughout the task. After the practice round, the rules of the learning task were summarized again.

Memory task

In the memory task (Figure 1b), participants viewed all 160 images from the learning task intermixed with 160 matching new images (lures) in pseudorandomized order. New images were different exemplars of the same animals or objects presented during learning. On each trial, one image was shown, and participants indicated whether it was old or new by pressing the left or right arrow key (positions randomized across participants). Participants received no feedback on response accuracy but were informed that 5 points would be added to their score for each correct response and 5 points subtracted for each incorrect response. Following the old/new choice, participants rated their choice confidence on a scale from 1 (guess) to 4 (completely certain) by pressing the corresponding number key. They had 5 s for each response type. If no response was given, a prompt indicating that they were too slow was shown, and the next trial started immediately.

Debriefing questionnaire

At the end of the experiment, participants completed a questionnaire (Supporting Information: Debriefing questionnaire). Questionnaire items were read aloud to children. On 5-point Likert scales, participants rated their understanding of the learning task rules, their own and the other player's learning performance, the extent to which they followed the observed choices and benefited from them, and how they felt when the other player received rewards or punishments.

Behavioral data analysis

Reward probabilities in all analyses refer to the expected reward probabilities estimated by the Bayesian ideal observer model (for details, see Supporting Information: Bayesian ideal observer model). For all mixed-effects models (lme4 package, R; Bates et al., 2015), fixed effects were hypothesis-driven, and the random-effects structure was determined by model comparison (lowest BIC; for details, see Supporting Information: Model selection). The predictors age group (adults, children), learning condition (EL, OL), choice (play, pass), confidence bin (low, high), and learning stage were treated as factors, while all other predictors were z-scored.

Finally, we assessed whether participants made more correct choices following observational trials. For each participant, we calculated the proportion of correct choices in these trials and compared it against chance (0.5) in each age group using a one-tailed one-sample t-test, and between age groups using a twosample t-test.

Memory performance

Memory accuracy

Memory accuracy was defined as the ability to discriminate old from new images. We computed the discrimination index d′ (z(hit rate)z(false-alarm rate)) for each participant and learning condition. Because old and new images were matching pairs showing the same kind of animal or object, false alarms were assigned to the learning condition of the matching old image. Some children had false-alarm rates of 0 in some conditions, which would result in infinite d′ values. Thus, hit and false-alarm rates were adjusted for all participants using the log-linear correction (Hautus, 1995). One-sample t-tests against 0 tested whether accuracy exceeded chance in each learning condition and age group.

Memory strength

Next, we combined the old/new judgment and the confidence rating (1-4) per trial into a memory score ranging from 1 ("new" with highest confidence) to 8 ("old" with highest confidence). To evaluate whether this score reflects memory strength, we examined its relation to the true proportion of old images. Debriefing questionnaire

Participants' responses in the debriefing questionnaire were analyzed using nonparametric tests. Both age groups reported overall good to very good rule understanding, although ratings were higher in adults (Figure S2). To assess the credibility of our social manipulation, we examined participants' perception of the other player. Most adults (75%) reported having benefited from observing the other player (ratings of 4 or 5), compared with fewer than half of the children (38%). Moreover, adults rated their own choice performance similarly to that of the other player (p = 0.21, paired Wilcoxon signed-rank test), whereas children rated the other player's performance higher than their own (p < 0.001).

Reward prediction errors and memory

To examine the effects of image and feedback RPEs on memory strength, we fitted linear regressions to memory scores and RPEs for each participant and condition. Consistent with our previous study (Woitow et al., 2026), analyses focused on RPE valence. RPEs were thus split by sign (RPE < 0, RPE > 0) before regressing the mean-centered memory scores on the mean RPE of each bin. Results

Experiential learning

We assessed participants' learning performance by analyzing their play/pass choices. Across age groups, the probability of accepting gambles (play choice) increased with trial value (Figure 2a; β = 0.79, z = 11.80, p < 0.001) and reward probability (P(rew); Figure 2b; β = 1.15, z = 19.51, p < 0.001; Table S1). Both effects were stronger in adults than in children (age group × trial value: β = 0.38, z = 5.81, p < 0.001; age group × P(rew): β = 0.38, z = 6.47, p < 0.001), driven by group differences at lower reward probabilities (P(rew) ≤ 0.5; ps < 0.001) and smaller trial values (trial value ≤ 10; ps ≤ 0.004; Table S2). Additionally, we found an age group × trial value × reward probability interaction (β = 0.08, z = 2.54, p = 0.011). Follow-up analyses showed that the effect of trial value increased with reward probability in adults (β = 0.23, z = 4.17, p < 0.001; Table S3) but not in children (p = 0.83; Table S4), suggesting that adults integrated value and probability information more strongly. Finally, adults played less often than children (β = -0.13, z = -2.98, p = 0.003). That is, they played in about 50% of the trials (mean play/pass ratio = 1.08) compared with 60% in children (mean ratio = 1.58). These results suggest that both age groups used reward information to guide their play/pass choices, but children did so to a lesser extent, as their choices depended less on this information when reward values and probabilities were low. Consistent with this, children achieved lower learning task scores (M = 575, SD = 212) than adults (M = 704, SD = 223; M diff = 129, 95% CI [61, 197], 𝑡157 = 3.73, p < 0.001, d = 0.59).

Moreover, we assessed reward probability learning by examining correct choices (i.e., playing for the more frequently rewarded and passing for the less frequently rewarded image category) in the first eight EL trials of each learning stage. The probability of a correct choice increased across trials (β = 0.22, z = 7.85, p < 0.001), was higher in adults than in children (β = 0.17, z = 4.18, p < 0.001), and increased more steeply in adults (age group × trial: β = 0.12, z = 4.40, p < 0.001; Figure 2c). This age difference varied with learning stage (age group × trial × learning stage: β = -0.07, z = -2.54, p = 0.011; Table S5), due to a flattening of the increase in correct choices in later learning stages in adults but not in children (trial × learning stage: adults: β = -0.10, z = -2.54, p = 0.011; children: p = 0.32; Tables S6-S7). In sum, these findings indicate poorer reward probability learning and less optimal choice behavior in 8-to 10-year-olds than in young adults.

Observational learning

Next, we explored the influence of the other player's choices on participants' decisions. We found that both age groups more often made correct choices after an OL trial (adults: M = 0.68, SD = 0.09, 95% CI [0.66, ∞], 𝑡78 = 17.56, p < 0.001, d = 1.98; children: M = 0.61, SD = 0.12, 95% CI [0.59, ∞], 𝑡79 = 8.72, p < 0.001, d = 0.98). Nonetheless, the proportion of correct choices was higher in adults (M diff = 0.07, 95% CI [0.04, 0.10], 𝑡157 = 4.17, p < 0.001, d = 0.66), suggesting that adults integrated vicarious feedback more effectively than children.

Memory accuracy

Memory performance was first assessed by analyzing participants' accuracy in discriminating old from new images (d′). Because lures were different exemplars of the same animals or objects as the old images, and false alarms were assigned to the condition and choice of the matching old image, d′ reflects how well participants distinguished studied images in each condition from their similar lures.

Memory accuracy was above chance in each learning condition and age group (adults: ts ≥ 23.55, ps < 0.001; children: ts ≥ 16.86, ps < 0.001; Figure S3). Interestingly, children and adults did not differ in accuracy (β = -0.01, 𝑡157 = -0.39, p = 0.70; Figure 3a-b; Table S8), which was moderately supported by a Bayesian analysis (B01 = 3.36) and reflected in comparable final memory test scores (adults: M = 588, SD = 181; children: M = 538, SD = 279; M diff = 50, 95% CI [-24, 124], 𝑡157 = 1.34, p = 0.18, d = 0.21). Age invariance in accuracy resulted from higher hit and false-alarm rates in adults (hits: β = 0.03, 𝑡157 = 3.30, p = 0.001; false alarms: β = 0.02, 𝑡157 = 2.20, p = 0.03), consistent with a more conservative response bias in children (Figure S4; Tables S9-S10). Memory accuracy was higher in EL than in OL trials (β = 0.03, 𝑡471 = 2.18, p = 0.03), with no evidence for an age difference (age group × learning condition: β = -0.002, 𝑡471 = -0.17, p = 0.87), suggesting a comparable benefit of experiential learning in adults and children. The effect of play/pass choice differed between age groups (β = 0.03, 𝑡471 = 2.49, p = 0.013), depending on the learning condition (age group × learning condition × choice: β = 0.03, 𝑡471 = 2.07, p = 0.04). Follow-up analyses revealed overall greater accuracy in play than in pass trials in adults (choice: β = 0.04, 𝑡234 = 2.28, p = 0.024; Figure 3a; Table S11).

In contrast, children showed a learning condition × choice interaction (β = -0.05, 𝑡237 = -2.41, p = 0.017; Figure 3b; Table S12), due to higher accuracy for pass than for play trials in the EL condition (estimate = 0.15, 𝑡237 = 2.61, p = 0.01) but not in the OL condition (estimate = -0.04, 𝑡237 = -0.79, p = 0.43). In sum, the influence of choice behavior on memory encoding differed between age groups and learning conditions. An exploratory analysis showed similar results when d′ was based on overall false-alarm rates (Figure S5; Table S13). Further, image category did not interact with age group, learning condition, or choice but attenuated the EL benefit (p = 0.18; Table S34), likely because additionally splitting trials by image category reduced the reliability of the d′ estimates.

In addition, we explored whether the play/pass pattern in EL trials in adults and children was related to differences in play/pass ratios. However, we found no evidence that memory accuracy for play and pass trials depended on the frequency of play and pass choices (p = 0.61; Table S14).

In the next step, we tested whether participants' confidence ratings reflected memory accuracy. We found higher accuracy for high-than for low-confidence judgments (β = 0.37, 𝑡146 = 17.08, p < 0.001), which did not differ between age groups (confidence bin × age group: p = 0.57; Table S15), indicating that subjective confidence ratings reflected memory accuracy in adults and children.

Memory strength

We then combined old/new choices and confidence ratings per trial into a single memory score ranging from 1 ("new", highest confidence) to 8 ("old", highest confidence). Memory scores predicted the proportion of old images in both age groups (Figure 3c; β = 0.20, 𝑡157 = 35.11, p < 0.001), supporting their validity as a measure of memory strength. However, this relationship was stronger in adults (age group × memory score: β = 0.03, 𝑡157 = 4.47, p < 0.001; Table S16), suggesting that adults' confidence tracked their memory more accurately. In line with this, adults showed greater memory strength than children (Figure 3d-e; β = 0.20, 𝑡157 = 3.37, p < 0.001; Table S17).

Memory strength was greater in EL than in OL trials across age groups (β = 0.11, 𝑡471 = 6.50, p < 0.001), with no evidence for age differences (age group × learning condition: p = 0.66). Moreover, we found an age group × choice interaction (β = 0.04, 𝑡471 = 2.29, p = 0.02), driven by greater memory strength for play than for pass trials in adults (estimate = 0.14, 𝑡471 = 2.83, p = 0.005; Figure 3d), but no overall play/pass effect in children (estimate = -0.02, 𝑡471 = -0.41, p = 0.68; Figure 3e). Note that when image category was included, the EL benefit remained significant, but the age group × choice interaction was attenuated (p = 0.08; Table S37), possibly because the play advantage in adults' memory strength partly reflected an animacy effect.

Reward prediction errors and memory

Next, we examined whether a key reinforcement learning signal, the reward prediction error (RPE), influenced episodic memory, and whether this relationship differed between learning conditions and age groups.

Image RPE

The image RPE reflects the difference between the reward prediction after and before image presentation. Slopes relating image RPE valence to memory strength did not differ from zero in any condition or age group (adults: ps ≥ 0.19; children: ps ≥ 0.58; Figure 4a-d; Table S18). There was no effect of age group on these slopes (p = 0.99), and age group did not interact with learning condition or choice (ps ≥ 0.28; Table S19). Thus, signed experienced and vicarious image RPEs were not related to memory strength in either adults or children. Following the exploratory analysis in our previous study (Woitow et al., 2026), we then examined memory strength separately for trials with positive and negative image RPEs. In adults, memory for play trials with positive image RPEs was above participants' average in both learning conditions (EL: M = 0.11, SD = 0.36, 95% CI [0.03, 0.19], 𝑡78 = 2.66, p = 0.009, d = 0.30; OL: M = 0.09, SD = 0.33, 95% CI [0.01, 0.16], 𝑡78 = 2.37, p = 0.02, d = 0.27; α corrected = 0.025), whereas children showed no such effect (ps ≥ 0.52; Table S20). Thus, positive image RPEs in play trials were associated with better memory in adults but not in children, although the effect did not differ significantly between age groups.

Building on prior work linking larger unsigned PEs to better memory in children (Breitwieser & Brod, 2021; Brod et al., 2022), we explored unsigned image RPEs in children. We found greater memory strength in EL play trials with larger than with smaller unsigned image RPEs (M = 0.02, SD = 0.07, 95% CI [0.005, 0.04], 𝑡79 = 2.58, p = 0.012, d = 0.29; α corrected = 0.0125), but not in OL or pass trials (ps ≥ 0.08; Table S21), suggesting that, when children gambled, more surprising reward cues may have benefited encoding more than less surprising ones. This association was stronger in children whose choices were more sensitive to reward probabilities (Spearman's ρ = 0.24, p = 0.03).

Feedback RPE

Moreover, mnemonic effects of signed RPEs elicited by the reward outcome were assessed. Neither actual feedback RPEs in play trials nor, in exploratory analyses, fictive feedback RPEs in pass trials were related to memory strength in either age group or learning condition (play: ps ≥ 0.054; pass: ps ≥ 0.20; α corrected = 0.0125; Figure S6; Table S22). These slopes did not differ between age groups or learning conditions (ps ≥ 0.44), but they were more positive for actual than fictive feedback RPEs (β = 0.004, 𝑡471 = 3.09, p = 0.002), driven by a negative slope for fictive feedback RPEs across age groups and learning conditions (𝑡423 = -2.60, p = 0.01, d = -0.15; α corrected = 0.025), whereas actual feedback RPEs were unrelated to memory (p = 0.13; Table S23). Thus, signed feedback RPEs in play trials did not affect memory, whereas positive fictive feedback RPEs (i.e., missed wins) might have reduced memory strength. Finally, exploratory analyses of unsigned feedback RPEs showed no reliable effects (play: ps ≥ 0.02; pass: ps ≥ 0.25; α corrected = 0.0125; Table S24), and no differences between age groups, learning conditions, or choices (ps ≥ 0.11; Table S25), suggesting that the magnitude of actual and fictive feedback RPEs did not affect memory.

Discussion

The present study used an incidental memory paradigm to examine developmental differences between 8-to 10-year-old children and young adults in how reward prediction errors (RPEs) during experiential and observational reinforcement learning affect episodic memory. Although children's choices were less optimal than adults', both age groups used reward information to guide their choices and benefited from observing another player. Across age groups, memory accuracy and strength were higher after experiential than after observational learning. Memory accuracy was comparable between age groups, whereas adults showed greater memory strength. Additionally, choice effects on memory differed between age groups. Finally, in adults, positive image RPEs in experienced and observed play trials were associated with enhanced memory strength. In children, larger unsigned image RPEs in experienced play trials were linked to better memory.

Learning performance

Adults' and children's play/pass choices indicated that they attended to reward information and used it to guide gambling behavior. However, children played more often than adults on trials with low reward values and probabilities, resulting in lower learning task scores. This suggests that children had difficulties forming accurate representations of task-appropriate behavior (Eppinger et al., 2009) and supports prior research showing that primary school children partially neglect reward probabilities when making decisions (Lang & Betsch, 2018). Accordingly, children's proportion of correct choices increased less over the course of learning, consistent with evidence for less efficient probabilistic reinforcement learning in children (Topel et al., 2023; Westhoff et al., 2021; Xia et al., 2021).

Notably, reward probabilities in our study changed repeatedly. Although exploratory analyses indicated that children, like adults, detected these changes and adjusted their choices accordingly (Table S26), they made fewer correct choices overall. This aligns with studies showing lower choice accuracy in children than in adults when reward probabilities are non-stationary (for a review, see Topel et al., 2023). Both age groups also adjusted their choices to recent outcomes, but children did so less (Table S27), mainly because they used hypothetical losses less (Figure S7; Table S28), consistent with evidence that counterfactual outcome integration continues to develop into adolescence (Palminteri et al., 2016).

Children's weaker use of hypothetical losses may have contributed to their more frequent play choices and lower learning task scores. Moreover, although both age groups benefited from observing the other player's feedback, adults made more correct choices after observational trials, consistent with evidence for developmental differences in using vicarious information for learning (Rodriguez Buritica et al., 2018 , 2024).

Memory performance

Despite these age differences in learning performance, recognition accuracy did not differ between age groups. This contradicts our hypothesis and prior research showing better picture recognition in adults (Cycowicz et al., 2001; Czernochowski et al., 2005; Friedman et al., 2010; Sprondel et al., 2011). However, the findings match other studies reporting age-invariant recognition accuracy in young adults and children aged 8 and older (Billingsley et al., 2002; Brainerd et al., 2004; Ofen et al., 2007). Notably, because these studies vary in experimental design (e.g., explicit instructions to memorize items or repeated memory item presentation), comparisons should be made with caution. Overall, our findings provide evidence that young adults and 8-to 10-year-olds are similarly accurate in recognizing incidentally encoded images from experiential and observational learning and in discriminating them from similar lures. Given that adults often show better recognition, this finding may reflect a tendency in adults to miss details (e.g., image features) due to greater selective attention to task-relevant information (e.g., image category) relative to children (Blanco et al., 2023; Tandoc et al., 2024).

Taking subjective confidence into account, however, revealed greater memory strength in adults than in children, consistent with prior work (Friedman et al., 2010; Ghetti & Angelini, 2008; Ghetti & Bunge, 2012). That age differences emerged in memory strength but not in memory accuracy may reflect distinct developmental trajectories of the two processes of recognition memory: familiarity and recollection (for a review, see Ghetti & Angelini, 2008). Familiarity (recognizing an event without retrieving details) is thought to reach adult levels by about 8 years of age, whereas recollection (retrieving qualitative details of the study episode) continues to develop into young adulthood (Billingsley et al., 2002; Brainerd et al., 2004; Ghetti & Angelini, 2008). Although d′ has been linked to familiarity (Yonelinas et al., 2024) and highconfidence recognition to recollection (Yonelinas & Parks, 2007), high confidence can also reflect strong familiarity (Migo et al., 2012). Hence, our paradigm cannot clearly dissociate recollection-and familiaritybased contributions to memory strength.

In middle childhood, the ability to monitor and control one's own memory, that is, metamemory (Dunlosky & Thiede, 2013; Nelson, 1990), is present but still developing (Ghetti et al., 2008 (Ghetti et al., , 2011)).

Accordingly, children's confidence judgments reflect their memory accuracy more closely with increasing age (Ghetti et al., 2010 (Ghetti et al., , 2011;; Ghetti & Angelini, 2008; Roebers et al., 2009), which is associated with improvements in executive functions and metacognition (Roebers, 2017). Consistent with this, higher confidence was associated with higher memory accuracy in both age groups, but memory scores tracked the true proportion of old images more closely in adults, suggesting more accurate metacognitive monitoring. Taken together, our findings suggest that although 8-to 10-year-old children and young adults show comparable recognition accuracy, adults are better able to monitor their own memory.

Learning and memory

As predicted, recognition memory was better after experiential than after observational learning in both age groups, as reflected in memory accuracy and in memory strength. Given that confidence ratings in both age groups reflected recognition accuracy, these results suggest that one's own experiences facilitate encoding of image or context details, thereby enhancing memory accuracy and strength in children and adults. This aligns with the assumption that active, self-directed learning leads to richer representations of study details than passive observation (Markant et al., 2016). Research in adults further showed that simply choosing between two options enhances memory (Ding et al., 2021; Murty et al., 2015). Accordingly, making play/pass choices may have contributed to mnemonic benefits of experiential learning in both age groups. Overall, these findings support evidence from adult and developmental studies reporting better memory following active, compared with observational, learning (Gureckis & Markant, 2012; Markant et al., 2016; Ruggeri et al., 2019 Ruggeri et al., , 2025)).

Interestingly, play/pass choices affected memory differently in adults and children. In adults, both experienced and observed gambling enhanced memory accuracy and strength compared to passing. Given that rewards were probabilistic, this suggests that risk and outcome uncertainty associated with gambling for rewards benefited encoding (Jang et al., 2019; Rouhani et al., 2018; Stanek et al., 2019). The comparable effect across learning conditions indicates that adults encoded experienced and observed choices similarly (Woitow et al., 2026), in line with the assumption of similar neural activation during the generation, imagination, and observation of actions (Decety & Grèzes, 2006).

In children, choice effects differed between learning conditions. Observed choices did not affect memory accuracy, but in the experiential condition, accuracy was higher for pass than for play trials, suggesting that children encoded their own choices differently from adults. One explanation could be that because children played more often than they passed, the fewer pass trials were more salient. However, we found no evidence that the play/pass difference in accuracy depended on participants' play/pass ratios. Alternatively, children might have deliberated longer when passing and thus attended to the image longer, as suggested by their slower responses in pass trials (Table S29). However, within participants, slower responses were associated with fewer hits in both age groups (Table S30), arguing against this account. Another possibility is that, when children played, anticipating the upcoming outcome and reward uncertainty drew attention away from the image. Future studies could disentangle these effects by using eye tracking and physiological measures to track attention and arousal during decision-making.

In sum, our results are consistent with evidence that different cognitive processes, such as decisionmaking, probabilistic reinforcement learning, and recognition memory, follow distinct developmental trajectories. While familiarity-based recognition appears to be adult-like by the age of 8 (for a review, see Ghetti & Angelini, 2008), the ability to adjust decision-making based on reward cues and feedback in nonstationary, probabilistic environments improves into adolescence (Christakou et al., 2013; Topel et al., 2023; Xia et al., 2021). Future studies spanning a broader developmental range will be needed to delineate the timelines of these partially dissociable processes.

Prediction errors and memory

To further examine how experiential and observational learning shape episodic memory, we assessed the role of experienced and vicarious RPEs at the reward-predictive cue (image RPE) and the reward outcome (feedback RPE). In adults, positive image RPEs in play trials were associated with enhanced memory strength in both learning conditions, suggesting a similar role of experienced and vicarious RPEs in memory encoding (Woitow et al., 2026). In children, we found no evidence for this effect in either learning condition. Although this may suggest developmental differences in the role of signed RPEs, the effect did not differ significantly between age groups, so this conclusion remains tentative.

The absence of an effect in children may also reflect their still-developing ability to form accurate reward predictions. In our task, predicting rewards required combining the probability and magnitude of potential rewards and losses. Children's choices depended on both trial value and reward probability, but unlike adults, they showed no evidence of combining the two. If children weighted these components differently than our model assumed, image RPEs may not fully capture RPE signaling in 8-to 10-year-olds. However, exploratory analyses showed that children's play choices were sensitive to both the predicted reward value and the image RPE, although less strongly than adults' choices (Tables S31-S32). Thus, despite their difficulties in forming accurate reward predictions, children's choices tracked trial-by-trial changes in these predictions.

Exploratory analyses further showed that, in children, larger unsigned image RPEs were associated with greater memory strength in experienced play trials, particularly in children whose choices were more sensitive to reward probabilities. Thus, when children gambled for rewards, larger deviations from their reward predictions may have benefited encoding more than smaller deviations. Future research should replicate this finding and test, for example with pupillometry, whether responses to prediction violations scale with RPE magnitude and predict subsequent memory (Breitwieser & Brod, 2021; Brod et al., 2022).

Finally, we found no reliable evidence that signed or unsigned feedback RPEs in play or pass trials influenced memory in either age group or learning condition, although, across age groups and learning conditions, memory was worse for images followed by missed wins than by avoided losses. This may reflect post-encoding interference due to attention to and processing of hypothetical wins and may further suggest similar processing of one's own and others' outcomes in both age groups. Overall, these findings suggest that feedback RPEs may not enhance encoding when they do not coincide with the presentation of memory items (Jang et al., 2019; Rouhani & Niv, 2021; Woitow et al., 2026).

A limitation of the present study is the lack of behavioral measures in the observational learning condition to assess vicarious reward predictions. Future studies could address this by including catch trials requiring participants to predict the other player's choices or outcomes, which would also verify attention to reward information during observational trials. Notably, we used the same paradigm in adults and children to ensure comparability. Considering that children made less accurate reward predictions, future studies could reduce the number of different reward values and use more distinct reward probabilities, which might facilitate the formation of accurate reward predictions and hence RPE effects.

Conclusions

In summary, the present study reveals developmental differences in how experiential and observational reinforcement learning shape episodic memory. Adults chose more optimally during learning than children. Moreover, adults' memory accuracy was higher for accepted gambles (own and observed), whereas children's was higher when they rejected them. In adults, positive image RPEs during experienced and observed gambling were associated with better memory. In children, exploratory analyses linked better memory to larger unsigned image RPEs during experienced gambling. Given that feedback RPEs did not enhance memory in either age group, RPEs may enhance encoding only when temporally aligned with item presentation. Together, our findings suggest that children can learn from their own and others' experiences in changing environments and adjust their behavior accordingly, although their less accurate reward predictions may affect how the resulting prediction errors shape their memory.

Model selection

The fixed effects in all reported linear mixed-effects models (lme4 package, R; Bates et al., 2015) were hypothesis-driven. The random-effects structure for each model was determined by model comparison. Starting from the maximal model, containing a by-subject random slope for each within-subject fixed effect (Barr et al., 2013), we reduced the random slopes step by step to the simplest model, containing a bysubject random intercept (Matuschek et al., 2017). We then selected the model with the lowest Bayesian information criterion (BIC). If two models did not differ substantially (ΔBIC < 2; Kass & Raftery, 1995), we selected the simpler one.

Simulation of observed choice behavior

To simulate realistic, human-like choice behavior for the observational learning (OL) condition, we fitted two RL models -our base model and an extended model -directly to the choice behavior from 30 young adults (18-30 years) who participated in the pilot phase of our adult study. In the pilot, participants completed a learning task containing only 80 experiential learning trials. The base model contained four free parameters: (1) a temperature parameter (inverse T) of the softmax function, (2) a value exponent term that scales the effect of trial value on choice behavior, (3) a play bias term reflecting the attribution of higher value to play decisions, and (4) an intercept term that scales the effect of learning rate on choice behavior. The extended model contained the same free parameters as our base model and included two additional ones, surprise and uncertainty, which contributed to the trial-to-trial modulation of the learning rate. Next, we assessed model fits by computing the Bayesian information criterion (BIC) for each model and then comparing them. Since BIC values indicated that both models performed similarly well, we chose the simpler model (base model) to generate the choices for the OL condition. For this, we used the model-derived expected trial value (𝑉 𝐵 (𝑡)) and the temperature parameter estimates as inputs to the softmax function to generate a choice for each trial.

We used the base RL model derived from the pilot sample for the adult study to simulate choice behavior for the OL condition in the child study. This approach ensured that the observed choice behavior was comparable across participants and studies.

Bayesian ideal observer model

We used the same Bayesian ideal observer model as in the prior adult study (Woitow et al., 2026) to estimate the likelihood of a binary outcome (reward, no reward) on each trial while accounting for changes in the reward probabilities. Importantly, participants received information about trial outcomes regardless of the learning condition. Therefore, we applied the ideal observer model in both learning conditions to compute the expected reward rate, surprise, uncertainty, and ideal learning rate. As model input, we provided the binary outcome of each trial and the true probability of a reward probability change (change point, CP) occurring on any given trial (hazard rate, H). The hazard rate was computed per participant by dividing the number of reward probability change points by the total number of trials. The model assumes that a change point occurs on each trial with probability H. If no change point occurs, the reward rate (𝜇 𝑡 ) remains the same as on the previous trial (𝜇 𝑡-1 ). If a change point occurs, a new reward rate is drawn from a uniform distribution between 0 and 1. The current belief about the reward rate (𝑉(𝑡 + 1)) resulted from the previous reward rate belief (𝑉(𝑡)), the ideal learning rate 𝛼, and the prediction error (𝑃𝐸). PE was computed as the difference between the obtained outcome (𝑅(𝑡)) and the predicted outcome (𝑉(𝑡)). Note: This is just an example. The probabilities from the actual game will be different.
