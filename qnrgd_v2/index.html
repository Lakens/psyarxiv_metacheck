Meta-scientific research has shown nonsignificant p values are commonly misinterpreted. It is incorrect to infer that there is ‘no effect’, ‘no difference’, or that groups are ‘the same’ after p > 0.05.

It is possible that there is a true non-zero effect, but that the study did not detect it. Make sure your inference acknowledges that it is possible that there is a non-zero effect. It is correct to include the effect is ‘not significantly’ different, although this just restates that p > 0.05.

This module searches for statements of ethics approval, IRB approval, institutional review board approval, and related terms.

Patterns are designed to capture:

How Power Analysis Check works

This module uses regular expressions to identify sentences that contain a statistical power analysis. If specified by the user, it also uses a large language model (LLM) to extract information reported in power analyses, including the statistical test, sample size, alpha level, desired level of power, and magnitude and type of effect size.

The Power Analysis Check module uses regular expressions to identify sentences that contain a statistical power analysis. Without the use of an LLM, the module uses regular expressions to classify the power analysis as a-priori, sensitivity or post-hoc. With the use of an LLM, it checks if the power analysis is reported with all required information.

The regular expressions can miss power analyses, or fail to classify them correctly. The type of power analysis is often difficult to classify, which can easily be solved by explicitly specifying the type of power analysis as ‘a-priori’, ‘sensitivity’, or ‘post-hoc’. Note that ‘post-hoc’ or ‘observed’ power is rarely useful. The LLM can fail to identify information in the paper, and will not have access to information in paragraphs in the paper other than those that contain the word ‘power’. This package was validated by the Metacheck team on articles in Psychological Science.

How Exact P-Values works

List any p-values reported with insufficient precision (e.g., p < .05 or p = n.s.), reported as exactly zero (e.g., p = .000), or impossible (below 0 or above 1, e.g., p = -.22).

This module uses regular expressions to identify p-values. It will flag any values reported as p > ? or p < numbers greater than .001. It will also flag p-values reported as exactly zero (e.g., p = .000, p = 0.00), which are mathematically impossible — p-values are never exactly zero and should instead be reported as p < .001.

A p-value that is not the result of a test is not flagged: a table note (“* p < .05, ** p < .01”), a figure legend (“Asterisks indicate significant differences (p < .05)”, “Values in bold are significant at p < .05”) or a stated threshold (“p < .05 was considered significant”, “thresholded at p < .001”). GROBID often puts such notes into the running text, so each p-value is judged by the words in its own clause (the text up to a “;” or a full stop), and never left out when a test statistic belongs to it (“F(1, 7) = 8.03, # p < .05”). The column not_a_test of the table says why a p-value was left out (“marker”, “threshold”, “legend” or “named”).

A p-value with the name of a correction or a test after the p (“pFWE < .05”, “padj < 0.05”, “p Wilcoxon = .02”) is flagged only when a test statistic comes before it in its clause (“t(37) = 7.17, p FWE < .05”). Without one it is mostly the rule that decided what was significant (“genes with padj < 0.05 were selected”); such a p-value is “named” in not_a_test. Notes in other forms, such as a marker after the p-value (“p < .05 (*)“), are still flagged.

A p-value below 0 or above 1 is impossible; it is listed apart and not also as imprecise. Often the statistic before it, or its minus sign, was copied into it (“t(134) = -2.32, p = -.13”, “Z = 3.091, P = 3.091”). A value above 1 is listed only after a test statistic in its clause: without one, a “P” above 1 was nearly always another quantity (a proportion, pH, a group’s mean, a model parameter). A number in scientific notation whose power of ten was lost when the PDF was read (“p = 2.4 x 10 -9” read as 2.4) is not listed. A “p” that is the subscript of another symbol (“r p = .64”, “²p = .02” for partial eta squared, “Δp = .33”), or a quantity with a unit, a logarithm or a ratio (“P = 2.9 µm”, “-log10 P = 7.5”, “Ca/P = 1.67”), is not read as a p-value at all (see extract_p_values()). Each p-value has its own row, also when the same one is written twice in a sentence.

This module sometimes flags false positives when sentences discuss how p-value thresholds were set. It can also miss an imprecise p-value that is reported against a threshold (“decreased at the p < .05 significance threshold”).

This module only checks p-values reported in the running text of the manuscript. It cannot (yet) process p-values reported only in tables (as opposed to a table’s footnote text, which the module does see and tries to exclude — see above).

This module was developed by Lisa DeBruine and Daniel Lakens

Read more in the metacheck manual.

Validation: Validated on 226 Psychological Science papers with 5,019 hand-coded p-values, 438 of them imprecise (scienceverse/validation, branch stat_p_exact). Version 0.4.4.3 reported 419 p-values as imprecise, 388 of them correctly (93%), and missed 50 (89% found). Of the misses, 13 are starred table notes (“*p < .05”) that the module leaves out on purpose and 11 are p-values it did not find; of the wrong reports, 20 are p-values the ground truth does not contain (such as “ps < .05”) and 6 use ≤ or ≥. How Data Check works

This module classifies the files in a repository into semantic types (data, codebook, code, software, output, supplemental, readme, asset, other) and, for tabular data files, extracts each column’s type and summary statistics.

The Data Check module consumes the file list produced by repo_check (or any files added via local_path). Each file is classified with rule-based heuristics layered over metacheck’s file_category() and file_types: file names matching README / codebook patterns win first, then an extension crosswalk, then format-locked extension overrides. For every file classified as tabular data that is available locally, the module reads the file head, describes each column with data_col_facets() and computes summary statistics for numeric columns. Every sheet of a spreadsheet that holds a table is read: a file with several such sheets has its columns under source_file = "file.xlsx [sheet]", and the sheet column names the sheet of any spreadsheet with several sheets; a sheet of notes or a codebook is treated as documentation when the file has another table. Following DDI, a column is described by orthogonal facets rather than a single type: representation (numeric/text/datetime/code — how it is stored), measurement_level (Stevens: nominal/ordinal/interval/ratio), concept (what it measures: reaction_time/age/gender/likert/id/…), role (identifier/measure/condition/timestamp), unit, and a quality state (ok/empty/constant). Concepts are detected by name+value rules (the demographic concepts via data_check_demographic()); when llm_use(TRUE) the model fills concepts and measurement levels the rules left blank. Qualtrics survey exports are recognised (data_check_is_qualtrics()): their extra header rows are stripped so columns type correctly, and the reserved response-metadata columns (StartDate, Duration, Finished, …) are tagged.

The module defaults to rules-only when llm_use(FALSE): columns the rules cannot resolve (ambiguous 3–20-unique integers, ambiguous character columns) fall back to continuous / text respectively. When llm_use(TRUE), ambiguous columns and unresolved file types (other) are sent to llm() for optional refinement, and every file is assigned a study group (ex1, pilot2, shared, …) so that multi-study repositories can be recognised (used by psychds_check). Without an LLM the study group is left NA (unknown).

Column extraction requires files to be readable from disk. Files fetched by repo_check from OSF/GitHub/etc. without a local copy (file_location is NA) are classified but not column-extracted; pass local_path to point at a downloaded copy of the repository.

For a paper whose repository is on Dryad, this means column extraction never happens unless a Dryad API key is set: Dryad requires one to download file bytes, even from a fully public dataset (dataset listing and metadata do not need one). Without a key, every Dryad file stays classified but un-downloaded, column_n is 0, and a warning naming Dryad and ?dryad_pat/?dryad_auth is included among the download failures. A one-time session message is also shown (see repo_check) the first time a Dryad dataset is encountered with no key set.

Every downloaded text file the authors wrote (code, settings, survey definitions such as Qualtrics .qsf files, documentation, outputs) is searched for keys: API keys, access tokens and private keys, which let anyone who downloads the file use a paid service at the authors’ cost. Of a tabular data file only the column names and first 3 rows of the table as read are searched: its values come from participants, but a key the authors set for a whole survey (as embedded data in a Qualtrics survey flow) is exported in every response. A key found turns the traffic light red; the report and the keys table give its file, line and type, and only its beginning. Other files over 25 MB and binary files are not searched. How Reproducibility Check works

This module assesses whether a paper’s R and Python code can be run on its data. It works in two phases. The static phase (always run) collects the package dependencies the code declares, rewrites the data-file paths that do not work in the repository as the authors organised it, works out the order the scripts must run in, and diagnoses why any referenced input file is unavailable — reporting what a reproduction attempt would involve and where it is likely to break. The execution phase (opt-in, execute = TRUE) then actually runs the code: it copies the repository into a throwaway directory, optionally installs the declared dependencies into a throwaway library, runs each script in order in an isolated subprocess with a per-script timeout, and captures the outcome and full output of each run.

By default (execute = FALSE) the module does not run any code — it performs only static analysis: reading dependencies with the same extractors as code_check, finding the files the code references in the repository, and building a run-order dependency graph. It reports what would be installed and run rather than doing it.

When execute = TRUE, the module additionally runs the downloaded code on your machine — a deliberate, opt-in action gated behind that argument (callr is required for R code). Each script runs in an isolated subprocess so a crash cannot take down the R session; note this isolates crashes, not the filesystem or network. Installs (when install_missing = TRUE) and the throwaway run library never touch your main R library. Each script’s outcome is one of ran_ok, errored, timed_out, dependency_unavailable, not_parsed, run_by_source (an R script another script runs with source(), which is run only inside that script, since on its own it lacks the packages and objects the sourcing script sets up first), run_by_import (a Python file other files import, a module rather than a script, unless it has an if __name__ == "__main__": block), jags_model (a JAGS or BUGS model saved with an R extension, which another script reads) or not_r_content (a file that is not R at all, such as a JSON or HTML dump); these last two are not run and are not failures. python2 marks Python 2 code that was not run. With sandbox = "docker" such code runs with Python 2.7 (option metacheck.docker_image_py2; FALSE turns this off), which modifications records; it is never converted, since that can change results. defines_functions is a file that only defines functions, which is used, not run (table$used_by names the scripts that use it), and not_analysis is a file of software rather than of the analysis: a package’s code, tests, documentation or setup.py, a copy of a tool, a web application, a script a program wrote (table$not_analysis_why says which); neither is run or counted as a script. docker_failed means the container never started, which says nothing about the script, so it keeps the light from being green but does not make it red. needs_a_person is a script that stopped because it asks a person to choose a file or answer a question, or that starts an app, and needs_internet one that stopped because the network is off in a Docker run, or, with internet = TRUE, could not reach what it asked for; download_too_large is a script stopped for downloading more than the limits allow (see internet), and out_of_memory one that, or a program it started (such as a compiler), ran out of the memory each script may use. All four are treated the same way. not_downloaded is a script that stopped on a file the repository lists but that was not downloaded, such as one over max_file_size: it could not be tried, so it is not counted as a script that did not reproduce (summary_table$repro_not_downloaded_n counts them apart). not_read is a file metacheck could not read, so it was not run; the light is then not green, as the file may read and run on another computer, and table$error_message says why, naming a package that is installed but cannot be loaded on the computer that ran the check. empty is a file with nothing in it, which is not run or counted as a script. For a script that did not run through, table$error_message is its error, short (at most 300 characters): the error line of its output, which names a package that is not there, with the address it asked for when it needed the internet, or the time limit it reached; table$reason sorts it into a kind. A timeout means “still running at the cutoff”, not a failure, so raise timeout for legitimately long-running (e.g. Bayesian) scripts. dependency_unavailable means the script’s own package could not be installed from live CRAN, the CRAN Archive, or a named GitHub/URL source — an infrastructure limitation, not a defect in the paper’s code, so unlike errored/timed_out it does not force the traffic light red. The full stdout/stderr of every run is kept in the result’s run_results (the report shows it in per-script dropdowns, capped for readability). The traffic light reflects the STATIC readiness signals by default, but an execution error (errored/timed_out) does recolour it to red — a script that crashes on its own analysis is a genuine reproduction failure. A script that fails with could not find function is run once more with the library() calls the project’s other scripts make added at its top (or the one package that exports the function, or magrittr for %>%), and a script that then runs is reported as reproducible only after that repair.

Dependencies are reported name-only, with the source (CRAN, GitHub, or a base package already shipped with R) — static analysis of the code cannot know which version was used, and running against current package versions is itself informative: a break argues the authors should have pinned versions. When the repository does record versions, a run with recorded_versions = TRUE installs the packages the scripts load at those versions, but it does not change the R version, which remains a limitation of the check.

Run order is derived from read-after-write data dependencies (a script writing a file another reads must run first), source() edges, and numeric filename prefixes as a weak tie-breaker. Ambiguous orderings, dependency cycles, and inputs a script reads but that no earlier script produces (and that are not in the repository) are surfaced as warnings, since these are the situations most likely to make an otherwise-correct reproduction fail.

Python code (.py files, and notebooks and Quarto documents whose code is Python, from which the code is extracted first) goes through the same two phases, reported in its own “Python code” section. Each file is checked for syntax errors with Python’s own parser when a Python interpreter (python, or else python3) is available; dependencies are read from the import statements, with versions from a requirements.txt or pyproject.toml when there is one, and installed with pip; each script runs as its own python process (processx is required), so unlike R scripts, a name one script defines is not available to another. When no Python interpreter is available, the Python files are reported as not run and the R results are still returned. Statistics the Python scripts print are compared with the paper together with the R output and any self-reproducible output (JASP/jamovi, SPSS-Viewer, notebook outputs).

Abstract

Remembering an experience can reinstate patterns of neural activity from when the event originally occurred. During encoding, individuals show synchronized neural responses as events unfold, and greater synchrony across individuals has been linked to better memory. These shared neural responses may reflect aspects of an event that are consistently represented and could support later reinstatement. Yet whether greater similarity to others is associated with stronger reinstatement remains unclear, particularly in older adults, whose neural responses are more variable. Here, younger and older adults watched a 26-minute television episode and then freely recalled it while in the scanner. We measured moment-to-moment neural synchrony and eventspecific spatial similarity across individuals in the posterior medial network (PMN). We then examined how these measures related to neural reinstatement and recall specificity. Older adults recalled fewer specific details and showed less similar event-specific encoding patterns to one another compared to younger adults. However, their patterns were more similar to those of younger adults than to those of other older adults. Both groups showed event-specific reinstatement.

Importantly, individuals whose encoding patterns more closely resembled those of other viewers showed stronger reinstatement in both age groups. Greater neural synchrony was also associated with more specific recall in younger adults, although this relationship did not differ significantly between age groups. Together, these findings establish a link between how similarly experiences are represented across individuals during encoding and how strongly those representations are reinstated during remembering, even in the context of greater neural variability in older adulthood.

INTRODUCTION

Remembering everyday experiences involves reconstructing meaningful events that bring together information about people, places, and actions encoded during the original experience (Radvansky & Zacks, 2014; Zacks, 2020; Reagh & Ranganath, 2023). Among the corticohippocampal networks that support episodic memory (Ranganath & Ritchey, 2012), the posterior medial network (PMN), consisting of the posterior cingulate cortex, retrosplenial cortex, angular gyrus, and dorsal prefrontal cortex (Barnett et al., 2021), has been implicated in representing the structure of events and maintaining event models that integrate information over extended timescales (Zacks, 2020; Baldassano et al., 2017; Ritchey & Cooper, 2020). PMN activity tracks changes in narrative and spatial context as experiences unfold, suggesting that this network plays a central role in organizing ongoing experience into coherent event representations (Baldassano et al., 2017; Reagh & Ranganath, 2023). During remembering, neural patterns established during encoding can be reactivated, a phenomenon known as neural reinstatement (Bird et al., 2015; Oedekoven et al., 2017). Studies using naturalistic films have shown that event-specific patterns of PMN activity during encoding are reinstated during free recall of those same events (Chen et al., 2017).

Although reinstatement is generally measured within individuals, the neural representations formed during experience are not entirely unique to each individual. When different individuals experience the same continuous events, they exhibit similar spatial patterns of activity in the PMN and other higher-order cortical regions (Chen et al., 2017; Oedekoven et al., 2017; Zadbood et al., 2017). Shared neural responses are also evident in the moment-tomoment temporal dynamics of activity, with neural responses becoming synchronized across individuals experiencing the same unfolding narrative (Hasson et al., 2004; Lerner et al., 2011; Simony et al., 2016). Whereas spatial pattern similarity captures whether the same events elicit similar patterns of activity across individuals, neural synchrony reflects the extent to which their responses unfold similarly over time (Nastase et al., 2019).

Importantly, these shared neural responses have also been linked to memory. Greater neural synchrony across individuals during movie watching is associated with successful memory for those portions of the experience (Hasson et al., 2008; Simony et al., 2016). Neural patterns during encoding of naturalistic videos were also more similar across individuals for episodes that were remembered compared to those that were forgotten, including episode-specific patterns in regions within the PMN (Kosh et al., 2020). Moreover, individuals whose neural responses are more strongly synchronized with those of their peers (Cohen & Parra, 2016), or whose encoding activity more closely resembles the group-averaged neural response (Sheng et al., 2023), tend to show better memory. These findings suggest that both the spatial organization and moment-tomoment temporal dynamics of shared neural responses during encoding may be relevant to later remembering.

However, these relationships with memory performance do not address the question of whether similarity across individuals during encoding is also related to the reinstatement of an individual's own neural representations. For instance, an individual could encode an event differently from others yet still strongly reinstate their own encoding pattern during recall.

Alternatively, if shared neural patterns reflect common representations of event content and structure, individuals whose encoding patterns more closely resemble those of others may show stronger reinstatement. Greater similarity across individuals could also reflect more consistent processing of the unfolding experience or more reliable encoding representations, which may contribute to stronger reinstatement. Although these possibilities are not mutually exclusive, they SHARED EVENT REPRESENTATION IN PMN PREDICTS REINSTATEMENT 5 raise an important question about whether the extent to which neural representations are shared across individuals during encoding is associated with how strongly individuals reinstate those representations during remembering. Examining this relationship would extend previous findings linking shared neural responses to behavioral memory by identifying whether they are also related to the neural reactivation of past experiences.

Aging provides an important context for examining this relationship as older adults show changes in episodic memory and in the neural processes supporting event representations. Older adults often retain the general meaning of past experiences while recalling fewer specific details (Grilli & Sheldon, 2022; Greene & Naveh-Benjamin, 2023), and they tend to organize their recall of naturalistic events around broader topics rather than the fine-grained temporal sequence that characterizes younger adults' recall (Delarazan et al., 2026). Prior work has also shown that older adults exhibit reduced stimulus-specific neural reactivation during memory retrieval (St-Laurent et al., 2014), and that age-related differences in reinstatement may partly originate from how information is represented during encoding (Hill et al., 2021). During naturalistic viewing, older adults show less synchronized and more idiosyncratic neural responses across individuals, particularly in regions associated with attention and memory (Campbell et al., 2015; Geerligs & Campbell, 2018), as well as reduced PMN responses to meaningful transitions in ongoing experiences (Reagh et al., 2020). These findings suggest that aging may affect the consistency with which individuals represent the same events. However, it is poorly understood whether older adults' less consistent neural responses reflect a shift toward distinct age-specific event representations or greater individual variability in representations that remain shared across age groups. It is also unclear whether older adults whose encoding patterns more closely resemble those of others show stronger reinstatement, despite greater variability in their neural responses.

Here, we examined whether shared neural representations during encoding were associated with later memory and event-specific reinstatement in younger and older adults. During functional MRI scanning (fMRI), participants watched a 26-minute episode of a "slice-of-life" television sitcom (HBO's Curb Your Enthusiasm) and provided an unconstrained spoken recall. RESULTS

Older adults showed reduced recall specificity

Twenty-nine younger and twenty-four older adult participants were presented with a "sliceof-life" television sitcom (HBO's Curb Your Enthusiasm) while undergoing functional MRI scanning (Fig. 1A). After viewing, participants were instructed to recall aloud everything that they can remember about the television episode in as much detail as possible (Fig. 1B). Recall was recorded with an MRI-compatible microphone and later transcribed and manually scored for the specificity of recall against a standardized rubric.

The television episode was divided into high-level meaningful transitions (Zacks et al., 2007), resulting in 37 possible coarse-grained events (Delarazan et al., 2026) and 195 detail descriptions (approximately 5 detail descriptions per event). Two raters (E.K. and H.C.) scored participants' recall against these descriptions (see Methods; Table S1). Gist units were awarded when a participant conveyed the general meaning of a description, and detail units when they additionally recalled its specific components (e.g., who, where, what). Given that detail units were nested within gist units, we summarized each participant's recall with a recall specificity score reflecting the balance of detailed versus gist-based recall, with higher values indicating more specific recall (Table S1).

Our results revealed a significant difference in recall specificity between younger (M = 0.76, SD = 0.19) and older (M = 0.61, SD = 0.15) adults (t(47.74) = 3.20, p = .002, Cohen's d = 0.88, 95% CI [0.28, 1.48]; Fig. 1C), indicating that older adults' recall was less specific compared to younger adults. Event-specific PMN patterns were reinstated in both age groups, but weaker in older adults

Prior evidence has shown that the posterior medial network (PMN) supports event-specific representations during naturalistic experiences and their reinstatement (Bird et al., 2015; Chen et al., 2017). Therefore, we selected the PMN as our a priori region of interest, aggregating data across individual parcels. We first examined whether event-specific neural patterns in the PMN were reinstated during recall in younger and older adults. For each participant, we computed eventspecific reinstatement as the similarity between PMN activity patterns during encoding and recall of the same event, relative to the similarity between different events (Fig. 2A; see Methods). Higher values indicate stronger event-specific reinstatement.

We found that pattern reinstatement was greater than chance in both younger (M = 0.045, SD = 0.039; t(28) = 6.21, p < .001, Cohen's d = 1.15, 95% CI [0.66, 1.64]), and older adults (M = 0.018, SD = 0.033; t(19) = 2.50, p = .022, Cohen's d = 0.56, 95% CI [0.06, 1.06]). This indicates that younger adults' recall patterns were more similar to their encoding patterns for the same event than were older adults'. Finally, a control analysis of early visual cortex did not reveal evidence of positive event-specific reinstatement (Table S2).

Age-related differences in shared neural responses during encoding Given that reinstatement involves the reactivation of neural patterns established during encoding, differences in how events are initially represented may influence reinstatement. Prior work suggests that similar neural responses across individuals reflect shared representations of event content and structure (Chen et al., 2017), whereas weaker correspondence may reflect more idiosyncratic representations (Campbell et al., 2015; Geerligs & Campbell, 2018; Cohen, 2018).

Thus, we next examined the extent to which PMN responses converged across individuals during encoding and whether this convergence differed between younger and older adults.

We assessed convergence using two complementary measures. Intersubject pattern similarity (ISPS) captured the similarity of encoding event-specific spatial activity patterns across individuals (Fig. 2C), whereas intersubject correlation (ISC) captured the moment-to-moment similarity of neural responses across individuals during encoding (Fig. 2E). For both measures, each participant was compared with the remaining participants in their own age group (withingroup) and with participants in the other age group (cross-group; see Methods). These comparisons allowed us to examine whether older adults showed distinct age-related patterns of neural activity or greater variability in representations shared across age groups.

Intersubject Pattern Similarity (ISPS).

We examined ISPS to determine whether the same events elicited similar PMN activity patterns across participants (Chen et al., 2017). For each event, we correlated each participant's PMN encoding pattern with the average pattern of other participants for the same event, relative to different events, such that higher values indicate greater similarity in event-specific encoding patterns across individuals (Fig. 2C; see Methods).

We found that event-specific ISPS was significantly greater than zero for both younger (within-group: M = 0.172, SD = 0.062; t(28) = 14.91, p < .001, Cohen's d = 2.77, 95% CI [1.93, SHARED EVENT REPRESENTATION IN PMN PREDICTS REINSTATEMENT 10 3.60]; cross-group: M = 0.131, SD = 0.044; t(28) = 15.95, p < .001, Cohen's d = 2.96, 95% CI [2.08, 3.84]) and older adults (within-group: M = 0.096, SD = 0.032; t(23) = 14.84, p < .001, Cohen's d = 3.03, 95% CI [2.03, 4.03]; cross-group: M = 0.116, SD = 0.048; t(23) = 11.96, p < .001, Cohen's d = 2.44, 95% CI [1.60, 3.28]). These findings indicate that the same events elicited similar spatial patterns across individuals in both age groups.

Importantly, the degree of event-specific similarity differed by age. In contrast, older adults' encoding patterns were more similar to those of younger adults than to other older adults (t(23) = 4.24, p < .001 corrected, Cohen's d = 0.50, 95% CI [0.32, 0.78]).

Younger adults' event-specific encoding patterns were more similar to those of other younger adults, whereas older adults showed less similarity to individuals in their own age group. However, older adults' encoding patterns were more similar to those of younger adults than to those of other older adults. Having established that shared event-specific encoding patterns were associated with neural reinstatement, we next examined whether these neural measures were also related to the specificity of behavioral recall. We correlated recall specificity with within-group and cross-group ISC and ISPS, as well as pattern reinstatement, separately for each age group. We corrected for multiple comparisons across the five neural measures within each age group using the false discovery rate (FDR; Benjamini & Hochberg, 1995). Adjusted p-values are reported as q, and associations with q < .05 were considered significant.

Among younger adults, greater neural synchrony during encoding was associated with more specific recall for both within-group ISC (r(27) = .43, 95% CI [.08, .69], p = .020, q = .049; Fig. 4A) and cross-group ISC (r(27) = .46, 95% CI [.11, .71], p = .012, q = .049; Fig. 4B). Together, these findings indicate that greater moment-to-moment neural synchrony during encoding was associated with more specific recall in younger adults but not older adults, although this association did not differ significantly between age groups.

DISCUSSION

The present study examined whether shared neural representations of naturalistic events during encoding were associated with reinstatement and recall specificity in younger and older adults. We found that individuals whose event-specific encoding patterns in the posterior medial network (PMN) more closely resembled those of others showed stronger reinstatement during recall in both age groups. Older adults recalled the episode with lower specificity and showed weaker event-specific reinstatement than younger adults. They also showed greater variability in event-specific encoding patterns, and their patterns were more similar to those of younger adults than to one another. Greater neural synchrony during encoding was associated with more specific recall in younger adults, although this relationship did not differ significantly between age groups.

By linking shared neural representations during encoding to their reinstatement within individuals, this study connects how experiences are represented across people with how they are reactivated during remembering.

Prior work has shown that individuals exhibit shared neural representations when experiencing the same naturalistic events (Chen et al., 2017; Oedekoven et al., 2017; Zadbood et al., 2017), and that greater similarity in neural responses across individuals during encoding is associated with better memory (Koch et al., 2020; Sheng et al., 2023). The present findings extend this work to reinstatement within individuals. An individual could encode an event differently from others yet still reinstate that representation during recall. However, we found that individuals whose encoding patterns were more similar to those of others showed stronger reinstatement. One possibility is that greater similarity across individuals reflects common representations of event content and structure, possibly converging on central or important pieces of content. The PMN is thought to integrate information about people, places, and actions over extended timescales, supporting coherent representations of unfolding events (Baldassano et al., 2017; Ritchey & Cooper, 2020; Reagh & Ranganath, 2023). To the extent that individuals organize their experiences around similar event information, these representations may provide a framework for reconstructing those events during recall, potentially supporting stronger reinstatement of encoding patterns. Alternatively, greater similarity across individuals may reflect more consistent processing of the unfolding experience or more reliable neural representations, both of which could increase similarity across individuals as well as between encoding and recall. Although the present findings cannot distinguish among these explanations, they suggest that the extent to which an individual's encoding patterns resemble those of others may be relevant to why some individuals show stronger reinstatement than others.

Age-related differences in shared encoding patterns provide an important context for understanding this relationship. Prior work has demonstrated that aging is associated with less synchronized and more idiosyncratic neural responses during naturalistic viewing (Campbell et al., 2015; Geerligs & Campbell, 2018). The present findings extend this work by showing that greater variability among older adults is also evident in event-specific spatial representations within the PMN. Interestingly, older adults' encoding patterns were more similar to those of younger adults than to other older adults, suggesting that aging may be associated with greater individual variability rather than a uniform shift toward distinct age-specific representations. This raises the possibility that older adults retain aspects of shared event representations but differ in how they organize or emphasize information within those events. For example, individuals may differ in the contextual information they attend to or integrate when constructing representations of unfolding experiences. A similar pattern in early visual cortex (Table S3) suggests that this variability is not limited to higher-order event representations and may also reflect differences in SHARED EVENT REPRESENTATION IN PMN PREDICTS REINSTATEMENT 17 attention during encoding (Campbell et al., 2015). Such differences may be relevant given prior evidence of altered PMN responses to meaningful event transitions in older adults (Reagh et al., 2020) and findings suggesting that age-related differences in reinstatement may partly originate during encoding (Hill et al., 2021). Despite greater variability in their encoding patterns and weaker overall reinstatement, older adults whose event representations more closely resembled those of others showed stronger reinstatement.

Beyond the relationship between shared encoding patterns and reinstatement, we found that greater neural synchrony during encoding was associated with more specific recall among younger adults. This finding extends prior work linking intersubject neural synchrony during naturalistic experiences to memory performance (Hasson et al., 2008; Simony et al., 2016; Cohen & Parra, 2016). One possibility is that greater neural synchrony reflects more similar allocation of attention to the unfolding experience across individuals, consistent with prior work linking neural synchrony during naturalistic viewing to attentional control (Campbell et al., 2015). Such attention may support the encoding of specific event information that can later be recalled. Although this relationship was not significant among older adults, the associations did not differ significantly between age groups, limiting conclusions about age-related differences. Nonetheless, it is possible that idiosyncratic processing of continuous events during encoding leads to relatively less stable event representations in older adults compared to younger adults, limiting the extent to which they can reinstate those representations during retrieval. We also did not observe significant associations between recall specificity and either ISPS or pattern reinstatement. First, our modest sample size, particularly among older adults with usable recall data, may have limited the precision of individual-difference estimates and our ability to detect age-related differences.

Nonetheless, the associations in older adults were relatively strong and remained when participants with lower neuropsychological scores were excluded (Tables S5 and S6). Older adults' greater similarity to younger adults may also partly reflect the larger and more consistent younger adult group. However, ISPS was associated with reinstatement even when participants were compared with others in their own age group. Larger samples could provide more precise estimates of these relationships across adulthood. Second, a key contribution of this study was linking shared eventspecific encoding patterns to reinstatement. However, this association is correlational, and both measures relied on the same encoding patterns. Individuals with more reliable PMN representations may therefore show greater similarity to others and stronger reinstatement. We applied denoising and motion exclusion procedures, and the association was not observed in early visual cortex (Table S4), reducing concern about artifacts that affect neural similarity across regions. However, these approaches cannot fully rule out differences in encoding reliability. Future studies could independently assess encoding reliability or manipulate encoding conditions to better understand the factors contributing to this relationship. Reinstatement was also measured only for successfully recalled events, leaving open whether shared encoding patterns relate to the likelihood of recalling particular events. Finally, we focused on the PMN based on prior evidence of its role SHARED EVENT REPRESENTATION IN PMN PREDICTS REINSTATEMENT 19 in representing and reinstating naturalistic events. Examining other neural systems and naturalistic experiences will be important for determining how broadly these relationships generalize across adulthood.

Together, our findings show that shared event-specific representations during encoding are associated with stronger reinstatement during recall. This relationship was evident in both younger and older adults, despite greater variability in older adults' neural representations. Although individuals may differ in how they represent the same experiences, the aspects of those representations that are shared across people may be important for understanding how events are later remembered.

Using the confound estimates generated by fMRIPrep, we regressed out 12 motion parameters (three translations and three rotations, plus their first temporal derivatives) and the six anatomical CompCor components (aCompCor; Behzadi et al., 2007) explaining the most variance within a combined white matter and cerebrospinal fluid mask. Linear detrending, confound regression, and z-scoring within each vertex were performed in a single step on the fsaverage surface timeseries using nilearn's signal.clean function (Abraham et al., 2014), which detrends both the signal and the confounds before regression. Participants with mean framewise displacement (FD) greater than 0.7 mm were excluded from analyses of the affected scan (see Participants). Older adults showed greater head motion than younger adults during both encoding SHARED EVENT REPRESENTATION IN PMN PREDICTS REINSTATEMENT 25 and recall (Table S7), consistent with prior reports of increased in-scanner motion with age (Savalia et al., 2017; Madan, 2018).

Region of Interest (ROI)

Normalized surface-based time-series were parcellated using the Glasser HCP-MMP atlas (Glasser et al., 2016). Parcel-level network identity was then assigned using the corticohippocampal network classification derived from data-driven resting-state functional connectivity analyses (Barnett et al., 2021). From these subnetworks, our a priori region of interest was the Posterior Medial Network (PMN), which includes the posterior cingulate cortex, anterior retrosplenial cortex, posterior angular gyrus, and dorsal prefrontal cortex. Early visual cortex (V1-V4) from the same atlas served as a control region (see Supplemental Materials).

Event Patterns. The television episode was segmented into 37 coarse-grained events based on meaningful transitions in the unfolding narrative (Zacks et al., 2007), and the onset and offset of each event were time-stamped to define encoding patterns. Recall patterns were defined using time-stamped transcript segments corresponding to each event, with segments assigned to the same event combined. To account for hemodynamic lag, timeseries were shifted by 5 TRs (6.1 s), and activity was averaged across all TRs corresponding to each event, yielding one spatial activity pattern per event in each hemisphere. Only events that a participant successfully recalled were included in the reinstatement analyses. These event-averaged encoding patterns were used in both the pattern reinstatement and ISPS analyses. Whereas reinstatement compared an individual's encoding patterns with their own recall patterns, ISPS compared those encoding patterns with the encoding patterns of other participants (see below).

Pattern Reinstatement.

Neural patterns for each event during encoding were correlated with neural patterns for each event during spoken recall using Pearson's r across vertices, separately for each hemisphere, and Fisher z-transformed to stabilize variance. To account for general neural similarity unrelated to event-specific reinstatement, we used the mean pattern similarity between mismatched encoding-to-recall event pairs (e.g., encoding of event A to recall of event B) as a baseline and subtracted this value from the mean pattern similarity for matched event pairs (e.g., encoding of event A to recall of event A). Baseline-corrected reinstatement values were averaged across hemispheres, yielding one reinstatement value per participant, with higher values reflecting stronger event-specific neural reinstatement.

Intersubject Pattern Similarity (ISPS).

Using the same event-averaged encoding patterns described above, we correlated each participant's pattern for a given event with the average pattern of the remaining participants in the same age group for the corresponding event using a leave-oneout approach (within-group), or with the average pattern of the participants in the other age group (cross-group), using Pearson's r. Resulting correlation coefficients were Fisher z-transformed and baseline-corrected by subtracting the similarity between mismatched event pairs (e.g., a participant's pattern for event A and the group-averaged pattern for event B) from the similarity for matched event pairs. Values were averaged across events and hemispheres, yielding one within-group and one cross-group ISPS value per participant, with higher values indicating more similar PMN patterns for the same event across individuals.

Intersubject Correlation (ISC).

For each participant, preprocessed encoding timeseries were averaged across PMN vertices within each hemisphere. We then correlated that participant's timeseries with the average timeseries of the remaining participants in the same age group using a leave-one-out approach (within-group), or with the average timeseries of the participants in the other age group (cross-group), computing Pearson's r. Resulting correlation coefficients were Fisher z-transformed to stabilize variance and averaged across hemispheres. This procedure yielded one within-group and one cross-group ISC value per participant within the PMN, where higher values reflect stronger temporal alignment and greater shared neural synchrony.

Statistical Analyses

All statistical analyses were conducted in Python using SciPy, statsmodels, and pingouin.

Tests were two-tailed with α = .05 unless otherwise noted. 95% confidence intervals for Cohen's d were computed from the large-sample standard error of d (Hedges & Olkin, 1985), using t critical values (n -1 degrees of freedom for one-sample and paired comparisons; n₁ + n₂ -2 for betweengroup comparisons). Because this standard error does not account for the correlation between conditions, 95% confidence intervals for paired comparisons were obtained by bootstrapping (5,000 resamples of participants; Efron & Tibshirani, 1993). Analytic and bootstrapped intervals for all main-text effect sizes are reported in Table S8.

Age Group Comparisons. Age-group differences were assessed using Welch's t-tests, with effect sizes expressed as Cohen's d and 95% confidence intervals. Label-shuffling permutation tests (5,000 iterations) yielded the same conclusions for every group comparison.

Tests Against Chance.

Event-specific reinstatement and ISPS were tested against zero using one-sample t-tests, with Cohen's d and 95% confidence intervals. To account for the dependence among leave-one-out ISC values, statistical significance of ISC was assessed using circular time-shift permutation tests (10,000 iterations; Nastase et al., 2019). Each participant's timeseries was independently shifted by a random lag, held constant across hemispheres, and group-mean ISC was recalculated. Empirical p-values were calculated as the proportion of permutations with ISC values greater than or equal to the observed value. Mixed ANOVAs. Age differences in ISC and ISPS were examined using separate mixed ANOVAs with age group (younger, older) as a between-participants factor and reference group (within-group, cross-group) as a within-participants factor, with effect sizes expressed as partial eta squared (ηp²). Significant interactions were followed by paired t-tests comparing reference SHARED EVENT REPRESENTATION IN PMN PREDICTS REINSTATEMENT 29 groups within each age group and Welch's t-tests comparing age groups within each reference group, with effect sizes expressed as Cohen's d (for paired comparisons, dav: the mean difference divided by the square root of the average of the two condition variances, as implemented in pingouin; Lakens, 2013; Vallat, 2018) and Bonferroni correction applied within each family of two comparisons. Correlations. Associations between neural measures, reinstatement, and recall specificity were assessed using Pearson correlations with 95% confidence intervals computed via Fisher's z transformation, separately for each age group. False discovery rate (FDR) correction was applied within each age group across the four encoding measures examined in relation to reinstatement and the five neural measures examined in relation to recall specificity (Benjamini & Hochberg, 1995). Adjusted p-values are reported as q. Differences in correlations between age groups were assessed using Fisher's r-to-z tests.
