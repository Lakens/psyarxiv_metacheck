How Power Analysis Check works

This module uses regular expressions to identify sentences that contain a statistical power analysis. If specified by the user, it also uses a large language model (LLM) to extract information reported in power analyses, including the statistical test, sample size, alpha level, desired level of power, and magnitude and type of effect size.

The Power Analysis Check module uses regular expressions to identify sentences that contain a statistical power analysis. Without the use of an LLM, the module uses regular expressions to classify the power analysis as a-priori, sensitivity or post-hoc. How StatCheck works

Check consistency of p-values and test statistics

The Statcheck module runs Statcheck. Statcheck searches for regular expressions that match a predefined pattern, and identifies APA reported statistical tests. More information on the package can be found at https://github.com/cran/statcheck. The module only returns Statcheck results for t-tests and F-tests, as these are the only tests which have been validated, see https://osf.io/preprints/psyarxiv/tcxaj_v1/.

Statcheck was developed by Michèle Nuijten and Sascha Epskamp.

Statcheck considers p = 0.000 an error, as you should report p < 0.001. Furthermore, p < 0.03 is an error if the p-value was 0.031, and one should simply report exact p-values (p = 0.031). When the sentence of a test says it is one-sided (“one-tailed”, “one-sided” or “directional”), a p-value that fits a one-sided test counts as consistent (statcheck’s OneTailedTxt setting; #695). Equivalence tests (TOST) are left out, as their p-values do not test the difference. A statistic written with “<” or “>” is read as a bound, and in a sentence about equal variances an F-test’s two-sided p (twice the one-tailed p) counts as consistent. How Exact P-Values works

List any p-values reported with insufficient precision (e.g., p < .05 or p = n.s.), reported as exactly zero (e.g., p = .000), or impossible (below 0 or above 1, e.g., p = -.22).

This module uses regular expressions to identify p-values. It will flag any values reported as p > ? or p < numbers greater than .001. It will also flag p-values reported as exactly zero (e.g., p = .000, p = 0.00), which are mathematically impossible — p-values are never exactly zero and should instead be reported as p < .001.

A p-value that is not the result of a test is not flagged: a table note (“* p < .05, ** p < .01”), a figure legend (“Asterisks indicate significant differences (p < .05)”, “Values in bold are significant at p < .05”) or a stated threshold (“p < .05 was considered significant”, “thresholded at p < .001”). GROBID often puts such notes into the running text, so each p-value is judged by the words in its own clause (the text up to a “;” or a full stop), and never left out when a test statistic belongs to it (“F(1, 7) = 8.03, # p < .05”). The column not_a_test of the table says why a p-value was left out (“marker”, “threshold”, “legend” or “named”).

A p-value with the name of a correction or a test after the p (“pFWE < .05”, “padj < 0.05”, “p Wilcoxon = .02”) is flagged only when a test statistic comes before it in its clause (“t(37) = 7.17, p FWE < .05”). Without one it is mostly the rule that decided what was significant (“genes with padj < 0.05 were selected”); such a p-value is “named” in not_a_test. Notes in other forms, such as a marker after the p-value (“p < .05 (*)“), are still flagged.

A p-value below 0 or above 1 is impossible; it is listed apart and not also as imprecise. Often the statistic before it, or its minus sign, was copied into it (“t(134) = -2.32, p = -.13”, “Z = 3.091, P = 3.091”). A value above 1 is listed only after a test statistic in its clause: without one, a “P” above 1 was nearly always another quantity (a proportion, pH, a group’s mean, a model parameter). A number in scientific notation whose power of ten was lost when the PDF was read (“p = 2.4 x 10 -9” read as 2.4) is not listed. A “p” that is the subscript of another symbol (“r p = .64”, “²p = .02” for partial eta squared, “Δp = .33”), or a quantity with a unit, a logarithm or a ratio (“P = 2.9 µm”, “-log10 P = 7.5”, “Ca/P = 1.67”), is not read as a p-value at all (see extract_p_values()). Each p-value has its own row, also when the same one is written twice in a sentence.

This module sometimes flags false positives when sentences discuss how p-value thresholds were set. It can also miss an imprecise p-value that is reported against a threshold (“decreased at the p < .05 significance threshold”).

This module only checks p-values reported in the running text of the manuscript. It cannot (yet) process p-values reported only in tables (as opposed to a table’s footnote text, which the module does see and tries to exclude — see above).

Telling this paper’s own deposit from the authors’ earlier one is less certain.

How Code Check works

This module retrieves information from repositories checked by repo_check about code files (R, Python, SAS, SPSS, Stata, Mplus, MATLAB).

The Code Check module checks R (also R Markdown and Quarto), Python (also Jupyter notebooks), SAS, SPSS, Stata, Mplus, and MATLAB files, using regular expressions to check the code; JASP files are listed but not read. The language of a Quarto document or a notebook is read from the file itself (its engine or kernel), not from its extension. The regular expression search will detect the number of comments, the lines at which libraries/imports are loaded, attempts to detect absolute paths to files, setwd() and install.packages() calls, and lists files that are loaded, and checks if these files are in the repository; R code is also parsed. The module will return suggestions to improve the code if there are no comments, if libraries/imports are loaded in lines further than 4 lines apart, if files that are loaded are not in the repository, if absolute file paths, setwd() or install.packages() are found, and if R code cannot be parsed.

The regular expressions can miss information in code files, or falsely detect parts of the code as a fixed file path. Libraries/imports might be loaded in one block, even if there are more than 3 intermittent lines. The module was tried out internally on papers published in Psychological Science, but has not been formally validated. There might be valid reasons why some loaded files can’t be shared, but the module can’t evaluate these reasons, and always gives a warning.

The module also checks whether the repository pins the R/package versions the analysis actually depended on: an renv.lock file (parsed for the R version and every locked package + its version/source), a sessionInfo()/sessioninfo::session_info() text dump (matched by filename — sessionInfo.txt/session_info.txt and similar, or embedded in a README), or a groundhog::groundhog.library()/checkpoint::checkpoint() date-pin call in the code (a bare library(groundhog)/library(checkpoint) does not count — the pinning call itself must be present). When none of these is found, the report flags it as a reproducibility gap: package versions may drift between when the analysis was run and any later reproduction attempt.

How Data Check works

This module classifies the files in a repository into semantic types (data, codebook, code, software, output, supplemental, readme, asset, other) and, for tabular data files, extracts each column’s type and summary statistics.

The Data Check module consumes the file list produced by repo_check (or any files added via local_path). Each file is classified with rule-based heuristics layered over metacheck’s file_category() and file_types: file names matching README / codebook patterns win first, then an extension crosswalk, then format-locked extension overrides. For every file classified as tabular data that is available locally, the module reads the file head, describes each column with data_col_facets() and computes summary statistics for numeric columns. Every sheet of a spreadsheet that holds a table is read: a file with several such sheets has its columns under source_file = "file.xlsx [sheet]", and the sheet column names the sheet of any spreadsheet with several sheets; a sheet of notes or a codebook is treated as documentation when the file has another table. Following DDI, a column is described by orthogonal facets rather than a single type: representation (numeric/text/datetime/code — how it is stored), measurement_level (Stevens: nominal/ordinal/interval/ratio), concept (what it measures: reaction_time/age/gender/likert/id/…), role (identifier/measure/condition/timestamp), unit, and a quality state (ok/empty/constant). Concepts are detected by name+value rules (the demographic concepts via data_check_demographic()); when llm_use(TRUE) the model fills concepts and measurement levels the rules left blank. Qualtrics survey exports are recognised (data_check_is_qualtrics()): their extra header rows are stripped so columns type correctly, and the reserved response-metadata columns (StartDate, Duration, Finished, …) are tagged.

The module defaults to rules-only when llm_use(FALSE): columns the rules cannot resolve (ambiguous 3–20-unique integers, ambiguous character columns) fall back to continuous / text respectively. When llm_use(TRUE), ambiguous columns and unresolved file types (other) are sent to llm() for optional refinement, and every file is assigned a study group (ex1, pilot2, shared, …) so that multi-study repositories can be recognised (used by psychds_check). Without an LLM the study group is left NA (unknown).

Column extraction requires files to be readable from disk. Files fetched by repo_check from OSF/GitHub/etc. without a local copy (file_location is NA) are classified but not column-extracted; pass local_path to point at a downloaded copy of the repository.

For a paper whose repository is on Dryad, this means column extraction never happens unless a Dryad API key is set: Dryad requires one to download file bytes, even from a fully public dataset (dataset listing and metadata do not need one). Without a key, every Dryad file stays classified but un-downloaded, column_n is 0, and a warning naming Dryad and ?dryad_pat/?dryad_auth is included among the download failures. A one-time session message is also shown (see repo_check) the first time a Dryad dataset is encountered with no key set.

Every downloaded text file the authors wrote (code, settings, survey definitions such as Qualtrics .qsf files, documentation, outputs) is searched for keys: API keys, access tokens and private keys, which let anyone who downloads the file use a paid service at the authors’ cost. Of a tabular data file only the column names and first 3 rows of the table as read are searched: its values come from participants, but a key the authors set for a whole survey (as embedded data in a Qualtrics survey flow) is exported in every response. A key found turns the traffic light red; the report and the keys table give its file, line and type, and only its beginning. Other files over 25 MB and binary files are not searched. A key is never tested with its provider. Every module’s result has any whole key replaced by “keyremoved” (see module_run()).

How Reproducibility Check works

This module assesses whether a paper’s R and Python code can be run on its data. It works in two phases. The static phase (always run) collects the package dependencies the code declares, rewrites the data-file paths that do not work in the repository as the authors organised it, works out the order the scripts must run in, and diagnoses why any referenced input file is unavailable — reporting what a reproduction attempt would involve and where it is likely to break. The execution phase (opt-in, execute = TRUE) then actually runs the code: it copies the repository into a throwaway directory, optionally installs the declared dependencies into a throwaway library, runs each script in order in an isolated subprocess with a per-script timeout, and captures the outcome and full output of each run.

By default (execute = FALSE) the module does not run any code — it performs only static analysis: reading dependencies with the same extractors as code_check, finding the files the code references in the repository, and building a run-order dependency graph. It reports what would be installed and run rather than doing it.

When execute = TRUE, the module additionally runs the downloaded code on your machine — a deliberate, opt-in action gated behind that argument (callr is required for R code). Each script runs in an isolated subprocess so a crash cannot take down the R session; note this isolates crashes, not the filesystem or network. Installs (when install_missing = TRUE) and the throwaway run library never touch your main R library. Each script’s outcome is one of ran_ok, errored, timed_out, dependency_unavailable, not_parsed, run_by_source (an R script another script runs with source(), which is run only inside that script, since on its own it lacks the packages and objects the sourcing script sets up first), run_by_import (a Python file other files import, a module rather than a script, unless it has an if __name__ == "__main__": block), jags_model (a JAGS or BUGS model saved with an R extension, which another script reads) or not_r_content (a file that is not R at all, such as a JSON or HTML dump); these last two are not run and are not failures. python2 marks Python 2 code that was not run. With sandbox = "docker" such code runs with Python 2.7 (option metacheck.docker_image_py2; FALSE turns this off), which modifications records; it is never converted, since that can change results. defines_functions is a file that only defines functions, which is used, not run (table$used_by names the scripts that use it), and not_analysis is a file of software rather than of the analysis: a package’s code, tests, documentation or setup.py, a copy of a tool, a web application, a script a program wrote (table$not_analysis_why says which); neither is run or counted as a script. docker_failed means the container never started, which says nothing about the script, so it keeps the light from being green but does not make it red. needs_a_person is a script that stopped because it asks a person to choose a file or answer a question, or that starts an app, and needs_internet one that stopped because the network is off in a Docker run, or, with internet = TRUE, could not reach what it asked for; download_too_large is a script stopped for downloading more than the limits allow (see internet), and out_of_memory one that, or a program it started (such as a compiler), ran out of the memory each script may use. All four are treated the same way. not_downloaded is a script that stopped on a file the repository lists but that was not downloaded, such as one over max_file_size: it could not be tried, so it is not counted as a script that did not reproduce (summary_table$repro_not_downloaded_n counts them apart). not_read is a file metacheck could not read, so it was not run; the light is then not green, as the file may read and run on another computer, and table$error_message says why, naming a package that is installed but cannot be loaded on the computer that ran the check. empty is a file with nothing in it, which is not run or counted as a script. For a script that did not run through, table$error_message is its error, short (at most 300 characters): the error line of its output, which names a package that is not there, with the address it asked for when it needed the internet, or the time limit it reached; table$reason sorts it into a kind. A timeout means “still running at the cutoff”, not a failure, so raise timeout for legitimately long-running (e.g. Bayesian) scripts. dependency_unavailable means the script’s own package could not be installed from live CRAN, the CRAN Archive, or a named GitHub/URL source — an infrastructure limitation, not a defect in the paper’s code. The full stdout/stderr of every run is kept in the result’s run_results (the report shows it in per-script dropdowns, capped for readability).

Provenance, kept so that a TRACE Research Object (TRO) declaration of the run can be written later from a stored result (metacheck #404; the helpers are in R/provenance.R). Only when code was run (execute = TRUE): * run_results$started_at, run_results$ended_at: when each run of a script started and ended (ISO 8601, UTC, milliseconds); NA for a script that was not started. A script run again in a later pass has the times of its last run. A TRO uses them for each trov:TransparentResearchPerformance. * run_results$exit_status: the exit status of the process that ran the script (0 = ended normally); NA when the process did not report one (a time limit, or Docker failing to start the container). * artifacts: one row per file, with stage (deposit: as downloaded from the repository, hashed from the downloaded file; before_run: the run folder just before the first script ran, after metacheck’s own changes, such as rewritten paths and unpacked archives; after_run: only the files the scripts made (status new), changed (changed) or removed (removed), as an unchanged file is the one listed before the run), path (relative to the run folder, as valid UTF-8, a byte of another encoding written as <xx>), size (bytes), sha256, mime_type (by extension, NA when unknown), source (the file’s address in the repository, for deposit). The package libraries metacheck installs in the run folder are left out, as are metacheck’s own files there (a script’s runner, and the statistical output it writes in statistical_output/). Files metacheck itself copied or made between passes (see modifications, output_copied, file_placed) show in after_run too. A TRO uses the rows as trov:ResearchArtifacts and each stage as a trov:ArtifactArrangement. * modifications$sha256_before, modifications$sha256_after: the hash of the changed script as downloaded and as it ran; NA when the script is not at the same path in both (a script made from an R Markdown file). * environment: the system that ran the code (trov:TransparentResearchSystem in a TRO): metacheck_version, started_at, ended_at, host (R version, platform, operating system), sandbox, network_isolated (TRUE only when every Docker run had --network none; the process sandbox does not stop the network), internet, timeout_per_script, total_timeout, python_local (the Python run outside Docker and its version), and docker: runs (for each kind of run, r_run, r_install, python_run, python_install, the image and the docker run arguments, such as --network none, --read-only, --cap-drop ALL, no-new-privileges, the process limit and the memory and processor limits) and images (for each image, its ID and digests from docker image inspect, its creation time and the R and Python versions its environment declares).

run_results$checked says what the run of each script shows about the code, in five groups, so that a script that does not reproduce is kept apart from one the check could not test: ran (it ran to the end); code_error (it did not reproduce: it stopped with an error of the code or the deposit, could not be read, or needs a file the deposit does not hold); dependency (a package or program was not available: a package that could not be installed or was not loaded, a program outside R and Python, a system library, or R crashing in a package’s compiled code); time (it did not finish within the time limit for one script, or was not started because the time for all scripts had run out); and not_checkable (it could not be checked automatically: it needs a person, the internet, a key or another setting of the authors’ computer, one platform such as Google Colab, Windows or OpenSAFELY, more memory than the run allows, a file that was not downloaded, a screen, or a program that runs it, or it is a file of a package of the code that Python runs only as a module of that package). It is NA for files run inside another script, files that are not an analysis, files not read, and a Docker failure. summary_table counts each group (repro_ran_n, repro_code_error_n, repro_dependency_n, repro_time_n, repro_not_checkable_n), and the report’s first sentence gives them. The traffic light reflects the static readiness signals by default; a script in code_error that stopped with an error makes it red, as a script that crashes on its own analysis is a genuine reproduction failure, and a script in one of the other three groups keeps it from being green. Calls that need a screen, which the run does not have (dev.print(), dev.copy2pdf(), dev.copy2eps(), savePlot(), windows(), win.graph(), x11(), quartz(), View()), are replaced before the run by calls that need none, which modifications records as screen_call_replaced. Dependencies are reported name-only, with the source (CRAN, GitHub, or a base package already shipped with R) — static analysis of the code cannot know which version was used, and running against current package versions is itself informative: a break argues the authors should have pinned versions. Abstract

Relapse of fear-related symptoms after exposure-based treatment remains a major challenge across anxiety disorders. One potential explanation is that extinction learning yields a new memory trace rather than being integrated with the original fear memory, allowing fear to resurface. Building on recent research in rodents, we tested whether gradually reducing the intensity of the unconditioned stimulus (US) during extinction attenuates the return of fear in humans by promoting the integration of extinction learning into existing fear memories. Using a two-day fear-conditioning paradigm, 60 participants underwent differential fear acquisition, in which one stimulus (conditioned stimulus, CS+) was paired with an aversive electric stimulation (US), while another stimulus (CS-) was never paired. Participants were then randomly assigned to either classic extinction (CE), in which no US was delivered, or gradual extinction (GE), in which the US intensity was progressively reduced across blocks. On the second day, fear memory was assessed using spontaneous recovery and reinstatement tests. Subjective fear ratings and heart rate responses were comparable between extinction procedures. In contrast, during spontaneous recovery, electrodermal responses were larger in the CE group than in the GE group, with heightened responses to both CS+ and CS-. Overall, our findings provide partial support for the translation of gradual extinction effects observed in animal models to humans. While effects differed across response systems, the attenuated electrodermal recovery following gradual extinction suggests that progressively reducing US intensity to minimize prediction errors may alter the subsequent expression of fear memories. These findings highlight gradual US-intensity reduction as a promising translational approach for investigating mechanisms underlying fear relapse in humans.

1. Introduction

The survival of both humans and animals depends on the ability to learn and retain associations between environmental events. Such associations, once stored in memory, allow past experiences to guide predictions about biologically relevant future events, thereby enabling adaptive behavioral responses. For instance, when organisms encounter a cue that has previously signaled the presence of a predator, they instinctively engage in defensive responses that increase their chances of avoiding the impending threat and, in turn, to survive. However, in a constantly changing world, previously learned associations may no longer be reliable in the current context. In such cases, new information needs to be integrated with existing knowledge. One possibility is that new learning directly updates existing memory representations. Alternatively, new information may be stored separately, leading to multiple memory traces that compete with each other (Borgomaneri et al., 2021; Milad & Quirk, 2012; Raskin & Monfils, 2023).

Influential theories on learning propose that the prediction error, defined as the discrepancy between expected and actual outcomes, is a fundamental computational signal driving learning and memory updating (Gershman et al., 2017; Pearce & Hall, 1980; Rescorla & Wagner, 1972). Beyond determining the extent of associative change, prediction errors may also regulate whether new experiences are integrated into an existing memory representation or assigned to a newly formed memory trace (Alberini & Ledoux, 2013; Gershman et al., 2010 Gershman et al., , 2013 Gershman et al., , 2017)).

In this context, fear conditioning provides one of the most widely used experimental models for investigating these processes across species (Haaker et al., 2019) . In a typical design, an initially neutral stimulus (e.g., a tone or picture) is repeatedly paired in close temporal proximity and contingent association with an aversive unconditioned stimulus (US, e.g., electric stimulation). As a result, the previously neutral stimulus becomes a conditioned stimulus (CS) and acquires the ability to elicit defensive responses (conditioned responses, CRs) that were previously evoked only by the US (Lonsdorf et al., 2017). Conditioned responses can be reduced through fear extinction, a procedure in which the CS is repeatedly presented alone (Milad & Quirk, 2012; Quirk & Mueller, 2008). As the expected aversive outcome no longer occurs, CRs progressively decline in strength and frequency. Importantly, evidence indicates that extinction does not erase the original CS-US association (Bouton, 2002). Rather, extinguished fear responses can re-emerge following the passage of time (spontaneous recovery), unsignaled re-exposure to the US (reinstatement), or testing outside the extinction context (renewal) (Bouton & Moody, 2004; Craske et al., 2014; Haaker et al., 2014; Milad et al., 2007 Milad et al., , 2009)). These phenomena indicate that extinction primarily reflects new inhibitory learning that coexists and competes with the original fear memory (Bouton, 2002 (Bouton, , 2004)). The acquisition and extinction of conditioned responses have traditionally been explained by classical learning models that place prediction errors at the core of associative change.

According to influential computational models, such as the Rescorla-Wagner or Pearce-Hall models, learning is driven by the discrepancy between the expected and actual outcomes, such that larger prediction errors produce greater changes in associative strength (Pearce & Hall, 1980; Rescorla & Wagner, 1972). During fear acquisition, unexpected US presentations progressively strengthen the CS-US association, whereas during extinction, the omission of the expected US generates a negative prediction error that drives new inhibitory learning.

While classical models provide a powerful account of how prediction error drives changes in associative strength, they are less informative about how newly acquired information is organized in relation to existing memory traces. More recent latent-state models extend the classical associative framework by proposing that prediction errors not only regulate learning but also determine the memory state to which new experiences are assigned (Cochran & Cisler, 2019; Gershman et al., 2010 Gershman et al., , 2017)). Specifically, when new experiences are sufficiently similar to previous ones and generate relatively small prediction errors, they are integrated into the same latent state, resulting in the updating of existing memory representations. Conversely, large prediction errors signal a substantial change in the environment and promote the inference of a new latent state, allowing new information to be encoded separately while preserving the original memory. In the case of extinction, the abrupt omission of an expected US generates a large prediction error, signaling a significant deviation from the previously learned CS-US contingency.

When this discrepancy is sufficiently large, the organism may infer that the current experience belongs to a distinct latent state, a process referred to as state-splitting (Gershman et al., 2017). Consequently, the observed change in environmental contingencies may be encoded in a separate memory representation. As a result, the original CS-US association may remain intact, providing a potential mechanism for the later return of fear (RoF) following extinction. Critically, latent-state models make the opposite prediction when changes in the environment generate only small prediction errors. If the discrepancy between expected and actual outcomes is progressively reduced, new experiences should remain assigned to the original latent state, allowing new information to directly update the existing memory representation rather than being encoded in a separate competing memory.

Building on these theoretical accounts, recent research has focused on gradual extinction procedures designed to minimize prediction errors and thereby promoting the updating of the original fear memory (Quintero et al., 2024). This possibility is particularly relevant from a clinical perspective, as fear extinction is widely considered a laboratory model of exposure therapy (Craske et al., 2014). Although these interventions are effective, their long-term efficacy can be undermined by RoF following successful treatment (Boschen et al., 2009; Vervliet, Baeyens, et al., 2013; Vervliet, Craske, et al., 2013). Thus, gradual extinction procedures that have the potential to update the original fear memory with information about reduced threat may represent a promising therapeutic approach to reduce the relapses and thereby improve the long-term durability of exposure-based interventions.

Empirical attempts to test this theoretical rationale predominantly relied on occasional reinforced extinction procedures, in which occasional CS-US pairings are retained during extinction to manipulate the probability of US occurrence. Across studies, occasional reinforced extinction procedures has been examined using heterogeneous reinforcement schedules, outcome measures, and tests of fear recovery, yielding mixed findings (Culver et al., 2018; Lipp et al., 2021; Morís et al., 2017; Quintero et al., 2022; Shiban et al., 2015; Thompson et al., 2018; Wang et al., 2024).

While some studies reported beneficial effects on specific indices of spontaneous recovery or reinstatement, others failed to replicate these effects, with the most consistent evidence favoring a slowing of rapid reacquisition rather than a general reduction in RoF (Quintero et al., 2024). Thus, despite substantial methodological heterogeneity, previous human studies share a common approach: prediction errors have been manipulated primarily by varying the probability of US occurrence during extinction, resulting in a non-monotonic trajectory of prediction errors over the course of extinction. Recently, Kennedy and colleagues (2024) adopted a conceptually distinct approach in rodents, manipulating the intensity rather than the probability of the US. Following fear acquisition, shock intensity was progressively reduced across successive extinction sessions until the CS was eventually presented alone. Using freezing as an index of conditioned fear, this gradual extinction procedure reduced spontaneous recovery and reinstatement compared to classic extinction. Consistent with latent-state accounts, the authors proposed that a series of small prediction errors generated by the progressive reduction of US intensity prevented state splitting, allowing acquisition and extinction experiences to be encoded within a common memory state.

However, whether gradually reducing US intensity can similarly decrease RoF in humans remains unknown. To date, no human study has directly tested the effects of an intensity-based gradual extinction procedure on the persistence of conditioned fear. The present work addresses this gap by translating the gradual US-intensity reduction approach introduced by Kennedy et al. (2024) to humans. To this aim, we employed a two-days differential fear conditioning paradigm in which participants first acquired a conditioned defensive response and subsequently underwent either a classic or a gradual extinction procedure involving a progressive reduction in US intensity, closely following the procedure used in the animal study. On the next day, fear memory was assessed using spontaneous recovery and reinstatement tests. Defensive responses were evaluated across multiple domains, including subjective ratings and autonomic indices. We hypothesized that progressively reducing US intensity during extinction would reduce the likelihood of state splitting, thereby favoring the integration of acquisition and extinction experiences within a common memory representation. Accordingly, we expected gradual extinction to confer greater protection against RoF than classic extinction during both spontaneous recovery and following reinstatement.

2. Methods

All hypotheses, methods, and analyses for this study were preregistered on the Open Science Framework (https://osf.io/x7qmk). Aggregated data and analysis codes are publicly available (https://tinyurl.com/gemexp).

2.1. Participants

The pre-registered sample size was set at 60 participants, based on previous human studies using comparable experimental designs with manipulations of CS-US contingency (Shiban et al., 2015; Thompson et al., 2018; Wang et al., 2024), with approximately 30 participants allocated to each experimental group to ensure an equal distribution. A total of 61 participants were recruited. One participant was excluded due to technical issues during data collection, resulting in a final sample of 60 participants, evenly distributed between a classic extinction (CE) group (21 female, M = 25.23 years, SD = 4.80, range = 20-40), and a gradual extinction (GE) group (21 female, 1 diverse, M = 25.6 years, SD = 4.76, range = 20-39). All participants were older than 18 years and had normal or corrected to normal vision (with contact lenses only). None of the participants reported current or previous pain-related disorders. Further exclusion criteria included self-reported current or previous neurological or psychiatric disorders, as well as current use of psychopharmacological or analgesic medication. The participants provided written informed consent prior to participation and received either course credit or monetary compensation of 12.5 € per hour. The experiment was approved by the ethics committee of the University of Würzburg (GZEK 2025-13) in accordance with the recommendations of the Declaration of Helsinki.

2.2. Stimuli and Apparatus

Two blue colored geometrical shapes (square and diamond, see Figure 1) were used as conditioned stimuli (CS+ and CS-). The assignment of shapes to CS type was counterbalanced across participants.

The unconditioned stimulus (US) consisted of an electrotactile stimulation delivered to the medial side of the forearm of the non-dominant hand using a DS7A stimulator (Digitimer). The stimulation comprised a train of three 2-ms square-wave pulses separated by 50 ms. Prior to the experiment, the stimulation intensity was individually calibrated for each participant to elicit an unpleasant, moderately painful sensation, corresponding to a rating of 6 on a numerical rating scale ranging from 0 ("no pain") to 10 ("unbearable pain"). The subjective pain threshold obtained was used during the acquisition phase and served as the reference intensity for the gradual reductions applied during extinction in the GE group (see below). The experiment was programmed using PsychoPy (version 2024.2.4) and presented on a 24-inch Asus VG248QE display (53.136 × 29.889 cm, 1920 × 1080 pixels, 60 Hz refresh rate). Electrodermal activity (EDA) and an electrocardiogram (ECG) were recorded using a BIOPAC MP160 system (BIOPAC Systems, Inc.) at a sampling rate of 1000 Hz. The ECG was acquired using three Ag/AgCl electrodes placed over the right sternum and the lower left and right ribcage. For EDA, the skin was first washed with lukewarm water (Nebe et al., 2023) before attaching two Ag/AgCl electrodes filled with 0.05 ml NaCl electrolyte to the thenar and hypothenar eminences of the participants' non-dominant hand.

Eye-tracking data were recorded from the right eye using an EyeLink 1000 Plus system (SR Research Ltd., Ottawa, Canada) configured in tower-mount mode and sampling at 1000 Hz. Before the experiment, a standard 9-point calibration and validation procedure was performed. A summary of pupil dilation preprocessing and results is available in Supplementary Materials.

2.3. Procedure

The experiment was conducted over two consecutive days and consisted of five phases: habituation, acquisition, extinction, spontaneous recovery, and reinstatement (Figure 1). Extinction Stage 1 comprised the first three blocks, during which US intensity was progressively reduced in the GE group, while Extinction Stage 2 consisted of a final unreinforced block for both groups. On Day 2, fear memory was assessed via spontaneous recovery and reinstatement tests.

On Day 1, participants completed the habituation, acquisition, and extinction phases.

During the habituation phase, the CS+ and CS-were each presented twice in a pseudo-random order without delivery of the US. The acquisition phase was characterized by two identical blocks of eight trials (four CS+ and four CS-trials per block). The CS+ was paired with the US on every presentation (100% reinforcement rate), whereas the CS-was never followed by the US.

Participants were then randomly assigned to either the classic extinction (CE) group or the gradual extinction (GE) group. The extinction phase consisted of four blocks, each comprising eight trials (four CS+ and four CS-). Importantly, the extinction phase differed between the two groups. In the GE group, the CS+ remained paired with the US during the first three extinction blocks (100% reinforcement rate), while the intensity of the US was gradually reduced to 50%, 25%, and 12.5% of the calibrated intensity across the first, second, and third blocks, respectively. During the fourth extinction block, no US was delivered. This procedure was designed to closely align with the gradual extinction protocol recently applied in animal models, preserving its core feature of progressively reducing US intensity across extinction (Kennedy et al., 2024). In contrast, participants in the CE group underwent a classic extinction procedure in which the CS+ was not paired with the US throughout the entire extinction phase.

Twenty-four hours later, on Day 2, participants completed the spontaneous recovery and reinstatement phases. During spontaneous recovery, the CS+ and CS-were presented four times each without the US. Although no electrotactile stimulation was delivered during this phase, the stimulation electrodes were attached. During the reinstatement phase, participants first received three unsignalled US presentations, separated by a 1-s interstimulus interval, while viewing a grey background. The US intensity was identical to that used during acquisition. Subsequently, the CS+ and CS-were each presented four times without the US.

Across all phases, each trial consisted of an 8-s presentation of either the CS+ or the CS-.

When delivered, the US occurred at CS+ offset and was never presented following the CS-. The inter-trial interval (ITI) varied randomly between 7 and 9 s (uniform distribution), during which a fixation cross was displayed at the center of the screen. During extinction, a 20-s interval was introduced between consecutive blocks in both groups, during which participants viewed a grey background with a fixation cross, as in an extended ITI. During this interval, the experimenter manually adjusted the US intensity according to the level scheduled for the subsequent block in the GE group. On Day 2, a 20-s interval followed the spontaneous recovery phase before the unsignalled US presentations, and another 20-s interval followed the third unsignalled US before the subsequent CS presentations during the reinstatement phase. Trial order was pseudorandomized, such that no more than two consecutive trials featured the same condition. At the end of each experimental phase (habituation, acquisition, extinction, spontaneous recovery, and reinstatement), participants completed subjective ratings of perceived threat and shock expectancy for both the CS+ and CS-. Perceived threat was assessed using the question, "To what extent do you perceive this stimulus threatening?", and shock expectancy using the question, "How likely is it that an electric stimulation will be presented after this stimulus?". The two questions were presented separately alongside each stimulus, and both ratings were provided on separate 9-point Likert scales ranging from 1 to 9 (1 = not aversive/no shock,5 = uncertain,9 = aversive/shock). At the conclusion of the experiment, participants completed the German versions of the State-Trait Anxiety Inventory (STAI; Laux et al., 1981)

2.4. Data Pre-processing 2.4.1. Electrodermal Activity (EDA)

Across all experimental phases, event onsets were derived from digital trigger markers sent by the experimental script, and all analyses were time-locked to these onsets. The raw EDA signal was downsampled to 20 Hz and smoothed with a second-order low-pass Butterworth filter (2-Hz cutoff) using zero-phase filtering. Skin conductance responses (SCR) amplitudes were defined as the difference (in μS) between the response onset (1-4 seconds after stimulus onset) and the maximum response peak (Boucsein, 2012). Trials in which no SCR onset could be identified were coded as zero for subsequent analyses (58.5% ± 16.4) Trial-level data were square-root transformed and then averaged within each condition prior to statistical analyses.

2.4.2. Electrocardiogram (ECG)

The ECG recordings were high-pass filtered at 2 Hz using a second-order Butterworth filter to reduce slow drifts. R-peaks were then identified using an amplitude-based semiautomatic detection procedure and manually corrected where required to account for artifacts due to extrasystoles or conspicuously altered cardiac complexes. Heart rate (HR) was subsequently calculated in beats per minute (bpm) from the resulting R-R intervals. Baseline correction was performed by subtracting the mean HR during the final second preceding stimulus onset (-1 to 0 s) from each subsequent HR measurement, thereby accounting for individual differences in tonic HR. Baseline-corrected HR responses were calculated in consecutive 500-ms bins from stimulus onset over the 8-s period following stimulus onset using a real-time scaling procedure. For statistical analyses, baselinecorrected HR responses were averaged across 4-8 s post-stimulus interval (Merscher et al., 2022).

The same preprocessing procedure was applied to data collected on both experimental days.

2.5. Statistical Data Analysis

Statistical analyses were performed in R (version 4.4.2). Separate mixed-design analyses of variance (ANOVAs) were conducted for each experimental phase (acquisition, extinction, spontaneous recovery, and reinstatement) using the afex package (Singmann et al., 2025).

Depending on the experimental phase, Group (CE, GE) served as a between-subjects factor, whereas Stimulus (CS+, CS-) and, where applicable, Block were included as within-subject factors.

The a priori significance level was set to α = .05 for all statistical tests. For analyses involving within-subject factors with more than two levels, Huynh-Feldt correction was applied where appropriate, and effect sizes are reported as partial eta squared (𝜂 𝑝 2 ) together with their 95% confidence intervals calculated with the effectsize package (Ben-Shachar et al., 2020). Significant effects were followed by t-test post hoc comparisons.

To further examine changes in conditioned responses across experimental days, separate mixed-design ANOVAs were conducted by comparing the final extinction block on Day 1 with the spontaneous recovery and reinstatement phases on Day 2.

4. Discussion

The goal of the present study represents the first attempt to translate an intensity-based gradual extinction procedure from rodents to human fear conditioning. Rather than manipulating the probability of US occurrence, as typically done in occasionally reinforced extinction procedures (Quintero et al., 2024), we progressively reduced US intensity across extinction learning blocks before eventually omitting the US, closely following a recently developed protocol in rodents (Kennedy et al., 2024). The key advantage of this approach is that prediction errors are monotonically reduced throughout the extinction procedure, potentially reducing the likelihood of state splitting and thereby favoring the integration of acquisition and extinction experiences within a common memory representation. To examine whether this prediction error manipulation influenced the organization of fear memories, participants underwent either standard or gradual extinction on the first day and were tested 24 h later using spontaneous recovery and reinstatement procedures. According to latent-state models (Cochran & Cisler, 2019; Gershman et al., 2017), gradually reducing US intensity was expected to minimize prediction error during extinction, thereby promoting the assignment of acquisition and extinction experiences to a common latent state rather than separate competing memory representations. Consequently, we predicted that gradual extinction would reduce RoF during memory tests. Contrary to our expectations, the findings provided only partial support for our prediction. While subjective ratings and heart rate responses did not differ between groups during memory tests, SCR revealed a different pattern.

Although electrodermal activity increased from the last extinction block to spontaneous recovery in both groups, this increase was larger following standard than gradual extinction. Therefore, participants who underwent classic extinction exhibited a stronger defensive activation during the spontaneous recovery compared to the GE group. This evidence supports the notion that gradually reducing US intensity during extinction may have attenuated state splitting between acquisition and extinction and consequentially reduced RoF in GE group. However, this pattern was not consistent across outcome measures as well as experimental phases and was absent following reinstatement.

A key prerequisite for interpreting the effects of our manipulation is that both groups acquired the conditioned threat association successfully. This was consistently reflected across all response measures, with higher ratings, greater electrodermal responses and a stronger heart rate deceleration for the CS+ compared to the CS-, indicating that fear conditioning was evident across subjective, sympathetic and parasympathetic systems (Battaglia et al., 2024; Lonsdorf et al., 2017).

The extinction phase provided the first opportunity to evaluate the effects of gradual extinction manipulation. At the end of extinction, electrodermal responses no longer differentiated between the CS+ and CS-in either group, indicating successful physiological extinction. Explicit ratings showed a similar, although not identical, pattern. Participants in the GE group reported higher CS+ perceived threat and US expectancy ratings compared to those in the CE group, which is consistent with the nature of the manipulation: participants in the GE group continued to receive US presentations during extinction. Although US intensity gradually decreased across blocks, receiving a less aversive US may still be more aversive than receiving no US at all. Importantly, however, the magnitude of the CS+/CS-difference was reduced relative to acquisition in both groups, indicating that extinction learning had nevertheless occurred. These findings are particularly relevant in the context of previous human studies using on occasional reinforced extinction procedures (Quintero et al., 2024), in which the degree of extinction achieved before fear memory testing has varied considerably. While some studies reported complete extinction of conditioned responses before assessing fear recovery (Shiban et al., 2015; Thompson et al., 2018), others observed persistent differential responses at the end of extinction and consequently interpreted their memory-test findings more cautiously (Culver et al., 2018; Lipp et al., 2021; van den Akker et al., 2015; Wang et al., 2024). Our results suggest that gradually reducing US intensity may represent an alternative approach of introducing a gradual reduction of prediction errors while still allowing robust extinction learning before subsequent memory tests.

The memory tests on Day 2 showed a mixed pattern across the different dependent measures. Electrodermal responses revealed a selective effect of gradual extinction during spontaneous recovery. When comparing the last block of extinction with the spontaneous recovery we observed that the CE group showed greater electrodermal response to both CSs compared to GE. Moreover, visual inspection of the trial-by-trial response profile suggested that the CE group showed a differential response between CS+ and CS-during the first spontaneous recovery trial compared to GE group. Although these observations should be interpreted cautiously, they are consistent with the hypothesis that gradually reducing US intensity during extinction may have limited the formation of a separate extinction memory, thereby promoting the integration of acquisition and extinction experiences within a common latent state (Cochran & Cisler, 2019; Gershman et al., 2017). These results differ from the findings of Shiban et al. (2015), who implemented a probability-based gradual extinction procedure originally proposed by Gershman et al. (2013) but observed no reduction in electrodermal fear recovery despite successful extinction before the test (Gershman et al., 2013; Shiban et al., 2015). In contrast, our findings are more closely aligned with those of Thompson et al. (2018), who reported attenuated spontaneous recovery of electrodermal responding following an occasionally reinforced extinction procedure in which intermittent CS-US pairings were retained during extinction (Thompson et al., 2018).

Importantly, in contrast to this previous study, we evaluated fear recovery 24 hours later, thereby examining the effects of gradual extinction on the expression of consolidated fear memory (Dudai, 2004) rather than on immediate post-extinction performance (Thompson et al., 2018). Notably, this effect was specific to spontaneous recovery and was no longer evident following reinstatement, consistent with the pattern reported by Thompson and colleagues. This pattern can be explained by a re-extinction during the spontaneous recovery phase. The number of preceding non-reinforced CS presentations during the spontaneous recovery test may have weakened the impact of the reinstatement manipulation, thereby reducing the likelihood of detecting group differences (for a review on reinstatement research, see Haaker et al., 2014). Nevertheless, electrodermal activity was overall higher during reinstatement than during the final extinction block, indicating a generalized increase in autonomic arousal despite the absence of differential recovery between groups.

Interestingly, a dissociation between autonomic and explicit measures emerged during the memory tests on Day 2. Subjective ratings did not differ between groups during either spontaneous recovery or reinstatement. These findings highlight, on the one hand, the absence of the expected spontaneous recovery effect in the classic extinction group and, on the other hand, that the continuous exposure to progressively weaker shocks did neither lead to a reduced nor to a more pronounced fear relapse, as both extinction procedures resulted in comparable subjective evaluations during the memory tests. It is important to note that unlike previous studies, which assessed ratings trial by trial (Culver et al., 2018; Morís et al., 2017; Quintero et al., 2022; Thompson et al., 2018; van den Akker et al., 2015; Wang et al., 2024), we collected explicit responses only at the end of each experimental session. In this scenario, the absence of group differences during the spontaneous recovery and reinstatement tests may partly reflect the fact that participants had already undergone several non-reinforced CS presentations before providing their ratings, allowing new extinction learning to occur and potentially reducing the sensitivity of these measures to detect early fear relapse. This choice was intended to more closely match the procedure of animal research (Kennedy et al., 2024) and avoid potential influences of repeated online expectancy judgments on the learning process itself, as recent evidence suggests that trial-by-trial expectancy ratings can alter associative learning and physiological responses (Atlas et al., 2022).

Future studies should directly compare trial-by-trial and end-of-phase expectancy assessments in gradual extinction paradigms to determine whether repeated online ratings influence extinction learning and subsequent fear memory expression.

Beyond these findings, heart rate response profiles deserve separate consideration. Unlike electrodermal activity, HR did not reveal differences between extinction procedures during either spontaneous recovery or reinstatement. This finding may be explained by at least two factors. First, the relatively small number of trials during the Day 2 memory tests may have limited the emergence of robust stimulus-specific cardiac responses. Second, heart rate responses failed to extinguish in either group, with participants continuing to show greater cardiac deceleration to the CS+ than to the CS-across the extinction phase. Consequently, the absence of group differences during the subsequent memory tests should be interpreted with caution, as differential cardiac responding was still present before spontaneous recovery and reinstatement were assessed. Nevertheless, the persistence of heart rate bradycardia to the threat stimulus during extinction represents an interesting observation that extends beyond the primary aim of the present study. To our knowledge, although heart rate has frequently been used to characterize fear acquisition (Battaglia et al., 2024), relatively little attention has been devoted to its dynamics during extinction learning. Moreover, our work represents the only one assessing cardiac responses in the context of gradual extinction manipulations (for a review see, Quintero et al., 2024).

Overall, the present findings should be considered within a growing but heterogeneous body of translational studies investigating gradual extinction procedures. Studies implementing probability-based gradual extinction protocols remain relatively few and differ substantially in their methodological characteristics, including reinforcement schedules, outcome measures, and the specific fear recovery tests employed (Dunsmoor et al., 2018; Morís et al., 2017; Quintero et al., 2022; Shiban et al., 2015; Wang et al., 2024). Following the seminal work of Gershman et al. (2013), which introduced a probability-based gradual extinction protocol in rodents, several human studies have attempted to translate this approach, yielding mixed and often inconsistent findings (Quintero et al., 2024). Collectively, these studies can be contextualized within a broader class of extinction protocols that maintain occasional CS-US pairings during extinction. Despite their methodological differences, however, a stable consensus regarding the effectiveness of these approaches has yet to emerge (Quintero et al., 2024). Part of this inconsistency may arise from the fact that two main approaches have been adopted: gradually reducing reinforcement probability or maintaining occasional fixed reinforcements during extinction. Importantly, both strategies preserve a constant US intensity. Regardless of their specific implementation, these procedures may share a hidden theoretical and practical contradiction. Although maintaining occasional reinforced CS-US pairings during extinction is intended to prevent the inference of a new latent state (Morís et al., 2017; Quintero et al., 2022; Shiban et al., 2015; Wang et al., 2024) or to augment the strength of extinction (Bouton et al., 2004; Culver et al., 2018; Lipp et al., 2021; Thompson et al., 2018; van den Akker et al., 2015), occasional presentations of full-intensity USs do not result in a trajectory of monotonically decreasing prediction errors and thereby may even strengthen or stabilize the original acquisition memory (Chan & Harris, 2019). Consistent with this interpretation, occasionally reinforced CS+ presentations are frequently incorporated into fear generalization paradigms during the test phase precisely to prevent extinction and preserve the original conditioned association (Lissek et al., 2008; Stegmann et al., 2019).

Furthermore, the present findings should also be interpreted within the broader framework of translational research (Haaker et al., 2019). The gradual extinction procedure employed here was directly inspired by the recent series of rodent experiments by Kennedy and colleagues (2024), which consistently demonstrated that progressively reducing US intensity protects against subsequent fear recovery by promoting memory updating rather than state splitting. However, translating this protocol from rodents to humans inevitably introduces methodological differences that may have contributed to the less consistent effects observed in the present work (Bach, 2022; Haaker et al., 2019). First, the temporal structure of the protocol differed substantially. In the animal experiments, acquisition, gradual reduction of US intensity, and subsequent memory tests were distributed across several days, whereas in the present study, acquisition and extinction occurred within a single experimental session, with gradual extinction implemented across successive blocks, followed by memory tests on the following day, as is commonly done in human studies (Anderson et al., 2026). Second, unlike animal studies in which all subjects receive the same absolute US intensity, ethical constraints require individualized calibration in humans.

Consequently, a 50% reduction in physical stimulation may have generated substantially different subjective prediction errors across participants. For some individuals, the first reduction may have remained clearly perceptible, whereas for others it may already have approached perceptual threshold. Because the theoretical rationale of gradual extinction depends on maintaining a sequence of small but detectable prediction errors, such interindividual variability may have reduced the effectiveness of the manipulation. Finally, despite growing efforts to characterize freezing-like defensive responses in humans, establishing a direct human counterpart to rodent freezing remains challenging (Blanchard, 2017; Roelofs, 2017; Roelofs & Dayan, 2022; Rösler & Gamer, 2019; Stegmann et al., 2024). As a result, the autonomic measures typically employed in human fear-conditioning studies, including SCR and heart rate, capture only partially overlapping aspects of defensive responses and cannot be regarded as direct translational equivalents of the behavioral endpoint used in animal experiments. This methodological gap continues to represent a major challenge for translating mechanistic findings across species (Haaker et al., 2019).

Taken together, these observations emphasize the methodological challenges involved in faithfully translating animal protocols into humans. Future studies should therefore focus on optimizing the implementation of gradual US reduction to better preserve the theoretical principles underlying this approach. Particularly, it will be important to develop calibration procedures ensuring that progressively weaker US presentations remain consciously detectable while still eliciting only small prediction errors across individuals. Direct assessment of participants' subjective perception of the reduced US throughout extinction may also help determine whether the intended gradual re-evaluation of the US is successfully achieved without introducing large expectancy violations. More broadly, future work should investigate whether alternative schedules of US reduction, different step sizes, or adaptive participant-specific procedures can further improve the effectiveness of intensity-based gradual extinction. Finally, it will also be important to determine whether the temporal structure of the protocol should more closely resemble that used in animal studies. Specifically, distributing gradual US reductions across multiple days rather than within a single extinction session may differentially influence consolidation processes and, consequently, the later expression of aversive memories. Such refinements may help clarify the conditions under which intensity-based gradual extinction promotes updating of the original threat memory while minimizing state splitting.

In conclusion, the present study represents the first attempt to translate an intensity-based gradual extinction protocol from animal models to humans. Beyond its translational significance, this approach provides a novel framework for investigating the mechanisms underlying the formation, updating, and expression of emotional memories. Although our data provide only partial support for our hypotheses, we propose that modulating prediction errors through gradual reduction of US intensity may overcome some of the limitations associated with probability-based gradual extinction procedures. Specifically, this methodology preserves the deterministic occurrence of the US while successively and monotonically reducing its aversive value and, consequently, the prediction error across the extinction procedure. In doing so, it may facilitate the updating of the original threat memory while reducing the likelihood of assigning extinction to a separate latent cause. This possibility is particularly intriguing given recent evidence suggesting that prediction errors can encode violations in specific features of expected outcomes rather than merely signaling whether an outcome occurred, thereby supporting associative learning beyond value alone (Kahnt & Schoenbaum, 2025). Ultimately, advancing our understanding of these processes may inform the development of more effective interventions for psychopathologies characterized by maladaptive expression of fear memories.
