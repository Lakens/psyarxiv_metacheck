Reporting p values imprecisely (e.g., p < .05) reduces transparency, reproducibility, and re-use (e.g., in p value meta-analyses). Best practice is to report exact p-values with three decimal places (e.g., p = .032) unless p values are smaller than 0.001, in which case you can use p < .001.

To check Non-Significant P Value Check

What we found

We found 24 non-significant p values that should be checked for appropriate interpretation.

Show details

Meta-scientific research has shown nonsignificant p values are commonly misinterpreted. It is incorrect to infer that there is ‘no effect’, ‘no difference’, or that groups are ‘the same’ after p > 0.05.

It is possible that there is a true non-zero effect, but that the study did not detect it. Make sure your inference acknowledges that it is possible that there is a non-zero effect. It is correct to include the effect is ‘not significantly’ different, although this just restates that p > 0.05.

The Power Analysis Check module uses regular expressions to identify sentences that contain a statistical power analysis. The module only returns Statcheck results for t-tests and F-tests, as these are the only tests which have been validated, see https://osf.io/preprints/psyarxiv/tcxaj_v1/.

Statcheck considers p = 0.000 an error, as you should report p < 0.001. Furthermore, p < 0.03 is an error if the p-value was 0.031, and one should simply report exact p-values (p = 0.031). When the sentence of a test says it is one-sided (“one-tailed”, “one-sided” or “directional”), a p-value that fits a one-sided test counts as consistent (statcheck’s OneTailedTxt setting; #695). A statistic written with “<” or “>” is read as a bound, and in a sentence about equal variances an F-test’s two-sided p (twice the one-tailed p) counts as consistent. How Exact P-Values works

List any p-values reported with insufficient precision (e.g., p < .05 or p = n.s.), reported as exactly zero (e.g., p = .000), or impossible (below 0 or above 1, e.g., p = -.22).

This module uses regular expressions to identify p-values. It will flag any values reported as p > ? or p < numbers greater than .001. It will also flag p-values reported as exactly zero (e.g., p = .000, p = 0.00), which are mathematically impossible — p-values are never exactly zero and should instead be reported as p < .001.

A p-value that is not the result of a test is not flagged: a table note (“* p < .05, ** p < .01”), a figure legend (“Asterisks indicate significant differences (p < .05)”, “Values in bold are significant at p < .05”) or a stated threshold (“p < .05 was considered significant”, “thresholded at p < .001”). GROBID often puts such notes into the running text, so each p-value is judged by the words in its own clause (the text up to a “;” or a full stop), and never left out when a test statistic belongs to it (“F(1, 7) = 8.03, # p < .05”). The column not_a_test of the table says why a p-value was left out (“marker”, “threshold”, “legend” or “named”).

A p-value with the name of a correction or a test after the p (“pFWE < .05”, “padj < 0.05”, “p Wilcoxon = .02”) is flagged only when a test statistic comes before it in its clause (“t(37) = 7.17, p FWE < .05”). Without one it is mostly the rule that decided what was significant (“genes with padj < 0.05 were selected”); such a p-value is “named” in not_a_test. Notes in other forms, such as a marker after the p-value (“p < .05 (*)“), are still flagged.

A p-value below 0 or above 1 is impossible; it is listed apart and not also as imprecise. Often the statistic before it, or its minus sign, was copied into it (“t(134) = -2.32, p = -.13”, “Z = 3.091, P = 3.091”). A value above 1 is listed only after a test statistic in its clause: without one, a “P” above 1 was nearly always another quantity (a proportion, pH, a group’s mean, a model parameter). A number in scientific notation whose power of ten was lost when the PDF was read (“p = 2.4 x 10 -9” read as 2.4) is not listed. A “p” that is the subscript of another symbol (“r p = .64”, “²p = .02” for partial eta squared, “Δp = .33”), or a quantity with a unit, a logarithm or a ratio (“P = 2.9 µm”, “-log10 P = 7.5”, “Ca/P = 1.67”), is not read as a p-value at all (see extract_p_values()). Each p-value has its own row, also when the same one is written twice in a sentence.

This module sometimes flags false positives when sentences discuss how p-value thresholds were set. It can also miss an imprecise p-value that is reported against a threshold (“decreased at the p < .05 significance threshold”).

This module only checks p-values reported in the running text of the manuscript. It cannot (yet) process p-values reported only in tables (as opposed to a table’s footnote text, which the module does see and tries to exclude — see above).

This module retrieves information from repositories checked by repo_check about code files (R, Python, SAS, SPSS, Stata, Mplus, MATLAB).

The Code Check module checks R (also R Markdown and Quarto), Python (also Jupyter notebooks), SAS, SPSS, Stata, Mplus, and MATLAB files, using regular expressions to check the code; JASP files are listed but not read. The language of a Quarto document or a notebook is read from the file itself (its engine or kernel), not from its extension. The regular expression search will detect the number of comments, the lines at which libraries/imports are loaded, attempts to detect absolute paths to files, setwd() and install.packages() calls, and lists files that are loaded, and checks if these files are in the repository; R code is also parsed. The module will return suggestions to improve the code if there are no comments, if libraries/imports are loaded in lines further than 4 lines apart, if files that are loaded are not in the repository, if absolute file paths, setwd() or install.packages() are found, and if R code cannot be parsed.

The regular expressions can miss information in code files, or falsely detect parts of the code as a fixed file path. Libraries/imports might be loaded in one block, even if there are more than 3 intermittent lines. The module was tried out internally on papers published in Psychological Science, but has not been formally validated. There might be valid reasons why some loaded files can’t be shared, but the module can’t evaluate these reasons, and always gives a warning.

The module also checks whether the repository pins the R/package versions the analysis actually depended on: an renv.lock file (parsed for the R version and every locked package + its version/source), a sessionInfo()/sessioninfo::session_info() text dump (matched by filename — sessionInfo.txt/session_info.txt and similar, or embedded in a README), or a groundhog::groundhog.library()/checkpoint::checkpoint() date-pin call in the code (a bare library(groundhog)/library(checkpoint) does not count — the pinning call itself must be present). When none of these is found, the report flags it as a reproducibility gap: package versions may drift between when the analysis was run and any later reproduction attempt.

If you want to extend the package to perform additional checks on code files, or make the checks work on other types of code files, reach out to the Metacheck development team.

Checking code requires downloading its file contents. For a paper whose repository is on Dryad, this never succeeds unless a Dryad API key is set: Dryad requires one to download file bytes, even from a fully public dataset (listing the repository’s files does not need one). Without a key, every Dryad-hosted code file is listed but unchecked, and a warning naming Dryad and ?dryad_pat/?dryad_auth is included among the download failures recorded in the manifest.

How Data Check works

This module classifies the files in a repository into semantic types (data, codebook, code, software, output, supplemental, readme, asset, other) and, for tabular data files, extracts each column’s type and summary statistics.

The Data Check module consumes the file list produced by repo_check (or any files added via local_path). Each file is classified with rule-based heuristics layered over metacheck’s file_category() and file_types: file names matching README / codebook patterns win first, then an extension crosswalk, then format-locked extension overrides. For every file classified as tabular data that is available locally, the module reads the file head, describes each column with data_col_facets() and computes summary statistics for numeric columns. Every sheet of a spreadsheet that holds a table is read: a file with several such sheets has its columns under source_file = "file.xlsx [sheet]", and the sheet column names the sheet of any spreadsheet with several sheets; a sheet of notes or a codebook is treated as documentation when the file has another table. Following DDI, a column is described by orthogonal facets rather than a single type: representation (numeric/text/datetime/code — how it is stored), measurement_level (Stevens: nominal/ordinal/interval/ratio), concept (what it measures: reaction_time/age/gender/likert/id/…), role (identifier/measure/condition/timestamp), unit, and a quality state (ok/empty/constant). Qualtrics survey exports are recognised (data_check_is_qualtrics()): their extra header rows are stripped so columns type correctly, and the reserved response-metadata columns (StartDate, Duration, Finished, …) are tagged.

The module defaults to rules-only when llm_use(FALSE): columns the rules cannot resolve (ambiguous 3–20-unique integers, ambiguous character columns) fall back to continuous / text respectively. When llm_use(TRUE), ambiguous columns and unresolved file types (other) are sent to llm() for optional refinement, and every file is assigned a study group (ex1, pilot2, shared, …) so that multi-study repositories can be recognised (used by psychds_check). Without an LLM the study group is left NA (unknown).

Column extraction requires files to be readable from disk. Files fetched by repo_check from OSF/GitHub/etc. without a local copy (file_location is NA) are classified but not column-extracted; pass local_path to point at a downloaded copy of the repository.

Without a key, every Dryad file stays classified but un-downloaded, column_n is 0, and a warning naming Dryad and ?dryad_pat/?dryad_auth is included among the download failures. A one-time session message is also shown (see repo_check) the first time a Dryad dataset is encountered with no key set.

Every downloaded text file the authors wrote (code, settings, survey definitions such as Qualtrics .qsf files, documentation, outputs) is searched for keys: API keys, access tokens and private keys, which let anyone who downloads the file use a paid service at the authors’ cost. How Reproducibility Check works

This module assesses whether a paper’s R and Python code can be run on its data. It works in two phases. The static phase (always run) collects the package dependencies the code declares, rewrites the data-file paths that do not work in the repository as the authors organised it, works out the order the scripts must run in, and diagnoses why any referenced input file is unavailable — reporting what a reproduction attempt would involve and where it is likely to break. The execution phase (opt-in, execute = TRUE) then actually runs the code: it copies the repository into a throwaway directory, optionally installs the declared dependencies into a throwaway library, runs each script in order in an isolated subprocess with a per-script timeout, and captures the outcome and full output of each run.

By default (execute = FALSE) the module does not run any code — it performs only static analysis: reading dependencies with the same extractors as code_check, finding the files the code references in the repository, and building a run-order dependency graph. It reports what would be installed and run rather than doing it.

When execute = TRUE, the module additionally runs the downloaded code on your machine — a deliberate, opt-in action gated behind that argument (callr is required for R code). Each script runs in an isolated subprocess so a crash cannot take down the R session; note this isolates crashes, not the filesystem or network. Installs (when install_missing = TRUE) and the throwaway run library never touch your main R library. Each script’s outcome is one of ran_ok, errored, timed_out, dependency_unavailable, not_parsed, run_by_source (an R script another script runs with source(), which is run only inside that script, since on its own it lacks the packages and objects the sourcing script sets up first), run_by_import (a Python file other files import, a module rather than a script, unless it has an if __name__ == "__main__": block), jags_model (a JAGS or BUGS model saved with an R extension, which another script reads) or not_r_content (a file that is not R at all, such as a JSON or HTML dump); these last two are not run and are not failures. python2 marks Python 2 code that was not run. With sandbox = "docker" such code runs with Python 2.7 (option metacheck.docker_image_py2; FALSE turns this off), which modifications records; it is never converted, since that can change results. defines_functions is a file that only defines functions, which is used, not run (table$used_by names the scripts that use it), and not_analysis is a file of software rather than of the analysis: a package’s code, tests, documentation or setup.py, a copy of a tool, a web application, a script a program wrote (table$not_analysis_why says which); neither is run or counted as a script. docker_failed means the container never started, which says nothing about the script, so it keeps the light from being green but does not make it red. needs_a_person is a script that stopped because it asks a person to choose a file or answer a question, or that starts an app, and needs_internet one that stopped because the network is off in a Docker run, or, with internet = TRUE, could not reach what it asked for; download_too_large is a script stopped for downloading more than the limits allow (see internet), and out_of_memory one that, or a program it started (such as a compiler), ran out of the memory each script may use. All four are treated the same way. not_downloaded is a script that stopped on a file the repository lists but that was not downloaded, such as one over max_file_size: it could not be tried, so it is not counted as a script that did not reproduce (summary_table$repro_not_downloaded_n counts them apart). not_read is a file metacheck could not read, so it was not run; the light is then not green, as the file may read and run on another computer, and table$error_message says why, naming a package that is installed but cannot be loaded on the computer that ran the check. empty is a file with nothing in it, which is not run or counted as a script. For a script that did not run through, table$error_message is its error, short (at most 300 characters): the error line of its output, which names a package that is not there, with the address it asked for when it needed the internet, or the time limit it reached; table$reason sorts it into a kind. A timeout means “still running at the cutoff”, not a failure, so raise timeout for legitimately long-running (e.g. Bayesian) scripts. dependency_unavailable means the script’s own package could not be installed from live CRAN, the CRAN Archive, or a named GitHub/URL source — an infrastructure limitation, not a defect in the paper’s code. The full stdout/stderr of every run is kept in the result’s run_results (the report shows it in per-script dropdowns, capped for readability).

Provenance, kept so that a TRACE Research Object (TRO) declaration of the run can be written later from a stored result (metacheck #404; the helpers are in R/provenance.R). Only when code was run (execute = TRUE): * run_results$started_at, run_results$ended_at: when each run of a script started and ended (ISO 8601, UTC, milliseconds); NA for a script that was not started. A script run again in a later pass has the times of its last run. A TRO uses them for each trov:TransparentResearchPerformance. * run_results$exit_status: the exit status of the process that ran the script (0 = ended normally); NA when the process did not report one (a time limit, or Docker failing to start the container). * artifacts: one row per file, with stage (deposit: as downloaded from the repository, hashed from the downloaded file; before_run: the run folder just before the first script ran, after metacheck’s own changes, such as rewritten paths and unpacked archives; after_run: only the files the scripts made (status new), changed (changed) or removed (removed), as an unchanged file is the one listed before the run), path (relative to the run folder, as valid UTF-8, a byte of another encoding written as <xx>), size (bytes), sha256, mime_type (by extension, NA when unknown), source (the file’s address in the repository, for deposit). The package libraries metacheck installs in the run folder are left out, as are metacheck’s own files there (a script’s runner, and the statistical output it writes in statistical_output/). Files metacheck itself copied or made between passes (see modifications, output_copied, file_placed) show in after_run too. A TRO uses the rows as trov:ResearchArtifacts and each stage as a trov:ArtifactArrangement. * modifications$sha256_before, modifications$sha256_after: the hash of the changed script as downloaded and as it ran; NA when the script is not at the same path in both (a script made from an R Markdown file). * environment: the system that ran the code (trov:TransparentResearchSystem in a TRO): metacheck_version, started_at, ended_at, host (R version, platform, operating system), sandbox, network_isolated (TRUE only when every Docker run had --network none; the process sandbox does not stop the network), internet, timeout_per_script, total_timeout, python_local (the Python run outside Docker and its version), and docker: runs (for each kind of run, r_run, r_install, python_run, python_install, the image and the docker run arguments, such as --network none, --read-only, --cap-drop ALL, no-new-privileges, the process limit and the memory and processor limits) and images (for each image, its ID and digests from docker image inspect, its creation time and the R and Python versions its environment declares).

run_results$checked says what the run of each script shows about the code, in five groups, so that a script that does not reproduce is kept apart from one the check could not test: ran (it ran to the end); code_error (it did not reproduce: it stopped with an error of the code or the deposit, could not be read, or needs a file the deposit does not hold); dependency (a package or program was not available: a package that could not be installed or was not loaded, a program outside R and Python, a system library, or R crashing in a package’s compiled code); time (it did not finish within the time limit for one script, or was not started because the time for all scripts had run out); and not_checkable (it could not be checked automatically: it needs a person, the internet, a key or another setting of the authors’ computer, one platform such as Google Colab, Windows or OpenSAFELY, more memory than the run allows, a file that was not downloaded, a screen, or a program that runs it, or it is a file of a package of the code that Python runs only as a module of that package). It is NA for files run inside another script, files that are not an analysis, files not read, and a Docker failure. summary_table counts each group (repro_ran_n, repro_code_error_n, repro_dependency_n, repro_time_n, repro_not_checkable_n), and the report’s first sentence gives them. The traffic light reflects the static readiness signals by default; a script in code_error that stopped with an error makes it red, as a script that crashes on its own analysis is a genuine reproduction failure, and a script in one of the other three groups keeps it from being green. Calls that need a screen, which the run does not have (dev.print(), dev.copy2pdf(), dev.copy2eps(), savePlot(), windows(), win.graph(), x11(), quartz(), View()), are replaced before the run by calls that need none, which modifications records as screen_call_replaced. A script that fails with could not find function is run once more with the library() calls the project’s other scripts make added at its top (or the one package that exports the function, or magrittr for %>%), and a script that then runs is reported as reproducible only after that repair.

Dependencies are reported name-only, with the source (CRAN, GitHub, or a base package already shipped with R) — static analysis of the code cannot know which version was used, and running against current package versions is itself informative: a break argues the authors should have pinned versions. When the repository does record versions, a run with recorded_versions = TRUE installs the packages the scripts load at those versions, but it does not change the R version, which remains a limitation of the check.

Run order is derived from read-after-write data dependencies (a script writing a file another reads must run first), source() edges, and numeric filename prefixes as a weak tie-breaker. Ambiguous orderings, dependency cycles, and inputs a script reads but that no earlier script produces (and that are not in the repository) are surfaced as warnings, since these are the situations most likely to make an otherwise-correct reproduction fail.

Python code (.py files, and notebooks and Quarto documents whose code is Python, from which the code is extracted first) goes through the same two phases, reported in its own “Python code” section. Each file is checked for syntax errors with Python’s own parser when a Python interpreter (python, or else python3) is available; dependencies are read from the import statements, with versions from a requirements.txt or pyproject.toml when there is one, and installed with pip; each script runs as its own python process (processx is required), so unlike R scripts, a name one script defines is not available to another. When no Python interpreter is available, the Python files are reported as not run and the R results are still returned. Statistics the Python scripts print are compared with the paper together with the R output and any self-reproducible output (JASP/jamovi, SPSS-Viewer, notebook outputs).

Abstract

Recent research suggests that responses during experimental fear conditioning follow distinct latent trajectory classes. Computational reinforcement learning models can be used to infer latent learning processes during the task (e.g., learning rates and prediction-error sensitivity) that may help explain these classes. The present study re-analysed previously published and unpublished datasets to examine patterns of fear learning using skin conductance responses (SCRs) in a large sample of healthy participants. Data were aggregated from 12 fear conditioning experiments (N = 1,083; Mage = 20.72 years), encompassing acquisition, extinction, and return-of-fear phases. Using k-means clustering, we identified solutions comprising either two or three distinct response profiles. Across clusters, approximately half of participants showed minimal differential SCRs, while the remaining participants exhibited higher conditioned responding during acquisition, with subsets differing in whether fear returned following extinction. Cluster membership was significantly predicted by gender, current anxiety levels, post-acquisition conditioned stimulus pleasantness ratings, and Bayes factors quantifying evidence for model-based learning. Comparison of reinforcement learning models indicated that a latent cause model provided a superior account of SCR data relative to Rescorla-Wagner, Pearce-Hall, and hybrid models, with latent cause parameters differing by cluster and gender. The clustering data provide preliminary evidence that SCR outcomes in fear conditioning studies may be disproportionately influenced by a minority of participants with specific pre-existing characteristics, rather than reflecting uniform learning processes. Moreover, the results provide support for latent cause theories of fear learning and highlight the value of combining clustering and computational approaches to better understand individual differences in fear acquisition, extinction, and relapse.

[div-01]

Fear conditioning experiments are used to understand how a fear association is learnt (i.e., fear acquisition), how it is learnt that a feared stimulus is no longer a threat (i.e., fear extinction), and how the memory of fear can return over time (return of fear). The concepts of fear acquisition, extinction, and return of fear underpin modern exposure therapies that are used to treat anxiety-related disorders, such as posttraumatic stress disorder and anxiety (Beckers et al., 2023; Bouton et al., 2020; Ney, Schenker, & Lipp, 2022). Experimental fear conditioning involves the repeated pairing of a neutral stimulus with an aversive outcome such as an electric shock (an unconditioned stimulus; US), after which this neutral stimulus is referred to as a conditional threat stimulus (CS+) and may subsequently evoke a threat response from a participant in absence of the aversive outcome. A different neutral stimulus is not paired with the aversive outcome and is referred to as a conditional safety stimulus (a CS-). Typically, physiological responses (e.g., skin conductance) are compared for the CS+ and CS-within an acquisition phase (in which the CS+ is paired with the US), an extinction phase (in which the CS+ ceases to be paired with the US), and variations of return of fear phases, where the return of differential responding to the CS+ compared to CS-is measured following successful extinction. Larger differential responding-CS+ minus CS-responsesis indicative of a stronger threat memory (Lipp, 2006; Lonsdorf et al., 2017). High differential responding during and following extinction can be indicative of an individual's persistent sense of imminent threat (Beckers et al., 2023). Slower extinction learning and higher return of fear are believed to underlie anxiety disorders and PTSD (Duits et al., 2015), and the fear conditioning paradigm is consequently used to understand the relationship between emotional learning and these disorders.

The optimal methods for quantifying the change in responding observed during a fear conditioning procedure have not been determined (Greaves et al., 2024; Kuhn et al., 2022; Lonsdorf et al., 2017; Lonsdorf, Merz, & Fullana, 2019; Ney et al., 2020); however, historically, researchers have used different ANOVA-type methods that simplify the temporal structure of threat responses by averaging these data within phase. We have previously argued that such approaches run the risk of over-simplifying data that putatively reflect complex learning processes occurring in real-time (Ney et al., 2018), and we have further argued that this over-simplification results in the potential for significant researcher degrees of freedom that can affect the robustness of results reported by the field (Ney, Laing, et al., 2022).

There has been an increasing interest in model-based methods for analysing fear conditioning data. One of the most prevalent has been latent class growth modelling (Duits et al., 2021; Galatzer-Levy et al., 2013; Galatzer-Levy et al., 2017; Leen et al., 2021). Latent class growth analysis (LCGA) is a statistical method that identifies patterns in longitudinal data, and categorises individual cases into these patterns, or 'clusters' of responses (Jung & Wickrama, 2008). To do this, LCGA summarises the evolution of first-level data in terms of growth trajectories that are a function of (latent) second-level variables. In the case of fear conditioning, Galatzer-Levy and colleagues (2013) first identified three distinct clusters of fear conditioning in rats (N = 58), as measured by the freezing response. This analysis suggested that more than half of the sample extinguished threat quickly, one-third showed a slower reduction in threat response during extinction, and ten percent did not extinguish their threat responses at all (Galatzer-Levy, et al., 2013). Analogous findings were reported in the fear-potentiated startle responses of healthy humans (N = 724) during fear acquisition and extinction, with the majority of the sample experiencing minimal acquisition of differential fear responding and rapid extinction, and smaller proportions experiencing strong differential acquisition of fear and rapid extinction, or strong acquisition but incomplete fear extinction (Galatzer-Levy et al., 2017). This result was somewhat replicated in a recent study by Leen et al. (2021), who found that 12% of a sample of N = 300 were poor extinguishers, 56% had strong acquisition but had rapid differential extinction, and the remaining 32% were low responders during both acquisition and extinction. This study used subjective ratings of fearfulness towards the CS+ as the outcome measure -speaking to the generalisability of the findings of previous studies -but did not include a physiological outcome (Leen et al., 2021). Similarly, LCGA revealed the hypothesised clusters (i.e., normal extinguishers, slow extinguishers, and nonextinguishers) in a sample of N = 197 healthy and anxious participants when subjective differential fear and expectancy ratings were used as the outcome measure (Duits et al., 2021). This study also identified that anxious participants were significantly more likely to belong to the non-extinguisher cluster when the outcome variable was subjective fear ratings towards the CS+, and belong to the slow safety learning cluster when the outcome variable was subjective fear ratings towards the CS- (Duits et al., 2021). Similar to Leen et al. (2021), this study also had more participants allocated to the high acquisition/rapid extinction cluster compared to the low responder cluster.

Additional work has supported the presence of heterogeneous fear-learning trajectories using physiological outcome measures. For example, Lewis et al. (2021) identified distinct latent trajectories in fear-potentiated startle responding during acquisition and extinction in a smaller sample of healthy adults (N = 65), with most participants showing decreasing fear responding across phases and a smaller subgroup exhibiting increasing fear responses across acquisition. Gazendam et al. (2020) identified heterogeneous trajectories across acquisition, extinction, generalization, reinstatement, and re-extinction phases using subjective distress ratings, fear-potentiated startle, and skin conductance measures in a large sample (Ns = 670-924 depending on outcome measure). Importantly, distinct skin conductance trajectories included patterns characterised by rapid extinction, persistent responding, and comparatively limited physiological responsivity, suggesting that heterogeneity in fear learning trajectories extends beyond acquisition and extinction alone. However, associations between physiological trajectory classes and personality measures were comparatively weak (Gazendam et al. 2020). In line with earlier reports, Andres et al. (2026) pooled several fear conditioning datasets and identified two reproducible skin conductance extinction phenotypes: a larger "fast extinguisher" class and a smaller "slow extinguisher" class. Trait anxiety and participant sex did not reliably predict class membership (Andres et al., 2026).

Overall, acquisition and extinction have been examined consistently, but return of fear manipulations (i.e., reinstatement, re-extinction, renewal, or reacquisition) have been rarely examined.

Various reinforcement learning models have also been applied to fear conditioning data over the past decade including the classic model developed by Rescorla and Wagner (Rescorla & Wagner, 1972), the Pearce-Hall model of learning (Pearce & Hall, 1980), as well as a hybrid Rescorla-Wagner-Pearce-Hall (RW-PH) model (described in Tzovara et al., 2018), and the latent cause (LC) model of learning (Gershman & Niv, 2012). The RW model postulates that threat learning will be most pronounced when an organism's expectations are violated, such that learning is fundamentally error-driven, with associative strength updated in proportion to the magnitude of the prediction error between expected and actual outcomes (Rescorla & Wagner, 1972). For example, when an US begins to follow a CS+, learning will be strongest as the relationship is unexpected, while the learning rate itself remains fixed across trials. In contrast, the PH model proposes that learning is governed by uncertaintydriven changes in stimulus associability rather than by prediction error magnitude alone (Pearce & Hall, 1980). According to this account, stimuli command greater attention-and therefore support stronger learning-when their consequences are uncertain or poorly predicted, whereas associability declines as outcomes become more predictable. Thus, whereas the RW model assumes a static learning rate and attributes changes in learning solely to error magnitude, the PH model emphasises dynamic allocation of attention to cues based on outcome uncertainty.

Hybrid RW-PH models use various combinations of the RW and PH terms, for example, in the hybrid model from Tzovara et al. (2018), prediction errors are weighted by an associability term that is itself updated as a function of prediction errors. This hybrid formulation integrates error-driven learning with uncertainty-dependent modulation of learning rate, deviating from the RW model by modelling a learning rate that changes over time rather than remaining static. Finally, the LC model utilises a form of clustering to describe an agent's inferences with regards to the number of unobserved causes governing observed CS-US contingencies across time and encodes an expectation that the number of inferred causes may change, given new data and new contingencies (Gershman & Niv, 2012; Gershman et al., 2015). This model deviates from RW-based learning models by rejecting the idea that learning is governed by learning of explicit CS-US contingencies, but rather by learning the relationship between unobservable 'latent' causes of actual events. In conditioning, if the current trial is observably similar to a previous trial, then the same latent cause will be attributable to both trials. However, if a new trial is observably different (e.g., from acquisition to extinction), it is likely that a new latent cause will be generated (Gershman et al., 2015).

There are an increasing number of studies that have analysed fear conditioning data according to the models described above (Cisler et al., 2024; Gershman & Hartley, 2015; Gershman et al., 2017; Norbury et al., 2021; Paskewitz et al., 2022; Prévost et al., 2013; Tzovara et al., 2018). In these analyses, participant-specific parameters are inferred, and the fit of (or evidence for) competing models (generative hypotheses) is often compared.

Winning models can then inform theories of how fear learning and extinction occur (Adams et al., 2016). Formalisation of theory-testing in this way can help to generate more precise theories from available empirical data. By using computational modelling to formally identify, test, and quantify latent processes that are not directly observable from aggregate behavioural responses, such as threat updating, uncertainty estimation, and extinction learning, fear conditioning data can be used to improve our understanding of the mechanisms underlying anxiety and trauma-related disorders (Gershman, 2015; Huys et al., 2016). This improved understanding of mechanisms may lead to the development of better treatments (Culver et al., 2014). A large proportion of computational modelling work in fear conditioning has focused on comparing candidate models of learning and testing associations between model-derived parameters and individual difference measures. However, relatively fewer studies have examined whether individuals cluster into qualitatively distinct subgroups based on their latent computational profiles following model fitting. Addressing this gap may therefore provide additional insight into whether heterogeneity in fear learning reflects continuous variation or the presence of distinct computational phenotypes.

In the current study, we re-analysed data from human participants who completed fear conditioning across multiple experiments conducted in our laboratory that used similar experimental designs. Our primary objective was to identify heterogeneous trajectories of fear acquisition, extinction, and return of fear using longitudinal clustering methods applied to trial-by-trial skin conductance responses. Specifically, we modelled the data using the kmeans clustering method (kml, a variant of LCGA) (Genolini & Falissard, 2011) to differential skin conductance trajectories to determine whether patterns of fear learning and extinction could be identified within the pooled sample. A secondary objective was to examine whether identified trajectory clusters were associated with participant characteristics and self-reported measures relevant to anxiety vulnerability. We examined whether cluster allocation differed according to demographic and questionnaire measures. A final objective was to compare the extent to which differential learning models accounted for participant characteristics and trajectory clusters, and to determine which learning models best fit the data. To do this, we fitted the RW, PH, hybrid RW-PH, and LC models to participants trialby-trial skin conductance data and compared between models as well as across participant characteristics and trajectory clusters.

We predicted that we would replicate previous research and find three distinct trajectories of fear conditioning -normal extinguishers with lower acquisition, fast extinguishers with high acquisition, and non-extinguishers with high acquisition. We hypothesised that return of fear would be higher for participants who did not extinguish fear during extinction. We further hypothesised that formal learning models (the winning model of RW, PH, hybrid RW-PH, or LC in our data) would be able to explain learning differences between the different clusters identified using k-means clustering.

Methods

Participants

This study is a re-analysis of a previously described datasets and some unpublished data.

In total, 1,083 participants (816 female, 262 male, 2 non-binary, 3 undisclosed, Mage = 20.72, SD = 5.33) across 12 different experiments (6 unpublished) were recruited at the Queensland University of Technology and Curtin University through undergraduate psychology programs and from the wider community. Experiments were approved by the Queensland University of Technology and Curtin University human research ethics committees. Informed consent was obtained from all participants prior to beginning the experiments.

Fear conditioning tasks

Participants completed basic fear conditioning and extinction tasks, seven of which have previously been described (Eales et al., 2025; Lipp et al., 2024; Lipp, Luck, et al., 2025; Lipp, Ney, et al., 2025; Tyson et al., 2025; Wang, Luck, et al., 2024). Participants were connected to a DS7A Digitimer, which generated the electrotactile USs, and had skin conductance responses recorded throughout the experiments. The USs consisted of a sequence of three 2 ms electro-tactile stimuli presented 16 ms apart, resulting in the perception of one discrete shock stimulus, though one study used a screaming lady sound as US for half of participants during acquisition. Participants viewed a CS+, which was paired with the US 100% of the time during acquisition, and a CS-, which was never paired with the US. The different studies varied in what type of CSs were presented as well as how many trials were included across phases (for details see Table 1). Across studies, intertrial intervals varied from 10 to 18 seconds.

Each experiment started with a shock calibration, where beginning at 0 mA, participants worked up in 0.1 mA increments to a shock intensity that was "unpleasant, but not painful".

During habituation phases no US was delivered. This data is not analysed in this manuscript as no relevant learning occurred. During acquisition, there were 8 trials of each of the CS+ and CS-(with 100% reinforcement of CS+) in most studies. In all studies, extinction followed acquisition, with either 24, 12, or 6 trials in each study. Across most studies, an ABA renewal design was used (Wang, Olsson, et al., 2024), with blue (RGB: 000128255) and pink (RGB: 255128192) used as background colours, with the colour counterbalanced across participants. The first colour (A) was presented during acquisition, renewal, and reacquisition, and the second colour (B) was presented during extinction. Wang, Luck, et al., (2024) and Wang et al. (2026) additionally used yellow (RGB: 255255000), though only used two of the three available colours for each participant. In contrast, Lipp et al. (unpublished B) used a 2-day design with acquisition and extinction on day 1 and extinction retention and reacquisition on day 2. Hanlin et al. (unpublished) used a 1-day paradigm where participants underwent extinction re-test after ten minutes and reacquisition. An ABA design was not used for these studies -in both of these studies a white background was used throughout the experiment (i.e., no background context change between phases). CS order was pseudorandom: the same CS was not presented more than twice at any point during the experiment. The experiments were controlled by either DMDX (Forster & Forster, 2003) or Inquisit (Millisecond Software). Skin Conductance

Electrodermal activity was assessed via skin conductance responses (SCRs) using two adhesive BIOPAC EL507 electrodes placed on the thenar and hypothenar regions of the palm on participants' non-dominant hand. Data were collected with a BIOPAC MP150 acquisition system in conjunction with a GSR100C amplifier at QUT and a BIOPAC MP160 with GSR100C at Curtin. Signals at QUT were recorded using AcqKnowledge software (version 3.9.1) and subsequently scored either manually or with EzySCR, which is a supervised scoring program which enables manual verification of scored SCRs (Ney et al., 2024). SCRs were scored at Curtin manually using AcqKnowledge version 5.0. SCRs were scored using the trough-to-peak method, with the difference between the trough and peak of a SCR beginning within a 1-4 s window following conditioned stimulus (CS) onset, encompassing the first interval response (Prokasy & Ebel, 1967; Prokasy et al., 1973). Responses below a minimum threshold of 0.2 µS were scored as zero. To account for potential movement-related artefacts, respiratory activity was concurrently monitored using a BIOPAC TSD201 respiratory belt and an RSP100C amplifier. If evidence of participant movement (e.g., coughing) was observed in the respiratory channel, any corresponding SCR was flagged and scored as missing. Participants were omitted from SCR analyses if they met criteria for nonresponsiveness, operationalised as exhibiting no unconditioned stimulus response on 50% or more of CS+ trials during acquisition. This criterion is consistent with established psychophysiological guidelines recommending exclusion of participants with insufficient autonomic reactivity to the US, as reliable estimation of conditioned responding requires a measurable US-evoked signal (Boucsein et al., 2012; Lonsdorf et al., 2017). A 50% threshold was selected as a conservative upper bound within commonly applied ranges to balance data retention with ensuring stable estimation of learning-related SCRs, particularly given that downstream computational and clustering analyses rely on reliable trial-wise US-driven learning signals. All SCRs were square-root transformed and range corrected prior to analysis.

CS Pleasantness Evaluations

Across most of the experiments, participants completed pre-habituation and postacquisition CS pleasantness evaluations. For this outcome measure, participants were presented with each CS and asked to rate how pleasant they found it on a scale of 1 to 9, where1 = "very unpleasant",5 = "neutral", and9 = "very pleasant". This task was completed with white text on a black background screen and is used in the current article as a measure of subjective CS+/CS-differentiation.

Questionnaires

At the end of each experiment, participants completed a questionnaire battery. For the most part, the same questionnaire battery was administered; though, not all studies used the same questionnaires. Approximately half of the included studies did not administer psychopathology questionnaires, and analyses involving questionnaire predictors therefore used only the subset of participants with available data, with study entered as a factor to account for this structured missingness.

State-Trait Anxiety Inventory -Trait version (STAI-T).

The STAI-T is a 20-item selfreport measure assessing relatively stable individual differences in anxiety proneness (trait anxiety). Items reflect how respondents generally feel, rated on a 4-point Likert scale, with higher scores indicating greater trait anxiety (Spielberger, 1970).

State-Trait Anxiety Inventory -State version (STAI-S).

The STAI-S is a 20-item selfreport measure assessing current levels of anxiety (state anxiety), capturing transient feelings of tension, nervousness, and apprehension "at this moment." Items are rated on a 4-point Likert scale, with higher scores reflecting greater state anxiety (Spielberger, 1970).

Penn State Worry Questionnaire (PSWQ).

The PSWQ is a 16-item self-report measure designed to assess the tendency to engage in excessive and uncontrollable worry. Items are rated on a 5-point Likert scale, with higher scores indicating greater levels of pathological worry (Meyer et al., 1990).

Intolerance of Uncertainty Scale -Short Form (IUS-12).

The IUS-12 is a 12-item selfreport measure assessing emotional, cognitive, and behavioural reactions to uncertain situations. Items are rated on a 5-point Likert scale, with higher scores indicating greater intolerance of uncertainty (Carleton et al., 2007).

Mood and Feelings Questionnaire (MFQ).

The MFQ is a self-report measure assessing depressive symptoms experienced over the past two weeks. Items assess core affective, cognitive, and behavioural features of depression, with higher scores indicating greater depressive symptom severity (Angold et al., 1995).

Data analysis

K-means Analysis.

Clustering was performed on trial-wise differential SCRs (CS+ minus CS-) rather than on CS+ and CS-trajectories separately. This approach was chosen to isolate associative learning-related variance from non-associative influences on electrodermal activity, such as individual differences in general autonomic responsivity, arousal, and habituation (Lonsdorf et al., 2017). By focusing on differential responding, clustering is driven by the extent to which participants discriminate between threat-and safety-predictive cues, which is the central construct of Pavlovian fear learning.

To harmonise heterogeneous experimental designs, trial-wise differential skin conductance responses (CS+ minus CS-) were extracted for each participant and aligned onto a common temporal index spanning up to 48 trials, corresponding to the maximum number of differential observations available across studies. This 48-trial structure reflects the longest observed continuous learning sequence in the pooled dataset rather than a fixed truncation point. Missing values arising from study-specific differences in trial numbers were handled using the native missing-data handling procedures implemented in the kml package, which allows clustering of longitudinal trajectories under incomplete observation without imputation. Participants were excluded if more than 18 of the 48 time points were missing, ensuring sufficient temporal information for stable trajectory estimation. All trials described in Table 1 were included for each phase of the analysis.

Differences in trial counts across studies were handled by aligning participants' data onto a common trial-indexed time axis and retaining all available observations without imputation or truncation of earlier trials. This resulted in unequal trajectory lengths across participants, with missing values occurring at later time points for studies with fewer trials. The k-means longitudinal clustering algorithm (kml; Genolini et al., 2015) explicitly accommodates such unequally observed trajectories under a missing-at-random assumption. Importantly, no interpolation or imputation was performed, and clustering was based solely on observed data.

As a consequence, participants contributed all available trial-level information to the estimation of cluster structure, with earlier trials (common across studies) contributing most strongly to clustering and later phases contributing proportionally less information where data were not available. This approach allows integration of heterogeneous experimental designs while preserving within-subject learning dynamics.

Because the present analyses were exploratory and not preregistered, we aimed to make preprocessing decisions transparent and consistent with prior trajectory-clustering recommendations. Participants were excluded due to non-response or technical recording failure using established psychophysiological criteria (see above) (Boucsein, 2012), and extreme multivariate outliers were removed using Tukey's (1977) interquartile range rule to reduce disproportionate influence on k-means trajectory estimation, which is sensitive to extreme values and noise (Genolini & Falissard, 2011). Although these preprocessing decisions were made to improve the stability and interpretability of clustering solutions, alternative preprocessing pipelines or exclusion thresholds may have produced somewhat different cluster structures. Accordingly, the present findings should be interpreted as exploratory and requiring independent replication.

SCR trajectories within the phases were considered longitudinal data. Differential clustering analyses were conducted for the difference between CS+ and CS-across the entire data. K-means clustering of the trajectories was performed using the kml R package (Genolini et al., 2015). This method represents an unsupervised machine learning approach which aims to partition the data into k clusters. The data trajectories within a cluster are chosen such that the within-cluster variances are minimal. We set k from 2 to 6 for clustering analyses. Default parameter settings of the kml package were used when performing clustering (Euclidean distance, 20 random initializations per k, selection of the solution minimizing within-cluster variance, default convergence criteria). To determine the best partitioning of the data (i.e., the optimal number of clusters), Calinski-Harabatz, Davies-Bouldin and Ray-Turi cluster validity indices were used (Vergara et al., 2020). The cluster validity indices are measures indicating the parsimony of the cluster analysis. Higher scores of the Calinski-Harabasz index indicate better performance, while lower scores for Davies-Bouldin and Ray-Turi indices indicate better performance (Ray & Turi, 2000). Akaike information criterion (AIC) values were also computed during the clustering analysis and assisted in choosing the optimal number of clusters. Posterior predictive checks were conducted using the getBestPostProba function in the kml function, which provides a posterior probability that the fitted model predicts the actual observed data.

Repeated Measures ANOVA between clusters.

Following from k-means analyses, a repeated measures ANOVA was conducted in R to assess the magnitude of differential responding across the clusters on data from the acquisition, extinction, and return of fear phases. These ANOVAs included within subject factors of CS type (CS: CS+, CS-) and Trial (Trials 1-6 to capture all data for acquisition and extinction, Trials 1-3 for renewal, and Trials 1-4 for reacquisition) as well as a between subject factor of cluster (clusters A, B, C). As sphericity was violated, Greenhouse Geisser corrections were applied.

Participant characteristics and cluster membership. Factorial ANOVAs were conducted in R to test the difference between clusters on questionnaire data scores (STAI-T, STAI-S, IUS-12, PSWQ, MFQ), age, and differential CS pleasantness ratings, which was calculated as the difference between CS+ and CS-pleasantness ratings post-acquisition for each participant. Partial eta squared was used as an effect size measure and Tukey's corrections for multiple comparisons were used for post hoc tests. Chi square tests were used to assess the difference between clusters in gender distribution. These models included the factor of study and interaction term study × cluster membership (see Manipulation Check below) after it was discovered that most of the characteristics (except for age and sex) were affected by the study that participants completed.

Results

In total, 60 participants (5.5%) of the sample were removed prior to analysis due to nonresponding or technical issues where data were not able to be recorded. An additional 68 participants were removed after removal of outlying values, defined as having overall scores falling outside 1.5 times the interquartile range below the first quartile or above the third quartile of the distribution of row-wise means (Tukey, 1977). This step was taken so as to not bias the k-means modelling (Genolini & Falissard, 2011). In total, 953 participants were included in the final analysis.

Manipulation Check

A manipulation check was conducted to test whether the factor of Study impacted fear acquisition, extinction, and return of fear tests. Using repeated measures ANOVAs, we found that Study × CS effects were significant in acquisition (p < .001) and re-acquisition (p = .019), but not extinction (p = .124) or renewal (p = .095). Weaker acquisition and re-acquisition (CS+/CS-difference) were observed in studies 7 (p = .022), 8 (p = .025), and 9 (p = .520) for acquisition (all other studies p < .001) and in studies 8 (p = .411), 9 (p = .104), and 10 (p = .165) for re-acquisition (all other studies p < .035). The factor of Study also had various effects on other variables in the present analyses: US pleasantness (p < .001), US intensity (p < .001), STAIT (p = .006), STAIS (p = .017), PSWQ (p = .001), IUS (p = .012), Mood (p = .028), and actual US intensity (p < .001) all differed between studies. Neither sex (p = .725) nor age (p = .111) differed between studies (see Supplementary Material and Table 1 for differences in characteristics and related scores across studies).

Due to these findings, we inferred that there were differences across the included studies that could affect the modelling results. Study was taken into account for the subsequent analyses.

Discussion

The present study used a combination of emerging statistical techniques to examine fear conditioning in a combined dataset of healthy participants. Using a k-means approach, we identified solutions involving either two or three distinct clusters of conditioned responding across acquisition, extinction, and return of fear phases. While approximately half of participants showed low levels of differential responding throughout the experiments, one quarter of participants had high differential responding during acquisition and a high return of fear during reacquisition, and one quarter had higher differential responding during acquisition and no return of fear. Participant gender was significantly different between clusters, as were current anxiety levels, differential CS pleasantness evaluations following acquisition, perceived (but not actual) US intensity, subjective US pleasantness, and logBF values generated by the latent cause computational model, where higher values reflected greater evidence for multi-state (multi-cause) inference across conditioning phases. The latent cause model outperformed the other included computational models in the current pooled data. Overall, these results show the value of using computational models to fit fear conditioning data and provide some possible preliminary evidence that some skin conductance responding in conditioning experiments might be differentially influenced by participants with particular, pre-existing characteristics.

Recent studies have sought to apply LCGA to fear conditioning data so that participant responding can be categorised into meaningful clusters of responses. Galatzer-Levy et al.

(2013) first performed the technique in animals, and three distinct trajectories of fear responding were identified: rapid extinction, slow extinction, and no extinction. This finding was partially replicated in humans using fear-potentiated startle, where low responders made up the majority of cases but a smaller proportion of participants with high responses were categorised as either extinguishers or non-extinguishers of fear during extinction (Galatzer-Levy et al., 2017). A three cluster model with a similar cluster structure was optimal for subjective ratings data in two other recent studies, though this model was not evident in fear potentiated startle data (Duits et al., 2021; Leen et al., 2021). Moreover, very few studies have tested whether cluster differences in extinction learning translate to return of fear (Gazendam et al., 2020), despite the theoretical importance of return of fear manipulations to the retention of treatment gains following extinction (Vervliet et al., 2013). To our knowledge, our study is the first to examine return of fear using renewal and re-acquisition.

We found that a 2-cluster model, comprising low responders (Cluster A) and high responders showing acquisition and return of fear (Cluster B), provided the best overall statistical fit to the data. However, the 3-cluster solution also demonstrated acceptable fit and provided additional theoretical resolution by separating high responders who exhibited return of fear from those who did not. This distinction is particularly relevant within contemporary models of fear relapse, where heterogeneity in the recovery of conditioned fear is considered central to understanding vulnerability to relapse following extinction (Bouton et al., 2020; Lipp et al., 2020; Vervliet et al., 2013). Importantly, the 2-cluster solution collapsed these relapserelated trajectories into a single high-responder group, thereby obscuring potentially meaningful variation in return of fear processes. However, although we hypothesised that return of fear would be higher among participants who did not extinguish during extinction, this prediction could not be directly evaluated within the present cluster solution. The largest cluster (Cluster A) showed no differential acquisition, meaning that their low return of fear responses could not be meaningfully interpreted as successful extinction or failure to extinguish. Instead, the absence of measurable conditioned responding in this group reflects a limitation of SCR as an outcome measure: when acquisition is not detected, extinction and return of fear cannot be validly quantified. As a result, Hypothesis 2 could not be tested in a theoretically coherent way with the current data structure. Because the clustering analyses were exploratory and not preregistered, we report both the statistically optimal 2-cluster solution and the theoretically informative 3-cluster solution, with the former presented in the Supplementary Materials. Accordingly, conclusions drawn from the 3-cluster solution should be interpreted cautiously and viewed as hypothesis-generating rather than definitive.

We were surprised to find that such a significant proportion of participants show minimal CS+/CS-differentiation in skin conductance responding, and neither of these clustering solutions replicated previous findings of fast versus slow extinguishers. The topic of "nonlearning" during fear conditioning has been previously explored and it has been concluded by multiple research groups that lack of differential responding during acquisition -especially for physiological outcome measures -does not necessarily reflect lack of learning (Lam et al., 2024; Lipp et al., 2022; Lonsdorf, Klingelhöfer-Jens, et al., 2019; Ney et al., 2023).

Importantly, the graded pattern of differential responding across clusters (C > B > A) was mirrored across subjective CS evaluations and computational model evidence. Participants in cluster A did not appear to exhibit aberrant responding; rather, they showed comparatively attenuated physiological, evaluative, and model-based indices of differential learning. This convergence suggests quantitative differences in learning-or arousal-related processes rather than categorical non-learning.

However, while this pattern may reflect meaningful heterogeneity in fear learning, it is also important to recognise that it may be explained by other factors. Firstly, SCRs are highly variable across individuals, susceptible to noise and preprocessing decisions (Greaves et al., 2024), and influenced by multiple non-associative processes including general arousal, orienting responses {Öhman, 1974 #1929; (Prokasy & Ebel, 1967), habituation (Juuse et al., 2024), and individual differences in electrodermal responsivity (Boucsein, 2012).

Consequently, the current findings may reflect measurement error as low differential SCRs could be caused by lack of sensitivity to detect differentiation in individuals with low tonic skin conductance or low arousal. Several methodological factors may additionally have contributed to reduced CS+/CS-differentiation in the present dataset, including differences in US salience (Ney et al., 2023), reinforcement schedules, task structure, response scaling, and the pooling of studies involving somewhat different return of fear paradigms (e.g., renewal, retention, and re-test procedures) (Lonsdorf et al., 2017). Importantly, however, the graded pattern of responding across clusters was mirrored across subjective CS evaluations and computational model evidence, suggesting that the identified trajectories were not solely attributable to noise or measurement artefacts. It is also important to note that the cluster assignment was, in some cases, influenced by the study -however, cross-examination of the study design characteristics and cluster allocation did not reveal any consistent underlying determinants of cluster allocation (see Supplementary Materials and Table 1). Future studies should incorporate multimodal outcome measures, including expectancy ratings, fearpotentiated startle, and neurophysiological indices, to determine whether similar clustering structures emerge across different indicators of conditioned fear.

We next tested whether cluster membership was associated with pre-existing characteristics. A significant proportion of participants in the current database completed the same questionnaires; of these, only the STAI-S showed significant effects -higher STAI-S (a measure of current anxiety (Spielberger et al., 1983)) was associated with membership of the higher responding clusters B and C. Moreover, B cluster members were more likely to be male and C cluster members were more likely to be female, and both B and C cluster members rated the CS+ as significantly more unpleasant compared to A cluster members.

Interestingly, although there were no differences between the clusters in terms of actual US intensity, the C cluster rated the US as subjectively more intense and unpleasant. These tests provide some preliminary evidence that participants may respond in particular ways during fear conditioning based on pre-existing characteristics (gender, anxiety, and possibly pain perception), which has the potential to bias findings in fear conditioning studies seeking to minimise individual differences (Lonsdorf & Merz, 2017). This issue is particularly important given that skin conductance data derived from fear conditioning is often highly skewed and characterised by substantial individual variability (Lonsdorf et al., 2017). Under such conditions, aggregate group estimates have the potential to be disproportionately influenced by a subset of participants showing relatively strong differential responding, particularly when many participants exhibit minimal differential SCRs. Importantly, low differential SCR responding does not necessarily imply complete absence of learning, and may reflect floor effects, measurement limitations, or variability in physiological responsivity.

We found that the LC model (Gershman & Niv, 2012) was the best performing model for most of our participants, though this varied somewhat by cluster membership and gender.

Thus, our data suggests that the LC model may more effectively describe fear conditioning processes, relative to the RW, PH, and hybrid RW-PH models. The LC model describes the extent to which participants in a fear conditioning experiment infer that trials have one or more causes, which then confers an expectation about the probability of a US occurring (Gershman & Niv, 2012). In applied studies, the model has been used to provide evidence that suggests participants who update a single fear memory-i.e., tend to assign all trials to a single cause (despite the statistical differences between acquisition and extinction phases)are less likely to exhibit the spontaneous recovery of fear than participants who acquire a new fear memory-i.e., assign trials to more than one latent cause-during the extinction phase (Gershman & Hartley, 2015). Importantly, cluster membership was systematically related to evidence for multiple latent causes, with cluster C showing the strongest support for multicause inference. This graded association aligns with theoretical accounts linking latent cause inference to vulnerability to fear return and anxiety-related symptomatology. Although these associations require replication, the present findings provide cross-sectional support for latent cause theory that extends beyond model fit comparisons alone. It is also important to acknowledge that the apparent superiority of the LC model may partly reflect characteristics of the included experimental paradigms. In particular, the predominantly 100% reinforcement schedules and relatively abrupt transition from acquisition to extinction within a single experimental session may have increased the statistical distinctiveness of experimental phases, thereby favouring latent-cause inference over associative models such as RW or PH that assume continuous updating of a single associative representation (Gershman, 2015; Gershman et al., 2013). Under these conditions, participants may have been more likely to infer that extinction trials reflected a new latent state or context rather than an update to the original acquisition memory.

The limitations of this work include the following issues. Firstly, although our sample size is significantly larger than the majority of physiological fear conditioning studies, it was derived from a single laboratory conducting experiments of a similar nature using the same equipment and mostly the same stimuli. These tests should be treated as preliminary and not yet indicative of data that might be derived from a different laboratory. Second, the 12 included studies differed in several important design characteristics, including phase structure, contextual manipulations, return of fear procedures, trial numbers, and stimulus categories. Consistent with this heterogeneity, study membership significantly influenced acquisition and re-acquisition responding, cluster membership, and several questionnaire and US evaluation measures. Although study was statistically controlled for in subsequent analyses, it remains possible that some aspects of the identified clustering structure partly reflect procedural differences between studies rather than stable latent subtypes of fear learning. Third, the large low-differentiation SCR cluster may reflect multiple sources of variance. While this group may represent meaningful individual differences in conditioned responding, it could also partly reflect non-associative factors such as variability in electrodermal responsivity, preprocessing decisions (including outlier removal and nonresponse exclusion criteria), response scaling, or task-specific features that reduce observable CS+/CS-discrimination. One additional limitation is that clustering was based on differential SCRs (CS+ minus CS-) rather than modelling CS+ and CS-trajectories separately.

Although this approach was intended to isolate associative learning-related variance from broader non-associative influences on electrodermal responding, alternative approaches that separately model threat and safety cue responding may yield different trajectory structures and interpretations. Another limitation is that the present computational modelling approach examined a restricted set of learning models and did not include several potentially informative alternatives, including probabilistic or dual-learning-rate variants that separately model CS+ and CS-learning. The selected models were chosen to provide a focused comparison between influential associative learning frameworks and latent cause inference approaches commonly applied in fear conditioning research, while also maintaining comparability with prior work. Nevertheless, because different model architectures may capture distinct features of conditioned responding, future studies should test whether the present findings generalise across broader classes of computational models. The present study also did not include formal model recovery or parameter recovery analyses, limiting conclusions regarding the computational specificity and identifiability of the fitted models.

Although models were compared against null baselines and evaluated using multiple fit indices and posterior predictive checks, future work should more comprehensively assess model discriminability and parameter recoverability against a broader range of models. Next, the associations between cluster membership and questionnaire, evaluative, and demographic measures were relatively small and cross-sectional in nature. Accordingly, these effects should be interpreted cautiously and not as evidence of causal or mechanistic relationships between self-reported anxiety-related traits and fear learning trajectories. Finally, approximately half of the included studies did not administer psychopathology questionnaires, meaning that analyses involving these measures were necessarily restricted to the subset of participants with available data and should be interpreted with this structured missingness in mind.

Despite these weaknesses, this work has some clear strengths. A key strength of the present study was the convergence across physiological, subjective, and computational indicators of fear learning, with cluster differences emerging not only in SCR trajectories but also in pleasantness ratings and formal learning-model parameters, even where effect sizes were modest. To our knowledge, this is among the first studies to combine longitudinal SCR trajectory clustering with formal computational model comparison within a large pooled fear conditioning dataset. The large sample size provided substantial power to detect stable individual differences in fear learning and relapse-related trajectories that may be difficult to observe in smaller experimental samples. Importantly, the clustering analyses identified heterogeneity in renewal and re-acquisition responding, suggesting that return of fear processes are not uniform across individuals. These findings support the utility of integrating data-driven trajectory analyses with computational modelling approaches to better characterise individual variability in fear learning and relapse.

In conclusion, we find evidence for two and three distinct clusters of fear conditioning responses that extends those reported in earlier literature to broach a broader topic about interpretation of non-differential responding in skin conductance responses (Olsson et al., 2025). This issue is especially important if learning indexed by skin conductance responses has the potential to be influenced by pre-existing participant characteristics, rather than the intended study manipulations. This possibility must be explored in future studies. Our findings also provide support for the latent cause theory of fear conditioning, with the optimal clustering of conditioned responses predicting latent cause inferences (as encoded by the LC model). Beyond theoretical implications, the present approach offers a data-driven and model-informed method for identifying individuals who exhibit return of fear. In the context of ongoing debates regarding optimal indices of extinction retention, clustering approaches may provide an alternative route to operationalising relapse-like phenomena at the individual level. Our study needs to be replicated in larger and more diverse datasets, but for the first time reveals potential learning differences described by a combination of latent growth and computational models that may begin to explain why certain participants fail to extinguish fear memories. This way of examining fear conditioning data provides initial steps towards a more comprehensive understanding of what drives human fear learning and its extinction.
