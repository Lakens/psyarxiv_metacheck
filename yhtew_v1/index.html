Meta-scientific research has shown nonsignificant p values are commonly misinterpreted. It is incorrect to infer that there is ‘no effect’, ‘no difference’, or that groups are ‘the same’ after p > 0.05.

It is possible that there is a true non-zero effect, but that the study did not detect it. Make sure your inference acknowledges that it is possible that there is a non-zero effect. It is correct to include the effect is ‘not significantly’ different, although this just restates that p > 0.05.

This module searches for statements of ethics approval, IRB approval, institutional review board approval, and related terms.

How Power Analysis Check works

This module uses regular expressions to identify sentences that contain a statistical power analysis. If specified by the user, it also uses a large language model (LLM) to extract information reported in power analyses, including the statistical test, sample size, alpha level, desired level of power, and magnitude and type of effect size.

The Power Analysis Check module uses regular expressions to identify sentences that contain a statistical power analysis. Without the use of an LLM, the module uses regular expressions to classify the power analysis as a-priori, sensitivity or post-hoc. With the use of an LLM, it checks if the power analysis is reported with all required information.

The regular expressions can miss power analyses, or fail to classify them correctly. The type of power analysis is often difficult to classify, which can easily be solved by explicitly specifying the type of power analysis as ‘a-priori’, ‘sensitivity’, or ‘post-hoc’. Note that ‘post-hoc’ or ‘observed’ power is rarely useful. The LLM can fail to identify information in the paper, and will not have access to information in paragraphs in the paper other than those that contain the word ‘power’. This package was validated by the Metacheck team on articles in Psychological Science.

How Preregistration Check works

Retrieve information from preregistrations in a standardised way, and make them easier to check.

The Preregistration Check module identifies preregistrations on the OSF and AsPredicted based on links in the manuscript, retrieves the preregistration text, and organizes the information into a template. The module retrieves text from the OSF with its API, and from AsPredicted with ResearchBox’s API when a ResearchBox key is set (see rbox_token()), or else from the preregistration’s web page. How Exact P-Values works

List any p-values reported with insufficient precision (e.g., p < .05 or p = n.s.), reported as exactly zero (e.g., p = .000), or impossible (below 0 or above 1, e.g., p = -.22).

This module uses regular expressions to identify p-values. It will flag any values reported as p > ? or p < numbers greater than .001. It will also flag p-values reported as exactly zero (e.g., p = .000, p = 0.00), which are mathematically impossible — p-values are never exactly zero and should instead be reported as p < .001.

A p-value that is not the result of a test is not flagged: a table note (“* p < .05, ** p < .01”), a figure legend (“Asterisks indicate significant differences (p < .05)”, “Values in bold are significant at p < .05”) or a stated threshold (“p < .05 was considered significant”, “thresholded at p < .001”). GROBID often puts such notes into the running text, so each p-value is judged by the words in its own clause (the text up to a “;” or a full stop), and never left out when a test statistic belongs to it (“F(1, 7) = 8.03, # p < .05”). The column not_a_test of the table says why a p-value was left out (“marker”, “threshold”, “legend” or “named”).

A p-value with the name of a correction or a test after the p (“pFWE < .05”, “padj < 0.05”, “p Wilcoxon = .02”) is flagged only when a test statistic comes before it in its clause (“t(37) = 7.17, p FWE < .05”). Without one it is mostly the rule that decided what was significant (“genes with padj < 0.05 were selected”); such a p-value is “named” in not_a_test. Notes in other forms, such as a marker after the p-value (“p < .05 (*)“), are still flagged.

A p-value below 0 or above 1 is impossible; it is listed apart and not also as imprecise. Often the statistic before it, or its minus sign, was copied into it (“t(134) = -2.32, p = -.13”, “Z = 3.091, P = 3.091”). A value above 1 is listed only after a test statistic in its clause: without one, a “P” above 1 was nearly always another quantity (a proportion, pH, a group’s mean, a model parameter). A number in scientific notation whose power of ten was lost when the PDF was read (“p = 2.4 x 10 -9” read as 2.4) is not listed. A “p” that is the subscript of another symbol (“r p = .64”, “²p = .02” for partial eta squared, “Δp = .33”), or a quantity with a unit, a logarithm or a ratio (“P = 2.9 µm”, “-log10 P = 7.5”, “Ca/P = 1.67”), is not read as a p-value at all (see extract_p_values()). Each p-value has its own row, also when the same one is written twice in a sentence.

This module sometimes flags false positives when sentences discuss how p-value thresholds were set. It can also miss an imprecise p-value that is reported against a threshold (“decreased at the p < .05 significance threshold”).

This module only checks p-values reported in the running text of the manuscript. It cannot (yet) process p-values reported only in tables (as opposed to a table’s footnote text, which the module does see and tries to exclude — see above).

How Non-Significant P Value Check works

In the future, the Metacheck team aims to incorporate a machine learning classifier to only return sentences likely to contain misinterpretations. If you want to help to improve the module, reach out to the Metacheck development team.

How Codebook Check works

This module checks whether the data columns in a repository are documented in a codebook or README. It locates codebook/readme files, extracts the variable definitions they contain, matches those definitions against the data columns extracted by data_check, and reports documentation coverage: how many data columns are documented, and which documented variables are never used.

The Codebook Check module consumes the columns and file classification produced by data_check (and, transitively, repo_check). Files classified as codebook or readme are parsed with parse_codebook(), which reads structured tables (CSV/TSV/Excel with a variable-name column and a label column), embedded labels in haven files (SPSS/Stata/SAS), and plain text from rich-text formats (docx/pdf/rtf/odt). Embedded haven labels from data files are also harvested directly.

Each data column is then matched against the parsed variable definitions with match_column_labels(), using normalised-name matching with experiment-group scoping, haven-label priority, and rule-based label-equivalence merging.

Beyond the variable label, the module harvests the DDI-style per-variable properties a source supplies: the value labels / code list (the 1=“Strongly disagree”…5=“Strongly agree” mapping — from SPSS/Stata value labels and from a codebook “values”/“coding” column), the missing-value scheme (which codes denote missingness, from haven declared missings and labels that read as “refused”/“n/a”), and question text and columns when present. This module classifies the files in a repository into semantic types (data, codebook, code, software, output, supplemental, readme, asset, other) and, for tabular data files, extracts each column’s type and summary statistics.

How Reproducibility Check works

This module assesses whether a paper’s R and Python code can be run on its data. It works in two phases. The static phase (always run) collects the package dependencies the code declares, rewrites the data-file paths that do not work in the repository as the authors organised it, works out the order the scripts must run in, and diagnoses why any referenced input file is unavailable — reporting what a reproduction attempt would involve and where it is likely to break. The execution phase (opt-in, execute = TRUE) then actually runs the code: it copies the repository into a throwaway directory, optionally installs the declared dependencies into a throwaway library, runs each script in order in an isolated subprocess with a per-script timeout, and captures the outcome and full output of each run.

By default (execute = FALSE) the module does not run any code — it performs only static analysis: reading dependencies with the same extractors as code_check, finding the files the code references in the repository, and building a run-order dependency graph. It reports what would be installed and run rather than doing it.

When execute = TRUE, the module additionally runs the downloaded code on your machine — a deliberate, opt-in action gated behind that argument (callr is required for R code). Each script runs in an isolated subprocess so a crash cannot take down the R session; note this isolates crashes, not the filesystem or network. Installs (when install_missing = TRUE) and the throwaway run library never touch your main R library. Each script’s outcome is one of ran_ok, errored, timed_out, dependency_unavailable, not_parsed, run_by_source (an R script another script runs with source(), which is run only inside that script, since on its own it lacks the packages and objects the sourcing script sets up first), run_by_import (a Python file other files import, a module rather than a script, unless it has an if __name__ == "__main__": block), jags_model (a JAGS or BUGS model saved with an R extension, which another script reads) or not_r_content (a file that is not R at all, such as a JSON or HTML dump); these last two are not run and are not failures. python2 marks Python 2 code that was not run. With sandbox = "docker" such code runs with Python 2.7 (option metacheck.docker_image_py2; FALSE turns this off), which modifications records; it is never converted, since that can change results. defines_functions is a file that only defines functions, which is used, not run (table$used_by names the scripts that use it), and not_analysis is a file of software rather than of the analysis: a package’s code, tests, documentation or setup.py, a copy of a tool, a web application, a script a program wrote (table$not_analysis_why says which); neither is run or counted as a script. docker_failed means the container never started, which says nothing about the script, so it keeps the light from being green but does not make it red. needs_a_person is a script that stopped because it asks a person to choose a file or answer a question, or that starts an app, and needs_internet one that stopped because the network is off in a Docker run, or, with internet = TRUE, could not reach what it asked for; download_too_large is a script stopped for downloading more than the limits allow (see internet), and out_of_memory one that, or a program it started (such as a compiler), ran out of the memory each script may use. All four are treated the same way. not_downloaded is a script that stopped on a file the repository lists but that was not downloaded, such as one over max_file_size: it could not be tried, so it is not counted as a script that did not reproduce (summary_table$repro_not_downloaded_n counts them apart). not_read is a file metacheck could not read, so it was not run; the light is then not green, as the file may read and run on another computer, and table$error_message says why, naming a package that is installed but cannot be loaded on the computer that ran the check. empty is a file with nothing in it, which is not run or counted as a script. For a script that did not run through, table$error_message is its error, short (at most 300 characters): the error line of its output, which names a package that is not there, with the address it asked for when it needed the internet, or the time limit it reached; table$reason sorts it into a kind. A timeout means “still running at the cutoff”, not a failure, so raise timeout for legitimately long-running (e.g. Bayesian) scripts. dependency_unavailable means the script’s own package could not be installed from live CRAN, the CRAN Archive, or a named GitHub/URL source — an infrastructure limitation, not a defect in the paper’s code. The full stdout/stderr of every run is kept in the result’s run_results (the report shows it in per-script dropdowns, capped for readability).

run_results$checked says what the run of each script shows about the code, in five groups, so that a script that does not reproduce is kept apart from one the check could not test: ran (it ran to the end); code_error (it did not reproduce: it stopped with an error of the code or the deposit, could not be read, or needs a file the deposit does not hold); dependency (a package or program was not available: a package that could not be installed or was not loaded, a program outside R and Python, a system library, or R crashing in a package’s compiled code); time (it did not finish within the time limit for one script, or was not started because the time for all scripts had run out); and not_checkable (it could not be checked automatically: it needs a person, the internet, a key or another setting of the authors’ computer, one platform such as Google Colab, Windows or OpenSAFELY, more memory than the run allows, a file that was not downloaded, a screen, or a program that runs it, or it is a file of a package of the code that Python runs only as a module of that package). It is NA for files run inside another script, files that are not an analysis, files not read, and a Docker failure. summary_table counts each group (repro_ran_n, repro_code_error_n, repro_dependency_n, repro_time_n, repro_not_checkable_n), and the report’s first sentence gives them. The traffic light reflects the static readiness signals by default; a script in code_error that stopped with an error makes it red, as a script that crashes on its own analysis is a genuine reproduction failure, and a script in one of the other three groups keeps it from being green. Calls that need a screen, which the run does not have (dev.print(), dev.copy2pdf(), dev.copy2eps(), savePlot(), windows(), win.graph(), x11(), quartz(), View()), are replaced before the run by calls that need none, which modifications records as screen_call_replaced. A script that fails with could not find function is run once more with the library() calls the project’s other scripts make added at its top (or the one package that exports the function, or magrittr for %>%), and a script that then runs is reported as reproducible only after that repair.

Dependencies are reported name-only, with the source (CRAN, GitHub, or a base package already shipped with R) — static analysis of the code cannot know which version was used, and running against current package versions is itself informative: a break argues the authors should have pinned versions. When the repository does record versions, a run with recorded_versions = TRUE installs the packages the scripts load at those versions, but it does not change the R version, which remains a limitation of the check.

Run order is derived from read-after-write data dependencies (a script writing a file another reads must run first), source() edges, and numeric filename prefixes as a weak tie-breaker. Ambiguous orderings, dependency cycles, and inputs a script reads but that no earlier script produces (and that are not in the repository) are surfaced as warnings, since these are the situations most likely to make an otherwise-correct reproduction fail.

Python code (.py files, and notebooks and Quarto documents whose code is Python, from which the code is extracted first) goes through the same two phases, reported in its own “Python code” section. Each file is checked for syntax errors with Python’s own parser when a Python interpreter (python, or else python3) is available; dependencies are read from the import statements, with versions from a requirements.txt or pyproject.toml when there is one, and installed with pip; each script runs as its own python process (processx is required), so unlike R scripts, a name one script defines is not available to another. When no Python interpreter is available, the Python files are reported as not run and the R results are still returned. Statistics the Python scripts print are compared with the paper together with the R output and any self-reproducible output (JASP/jamovi, SPSS-Viewer, notebook outputs).

Full text

Abstract

Motor intention reflects the decision to perform a goal-directed voluntary action independent of external stimuli. Yet, the private nature of motor intentions makes it difficult to measure them objectively. Here, we use the premotor shift of attention (PSA), an enhancement of perceptual processing at upcoming movement goals, as a novel approach to measure motor intentions. Across two experiments, participants freely chose their movement goals, without spatially specific cues. In doing so, we were able to assess intentional aspects of movement without confounding them with cue-driven priority. Results yielded consistent evidence for attentional enhancement at goals of selfdetermined pointing movements, demonstrating that motor intention alone was sufficient to give rise to PSA. Attentional benefits also extended to another part of the same object, indicating selection over object representations rather than spatial coordinates alone. Together, these findings establish premotor attention as a simple behavioral marker of motor intention.

Tracking motor intention using attention

Motor intentions represent the precursors of our everyday actions. They specify the goals and parameters of voluntary movements before their execution, independent of external sensory cues (Haggard, 2008; Seghezzi et al., 2019). Yet intentions are inherently private, which makes them difficult to observe from the outside. Measures of intention have mostly relied either on self-report (most notably judgements of the moment an urge to move was first felt; Libet et al., 1983), or on neural activity preceding movements (such as the readiness potential or preparatory activity in the brain; Cunnington et al., 2003; Schurger et al., 2021). Both approaches, however, have their limitations. Selfreports are subjective and open to retrospective reconstruction (Kühn & Brass, 2009; Wegner, 2004) while neural markers require specialized recording and analysis. Conversely, an objective behavioral measure capable of tracking motor intention is still missing.

Studying motor intention inherently requires the use of internally driven, or self-determined actions (Passingham et al., 2010). These can be contrasted with externally driven actions, which are extrinsically induced by cues or instructions (Haggard, 2008; Seghezzi et al., 2019). Such actions can be no less intentional, but here the external cue specifies part of what is done and when, making it hard to dissociate cue-related contributions from that of intention. Notably, despite some overlap in the neural substrates of both action types, internally driven actions engage additional decision-related processes (Mueller et al., 2007) and exhibit distinct neural and behavioral signatures (e.g., Ariani et al., 2015; Krieghoff et al., 2011; Schenk et al., 2003; Schenk & Mai, 1999), highlighting that the two are not merely procedurally different, but neuronally dissociable. Therefore, only when actions are freely chosen rather than externally cued, can their intentional dimensions be examined in isolation.

One promising avenue for investigating the content of motor intentions lies in the tight coupling between attention and action. Neurophysiological studies in humans (Beauchamp et al., 2001; Corbetta et al., 1998) and non-human primates (Moore & Armstrong, 2003; Müller et al., 2005) have documented a considerable overlap of the neural substrates of visual attention and eye movement control. Moreover, behavioral experiments have established that eye and hand movements are preceded by a so-called premotor shift of attention (PSA), reflected in a spatially selective enhancement of visual processing at the upcoming movement goal (Deubel & Schneider, 1996; Jonikaitis & Deubel, 2011; Wollenberg et al., 2018). This (pre-movement) attentional orienting is widely interpreted as a behavioral readout of motor preparation, positioning PSA as a possible marker of spatial motor intentions that guide our actions (Bielas & Michalczyk, 2019).

The PSA phenomenon has been extensively studied using externally specified movement goals. However, no clear attempts have been made to explain PSA in the context of internally generated actions. Importantly, external cues (endogenous or exogenous) can independently increase spatial attentional priority (Fecteau & Munoz, 2006; Wolfe, 1994 Wolfe, , 2021) ) even without planned motor action. Moreover, overlearned symbolic cues such as arrows may further bias spatial attention (Chacón-Candia et al., 2023; Hommel et al., 2001) in ways that are not fully controllable. It consequently remains unclear how PSA maps onto intentional aspects of motor control in the absence of attentionmodulating cues. A critical test of a motor intention account of PSA requires isolating motor preparation from externally induced spatial bias. This can be achieved by examining internally generated actions, in which movement goals are freely selected rather than externally specified.

Demonstrating PSA under such conditions would reveal that it can emerge on the basis of motor intention alone, thereby establishing PSA as a tool to track of motor intention.

Our everyday actions are typically directed toward objects (for interaction) rather than toward abstract spatial coordinates. If PSA reflects motor intention rather than merely cue-driven spatial priority, it is conceivable that its effect may extend beyond spatial coordinates to object representations intrinsic to action goals. Visual attention shows a comparable bias in the absence of any action, wherein a cued location facilitates processing at uncued locations of the same object (Chen, 2012; Egly et al., 1994); a phenomenon known as object-based attention (OBA). Yet relatively few attempts have been made to establish whether OBA reliably extends to premotor selection in goal-directed action. It therefore remains an open question whether selecting one part of an object for an intended action enhances processing of other parts of the same object relative to equally proximal parts of different objects. Evidence for such an effect would highlight that premotor attention allocation is shaped by object representations rather than being exclusively governed by space-based mechanisms. This would support the idea that the PSA phenomenon relates to the selection of objects as action goals (consistent with Schneider, 1995) instead of simply reflecting the spatial parameters of a subsequent movement (Rizzolatti et al., 1987), thereby strengthening its standing as a marker of motor intention.

The present study employs a novel paradigm involving self-determined actions to address the fundamental question of whether PSA can be used as a viable behavioral marker to track spatial aspects of motor intention. Towards this, we test whether internally generated motor intentions are sufficient to elicit PSA when movement goals are self-determined rather than externally specified. Moreover, we examine the representational scope of internally driven PSA by testing whether it extends beyond spatial coordinates to object-based selection.

Experiment 1 Methods

Participants

The following steps went into determining the sample size for the current study. We first computed the average effect size of PSA across three recent dual-task studies (Hanning et al., 2018 (Hanning et al., , 2022;; Jonikaitis & Deubel, 2011) involving spatially cued pointing movements, which yielded a value of dz = 1.37. Importantly, however, the current study featured a self-determined movement task without the display of spatial cues, for which attentional effects are likely to be less pronounced. Thus, we decided to settle for a more conservative PSA effect size estimate corresponding to half of the computed cueassociated PSA effect size, that is dz = 0.68. Based on this conservative effect size estimate, we then performed an a priori power analysis (paired samples t-test, one-tailed, dz = 0.68, α = .05, power = 0.80), which indicated a minimum required sample size of N = 15 for the current experiment. The final sample size (i.e., the number of participants included in statistical analyses) was eventually set to N = 20, thereby further increasing sensitivity to small effects.

Data was collected from 22 participants. However, one participant did not complete the experiment. Moreover, due to an insufficient number of usable trials per condition, the data of another participant had to be excluded from the analysis (see Analysis section for details). Thus, 20 participants (median age: 26 years; range: 21 -40 years; 5 males; 3 left-handed) contributed to the final sample of the study. All participants reported normal or corrected-to-normal vision, and no motor impairment for the dominant arm. Written informed consent was obtained from all participants, and study participation was compensated either monetarily or in the form of course credits.

Experimental Setup and Procedure

Participants were seated on a chair and faced a monitor (Dell Alienware AW2518H) at a viewing distance of 72 cm (Figure 1a). Finger position of the index finger of the dominant hand was recorded via a touchscreen (Elo 2700 IntelliTouch, Elo Touchsystems, 1024 × 768 pixels; 40.7 cm width; 60 Hz) and mapped in real time to a circular black cursor (0.5° radius in visual angle) displayed on the monitor. To make it easier for participants to move their fingers above the surface, the touchscreen, placed on a table in front of participants, was positioned at an inclination of 15° degree. Thus, there was 75° offset between the planes of the touchscreen and the monitor. The display of the monitor was scaled to match the active area of the touchscreen, ensuring spatial correspondence between hand position and visual cursor feedback. Gaze position was recorded using an eye-tracker (EyeLink 1000, SR Research, Canada), and head movements were minimized with a chin-forehead-support.

Stimulus presentation and response collection were controlled using PsychoPy (v2024.2.5; Peirce et al., 2019). All stimuli were either white (RGB: 255, 255, 255) or black (RGB: 0, 0, 0) and presented against a grey (RGB: 128, 128, 128) background. Each trial followed a fixed sequence that started with the display of a distinct stimulus configuration (Figure 1b). This configuration consisted of a fixation landmark, containing a white fixation cross (1° × 1°) enclosed by a white circular outline (1° radius), and two white-outlined horizontal rectangles (20° × 5°), positioned above and below fixation (±7.5°).

At the beginning of each trial, participants were required to align both their gaze and the cursor (controlled by the index finger on the touchscreen) with the central fixation landmark. Fixation was considered successful when gaze position and cursor position were respectively registered within a distance of 3° and 1° around the fixation landmark center. Contingent on the detection of 300 ms of continuous eye and hand fixation, and following a variable delay of 500-1000 ms, the central fixation landmark was filled in white. This central illumination event acted as a go-signal prompting participants to freely select one of the four rectangle corners and perform a pointing movement that landed the cursor in the selected rectangle corner. Thus, participants determined movement goals internally, with the central go-signal conveying no spatial information regarding movement direction.

Between 200 and 300 ms after the central go-signal onset, four black stimuli (size: 1.2° × 1.2°) -one in each of the four implied rectangle corners -were briefly presented for 50 ms. One of these stimuli served as the to-be-discriminated probe stimulus ("3" or "E"), while the remaining three were distractor stimuli ("2" or "5"). The timing of these stimuli ensured that processing of the to-bediscriminated probe fell into the movement preparation interval, thereby allowing for an assessment of premotor attentional allocation.

Participants were instructed to initiate the pointing movement by lifting the finger from the central fixation reference and placing it directly into the selected corner, rather than sliding across the touchscreen, to ensure discrete pointing movements. Correct aiming was registered when the cursor (as controlled by the finger) landed inside any of the rectangle corners which were defined by 4 invisible squares (size: 6° × 6°; positions centered at [±7.5°, ±7.5°]). All other landing positions were registered as an incorrect aiming event. Participants were instructed to complete movements as quickly as possible after initiation (i.e., to minimize movement duration), which helped to ensure that movement planning occurred prior to movement onset and coincided with the probe stimulus interval.

Participants freely selected the movement goal among the four corners on each trial, but were instructed to distribute their responses evenly across rectangle corners throughout the experiment. To facilitate this, intermittent feedback screens (presented in steps of 48 trials) displayed the cumulative percentage of movements directed to each corner and the proportion of incorrect aiming trials, encouraging approximately equal selection (25% per corner) while minimizing errors.

After completing the movement, participants reported the identity of the probe stimulus using a keyboard (left arrow key for "3", and right arrow key for "E") with their non-dominant hand. Correct and incorrect responses were followed by high-and low-pitched tones, respectively. Additional auditory feedback messages were delivered when predefined movement violations occurred. If gaze left the fixation window before movement completion, the message "eye moved before finger" was presented. The message "incorrect aiming" was played when the cursor landed outside the designated corners. Further feedback signaled movement timing violations ("early movement," "late movement," and "slow movement"; see Analysis section for timing details). Participants were instructed to minimize all movement-feedback triggering events.

Prior to the main experiment, participants completed a brief practice session to familiarize themselves with the task and pointing setup.

Design and Trial Conditions

Trials were categorized into four experimental conditions based on the spatial relationship between the probe location and the movement endpoint (Figure 1c), i.e., the rectangle corner in which the pointing movement had landed. In congruent trials, probe and movement endpoints coincided. In incongruent-same trials, the probe and movement endpoint were in different corners of the same object. In incongruent-different trials, probe and movement endpoint were in different corners of different objects within the same visual hemifield. Note that the probe in the latter two incongruent conditions was equidistant relative to the selected corner. Finally, in incongruent-diagonal trials, probe and movement endpoint were in different corners of different objects that were diagonally placed across opposite visual hemifields.

The experiment consisted of 576 trials in the experiment, divided into 12 blocks of 48 trials each. There were 16 unique trial types which were made up of 4 movement goal positions × 4 probe positions relative to the movement goal position.

Analysis

Preprocessing. Data were preprocessed to classify trials according to experimental condition, determined by the movement endpoint and the position of the probe stimulus (see Design and Trial Condition). In addition, movement parameters were defined as follows: Movement latency was defined as the time between go-signal onset and movement initiation (i.e., time of finger lift-off from the touchscreen), and movement duration as the time between movement initiation and movement completion (i.e., timepoint of re-established finger contact with the touchscreen). Finally, movement error was defined as the Euclidean (cartesian) distance between the cursor landing position and the center of the invisible square corresponding to the selected corner.

Trials were excluded from further analysis if they met at least one of several criteria. Any trial triggering an online "incorrect aiming" feedback (described earlier) was excluded, thereby confining our analysis to reasonably accurate movements. In addition, we excluded trials associated with online "eye moved before finger" feedback (described earlier). This allowed us to insulate examined attentional effects from any influence of eye movement programming. To ensure that attention measures applied to the premotor interval, our offline analysis led to the exclusion of trials for which pointing movement onset preceded probe offset; we used a fixed online "early movement" feedback (triggered upon detection of a movement latency < 400 ms) to generally discourage rushed movement execution. Conversely, to ensure inclusion of reasonably rapid movements executed soon after probe presentation, trials with a movement latency > 700 ms (see also Hanning et al., 2022) were excluded on the basis of our offline analysis; a more liberal online "late movement" feedback for movements with a latency > 1500 ms was used to avoid excessive time pressure during the experiment. Finally, trials associated with an online "slow movement" feedback, triggered in the event of a movement duration > 500 ms, were excluded to focus on well planned, swift movements without online adjustments. Although for one participant nearly all trials were excluded due to frequent late movements (and therefore this participant was excluded from the analysis), the remaining participants retained enough usable trials (348 trials on average) to proceed with the analysis.

Statistical Analysis.

Since some data violated the assumption of normality, we consistently report the non-parametric Friedman test (test statistic: χ²F (df); effect size: Kendall's W) as an alternative to the repeated-measures ANOVA. Along with this, the Bayesian repeated measures ANOVA (BFM: Bayes Factor quantifying evidence for alternate hypothesis) are reported. Following the Friedman test, if a significant effect was observed, post-hoc comparisons using the non-parametric Conover test with Bonferroni correction (unless a specific pre-planned analysis was defined) were performed.

For the pre-planned assessment of the PSA effect, we conducted pairwise comparisons between the congruent condition and a measure obtained from collapsing across all incongruent conditions (incongruent-collapsed). Additionally, the congruent and incongruent-same conditions were compared as a more conservative estimate of the PSA effect. To evaluate the OBA effect, the incongruent-same and incongruent-different conditions were compared. All comparisons were performed on discrimination accuracy (percentage of correct probe discrimination responses) and reaction times (RTs; i.e., the time between probe onset and button press indicating the probe discrimination response) observed in trials associated with a correct discrimination response. Discrimination accuracy was treated as the primary dependent measure, whereas RTs served as a secondary measure. This relates to the fact that participants were instructed to discriminate the probe as accurately as possible, with no explicit encouragement of speeded discrimination responses. Moreover, RTs in our dual-task design (where perceptual discrimination follows motor execution) are contingent on motor performance and may therefore be influenced by motor-related variability. To account for potential speed-accuracy trade-offs, we additionally computed the Balanced Integration Score (BIS; Liesefeld & Janczyk, 2019 , 2022), which linearly combines speed and accuracy into a composite performance measure that is relatively uncontaminated by such trade-offs.

Pairwise comparisons were conducted using one-tailed Wilcoxon signed-rank tests. Effect sizes are reported as rank-biserial correlations (r), where r = 1 indicates perfectly consistent effects across participants. Bayesian Wilcoxon signed-rank tests (result based on data augmentation algorithm with 5 chains of 10,000 iterations) were additionally performed, and Bayes Factors (BF10) were reported to quantify evidence for the alternative hypothesis. Bayes factors were computed using a Jeffreys-Zellner-Siow Cauchy prior (with scale factor r = √2/2) and classified according to Jeffreys' criteria (van Doorn et al., 2021), whereby BF10 values of 1-3, 3-10, and >10 indicate weak, moderate, and strong evidence for the alternative hypothesis, respectively, whereas values of 0.33-1, 0.10-0.33, and <0.10 indicate weak, moderate, and strong evidence for the null hypothesis. All analysis were performed using JASP v0.95.4 (JASP Team, 2025) and custom scripts in Python.

Results

Movement Statistics

Per Corner Results: We first assessed whether certain movement parameters varied depending on which rectangle corner was selected as the movement goal. A Friedman test (non-parametric alternative to repeated-measures ANOVA) revealed a significant effect of corner on several movementrelated measures. The number of selections (movement endpoint counts) differed significantly across corners, χ²F (3) = 14.03, p = .003, Kendall's W = .23, BFM = 2246.39. Post-hoc comparisons revealed that participants landed more frequently in the bottom-left corner than in the bottom-right corner (diff = 5.57%; pbonferroni = .005, rrb = .78, BF10 = 22.05), and top-left corner (diff = 7.03%; pbonferroni = .005, rrb = .80, BF10 = 25.73). Movement latency also varied significantly by corner, χ²F (3) = 15.54, p = .001, Kendall's W = .26, BFM = 52.48. Latencies were longer for movements toward the top-left corner compared to bottom-left corner (diff = 15 ms; pbonferroni = .006, rrb = .76, BF10 = 28.06) and bottom-right corner (diff = 17 ms; pbonferroni = .003, rrb = .71, BF10 = 13.38). Similarly, movement duration differed between corners, χ²F (3) = 17.34, p < .001, Kendall's W = .29, BFM = 13.88, with shorter durations for movements toward the bottom-left corner compared to the bottom-right corner (diff = 49 ms; pbonferroni = .005, rrb = .59, BF10 = 5.86) and top-left corner (diff = 36 ms; pbonferroni = .011, rrb = .53, BF10 = 2.51). In addition, the duration of movements toward the top-right corner was shorter than that of movements toward the bottom-right corner (diff = 36 ms; pbonferroni = .005, rrb = .51, BF10 = 1.82). No significant differences between corners were observed with respect to movement error, χ²F (3) = 5.46, p = .141, Kendall's W = .09, BFM = 2.27. Overall, these results suggest some differences regarding the characteristics of pointing movements across the four corners. However, because the present hypotheses are theoretically independent of absolute spatial positions, these variations do not affect the core predictions of our study.

Per Condition Results:

We also checked whether movement parameters differed between experimental conditions. Friedman tests revealed no significant differences across the four conditions for any of the movement-related measures (counts, χ²F (3) = 5.52, p = .138, Kendall's W = .09, BFM = 0.92; movement latency: χ²F (3) = 1.62, p = .655, Kendall's W = .03, BFM = 0.1; movement duration: χ²F (3) = 2.82, p = .420, Kendall's W = .05, BFM = 0.13; and movement error: χ²F (3) = 0.78, p = .854, Kendall's W = .01, BFM = 0.11). Thus, when the relevant experimental conditions are considered, no substantial differences were observed in any of the movement parameters.

Premotor Shift of Attention

Attention modulations related to self-directed pointing were examined on the basis of probe discrimination accuracy. A Friedman Test revealed a significant difference in the discrimination accuracy (see Figure 3a) between the four conditions, χ²F (3) = 32.10, p < .001, Kendall's W = .54, BFM = 55986.51. Such general modulation does, however, not have a direct implication with respect to the presence of a PSA effect, which should be reflected in a selective enhancement of discrimination accuracy at the movement goal. In our design, such selective enhancement can be revealed on the basis of comparing discrimination accuracy between the congruent and incongruent conditions. Our first pre-planned pairwise comparison in that regard revealed a significant accuracy benefit (diff =13.86%) for the congruent condition (Mean±95%CI = 91.58±5.14%) when compared against the collapsed accuracy level across all of the three incongruent conditions (77.73±7.67%), z = 3.78, p < .001, r = 0.99, BF10 = 2680.97 (see Figure 3c). Importantly, this benefit was quite pronounced (diff = 9.84%) and statistically reliable even under the most conservative comparison between the congruent condition and the incongruent-same condition (81.74%±7.50%), z = 3.06, p < .001, r = 0.78, BF10 = 161.60.

The reaction times (RT) did not reveal any differences between the different conditions (see Figure 3b) in the Friedman test, χ²F (3) = 1.14, p = .767, Kendall's W = .02, BFM = 0.11. The pre-planned pairwise comparison between the congruent condition (918.84±83.73ms) and the data collapsed across all incongruent conditions (920.70±80.39ms) revealed no significant difference, z = 0.485, p = .324, r = 0.124, BF10 = 0.31. Likewise, no significant difference was observed for the most conservative comparison between the congruent condition and the incongruent-same condition (922.20±79.70ms), z = 0.67, p = .261, r = 0.17, BF10 = 0.33. Further, to eliminate the possibility of the increase in discrimination accuracy at the movement goal being driven by a speed-accuracy trade-off in our results, we computed the Balanced Integration Score (BIS). Results implied significantly better performance for the congruent condition compared to the data collapsed across incongruent conditions, z = 3.85, p < .001, r = 0.98, BF10 = 2121.69. Again, this result remained robust for the comparison of the congruent and incongruent-same conditions, z = 2.88, p = .001, r = 0.73, BF10 = 96.28. Taken together, these results provide consistent evidence for a PSA prior to self-directed pointing, as observed in the absence of an external cue.

Object-Based Premotor Attention Effect

To examine whether self-directed pointing induces an OBA effect, discrimination performance was compared between the incongruent-same and incongruent-different conditions (see Figure 3d). A pairwise-comparison revealed a significant increase (diff = 7.15%) in discrimination accuracy for the incongruent-same condition compared to the incongruent-different condition (74.60±8.63%), z = 2.95, p < .001, r = 0.75, BF10 = 151.02. Reaction times did not reveal a difference between the two conditions, z = -0.90, p = .816, r = -0.23, BF10 = 0.13. Although non-significant, reaction time was slightly shorter (diff = 7.43ms) in the incongruent-different condition (914.77±81.10ms) compared to the incongruentsame condition. When taken together with the accuracy data, this might suggest a speed-accuracy trade-off. To avoid any undue influence of such a possible trade off, we computed the BIS, which clearly indicated the existence of a true OBA effect, z = 2.91, p = .001, r = 0.74, BF10 = 111.42. These results strongly support the idea that the preparation of self-directed pointing movements was associated with an OBA effect.

Experiment 2

Experiment 1 demonstrated PSA and OBA effects prior to manual actions towards freely selected (i.e., uncued) movement goals. These results were obtained using a classical two-alternative forced choice perceptual task, in which participants were anticipating to discriminate the identity of a single probe stimulus on each trial. Accordingly, the attentional effects observed here might be somewhat specific, and possibly limited, to an active, template-driven search mode. To go beyond this possible limitation, we next aimed at examining premotor attention allocation in a slightly different task with a more complex probing scenario, i.e., one entailing the presentation of multiple task-relevant probe stimuli on each trial. As such, Experiment 2 served the purpose of internally replicating our novel findings under different, more complex perceptual demands, and thus substantiate attention as a robust, general marker for spatial motor intention.

Methods

Participants

Data were collected from 21 participants. However, one did not complete the session and was subsequently excluded from the analysis. Thus, 20 participants (median age: 25 years; range: 20-36 years; 8 males; 1 left-handed) contributed to the final sample. As in Experiment 1, all participants reported normal or corrected-to-normal vision and no motor impairment for the dominant arm. Written informed consent was obtained from all participants, and study participation was compensated either monetarily or in the form of course credits.

Experimental Setup and Procedure

The setup was identical to Experiment 1 and the procedure followed the same course until the gosignal appeared (see Figure 1). Between 200 and 300 ms after the onset of the central go-signal, four black digits (0-9; height: 1°; font: Arial) appeared briefly for 25 ms, with one digit presented at each of the four rectangle corners. Other than in Experiment 1, all of these digits constituted probe stimuli. Accordingly, instead of reporting a single probe stimulus, participants were required to report the various digits they had perceived by typing them into a small rectangular box displayed on the screen after movement completion. In Phase 1, participants reported as many digits as they had perceived with confidence in a particular trial, yielding a relatively straight-forward measure of perceptual priority. In Phase 2, they were required to report all four digits presented in the trial, with the instruction to guess any digits they had not consciously perceived. Thus, Phase 2 required participants to exert additional effort and potentially assign equal importance to all four probed locations. Thereby, we could observe the most conservative signature of PSA, i.e., the spatially specific intentional effect that survives despite the broader perceptual task demands. All other aspects of the experimental procedure, including the instructions for initiating and completing the pointing movement, the definition of correct aiming, the free selection of movement goals with balanced distribution across corners, and the auditory feedback for movement violations were identical to the previous experiment (see Experiment 1 for details).

Design and Trial Conditions

Unlike Experiment 1, where only one probe was presented and trials were categorized based on the spatial relationship between the probe location and the movement endpoint, Experiment 2 comprised all four conditions within each trial. Conditions were defined relative to the movement endpoint, i.e., the rectangle corner selected by the participant via a corresponding pointing movement. The selected corner itself constituted the congruent condition; the other, unselected corner of the same rectangle constituted the incongruent-same condition. The corner of a different rectangle within the same visual hemifield as the movement endpoint constituted the incongruent-different condition, whereas the corner diagonally opposite the movement endpoint, in a different rectangle across the opposite visual hemifield, constituted the incongruent-diagonal condition.

The experiment was divided into two phases. Phase 1 consisted of 5 blocks of 48 trials each (240 trials total), in which participants were instructed to report as many digits as they had confidently perceived on a given trial. This was followed by Phase 2, which also consisted of 5 blocks of 48 trials each (240 trials total). Here, participants were instructed to report all four digits presented in the trial, guessing if necessary.

Analysis

Preprocessing. Data were preprocessed following the same procedure as in Experiment 1, with the exception that experimental condition was determined solely by the movement endpoint, since all four digits appeared on every trial (see Design and Trial Conditions). All other aspects (such as, movement parameter definitions and trial exclusion criteria) were identical to Experiment 1. Note that, unlike in Experiment 1 (where online feedback thresholds were more lenient than the offline exclusion criteria), the online movement feedback criteria in Experiment 2 were identical to the offline exclusion criteria used for analysis. This resulted in a mean trial number of 180.4±15 and 166.3±18 in Phase 1 and Phase 2, respectively. Mean digits reported per trial in Phase 1 was 2.27±0.26 (in Phase 2 participants always reported 4 digits).

Statistical Analysis.

To maintain consistency with Experiment 1, we again report the non-parametric Friedman test (test statistic: χ²F (df); effect size: Kendall's W) along with the Bayesian repeated measures ANOVA (BFM: Bayes Factor quantifying evidence for alternate hypothesis). As in Experiment 1, we assessed the PSA effect by comparing the congruent condition against the incongruent-collapsed measure, as well as against the incongruent-same condition alone (a more conservative estimate). The OBA effect was assessed by comparing the incongruent-same and incongruent-different conditions. In Experiment 2, all comparisons were performed on report rate and mean report rank per condition. Report rate was defined as the percentage of trials on which a digit associated with a specific condition was correctly included in the participant's response, regardless of its rank in the order of reported digits. Mean report rank per condition was defined as the average sequential position (1 st , 2 nd , 3 rd , or 4 th ) at which the digit of a condition was correctly reported. The pairwise comparisons were conducted using one-tailed Wilcoxon signed-rank tests.

Results

Movement Statistics

As in Experiment 1, we first assessed whether movement parameters varied depending on which rectangle corner was selected as the movement goal. Here, movement statistics are reported collapsed across the two phases. A Friedman test revealed a significant effect of corner on several movementrelated measures. The number of selections (movement endpoint counts) differed significantly across corners, χ²F (3) = 24.52, p < .001, Kendall's W = .41, BFM = 3.48×10 3 . Post-hoc comparisons revealed that participants landed more frequently in the bottom-left corner than in the bottom-right corner (diff = 5.45%; pbonferroni = .004, rrb = .84, BF10 = 22.16), top-left corner (diff = 9.49%; pbonferroni < .001, rrb = .97, BF10 = 1100), and top-right corner (diff = 5.49%; pbonferroni = .027, rrb = .63, BF10 = 4.82). Movement latency showed no significant difference by corner, χ²F (3) = 6.90, p = .075, Kendall's W = .12 in the Friedman's Test. However, the Bayes Factor, BFM = 9.42 showed moderate evidence for the alternate hypothesis, with marginally higher latency for top-right compared to bottom-right corner (diff = 15.10 ms; pbonferroni = .060, rrb = .59, BF10 = 5.01). Movement duration differed between corners, χ²F (3) = 39.12, p < .001, Kendall's W = .65, BFM = 2.19×10 9 , with shorter durations for movements toward the bottom-left corner compared to the bottom-right corner (diff = 48.5 ms; pbonferroni < .001, rrb = .89, BF10 = 5254), and top-left corner (diff = 50.8 ms; pbonferroni < .001, rrb = 1.00, BF10 = 2.12×10 5 ). In addition, the movement duration toward the top-right corner was shorter than that of bottom-right corner (diff = 50.3 ms; pbonferroni < .001, rrb = .81, BF10 = 288.3), and top-left corner (diff = 52.6 ms; pbonferroni < .001, rrb = .99, BF10 = 2.14×10 5 ). Movement error also showed significant difference between corners, χ²F (3) = 19.62, p < .001, Kendall's W = .33, BFM = 360.40, with smaller error for movements toward the bottomleft corner compared to the bottom-right corner (diff = 0.20°; pbonferroni = .046, rrb = .68, BF10 = 6.51), top-left corner (diff = 0.28°; pbonferroni = .020, rrb = .71, BF10 = 11.82), and top-right corner (diff = 0.38°; pbonferroni < .001, rrb = .98, BF10 = 129.1). Similar to Experiment 1, these results indicate some variation in movement characteristics across the four corners. However, given that our hypotheses are independent of absolute spatial position, these variations do not affect our core predictions relating to attention allocation.

Premotor Shift of Attention

Attention modulations related to self-directed pointing were examined on the basis of report rate, separately for Phase 1 and Phase 2. In both phases (see Figure 4a), a Friedman test revealed a significant difference in report rate between the four conditions (Phase 1: χ²F (3) = 48.73, p < .001, Kendall's W = .81, BFM > 10 308 ; Phase 2: χ²F (3) =23.56, p < .001, Kendall's W = .39, BFM = 1.35×10 5 ). The pre-planned comparison between the congruent condition report rate and the collapsed report rate across the three incongruent conditions revealed a significant benefit in both phases (see Figure 4c); Phase 1 (diff = 26.27%): 60.43±4.31% vs. 34.17±5.95%, z = 3.92, p < .001, r = 1.00, BF10 = 6.62×10 4 ; Phase 2 (diff = 8.61%): 70.53±3.28% vs. 61.92±4.24%, z = 3.66, p < .001, r = 0.93, BF10 = 2247. This benefit remained significant also under the more conservative comparison between the congruent and incongruent-same (Phase 1: 46.88±5.82%; Phase 2: 66.34±4.04%) conditions for both phases; Phase 1 (diff = 13.55%): z = 3.66, p < .001, r = 0.93, BF10 = 3015; Phase 2 (diff = 4.13%): z = 2.46, p = .006, r =0.63, BF10 = 19.82. Taken together, these results provide consistent evidence for a pronounced PSA effect prior to self-directed pointing, extending the inference drawn from Experiment 1 to conditions featuring competition among multiple probe stimuli.

Object-Based Premotor Attention Effect

Similar to Experiment 1, we examined whether self-directed pointing induces an OBA effect by comparing report rate between the incongruent-same and incongruent-different conditions, separately for each phase. In both phases, a significant increase in report rate (see Figure 4c) was observed for the incongruent-same condition compared to the incongruent-different (Phase 1: 27.89±6.44%; Phase 2: 58.85±5.31%) condition; Phase 1 (diff = 18.99%): z = 3.92, p < .001, r = 1.00, BF10 = 1.31×10 4 ; Phase 2 (diff = 7.49%): z = 3.18, p < .001, r = 0.92, BF10 = 395.2). This replicates the OBA effect observed in Experiment 1, confirming that it persists even when multiple task-relevant probe stimuli compete for perceptual selection.

Report Rank Results

As a secondary measure, we examined report rank (i.e., the sequence in which participants reported each probe within a trial). Report order can index prioritization, as items held in a more accessible state are available for retrieval sooner. As such, an item reported early is often the one currently favored by internal attention or action preparation (Myers et al., 2017; Saito et al., 2025). Thus, if PSA indexes spatial intention, this should be reflected not only in whether a probe is correctly reported, but also in when it is reported relative to others. Figure 4d shows the proportion of correct reports as a function of report rank for each condition. Correctly reported digits of the congruent condition were most likely to rank first in the response sequence and correctly reported digits of the incongruentsame condition were most likely to rank second in the response sequence. To statistically test for such an implied primacy effect at the level of report order, we compared the mean report rank per condition (see Figure 4b). A Friedman test revealed a significant difference in report rank between the four conditions (Phase 1: χ²F(3) = 38.91, p < .001, Kendall's W = .65, BFM = 3.12×10 9 ; Phase 2: χ²F(3) = 39.78, p < .001, Kendall's W = .66, BFM = 1.70×10 11 ). In line with a PSA effect in terms of reporting primacy, pairwise comparisons (Wilcoxon signed-rank tests) showed that mean report rank was significantly lower for the congruent condition compared to incongruent-same condition (Phase 1: 1.42 vs. 1.61, z = -3.25, p < .001, r = -0.83, BF10 = 415.2; Phase 2: 1.93 vs. 2.13, z = -2.69, p = .003, r = -0.69, BF10 = 47.51). Likewise, there was evidence for an OBA effect, as reflected in a significantly lower report rank for the incongruent-same condition compared to the incongruent-different condition (Phase 1: 1.61 vs. 1.85, z = -3.58, p < .001, r = -0.91, BF10 = 2363; Phase 2: 2.13 vs. 2.52, z = -3.88, p < .001, r = -0.99, BF10 = 6918). Together, these report rank results provide converging evidence for PSA and OBA effects. In particular, they indicate that stimuli coinciding with the selected movement goal (or appearing within an object that is being targeted by a movement) gain discernible behavioral priority.

Performance Difference Between Phase 1 and Phase 2

To test whether performance differed between the two phases, we performed a 2 × 4 repeated measures ANOVA on the correct report rates, with phase and condition as within-subject factors. The main effect of Phase revealed better performance for Phase 2 compared to Phase 1 (see Figure 4a), F(1, 19) = 125.10, p < .001, ω² = .60, BF10 > 10 308 . Because Phase 2 always followed Phase 1, this effect could reflect either practice with the task or a genuine consequence of the change in task demands. The interaction term separates these two accounts. Because exposure was equal across conditions, a mere practice benefit should be uniform and produce no interaction. A change in task demand, by contrast, should benefit some conditions more than others, as reflected in an interaction. In keeping with this second option, the interaction was reliable, F(3, 57) = 28.76, p < .001, ω² = .20, BF10 = 1.01 × 10¹¹, and the improvement from Phase 1 to Phase 2 was clearly non-uniform (Figure 4a). Task exposure alone therefore cannot account for the phase effect. This distribution of gains suggests that the phases differ less in how much information about the different probe identities participants had than in how much of it they were willing to report. Free report in Phase 1 apparently made them withhold digits they felt unsure about. Put differently, participants may have reported only those digits that exceeded their individual reporting criteria, with digits outside the focus of attention going unreported. The requirement to always report four digits in Phase 2 removes that option, which would explain why report rate gains were largest for digits outside the attended object (incongruent-different: 30.96%; incongruent-diagonal: 32.83%) and smallest within the attended object where corresponding reports were already associated with high confidence in Phase 1 (congruent: 10.10%; incongruent-same: 19.46%). Importantly, the advantages indicative of PSA and OBA effects persisted in Phase 2 (see PSA and OBA results sections), even though forced guessing increases report rate precisely where it was initially lowest and therefore works against these effects rather than creating them. Phase 2 thus provides the most conservative signature of PSA, that survives even when the task requires attention to the whole display.

Additional Results of Experiment 1 and Experiment 2

Finally, we wanted to examine the possibility of an alternative explanatory account of our results. It could be argued that participants systematically moved to the position at which they happened to perceive a probe stimulus. Indeed, evidence in favor of such an alternative account would clearly undermine the validity of our conclusion that the observed enhancements of probe discrimination accuracy (Experiment 1) and probe report rate (Experiment 2) reflect selective attention allocation driven by the intention to move to a corresponding position. Instead, if it were true that participants simply moved to the perceived probe position, the observed visuo-perceptual modulations would be indicative of a more trivial association between probe processing and movement goal selection. A first indication arguing against the notion that our findings can be explained on the basis of probecontingent movement goal selection is that the large majority of trials in Experiment 1 belonged to one of the three incongruent conditions. In other words, the majority of trials in Experiment 1 involved pointing movements to positions other than the probe position (note that statements of that kind cannot be made for Experiment 2, as each of the four rectangle corners contained a probe stimulus). Assuming that movement goal selection was largely contingent on probes, one would, however, expect to observe that the majority of trials ends up in the congruent condition. Nonetheless, despite this apparent counterindication, we set out to further explore the viability of the proposed alternative account in light of our data based on two additional analyses. These analyses allowed us to test certain predictions that can be derived under the assumption that probe stimuli themselves played a central role in determining movement goal selection.

Probe onset does not meaningfully modulate movement latency: Our first additional analysis focused on examining whether movement latencies were substantially modulated by the probe timing, as would be expected when the decision where to move was largely contingent on selective processing of a probe stimulus. To this end, we assessed the relationship between probe onset and movement latency (both measures calculated relative to the go-signal) on the basis of correlations.

In Experiment 1, we observed a negligible mean Pearson correlation coefficient of r = 0.11 (W = 210.00, z = 3.92, p < .001). Although this effect was significant, it corresponds to a coefficient of determination of r² = 0.012, indicating that the probe onset timing accounted for only 1.2% of the variance in movement latency. However, under the proposed alternative account, it is conceivable that the relationship between probe timing and movement latency is strongest when participants actually point to the location of the (predefined) probe stimulus, i.e., in the congruent condition. Thus, we additionally correlated the two measures for the subset of trials corresponding to the congruent condition. Again, a negligible and almost unchanged correlation coefficient of r = 0.12 (W = 198.00, z = 3.47, p < .001, r² = 0.014) was observed. Equally negligible correlations coefficients were found in both phases of Experiment 2 (Phase 1: r = 0.13, W = 207.00, z = 3.81, p < .001, r² = 0.016; Phase 2: r = 0.11, W = 188.00, z = 3.099, p < .001, r² = 0.012). Together, these consistently marginal effect sizes (r 2 ) across experiments suggest that probe timing did not considerably affect movement latencies, providing no evidence in favor of the alternative account.

PSA and OBA effects remain robust in trials with short interval between probe and movement onset:

The rationale for the second additional analysis was also guided by considerations regarding the latencies of pointing movements. More precisely, assuming that our results mainly reflect the fact that participants pointed to positions at which they perceived a probe stimulus, then the reported PSA effect (and possibly also the OBA effect) should not be observed in trials for which movements were executed very rapidly after probe onset. This can be asserted because an external event (i.e., the probe stimulus) can only cause a motor response (i.e., a pointing movement) with a sufficient delay during which the response can be programmed. To examine whether our main results were preconditioned on a sufficient delay between probe stimulus and movement execution, we adopted a median-split approach. For each participant, we first computed movement latencies relative to the probe onset (rather than relative to the go-signal, and thereby establishing a direct measure of the time between probe onset and movement onset). We then selected only trials falling below the individual movement latency median, i.e., only trials in which the movement was executed relatively rapidly after probe onset. Using this "short movement latency" subset of our data, we re-ran our main analysis. Figure 5 depicts the main pattern of results of this analysis for Experiment 1 (left plot) and Experiment 2 (right plot).

Premotor Shift of Attention:

We observed the same pattern of results in the "short movement latency" data as in the full dataset. In particular, Experiment 1 showed a significant accuracy benefit for the congruent condition compared to the incongruent-collapsed measure (z = 3.66, p < .001, r = 0.93, BF10 = 2331). This effect remained pronounced and statistically reliable even for the most conservative comparison between the congruent and incongruent-same conditions (z = 3.62, p = .005, r = 0.68, BF10 = 27.60). Reaction times (not shown in Figure 5) showed no significant differences across these comparisons, while the BIS measure (also not shown in Figure 5) corroborated the accuracy analysis results (congruent vs incongruent-collapsed: z = 3.85, p < .001, r = 0.98, BF10 = 4094; congruent vs. incongruent-same: z = 2.87, p = .001, r = 0.73, BF10 = 94.46).

Experiment 2 similarly showed a significant increase in report rate (see Figure 5b) in the congruent condition relative to the incongruent-collapsed measure for both phases (Phase 1: z = 3.92, p < .001, r = 1.00, BF10 = 6389; Phase 2: z = 3.55, p < .001, r = 0.95, BF10 = 1406). Even under the more conservative congruent vs. incongruent-same comparison, this benefit remained significant (Phase 1: z = 3.73, p < .001, r = 0.95, BF10 = 2215; Phase 2: z = 2.74, p = .003, r = 0.72, BF10 = 36.56).

Object-Based Premotor Attention Effect:

Object-based modulations evident in the full dataset were consistently replicated in the "short movement latency" data. In Experiment 1, we observed a significant accuracy advantage the incongruent-same condition relative to the incongruent-different condition (z = 2.82, p = .003, r = 0.74, BF10 = 39.34). Reaction times showed no significant difference for the same comparison, while the BIS measure (z = 2.912, p = .001, r = 0.74, BF10 = 100.10) confirmed the accuracy results. Experiment 2 similarly revealed a robust perceptual advantage of the incongruent-same condition over the incongruent-different condition in both phases (Phase 1: z = 3.58, p < .001, r = 0.91, BF10 = 739.6; Phase 2: z = 3.06, p = .001, r = 0.80, BF10 = 193.5).

Further, for the "short movement latency" data, we observed mean movement latencies (relative to probe onset) of 277 ms (in Experiment 1), 241 ms (in Phase 1 of Experiment 2), and 249 ms (in Phase 2 of Experiment 2). By contrast, pointing movements prompted by a salient movement cue, as reported in Hanning et al. (2022), for instance, typically yield average latencies of more than 350 ms. Accounting for the fact that such longer latencies have been reported in response to a dedicated salient movement cue, they establish a lower-bound reference level for the speed at which pointing movements can conceivably be elicited contingent on more subtle stimuli such as our brief and hardto-detect probe stimulus. It therefore appears extremely implausible that our probe stimuli could have caused movements with latencies shorter than what is reported in standard paradigms with a dedicated salient movement cue. Together, our additional analyses provided no evidence to suggest that our findings can be explained in terms of probe-contingent movement goal selection. Against this background, we conclude that premotor attention allocation (PSA) was caused by motor intention and that the former therefore establishes a proxy for the latter.

General Discussion

Across two experiments, using a paradigm in which participants chose their own movement goal, we demonstrate a premotor shift of attention toward the goal of the forthcoming movement. This finding implies that a self-determined plan to act is sufficient to induce spatially selective perceptual prioritization and establishes that the PSA phenomenon does not depend on externally imposed, cuerelated prioritization. Furthermore, moving to a given part of an object (i.e., selecting part of an object as a movement goal) facilitated processing of another part of the same object relative to an equidistant location of a different object. The observation of such object-based modulation of PSA indicates that attention can operate at the level of object representations rather than being allocated in a purely space-based fashion. Importantly, insights from additional analyses argue against the possibility that our results can be explained in terms of probe-contingent movement goal selection. Together, these findings position PSA as an objective behavioral marker of intention that carries information about its contents (here, location and selected object).

Motor intention as a sufficient driver of PSA

Recent evidence from dual-task studies involving eye movements suggests that PSA is spatially coupled to the intended goal rather than to actual endpoint of motor actions (Wollenberg et al., 2018 (Wollenberg et al., , 2020)). However, in keeping with the large body of work on PSA, these studies relied on externally defined movement goals, specified by salient cues. Critically, such salient stimuli can trigger involuntary attentional shifts (attentional capture) toward corresponding locations, with electrophysiological markers showing initial attentional misallocation towards salient distractors, that are later reallocated toward the target (Gaspelin et al., 2023; Liesefeld et al., 2017; Mandal et al., 2024). Likewise, endogenous symbolic cues (like arrows) as well as semantic cues (like the words "left" or "right") can also bias spatial attention (Hommel et al., 2001), even when not presented in the visual modality (Ho & Spence, 2006). Thus, any externally specified movement goal can in principle bias attention toward a corresponding location, independent of movement preparation. Because prior studies focusing on the attention-action coupling relied on such cue-defined movement goals, their results may have confounded cue-driven spatial bias. Thus, it has remained unclear whether motor intention alone is sufficient to account for the perceptual enhancement attributed to PSA. The present study employed self-determined actions and evaded the influence of externally induced spatial priority on attention allocation. The emergence of PSA under these conditions provides evidence that motor intention alone is sufficient to drive the implied perceptual enhancement, positioning PSA as an observable marker for tracking motor intention. Here, motor intention is defined as an orientation toward a location (or object) for the purpose of executing a motor action. This conceptualization aligns with the one proposed by Bielas & Michalczyk (2019), who describe PSA in terms consistent with the phenomenological notion of pre-reflective intentionality. Within this framework, motor intention is understood as a pre-reflective process (i.e., preceding judgement, linguistic description, or introspection) characterized by a directedness toward possible action goals, rather than a purely reflective or linguistic plan for action.

Premotor attention as a behavioral marker for motor intention

Beyond this, the results have a practical significance for how intention can be studied. Introspective report remains the most direct route to intention, but it is available only after the action and is shaped by the act of reporting. Neural measures circumvent this problem, yet they require specialized recording. PSA requires neither. A perceptual probe presented during movement preparation is sufficient to indicate where a movement is directed and, as the object-based modulation demonstrates, how its goal is represented. Intention (and its contents) can thus be tracked with PSA, a simple behavioral measure. This measure directly relates to visuo-perceptual properties before the action is executed and it comes without recourse to self-report or neural recording requirements. Notably, our results highlight that PSA establishes a quite robust marker for motor intention, as we observed it even under the most conservative report format tested (Phase 2, Experiment 2). Together, this positions our approach as a way to measure intention where prior methods fall short. Ultimately, it may offer a tool for studying broader aspects of intention, volition, and agency in the future.

Premotor object-based attention effect and its implications regarding the attention-action coupling

PSA is a well-established phenomenon, but its explanation remains controversial, with at least two influential accounts of the attention-action coupling competing to explain it. The premotor theory of attention (Rizzolatti et al., 1987) holds that there is a strict spatial correspondence between attention allocation and motor programming. The visual attention model (Schneider, 1995), by contrast, treats attention as a fundamental mechanism underlying the selection of objects as goals for upcoming actions. The object-based advantage observed here is difficult to reconcile with the account offered by the premotor theory of attention and follows naturally from the visual attention model. Critically, the location that benefited was not itself a movement goal, and it was no closer to the goal than the corresponding location on the other object, so the advantage cannot be attributed to a spatial gradient centered on the programmed movement endpoint. Since many everyday actions often involve the interaction with or manipulation of objects, motor control processes can plausibly be assumed to operate over object-level representations. Our findings suggest that PSA reflects selection at precisely this level. Rather than being confined to the spatial coordinates of a narrowly defined proximal movement goal, PSA is sensitive to broader aspects of motor intention, particularly those involving interaction with objects.

Conclusion

In summary, a self-determined intention to act is sufficient to shift attention toward the goal of the forthcoming movement. The well-established PSA phenomenon therefore appears to reflect intentionally guided selection and can therefore be employed as an objective behavioral index of motor intention that specifies where the action is directed. Beyond closing a gap in the study of motor intention, where the available measures have been either introspective, uninformative about content, or simply difficult to obtain, this study opens a new perspective on the level at which attention and action interact. Methodologically, we introduce a novel way to examine intention through attention, that does not require an external cue to trigger a spatially directed action. Using this approach, we can read out behavioral priority regardless of specific reporting conditions. Having shown that it is possible to track motor intention with a simple behavioral measure, our approach can be extended to examine other dimensions of motor intention in the future.
