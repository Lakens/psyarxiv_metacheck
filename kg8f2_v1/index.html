Meta-scientific research has shown nonsignificant p values are commonly misinterpreted. It is incorrect to infer that there is ‘no effect’, ‘no difference’, or that groups are ‘the same’ after p > 0.05.

It is possible that there is a true non-zero effect, but that the study did not detect it. Make sure your inference acknowledges that it is possible that there is a non-zero effect. It is correct to include the effect is ‘not significantly’ different, although this just restates that p > 0.05.

How Exact P-Values works

List any p-values reported with insufficient precision (e.g., p < .05 or p = n.s.), reported as exactly zero (e.g., p = .000), or impossible (below 0 or above 1, e.g., p = -.22).

This module uses regular expressions to identify p-values. It will flag any values reported as p > ? or p < numbers greater than .001. It will also flag p-values reported as exactly zero (e.g., p = .000, p = 0.00), which are mathematically impossible — p-values are never exactly zero and should instead be reported as p < .001.

A p-value that is not the result of a test is not flagged: a table note (“* p < .05, ** p < .01”), a figure legend (“Asterisks indicate significant differences (p < .05)”, “Values in bold are significant at p < .05”) or a stated threshold (“p < .05 was considered significant”, “thresholded at p < .001”). GROBID often puts such notes into the running text, so each p-value is judged by the words in its own clause (the text up to a “;” or a full stop), and never left out when a test statistic belongs to it (“F(1, 7) = 8.03, # p < .05”). The column not_a_test of the table says why a p-value was left out (“marker”, “threshold”, “legend” or “named”).

A p-value with the name of a correction or a test after the p (“pFWE < .05”, “padj < 0.05”, “p Wilcoxon = .02”) is flagged only when a test statistic comes before it in its clause (“t(37) = 7.17, p FWE < .05”). Without one it is mostly the rule that decided what was significant (“genes with padj < 0.05 were selected”); such a p-value is “named” in not_a_test. Notes in other forms, such as a marker after the p-value (“p < .05 (*)“), are still flagged.

A p-value below 0 or above 1 is impossible; it is listed apart and not also as imprecise. Often the statistic before it, or its minus sign, was copied into it (“t(134) = -2.32, p = -.13”, “Z = 3.091, P = 3.091”). A value above 1 is listed only after a test statistic in its clause: without one, a “P” above 1 was nearly always another quantity (a proportion, pH, a group’s mean, a model parameter). A number in scientific notation whose power of ten was lost when the PDF was read (“p = 2.4 x 10 -9” read as 2.4) is not listed. A “p” that is the subscript of another symbol (“r p = .64”, “²p = .02” for partial eta squared, “Δp = .33”), or a quantity with a unit, a logarithm or a ratio (“P = 2.9 µm”, “-log10 P = 7.5”, “Ca/P = 1.67”), is not read as a p-value at all (see extract_p_values()). Each p-value has its own row, also when the same one is written twice in a sentence.

This module sometimes flags false positives when sentences discuss how p-value thresholds were set. It can also miss an imprecise p-value that is reported against a threshold (“decreased at the p < .05 significance threshold”).

This module only checks p-values reported in the running text of the manuscript. It cannot (yet) process p-values reported only in tables (as opposed to a table’s footnote text, which the module does see and tries to exclude — see above).

How Reproducibility Check works

This module assesses whether a paper’s R and Python code can be run on its data. It works in two phases. The static phase (always run) collects the package dependencies the code declares, rewrites the data-file paths that do not work in the repository as the authors organised it, works out the order the scripts must run in, and diagnoses why any referenced input file is unavailable — reporting what a reproduction attempt would involve and where it is likely to break. By default (execute = FALSE) the module does not run any code — it performs only static analysis: reading dependencies with the same extractors as code_check, finding the files the code references in the repository, and building a run-order dependency graph. It reports what would be installed and run rather than doing it.

When execute = TRUE, the module additionally runs the downloaded code on your machine — a deliberate, opt-in action gated behind that argument (callr is required for R code). Each script runs in an isolated subprocess so a crash cannot take down the R session; note this isolates crashes, not the filesystem or network. Installs (when install_missing = TRUE) and the throwaway run library never touch your main R library. Each script’s outcome is one of ran_ok, errored, timed_out, dependency_unavailable, not_parsed, run_by_source (an R script another script runs with source(), which is run only inside that script, since on its own it lacks the packages and objects the sourcing script sets up first), run_by_import (a Python file other files import, a module rather than a script, unless it has an if __name__ == "__main__": block), jags_model (a JAGS or BUGS model saved with an R extension, which another script reads) or not_r_content (a file that is not R at all, such as a JSON or HTML dump); these last two are not run and are not failures. python2 marks Python 2 code that was not run. Full text

Abstract

Various computational models have been proposed to explain interference and its resolution in word production. Of these, incremental learning models provide an elegant explanation of the interfering effects of the similarity between a target word and its context. However, such models have not been extended to explain how the production system deals with other kinds of interference, such as the presence of a prepotent distractor. It thus remains unclear whether incremental learning can furnish a general mechanism for explaining interference and its resolution in word production.

This paper proposes the Cognitive Control, Production, and Learning Model (CoCo-PaLM), a comprehensive learning-based model of interference and control in word production. In addition to capturing the previously modeled effects, CoCo-PaLM predicts sequential effects of control, as well as effects involving the transfer of control between the language system and non-linguistic systems. More broadly, the model establishes learning as a computational principle for explaining interference and control and offers a framework for dissociating the neural domain-generality of control from its implementation in specific domains.

Introduction

Cognitive control is the regulation of cognition and behavior in accordance with goals (e.g., Braver, 2012). In language production, control plays a prominent role, as speakers have many choices in terms of message, words, and syntactic structures to fulfill their communicative goals (Nozari, 2018; Quinn et al., 2025). While the relevance of cognitive control to production is undisputed, the mechanisms by which control is implemented remain vague. The goal of this paper is to provide an account of how word production is controlled, and how such control interfaces with control in non-linguistic tasks. We limit the scope of our investigation to single-word (as opposed to phrase or sentence) production, to have room to examine different kinds of interference involved in this seemingly simple operation. We maintain, however, that the principles derived from this investigation can be extended to the production of larger linguistic chunks.

This study has two goals: a language-specific goal and a more general goal. The languagespecific goal is to deliver a computational model of control in word production. We show that a language model, without appealing to language-external structures, can capture a number of empirical findings. At the same time, we demonstrate the shortcomings of that model in capturing other effects. On this basis, we argue that control in word production is best implemented as a hierarchical model, in which the core language model is embedded in a "domain-general" monitoring and control loop shared between the language production system and other cognitive systems (e.g., Acheson & Hagoort, 2014; Fedorenko, 2014; Fedorenko & Thompson-Schill, 2014; Piai et al., 2013; Wessel & Anderson, 2024; Wolna et al., 2024). We demonstrate that this hierarchical model, CoCo-PaLM (Cognitive Control, Production, and Learning Model), accounts for what the existing models of interference in word production account for, as well as new findings.

CoCo-PaLM also allows us to test the study's second goal, which is to develop an account of how domain-general neural systems implement control in specific domains. A central issue that we must confront is the distinction between neural and functional mechanisms. A tacit assumption in the field is that neural domain-generality (i.e., shared neural substrates of control across tasks) leads to functional domain-generality (i.e., transfer of control from one task to another; e.g., Hussey et al., 2017; Ness et al., 2023; cf. Nozari & Martin, 2024; Nozari & Novick, 2017). The assumption of functional domain-generality, in turn, underlies practices such as brain training, where training using a simple computerized task is expected to generate broad benefits for everyday functions (e.g., Au et al., 2015; Jaeggi et al., 2008; Klingberg, 2010; Schweizer et al., 2011), even though the empirical support for such benefits is in question (Gobet & Sala, 2023; Melby-Lervåg & Hulme, 2013; Owen et al., 2010; Redick et al., 2013; Sala et al., 2019; Sala & Gobet, 2019; Simons et al., 2016). We explore this assumption computationally by augmenting the core language model with a domain general control loop and simulating known empirical effects of the transfer of control between language and non-language tasks.

The link between the two goals is not arbitrary. To understand the implementation of cognitive control in lexical retrieval, which is the primary goal of this research, one must determine whether control in language production is domain-general or not. At the same time, language production is an excellent and often neglected tool for studying cognitive control. It is a naturally complex and highly generative task, which is nevertheless well-practiced. These characteristics allow us to go beyond artificial forced-choice button-press tasks with very limited response sets and arbitrary stimulus-response mappings often used in studies of cognitive control. Thus, our framework is highly informative for understanding the implementation of control, more generally, by providing a mechanistic account of the relationship between neural domain-generality and functional domain-specificity within and across control-demanding tasks.

We focus on tasks that require response selection; we do not address response inhibition in the form of withholding a response (Verbruggen & Logan, 2008; Wessel & Aron, 2017).

Throughout the paper, we use the term "interference" to refer to the behavioral manifestation of task difficulty, such as slow responses or errors. The mechanism underlying interference in our tasks is "conflict" or simultaneous co-activation of multiple responses that compete for selection (e.g., Botvinick et al., 2001). We use the term "monitoring" to refer to a continuous process of collecting information about the ongoing state of the system. In our model, this is achieved by continuously surveying conflict levels among units representing potential responses (Botvinick et al., 2001; Nozari et al., 2011; Verguts & Notebaert, 2008; Yeung et al., 2004). Finally, we use the term "control" to refer to the active adjustments in the system, in response to the information collected by the monitor, at the service of optimizing performance in accordance with task goals (Braver, 2012; Nozari, 2025b).

The Problem of Lexical Retrieval and Its Relevance to Cognitive Control

The current study targets lexical retrieval, a key component of word production. We chose lexical retrieval, as it is one of the most well-studied phenomena in language production (Dell, 1986; Goldrick et al., 2014; Levelt, 1989; Levelt et al., 1999). To produce a word, speakers must first activate the concept behind the word. This concept may be activated by external stimuli (e.g., a picture of a cat, real objects like the cat itself, etc.), or internally, via memory recall. It is now largely accepted that concepts are represented in a distributed network, with potential hubs to connect and condense individual features (Lambon Ralph et al., 2017). The concept activates abstract lexical representations, which carry grammatical information such as grammatical gender for nouns or argument structures for verbs, but do not represent forms (Caramazza, 1997; Dell, 1986; Garrett, 1980). In the next stage, lexical items are mapped onto their segments (phonemes in spoken and graphemes in written production); those segments are sequenced, and finally commands are sent to motor effectors for execution.

This study focuses on the first stage of this process, namely, the mapping of semantic features onto lexical items. The challenge here is that such mapping is not exclusive to the target.

Other lexical items that share some of the semantic features with the target item are simultaneously activated. For example, upon seeing the picture of a cat, other furry four-legged animals, such as dogs, also come to mind, and their lexical entries are correspondingly activated. This co-activation creates conflict during selection (e.g., Nozari et al., 2011). Evidence for such conflict comes from a large body of work showing that introducing semantically related items (e.g., "dog" for the target "cat"), either as distractor words or as previously named items, causes interference in naming the target (Belke et al., 2005; Damian & Martin, 1999; Howard et al., 2006; Ganushchak & Schiller, 2008; Glaser & Düngelhoff, 1984; Lupker, 1979; see Bürki et al., 2020, for a meta-analysis). While this interference is relatively mild and often manifests in slowed response times in neurotypical individuals, it often leads to overt semantic errors in individuals with post-stroke damage to the language system (aphasia; Dell et al., 1997; Schwartz et al., 2009), showcasing the necessity for the successful resolution of conflict during lexical selection.

Resolving conflict in lexical selection has often been tied to domain-general cognitive control, mostly through correlational analysis: researchers have examined the correlation between the size of interference in a generic cognitive control task, such as Stroop (Stroop, 1935), flanker (Eriksen & Eriksen, 1974), Simon (Simon, 1969; Simon & Rudell, 1967; Simon & Wolf, 1963), etc., or a combination of control tasks (e.g., Miyake et al., 2000) and performance on some aspect of lexical retrieval. Such studies have reported mixed results (Alario et al., 2012; Boned et al., 2021; Calabria et al., 2019; Crowther & Martin, 2014; Shao et al., 2012 Shao et al., , 2013 Shao et al., , 2015)).

Methodological problems with the analysis of individual differences and low test-retest reliability in cognitive control tasks (Hedge et al., 2018) aside, there is potentially also a conceptual problem here: such studies assume that neural domain-generality of control regions necessarily leads to functional domain-generality in control, meaning that being connected to the same control center makes it possible to predict how well control should operate in picture naming based on how well it operates in the flanker task. However, this assumption has been demonstrated to be false (Nozari & Martin, 2024).

If the analysis of individual differences is difficult to interpret as a means of investigating the involvement of control in lexical retrieval, what is the alternative? Here, we lay out a blueprint of such an approach in four steps and carry out those steps in the following sections. As explained earlier, interference is simply a behavioral observation; it does not define a mechanism. It is usually mediated by underlying conflict, which relies on monitoring and control for its resolution. At this stage, the key question is: Is all conflict resolved using the same mechanism or not? Answering

Are All Types of Conflict Resolved the Same Way?

A very large body of literature has examined interference in word production, using different kinds of paradigms. These studies can generally be divided into two groups: those that have investigated the interference induced by the similarity between a target and its context (contextual similarity), and those that have examined the interference induced by the presence of a strong non-target alternative that biases processing away from the target (prepotent response).

These two sources of interference have clear relevance to everyday language production and may even coexist: many conversations involve mentioning items from the same category (e.g., what ingredients to buy for cooking dinner, which clothing items to match for a party, etc.). Moreover, many social conversations demand overriding a prepotent response. For example, if a dish you are served at a dinner party naturally evokes the word "terrible", you may have to override that response with the word "delicious" when asked for your opinion. The paradigms used for examining these two effects are also some of the most well-known and widely used paradigms in psycholinguistic research. Below, we provide a brief summary of these paradigms and their main findings.

Contextual Similarity

Contextual similarity refers to the interference that arises when a target item shares semantic or segmental features with other items in the context in which it is produced (Belke et al., 2005; Breining et al., 2016; Harrison et al., 2020; Nozari, Freund, et al., 2016; Schnur et al., 2006 Schnur et al., , 2009)). Most relevant to lexical selection, which is the primary focus of this paper, is semantic similarity. Semantic similarity itself can be divided into taxonomic and thematic similarity (Mirman et al., 2017; Zhai et al., 2024; Zhang et al., 2023). Taxonomic similarity refers to items within the same category (e.g., cat, dog, sheep; category of animals). Thematic similarity refers to items that do not belong to the same categorical cohort, but often co-occur around a theme (e.g., balloon, cake, present; theme of a birthday party). Generally speaking, taxonomic, but not thematic, relations cause interference in language production (Alario et al., 2000; Belke & Stielow, 2013; Costa et al., 2005; Damian & Martin, 1999; Howard et al., 2006; Mahon et al., 2007; Oppenheim & Nozari, 2024; see Nozari & Pinet, 2020, for a review). Since our focus is on interference and its resolution, we focus on studies of taxonomic similarity, hereafter simply referred to as contextual similarity.

Two paradigms have often been used to study pure contextual similarity in picture naming (i.e., without additional demands, such as the suppression of prepotent responses): continuous naming (CN) and blocked-cyclic naming (BCN) paradigms. In the CN paradigm, participants name a series of pictures containing exemplars from the same semantic category. Reaction times (RTs) increase linearly as a function of the ordinal position of the item within the target category, demonstrating a clear cumulative interference effect (e.g., Alario & Moscoso del Prado Martín, 2010; Howard et al., 2006; Schnur, 2014). In the BCN paradigm, participants name small sets of pictures that repeat across multiple cycles. In the homogeneous condition, all items within a block are drawn from the same semantic category (e.g., dog, cat, lion, sheep, cow), whereas in the heterogeneous condition, items are drawn from different semantic categories (e.g., dog, shirt, boat, pear, book). Although mean RTs generally decrease across cycles in both conditions, RTs in the homogeneous blocks are consistently longer than those in the heterogeneous blocks starting from cycle 2, demonstrating clear semantic interference (e.g., Belke et al., 2005; Damian et al., 2001; Schnur et al., 2006; Shao et al., 2015). However, whether this interference continues to accumulate across cycles or stabilizes after the first cycle remains debated in the literature; some studies report cumulative interference across cycles (e.g., Schnur et al., 2006), while others fail to observe such accumulation (e.g., Belke, 2013; see Wöhner & Jescheniak, 2026, for a review).

In short, both CN and BCN paradigms reveal a robust contextual interference as a function of taxonomic similarity between the target and context. Although both tasks tap contextual similarity, it is important to note that each has a unique place in the language literature. Specifically, CN addresses lexical retrieval without repetition, whereas BCN focuses on the repeated production of a small group of items, a situation that is often used in training vocabulary in a new language or re-training vocabulary after brain damage (e.g., Nozari et al., 2026). This difference brings in additional complexities to BCN, including priming effects and a possible role for working memory (Belke & Stielow, 2013; in later cycles, naming each picture makes the remaining pictures more predictable), possibly explaining the differences observed in the cumulativeness of interference (Crowther & Martin, 2014).

Prepotent Response

Interference can also arise from the need to suppress a prepotent non-target response, which is commonly investigated with the picture-word interference (PWI) paradigm (Lupker, 1979; Rosinski et al., 1975). In the PWI task, participants are asked to name pictures while ignoring a simultaneously presented distractor word (often presented as a word superimposed on the picture) or a non-lexical string (such as "XXXX"). Previous research has shown that RTs and error rates are significantly higher when the distractor is a word compared to a non-lexical string, indicating that the interference is driven by the lexical properties of the distractor rather than its visual features (e.g., Piai et al., 2016). Furthermore, when the distractor word is the actual name of the picture (the congruent condition), performance is better than when it does not (incongruent condition; e.g., Glaser & Düngelhoff, 1984; La Heij, 1988). It is worth mentioning that PWI has also been used to demonstrate interference arising from contextual similarity by manipulating the relationship between the picture and the superimposed distractor. The general finding matches that discussed in the previous section: taxonomic relationships interfere with production. For example, the incongruent trial with the target picture of a "cat" and the taxonomically related distractor word "dog" creates more behavioral interference than the incongruent trial with the picture of a "cat" and the unrelated distractor word "pen" (Costa et al., 1999; La Heij et al., 1990; Rayner & Springer, 1986; Schriefers et al., 1990; van der Burght & Meyer, 2025).

In short, the main PWI effect is the interference created by any lexical distractor (related or unrelated) presented over a target picture. Taxonomic relatedness of the distractor to the target can increase the overall interference effect, but this increase is small compared to the interference generated by any distractor. When we use PWI as a prime example of a task imposing a prepotent distractor, we are focused on the main effect of lexical interference, which encompasses both related and unrelated distractors.

Same or Different Mechanisms?

Although both contextual similarity and a prepotent distractor produce behavioral interference that can be successfully resolved, behavioral and neural evidence suggests distinct underlying mechanisms. Nozari, Freund, et al. (2016) presented participants with several blocks of pictures to name. Each block had only two pictures, each repeated multiple times at random. Two manipulations were embedded in this design: (a) contextual similarity, which was manipulated by changing the relationship between the two pictures within a block (e.g., semantically related: hat/wig, initial-segment-overlap: pen/pot; final-segment-overlap: cup/map).

(b) Presence of a prepotent response was manipulated by asking participants to reverse the names of the two pictures in the second half of each block. For example, if they saw a picture of "hat", they would have to say "wig" and vice versa. As expected, both manipulations created behavioral interference. However, the interference due to semantic similarity and prepotent response suppression during name reversal did not interact.

In an EEG study, Pinet and Nozari (2023) replicated the findings of Nozari, Freund, et al. (2016) with a new set of materials: they found interference, both as a function of semantic similarity and name reversal, which were orthogonal to one another. Classic stimulus-locked EEG analyses revealed stark differences between the electrophysiological signatures of semantic similarity and name reversal. The two effects had opposite polarities, different timelines, and different topographies. Response-locked analyses revealed similar effects. Finally, a representational similarity analysis (RSA) showed a sustained effect of similarity throughout the trial, with greater similarity scores for the semantically related compared to the unrelated condition. In contrast, a clearly biphasic electrophysiological signature was observed for name reversal, with a higher similarity score for the reversed compared to the straight trials in the first half of the trial, followed by a clear reversal of similarity scores in the second half of the trial. This switch was interpreted as the point of control implementation to tease apart the two representations.

More recently, Pirnia et al. (2026) reanalyzed Pinet and Nozari's (2023) data with machine learning methods. This is the most powerful approach to analyzing the EEG data, as it takes into account data from all 128 electrodes, for the entire trial duration, across all participants. The authors reasoned that if there was a common mechanism for resolving conflict due to contextual similarity and name reversal, it should be possible to uncover shared high-vs. low-conflict neural states between the two trial types. Specifically, a classifier trained to differentiate between highand low-conflict trials as defined by contextual similarity of the two words (similar vs. not similar, respectively) should be able to successfully classify high-and low-conflict trials as defined by name reversal (reversed vs. not reversed) and vice versa. The authors showed that several classifiers, when trained on the contextual similarity data, could successfully tease apart high-vs. low-conflict trials in that task. The same success was obtained when classifiers were trained and tested on the name reversal data. Moreover, the study showed generalization to new participants: using a leave-one-out approach, the authors demonstrated that, when trained on the name reversal of 27 participants, the classifier could successfully classify high-vs. low-conflict states of the leftout 28 th participant in name reversal. Finally, conflict states could be cross-classified between semantic and phonological similarity within the contextual similarity manipulation. Despite these successful generalizations, cross-task classification between contextual similarity and name reversal was completely at chance, providing no support for common conflict states across the two sources of conflict.

To summarize, behavioral data, classic EEG analysis, RSA analysis, and classification approaches to analyzing EEG data have provided converging evidence for a separation of the mechanisms underlying conflict resolution induced by contextual similarity and a prepotent response. This separation has a solid theoretical motivation (Nozari, 2025a): For contextual similarity, even though non-target items create competition with the target item, the stimulusdriven information leads processing towards the target as the response. For example, in CN, the stimulus is the picture. In neurotypical individuals, a picture activates, first and foremost, its own label, not the label of any of the semantically similar distractors. In contrast, in tasks such as PWI or name reversal, the stimulus information actually biases competition in favor of the non-target item to be selected as the response: the word printed on the picture (or at times spoken over the picture) has privileged access to a name response, through the reading or the auditory processing route (Mahon et al., 2007), when compared to the picture which must first be semantically decoded. In name reversal, the presented picture strongly evokes its own name, which must be suppressed before the alternate word can be produced. This suppression must be guided by a task goal that is set and maintained throughout the task. Maintaining task goals is one of the most widely agreed-upon functions of domain-general control regions such as the prefrontal cortex (Braver, 2012; Duncan, 2010; Miller & Cohen, 2001; Wiecki & Frank, 2013).

Key Characteristics of Interference Caused by Contextual Similarity and a Prepotent Response

The empirical evidence reviewed above pointed to different mechanisms underlying the interference caused by contextual similarity and a prepotent response. This section investigates their key characteristics, which, in turn, point to some similarities. A key characteristic of interference caused by contextual similarity is that it is long-lasting and largely immune to the insertion of irrelevant items between the semantically related items. For example, Howard et al. (2006) showed that the magnitude of semantic interference remained unaffected by lag, defined as the number of unrelated intervening items (i.e., 2, 4, 6, or 8 intervening items). Schnur (2014) also reported robust interference when 2-8 lags separated two semantically related items in CN. The author further showed that under some circumstances, interference can persist across even longer lags (e.g., 14). In a similar vein, Hepner and Nozari (2020) showed that lexical perseverations on pictures that were semantically related to a previously named item showed long lags, with median lags between 35-40 items in three individuals with aphasia who demonstrated many such perseverations. Just like CN, BCN interference also persists despite longer intervals and insertion of unrelated items. Hsiao et al. (2009) analyzed perseverative errors (repetition of past responses for new targets) in the BCN paradigm and demonstrated that such errors can occur despite multiple intervening items within a cycle.

The evidence above shows that contextual similarity creates long-standing effects. Is the same true for prepotent responses? One of the best ways to investigate this is to examine sequential effects in PWI. As noted above, both CN and BCN interference effects are inherently sequential effects; interference only arises because later items are associated with earlier items. In contrast, the primary interference effect in PWI is often not sequential. In many cases, pictures and distractor words are presented simultaneously. However, it is possible to examine performance across different trials of a PWI task. For example, one could examine performance on each trial as a function of the previous trial type. Given that each trial can be either congruent (distractor word matching the picture's name) or incongruent (distractor word not matching the picture's name) four trial types arise: cC, cI, iC, and iI, where c and i denote the congruency of the previous trial, and C and I the congruency of the current trial. A common finding when analyzing the data this way is that (iI -iC) creates smaller interference than (cI -cC). In other words, the difference between incongruent and congruent trials shrinks after an incongruent, compared to a congruent, trial. This is called a congruency sequence effect (CSE; Egner, 2007; Gratton et al., 1992) and is observed across a wide range of tasks with congruent and incongruent trials, including visuospatial tasks (e.g., Simon: Stürmer et al., 2002; flanker: Ullsperger et al., 2005; and prime-probe: Kunde & Wühr, 2006), and tasks that involve linguistic representations (e.g., Stroop, and PWI; Kerns et al., 2004; Freund et al., 2016).

Importantly, CSE is a long-lasting effect, resilient to the passage of time and insertion of irrelevant tasks. Freund and Nozari (2018) tested this in a task-switching paradigm by alternating PWI trials with trials from a visuospatial task called the prime-probe (PP) task (Weissman et al., 2015). In the latter, a large prime arrow appeared on each trial, followed by a smaller probe arrow.

Participants indicated the direction of the probe arrow by pressing one of four buttons (up, down, left, or right). On congruent trials, prime and probe arrows pointed in the same direction. On incongruent trials, they pointed in different directions. The design was perfectly balanced for examining both 2-back within-task CSE and 1-back cross-task CSE. Results showed a robust 2back within-task CSE for both PWI and PP tasks, showcasing the longevity of the CSE. Interestingly, no support was found for a 1-back cross-task CSE, whether from PWI to PP or vice versa, pointing to a task/domain-specific CSE (Freund & Nozari, 2018; Experiment 1). These results were replicated in a second experiment, where PP trials were swapped for a sentence reading task. Sentences either contained lexical or syntactic ambiguity, which is known to induce conflict (Duffy et al., 1988; Ferreira & Henderson, 1990; Grodner et al., 2002; Nelson et al., 1980), or they did not. As in Experiment 1, a 2-back within-task CSE was found for both tasks, but no 1back cross-task CSE (Freund & Nozari, 2018, Experiment 2). Recently, these results have been replicated in Mandarin and Dutch, and using other non-linguistic tasks (e.g., Lakhani et al., 2026; Zhang et al., 2025; Zhu, Wang, et al., 2025).

In summary, both contextual similarity and suppression of a prepotent response influence the following trials. This influence is long-lasting, persisting across time and intervening unrelated trials. The nature of the influence is distinct, though: contextual similarity creates accumulating interference over the following trials, whereas suppression of a prepotent response creates facilitation over the next incongruent trial. Moreover, sequential effects appear to be task-specific.

Existing Models of Interference in Language Production and Their Core Computations

Long-lasting influences that are largely immune to the passage of time and insertion of unrelated items have the distinct signature of learning. By learning, we refer to mechanisms that go beyond the activation of neurons and instead target the connections between neural populations.

In artificial neural networks, learning is represented by the change in the strength (weights) of the connections between the nodes in the network, rather than the activation value of individual nodes, which is often subject to quick decay, making learning a more lasting mechanism than activation.

Importantly, incremental learning has been used successfully to model interference resulting from contextual similarity (e.g., Howard et al., 2006; Oppenheim, 2018; Oppenheim & Nozari, 2024; Oppenheim et al., 2010), showing the promise of this approach, at least for modeling one kind of interference. However, the same learning models have not been applied to tasks such as PWI, where suppression of a prepotent distractor is required. In contrast, there are alternative accounts of interference that do not have learning mechanisms (e.g., Abdel Rahman & Melinger, 2009; Roelofs, 2018). In the next sections, we present a detailed review of the learning and non-learning models of interference in language production, and show that, to date, no model captures all the empirical effects with a clear, simple, neurobiologically plausible mechanism.

Learning Models of Interference in Production

The idea of incremental learning as the mechanism underlying semantic interference was first implemented by Howard et al. (2006) to explain semantic interference in CN. Their simple network consists of a semantic layer (S-units, or semantic nodesfoot_0 ) and a lexical layer (L-units, or lexical nodes). The model has three key mechanisms: (1) shared activation, (2) competition, and (3) priming.

Upon the presentation of a stimulus, the semantic node of the target gains the most activation, with the semantic nodes of the related items also gaining partial activation (shared activation). Activation then spreads to lexical nodes, which compete for selection via lateral inhibitory connections (competition). Once the activation of a lexical node reaches the threshold, it is selected as the response, and the processing time until selection is recorded as the simulated RT. After the response is selected, the connection weight between the active semantic feature nodes and the selected lexical node is strengthened by a constant proportion (priming). Notably, this strengthening is restricted to the connection to the selected node, while connections to coactivated competitors are left unchanged. In subsequent trials, when a member of the same semantic category is presented, interference is induced from shared activation partially activating the previously named competitor's semantic node. Since the competitor's semantic-lexical connection has been previously strengthened, its lexical node becomes more active and thus creates stronger lateral inhibition to suppress the activation of the current target's lexical node, resulting in a longer time before the target can accumulate enough activation to reach the selection threshold. As more items from the same category are named, the number of primed competitors accumulates, leading to an approximately linear increase in RTs across ordinal positions. Howard et al.'s (2006) model is plausible in its assumptions and elegant in its implementation, naturally generating RT distributions as a function of competition. However, adding a constant proportion only to the selected connection is not a common learning rule in artificial networks. The next generation of learning models offered an improvement by using a common learning function. Oppenheim and colleagues proposed a series of incremental learning models employing the error-based delta rule (Rumelhart et al., 1986; Widrow & Hoff, 1960): The first of these was the Dark Side model (Oppenheim et al., 2010). Similar to Howard et al. (2006), the model has two layers, mapping distributed semantic features to lexical nodes. The model is a feedforward network in which semantic feature nodes (e.g., MAMMALIAN, AQUATIC) form the input layer and lexical nodes (e.g., "dog", "boat") form the output layer. Each lexical node is connected to a set of semantic feature nodes, with semantically related words sharing some of the semantic feature nodes (e.g., "dog" and "whale" share the feature MAMMALIAN). Every semantic feature node has potential connections directly to every lexical node, with no lateral connections within either layer, and no feedback connections from the lexical to the semantic layer.

When a stimulus is presented, activation spreads from semantic features to the lexical layer, activating the target along with competitors. Then, a booster repeatedly and multiplicatively amplifies the activation of every lexical node until one node's activation exceeds the mean activation of all other nodes by a threshold. At this point, the highest activated lexical node is selected as the response, and RTs are computed as a function of the number of boosting cycles required. If no lexical node satisfies the selection rule before a fixed deadline, the trial ends in an omission error.

Importantly, after each trial, the semantic-to-lexical connections are updated based on the discrepancy between the node's actual and desired activation according to the delta rule; connections from active features to the target are strengthened, while connections from the shared features to competing non-target words are weakened. Thus, a subsequent target in the same category requires more boosting cycles to adequately separate its activation from those recently strengthened competitors, resulting in progressively longer RTs in CN. The same mechanism also explains the data from BCN; the model simultaneously captures repetition priming (i.e., an overall decrease in RTs in both homogeneous and heterogeneous conditions across cycles), as well as the overall advantage of the heterogeneous over the homogeneous condition. Oppenheim (2018) further extended the model to interference resulting from newly acquired words. Finally, Oppenheim and Nozari (2024) retained the core architecture of the 2010 model but extended the representational framework to account for both interference in taxonomically related BCN and the null effect or facilitation observed in thematically related BCN (e.g., Abdel Rahman & Melinger, 2007 , 2011; Damian et al., 2001; de Zubicaray et al., 2014; Schnur et al., 2006).

In short, learning models have successfully modeled long-lasting effects of contextual similarity, as well as the diverging effects of taxonomic and thematic contextual similarity. However, they have room for improvement; some do not have a natural mechanism for simulating RTs, while others do not have a widely accepted learning function. Most importantly, none of them has been applied to PWI, or similar tasks that require the suppression of a prepotent response, leaving a clear gap in our understanding of the extent to which incremental learning can explain interference and its resolution in language production.

Non-Learning Models of Interference

The most important non-learning model of lexical interference is WEAVER and its subsequent versions (Levelt et al., 1999; Roelofs, 1992 Roelofs, , 1997 Roelofs, , 2003 Roelofs, , 2018)). The model can also be construed as the most complete model of lexical interference to date, as it has been applied to CN, BCN, and PWI, although it has not attempted to capture CSE. The model consists of three layersa conceptual layer with lexical concept nodes, a syntactic layer with lemma nodes, and a wordform layer containing morphological, phonological, and phonetic representations. The conceptual layer consists of non-decompositional semantics, meaning each lexical concept is represented by a single, independent node rather than a distributed set of semantic features. To capture semantic similarity, the conceptual layer organizes nodes into a semantic network connected by explicit, labeled links (e.g., IS-A link; Collins & Loftus, 1975; Quillian, 1969). When a stimulus is presented, its corresponding conceptual node is activated and sends a proportion of its activation through the semantic network to other connected concept nodes. The activation simultaneously spreads through the network, activating nodes in the lemma layer. Lemma selection follows a competitive selection rule based on Luce's choice ratio (Luce, 1959). At each timepoint, the selection probability of a lemma is determined by the ratio of its own activation to the summed activation of all co-activated lemmas (Roelofs, 1992). The number of timesteps required to make the selection is proportional to the simulated RT (Roelofs, 2018).

In its original form, the model does not account for interference either in contextual similarity or suppression of a prepotent response; therefore, different extensions have been used to account for different kinds of interference. To account for the interference effects observed in the PWI paradigm, Roelofs (2003) added an executive verification process. Rather than blindly selecting the most active lemma, an executive production rule checks the explicit goal of the task.

In the PWI task where the goal is to name a picture, this control rule blocks the input from the irrelevant written word. However, this blocking mechanism operates with a slight temporal latency, allowing the distractor word to gain a temporary head start in activation, driving up the early-stage competition and thereby slowing the RT for the target picture name. As explained earlier, the idea of goal-setting is critical for explaining the overriding of a prepotent response, since stimulus-driven information simply will not get one to the correct response. However, it is unclear why the implementation of goals should work with a delay built into the model, when the task goal is known to the speaker from the start.

To capture the semantic interference observed in CN and in BCN, Roelofs (2018) proposed a new extension. Specifically, after a lexical concept node is selected in each naming trial, a constant bias term is added to that specific concept node's activation in subsequent same-category item trials. This constant activation term is added iteratively and exclusively to items from the same semantic category in both CN and BCN. For example, in BCN, the first cycle has no bias. A bias of 2.5 units is introduced in the second cycle, and an additional bias of 2.5 is manually added in each subsequent cycle (e.g., 5, 7.5, 10, and so on). This incremental addition of a bias increases the lexical competition for the current target. As a result, the target word requires more time steps to accumulate enough activation to win competitive selection, hence the increase in RTs. Roelofs (2018) motivated this manipulation by appealing to the fact that conversations usually form around a theme, giving rise to a temporary conceptual bias for that theme. Conceptual priming is a reasonable assumption, but by the same assumption, it can be argued that conceptual biases are short-lived; when the topic of conversation shifts, interlocutors can flexibly and quickly shift their attention to new topics. Given that we are specifically interested in long-lasting effects that survive irrelevant items (in CN) and blocks (in BCN), it is reasonable to ask why conceptual bias towards a given semantic category after a gap not only never decays but is continuously amplified despite the presence of irrelevant items and other categories in between. In that sense, it may be better construed as a form of learning.

Another important non-learning framework for explaining interference is Abdel Rahman and Melinger's (2009) Swinging Lexical Network, aimed specifically at explaining semantic interference and facilitation effects within PWI and BCN. The framework inherits its two-level architecture of conceptual and lexical layers from WEAVER, where conceptual nodes can be connected via shared category or associative relationship. The framework also retains competitive lexical selection with two additional assumptions: (1) lexical competition is only strong enough to produce interference when an interrelated cohort of competitors, rather than a single isolated competitor, is co-activated; and (2) the semantic context simultaneously triggers conceptual facilitation via priming of the target concept, and lexical competition via lexical cohort activation.

The polarity of the net behavioral effect is thus determined by the trade-off between conceptual facilitation and lexical competition, which ultimately hinges on the size of the co-activated lexical cohort.

The most important contribution of the Swinging Lexical Network has been its explanation for the dual effect of semantic similarity observed in PWI, namely interference with a categorical distractor (e.g., Glaser & Düngelhoff, 1984; Glaser & Glaser, 1989; La Heij, 1988; Lupker, 1979; Lupker & Katz, 1981 , 1982; Schriefers et al., 1990) and facilitation with an associative distractor (e.g., Alario et al., 2000; Bölte et al., 2013; La Heij et al., 1990; Lupker, 1979). When the distractor is categorically related to the target, both items share a superordinate category node, causing the activation to converge on and co-activate a whole cohort of related lexical competitors. This highly interconnected cohort creates strong one-to-many lexical competition that overwhelms conceptual priming, resulting in delayed RTs, or interference. In contrast, when the distractor is associatively related but belongs to a different category, activation spreads to mutually unrelated nodes in different categories and does not converge. This produces only one-to-one competition, which is insufficient to overrule the conceptual priming benefit, yielding a net decrease in RTs, or facilitation. The same mechanism is also extended to explain interference in the BCN paradigm.

In a homogeneous block, repeatedly naming items from the same category activates a shared category node, which spreads activation to an interrelated lexical cohort. The resulting one-tomany competition overcomes conceptual facilitation and causes interference in RTs. Conversely, in a heterogeneous block, unrelated items do not produce convergent activation, thus no competition or interference arises.

The Swinging Lexical Network does not have a computational implementation, which makes it difficult to fully understand its mechanisms and predictions. Also, the longevity of interference induced by contextual similarity may not be easy to explain with the Swinging Lexical Network. As such, the only implementation of a non-learning account of interference and control in language production remains to be Roelofs (2018). This model has the unique advantage of capturing performance across CN, BCN, and PWI, which no other model does. However, some of the model's assumptions, such as non-decaying conceptual priming and delayed goal implementation, are questionable or may be variants of learning. Finally, even this model does not explain sequential effects in control implementation in the form of CSEs.

Towards a New Model

The previous section demonstrated that much insight has been gained from the various models of interference in language production. At the same time, it highlighted some important shortcomings, ranging from implementational issues (e.g., unnatural methods of RT simulation, etc.) to scope (i.e., lack of a single model that captures all the empirical data). The goal of this study is to propose a model that addresses these shortcomings. We aim for this model to ( a We propose a learning framework to achieve these goals. This choice is motivated by two facts: (a) as reviewed in earlier sections, both types of interference show long-lasting effects that can be most elegantly captured by learning models, and (b) there is now growing evidence that incremental learning underlies many aspects of language production, such as repetition priming (e.g., Howard et al., 2006), phonotactic learning (e.g., Dell et al., 2000; Warker, 2013; Warker & Dell, 2015; Warker et al., 2008 Warker et al., , 2009) ) and orthotactic learning (e.g., Atilgan & Nozari, 2026; Pacton et al., 2001; see Dell et al., 2021, for a review). In the same vein, there is a growing belief in the cognitive control literature that learning provides the best account of findings such as CSE (Abrahamse et al., 2016; Braem et al., 2019; Egner, 2014 Egner, , 2023;; Verguts & Notebaert, 2008).

Given this state of literature, and the success of several computational models in modeling interference induced by contextual similarity with learning (Howard et al., 2006; Oppenheim, 2018; Oppenheim et al., 2010; Oppenheim & Nozari, 2024), we aim to test the explanatory power of incremental learning as the common principle underlying conflict generation and its resolution.

We further propose that the differences observed between the two types of interference simply arise from incremental learning, implemented as synaptic changes between representational elements, in different parts of the system. Specifically, incremental learning within the core language system accounts for findings related to contextual similarity, whereas learning between the core system and the domain-general control regions accounts for findings related to the presence of a prepotent distractor.

The domain-specific module in this model can be any cognitive module (e.g., visual processing). Since the current study focuses on language production tasks, the core model is a model of lexical retrieval. When comparing across lags (i.e., 2, 4, 6, 8), we found a main effect of ordinal position (β = 12.33, SE = 1.46, t = 8.45, p < .001), no effect of lag (β = -0.99, SE = 0.89, t = -1.11, p = .27), and no interaction between the two (β = 0.29, SE = 0.27, t = 1.09, p = .28), mirroring the empirical findings. Since weight adjustments are determined by the concurrent activation of semantic features and word nodes, processing an unrelated intervening item strengthens only the connections for that specific word.

Furthermore, since the intervening item shares no semantic features with the target category, these localized updates do not affect the connection weights in the target category. As a result, the number of intervening trials (i.e., lag condition) does not influence the RT of naming the subsequent target-category item.

In summary, results of Simulation 1 showed that the dynamics of the core model closely captured the data pattern observed in CN, showed robustness in a large part of the parameter space, and correctly reproduced the additional finding of RT invariance across lags.

Simulation 2. Blocked Cyclic Naming

In Simulation 2, we simulated BCN with the exact same parameters as in Simulation 1.

Recall that in BCN, participants repeatedly name a small set of pictures across multiple cycles. In the homogeneous condition, all items within the set belong to the same category, whereas in the heterogeneous condition, the items are drawn from distinct categories. Two key observations are as follows: (1) average RTs in heterogeneous blocks are faster than in homogeneous blocks from cycle 2 onward; and (2) average RTs decrease overall as cycles progress, reflecting repetition priming (e.g., Schnur et al., 2006; Figure 5a).

We simulated 5,000 participants, each completing one homogeneous block and one heterogeneous block. Each block consisted of four cycles of five trials, yielding 20 trials per block.

The generated RTs were analyzed using the same analytical approach used in Simulation 1. The model included condition (i.e., homogeneous vs. heterogeneous), cycle (i.e., 1-4), and their interaction as fixed effects, as well as random intercepts for participants. To evaluate the robustness of the model, we conducted a parameter space search for the combinations of selection threshold (k) and the Hebbian learning rate (η). The selection threshold ranged from 3.5 to 5.5 (step size = 0.25) and the learning rate from 0.005 to 0.015 (step size = 0.001). Each coordinate in the resulting parameter space represents the outcomes from 1,000 simulated participants. The resulting heatmap shows the t-statistics for the semantic interference in RTs (i.e., mean RTs in homogeneous condition -mean RTs in heterogeneous condition), thresholded for statistical significance using a two-sided test with 𝛼𝛼 = .05.

Figure 5b presents the results of Simulation 2. The model successfully reproduced both of these cycle-level patterns described above. Statistical analyses confirmed significant main effects for both condition (β = -10.68, SE = 2.53, t = -4.22, p < .001) and cycle (β = -69.57, SE = 0.46, t = -150.36, p < .001). In summary, the results of Simulation 2 demonstrated that the same learning model used to capture the results of the CN task also successfully captured the pattern of results in the BCN task.

Simulation 3. Picture-Word Interference: Where the Core Model Fails

Recall that in PWI, participants name a picture that either matches a distractor word superimposed on it (congruent) or not (incongruent). Unlike in CN and BCN, simple S-R mapping often leads to selecting the prepotent distractor rather than the target. However, humans can perform the task with high accuracy by setting and maintaining goals (Duthoo et al., 2014; Freund et al., 2016; Schriefers et al., 1990; Shitova et al., 2017; van Maanen & van Rijn, 2010). Simulation 3 tests whether the core model, which does not have a goal-setting mechanisms, can capture the basics of human performance in this task.

To simulate the PWI paradigm, we expanded the core model to include a stimulus letter layer for the written distractor, with three letter nodes connected to the corresponding word node in the response layer, simulating a simple word-reading route. Prepotency of the distractor was modeled as stronger letter-to-lexical connection weights (l). Specifically, the same input of 0.1 was given to the three letter nodes connected to word with weights of 0.002, leading to an input of 0.0006 to the distractor. As such, the distractor was, on average, 1.2 times as much input as the target, making it the prepotent response in line with previous computational implementations of Stroop-like tasks with a prepotent response (e.g., Verguts & Notebaert, 2008). Activation, selection, and weight updating were carried out using Equations 1-4.

We simulated 5,000 participants, each completing 64 congruent and 64 incongruent trials.

In congruent trials, identical pictures and words were simulated. In incongruent trials, each target picture was paired with a distractor word from the same semantic category. Stimulus order and congruency conditions were randomized independently for each participant. As expected, this model had an unreasonably high error rate in incongruent trials of 65.56% ± 0.15%, indicating that without top-down control from the task goal, the model commonly selected the highly activated prepotent distractor.

CoCo-PaLM: Simulations 4 and 5

As demonstrated with the previous set of simulations, although the core lexical retrieval model successfully resolves conflict arising from contextual similarity, it cannot overcome a prepotent distractor on its own. This section introduces CoCo-PaLM, which situates the core model into a domain-general monitoring-control loop. This extension allows us to (a) complete our model of interference in language production, and (b) test the second goal of the paper, which is investigating whether neural domain-generality of control necessarily leads to the transfer of control across tasks. Importantly, we maintain incremental learning as the core mechanism responsible for generating and resolving interference in this model.

Figure 6 shows the hierarchical architecture of CoCo-PaLM, comprising the core language model, embedded in a domain-general monitoring-control loop. A second, non-language, task has also been embedded under this loop to model the transfer of control between the language and non-language tasks. The core language model is simply the model used in Simulations 1-3. The monitoring and control loop is adapted from the adaptation-by-binding model (Verguts & Notebaert, 2008 , 2009). This is a model of Stroop-like tasks, with a stimulus layer, a response layer, a monitoring center that tracks conflict, and a control center that represents the task goals via task nodes (Rainer et al., 1998). On each trial, the model encounters a congruent or an incongruent trial, and response conflict is compared to the average conflict experienced in the task.

This difference is then used by the control center to adjust the connection weights between the task nodes in the control center and the stimulus layer through a learning function.

The key element in the adaptation-by-binding model is the implementation of control through learning. It is not simply the activation of the task nodes that matters in biasing competition away from the irrelevant and towards the relevant information, but the strength of the connections between those nodes and task-specific representations. If one practices task A, a certain set of connections between the control center and the representations involved in task A will be trained, leading to improved performance in task A. However, the connections between the control center and task B remain untrained. This instantiation of control as learning allows the model to successfully capture within-task CSE in the absence of cross-task CSE, supported by the empirical data (Akçay & Hazeltine, 2011; Egner et al., 2007; Freund & Nozari, 2018; Funes et al., 2010; Kiesel et al., 2006; Kim & Cho, 2014; Notebaert & Verguts, 2008; Wendt et al., 2006 Wendt et al., , 2014;; Zhang et al., 2025; Zhu, Wang, et al., 2025).

We adopted a similar architecture for CoCo-PaLM. Domain-specific processes, such as default stimulus-response mapping, are carried out within the modules and are subject to withinmodule incremental learning. At the same time, goal-driven behavior is implemented as learning that takes place between the domain-specific module and the domain-general control center. The PWI model is implemented as in Simulation 3. A monitoring center is added that continuously computes the conflict between the two most highly activated responses and relays this to the control center. To give neural domain-generality of control its best shot, we only implemented a single pair of relevant (R) and irrelevant (IR) task nodes in the control center (c) (cf., Verguts & Notebaert, 2008). Task nodes are connected to relevant and irrelevant dimension nodes in the dimension (d) layer, with the same initial weights 𝑤𝑤 𝑐𝑐𝑐𝑐 (Verguts & Notebaert, 2008). For PWI, the relevant dimension (picture) projects to all semantic feature nodes and the irrelevant (word) dimension to all letter nodes with the same weights (𝑤𝑤 𝑐𝑐𝑖𝑖 ).

The dimension layer is often absent in computational models of tasks such as Stroop, where control is usually implemented by changing the weights between task nodes and stimulus nodes.

Such direct implementation works well for tasks with limited S-R mappings and many repetitions, as all items will be quickly trained within a few iterations of the task. However, repetition is not necessary for producing CSE. PWI tasks often have a large set of unique items that are not frequently repeated, and yet the task produces robust CSE (Freund et al., 2016; Freund & Nozari, 2018; Zhu, Wang, et al., 2025). The quick generalization to new items indicates that the trained mapping is not between individual items, but rather, constitutes training a broader strategy of biasing processing towards the relevant information and away from the irrelevant information. We represent such information in a dimension layer. Dimensions are task-dependent; in PWI, the relevant dimension is the picture, and the irrelevant dimension is the written word. In a Stroop task, the relevant dimension is the color, and the irrelevant dimension is the word. The addition of the dimension layer allows us to modulate control effects by adjusting the weights between task nodes and dimensions, rather than the stimulus layer directly (see Cohen et al., 1990, for a related approach to control implementation).

General Discussion

This project had two goals: (a) to build a model of interference and control in lexical retrieval that could account for CN, BCN, PWI, and sequential effects of adaptive control, and (b) to use that model to examine the transfer of control between language and non-linguistic tasks and test the functional domain-generality of control.

CoCo-PaLM achieved both goals. We showed that learning mechanisms could account for data patterns in all three tasks and provide a natural explanation for the longevity of sequential effects. We also showed that since learning resides in the connection between representations, and not representations themselves, even fully domaingeneral control representations will still lead to largely domain-specific control implementation.

In other words, neural domain-generality does not translate into functional domain-generality.

CoCo-PaLM builds on previous language models, but it is novel in several respects: First, while previous models of interference in language production have captured contextual similarity effects with learning mechanisms within the core language system (e.g., Howard et al., 2006; Oppenheim, 2018; Oppenheim et al., 2010; Oppenheim & Nozari, 2024), CoCo-PaLM extends learning to the connection between the language system and a domain-general monitoring-control loop. Second, CoCo-PaLM naturally accounts for both RTs and error rates, while using wellmotivated learning rules. The third advantage of CoCo-PaLM over previous models is its robust and interpretable parameters. We have intentionally kept the model parameters to a minimum, explained them conceptually, and have kept them constant across simulations, when theoretically motivated. For example, the parameters used for simulating CN (Simulation 1) were kept unchanged for the simulation of BCN (Simulation 2). Similarly, the domain-general parameters were kept constant across the simulation of language and non-linguistic tasks, despite different neighborhoods (Simulations 4 and 5). Moreover, all the core language models' parameters were kept the same when the model was embedded in the domain-general monitoring-control loop, to faithfully capture the hierarchical nature of CoCo-PaLM.

Finally, the hierarchical architecture of CoCo-PaLM allows for studying the interaction between control in language and non-linguistic tasks. Simulation 5 showed such an interaction between two tasks, but the architecture can easily be extended to include more tasks with different neighborhoods. Importantly, CoCo-PaLM provides a framework for studying how dimensional overlap may modify cross-task transfer of control (Zhu, Kaiser, et al., 2025). We have so far shown that when the dimensions that determine relevance to task goals differ between two tasks, the model does not exhibit a positive CSE, in line with a large body of empirical data (Akçay & Hazeltine, 2011; Egner et al., 2007; Freund & Nozari, 2018; Funes et al., 2010; Kiesel et al., 2006; Notebaert & Verguts, 2008; Wendt et al., 2006; Zhang et al., 2025; Zhu, Wang, et al., 2025; see Braem et al., 2014, for a review). In the rest of the General Discussion, we unpack some of the key modeling choices and results in terms of their theoretical and practical implications.

What Does Learning Theoretically Signify in the Model?

Traditional computational models typically treat connection weight changes as analogous to long-term synaptic strengthening or weakening (Grossberg, 2013; McClelland et al., 1995; O'Reilly & Munakata, 2000; Rumelhart & McClelland, 1986). This treatment is also common in models of language production. For example, smaller connection weights are used to represent an immature production system in children (e.g., Budd et al., 2011 Budd et al., , 2012;; Hanley et al., 2016) or a damaged production system in adults (e.g., Dell et al., 1997; Nozari et al., 2010; see Dell et al., 2014, for a review). While this view is certainly apt for representing long-term structural changes to the system, it is not the only kind of learning at play. For example, people can quickly learn new task rules and implement them with only a handful of practice trials (Cole, Laurent, & Stocco, 2013; MacLeod & Dunbar, 1988; Palenciano et al., 2019; Ranti et al., 2015; Ruge & Wolfensteller, 2010). Moreover, they can quickly switch those rules, if need be (Braver, 2012; Monsell, 2003).

This ability is impaired in patients with prefrontal damage, suggesting that this kind of rapid rule learning and implementation is likely to be related to the function of domain-general control regions (Aron et al., 2004; Duncan, 2010; Luria et al., 1964; Milner, 1963; see Badre & Nee, 2018, for a review).

However, long-term structural changes are not the only form of change in the communication between neurons. One alternative is the communication-through-coherence (CTC) framework (Fries, 2005 (Fries, , 2015)). CTC posits that effective neural communication relies less on fixed anatomical connections, but more on the relative phase alignment of rhythmically fluctuating excitability windows across sending and receiving neural populations. Empirical evidence demonstrates that this phase-dependent routing is hierarchically organized via cross-frequency coupling-the overarching control rhythm (e.g., theta band) orchestrates the phase alignment of content-carrying rhythms (e.g., gamma band) associated with competing stimuli (Akam & Kullmann, 2012; Bosman et al., 2012; Deco & Kringelbach, 2016; Fiebelkorn & Kastner, 2019; Spyropoulos et al., 2018; Tiesinga & Sejnowski, 2010; Voloh et al., 2015). Within the domain of language production, the theta-band oscillatory dynamics are often investigated through the PWI paradigm. MEG evidence demonstrates a theta-power (4-8 Hz) increase in incongruent compared to congruent trials (Piai et al., 2014). More generally, this mid-frontal theta signature has been taken as the signature of top-down control recruitment to resolve the competition between the picture and distractor processing streams (Cui et al., 2024; Krott et al., 2019; Shitova et al., 2017; but see Zheng & Piai, 2025, for a different oscillatory profile in older adults).

Accordingly, in our model, the rapid weight adjustments between the control center and the task-relevant and irrelevant dimensions can be taken to represent the theta-driven rhythmic gating, which orchestrates large-scale networks through phase resetting to route processing towards task-relevant goals (Verbeke & Verguts, 2019; Verguts, 2017). Increasing the connection weight is analogous to the control center aligning its theta rhythm with the task-relevant sensory network (Cavanagh & Frank, 2014; Cohen, 2014). The resulting phase reset ensures that incoming task-relevant signals arrive during the high-excitability phase of the oscillatory cycle, facilitating cross-frequency coupling and amplifying the corresponding functional impact without requiring structural synaptic changes (Canolty & Knight, 2010; Fiebelkorn & Kastner, 2019; Helfrich & Knight, 2016; Lakatos et al., 2008; Lisman & Jensen, 2013; Riddle et al., 2021; Voloh & Womelsdorf, 2016; Womelsdorf et al., 2007). In contrast, decreasing the connection weight maps onto the control-driven phase misalignment. By intentionally keeping competing rhythms out of phase, the control center ensures that task-irrelevant distractors arrive during the low-excitability trough of the cycle, effectively attenuating the interfering signals (Bonnefond & Jensen, 2012; Helfrich et al., 2018; Huang et al., 2015; Mathewson et al., 2009; Mazaheri & Jensen, 2010; Pomper & Ansorge, 2021; Womelsdorf et al., 2007; Xu et al., 2024).

In short, "learning" in CoCo-PaLM defines a process of changing how different representations communicate with one another. This communication can be represented in longterm synaptic changes or short-term rhythmic gating. In either case, the model's emphasis on the changes to the communication between representations contrasts with non-learning models, which instead attempt to explain interference in persistent activation of representations themselves.

What Kind of Learning Is the Right Kind of Learning?

Learning comes in different forms. One important classification of learning mechanisms concerns the use of error signals. Two prominent mechanisms in this regard include Hebbian learning (Hebb, 1949), which does not use error signals, and error-based learning (Rumelhart et al., 1986; Widrow & Hoff, 1960), which does. Hebbian learning assumes that the co-activation of pre-and postsynaptic neurons correlates with the strengthening of their connection (Choe, 2022).

This localized, activation-driven strengthening has been widely observed across multiple cortical and subcortical regions, most notably the hippocampus, further endorsing the use of Hebbian learning (Barrionuevo & Brown, 1983; Bliss & Gardner-Medwin, 1973; Bliss & Lømo, 1973; Dayan & Abbott, 2001; Dolphin et al., 1982; Frégnac, 2003; Gerstner & Kistler, 2002; McNaughton et al., 1978; Shouval, 2007). Behaviorally, evidence for Hebbian learning comes from studies showing that errors are learned (e.g., language : Humphreys et al., 2010; McCandliss et al., 2002; Waller et al., 2024; memory: Marsh et al., 2007; McDermott, 1996; Roediger & Marsh, 2005; motor control: Diedrichsen et al., 2010; Huang et al., 2011). Since nobody intends to learn or strengthen their own errors, and error-based learning mechanisms aim specifically to prevent errors from being repeated, learning one's errors is most compatible with Hebbian learning. This learning mode is unsupervised and thus mirrors the ecological reality of many cognitive actions for which explicit feedback is not available in the environment or necessarily attended to (Linsker, 1986; McClelland, 2001; Rumelhart & Zipser, 1985; Waller et al., 2024; Whittington & Bogacz, 2019).

However, Hebbian learning cannot be the whole story. Humans can learn effectively from feedback when it is provided and attended to, and such feedback leads to faster and more efficient learning. For example, attempting to answer a question and receiving correction after an error lead to better retention than studying the correct answer alone (Butterfield & Metcalfe, 2001; Chen et al., 2025; Kornell et al., 2009). In fact, many language studies have shown that allowing people to make mistakes and receive corrective feedback leads to better performance (Middleton et al., 2015; Saxton, 1997; Saxton et al., 1998; Schuchard & Middleton, 2018; cf. Fillingham et al., 2006; see Fillingham et al., 2003, and Middleton & Schwartz, 2012, for a review). These findings form the basis for error-based learning (Rumelhart et al., 1986; Widrow & Hoff, 1960). Error-based learning refers to adjustments that are driven by detecting a discrepancy between an anticipated and an actual outcome. Since deviations can be directional (actual outcomes may be better or worse than expected outcomes), changes to connection weights can be directional as well. Computationally, error-based learning in multi-layered networks had to be implemented through backpropagation, which has been criticized for potential lack of biological plausibility (Crick, 1989; Grossberg, 1987; Stork, 1989). However, more recent work has shown that error-based learning can be approximated in biologically plausible ways, for example, through local synaptic changes driven by differences in neural activity (Lillicrap et al., 2020; O'Reilly, 1996; Richards & Lillicrap, 2019; Sacramento et al., 2018; Whittington & Bogacz, 2019).

Both kinds of learning have been previously employed in models of interference in language production. Howard et al.'s (2006) model is a Hebbian learning model: It simply strengthens the connections between the selected word and its semantic features. In contrast, Oppenheim et al.'s (2010) model and its related models are error-based learning models. At the end of a trial, with targets and distractors activated, targets are assumed to be less activated than expected and distractors to be more activated than expected. Subsequently, the weights between target words and semantic features are strengthened, and those between distractor words and semantic features are weakened.

Our choice of learning rules was driven by simplicity, allowing us to test where simpler mechanisms are sufficient and where, instead, more complex processing is required. For contextual similarity, a simple Hebbian rule sufficed: No negative weight changes were necessary to produce the interference pattern in CN and BCN. In contrast, capturing the correct sequential pattern of adaptive control in PWI required that weights be scaled by a conflict error signal. Recall that on each trial, the running average of conflict was subtracted from the current conflict, thus determining whether the trial was harder or easier than expected. A harder-than-expected trial provided a positive signal for weight updates, whereas an easier-than-expected trial provided a negative signal for weight updates. This differential signal is critical for differential adjustments after congruent vs. incongruent trials, which are generally easier and harder than average, respectively. In short, CoCo-PaLM takes advantage of both simple Hebbian learning (within modules) and error-based learning (between modules and the domain-general control center), with internal conflict acting as the external feedback (Verguts & Notebaert, 2008).

Competitive or Non-Competitive Selection?

One of the longest and most vigorous debates in language production research concerns how a word is selected among competing alternatives. Two mechanisms are often considered: noncompetitive and competitive. Non-competitive selection assumes an absolute selection threshold (Mahon et al., 2007; Navarrete et al., 2014). Any lexical item that passes that threshold can be selected, regardless of the activation of other lexical items. Competitive selection (Abdel Rahman & Melinger, 2009; Roelofs, 2003 Roelofs, , 2018)), in contrast, assumes that a relative threshold is necessary for selection, with or without an absolute threshold. In other words, competitive selection assumes that a lexical item must be more activated than its competitors by at least a certain amount before selection can proceed. Originally, the debate centered around facilitatory vs. inhibitory influence of semantically related items; proponents of non-competitive selection often appealed to the facilitatory effect of thematic relations (e.g., Alario et al., 2000; Costa et al., 2005; McDonagh et al., 2020; Mirman et al., 2017; Zhang et al., 2023), whereas proponents of competitive selection cited the interference induced by taxonomic cohorts (e.g., Schriefers et al., 1990). However, recent modeling work has shown that the dual effect of semantically similar items can be explained without assuming one selection mechanism or another (Oppenheim & Nozari, 2024). Both mechanisms can produce facilitation or interference depending on the configuration of the semantic space and the timeline of activation of semantic features, which are more relevant to the differences between thematic and taxonomic similarity than selection rules, per se.

The question thus remains, which selection rule is the correct one? Here, we have opted for a competitive selection rule (Howard et al., 2006; Roelofs, 2003 Roelofs, , 2018)). However, we do not view the selection process as an either-or choice. Rather, we believe that a flexible criterion provides the best account of selection in a system such as language production, which can easily adapt to new goals (Nozari & Hepner, 2019a , 2019b). Specifically, if accuracy is an important goal (choosing between "probability" and "likelihood" while teaching statistics to a class), speakers would want to ensure that they have the correct word before producing it. This can be achieved by setting a high relative threshold (a conservative criterion). Conversely, when accuracy is not an important goal (choosing between "probability" and "likelihood" when talking about the chance of rain to a friend), and multiple alternatives achieve the same communicative goal, speakers may choose to opt for a low relative threshold (a liberal criterion). If the relative threshold is low enough, selection effectively becomes non-competitive.

Put differently, an inherently competitive selection mechanism can easily become noncompetitive based on task goals, if it has a flexible criterion. In contrast, a purely non-competitive selection mechanism cannot simply become competitive on demand. Furthermore, there is abundant evidence that the brain can keep track of competing alternatives (here and elsewhere formalized as conflict; e.g., Botvinick et al., 2001; Nozari et al., 2011), which would be futile in a purely non-competitive system. For these reasons, we adopted a competitive selection rule. All current simulations target tasks in which accuracy is emphasized. To capture this, we chose a threshold not close to zero. However, this parameter can be easily changed to capture situations in which accuracy is not emphasized.

Does Lexical Retrieval Require Inhibitory Control?

The term inhibitory control has been used widely and loosely in the language production literature. As explained in the Introduction, evidence of behavioral interference has often been taken to imply the involvement of inhibitory control. Moreover, the term is often taken to represent a unitary mechanism. One of the main claims of the current study, supported by behavioral and neural data, and borne out by the simulations, is that there is more than one mechanism for the generation of interference and resolution of the ensuing conflict (see also Quinn et al., 2025).

Specifically, when stimulus-driven information is generally sufficient to guide processing towards the correct response, as in the case of interference induced by contextual similarity, languageinternal processes suffice. In contrast, when stimulus-driven information generally leads to the wrong response, as when prepotent distractors are present, language-external mechanisms are needed.

Interference induced by contextual similarity has been captured by two mechanisms in previous computational models: either competitive selection (e.g., current study; as well as competitive selection mechanism. Biologically, competitive selection can be captured by lateral inhibition (Kohonen, 1982; Linsker, 1986; Rumelhart & Zipser, 1985) or mutual inhibitory connections between competing representations for which there is an abundance of evidence (Adesnik & Naka, 2018; Douglas & Martin, 2004; Fishell & Kepecs, 2020; Hartline & Ratliff, 1957; Isaacson & Scanziani, 2011; Snyder et al., 2010). The ubiquity of lateral inhibition across various sensory-motor domains shows its domain-generality as a computational principle.

However, the implementation is clearly local, sharing no neural machinery across domains. In case of contextual similarity, these local processes are sufficient to resolve conflict.

In contrast, a prepotent distractor induces interference by virtue of having a priori stronger S-R mapping than the target. As such, lateral inhibition between the target and the distractor will generally be resolved in favor of the distractor, leading to the wrong response. This necessitates the involvement of a goal-directed process that can override the prepotent S-R mapping. In CoCo-PaLM, this top-down process is modeled as a language-external monitoring-control loop. Goal maintenance is implemented through the adjustment of the connection between set goals in the control center and the relevant and irrelevant task dimensions. Recall that, in the context of the weights between the control center and dimensions, weight adjustments are a proxy for short-term reorientation. Two factors determine the direction and magnitude of these weight changes: the conflict error signal and parameter B. As explained earlier, harder-and easier-than-expected trials generate positive and negative conflict error signals, respectively, prompting positive and negative weight changes. However, this signal is also modulated by B. The thorough parameter space exploration of B showed that for the correct CSE pattern to be obtained, B must be set to induce strong negative adjustments to the weights connected with irrelevant information. This analysis clearly points to the critical role of central inhibition in tasks with a prepotent distractor.

In short, the results suggest that lexical retrieval in the absence of a prepotent distractor, at best requires local (lateral) inhibition. In contrast, central inhibition is required when a prepotent distractor is present. This is not to say that central inhibition cannot possibly be involved in the former case. Any task can benefit from greater focus on goal-relevant information (Nozari, 2025b; Nozari, Mirman, & Thompson-Schill, 2016). Rather, the key claim is that the involvement of central inhibition in such cases is optional, rather than critical. In line with this optionality, regions often associated with the central monitoring-control loop have sometimes been identified in resolving contextual similarity (Abel et al., 2009 (Abel et al., , 2012;; de Zubicaray & McMahon, 2009; de Zubicaray et al., 2013) but not always (Gauvin et al., 2021; Rizio et al., 2017; Spalek & Thompson-Schill, 2008).

Neural Mapping of CoCo-PaLM

While providing a detailed neurobiological model is clearly beyond the scope of this paper, we present a brief neural mapping of the model in this section for two reasons. The first reason is to show that the model has the potential to be fully neurally mapped in the future. The second reason is that linking model components and parameters to neural regions can help with understanding their function.

The core language model in CoCo-PaLM includes a largely distributed semantic network, aligned with modern theories of semantic processing (see Binder & Desai, 2011; Lambon Ralph et al., 2017; Pulvermüller, 2013, for reviews). The lexical layer maps onto the middle temporal gyrus (MTG; see Indefrey, 2011; Indefrey & Levelt, 2004; Nozari, 2020, for reviews). This choice is further endorsed by the evidence showing that MTG is consistently activated during our target tasks, CN, BCN, and PWI (Abel et al., 2012; de Zubicaray et al., 2001 de Zubicaray et al., , 2014 de Zubicaray et al., , 2015 de Zubicaray et al., , 2017;; Gauvin et al., 2021; Hocking et al., 2009; Rizio et al., 2017; Schnur et al., 2009; Vieth et al., 2015). Also, lesion studies demonstrate that damage in MTG produces deficits in word finding and larger semantic interference effects (Baldo et al., 2013; Dronkers et al., 2004; Harvey & Schnur, 2015; Piai & Knight, 2018; Pino et al., 2022; Riès et al., 2015; Schnur et al., 2009), further affirming MTG as the region in which lexical representations are stored and compete for selection.

The domain-general monitoring-control loop in CoCo-PaLM is modeled after the frontoparietal network, especially the prefrontal cortex (PFC), as conceived of by Miller and Cohen (2001). These authors proposed that cognitive control arises from the PFC's capacity to actively maintain patterns of neural activity representing goals and the rules needed to achieve them. These prefrontal representations function as a modulatory network, sending excitatory top-down bias signals to widespread downstream structures, guiding the flow of neural activity along the specific neural pathways needed in the task. PFC implements task goals and moderates performance through two distinct albeit interactive functions (Nozari, 2025b): monitoring and control. The medial prefrontal cortex, especially the anterior cingulate cortex (ACC) acts as the monitor, combining interoceptive effort costs and goal values (Botvinick et al., 2001; Brown & Braver, 2005; Kok, 2022; Shenhav et al., 2013; Verguts et al., 2015). As such, ACC is consistently involved in conflict-inducing paradigms, such as the Stroop and Simon tasks (Barch et al., 2001; Hanslmayr et al., 2008; Milham et al., 2001; Piai et al., 2013; Swick & Jovanovic, 2002).

Unsurprisingly, ACC has also been implicated in conflict-monitoring processes in PWI (Abel et al., 2009 (Abel et al., , 2012;; de Zubicaray et al., 2001; de Zubicaray & McMahon, 2009; Piai et al., 2013).

The lateral prefrontal cortex serves as the primary control center, storing and maintaining the explicit task rules and guiding goal-directed behavior (Botvinick et al., 2009; Kouneiher et al., 2009; Lapate et al., 2024; Rainer et al., 1998; Rushworth et al., 2005; Tanji & Hoshi, 2008; Tanji et al., 2007; Yamagata et al., 2012). For example, TMS experiments and lesion studies of patients with frontal impairment demonstrated that individuals frequently struggle to adhere to task rules, suggesting the necessity of the PFC in situations where automatic stimulus-driven processing is insufficient (Barceló et al., 2000; Capotosto et al., 2009; Duncan, 1986; Fuster et al., 1985; Miller et al., 2011; Ruff et al., 2008; Shallice, 1982; Taylor et al., 2007). In line with this, patients with PFC damage experience severe difficulty in resolving interference in the PWI task (Piai et al., 2016).

The question remains: how does PFC select representations? Much evidence points to subcortical structures, especially the basal ganglia, for this role. Studies have shown that basal ganglia receive converging projections from large parts of the cortex, but relay only selective information to PFC via thalamus (Albin et al., 1989; Alexander et al., 1986; DeLong, 1990; Gurney et al., 2001; Kemp & Powell, 1971; Redgrave et al., 1999; Stephenson-Jones et al., 2011).

Importantly, such selection is not confined to motor programs, and encompass cognitive information as well (Frank et al., 2007; Houk et al., 2007; Humphries et al., 2006; O'Reilly & Frank, 2006; Stewart et al., 2010; Stocco & Lebiere, 2014; Stocco et al., 2010). It is widely agreed that the information selection process results from the competition between two main pathways, direct and indirect, which have excitatory and inhibitory effects on thalamus, respectively (Albin et al., 1989; DeLong, 1990). To optimize performance, the two pathways must reach a balance for relaying the most relevant information and keeping out the irrelevant information (O' Reilly & Frank, 2006; Stocco et al., 2010).

In CoCo-PaLM, parameter B most closely captures the role of the basal ganglia. The positive and negative weight changes to the relevant and irrelevant information, respectively, represent the balance between the direct and indirect pathways, biasing competition towards the relevant information. Recall that the parameter space search showed that adjustments were mainly driven by negative adjustments to the irrelevant weights, suggesting a more prominent role for the indirect pathway. Incidentally, in cognitive tasks with interfering distractors, the indirect pathway has been shown to play a particularly prominent role by discarding irrelevant information (e.g., McNab & Klingberg, 2008; Stocco et al., 2017).

The Dissociation between Neural Domain-Generality and Functional Domain-Specificity of Control: Implications for Studying Cognitive Control

Results of Simulation 5 showed that even assuming full neural domain-generality of the control center does not necessarily lead to functional domain-generality of control. CoCo-PaLM is well-positioned to test this issue, since we intentionally used a single pair of task nodes in the control center, unlike previous control models that have used different task nodes for different tasks (e.g., Verguts & Notebaert, 2008). As such, CoCo-PaLM fully embraces the neural domaingenerality of control (e.g., Assem et al., 2020; Bernardi et al., 2020; Camilleri et al., 2018; Cole, Reynolds, et al., 2013; Duncan, 2010; Fedorenko et al., 2013; Fusi et al., 2016; Parthasarathy et al., 2017; Rigotti et al., 2013; Wessel & Anderson, 2024; Woolgar et al., 2011). Nevertheless, we showed that implementing control in the connections between a domain-general control center and domain-specific representations still leads to functional domain-specificity of control, simply because training one set of control weights does not change other control weights. This finding is well-aligned with the absence of notable positive cross-task CSEs (Akçay & Hazeltine, 2011; Egner et al., 2007; Freund & Nozari, 2018; Funes et al., 2010; Notebaert & Verguts, 2008; Wendt et al., 2006; Zhang et al., 2025; Zhu, Wang, et al., 2025) and the absence of far transfer in training studies (Melby-Lervåg & Hulme, 2013; Owen et al., 2010; Redick et al., 2013; Sala et al., 2019; Sala & Gobet, 2019; Shipstead et al., 2012; Simons et al., 2016; Thompson et al., 2013).

The dissociation between the neural domain-generality of control and its functional domain-specificity also questions the logic of using analysis of individual differences as a reliable method for determining whether a task requires central inhibition or not. Here, we refer to correlational studies, where the size of interference in task A is correlated with the size of interference in a task such as Stroop, flanker, or Simon (or a combination of them), to determine whether task A requires domain-general inhibitory control or not (e.g., Brown-Schmidt, 2009; Nozari & Omaki, 2018; Nozari, Trueswell, & Thompson-Schill, 2016; Shao et al., 2015). To understand the problem with this argument, let us use a simple example: you and your neighbor both receive electricity from the same power plant (a proxy for domain-general control regions in the brain). Does the shared power plant predict a correlation between the electrical status of your respective houses? Yes and no. If something goes wrong in the power plant, you both lose electricity, so the weakening or removal of the shared resource affects both of you negatively. This is the correlation often observed in patients with damage to domain-general control regions (e.g., PFC), who show impairment across a wide variety of tasks that tap control (Alvarez & Emory, 2006; Barbey et al., 2012; Burgess & Shallice, 1996; Gläscher et al., 2012; Jones & Graff-Radford, 2021; Nozari, 2019; Stuss & Alexander, 2000; Woolgar et al., 2010 Woolgar et al., , 2018)). But what if the power plant is up and running at full capacity? Can you predict the electrical capabilities of your neighbor based on what you can do in your own house? The answer is no. For example, you may be able to install an electric vehicle charger in your house, but your neighbor may not, because the capacity depends not only on the shared power plant but also on the cables between the power plant and your individual houses, as well as the type of fuse box and other appliances consuming electricity in each house. Therefore, despite having the shared power plant, you cannot know with certainty the electrical capabilities of your neighbor based on your own. By extension, in a neurotypical system, a shared neural resource is not by itself sufficient to predict function across two different domains. A similar logic holds for training. If control is implemented in the connections between domain-general control center and domain-specific task dimensions, achieving results is contingent on training those weights within the context of the task, or a task similar enough to train the relevant dimension.

But what about cases where a positive correlation is observed? We believe that such cases may reflect a common parameter in the control implementation across tasks. For example, in our model, we kept B, which is responsible for biasing competition away from the irrelevant and towards the relevant information, the same across PWI and PP, to keep free parameters to a minimum. However, B may very well differ across tasks. Similarly, the conflict error signal can, and often does, depend on task difficulty and can differ from task to task. Therefore, while a positive correlation in the size of interference may signal some common parameters, a null effect does not refute relying on central monitoring-control loops. For this reason, correlational analysis of individual differences is an unreliable tool for examining the role of inhibitory control in a given task or operation. Rather, simple heuristics, such as the insufficiency of stimulus-driven information for guiding the process towards the correct response, can be much more informative in determining whether a task does or does not require central control. In brief, we demonstrate that computationally implementing cognitive control and how it interacts with various tasks, provides a path forward for cognitive transfer studies: Computational implementation allows to predict what exactly transfers between which tasks, and how such transfer should be measured.

Conclusion

CoCo-PaLM was able to capture the dynamics of interference induced by both contextual similarity and the presence of a prepotent response. Two key elements in the model account for its explanatory power: its hierarchical architecture (with modules embedded in the domain-general monitoring-control loop) and its use of learning at each level to explain how interference arises and is mitigated. Hebbian learning within the domain-specific task modules appears sufficient for explaining the data on contextual similarity. In contrast, learning in the domain-general monitoring control center is necessary for explaining the data on prepotent response distraction and interactions between language and non-linguistic tasks. We further showed that this framework can explain the dynamics of control transfer between tasks. Specifically, even assuming full neural domain-generality of control is insufficient to expect functional transfer of control between tasks, at least when they do not share relevant or irrelevant dimensions. With this foundation in place, future work can focus on how overlap in task-relevant or irrelevant dimensions can modulate such transfer.
