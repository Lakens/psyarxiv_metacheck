To fix Exact P-Values

What we found

We found 2 imprecise p values out of 95 detected p values.

Show details

Reporting p values imprecisely (e.g., p < .05) reduces transparency, reproducibility, and re-use (e.g., in p value meta-analyses). Best practice is to report exact p-values with three decimal places (e.g., p = .032) unless p values are smaller than 0.001, in which case you can use p < .001.

This module sometimes flags false positives when sentences discuss how p-value thresholds were set. It can also miss an imprecise p-value that is reported against a threshold (e.g., “decreased at the p < .05 significance threshold”).

To check Non-Significant P Value Check

What we found

We found 8 non-significant p values that should be checked for appropriate interpretation.

Show details

Meta-scientific research has shown nonsignificant p values are commonly misinterpreted. It is incorrect to infer that there is ‘no effect’, ‘no difference’, or that groups are ‘the same’ after p > 0.05.

It is possible that there is a true non-zero effect, but that the study did not detect it. Make sure your inference acknowledges that it is possible that there is a non-zero effect. It is correct to include the effect is ‘not significantly’ different, although this just restates that p > 0.05.

How Power Analysis Check works

This module uses regular expressions to identify sentences that contain a statistical power analysis. If specified by the user, it also uses a large language model (LLM) to extract information reported in power analyses, including the statistical test, sample size, alpha level, desired level of power, and magnitude and type of effect size.

The Power Analysis Check module uses regular expressions to identify sentences that contain a statistical power analysis. Without the use of an LLM, the module uses regular expressions to classify the power analysis as a-priori, sensitivity or post-hoc. How StatCheck works

Check consistency of p-values and test statistics

The Statcheck module runs Statcheck. Statcheck searches for regular expressions that match a predefined pattern, and identifies APA reported statistical tests. More information on the package can be found at https://github.com/cran/statcheck. The module only returns Statcheck results for t-tests and F-tests, as these are the only tests which have been validated, see https://osf.io/preprints/psyarxiv/tcxaj_v1/.

Statcheck was developed by Michèle Nuijten and Sascha Epskamp.

Statcheck considers p = 0.000 an error, as you should report p < 0.001. Furthermore, p < 0.03 is an error if the p-value was 0.031, and one should simply report exact p-values (p = 0.031). When the sentence of a test says it is one-sided (“one-tailed”, “one-sided” or “directional”), a p-value that fits a one-sided test counts as consistent (statcheck’s OneTailedTxt setting; #695). When the paper says anywhere that its tests are one-sided, a p-value that fits a one-sided test in either direction counts as consistent too: half the two-sided p, or 1 minus that half for an effect against the predicted direction. Equivalence tests (TOST) are left out, as their p-values do not test the difference. A statistic written with “<” or “>” is read as a bound, and in a sentence about equal variances an F-test’s two-sided p (twice the one-tailed p) counts as consistent. For more information, see StatCheck.

This module only checks statistical results reported in the running text of the manuscript. It cannot (yet) process statistics reported only in tables.

How Exact P-Values works

List any p-values reported with insufficient precision (e.g., p < .05 or p = n.s.), reported as exactly zero (e.g., p = .000), or impossible (below 0 or above 1, e.g., p = -.22).

This module uses regular expressions to identify p-values. It will flag any values reported as p > ? or p < numbers greater than .001. It will also flag p-values reported as exactly zero (e.g., p = .000, p = 0.00), which are mathematically impossible — p-values are never exactly zero and should instead be reported as p < .001.

A p-value that is not the result of a test is not flagged: a table note (“* p < .05, ** p < .01”), a figure legend (“Asterisks indicate significant differences (p < .05)”, “Values in bold are significant at p < .05”) or a stated threshold (“p < .05 was considered significant”, “thresholded at p < .001”). GROBID often puts such notes into the running text, so each p-value is judged by the words in its own clause (the text up to a “;” or a full stop), and never left out when a test statistic belongs to it (“F(1, 7) = 8.03, # p < .05”). The column not_a_test of the table says why a p-value was left out (“marker”, “threshold”, “legend” or “named”).

A p-value with the name of a correction or a test after the p (“pFWE < .05”, “padj < 0.05”, “p Wilcoxon = .02”) is flagged only when a test statistic comes before it in its clause (“t(37) = 7.17, p FWE < .05”). Without one it is mostly the rule that decided what was significant (“genes with padj < 0.05 were selected”); such a p-value is “named” in not_a_test. Notes in other forms, such as a marker after the p-value (“p < .05 (*)“), are still flagged.

A p-value below 0 or above 1 is impossible; it is listed apart and not also as imprecise. Often the statistic before it, or its minus sign, was copied into it (“t(134) = -2.32, p = -.13”, “Z = 3.091, P = 3.091”). A value above 1 is listed only after a test statistic in its clause: without one, a “P” above 1 was nearly always another quantity (a proportion, pH, a group’s mean, a model parameter). A number in scientific notation whose power of ten was lost when the PDF was read (“p = 2.4 x 10 -9” read as 2.4) is not listed. A “p” that is the subscript of another symbol (“r p = .64”, “²p = .02” for partial eta squared, “Δp = .33”), or a quantity with a unit, a logarithm or a ratio (“P = 2.9 µm”, “-log10 P = 7.5”, “Ca/P = 1.67”), is not read as a p-value at all (see extract_p_values()). Each p-value has its own row, also when the same one is written twice in a sentence.

This module sometimes flags false positives when sentences discuss how p-value thresholds were set. It can also miss an imprecise p-value that is reported against a threshold (“decreased at the p < .05 significance threshold”).

This module only checks p-values reported in the running text of the manuscript. It cannot (yet) process p-values reported only in tables (as opposed to a table’s footnote text, which the module does see and tries to exclude — see above).

This module was developed by Lisa DeBruine and Daniel Lakens

How Codebook Check works

Listing a repository’s files never requires an API key, but some hosts answer faster or more completely with one: OSF allows 100 requests/hour unauthenticated versus 10,000/day with a token (see [osf_pat()]), and Dryad enforces a strict per-IP daily quota on repeated listing (see cache below). How Code Check works

This module retrieves information from repositories checked by repo_check about code files (R, Python, SAS, SPSS, Stata, Mplus, MATLAB).

The Code Check module checks R (also R Markdown and Quarto), Python (also Jupyter notebooks), SAS, SPSS, Stata, Mplus, and MATLAB files, using regular expressions to check the code; JASP files are listed but not read. The language of a Quarto document or a notebook is read from the file itself (its engine or kernel), not from its extension. The regular expressions can miss information in code files, or falsely detect parts of the code as a fixed file path. Libraries/imports might be loaded in one block, even if there are more than 3 intermittent lines. The module was tried out internally on papers published in Psychological Science, but has not been formally validated. How Reproducibility Check works

This module assesses whether a paper’s R and Python code can be run on its data. It works in two phases. The static phase (always run) collects the package dependencies the code declares, rewrites the data-file paths that do not work in the repository as the authors organised it, works out the order the scripts must run in, and diagnoses why any referenced input file is unavailable — reporting what a reproduction attempt would involve and where it is likely to break. The execution phase (opt-in, execute = TRUE) then actually runs the code: it copies the repository into a throwaway directory, optionally installs the declared dependencies into a throwaway library, runs each script in order in an isolated subprocess with a per-script timeout, and captures the outcome and full output of each run.

By default (execute = FALSE) the module does not run any code — it performs only static analysis: reading dependencies with the same extractors as code_check, finding the files the code references in the repository, and building a run-order dependency graph. It reports what would be installed and run rather than doing it.

When execute = TRUE, the module additionally runs the downloaded code on your machine — a deliberate, opt-in action gated behind that argument (callr is required for R code). Each script runs in an isolated subprocess so a crash cannot take down the R session; note this isolates crashes, not the filesystem or network. Installs (when install_missing = TRUE) and the throwaway run library never touch your main R library. Each script’s outcome is one of ran_ok, errored, timed_out, dependency_unavailable, not_parsed, run_by_source (an R script another script runs with source(), which is run only inside that script, since on its own it lacks the packages and objects the sourcing script sets up first), run_by_import (a Python file other files import, a module rather than a script, unless it has an if __name__ == "__main__": block), jags_model (a JAGS or BUGS model saved with an R extension, which another script reads) or not_r_content (a file that is not R at all, such as a JSON or HTML dump); these last two are not run and are not failures. python2 marks Python 2 code that was not run. With sandbox = "docker" such code runs with Python 2.7 (option metacheck.docker_image_py2; FALSE turns this off), which modifications records; it is never converted, since that can change results. defines_functions is a file that only defines functions, which is used, not run (table$used_by names the scripts that use it), and not_analysis is a file of software rather than of the analysis: a package’s code, tests, documentation or setup.py, a copy of a tool, a web application, a script a program wrote (table$not_analysis_why says which); neither is run or counted as a script. docker_failed means the container never started, which says nothing about the script, so it keeps the light from being green but does not make it red. needs_a_person is a script that stopped because it asks a person to choose a file or answer a question, or that starts an app, and needs_internet one that stopped because the network is off in a Docker run, or, with internet = TRUE, could not reach what it asked for; download_too_large is a script stopped for downloading more than the limits allow (see internet), and out_of_memory one that, or a program it started (such as a compiler), ran out of the memory each script may use. All four are treated the same way. not_downloaded is a script that stopped on a file the repository lists but that was not downloaded, such as one over max_file_size: it could not be tried, so it is not counted as a script that did not reproduce (summary_table$repro_not_downloaded_n counts them apart). not_read is a file metacheck could not read, so it was not run; the light is then not green, as the file may read and run on another computer, and table$error_message says why, naming a package that is installed but cannot be loaded on the computer that ran the check. empty is a file with nothing in it, which is not run or counted as a script. For a script that did not run through, table$error_message is its error, short (at most 300 characters): the error line of its output, which names a package that is not there, with the address it asked for when it needed the internet, or the time limit it reached; table$reason sorts it into a kind. A timeout means “still running at the cutoff”, not a failure, so raise timeout for legitimately long-running (e.g. Bayesian) scripts. dependency_unavailable means the script’s own package could not be installed from live CRAN, the CRAN Archive, or a named GitHub/URL source — an infrastructure limitation, not a defect in the paper’s code. The full stdout/stderr of every run is kept in the result’s run_results (the report shows it in per-script dropdowns, capped for readability).

Provenance, kept so that a TRACE Research Object (TRO) declaration of the run can be written later from a stored result (metacheck #404; the helpers are in R/provenance.R). Only when code was run (execute = TRUE): * run_results$started_at, run_results$ended_at: when each run of a script started and ended (ISO 8601, UTC, milliseconds); NA for a script that was not started. A script run again in a later pass has the times of its last run. A TRO uses them for each trov:TransparentResearchPerformance. * run_results$exit_status: the exit status of the process that ran the script (0 = ended normally); NA when the process did not report one (a time limit, or Docker failing to start the container). * artifacts: one row per file, with stage (deposit: as downloaded from the repository, hashed from the downloaded file; before_run: the run folder just before the first script ran, after metacheck’s own changes, such as rewritten paths and unpacked archives; after_run: only the files the scripts made (status new), changed (changed) or removed (removed), as an unchanged file is the one listed before the run), path (relative to the run folder, as valid UTF-8, a byte of another encoding written as <xx>), size (bytes), sha256, mime_type (by extension, NA when unknown), source (the file’s address in the repository, for deposit). The package libraries metacheck installs in the run folder are left out, as are metacheck’s own files there (a script’s runner, and the statistical output it writes in statistical_output/). Abstract

Visual cognition is shaped not only by sensory input, but also by social relevance. While self-related information is processed preferentially, similar advantages extend to close others. How prioritization rapidly extends to others, however, remains unclear. We propose an empirically measurable framework of 'representational closeness', whereby individuals cognitively represented closer to the self, benefit from more efficient processing. Devising three markers -closeness, boundary imprecision, overlapin a reanalysis of Scheller & Sui (2022, n = 43) and a new experiment (n = 78), we show that this framework explains processing benefits across two domains: friends over strangers, and more over less attractive strangers. Faster and more accurate responses, reduced response variability, and increased self-other confusion tracked representational closeness. These findings suggest that prioritization reflects a general organising principle of social perception through which cognitive resources are dynamically allocated according to social relevance and allows to link empirical measures of visual processing to the structure of social representation.

1. Introduction

Human cognition and behaviour are fundamentally shaped by social information. Across diverse phenomena -from halo effects and first impressions to in-group favouritism and selective social learning -people preferentially attend to, perceive, and remember information associated with socially meaningful individuals. These biases influence not only social evaluation and decision-making but also early perceptual processing, determining which information gains access to limited cognitive resources (Humphreys & Sui, 2016; Macrae et al., 2018; Scheller et al., 2024 Scheller et al., , 2026;; Sui et al., 2015; Turk et al., 2008). Understanding how the cognitive system organises social information and prioritises some people over others is therefore central to explaining how social relationships shape behaviour.

To behave efficiently in complex environments, the brain needs to prioritise goal-relevant input by evaluating incoming information against internal reference points -anchors -that structure perception (Apps & Tsakiris, 2014; Hohwy, 2020; Moutoussis et al., 2014; Scheller et al., 2024). The self serves as a particularly stable and powerful anchor that systematically guides this prioritisation (Golubickis et al., 2020; Scheller & Sui, 2022; Trope & Liberman, 2010), explaining why self-related stimuli, including one's face, name, or owned objects, are consistently processed more rapidly and accurately than non-self stimuli (Keyes & Brady, 2010; Moray, 1959; Tong & Nakayama, 1999; Turk et al., 2011). Although these effects were initially attributed to stimulus familiarity, similar prioritization effects emerge for arbitrary stimuli newly associated with the self, suggesting a more general mechanism of self-relevance (Lee et al., 2021; Sui et al., 2012; Woźniak et al., 2018). Crucially, prioritisation is not confined to the self but extends to socially meaningful others such as friends and family, as well as socially affiliated groups or individuals sharing self-related attributes (Enock et al., 2018; Gao et al., 2025; Golubickis et al., 2020). Yet it remains unclear how prioritization generalises beyond the self and what representational principles determine which others receive privileged access to perceptual processing.. Although current multidimensional models comprehensively map social perception (Conway et al., 2019; Tamir & Thornton, 2018; Thornton & Mitchell, 2017), they do not inherently account for the mechanisms driving social preference and prioritisation.

We propose that a framework of representational closeness, in which the cognitive distance between identities and the self, can explain these prioritization effects. This framework suggests that individuals, who are represented as closer to the self -via similarity, preference, or affiliation -benefit from more efficient processing, indexed by higher accuracy and faster response times. Individual representations are assumed to be structured by functional boundaries that separate the "self" from the "other" identities. The precision of these boundaries varies: highly precise boundaries support stable, distinct representations, whereas less precise boundaries indicate greater representational uncertainty. Prior work suggests that self-representations are more stable than those of close or distant others (Scheller & Sui, 2022), consistent with smaller boundary imprecision for the self.

Importantly, if closeness and variability in social identity representations influence how socially associated information is processed, this should have a direct impact on their discriminability: Increased representational closeness and uncertainty would lead to enhanced overlap between the representations. That is, if portions of the same social representational space are activated by two distinct identities simultaneously -i.e., they overlap -this should lead to increased confusion between the two identities. Such confusion should, experimentally, be measurable via enhanced discrimination errors when information from two identities is presented simultaneously.

Overall, we can operationalise this framework using three behavioural signatures (Figure 1): (1) representational closeness, indexed by mean relative performance advantages; (2) boundary imprecision, indexed by variability in performance; and (3) representational overlap, indexed by confusion-based errors and slowed responses on mismatch trials.

Theoretical-empirical deduction

While representational closeness of cognitive constructs is not an entirely new concept and has previously been suggested to structure social representations (Aron et al., 1991; Courtney & Meyer, 2020; Mashek et al., 2003; Zhu et al., 2007), these accounts typically remained in the realm of theoretical possibilities or were linked to neural representations, rather than established by readily measurable markers of perceptual-cognitive processing performance. Here, we deduce the empirical, functional markers of this framework via differences in social information processing. For the first time, we outline how the functional outcomes of these theoretical constructs can be empirically measured via the social identity-matching task.

To deduce empirical measures of the theoretical framework of representational closeness we employed a systematic approach of theory construction as outlined by Borsboom et al., (2021), and tested explanatory adequacy across two data sets. The process involved: (1) identifying the relevant phenomenon (social biases in information processing), (2) formulating the prototheory (representational closeness), (3) formalising the theoretical model (see model formalisation), (4) checking its adequacy, and finally (5) evaluating the overall worth of the theory.

Importantly, a clear formalisation of the theoretical framework allowed us to derive testable predictions, which were assessed in empirical data via two complementary approaches. First, we reanalysed existing matching-task data that demonstrated prioritisation for the self and a friend relative to strangers using both abstract shapes and personally meaningful objects (Scheller & Sui, 2022).

Here, participants matched identity labels to stimuli (Sui et al., 2012), allowing us to examine representational structure across stimulus complexity. We predicted graded performance averages (self > friend > stranger), increasing response variability with further distance from the self (self < friend < stranger), and greater rates of confusion errors between self-friend than self-stranger mismatch trials.

Second, we conducted a new experiment using a different set of stimuli: faces and names. In this experiment, we operationalised closeness via physical attractiveness, which is known to reliably enhance attentional and evaluative processing even when task-irrelevant (Hung et al., 2016; Maner et al., 2008; Sui & Liu, 2009). Attractiveness is also associated with self-similarity, self-other overlap, and affiliation (DeBruine, 2004; Zhao et al., 2023), making it a strong candidate for inducing representational closeness. Notably, physical attractiveness was chosen as a theoretically meaningful social cue that could influence the perceived representational closeness of two unfamiliar individuals without introducing additional assumptions about their identities or social relationships. In contrast to group membership, which may conflate factors such as perceived similarity and shared identity, attractiveness allowed us to manipulate a single dimension while keeping both strangers unfamiliar.

Given its well-established influence on social perception and evaluation, attractiveness therefore provided a controlled means of examining whether a socially relevant feature alone could influence representational distance between unfamiliar others.

Across both studies, we predicted graded prioritisation (self > highly attractive stranger > less attractive stranger), increasing response variability with further distance from the self (self < highly attractive stranger < less attractive stranger), and greater confusion errors on mismatch trials between the self and the highly attractive stranger, compared to the self and the less attractive stranger.

Model formalisation

To formalise our theoretical framework, we approximate representational closeness through a probabilistic model in which each identity i is represented by a Gaussian distribution. The dimensionality is assumed to be dependent on the explanatory metrics: Here, we formalise the representations as two-dimensional Gaussians, to allow mapping the representations to two separate performance metrics in the empirical data: accuracy and response times. These are, for simplicity and clarity, assumed to be orthogonal. The mean vector specifies each identities' locations, μ i , in representational space and the covariance matrix specifies representational uncertainty. Uncertainty is assumed to be isotropic, such that each identity's representational uncertainty is characterised by its standard deviation, σ i . Representational closeness is related to the Euclidean distance between the mean locations of two identities. Representational overlap Oi,j, the shared space activated by two different identities, is dependent on the relative locations and uncertainties, rather than treated as an independent parameter. position, with greater variability for more distant representations. Representational closeness is shaped by factors such as similarity and preference, while boundary imprecision depends on uncertainty in knowledge of the identity. Increased closeness and reduced boundary precision lead to greater overlap between representations, resulting in increased confusion errors.

This formulation clearly distinguishes representational location from representational precision.

In empirical measures, identities located closer to the self would be predicted to receive greater processing priority -i.e., higher accuracy and faster response times -than identities represented further from the self. Identities that are located closer to the self would also be expected to be represented with less uncertainty -and therefore less variability in accuracy and response timesthan identities located further away. The degree of overlap between neighbouring representations would result from the relative locations and uncertainties associated with different identities. To quantify representational overlap, we measured confusion error rates and response times for mismatch trials, in which two different identities were presented simultaneously. Empirically, greater overlap would be indicated by a higher likelihood of identity confusion, leading to increased false alarms and the associated costs in response times on mismatch trials. This mapping between theoretical constructs and empirical measures is further outlined in Table 1. The above mappings from latent representational properties to behaviourally measurable outcomes constitute explicit model assumptions that can be evaluated empirically. The framework hence generates separate predictions for mean performance, response variability, and identity confusion: It predicts a graded prioritisation, with less prioritization as representational distance increases from the self, a graded level of representational uncertainty that increases with representational distance, and increased confusion errors when identity representations are close to each other. These effects do not need to be equally spaced, as they may link to individually different features that tie the close other to the self. Overall, the mapping can therefore accommodate dissociations between accuracy, response time, variability, and confusion errors while providing a common account of their relationship to the underlying representational structure.

Furthermore, if the proposed framework adequately describes a more general cognitive social representational organisation principle, it makes predictions about how the measures relate across individuals. Hence, it would predict that processing advantages would correlate with the relative boundary imprecision of two identities. That is, people that show larger differences in mean identities. This would indicate that, as the distance of an other's representation increases relative to the self, its boundary becomes increasingly imprecise.

2. Experiment 1: 'Close other' defined through friendship -Reanalysis of Scheller & Sui (2022)

2.1. Methods

2.1.1. Participants

In session 1, 43 adult participants (23 females, 27 ± 6 years) took part in the study. All participants reported to be right-handed and have normal or corrected-to-normal vision, and no developmental or cognitive impairments. In session 2, 38 of the participants that completed session 1 (21 females, 26.7 ± 6.1 years), took part. All participants were recruited via Prolific. Ethical approval was given by the University of Aberdeen Psychology Ethics Committee (PEC/4476/2020/3). This part of the present study presents a re-analysis of this data, and no new data was collected.

2.1.2. Tasks & Stimuli

The experiments were conducted online using a within-participant design. Participants completed two tasks: a perceptual matching task and a social categorization task. Here, only data from the perceptual matching task is re-analysed. In session 1, participants learned associations between geometric shapes and three identities (self, closest friend, stranger). Two sets of shapes were used across participants (e.g., circle, triangle, square or diamond, hexagon, trapezoid), with each shape assigned to one identity. In session 2, the stimuli consisted of pictures of personally meaningful objects: one owned by the participant, one by their closest friend, and a third object of the same category selected by the experimenter to represent the stranger's object. Images were standardised for size and luminance contrast after background removal.

During the matching task, participants judged whether presented stimulus-label pairs (e.g., shape/object and identity label) matched or mismatched. Stimuli were presented above or below a central fixation cross on a dark grey background, with stimulus positions counterbalanced across trials, and response mappings counterbalanced across participants. Although the original study manipulated stimulus contrast (high vs. low) to isolate perceptual effects, response measures were collapsed across contrast conditions for the present analyses. See Scheller & Sui (2022) for full methodological details.

2.1.3. Data analysis

Response averages and variability was extracted from raw response data using batchscripting in R (version: 4.1.2024) and analysed in JASP (version: 0.18.3, 2024). Trials with RTs below 200ms were excluded, as they were unlikely to reflect conscious perceptual decisions. RT analyses included correct trials only, following standard practice in SPE research (Scheller & Sui, 2022; Sui et al., 2012).

2.1.3.1 Representational closeness and boundary imprecision

To assess representational closeness and boundary imprecision, average accuracy, RTs, and their variability were extracted from match trials for each participant and identity. Response variability was indexed by the within-participant standard deviation across trials. These measures mapped directly onto the theoretical framework: differences in mean performance indexed representational closeness, whereas variability indexed boundary imprecision.

Repeated measures ANOVAs assessed the influence of identity on mean performance and variability measures. Greenhouse-Geisser corrections were applied in cases of sphericity violations and significant effects were followed up with paired t-tests.

2.1.3.2. Representational overlap

To assess representational overlap, confusion error rates and RTs were extracted from mismatch trials in which stimuli and labels belonged to different identities. False alarms ("match" responses or timeouts to mismatch trials) indicated difficulty dissociating the two identities and were interpreted as confusion errors. Note that excluding timeouts from the false alarm rate did not alter the pattern of results.

Mismatch trials pairing the same two identities (e.g., [Close other-shape + Self-label] and [Self-shape + Close other-label]) were averaged across stimulus-label pairs, yielding 30 trials per condition in Experiment 1 and 48 in Experiment 2. This affords false alarm rates with a precision of 2-3.3%. Higher false alarm rates and slower RTs were interpreted as greater representational overlap between identities.

Repeated-measures ANOVAs tested the effect of identity pair on false alarms and mismatch

RTs, with Greenhouse-Geisser corrections applied in cases of sphericity violations and significant effects were followed up with paired t-tests.

4. Discussion

>Discussion

Efficient social behaviour depends on prioritising information about some people over others.

Across domains as diverse as first impressions, social learning, in-group favouritism, and interpersonal decision-making, cognitive systems preferentially allocate resources to socially meaningful individuals. Self-representations provide a powerful organising principle for this process, ensuring that self-relevant information is processed rapidly and efficiently. Consistent with this, selfrelevance of stimuli -whether arbitrary (e.g., shapes or unfamiliar faces) or well-established (e.g., one's face or owned objects) -enhances accuracy and speeds up responses, with benefits extending to socially affiliated others such as friends, family, and group members (Enock et al., 2018; Gao et al., 2025; Golubickis et al., 2020; Moradi et al., 2020; Żochowska et al., 2022). What remained less clear is what determines which other people are prioritised. Our findings support that prioritisation is governed by representational proximity to the self: individuals represented as cognitively closer to the self receive more efficient processing, extending self-prioritisation mechanisms beyond the self to structure social perception more broadly.

Across shape-label, object-label, and face-name matching tasks, prioritisation was consistently expressed through three complementary signatures of representational organisation: representational closeness, boundary precision, and representational overlap. Self-associated stimuli were processed most accurately, fastest, and with the least response variability, followed by close others (friend, highly attractive stranger), and then more distant others (stranger, less attractive stranger). At the same time, pairing self-associated stimuli with close others increased false alarms relative to pairings with distant others, indicating greater identity confusion and, hence, representational overlap. Together, these findings support a graded representational architecture in which people closer to the self occupy neighbouring representational space, are encoded with greater precision, and share more overlapping representations than socially distant individuals.

The findings from Experiment 2 further suggest that this representational architecture is not determined solely by long-established familiarity of the close other identity. Even when participants matched their own face and name with those of previously unfamiliar others, highly attractive strangers elicited greater confusion with the self and slower mismatch responses than less attractive strangers. Although response time effects were less consistent in Experiment 1, they converged with the overall accuracy findings: highly attractive strangers were processed more quickly and with lower response variability than less attractive strangers, and self-highly attractive stranger pairings selectively slowed mismatch decisions. Notably, the magnitude of this processing advantage scaled with participants' subjective attractiveness ratings, such that larger perceived differences between the highly attractive and less attractive strangers predicted larger prioritisation effects. These findings suggest that physical attractiveness influences how closely others are represented relative to the self, increasing representational overlap even in the absence of prior familiarity with the individual.

Rather than simply enhancing attention to attractive individuals, these findings suggest that physical attractiveness can alter the representational organisation of social identities. Attractive others appear to be encoded as occupying positions closer to the self within representational space, resulting in both more efficient processing and greater representational overlap (Fig. 7). More broadly, our results identify representational proximity to the self as a general principle governing social prioritisation, providing a common framework for understanding how both enduring social relationships and rapidly evaluated social characteristics shape the efficiency with which different people are perceived. This is further in line with the Construal-Level Theory of Psychological Distance (Trope & Liberman, 2010), which suggests that people mentally construe social and psychological representations in relation to the current self, with distances to the self indicating increased abstraction, or reduced significance. The markers established in this study were derived from an identity-matching task involving three types of stimuli: abstract shapes, which were perceptually simple and familiar but carried no preexisting social associations; pictures of personally meaningful, owned objects, which were perceptually more complex but had established long-term associations with the identities involved; and pictures of faces, which were perceptually complex and had no established social associations with the strangers, but were associated with the self. Self-prioritisation effects were evident across all stimulus types and both measures. Prioritisation of the close other, however, was consistent across all stimulus types only in the accuracy measure. Response time effects were less consistent, particularly in the re-analysis of Scheller and Sui (2022; Experiment 1). Although self-associated stimuli were reliably prioritised, friends showed no clear advantage over strangers in response speed or response variability for either abstract shapes or personally owned objects. Evidence of greater representational confusion emerged only for self-friend pairings involving owned objects, for which incongruent labels slowed responses. Importantly, accuracy effects were consistent across stimulus types, while response time effects, although not always statistically significant, generally followed the expected direction and showed no systematic dependence on stimulus type. This pattern suggests that neither stimulus complexity (simple: shapes; complex: objects, faces), stimulus familiarity (familiar: shapes, objects; unfamiliar: faces), nor pre-existing social associations (previous associations: objects; no previous associations: shapes, faces) are necessary for these effects to emerge. Instead, the divergence between accuracy and response times likely indicates that accuracy provides a more sensitive index of representational proximity, whereas response times are more susceptible to methodological constraints: In comparison with Experiment 2, in which effects were consistent across both accuracy and response time measures, Experiment 1 involved smaller samples, was conducted online, and employed a longer response time window. These methodological differences may have reduced the sensitivity of the experiment to detect more subtle differences between friend and stranger conditions.

Importantly, our framework proposes a graded organisation of representational distance and does not assume that differences between all identities will necessarily produce equally strong behavioural effects. The larger effects observed between the self and others, compared with those between close and distant others, are therefore compatible with a hierarchical structure in which representational distances vary in magnitude. This highlights the importance of considering both the relative magnitude of identity-based differences and the sensitivity of the behavioural measures used to capture them. The present study demonstrates how markers of representational closeness can be derived from the identity-matching task. However, while social prioritisation effects have been demonstrated across a wide range of tasks and levels of processing, including categorisation, temporal order judgements, action planning, and multisensory integration (Constable et al., 2019; Desebrock & Spence, 2021; Golubickis et al., 2026; Hu et al., 2020; Scheller et al., 2024 Scheller et al., , 2026;; Truong et al., 2017), it remains unclear whether other tasks can also capture boundary imprecision and representational overlap. Hence, an important direction for future research will be to establish whether other tasks also allow markers of boundary imprecision and representational overlap to be identified, and whether their sensitivity to these effects varies across task contexts.

Taken together, the three datasets converge on a common representational framework (Fig. 7): both familiarity and physical attractiveness appear to increase representational proximity to the self, resulting in more precise representations and greater overlap with self-representations. This framework offers a unified account of how diverse social characteristics influence the efficiency with which different people are processed.

While the present framework of representational closeness aligns with previous reports on neural representations of social identities (Gao et al., 2025; Han et al., 2016; Zhu et al., 2007) it should be viewed as a guiding account of social prioritisation rather than a comprehensive explanation of all social biases. We propose representational proximity to the self as one mechanism through which social information shapes perceptual and cognitive processing, while recognising that its scope and boundary conditions remain to be established. Further, while existing multidimensional theories of social perception lack the ability to explain the emergence of these social biases, our findings indicate that integration of self-perception might present a viable solution to this problem. Future work should therefore test how broadly this framework generalises across different social contexts and forms of prioritisation.

Alternative explanations for the findings in Experiment 2 should also be considered. Attractive faces may benefit from perceptual properties such as greater symmetry or typicality (Koehler et al., 2004; Kowner, 1996; Ryali et al., 2020; Trujillo et al., 2014), although the use of subjective attractiveness ratings -and evidence that subjective rather than objective attractiveness best predicts attentional capture (Roth et al. 2023) -makes a purely perceptual account less likely. Likewise, attractive individuals are often perceived as more rewarding (Aharon et al., 2001; Kranz & Ishai, 2006), which may contribute to processing advantages. However, neither perceptual nor value-based accounts readily explain the increased confusion and representational overlap observed between the self and highly attractive others. These factors may therefore contribute to, but are unlikely to fully account for, the representational changes captured by the present framework.

5. Conclusion

The present study introduces and validates a framework of representational closeness to explain how social information shapes perceptual prioritisation. Across three datasets spanning abstract shapes, owned objects, and face-name associations, individuals represented as closer to the self were processed more efficiently, encoded with greater precision, and showed greater representational overlap with the self. Importantly, these effects emerged not only for familiar others but also for previously unfamiliar individuals who were perceived as highly attractive, indicating that representational proximity is dynamically shaped by social evaluation. These findings suggest that social perception is organised around a graded, self-referential representational structure rather than discrete categories of self and other. By positioning representational proximity as a general organising principle, this framework offers a mechanistic account of how diverse social biases may emerge across domains: In psychopathology, disruptions in representational precision may contribute to altered self-experience and self-other confusion. In social cognition, the framework may help explain in-group favouritism and out-group stereotyping, as increased representational distance sharpens differences between social targets. Likewise, parasocial relationships and personification may reflect cases in which non-reciprocal agents are represented as unusually close to the self, gaining privileged access to perception and memory. Overall, the present framework provides a measurable link between social meaning and perceptual processing, generating testable predictions about how self-other representations are altered across different social contexts and populations.
