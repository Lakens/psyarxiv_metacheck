Show details

Meta-scientific research has shown nonsignificant p values are commonly misinterpreted. It is incorrect to infer that there is ‘no effect’, ‘no difference’, or that groups are ‘the same’ after p > 0.05.

It is possible that there is a true non-zero effect, but that the study did not detect it. Make sure your inference acknowledges that it is possible that there is a non-zero effect. It is correct to include the effect is ‘not significantly’ different, although this just restates that p > 0.05.

This module uses regular expressions to identify sentences that contain a statistical power analysis. If specified by the user, it also uses a large language model (LLM) to extract information reported in power analyses, including the statistical test, sample size, alpha level, desired level of power, and magnitude and type of effect size.

The Power Analysis Check module uses regular expressions to identify sentences that contain a statistical power analysis. Without the use of an LLM, the module uses regular expressions to classify the power analysis as a-priori, sensitivity or post-hoc. How StatCheck works

Check consistency of p-values and test statistics

The Statcheck module runs Statcheck. Statcheck searches for regular expressions that match a predefined pattern, and identifies APA reported statistical tests. More information on the package can be found at https://github.com/cran/statcheck. The module only returns Statcheck results for t-tests and F-tests, as these are the only tests which have been validated, see https://osf.io/preprints/psyarxiv/tcxaj_v1/.

Statcheck was developed by Michèle Nuijten and Sascha Epskamp.

Statcheck considers p = 0.000 an error, as you should report p < 0.001. Furthermore, p < 0.03 is an error if the p-value was 0.031, and one should simply report exact p-values (p = 0.031). When the sentence of a test says it is one-sided (“one-tailed”, “one-sided” or “directional”), a p-value that fits a one-sided test counts as consistent (statcheck’s OneTailedTxt setting; #695). When the paper says anywhere that its tests are one-sided, a p-value that fits a one-sided test in either direction counts as consistent too: half the two-sided p, or 1 minus that half for an effect against the predicted direction. Equivalence tests (TOST) are left out, as their p-values do not test the difference. A statistic written with “<” or “>” is read as a bound, and in a sentence about equal variances an F-test’s two-sided p (twice the one-tailed p) counts as consistent. For more information, see StatCheck.

How Exact P-Values works

List any p-values reported with insufficient precision (e.g., p < .05 or p = n.s.), reported as exactly zero (e.g., p = .000), or impossible (below 0 or above 1, e.g., p = -.22).

This module uses regular expressions to identify p-values. It will flag any values reported as p > ? or p < numbers greater than .001. It will also flag p-values reported as exactly zero (e.g., p = .000, p = 0.00), which are mathematically impossible — p-values are never exactly zero and should instead be reported as p < .001.

A p-value that is not the result of a test is not flagged: a table note (“* p < .05, ** p < .01”), a figure legend (“Asterisks indicate significant differences (p < .05)”, “Values in bold are significant at p < .05”) or a stated threshold (“p < .05 was considered significant”, “thresholded at p < .001”). GROBID often puts such notes into the running text, so each p-value is judged by the words in its own clause (the text up to a “;” or a full stop), and never left out when a test statistic belongs to it (“F(1, 7) = 8.03, # p < .05”). The column not_a_test of the table says why a p-value was left out (“marker”, “threshold”, “legend” or “named”).

A p-value with the name of a correction or a test after the p (“pFWE < .05”, “padj < 0.05”, “p Wilcoxon = .02”) is flagged only when a test statistic comes before it in its clause (“t(37) = 7.17, p FWE < .05”). Without one it is mostly the rule that decided what was significant (“genes with padj < 0.05 were selected”); such a p-value is “named” in not_a_test. Notes in other forms, such as a marker after the p-value (“p < .05 (*)“), are still flagged.

A p-value below 0 or above 1 is impossible; it is listed apart and not also as imprecise. Often the statistic before it, or its minus sign, was copied into it (“t(134) = -2.32, p = -.13”, “Z = 3.091, P = 3.091”). A value above 1 is listed only after a test statistic in its clause: without one, a “P” above 1 was nearly always another quantity (a proportion, pH, a group’s mean, a model parameter). A number in scientific notation whose power of ten was lost when the PDF was read (“p = 2.4 x 10 -9” read as 2.4) is not listed. A “p” that is the subscript of another symbol (“r p = .64”, “²p = .02” for partial eta squared, “Δp = .33”), or a quantity with a unit, a logarithm or a ratio (“P = 2.9 µm”, “-log10 P = 7.5”, “Ca/P = 1.67”), is not read as a p-value at all (see extract_p_values()). Each p-value has its own row, also when the same one is written twice in a sentence.

This module sometimes flags false positives when sentences discuss how p-value thresholds were set. It can also miss an imprecise p-value that is reported against a threshold (“decreased at the p < .05 significance threshold”).

This module only checks p-values reported in the running text of the manuscript. It cannot (yet) process p-values reported only in tables (as opposed to a table’s footnote text, which the module does see and tries to exclude — see above).

Telling this paper’s own deposit from the authors’ earlier one is less certain.

How Code Check works

This module retrieves information from repositories checked by repo_check about code files (R, Python, SAS, SPSS, Stata, Mplus, MATLAB).

The Code Check module checks R (also R Markdown and Quarto), Python (also Jupyter notebooks), SAS, SPSS, Stata, Mplus, and MATLAB files, using regular expressions to check the code; JASP files are listed but not read. The language of a Quarto document or a notebook is read from the file itself (its engine or kernel), not from its extension. The regular expression search will detect the number of comments, the lines at which libraries/imports are loaded, attempts to detect absolute paths to files, setwd() and install.packages() calls, and lists files that are loaded, and checks if these files are in the repository; R code is also parsed. The module will return suggestions to improve the code if there are no comments, if libraries/imports are loaded in lines further than 4 lines apart, if files that are loaded are not in the repository, if absolute file paths, setwd() or install.packages() are found, and if R code cannot be parsed.

The regular expressions can miss information in code files, or falsely detect parts of the code as a fixed file path. Libraries/imports might be loaded in one block, even if there are more than 3 intermittent lines. The module was tried out internally on papers published in Psychological Science, but has not been formally validated. There might be valid reasons why some loaded files can’t be shared, but the module can’t evaluate these reasons, and always gives a warning.

The module also checks whether the repository pins the R/package versions the analysis actually depended on: an renv.lock file (parsed for the R version and every locked package + its version/source), a sessionInfo()/sessioninfo::session_info() text dump (matched by filename — sessionInfo.txt/session_info.txt and similar, or embedded in a README), or a groundhog::groundhog.library()/checkpoint::checkpoint() date-pin call in the code (a bare library(groundhog)/library(checkpoint) does not count — the pinning call itself must be present). This module classifies the files in a repository into semantic types (data, codebook, code, software, output, supplemental, readme, asset, other) and, for tabular data files, extracts each column’s type and summary statistics.

The Data Check module consumes the file list produced by repo_check (or any files added via local_path). For every file classified as tabular data that is available locally, the module reads the file head, describes each column with data_col_facets() and computes summary statistics for numeric columns. Every sheet of a spreadsheet that holds a table is read: a file with several such sheets has its columns under source_file = "file.xlsx [sheet]", and the sheet column names the sheet of any spreadsheet with several sheets; a sheet of notes or a codebook is treated as documentation when the file has another table. Following DDI, a column is described by orthogonal facets rather than a single type: representation (numeric/text/datetime/code — how it is stored), measurement_level (Stevens: nominal/ordinal/interval/ratio), concept (what it measures: reaction_time/age/gender/likert/id/…), role (identifier/measure/condition/timestamp), unit, and a quality state (ok/empty/constant). Qualtrics survey exports are recognised (data_check_is_qualtrics()): their extra header rows are stripped so columns type correctly, and the reserved response-metadata columns (StartDate, Duration, Finished, …) are tagged.

The module defaults to rules-only when llm_use(FALSE): columns the rules cannot resolve (ambiguous 3–20-unique integers, ambiguous character columns) fall back to continuous / text respectively. When llm_use(TRUE), ambiguous columns and unresolved file types (other) are sent to llm() for optional refinement, and every file is assigned a study group (ex1, pilot2, shared, …) so that multi-study repositories can be recognised (used by psychds_check). Without an LLM the study group is left NA (unknown).

Without a key, every Dryad file stays classified but un-downloaded, column_n is 0, and a warning naming Dryad and ?dryad_pat/?dryad_auth is included among the download failures. A one-time session message is also shown (see repo_check) the first time a Dryad dataset is encountered with no key set.

How Reproducibility Check works

This module assesses whether a paper’s R and Python code can be run on its data. It works in two phases. The static phase (always run) collects the package dependencies the code declares, rewrites the data-file paths that do not work in the repository as the authors organised it, works out the order the scripts must run in, and diagnoses why any referenced input file is unavailable — reporting what a reproduction attempt would involve and where it is likely to break. The execution phase (opt-in, execute = TRUE) then actually runs the code: it copies the repository into a throwaway directory, optionally installs the declared dependencies into a throwaway library, runs each script in order in an isolated subprocess with a per-script timeout, and captures the outcome and full output of each run.

By default (execute = FALSE) the module does not run any code — it performs only static analysis: reading dependencies with the same extractors as code_check, finding the files the code references in the repository, and building a run-order dependency graph. It reports what would be installed and run rather than doing it.

When execute = TRUE, the module additionally runs the downloaded code on your machine — a deliberate, opt-in action gated behind that argument (callr is required for R code). Each script runs in an isolated subprocess so a crash cannot take down the R session; note this isolates crashes, not the filesystem or network. Installs (when install_missing = TRUE) and the throwaway run library never touch your main R library. Each script’s outcome is one of ran_ok, errored, timed_out, dependency_unavailable, not_parsed, run_by_source (an R script another script runs with source(), which is run only inside that script, since on its own it lacks the packages and objects the sourcing script sets up first), run_by_import (a Python file other files import, a module rather than a script, unless it has an if __name__ == "__main__": block), jags_model (a JAGS or BUGS model saved with an R extension, which another script reads) or not_r_content (a file that is not R at all, such as a JSON or HTML dump); these last two are not run and are not failures. python2 marks Python 2 code that was not run. With sandbox = "docker" such code runs with Python 2.7 (option metacheck.docker_image_py2; FALSE turns this off), which modifications records; it is never converted, since that can change results. defines_functions is a file that only defines functions, which is used, not run (table$used_by names the scripts that use it), and not_analysis is a file of software rather than of the analysis: a package’s code, tests, documentation or setup.py, a copy of a tool, a web application, a script a program wrote (table$not_analysis_why says which); neither is run or counted as a script. docker_failed means the container never started, which says nothing about the script, so it keeps the light from being green but does not make it red. needs_a_person is a script that stopped because it asks a person to choose a file or answer a question, or that starts an app, and needs_internet one that stopped because the network is off in a Docker run, or, with internet = TRUE, could not reach what it asked for; download_too_large is a script stopped for downloading more than the limits allow (see internet), and out_of_memory one that, or a program it started (such as a compiler), ran out of the memory each script may use. All four are treated the same way. not_downloaded is a script that stopped on a file the repository lists but that was not downloaded, such as one over max_file_size: it could not be tried, so it is not counted as a script that did not reproduce (summary_table$repro_not_downloaded_n counts them apart). not_read is a file metacheck could not read, so it was not run; the light is then not green, as the file may read and run on another computer, and table$error_message says why, naming a package that is installed but cannot be loaded on the computer that ran the check. empty is a file with nothing in it, which is not run or counted as a script. For a script that did not run through, table$error_message is its error, short (at most 300 characters): the error line of its output, which names a package that is not there, with the address it asked for when it needed the internet, or the time limit it reached; table$reason sorts it into a kind. A timeout means “still running at the cutoff”, not a failure, so raise timeout for legitimately long-running (e.g. Bayesian) scripts. dependency_unavailable means the script’s own package could not be installed from live CRAN, the CRAN Archive, or a named GitHub/URL source — an infrastructure limitation, not a defect in the paper’s code. The full stdout/stderr of every run is kept in the result’s run_results (the report shows it in per-script dropdowns, capped for readability).

Provenance, kept so that a TRACE Research Object (TRO) declaration of the run can be written later from a stored result (metacheck #404; the helpers are in R/provenance.R). Only when code was run (execute = TRUE): * run_results$started_at, run_results$ended_at: when each run of a script started and ended (ISO 8601, UTC, milliseconds); NA for a script that was not started. A script run again in a later pass has the times of its last run. A TRO uses them for each trov:TransparentResearchPerformance. * run_results$exit_status: the exit status of the process that ran the script (0 = ended normally); NA when the process did not report one (a time limit, or Docker failing to start the container). * artifacts: one row per file, with stage (deposit: as downloaded from the repository, hashed from the downloaded file; before_run: the run folder just before the first script ran, after metacheck’s own changes, such as rewritten paths and unpacked archives; after_run: only the files the scripts made (status new), changed (changed) or removed (removed), as an unchanged file is the one listed before the run), path (relative to the run folder, as valid UTF-8, a byte of another encoding written as <xx>), size (bytes), sha256, mime_type (by extension, NA when unknown), source (the file’s address in the repository, for deposit). The package libraries metacheck installs in the run folder are left out, as are metacheck’s own files there (a script’s runner, and the statistical output it writes in statistical_output/). Files metacheck itself copied or made between passes (see modifications, output_copied, file_placed) show in after_run too. A TRO uses the rows as trov:ResearchArtifacts and each stage as a trov:ArtifactArrangement. * modifications$sha256_before, modifications$sha256_after: the hash of the changed script as downloaded and as it ran; NA when the script is not at the same path in both (a script made from an R Markdown file). * environment: the system that ran the code (trov:TransparentResearchSystem in a TRO): metacheck_version, started_at, ended_at, host (R version, platform, operating system), sandbox, network_isolated (TRUE only when every Docker run had --network none; the process sandbox does not stop the network), internet, timeout_per_script, total_timeout, python_local (the Python run outside Docker and its version), and docker: runs (for each kind of run, r_run, r_install, python_run, python_install, the image and the docker run arguments, such as --network none, --read-only, --cap-drop ALL, no-new-privileges, the process limit and the memory and processor limits) and images (for each image, its ID and digests from docker image inspect, its creation time and the R and Python versions its environment declares).

It is NA for files run inside another script, files that are not an analysis, files not read, and a Docker failure. summary_table counts each group (repro_ran_n, repro_code_error_n, repro_dependency_n, repro_time_n, repro_not_checkable_n), and the report’s first sentence gives them. The traffic light reflects the static readiness signals by default; a script in code_error that stopped with an error makes it red, as a script that crashes on its own analysis is a genuine reproduction failure, and a script in one of the other three groups keeps it from being green. Calls that need a screen, which the run does not have (dev.print(), dev.copy2pdf(), dev.copy2eps(), savePlot(), windows(), win.graph(), x11(), quartz(), View()), are replaced before the run by calls that need none, which modifications records as screen_call_replaced. Introduction

Retrieving learned information from memory improves its longer-term retention relative to restudying or rehearsing the same information (Roediger & Butler, 2011; Rowland, 2014), a finding known in the memory literature as the retrieval practice effect (or testing effect). The retrieval practice effect is highly applicable to real-world and educational learning (Roediger et al., 2011), and is a recommended learning tool to boost educational performance in the classroom setting (Agarwal et al., 2012). Given these strong cognitive and pedagogical benefits, it is important to study the mechanisms and boundaries of retrieval practice further to inform appropriate learning practices.

Despite the positive influence of retrieval practice on memory, the underlying mechanisms are not fully understood. Some accounts, such as the bifurcation model (Kornell et al., 2011), explain the retrieval practice effect through differences in memory strength. According to this account, items that undergo restudy during learning are all strengthened to the same extent. For items that undergo retrieval practice, those unsuccessfully retrieved do not receive any strengthening, whilst successfully retrieved memories receive a large boost in memory strength, more so than the effect of restudy. This creates a bifurcation in the memory strength distribution for retrieved items. Later memory recall depends on a critical memory strength threshold: because successfully retrieved memories are strengthened more than restudy, they remain above this threshold for longer leading to longer-term memory benefits. Whilst this model provides a strong descriptive account of retrieval practice, explaining several moderating factors (Rowland, 2014), it falls short of providing a complete mechanistic explanation of retrieval practice. A neurocognitive account proposed by Antony et al. (2017) sought to address this gap by explaining retrieval practice effects through alterations in neural memory representations. According to the Rapid Consolidation Hypothesis (RCH), retrieval-based learning facilitates the consolidation and integration of new information with existing knowledge in the brain, supporting its longer-term retention. Under this framework, newly learned information is initially stored as an episodic representation in the hippocampus. If part of this information is retrieved in a subsequent phase of learning, the representations of semantically-related information in the cortex -the brain's long-term memory store -simultaneously coactivate, given the tendency for retrieval to be imprecise. This coactivation of new (episodic) and existing (cortical) information facilitates the integration of new information in the cortex by forming new and strong connections between co-activated representations. The establishment of a stable cortical representation, embedded within an existing knowledge structure, in turn supports the longer-term retention of the memory. Importantly, such co-activation of related information is not achieved when restudying or rehearsing a new piece of information. This hinders cortical integration and maintains the dependency on episodic memory in supporting the memory (Antony et al., 2017), which is subject to forgetting and decay over time (e.g., Hardt et al., 2013).

To evaluate the RCH, some studies have manipulated factors known to facilitate cortical consolidation, and compared their effects on retrieved and restudied information. Sleep is one such factor. Periods of sleep generally enhance memory retention compared to periods of wake (Berres & Erdfelder, 2021). This has been partly attributed to sleep playing an active role in memory consolidation, by redistributing and integrating new episodic information into cortical memory networks through hippocampal-cortical dialogue during certain sleep stages (Brodt et al., 2023; Klinzing et al., 2019; Rasch & Born, 2013). Therefore, the proposed overlapping effects of sleep and retrieval (Antony et al., 2017) should render further consolidation effects of sleep negligible on retrieved memories, but instead should particularly benefit restudied information. This was recently tested in Mak and Gaskell (2024), where participants learned some related word pairs (e.g., acid-rain) under retrieval practice conditions (acid -?), and learned other words under restudy conditions (acidrain). Participants returned 12 hrs later, after either a period of overnight sleep or a day of wakefulness, where their memory for the word pairs was tested. The sleep group outperformed the wake group for restudied information, but there were no significant group differences in memory for word pairs that underwent retrieval practice (see also Abel et al., 2019; Bäuml et al., 2014, for similar results). Although this pattern of results is consistent with the RCH, as discussed by the authors and Bäuml et al. (2014), these findings may also be explained by the bifurcation model. Under this model, sleep strengthens all memories to the same extent. Because restudied memories are more likely to drop below the critical recall threshold over time spent awake due to weaker memory strength (than successfully retrieved memories), sleep can push some of these memories back within the recall threshold, leading to better memory for restudied information after sleep than wake. In contrast, successfully retrieved (and hence substantially boosted) memories are likely to remain above the recall threshold even during time spent awake, reducing the benefit of sleep on retrieved memories.

Other empirical investigations have considered the behavioural consequences of cortical representation, and compared measures thought to index cortical representation between retrieved and restudied information. For example, a study by Lifanov et al. (2021) explored the "semanticising" effect of retrieval practice on memory, a feature of a shift in memory representation from the hippocampus to cortex, with the latter storing more gist and semantic-like features of a memory (Winocur & Moscovitch, 2011). This was operationalised by the relative speed in which participants recalled conceptual (e.g., "Does the recalled image represent an animate or inanimate object?") versus perceptual ("Does the recalled image represent a photo or a drawing?") properties of a memory, with quicker conceptual recall reflecting semanticisation. Critically, 48 hrs after learning, the difference in reaction time between these two question types was larger for information taught via retrieval practice relative to restudy, reflecting greater semanticisation following retrieval practice that hinted at cortical representation (see Caldwell et al., 2026 for similar electrophysiological evidence). Interestingly however, the reaction time difference across question types was nonsignificant immediately after learning, a point we return to later. Nonetheless, because the bifurcation model does not predict such qualitative differences between retrieved and restudied memories, the results from Lifanov and colleagues may provide more compelling evidence for distinguishing the bifurcation and RCH accounts than investigations of sleep.

Following retrieval practice, new memories are thought to be transformed from an initially labile episodic representation, to a more stable and longer-lasting cortical representation embedded with existing and similar memory representations (Antony et al., 2017). Another consequence of this integrated form of cortical representation is that following retrieval practice, new memories should be better placed to interact with the cortical representations of similar information, impacting how this information is processed online. However, this prediction is yet to be tested empirically, as existing research has largely measured the effect of retrieval practice on new, specific memories. For example, research exploring the interplay between sleep and retrieval practice has used pairwise-encoding procedures, such as learning word pairs, and tested memory for these specific pairings (Abel et al., 2019; Bäuml et al., 2014; Mak & Gaskell, 2024). Whilst this research supports the notion that retrieval practice benefits the retention of specific memories, it does not provide insight into whether this information is integrated alongside existing knowledge. Similarly, whilst Lifanov et al. (2021) found memories to be more semanticised after retrieval practice, perhaps reflecting cortical representation, this study did not specifically explore the possible interaction between new and existing memory representations. Thus, a core assumption of the RCH largely remains unexplored. The goal of this research was to address this gap by measuring the influence of retrieval practice on word learning.

It is well-established that retrieval practice benefits word learning, particularly in foreign language learning. For example, in Roediger & Karpicke (2008), the ability to recall the English translation of a newly-learned Swahili word (e.g., mashua-boat) was enhanced if the English word was retrieved one week earlier (e.g., mashua-?), relative to restudying the word pair again in its entirety (see also Barcroft, 2007; 2015; Candry et al., 2020; Kang et al., 2013; van den Broek et al., 2013; 2018). Pan and Rickard (2017) have similarly shown a benefit in remembering complex definitions for novel words in the native language. This word-learning benefit is also apparent in typically developing children (Goossens et al., 2014) and in children with Developmental Language Disorder (Leonard & Deevy, 2020), promoting retrieval practice as an effective word learning strategy in educational and clinical settings. Beyond enhancing the retention of word-meaning knowledge, however, the RCH would further predict that retrieval practice, relative to restudy conditions, should facilitate the emergence of lexical engagement. Lexical engagement is a term coined by Leach and Samuel (2007) to distinguish between different components of word knowledge. The ability to recall the meaning of a word -which is benefited by retrieval practice -is classified as lexical configuration and concerns factual knowledge about a certain word, such as its pronunciation and meaning. This form of understanding, however, is distinct from lexical engagement which concerns the ability of a word to interact with and influence how other words are processed. A common measure of lexical engagement is semantic priming whereby the processing of a target word is influenced by the preceding lexicosemantic context. For instance, when completing a primed lexical decision task, participants are typically quicker to respond to a target word (e.g., doctor) when it is preceded by a semantically related (e.g., nurse) compared to an unrelated prime word (e.g., chair; Mayer & Schvaneveldt, 1971).

Whilst the underlying mechanism of semantic priming is likely multifaceted and dependent on task demands (McNamara, 2005), under certain experimental conditions it is generally assumed that priming is underpinned by the interplay between representations in a semantic network. For example, according to Collins and Loftus' (1975) spreading activation account, the representation of the prime word diffuses a spread of activation towards associated and related concepts/representations. This temporarily reduces the activation threshold for accessing these related concepts, facilitating target word recognition.

Why, then, should retrieval practice promote lexical engagement, including semantic priming?

According to some theoretical accounts of word learning, new words display properties of lexical engagement once they have integrated with existing knowledge in cortical language networks (Davis & Gaskell, 2009; Lindsay & Gaskell, 2010). Much of the support for this idea derives from research investigating the impact of sleep on word learning. As sleep is thought to enhance longer-term memories by integrating and consolidating new episodic memories in cortical networks (Brodt et al., 2023; Klinzing et al., 2019; Rasch & Born, 2013), this reasoning suggests that words should display evidence of lexical engagement after a period of sleep. Although recent findings in the literature have challenged the completeness of this hypothesis, suggesting that sleep is not necessary for lexical engagement to emerge with novel words (Ball et al., 2024; Gaskell, 2024; Kapnoula & McMurray, 2016; Lindsay & Gaskell 2013; Weighall et al., 2017), sleep does appear to facilitate its emergence (for recent reviews see Palma & Titone, 2021; Schimke et al., 2021). A study by Tamminen and Gaskell (2013) revealed evidence consistent with this using semantic priming. In this study, participants learnt novel words and their associated meanings (e.g., feckton meaning a type of cat) which later served as prime words for related (e.g., dog, mouse and kitten) and unrelated target words. Novel words did not prime related targets immediately after they had been learned. However, words that had been taught at least one day prior to the priming task (Experiment 1), or one week earlier (Experiment 2), successfully primed related targets (see also Korochkina et al., 2024; van der Ven et al., 2015; cf Bakker-Marshall et al., 2018). Drawing on complementary learning systems frameworks of memory and word learning (Davis & Gaskell, 2009; McClelland et al., 1995), the authors proposed that newlylearned words are initially dependent on hippocampal processing that weakens their influence on the processing of known words stored in cortical semantic networks. However, periods of sleep in between learning and test facilitated the integration of novel words into semantic networks, promoting interactive processing between new and existing words (i.e., such as via a spreading activation type of mechanism described earlier).

Present research

Retrieval-practice is hypothesised to have a computationally similar impact as sleep on integrating new memories with existing cortical knowledge (Antony et al., 2017). However, this specific prediction has not been empirically tested. To address this, we investigated whether word learning strategy (i.e., retrieval practice vs. restudy), similar to sleep, influences the lexical engagement properties of novel words using semantic priming.

The experiment was pre-registered ahead of data collection (https://osf.io/xa3p5/overview?view_only=de584e4f08284ff988e894f159276c44). In Session 1 of the experiment, participants learnt a set of 40 novel words (e.g., blontack) and their definitions (a type of cat that has stripes and is grey) in a learning phase. Twenty of the words were encountered under restudy conditions, with participants instructed to rehearse and memorise the word and part of its definition. The remaining 20 were encountered under retrieval practice conditions, with participants asked to retrieve part of the word's definition when cued with the novel word form (followed by corrective feedback).

Immediately after the learning phase in Session 1, participants completed a primed lexical decision task to measure semantic priming (immediate task), where all of the novel words served as primes for related and unrelated target words. Participants returned ~48 hrs later for Session 2 which included a second primed lexical decision task (delayed task). Each session also included lexical decision tasks involving familiar prime words which served as positive control measures. It is important to note that all lexical decision tasks used a 200 ms stimulus onset asynchrony (SOA), which defines the temporal delay between prime and target onset. Semantic priming at this SOA is assumed to be underscored more strongly by mechanisms operating within semantic networks, such as spreading activation, compared to longer SOA where more explicit and conscious strategies can be utilised by the participant (see Ball et al., 2024 for a recent discussion in the context of word learning). We therefore opted for this SOA to increase the likelihood that any semantic priming effect was sourced from relatively "automatic" mechanisms, indexing integrated semantic representations.

Familiar prime words were expected to elicit semantic priming in both tasks due to their corresponding representations being well established and integrated in semantic networks. This is summarised by our first pre-registered hypothesis: 1) In the familiar prime word lexical decision tasks, we predict a statistically significant semantic priming effect.

Statistically speaking, this would be reflected by a significant main effect of relatedness (comparing related and unrelated trials).

As for the novel words, differences between learning conditions were anticipated in both lexical decision tasks. Concerning the immediate task, the RCH suggests that retrieval-based learning triggers cortical integration promptly, as soon as there is an attempt to retrieve an absent piece of information, provided that episodic and (related) cortical representations are sufficiently and simultaneously reactivated (Antony et al., 2017). In theory, this should trigger the immediate integration of novel words within existing semantic networks, facilitating semantic priming. As restudy does not lead to this same reactivation of related information, cortical integration is inhibited, with the memory remaining dependent on episodic/hippocampal processing. It is important to note that whilst this hypothesis would be predicted by the RCH, the existing evidence base paints a more tentative view on this hypothesis being supported. For example, in Lifanov et al. (2021), retrieval practice did not have a semanticising effect on memories immediately after learning. Similarly, Ball et al. (2024) found no evidence of semantic priming with a 200 ms SOA immediately after novel word learning which included retrieval opportunities as part of training (see also Tamminen and Gaskell, 2013; van der Ven et al., 2015 for similar "immediate" results with similar SOAs). Thus, whilst we take a theoretically-driven assumption in predicting that novel words taught via retrieval practice will engage in semantic priming immediately after learning (Antony et al., 2017), we acknowledge some scepticism in this prediction being met. Our second pre-registered hypothesis is as follows: 2) In the first lexical decision task with novel prime words, completed immediately after novel word learning, only novel words learned via retrieval practice are hypothesised to display a semantic priming effect; not words learned via restudy.

Statistically speaking, this hypothesis should correspond to a significant relatedness x learning condition interaction in the first primed lexical decision task, derived from our statistical model configured over data from both tasks (see Data analysis section). Examining the simple effect of relatedness within each learning condition should reveal a significant relatedness effect only in the retrieval practice condition.

Concerning the 48 hr delay, empirical (Roediger & Karpicke, 2006; Toppino & Cohen, 2009) and meta-analytical (Rowland, 2014) evidence suggests that the magnitude of the retrieval practice effect on memory recall increases in the days following learning, with retrieved information recalled to a higher degree of accuracy than restudied information. This is explained by the RCH as memory retrieval becoming more cortical, rather than episodic, dependent over time (Antony et al., 2017; see also Takashima et al., 2009). In addition, word learning studies have relieved evidence of semantic priming with novel words following delays of at least 24 hrs after learning (Korochkina et al., 2024; Tamminen & Gaskell, 2013; van der Ven et al., 2015; cf. Bakker-Marshall et al., 2018). Also relevant here is work exploring the interaction between sleep and retrieval practice on learning. Recall that when memory is tested ~12 hrs after learning, a period of overnight sleep benefits the recall of restudied information, whereas there is no benefit to retrieved information (Abel et al., 2019; Antony & Paller, 2018; Bäuml et al., 2014; Mak & Gaskell, 2024). However, over longer delays of 24 hrs (Mak & Gaskell, 2024) or one week later (Abel et al., 2019; Antony & Paller, 2018), memory performance is more strongly predicted by learning strategy, with retrieved information winning out. Retrieval practice, relative to sleep, may therefore represent a more targeted and longer-lasting route to cortical consolidation. Nonetheless, whilst sleep and retrieval practice may have qualitatively unique mechanisms for supporting cortical consolidation (Antony & Paller, 2018; Liu et al., 2024), the longerterm memory retention may still benefit from both processes (Himmer et al., 2019). This was taken to partly explain the delayed (~48 hrs later) effect of retrieval practice on semanticising memories in Lifanov et al. (2021): retrieval may establish cortical representation rapidly, but the extra consolidation effects afforded by sleep help to stabilise the representation to become "behaviourally relevant" ~48 hrs later when recall becomes more cortical dependent. Therefore, semantic priming ~48 hrs after learning may be stronger for words taught via retrieval practice relative to restudy. We are keen to stress the term stronger here, as we also predicted restudied information to display semantic priming 48 hrs later given offline consolidation opportunities afforded by sleep. However, given the combined impact of retrieval practice and sleep, this may be evident on a behavioural level as stronger semantic priming effects for words taught under retrieval practice. Note that our experiment did not directly manipulate sleep; rather, overnight sleep was assumed to have taken place twice after encoding, given the ~48 hr delay (see Procedure). The specific interval of 48 hrs was selected as memory is benefited by retrieval practice over this delay (Lifanov et al., 2021; Toppino & Cohen, 2009), whilst also being relatively soon after encoding that should aid in minimising participant attrition associated with multi-part experiments (relative to a longer delay such as one week later). Our third pre-registered hypothesis is as follows: 3) In the second novel word lexical decision task completed ~48 hrs after learning, words learned via retrieval practice are hypothesised to display an enhanced semantic priming effect relative to restudy.

Statistically speaking, this hypothesis should correspond to a significant relatedness x learning condition interaction in the second lexical decision task, derived from our statistical model configured over data from both primed lexical decision tasks. Examining the simple effect of relatedness within each learning condition should reveal a significant relatedness effect in both conditions, that is significantly stronger in the retrieval practice condition.

At the end of Session 2, participants completed a cued-recall task to provide a measure of explicit word knowledge. On each trial, one of the novel words was presented in the center of the screen, with the participant cued to provide its associated definition. Given the positive effect of retrieval practice on explicit memory (Rowland, 2014), we pre-registered the following hypothesis: 4) Definition recall, in terms of both recalling the core category of novel words and their features, will be superior for words taught under retrieval practice relative to restudy conditions.

Method

Participants

Our target sample size was 65 participants. This was derived from Brysbaert and Steven's (2018) recommendation of achieving 1600 observations per cell of an within-subjects experimental design measuring reaction time, whilst accounting for estimated data loss (i.e., incorrect responses and outliers). In total, 83 participants completed the experiment, recruited from Prolific (http://www.prolific.com/). Following pre-registered exclusion criteria, eighteen participants were excluded either for failing to recall the core concept of each word (e.g., "cat" in blontack) on <30% of trials in fourth (final) block of the learning phase 1 (see Procedure), or for achieving <75% accuracy in either the immediate or delayed primed lexical decision tasks (note that some participants met both criteria).

1In the pre-registration we stated that we would exclude participants who achieved <30% accuracy across the third and fourth block. However during recruitment we noticed that this threshold appeared overly conservative, and in some cases excluded participants who continued to improve into the fourth block. We therefore adjusted the criterion to the fourth block only.

This yielded a final sample of 65 participants (40 females, Mean age = 24.08 years, SD = 3.85 years).

Participants were aged 18-30 years, reported English to be their first language, and reported no known language (e.g., dyslexia) or memory-related disorders.

Materials

Our stimuli were mostly derived and adapted from Tamminen and Gaskell (2013). Forty novel words (e.g., blontack) were selected, originally derived from Deacon et al. (2004), and ranged from 4-8 letters in length (M length = 6.35 letters). Each novel word was associated with a definition during learning (e.g., "a type of cat that has stripes and is grey"). Definitions were constructed to contain a core known concept (e.g., cat -M log freq in British English = 4.40/million; van Heuven et al., 2014) along with two further semantic features (stripes and grey). The novel words and definitions were taught to participants in the familiarisation/learning tasks (see below). Two counterbalanced lists of learning stimuli were created, with each participant receiving one list that determined the 20 words taught under restudy conditions and the 20 under retrieval practice conditions. Within lists, learning conditions were matched on frequency of the core concept and definition length (all p's > .281).

In the primed lexical decision tasks, the novel words served as primes for related/unrelated real word targets. Accordingly, three semantic associates were identified for each word/definition from the University of South Florida Free Association Norms (Nelson et al., 2004). For example, dog kitten and mouse served as related associates to blontack (M log freq of associates = 4.52/million, M length = 4.78 letters, M association strength = 0.18; within lists, the two learning conditions were matched on these characteristics, all p's > .153). Unrelated real word targets were created by pairing each prime with a related target of a different prime (held consistent across participants, ensuring that there was no obvious semantic connection/association between the unrelated pairings).

Nonword targets were derived by substituting one letter from each real word to create a nonword (e.g., kitgen).

Forty familiar prime words (e.g., wasp) were also selected along with three semantic associates (bee, string, hornet) for the familiar primed lexical decision tasks. Thirty-four of these were again sourced from Tamminen and Gaskell (2013), with a further six selected from Nelson et al. (2004).

Words with relatively low frequencies (M log freq in British English = 3.79/million) were purposely selected to match them more closely with the very low frequencies of the novel words learned in training (M log freq of associates = 4.38/million, mean length = 5.2 letters, M association strength = 0.15). Unrelated real word trials and nonword targets were created in the same way as those from the novel prime words. Familiar primes and their real/nonword targets were presented in a separate task (see Procedure).

Design

The experiment utilised a within-subjects design. We manipulated two within-subjects factors. The first factor -Learning condition -had two levels and reflected novel words learned under retrieval practice or restudy conditions. The second factor -Test -had two levels and reflected the point in the experiment where the primed lexical decisions tasks were completed: immediately after encoding (immediate) or ~48 hrs later (delayed). In the primed lexical decision tasks, we measured reaction time (milliseconds) in making word/nonword decisions, along with response accuracy. In the cued-recall task, we measured accuracy in recalling the correct word form.

Procedure

All stages of the experiment were hosted on Gorilla Experiment Builder (Anwyl-Irvine et al., 2020). The experiment began with Session 1, which served two purposes: a) teach 40 novel words and their definitions to participants, and b) measure semantic priming immediately after learning had taken place. Session 2 was completed ~48 hrs later and included further lexical decision tasks, followed by a cued recall task for measuring explicit knowledge of the novel words. For both sessions, participants were asked to verify that they were positioned in a quiet environment with minimal distractions. A schematic overview of the procedure is illustrated in Figure 1.

Session 1: Familiarisation phase

Novel word training took place first and began with a familiarisation phase. In this phase, each word-definition pairing was presented sequentially for 6 s. The word was presented towards the top of the screen, with the associated definition appearing below it. Participants were instructed to learn and memorise each word and its definition, and that their memory for the words would be tested later on. Each word and definition was presented once.

Session 1: Learning phase

In the learning phase, half of the words from the familiarisation phase (20) were presented under restudy conditions, with the remaining words encountered under retrieval practice conditions.

There were eight learning blocks in total in the learning phase, with each block prompting learning for a specific aspect of word definition (see Figure 1). That is, category learning blocks prompted learning of the core category of novel words (e.g., blontack -"a type of cat"), feature 1 learning blocks prompted learning of the first feature of each word (blontack -"has stripes"), and feature 2 learning blocks prompted learning of the second feature (blontack -"is grey"). Within blocks, restudy and retrieval practice trials were randomly intermixed, with each participant receiving a different randomised order. On restudy trials, participants read the novel word and the block-relevant aspect of definition together for 5 s, before the full definition was shown for 3 s. The participant was tasked with studying and memorising the novel word and its definition. On retrieval practice trials, the blockrelevant aspect of definition was withheld (e.g., blontack -"a type of ___"; "has ___"; "is ___") and participants were asked to retrieve and type the missing information. After 5 s, the full definition was shown for 3 s to provide corrective feedback. We presented only certain aspects of word meaning in each learning block, rather than the full definition (as in the familiarisation phase), for the following reasons. Firstly, it was prudent to equate the two learning conditions on overall exposure time to ensure that any differences in memory or semantic priming were not confounded by differences in level of exposure. However, had participants been required to retrieve the full definitions on retrieval trials, this would have required particularly long restudy trials to match the time taken to retrieve and type a full definition, which could have introduced boredom/attention confounds. Second, it was also important not to present the full definition of retrieval trials (e.g., "a type of ___ that has stripes and is grey") to prevent contextual information contained in the definition biasing responses, above and beyond memory-driven responding. Each novel word and its partial definition was presented once per block, and the order of the eight learning blocks was as follows: 1) category recall, 2) feature 1 recall, 3) category recall, 4) feature 2 recall, 5) category recall, 6) feature 1 recall, 7) category recall, 8) feature 2 recall. There were purposely more category recall blocks (4) than each feature recall block (2) to facilitate learning of the core aspect of meaning that was relevant to encourage semantic priming with related words (e.g., "cat" was a related prime of "dog", "mouse", and "kitten"). However, feature learning was intended to aid in the formation of a unique memory representation for each novel word that helped it stand out from the existing category. Within each block of the learning task were two attention check trials. On attention check trials, participants viewed a three-digit sequence for three seconds before typing the sequence they had just seen. We pre-registered to exclude participants who failed six or more trials, however no participants met this threshold. In total, the familiarisation and learning phases took approximately 1 hour to complete.

Session 1: Primed lexical decision tasks

Immediately after the learning phase, participants completed two primed lexical decision tasks in succession. In one task, the forty learned novel words served as prime words for real/nonword targets, while in the other task the forty known, familiar words served as primes. The order of the novel and familiar priming tasks was counterbalanced across participants.

In each task, participants made speeded word/nonword decisions to the target words.

Participants were informed that they would see pairs of words in quick succession, and were asked to determine if the second word in each pair was a real English word or not. A trial began with a 500 ms fixation cross. This was then replaced by a prime word for 200 ms, followed by the target word (creating a 200 ms SOA). Participants could make their decision as soon as the target word appeared, pressing either the A or L key (key assignment was counterbalanced across participants). The target remained onscreen until the participant responded, or up to 2 s. To encourage fast and accurate responding, the reaction time of each trial was displayed for 500 ms after each response, or the text "Too slow!" was shown if 2 s had passed without a response.

Within each task, there were 120 real word and 120 nonword target trials. The real word trials were broken down further into 60 related and 60 unrelated trials, and for the novel priming task, this was broken down further into 30 trials per learning condition. Every prime was encountered six times, three times preceding a real word target and three times a nonword target. Given that there were three real word trials per prime, it was not possible to evenly distribute related and unrelated trials within primes. To counteract this, two counterbalanced priming lists were configured for both the novel and familiar priming task (A and B -see Figure S1 in the Appendix for an example). Half of the primes appeared with two related targets and one unrelated target in List A, and with one related target and two unrelated targets in List B, with the pairings reversed for the other half of words (balanced between restudy and retrieval practice conditions for the novel priming task). Individual targets appeared once per list but in a different relatedness condition across lists (e.g., dog was preceded by its related prime in List A and by an unrelated prime word in List B). Critically, participants received either List A and or List B in the primed lexical decision task in Session 1, and received the other list in the same task completed ~48 hours later in Session 2 (see below). This meant that withinparticipants and within-tasks, there was an equal amount of related/unrelated trials per learning condition, and that across tasks, each prime was encountered with a related and unrelated target an equal number of times. Importantly, this also ensured that specific prime-target pairings were not repeated across tasks. Each task was split into 3 blocks of 80 trials, with each prime appearing twice per block with both a nonword and real (related or unrelated) word target. For the familiar priming task, there were 20 related and 20 unrelated real word trials per block, and for the novel priming task, there were 10 real word trials for each cell of the design (restudy related; restudy unrelated; retrieval related; retrieval unrelated). Each lexical decision task took approximately ten minutes to complete, with participants permitted to take a short break after each block.

Session 2

Session 2 was accessible to participants on Prolific two days after completing Session 1, yielding an interval of around 48 hrs between the two sessions 2 . The goal of Session 2 was to measure semantic priming over a relatively lengthy interval following encoding (delayed test), and to measure explicit word knowledge. To this end, the session began with two further primed lexical decision tasks (one with novel and one with familiar prime word), with participants receiving their remaining priming task list. The task procedures were identical to the same tasks completed in Session 1.

Following this was a cued recall task. On a given trial, one of the novel words was presented in the centre of the screen. Participants were instructed to type the full definition to the best of their ability and could respond as soon as the word appeared. Participants pressed the Return key to submit their response and finish the trial. No feedback was provided. Each of the 40 novel words was presented in a new randomised order for each participant.

Results

We first present the results from the cued recall test administered in Session 2 to determine whether retrieval practice benefited explicit knowledge of the novel words, akin to the positive effects of retrieval on explicit memory (Knowland, 2014). We then report the results from the primed lexical decision tasks, measuring the more novel impact of retrieval practice on novel word semantic priming and memory integration. All of our analyses and data preprocessing steps were pre-registered ahead of data collection (https://osf.io/xa3p5/overview?view_only=de584e4f08284ff988e894f159276c44)

Cued recall of novel word meaning

We analysed two aspects of definition recall. We first analysed recall of the core category of the novel words (e.g., "cat" in "a type of cat that has stripes and is blueish-grey") using a generalised linear mixed effects model (GLMM). Recall accuracy (1 = core concept correctly recall,0 = incorrect response) was included as a binary outcome measure, predicted by a single sum-coded fixed effect of Learning condition. To construct our random effects structure, we used the Buildmer package (Voeten, 2023) to identify the most parsimonious structure, given our data (this procedure was used for all mixed models reported in this paper). For the analysis of category recall, Buildmer found the most parsimonious structure to include by-participant and by-novel word random intercepts, and random slopes for Learning condition which varied by participants. The model revealed a statistically significant main effect of Learning condition (B = 1.47, SE = 0.13, z = 11.08, p <.001). As expected, participants were more accurate at recalling the core category of words trained in the retrieval practice (M proportion correct recall = 0.60, SD = 0.49) relative to the restudy condition (M = 0.33, SD = 0.47; see Figure 2A).

The number of word features recalled on each trial (ranging from 0-2) was analysed using a

Poisson mixed-effects model. The random effects were identical to the analysis of category recall. This analysis also revealed a statistically significant main effect of Learning condition (B = 0.84, SE = 0.10, z = 8.55, p <.001), with a greater number of features recalled for words learned under retrieval practice (M number of features recalled per trial = 0.80, SD = 0.88) than restudy conditions (M = 0.43, SD = 0.75; see Figure 2B). Thus, consistent with hypothesis 4, word-meaning learning was benefited by retrieval practice, akin to the positive effects of retrieval practice on explicit memory.

Lexical decision task: Familiar prime words

Reaction time (ms) to real word targets in the lexical decision tasks was analysed in a linear mixed-effect model (LMM) using the lme4 R package (Bates et al., 2015). Prior to the analyses, incorrect responses were removed along with trials with <150 ms reaction time (Miller, 2023). We then log-transformed reaction time to reduce the impact of positive skew on the data. Whilst logtransformed reaction time was used as the dependent variable in the analysis, raw reaction time is presented in-text and in figures to improve readability.

For the familiar priming task, the model included sum-coded (-0.5, 0.5) fixed effects of Relatedness (related vs. unrelated prime-target trials) and Test (immediate vs. delayed test), along with the two-way interaction. The most parsimonious random effects structure included byparticipant, by-target, and by-prime random intercepts, random slopes for Test which varied by participants, and random slopes for Relatedness, Test and their interaction which varied by target.

There was a statistically significant main effect of Relatedness (B = 2.91, SE = 0.38, z = 7.64, p <.001) 3 , with quicker reaction times on related prime-target trials (M reaction time = 555.67 ms, SD = 91.25) compared to unrelated prime-target trials (M = 569.89 ms, SD = 81.37), revealing a semantic priming effect for familiar prime words consistent with hypothesis 1. There was no significant main effect of Session (B = 1.03, SE = 1.28, z = 0.81, p =.423), and although the magnitude of the priming effect was numerically stronger in the delayed test (see Figure 3B), there was no significant two-way interaction between Relatedness and Session (B = -1.03, SE = 0.75, z = 1.38, p =.169).

Lexical decision task: Exploratory Bayes factors

To follow up the null findings in the novel primed lexical decision task, we calculated Bayes Factors (BF10 ) for our effects of interest to inform us of the degree of support for the null hypothesis (i.e., unrelated reaction time = related reaction time). We used the ttestBF function from the BayesFactor R package (Morey & Rouder, 2024) to compare participant mean reaction time across the related and unrelated conditions, within each Test and Learning condition (four tests were performed). All four tests revealed moderate evidence in favour of the null hypothesis (BF10 0.10 -BF10 0.30: Lee & Wagenmakers, 2013): restudy immediate test BF10 = 0.16; retrieval practice immediate test BF10 = 0.18; restudy delayed test BF10 = 0.27; retrieval practice delayed test BF10 = 0.19. Conversely, equivalent tests for the familiar priming task revealed very strong evidence for the alternative hypothesis (unrelated reaction time ~= related reaction time): immediate test BF10 = 153.75; delayed test BF10 = 650.50.

Discussion

The aim of this experiment was to investigate a key yet untested tenet of the rapid consolidation hypothesis (RCH - Antony et al., 2017) that retrieval-based learning integrates new information with existing knowledge in cortical memory networks. We investigated this by measuring semantic priming with recently learned novel words, an established paradigm for measuring the effect of sleep on memory integration. After periods of sleep, novel words are typically more influential in speeding up (priming) the recognition of related words. This is explained by sleep facilitating the integration of novel words in semantic networks, where integrated semantic representations are better placed to influence the processing of related words/representations through shared neural connections (Davis & Gaskell, 2009; Tamminen & Gaskell, 2013). Due to the proposed overlapping effects of sleep and retrieval practice on memory integration (Antony et al., 2017), words taught under retrieval practice conditions should be more influential in priming the recognition of related words than words taught under restudy conditions.

We trained 20 novel words and their definitions to participants (e.g., blontacka type of cat that has stripes and is grey) under retrieval practice conditions and 20 under restudy conditions. Novel words served as primes for related (e.g., dog, kitten, mouse) and unrelated target words in primed lexical decision tasks both immediately after training and ~48 hrs later. Because retrieval practice, but not restudy, is hypothesised to trigger memory integration promptly, this should enable novel words taught via retrieval to exclusively engage in semantic priming in the immediate test 4 . Concerning the longer ~48 hr delay, memory is typically superior for retrieved vs. restudied information over longer delays. This is explained by the RCH as memory becoming more cortically-dependent over time (Takashima et al., 2009), with retrieval hypothesised to promote cortical representation (Antony et al., 2017). We therefore predicted to observe significantly stronger semantic priming for retrieved vs.

restudied words, with significant priming also being predicted in the restudy condition due to periods of sleep independently supporting memory integration. Although retrieval practice enhanced explicit word knowledge ~48 hrs later, we did not find significant evidence of semantic priming in either learning condition in any test, inconsistent with our predictions. Follow up Bayesian t-tests comparing reaction time between related and unrelated conditions within each test and learning condition revealed moderate evidence in favour of the null hypothesis. Importantly, these null results cannot be attributed to the parameters of the lexical decision task being insufficient to elicit priming, since significant semantic priming was observed in equivalent tasks involving familiar prime words.

First and foremost, the positive effect of retrieval practice on definition recall replicates the well documented benefit of retrieval-based learning on explicit memory (Rowland, 2014). In the context of word learning more specifically, this finding complements related work revealing a retrieval benefit on remembering the meanings of new words in foreign language learning (Barcroft, 2007; 2015; Candry et al., 2020; Kang et al., 2013; Roediger & Karpicke, 2008; van den Broek et al., 2013; 4 As a reminder, we acknowledged some scepticism in this prediction being confirmed. This was partly due to findings that the "semanticising" effect of retrieval practice on memory is not apparent immediately after learning but is 48 hrs later (Lifanov et al., 2021), and evidence that novel words do not prime related words immediately after learning despite retrieval exercises during word learning (Tamminen & Gaskell, 2013; van der Ven et al., 2015).

The positive influence of retrieval practice on definition recall thus validates our learning manipulation, which aids in contextualising the semantic priming results that constitute the more novel aspect of our study. As described in the Introduction, semantic priming represents a measure of lexical engagement concerning a word's ability to influence the processing of other words, which is distinct from lexical configuration related to core, factual word knowledge (Leach & Samuel, 2007).

Thus, our study suggests that retrieval practice may not benefit all aspects of word learning or knowledge. Before discussing the possible theoretical implications of our findings, it is important to first consider whether aspects of our methodology were insufficient for eliciting semantic priming, regardless of learning conditions. One relevant factor concerns the overall level of exposure to the novel words, with each word and its definition presented nine times in total across the familiarisation (1) and learning phases (8). Although some studies have reported significant semantic priming (24 hrs after learning) with a similar level of novel word exposure (van der Ven et al., 2015), our exposure level is considerably lower than other studies reporting significant effects, such as 17 exposures in Tamminen & Gaskell (2013; see also Ball et al., 2024). Related research exploring lexical engagement on the phonological level, measuring the influence of a novel word form (e.g., cathedruke) on the processing of a phonological neighbour (cathedral), has employed even higher exposure levels (e.g., 36 exposures of novel word forms in Dumay & Gaskell, 2007; Takashima et al., 2014). Therefore, on the one hand, our exposure level appeared sufficient for establishing fairly long-term memory traces for some words and their definitions (60% and 33% of word meanings were recalled in the retrieval and restudy conditions, respectively), but on the other, may have been too small to support the integration of novel words into semantic networks. Successful integration may require a sufficiently high exposure level to promote a relatively stable representation of a novel word and its meaning, irrespective of any integrating effects of retrieval practice and sleep. This could be overcome in future research by increasing the number of exposures for individual words. However, participants in the current study took approximately one hour to complete the familiarisation and learning phases, meaning further exposures in the current paradigm could feasibly introduce boredom or attention confounds.

Another relevant factor when considering semantic priming in the delayed test concerns the duration of time between learning and the delayed test. Given the ~48 hr delay used in the current paradigm, we assumed that at least two periods of overnight sleep had taken place between learning and the delayed test. In theory, memory replay processes during NREM sleep were expected to facilitate the integration of novel words into semantic networks (Brodt et al., 2023; Klinzing et al., 2019; Rasch & Born, 2013), promoting semantic priming (in both conditions) in the delayed test.

However, this time-frame may have been too short to allow sufficient quantities and integrating effects of sleep to take place. Indeed, some studies have failed to detect semantic priming with novel words over a 24-hr period that included overnight sleep (Bakker-Marshell et al., 2018). Importantly, Bakker-Marshall and colleagues used identical exposure levels to studies that have reported significant effects (e.g., Tamminen & Gaskell, 2013), although other factors could have played a role in these non-significant results (e.g., lower statistical power through a smaller sample size compared to prior studies). Nonetheless, the results could imply that a single night of sleep is not necessarily sufficient to adequately integrate novel words and their meaning to the extent required to elicit semantic priming. In our case, and coupled with the low exposure level, two nights of sleep may also have been insufficient. Future research could therefore seek to measure delayed priming over a longer period of time.

Beyond methodological considerations, the null confirmatory findings and follow-up Bayesian results could have theoretical ramifications, and may suggest that retrieval practice does not integrate new memories into cortical long-term memory (Antony et al., 2017), at least to the extent required to elicit semantic priming with novel words. This is intriguing considering findings that are consistent with some proposals of the RCH. For example, retrieved information experiences a reduced benefit of sleep compared to restudied information (Abel & Bäuml, 2019; Bäuml et al., 2014; Mak & Gaskell, 2024), although this finding may also be explained the bifurcation model (Bäuml et al., 2014; Mak & Gaskell, 2024). Furthermore, retrieved memories adopt a more semanticised representation than restudied information (Lifanov et al., 2021; Caldwell et al., 2026), with cortical long-term memory representing more gist or semantic-like details. However, these prior findings speak to the effect of retrieval practice on new, individual memory representations. For example, retrieval practice may consolidate new information into cortical memory networks, giving rise to a more semanticised and gist-like memory representation (Lifanov et al., 2021; Caldwell et al., 2026). Yet based on the current data, the retrieved and consolidated memory may still be stored in relative isolation, failing to integrate and form new connections with existing, related memory representations. A recent neurocognitive model by Brodt et al. (2023) to explain memory reactivation processes across wake and sleep appears consistent with this proposal. According to this model, active retrieval attempts during wakefulness may strengthen and consolidate the cortical representations of the retrieved memory/information (e.g., the cortical semantic representations of a novel word). Although the model does not describe the neurocognitive mechanisms underlying restudy events, consolidated cortical representations after retrieval could explain why participants were better at recalling the definitions of words taught under retrieval practice than restudy conditions in our experiment.

However, active retrieval is driven exclusively by cortical processes following a cue or deliberate search (e.g., retrieving a definition when cued with word form), and does not elicit the coactivation of related concepts as argued by the RCH (Antony et al., 2017). According to Brodt and colleagues, this limits the integration of new information with existing knowledge, with memory integration more strongly dependent on sleep. More specifically, memory replay processes during NREM sleep are also driven by the hippocampus that transmits contextual information to the cortex. This dialogue from the hippocampus is used to identify related memories stored in cortical long-term memory and integrate new information with such knowledge. Tentatively, therefore, our data may be more consistent with the proposed mechanisms of retrieval outlined by Brodt et al. (2023) than Antony et al. (2017).

In conclusion, the results from our experiment revealed significant evidence that retrieval practice, relative to restudy, enhances the longer-term retention of definitions for recently learned novel words. However, retrieval practice did not equivalently enhance a novel word's ability to prime an existing, related word in a semantic priming paradigm. Mechanistically, this could suggest that retrieval practice strengthens individual memory representations, but does not integrate these representations within cortical knowledge structures as argued by the RCH (Antony et al., 2017).

However, these null findings should be interpreted within the context of methodological considerations that may have reduced the capacity for semantic priming to emerge. In our view, therefore, it remains to be seen whether retrieval practice influences semantic priming with novel words, and hence supports cortical memory integration. Future research, potentially taking the raised methodological considerations into account, would be fruitful for continuing this investigation.
