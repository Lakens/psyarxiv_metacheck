An a priori power analysis for an independent samples t-test, conducted using the pwr.t.test function from pwr (Champely, 2020), indicated that for a Cohen’s d = 0.5, an alpha level of 0.05, and a desired power level of 80% required at least 64 participants in each group.

For a sensitivity power analysis, this sentence would look like:

A sensitivity power analysis for an independent samples t-test, conducted using the pwr.t.test function from pwr (Champely, 2020), indicated that with 64 participants in each group, and an alpha level of 0.05, a desired power level of 80% was reached for an effect size of d = 0.5.

How StatCheck works

Check consistency of p-values and test statistics

The Statcheck module runs Statcheck. Statcheck searches for regular expressions that match a predefined pattern, and identifies APA reported statistical tests. More information on the package can be found at https://github.com/cran/statcheck. The module only returns Statcheck results for t-tests and F-tests, as these are the only tests which have been validated, see https://osf.io/preprints/psyarxiv/tcxaj_v1/.

Statcheck was developed by Michèle Nuijten and Sascha Epskamp.

Statcheck considers p = 0.000 an error, as you should report p < 0.001. Furthermore, p < 0.03 is an error if the p-value was 0.031, and one should simply report exact p-values (p = 0.031). When the sentence of a test says it is one-sided (“one-tailed”, “one-sided” or “directional”), a p-value that fits a one-sided test counts as consistent (statcheck’s OneTailedTxt setting; #695). When the paper says anywhere that its tests are one-sided, a p-value that fits a one-sided test in either direction counts as consistent too: half the two-sided p, or 1 minus that half for an effect against the predicted direction. Equivalence tests (TOST) are left out, as their p-values do not test the difference. A statistic written with “<” or “>” is read as a bound, and in a sentence about equal variances an F-test’s two-sided p (twice the one-tailed p) counts as consistent. For more information, see StatCheck.

This module only checks statistical results reported in the running text of the manuscript. It cannot (yet) process statistics reported only in tables.

How Exact P-Values works

List any p-values reported with insufficient precision (e.g., p < .05 or p = n.s.), reported as exactly zero (e.g., p = .000), or impossible (below 0 or above 1, e.g., p = -.22).

This module uses regular expressions to identify p-values. It will flag any values reported as p > ? or p < numbers greater than .001. It will also flag p-values reported as exactly zero (e.g., p = .000, p = 0.00), which are mathematically impossible — p-values are never exactly zero and should instead be reported as p < .001.

A p-value that is not the result of a test is not flagged: a table note (“* p < .05, ** p < .01”), a figure legend (“Asterisks indicate significant differences (p < .05)”, “Values in bold are significant at p < .05”) or a stated threshold (“p < .05 was considered significant”, “thresholded at p < .001”). GROBID often puts such notes into the running text, so each p-value is judged by the words in its own clause (the text up to a “;” or a full stop), and never left out when a test statistic belongs to it (“F(1, 7) = 8.03, # p < .05”). The column not_a_test of the table says why a p-value was left out (“marker”, “threshold”, “legend” or “named”).

A p-value with the name of a correction or a test after the p (“pFWE < .05”, “padj < 0.05”, “p Wilcoxon = .02”) is flagged only when a test statistic comes before it in its clause (“t(37) = 7.17, p FWE < .05”). Without one it is mostly the rule that decided what was significant (“genes with padj < 0.05 were selected”); such a p-value is “named” in not_a_test. Notes in other forms, such as a marker after the p-value (“p < .05 (*)“), are still flagged.

A p-value below 0 or above 1 is impossible; it is listed apart and not also as imprecise. Often the statistic before it, or its minus sign, was copied into it (“t(134) = -2.32, p = -.13”, “Z = 3.091, P = 3.091”). A value above 1 is listed only after a test statistic in its clause: without one, a “P” above 1 was nearly always another quantity (a proportion, pH, a group’s mean, a model parameter). A number in scientific notation whose power of ten was lost when the PDF was read (“p = 2.4 x 10 -9” read as 2.4) is not listed. A “p” that is the subscript of another symbol (“r p = .64”, “²p = .02” for partial eta squared, “Δp = .33”), or a quantity with a unit, a logarithm or a ratio (“P = 2.9 µm”, “-log10 P = 7.5”, “Ca/P = 1.67”), is not read as a p-value at all (see extract_p_values()). Each p-value has its own row, also when the same one is written twice in a sentence.

This module sometimes flags false positives when sentences discuss how p-value thresholds were set. It can also miss an imprecise p-value that is reported against a threshold (“decreased at the p < .05 significance threshold”).

This module only checks p-values reported in the running text of the manuscript. It cannot (yet) process p-values reported only in tables (as opposed to a table’s footnote text, which the module does see and tries to exclude — see above).

How Code Check works

This module retrieves information from repositories checked by repo_check about code files (R, Python, SAS, SPSS, Stata, Mplus, MATLAB).

The Code Check module checks R (also R Markdown and Quarto), Python (also Jupyter notebooks), SAS, SPSS, Stata, Mplus, and MATLAB files, using regular expressions to check the code; JASP files are listed but not read. The language of a Quarto document or a notebook is read from the file itself (its engine or kernel), not from its extension. The regular expression search will detect the number of comments, the lines at which libraries/imports are loaded, attempts to detect absolute paths to files, setwd() and install.packages() calls, and lists files that are loaded, and checks if these files are in the repository; R code is also parsed. The module will return suggestions to improve the code if there are no comments, if libraries/imports are loaded in lines further than 4 lines apart, if files that are loaded are not in the repository, if absolute file paths, setwd() or install.packages() are found, and if R code cannot be parsed.

The regular expressions can miss information in code files, or falsely detect parts of the code as a fixed file path. Libraries/imports might be loaded in one block, even if there are more than 3 intermittent lines. The module was tried out internally on papers published in Psychological Science, but has not been formally validated. There might be valid reasons why some loaded files can’t be shared, but the module can’t evaluate these reasons, and always gives a warning.

The module also checks whether the repository pins the R/package versions the analysis actually depended on: an renv.lock file (parsed for the R version and every locked package + its version/source), a sessionInfo()/sessioninfo::session_info() text dump (matched by filename — sessionInfo.txt/session_info.txt and similar, or embedded in a README), or a groundhog::groundhog.library()/checkpoint::checkpoint() date-pin call in the code (a bare library(groundhog)/library(checkpoint) does not count — the pinning call itself must be present). When none of these is found, the report flags it as a reproducibility gap: package versions may drift between when the analysis was run and any later reproduction attempt.

How Data Check works

This module classifies the files in a repository into semantic types (data, codebook, code, software, output, supplemental, readme, asset, other) and, for tabular data files, extracts each column’s type and summary statistics.

The Data Check module consumes the file list produced by repo_check (or any files added via local_path). Each file is classified with rule-based heuristics layered over metacheck’s file_category() and file_types: file names matching README / codebook patterns win first, then an extension crosswalk, then format-locked extension overrides. For every file classified as tabular data that is available locally, the module reads the file head, describes each column with data_col_facets() and computes summary statistics for numeric columns. Every sheet of a spreadsheet that holds a table is read: a file with several such sheets has its columns under source_file = "file.xlsx [sheet]", and the sheet column names the sheet of any spreadsheet with several sheets; a sheet of notes or a codebook is treated as documentation when the file has another table. Following DDI, a column is described by orthogonal facets rather than a single type: representation (numeric/text/datetime/code — how it is stored), measurement_level (Stevens: nominal/ordinal/interval/ratio), concept (what it measures: reaction_time/age/gender/likert/id/…), role (identifier/measure/condition/timestamp), unit, and a quality state (ok/empty/constant). Concepts are detected by name+value rules (the demographic concepts via data_check_demographic()); when llm_use(TRUE) the model fills concepts and measurement levels the rules left blank. How Reproducibility Check works

This module assesses whether a paper’s R and Python code can be run on its data. It works in two phases. The static phase (always run) collects the package dependencies the code declares, rewrites the data-file paths that do not work in the repository as the authors organised it, works out the order the scripts must run in, and diagnoses why any referenced input file is unavailable — reporting what a reproduction attempt would involve and where it is likely to break. By default (execute = FALSE) the module does not run any code — it performs only static analysis: reading dependencies with the same extractors as code_check, finding the files the code references in the repository, and building a run-order dependency graph. It reports what would be installed and run rather than doing it.

Installs (when install_missing = TRUE) and the throwaway run library never touch your main R library. Age-Graded and Retirement-Related Interest Development in Later Adulthood

Interests are widely studied across educational, vocational, and personality psychology (Su, 2020). They are powerful predictors of educational choice and performance (Elsworth et al., 1999; Nye et al., 2012), among the most widely examined antecedents of career choice (Hanna & Rounds, 2020), and predict broader life outcomes like family formation, leisure, and community engagement (Roemer, Nye, Su, et al., 2026; Stoll et al., 2017). As broad motivational traits that guide individuals' behavior across various domains, interests form an integral part of human individuality, both in occupational contexts and beyond them (Holland, 1997; Roberts & Nickel, 2017). Therefore, understanding how these motivational tendencies develop across the lifespan is an important task for psychological research.

Prior research has shown modest mean-level changes in interests during adolescence and young adulthood (Hoff et al., 2018; Low et al., 2005) and highlighted that interest development results from ongoing interactions between a person and their environments (Holland, 1997; Nye et al., 2021; Wille & De Fruyt, 2019). However, even though people spend their entire lives transacting with environments and activities related to their interests, surprisingly little is known about how interests develop in midlife and older adulthood.

Because most interest research is focused on guiding young adults' transition into the workforce (e.g., Nauta, 2010), to our knowledge, there are no published studies on interest development after age ≈ 50. Examining age-graded interest trajectories in later adulthood allows researchers to refine theories of interest continuity and change. At a time of increased career mobility amid aging populations, insights into adult interest development also have practical relevance and may guide organizational practices focused on mature workers, such as late-career planning and talent management. If, for example, certain interests systematically decrease among older adults, organizations may consider targeted efforts to maintain motivation in this age group.

In later adulthood, retirement is a central life event. By definition, retirement disrupts the environments assumed to reinforce interests at work, while creating new opportunities for engagement outside the work domain. Because this contextual reconfiguration may affect older adults' interest levels, explicitly examining how the transition to retirement reshapes interest trajectories adds explanatory value to the study of interest development later in life.

Retirement-related analyses of interest development therefore theoretically and methodologically complement age-graded analyses in later adulthood. More practically, results may guide retirement planning and adjustment programs by informing about the normative interests that retirees have and may seek to pursue.

In this study, we use nationally representative data collected in three waves over ten years to investigate mean-level interest development in German older adults. The results contribute to the literature in three major ways. First, the current study provides much-needed longitudinal evidence from a population-representative sample on age-graded interest development among adults aged 50 and older, a demographically important, yet understudied life phase in the interest literature. Second, our study is the first to investigate the moderating effects of the transition to retirement on interest development. By comparing retirees with propensity-score matched non-retirees, the results inform the extent to which this near ubiquitous life event affects interest trajectories, which can refine theoretical mechanisms assumed to underly interest development. Third, in addition to these primary analyses, we explore whether and how the developmental patterns differ by gender and across individuals who are interested in their jobs (i.e., interest fit). By clarifying individual differences in change, these additional tests add context to developmental theories and help to identify the individuals who might benefit the most from late-career and retirement counseling.

Conceptualizing Individual Differences in Interests

The most common framework for studying individual differences in interests is Holland's (1997) RIASEC model. This model posits that interests-defined as trait-like preferences to engage in specific activities and contexts (Rounds & Su, 2014)-can be described in terms of six dimensions: Realistic, Investigative, Artistic, Social, Enterprising, and Conventional. Holland's model originated in the vocational domain and is typically assessed with preferences for work-related activities. Nevertheless, the RIASEC interests are broad constructs whose motivational power extends to both work and nonwork domains. For instance, along with work-related outcomes like career choice and job performance (Hanna & Rounds, 2020; Nye et al., 2012; Van Iddekinge et al., 2011), RIASEC interests also predict relationship, educational, and leisure outcomes (Cairo, 1979; Roemer, Stoll, et al., 2024; Stoll et al., 2017), and they do so across the adult lifespan (Roemer, Nye, Su, et al., 2026). Despite their broad predictive validity, interest assessments have been predominantly used for career guidance (Nauta, 2010). As a consequence, the vast majority of interest research relies on adolescent or young adult samples. For example, in a meta-analysis on interest stability, fewer than 8% of the studies analyzed captured interests after age 25, and none examined interests beyond age 40 (Low et al., 2005; see similarly Hoff et al., 2018).

Prior Findings on Interest Development

Consistent with their definition as trait-like preferences, individuals' interests show relatively high rank-order stability from adolescence to young and middle adulthood (ages 12-40; Low et al., 2005). This stability, however, does not preclude the possibility of change (Schwaba & Bleidorn, 2018): mean levels of even relatively stable constructs can and do change over time (e.g., the average person becomes more interested in Social activities across young adulthood, even as the relative ordering of Social interests remains relatively stable), and individuals within a sample can deviate from these mean-level trajectories even under conditions of relative stability (e.g., not every young adult becomes more interested in Social activities; Hoff et al., 2020; Holland, 1997).

Past research on adolescence and younger adulthood has found that age-graded developmental changes in interests are generally modest in magnitude. Meta-analytic results indicate that more people-oriented interests (Social, Artistic, Enterprising; see Prediger, 1982) tend to increase on average in young adulthood, with changes as large as a quarter of a standard deviation between the ages of 18 and 30 (Hoff et al., 2018). In contrast, average levels of things-oriented interests tend to either remain constant (Realistic) or decrease (Investigative, Conventional) during that age period, with cumulative changes ranging from 0 to -0.25 SD (Hoff et al., 2018). Individual studies diverge somewhat from these metaanalytic results. For instance, a study of Belgian college alumni documented decreases of ≈ -0.15 SD across a period of 22 years in most interest dimensions and suggested that these mean-level changes may be nonlinear over time (Nye et al., 2021). A study following engaged couples who were on average ≈ 25 years old at baseline and ≈ 40 at follow-up showed dimension-specific interest increases and decreases that partially differed for men and women (Schultz et al., 2017). Overall, prior research largely converges on relatively modest age-graded interest change during young adulthood.

Mechanisms Underlying Interest Development

Theories of development in vocational interests focus primarily on the underlying mechanisms and propose that these mechanisms reflect ongoing interactions between people and their environments (Holland, 1997; Lent et al., 1994; Wille & De Fruyt, 2019). Holland's (1997) seminal theory posits that an individual's interests affect the environments they select into, and these environments, in turn, reinforce or discourage certain preferences and behaviors over time. For example, a person with higher Social interests might choose to become a teacher, and working in an environment that values education might additionally deepen their interest in helping and supporting others. The Social Cognitive Career Theory (Lent et al., 1994) further specifies these transactional processes and posits that environmental influences on interests operate through social-cognitive experiences like perceiving the activities involved in an environment as achievable and desirable. Thus, consistent with a broader person-environment fit perspective, interest development is assumed to be driven by the interplay between a person's characteristics and those of their environment (Wille & De Fruyt, 2019).

Both major interest theories (Holland, 1997; Lent et al., 1994) converge on the assumption that these interest-environment transactions typically result in interest stability.

Because most adults tend to self-select into interest-congruent environments and avoid mismatching ones (Hanna & Rounds, 2020) and because these environments reward behaviors associated with existing interests, the transactions are assumed to stabilize individuals' interests over time rather than induce change (see also Nye et al., 2021; Wille & De Fruyt, 2019). Thus, as individuals select into and build environments that fit with their interests, the interests can be expected to remain at largely constant levels over time. From this perspective, the patterns of only modest mean-level changes observed in prior studies (e.g., Hoff et al., 2018) likely reflect these reinforcing interest-environment transactions, along with the fact that no single interest dimension is considered inherently more mature or adaptive for all people and in all environments.

At the same time, both interest theories (Holland, 1997; Lent et al., 1994) posit that under certain circumstances, interest-environment interactions can also induce interest change. If individuals engage in activities and environments that do not reflect their existing interests, they might be intrigued by these activities and develop interest in them over time (Holland, 1997; see also Hidi & Renninger, 2006; Su et al., 2019). Because people strive for fit between their interests and environments, they might gradually acquire the attributes that are desirable in a certain environment, even if that requires change (Wille & De Fruyt, 2019).

Social Cognitive Career Theory (Lent et al., 1994) posits that interest change requires persons to anticipate positive outcomes from the activities or consider them personally relevant, and suggests that the processes of interest change can repeat themselves at any time across the lifespan, as long as compelling experiences provoke the reappraisal of specific interests.

However, because of environmental barriers (e.g., relatively stable environments provide few opportunities to cultivate new interests) and learning contingencies (e.g., a person may not easily incorporate new information into their self-schema; see also Wrzus & Roberts, 2017), "such shifts are usually expected to be minor rather than major" (p. 17, Holland, 1985; see also Lent et al., 1994). Thus, interest-environment interactions are unlikely to produce dramatic changes in interests, unless there are dramatic shifts in environments.

Taken together, major interest theories converge on interest-environment transactions as a primary mechanism underlying interest development and suggest that even though the default outcome will be steady interest levels, changes remain possible, especially in response to major environmental shifts. Interest theory is less specific, however, about the concrete developmental patterns these transactions should produce across the lifespan, particularly in later adulthood. To address this gap, this study focuses on mean-level interest change. By informing whether normative developmental processes in later adulthood-across age and in relation to a major life transition in that life phase-lead to stable, increasing, or decreasing interest levels, evidence of mean-level change can extend and refine the theoretical understanding of interest development later in life.

Interest Development in Later Adulthood

Although the transactional mechanisms underlying interest development are assumed to operate "continuously over the lifespan" (Lent et al., 1994, p. 89; see also Holland, 1985, p. 52), interest theory does not articulate specific predictions about age-graded development in later adulthoodfoot_0 . To derive such expectations, interest theory must be integrated with lifespan theories that specify the conditions, environments, and motivational priorities of later adulthood (e.g., Atchley, 1989; Baltes, 1997; Riediger & Freund, 2006). Because these developmental conditions may affect how interests are expressed and reinforced, they likely influence the ways in which interest-environment transactions unfold later in life. Therefore, combining interest theory with these developmental frameworks allows us to derive more precise-and partially competing-predictions about how average interest levels may develop in later adulthood.

The selection, optimization, and compensation model of human development (Baltes, 1997) posits that the major developmental tasks of later adulthood center on the maintenance or compensation of functionality rather than exploration or personal growth (see Heckhausen et al., 1989). Accordingly, this life stage is typically characterized by largely consolidated identities (McAdams & Olson, 2010), relatively stable social roles (prior to eventual disengagement from work; Hutteman et al., 2014), and efforts to maintain continuity in internal and external structures (Atchley, 1989). Applied to interest-environment transactions, these features imply relatively fewer opportunities for exposure to novel activities that might provoke reappraisal of specific interests. Instead, individuals likely remain in previously selected environments that sustain their established preferences and the "the probability of change […] becomes smaller with age" (p. 17; Holland, 1985). Thus, pairing the principle of generally consolidating interest-environment transactions (Holland 1997; Lent et al., 1994) with the consistent environments and identities in older adults proposed by theories of human development (Atchley, 1989; Baltes, 1997), suggests that interest levels may remain largely constant throughout midlife and into older adulthood.

At the same time, the maintenance orientation in later adulthood also involves processes of motivational reorientation and selectivity (Hennecke & Fuths, 2024; Riediger & Freund, 2006). The goal development literature suggests that as older adults seek to maintain and compensate functionality, they tend to concentrate on pursuing fewer goals, often prioritizing the personally relevant ones (Freund, 2020 (Freund, , 2024)). Age-graded decreases in the importance of many life goals provide evidence for such motivational selectivity (Bühler et al., 2019; Riediger & Freund, 2006). Although this principle has primarily been studied in the context of goals, it may similarly apply to interests because they also capture motivational strivings that guide attention, behavior, and effort. Specifically, even within the interestcongruent environments that older adults are likely to have selected into, strenuous role demands (e.g., in the work, family, and health domains), finite time and energy resources, and shifts in goal content (Freund, 2024) may lead adults to focus on pursuing fewer interests over time. Thus, if processes of motivational selectivity also affect interests as motivational constructs, average interest levels are likely to decrease in later adulthood.

Taken together, evidence of mean-level changes can refine the theoretical assumptions underlying interest development: If interests indeed consolidate through ongoing interest-environment transactions in largely consistent environments (Atchley, 1989; Holland, 1997; Lent et al., 1994), interests in later adulthood would show largely flat agegraded trajectories. Conversely, if the developmental process of motivational selectivity also extends to interests (Riediger & Freund, 2006), mean levels should systematically decline with age. However, empirical research testing these assumptions is scarce. Because longitudinal research has focused on young adults transitioning into the workforce (Hoff et al., 2018; Low et al., 2005), a major gap exists for people whose interests have been shaped by decades of interest-environment transactions. In fact, we know of no longitudinal study on interest development in adults aged 50 and older. Even cross-sectional evidence is limited and inconsistent: One study showed that midlife and older adults have slightly lower interest scores than younger adults on average (Costa et al., 1984), while another study found that older participants had slightly higher interest scores (Morris, 2016). Therefore, to fill this empirical gap and inform the theoretical assumptions about interest development, our first research question asks: RQ1 -What are the age-graded patterns of mean-level interest development in later adulthood (ages 50-75)?

Interest Development During the Transition to Retirement

As described above, interest theories suggest that interests can develop in response to changes in individuals' environments (Holland, 1997; Lent et al., 1994). However, given the tendency toward stability, these environmental changes must be significant and provide compelling experiences to prompt individuals to reappraise their interests. In later adulthood, retirement is often positioned as the defining life event (Settersten, 2003), especially in the context of working life. Because it restructures the environments in which interests are realized, this transition adds explanatory power to accounts of interest development in later adulthood. Retirement disrupts the environments assumed to reinforce interests at work (Holland, 1997) and simultaneously creates opportunities for engaging in nonwork environments (Freund, 2020). This structural reconfiguration of daily roles and activities constitutes a context shift that may feed back onto interest levels (Venz & Wang, 2019; Wang & Shi, 2014). Prior evidence for such contextual influences on interest development exists for young adults. During the transition to college-when choosing environments that fit one's interests-all RIASEC interests showed normative increases of up to 0.30 SD (Stoll et al., 2021). Likewise, specific work environments predicted mean-level increases in corresponding interests (Nye et al., 2021; see also Hanna et al., 2021). If similar contextual influences also exist in retirement, the transition from work to leisure may affect interest development in older adults. Therefore, examining change in relation to retirement (i.e., structuring time in terms of distance-to-event, rather than in terms of age) informs the extent to which interest development later in life is context-dependent, which methodologically and theoretically complements the age-graded analyses. As with age-graded change, however, interest theory offers no clear predictions about the effects this context shift may have on interest levels. Instead, we believe that two theoretically plausible possibilities emerge, each implying different ways in which retirement may affect the interest-environment transactions that sustain or change interests over time.

According to Holland's broad conceptualization of interests, interest levels can be expected to remain largely stable during the transition to retirement, despite the context shift.

Although interests are typically assessed in terms of work-related activities, they can also be expressed outside of work (Holland, 1997; Roemer, Nye, Su, et al., 2026). Thus, after disengaging from work, retirees can continue to realize their interests through leisure, community, or family activities (Gaudron & Vautier, 2007). For instance, a retired engineer might still pursue Realistic interests by exploring activities that they did not have time for before, like remodeling vintage motorbikes or watching craftmanship documentaries (Su et al., 2019). This perspective aligns with retirement frameworks that emphasize the maintenance orientation of older adults: Continuity Theory (Atchley, 1989) proposes that individuals actively preserve familiar patterns of activity and identity during retirement, because such continuity reflects a functional strategy for adapting to aging. Drawing on established structures is assumed to conserve retirees' resources to adjust to the transition. Likewise, resource-based models of retirement (Venz & Wang, 2019; Wang & Shi, 2014) propose that successful retirement adjustment depends on individuals' resources that support goal pursuit and well-being, and that retirees seek to protect the resources threatened by the transition. Because interests direct retirees toward personally rewarding activities, interests might function as resources to structure post-retirement engagement, and are therefore likely to be retained across the transition (Venz & Wang, 2019). Together, these processes make major interest shifts in retirees unlikely. Thus, if interest development later in life builds not only on work-related transactions but also on interest-environment transactions in nonwork contexts and internalized self-concepts (Atchley, 1989; Holland, 1997; Venz & Wang, 2019), interest levels should remain largely constant across retirement.

At the same time, retirement structurally alters daily activities, and systematic changes in specific interest dimensions toward greater fit with the new environment remain theoretically plausible (Holland, 1997; Lent et al., 1994; Wille & De Fruyt, 2019). While the retirement context varies between people, it is on average more communal and leisureoriented compared to work life (Freund, 2020). Longitudinal data show that retirees increase their time spent volunteering (Hämäläinen et al., 2024) and in social or cultural activities (Henning et al., 2021), and cross-sectional data indicate that adults of retirement age engage more in artistic activities (Fluharty et al., 2021). This normative context shift seems to align with more people-oriented interests like Social and Artistic (Prediger, 1982) and might provide the compelling experiences that provoke the reappraisal of specific interests later in life (Lent et al., 1994). Thus, as retirees strive to fit with the new context, they may gradually develop the interests this new environment reinforces (Wille & De Fruyt, 2019). Therefore, mean-level increases in people-oriented interests during retirement would support the assumption that interests remain responsive to contextual influences even in later adulthood (Lent et al., 1994). To inform these possibilities and provide an event-based perspective on interest development in later life, our second research question asks: RQ2 -What are the mean-level developmental patterns of interests during the transition to retirement?

Gender and Fit as Moderators of Interest Development

Whether interest development is examined as age-graded or event-related change, the mean-level patterns characterize average patterns. However, individuals likely differ in their developmental trajectories (Haehner et al., 2026). In interest research, gender is a relevant variable for such differences. Gender differences in interest levels are well documented, with men scoring higher on Realistic and Investigative interests, and women scoring higher on Social, Artistic, and Conventional interests (|d| = 0.26 to 0.84; Su et al., 2009). Evidence of gender differences in interest change, however, is mixed. Gendered stereotypes are theorized to affect interest development in younger ages, but to be less relevant in adulthood (Gottfredson, 1981). Longitudinal evidence ranges from converging, parallel, to diverging trajectories for men and women during young adulthood (Hoff et al., 2018; Schultz et al., 2017; Stoll et al., 2021). Given this inconsistency and the lack of evidence in later life, we test gender as a potential moderator of age-graded and retirement-related interest change.

A second plausible source of individual differences in change is interest-environment fit. Holland's theory-and person-environment fit frameworks more broadly (Caplan, 1987; Schneider, 1987; Wille & De Fruyt, 2019)-propose that congruence between a person's interests and their occupational environments reward and reinforce a person's existing interests and encourage behavioral continuity. Accordingly, individuals working in jobs that fit their interests should show more constant-or potentially more positive-trajectories over time, whereas those in poor-fitting jobs may experience fewer opportunities that support their interests and thus show greater declines. Although evidence is surprisingly limited, available findings tend to support this notion, showing, for instance, that students with higher fit changed less in their interests over time (Ertl et al., 2023; see also Etzel & Nagy, 2021).

Importantly, fit may operate differently when individuals disengage from reinforcing environments, which matters during retirement. At retirement, individuals with a high preretirement fit leave environments that previously matched and supported their interests, and the post-retirement context may provide fewer opportunities that reinforce their interests in an equivalent way (Venz & Wang, 2019). Based on the same reinforcement logic, high pre-retirement fit may predict greater interest declines when leaving the workforce due to the removal of a well-matched environmental support. Thus, depending on the context, fit may have positive or negative effects on maintaining interests. We therefore examine interest fit as a moderator of age-graded and retirement-related interest development.

The Current Study

This study uses longitudinal data representative of the adult population in Germany, surveyed three times over a period of ten years, to examine interest development in later adulthood (ages 50-75). This age group is of growing demographic importance and yet largely ignored in interest research. Our first exploratory research question concerns the agegraded, normative patterns of interest development among older adults. Specifically, we examined whether interest levels show the largely flat mean-level trajectories that are implied by interest theories proposing consolidated interests in stable environments (Holland, 1997; Lent et al., 1994; see also Atchley, 1989; Baltes, 1997), or whether they show the declining trajectories that would be consistent with the assumption that motivational selectivity in later adulthood also affects interests (e.g., Freund, 2024; Riediger & Freund, 2006).

Our second exploratory research question focuses on the role of retirement as a potentially pivotal life event in later adulthood that may disrupt and modify individuals' interest trajectories. To isolate the event-related change and assess whether and how disengagement from work affects older adults' interest levels, we identified a subsample of retirees, which we compared to a propensity score-matched sample of non-retirees. We examined whether retirees' interest levels remain constant across the transition, as implied by the notion that interests can be expressed outside the work domain and retirees seek continuity (Atchley, 1989; Holland, 1997), or whether they develop in ways that are consistent with an adaptation to the more communal retirement context (e.g., Hämäläinen et al., 2024; Lent et al., 1994).

To further inform the literature on interest development in older adults, we examined gender and interest-job fit as theoretically plausible moderators of age-graded and retirement-related interest change (Gottfredson, 1981; Holland, 1997). Together, this study constitutes a first investigation of interest development in later adulthood and provides information critical for future testing and refining theoretical assumptions of interest stability and change across the adult lifespan.

Methods

Sample and Procedure

Because the current study uses secondary, de-identified data, the institutional review Participants were surveyed annually. We focused on data from the three waves with interest assessments, wave 4 (2011/12; henceforth referred to as T1), wave 7 (2014/15; T2), and wave 14 (2021/22; T3), spanning a period of 10 years. Data from the other waves were used to infer retirement status, employment, and covariates for propensity score matching.

Our baseline sample consisted of all participants who provided information on at least one interest item across the three waves (N = 12,299). We divided these data into three subsamples: a sample of older adults for the age-graded analyses, and samples of retirees and propensity-score matched non-retirees for the retirement-related analyses.

Age-Graded Development Sample

This sample included all participants who (1) were aged 50 or older in 2011 (at T1; n = 5,640) and (2) provided at least two measurement occasions of interest data (n = 2,036 were excluded because at least two observations are required to estimate within-person change), leading to a final age-graded development sample of n = 3,604. We chose a minimum age of 50 as the inclusion criterion because this age can be considered an inclusive lower bound of later adulthood (e.g., Infurna et al., 2020) and to ensure overlap with the samples of retirees and non-retirees, who were often younger than standard retirement age at T1. At baseline, the age-graded sample was on average M = 56.8 years old (SD = 4.9, range = 50-67); 50.0 % were female. The sample provided 8,455 interest assessments in total, with M = 2.3 assessments per person (SD = 0.5; range = 2-3). Importantly, while age was not an explicit inclusion criterion for the two event-related samples described next, nearly all retirees (98.3%) and non-retirees (98.6%) were also included in this age-graded sample, closely aligning the age-graded and event-related analyses.

Retiree Sample

The retiree sample included all participants who (1) reported receiving retirement pensions (i.e., statutory old-age pensions) or being in the passive phase of partial retirement 2 during at least one measurement occasion (n = 3,257), (2) reported the date of their retirement without conflicting information (n = 317 were excluded to ensure accurate timing in the models), (3) did not engage in any gainful employment after retirement (an additional n = 1,080 were excluded to ensure the discontinuity of the work context), and (4) provided interest data for 75 months both before and after retirement (an additional n = 1,436 were excluded to enable the estimation of within-person change), leading to a final retiree subsample of n = 424. We focused on the 75 months before and after retirement to ensure temporal proximity to retirement and enhance comparability with the other two samples, whose responses were spread out from 62 months before to 72 months after individuals' study midpoints (see also Table S3). Overall, these inclusion criteria largely align with those used in prior studies (e.g., Schimanski et al., 2025; Schwaba & Bleidorn, 2019). At T1 in 2011 (pre-retirement), retirees were M = 58.1 years old (SD = 3.5, range = 46-67), 47.0 % were female. Retirees provided a total of 927 interest assessments, with M = 2.2 per person (SD = 0.4; range = 2-3). Across retirees, the mean interest assessment occurred roughly half a year before retirement (M = -6.2 months, SD = 41.0).

Non-Retiree Comparison Sample

To generate a non-retiree comparison sample, we identified participants who (1) never reported receiving the relevant retirement pensions across all measurement occasions yet did report having ever worked or having a traineeship (n = 8,715), and (2) provided at least two measurement occasions for interests (n = 3,584 were excluded for this reason to allow for the estimation of within-person change). We used these n = 5,131 participants as a pool to create a propensity-score-matched comparison group of non-retirees. Specifically, we used 25 variables (see Table S1), including demographic, health, and the six interest variables to estimate the propensity to retire among retirees and non-retirees. The matching variables were selected to be a rich set of covariates potentially related to retirement and interest development (Thoemmes & Kim, 2011) and were similar to the covariates used in other studies of event-related change (e.g., Schwaba & Bleidorn, 2019). We used the R package MatchIt (Ho et al., 2011) and implemented nearest neighbor matching on this propensity using a 1:1 ratio, without setting a caliper to avoid unmatched retirees in order to retain statistical power. Thus, our final non-retiree sample included n = 424 participants who each matched in estimated propensity to retire with one of the n = 424 retirees, but who themselves did not retire during the study. At T1 in 2011, non-retirees were on average M = 54.6 years old (SD = 2.7, range = 44-67), 50.0 % were female. Non-retirees provided a total of 933 interest assessments, with M = 2.2 per person (SD = 0.4; range = 2-3). We present a comparison of retirees, non-retirees, and matched non-retirees on all matching variables in Table S1; non-retirees were slightly younger on average (by M = 3.45 years) but had nearidentical scores in each RIASEC interest domain and other the matching variables.

Measures

Interests

Interests were assessed using the Interest Inventory Life Span (IILS, Wohlkinger et al., 2019). The IILS measures the six RIASEC interests with three items each. Participants rated their interest in vocational activities on a 5-point scale (1 = I am very little interested in that; I do not like to do that at all;5 = I am very interested in that; I like to do that a lot).

Precise formulations are proprietary and cannot be shared, however, items refer to activities that are relatively broad and that can be answered without an active occupation. Sample activities are "build something using a plan" (Realistic), "observe and analyze something" (Investigative), "help sick people" (Social), "negotiate" (Enterprising), and "monitor rule compliance" (Conventional) (e.g., Wicht et al., 2022). We computed the six scale scores as unit-weighted means across the three respective items. Three-year retest reliabilities in the age-graded sample were r = .74 (Realistic), .61 (Investigative), .73 (Artistic), .63 (Social), .58 (Enterprising), and .53 (Conventional) (computed for all n = 3,000 who provided interest data at T1 and T2). To assess the structural validity of this measure, we used data from the agegraded sample at T1 to conduct randomization tests, which test whether the correlations between interest dimensions reflect the order implied by the RIASEC model's theoretical hexagonal structure (Hubert & Arabie, 1987). The resulting correspondence index-which ranges from -1 to 1-was .83, with p = .017 indicating that the probability that the observed hypothesized order occurred by chance was very low. This exceeds the meta-analytic estimate (.63; Tracey & Rounds, 1993) and suggests that current scores adhered to the assumed theoretical structure. To ensure that developmental changes do not erroneously reflect changes in scale functioning, we tested for longitudinal measurement invariance. Separately for each sample and interest dimension, we specified a longitudinal correlated factor model with one factor per timepoint. In these three-factor models (three timepoints), the three items at each timepoint loaded onto the corresponding factor. Residual correlations between the same items measured at different time points were estimated to account for item-specific stability (Newsom, 2015). We imposed increasingly stringent equality constraints across time to test for longitudinal invariance, testing models without equality constraints (configural model), against models constraining factor loadings to be equal across time (metric model), and then against models with additional equality constraints on the item intercepts (scalar model). To ensure comparability of interest means over time, each of these constraints must be imposed without substantial deterioration in model fit. As suggested by Chen (2007), invariance was rejected if ΔCFI < -.010 and ΔRMSEA > .015 or ΔSRMR > .030 for the metric invariance model. For the scalar invariance model, we used ΔCFI < -.010 and ΔRMSEA > .015 or ΔSRMR > .010 as the criteria.

As shown in Tables S2a-c, all models showed evidence for at least partial scalar invariance. In each sample, Realistic and Enterprising showed evidence for scalar invariance, while scalar invariance was rejected for Investigative, Artistic, Social, and Conventional interests. Instead, partial scalar invariance was established by allowing the item intercept for one item in each of these scales to vary across time. This evidence for (partial) scalar invariance suggests that the meaning of the scale scores did not change over time, and that observed mean level changes over time were unlikely to reflect artifactual differences in scale functioning (Leitgöb et al., 2023). Nevertheless, as described in the Sensitivity Analyses section below, we conducted additional analyses in which we re-estimated the models while excluding the nonequivalent item to test how these items affected the results.

Retirement Status

Germany has a public pension system that provides people with retirement pensions.

Pension benefits are based on the individuals' contribution history and can be drawn regularly once people reach statutory eligibility age, which is currently being gradually increased from 65 to 67 years. Early or late retirement is possible and involves actuarial deductions or supplements of the benefits. The public pension system covers about 85% of the German workforce. Even though additional income sources gain importance, pension receipts from the public system remain the most substantial income source during retirement (Börsch-Supan et al., 2023).

We operationalized retirement status by combining information on participants' pension receipt and employment status. From the fifth wave (2012/13) onwards, participants aged 55 and older were asked if they currently receive pension benefits, such as a retirement pension (i.e., statutory old-age pension), widower's pension, or disability pension. For the first recorded pension receipt, participants provided the month and year they entered retirement. We considered a person retired if they received old-age pensions or were in the passive phase of partial retirement (see also Footnote 2) and did not report any engagement in gainful employment after retirement (i.e., they did not re-enter the workforce).

Interest-Job Fit

To operationalize interest-job fit, we first identified what we considered participants' most relevant jobs. For the age-graded and non-retiree samples, this was the job participants held the longest during the study period in which interests were assessed; for retirees, it was their last job before retirement. Jobs were reported via ISCO-08-codes, which we then linked to the O*NET database. O*NET provides occupational interest profiles that indicate how descriptive each of the six RIASEC interests is for the given job (Putka et al., 2023). We operationalized interest-job fit via profile correlations between participants' interests at T1 and the occupational interest profiles of their jobs. This operationalization of fit considers the full interest profile, captures the similarity in profile shape, and has been shown to robustly reflect individual differences in fit (Granillo-Velasquez et al., 2025).

Data Analysis

For both research questions about age-graded and retirement-related interest development, we combined two complementary analytic approaches: For each, we first estimated (1) longitudinal multilevel models to parsimoniously describe mean-level trajectories and individual differences in change. Then, we estimated change using (2) datadriven generalized additive models (GAMs; Wood, 2017) that impose fewer assumptions about the timing and functional form of differences over time. As detailed below, we implemented this two-fold approach to minimize the dependence of the results on a singular methodology with its corresponding assumptions. Because the timepoints and intervals in our samples varied across participants, we analyzed the data using mixed models rather than structural equation models that require similarly-spaced assessment intervals across participants (e.g., McCormick et al., 2023). In the age-graded analyses, time was coded as age (in months and rescaled to years) and centered on age 60. In the event-related analyses, time was coded as time-in-study (in months and rescaled to years) and centered on individuals' month of retirement (for retirees) or on the midpoint of their observed study participation (for non-retirees). Table S3 shows the temporal distribution of interest assessments when coded as time-in-study and as time-as-age for the three samples. By studying time as age and as time-in-study/time-from-event, our results rest on the assumption that further temporal processes such as period effects are absent and do not unduly affect the current findings (e.g., Fosse & Winship, 2019; Roemer, Bonner et al., 2026).

First, to parsimoniously describe mean-level interest development, we estimated a series of longitudinal multilevel models using the R package nlme (Pinheiro et al., 2025). In these models, timepoints (see above for time coding) were nested in participants. Interests were regressed on time, such that the estimated trajectories reflect within-person differences in interestsfoot_3 . For the age-graded and non-retiree samples, we compared models with linear and quadratic slopes using likelihood-ratio tests to identify the functional form that best described interest development and selected more complex models if they significantly improved the fit to the data (p < .05). To allow for individual differences in interest trajectories, all models included random (person-varying) effects for the intercept and linear slopes. For retirees, we estimated piecewise models that included separate linear slopes for pre-and post-retirement periods, as well as an intercept shift at retirement (e.g., Doss et al., 2009; Schwaba & Bleidorn, 2019). Random effects were specified for the initial intercept, the intercept shift, and the post-retirement slopefoot_4 . As described in more detail in the results section, we used these (piecewise) multilevel models to investigate gender and interest-job fit as moderators of age-graded and event-related interest development.

While the (piecewise) multilevel models are commonly used and provide a relatively parsimonious way of examining mean-level trajectories and individual differences therein with straightforwardly interpretable parameters (e.g., Denissen et al., 2019; Schwaba & Bleidorn, 2019), they impose strong parametric assumptions about the functional form of change (linear or quadradic) and its timing (directly following retirement). However, the functional form might be more complex, and retirement-related changes may begin before or after the actual retirement transition. Therefore, our second, complementary analytic approach evaluated the accuracy of these assumptions. Specifically, we sought to capture potential non-linear developmental patterns while imposing fewer assumptions about the shape and timing of interest development. To that aim, we estimated generalized additive models (GAMs; Wood, 2017; see also Levelt et al., 2025) using the R package mgcv (Wood, 2025). GAMs flexibly estimate the overall shape of the change by fitting a data-driven smooth function rather than a predefined functional form. We specified the GAMs in the same way in each sample. Parameters included a fixed smooth function for time (see above for time coding) to flexibly model nonlinear change, along with random intercepts for individuals. GAMs were estimated using thin-plate spines with restricted maximum likelihood (Wood, 2017). The complexity of the smooth function (the "wiggliness") was optimized during model fitting, and, consistent with recent recommendations (Levelt et al., 2025), we set its upper limit to k = 20 for the age-graded sample to maintain computational efficiency and to k = number of unique timepoints -1 for retirees and non-retirees to facilitate model convergence. To identify periods of significant change, we examined the first derivative of the smooth function and identified intervals in which the 95% confidence intervals did not include zero (Levelt et al., 2025). These intervals thus indicate periods with statistically significant mean-level increases or decreases in interests. Thus, the GAMs complement the prior analyses by revealing forms of change that may not be approximated well by linear/quadratic or piecewise functions.

Both the multilevel models and the GAMs used all available time points from each participant. Missing data were therefore handled through the full (for multilevel models) or restricted (for GAMs) maximum-likelihood estimation underlying both approaches, which evaluate the likelihood over each participant's observed responses so that partially observed cases still contribute to estimates.

Nonlinear Patterns of Interest Development Across Retirement

As a sensitivity check on these retirement-related analyses, we next probed for potential nonlinear patterns. Supplementary Analyses of Interest Stability

Although this study focuses on mean-level patterns of interest development, we conducted exploratory analyses to examine rank-order stability as a complementary indicator.

To inform the age-graded development of interest stability, we compared 3-year rank-order stabilities across four age groups defined by their age at T1 (i.e., age 50-53; 54-57; 58-62; and 63-67). Supplementary Figure S4 shows that rank-order stability estimates were generally high (mean r = .68) and largely similar across the four age groups, with overlapping 95% confidence intervals in most cases. Exceptions occurred in isolated age groups for Investigative and Social interests. This pattern of relatively similar but less-than-unity stability across ages suggests that interests remained open to change throughout later adulthood. Moreover, rank-order stability generally varied across interests, with Artistic and Realistic interests showing higher estimates (mean r = .74) compared to the other interests (mean r = .63). Despite this relative stability, however, Artistic interests still showed significant mean-level declines with age, while Conventional interests showed hardly any mean-level change. These analyses show that mean-level change and rank-order stability estimates represent distinct aspects of development that are statistically independent of one another. Overall, results across both indicators suggest that ongoing interest-environment transactions do not necessarily lead to (increasingly) stable interests in older adults.

Discussion

This exploratory study provides the first longitudinal evidence of interest development in later adulthood (ages 50-75) that we are aware of. Based on three waves of population-representative data collected over ten years, we examined both age-graded interest trajectories and event-related change across the transition to retirement. The main findings are that, on average, participants' interests in four of the six dimensions declined substantially with age, with these changes ranging from d = -0.26 (Artistic) to -0.72 (Enterprising) SD between ages 50 and 75. Similar declines emerged for retirees and propensity-score matched non-retirees, but retirees tended to show relatively more positive trajectories in peopleoriented interests (Enterprising, and to a lesser extent, Artistic, Social) than the comparison sample, suggesting that retirement may buffer some of the observed interest declines. These conclusions were robust across both linear models and data-driven models that imposed fewer assumptions about the form and timing of change. By addressing a major empirical gap, these results refine conceptual assumptions about interest development in older adulthood and have practical implications for late-career planning and retirement counselling.

Age-Graded Interest Development in Later Adulthood

A central finding of our study is that while interest trajectories later in life differed across persons and interest dimensions, the average participant declined in most of their interests with age. People-oriented interests (Artistic, Social, Enterprising) decreased on average by up to three quarters of a standard deviation between the ages of 50 and 75.

Things-oriented interests either showed decreases (Investigative) that cumulated to a third of a standard deviation or did not change significantly with age (Realistic, Conventional).

These age-graded declines deviated from the flat interest trajectories that are predicted by interest theories that assume that environmental consistency fosters stable interest levels (Holland, 1997; Lent et al., 1994; see also Atchley, 1989; Baltes, 1997). Instead, they are consistent with the assumptions about increasing motivational selectivity in later adulthood ( Hennecke & Fuths, 2024; Riediger & Freund, 2006) and mirror prior findings that many life goals also decline with age (Atherton et al., 2021; Buchinger et al., 2022; Bühler et al., 2019; Sutu et al., 2024). Such average declines have been attributed to the multitude of demands in the work and family domains combined with finite personal resources, which lead adults to narrow their focus on their most crucial goals (Riediger & Freund, 2006). The present results suggest that such processes of motivational selectivity may extend to interests: As individuals age and resources become constrained, they might focus on their most relevant interests, such that on average, interest levels decline with age.

This interpretation would imply that the prospect of actively pursuing one's interests helps maintain them. In addition, goal content shifts with age, and career-related goals in particular tend to lose importance across adulthood (Buchinger et al., 2022; Bühler et al., 2019). Because the work domain is a central context for realizing interests-despite their broad conceptualization (Holland, 1997)-this reduced importance of career goals in later adulthood may likewise contribute to declining interest levels. Together, the goal literature suggests that motivational selectivity more broadly and the reduced focus on the work domain more specifically provide plausible mechanisms that affect interest development later in life (Hennecke & Fuths, 2024; Venz & Wang, 2019).

Note that the interest declines occurred during a life phase when people are assumed to have established niches that fit-and presumably maintain-their interests (Holland, 1997; see also Roberts & Nickel, 2017). However, the observed declines suggest that within these niches, people may not only lack experiences that trigger the development of new interests (Lent et al., 1994) but also may not encounter conditions sufficient to maintain existing interest levels on average. In other words, even if one has an interesting job or hobby, its appeal may fade over time. Perhaps, this is because the consolidation of niches, and repeatedly doing similar tasks and activities over time, comes at the cost of variety. Given that variety in tasks or activities predicts job satisfaction (Humphrey et al., 2007) and successful aging (Koffer et al., 2024), it may also have repercussions for maintaining interest levels in the long term.

It is interesting to note that decreases were stronger for people-oriented interestswith cumulated average changes of -0.51 SD for people-oriented interests compared to -0.06 SD for things-oriented interests. A similar differentiation between people-and things-oriented trajectories has been found in meta-analyses of young adult samples (Hoff et al., 2018), in which people-oriented interests increased with age while the trajectories of things-oriented interests were largely flat. Later adulthood seems to reverse these earlier increases in peopleoriented interests observed between the ages of 18 and 30. This suggests that interests in helping, influencing, and creatively expressing oneself to others change more across the lifespan than interests directed toward innate objects. A potential explanation might stem from the social investment principle (Roberts & Nickel, 2017), a hypothesis that the adaptation to social role demands is a major driver of developmental processes (see also Hoff et al., 2018). Because person-oriented interests seem more closely linked to social roles, they might respond more strongly to shifting role expectations across adulthood.

An alternative explanation for why only Conventional and Realistic interests displayed steady mean levels across ages is that these traits may be most strongly reinforced by the typical working environment of older adults. In our sample, most older adults worked in jobs best described by Conventional (30.8%) and Realistic interests (26.6%, see Table S7).

This could have stabilized the interest levels of these dimensions. However, the third-most common set of jobs (23.7%) were associated with Social interests, which showed substantial age-graded declines. Thus, differences in normative work environments can only partially account for the mean-level decreases in our data.

The major theoretical implication of these findings is that interest levels later in life are more malleable than typically assumed. The results suggest that ongoing interestenvironment transactions do not necessarily produce unchanging interest levels (cf. Holland, 1997; Lent et al., 1994). Instead, the age-graded declines observed in several interests suggest that additional processes, like motivational selectivity or shifting roles may also affect interest change. Thus, assuming interest maintenance and flat mean-level trajectories in later adulthood might not reflect the reality of this period of the life course. Rather, interest declines seem to represent the average developmental pattern. Accordingly, our study highlights the need for a more differentiated view of the processes underlying interest growth, maintenance, and decline and suggests that these processes may vary by life phase and interest dimension.

Retirement-Related Interest Development in Later Adulthood

Another unique contribution of our study is the direct examination of how a major life event-retirement-relates to interest development (cf. Schultz et al., 2017). By investigating trajectories in retirees and a propensity-score matched sample of non-retirees, we further contextualize the study of interest development in later life and provide evidence that the transition from work to retirement may modestly impact interest levels. Broadly, the pattern of interest declines observed in the age-graded sample also appeared among retirees and nonretirees. Notably, however, retirement seems to partially buffer these declines in Enterprising, and, to a lesser extent, Artistic and Social interests. That is, while interest levels declined in both groups, retirees' trajectories in these people-oriented interests were less negative. On the other hand, the trajectories of Realistic, Investigative, and Conventional interests did not differ between retirees and non-retirees.

Again, the results have implications that help to refine the understanding of the developmental mechanisms for interests. First, the similarities between the trajectories of retirees and non-retirees for several interests provide empirical support for the idea that interest development reflects not only work-related transactions but also nonwork transactions and consolidated self-concepts that older adults seek to retain (Atchley, 1989; Holland, 1997). As such, it challenges the view that direct reinforcement from vocational contexts is particularly-or exclusively-critical and that interests "might change after retirement in a way that those persons who are already retired 'might be expected to have lowered vocational interests in general'" (Venz & Wang, 2019 , p. 178, quoting Costa et al., 1984, p. 393).

Second, the relatively more positive trajectories among retirees in people-oriented interests suggest that interests can remain responsive to contextual influences even in older adulthood. We studied the transition to retirement as a broad context shift from work to leisure that might involve a bundle of environmental changes that likely differ across people.

While we can only speculate about which specific aspects of retirement relate to interest development, the disengagement from work roles, increased time to take up or intensify activities that were difficult to pursue while working, and normative tendencies toward more leisure-and communally-oriented ways of spending time (Hämäläinen et al., 2024; Henning et al., 2021) seem like plausible avenues for future research. Importantly, the observed adaptation of interests to retirement appeared to occur more through the maintenance of existing interests, rather than through their expansion or growth.

When interpreting these findings, it is important to consider the retirement context in Germany. Public retirement pensions constitute the most important income source in old age in Germany (Börsch-Supan et al., 2023) and our sample was restricted to individuals who did not engage in paid work after retirement. Therefore, many of the current participants may have experienced relatively high levels of economic security, maximizing opportunities to pursue their interests. In other contexts, financial or cultural constraints may limit opportunities to explore one's interests during retirement. For instance, for people who work or provide intergenerational care during retirement, their activities might differentially affect their interest trajectories. Future research should examine the cultural, economic, and individual boundary conditions of interest development during retirement.

Interest Development in the Context of Other Individual Differences

Interests exist in a nomological network with other individual differences such as the Big Five personality traits and life goals (Etzel et al., 2025; Mount et al., 2005; Roemer, Rammstedt, et al., 2024; Stoll et al., 2020). Situating our findings within the broader development literature reveals both similarities and differences with these constructs. On one side, the declines observed for many interests in later adulthood echo patterns for related constructs. During that age range, goals related to status, work, and personal growth decline by ≈ 0.25 to 0.70 SD (Bühler et al., 2019; see also Buchinger et al. 2022), and Openness, the Big Five trait most closely tied to interests (Mount et al., 2005), showed normative decreases of ≈ -0.50 SD (Bleidorn et al., 2022). Individual differences broadly related to striving and exploring thus appear to decline in similar ways in older adulthood. This convergence suggests that some developmental principles may generalize, at least partially, across construct domains (see also Roberts & Nickel, 2017). In fact, because interest theory is comparatively vague about developmental trajectories, prior research has drawn on principles established for related constructs-such as the social investment principle or the corresponsive principle (Roberts & Nickel, 2017)-to explain interest change (e.g., Hoff et al., 2018; Nye et al., 2021). These principles can help specify how interest-environment transactions play out under certain conditions and thereby shape interest development across the lifespan.

At the same time, our results also showed noteworthy discrepancies with other constructs. In particular, the retirement-related differences for interests contrast with evidence showing minimal retirement effects on Big Five traits. For example, a coordinated data analysis across six panel studies showed no retirement-related change in any Big Five trait (Haehner, Krämer et al., 2026). Similarly, while other studies have found changes at retirement of up to ≈ 0.15 SD in Openness and/or Neuroticism, the patterns of change did not differ substantially when compared to non-retirees (Schimanski et al., 2025; Schwaba & Bleidorn, 2019). This contrasts with the current results showing that retirees have more positive slopes than non-retirees (βs up to ≈ 0.10; indicating small effect sizes, e.g., Funder & Ozer, 2019). Although replication is needed before strong conclusions are drawn, the divergence supports the view that interests-as contextualized characteristic adaptationsmay be more sensitive to environmental influences than broad dispositional personality traits (Kandler et al., 2025; McAdams & Pals, 2006).

Together, these similarities and differences illustrate the value of studying interest development in personality psychology more broadly. Comparing how traits, goals, and interests develop across the same ages and life transitions can help to distinguish developmental principles that generalize across individual differences from those that depend on a construct's defining features.

Gender and Interest-Job Fit as Moderators of Interest Development

Our data further clarify potential moderators of interest development. Despite meaningful gender differences in interest levels (Su et al., 2009) and evidence for gendered trajectories in early adulthood (Hoff et al., 2018; Schultz et al., 2017), trajectories in late midlife and older adulthood were largely parallel for men and women. This suggests that the mechanisms driving interest change in older adulthood are gender-neutral (Gottfredson, 1981). Similar null effects for gender are common in other constructs such as the Big Five (Bleidorn et al., 2022) and life goals (Buchinger et al., 2022). Thus, theories of adult (interest) development should focus on domain-specific processes, rather than demographic subgroups, to explain stability or change.

In contrast, interest-job fit emerged as a more relevant moderator. The age-graded analyses showed somewhat mixed results, suggesting that fit was related to more positive trajectories for some interests but to more negative trajectories for others. These patterns only partly reflect the idea that well-fitting job environments reinforce individuals' interests (Holland, 1997; Wille & De Fruyt, 2019). Among retirees, however, a clearer set of results emerged: Those retiring from jobs that fit their interests showed steeper interest declines, whereas those leaving a poor fitting job had more positive trajectories. This suggests that leaving a well-fitting environment may remove important mechanisms that previously supported one's interests. Overall, the results support the assumed theoretical relevance of fit for interest development (Holland, 1997; Nye et al., 2021; Wille & De Fruyt, 2019), while highlighting that its developmental implications are complex and may depend on both the life context and the interest dimension.

Practical Implications

The present findings have practical implications for late-career development and retirement planning. The observed age-graded declines suggest that several interests lose salience in later adulthood. For example, during a pre-retirement period between ages 50 and 65, average declines in Enterprising and Social interests were as large as -0.52 SD. If replicated, these patterns highlight the need for proactive late-career counselling to sustain interest and support motivation among more mature workers. Organizations with primarily Enterprising and Social roles may especially profit from practices that focus on retaining older employees' interests.

The results also highlight the value of assessing interests later in life. If individuals' interests in many domains decrease with age, then the types of activities that they find appealing may change as well. Repeated assessments can support older adults' ongoing selection into activities they find interesting. This seems particularly useful for retirement planning, when insight into individuals' interest profiles can guide their choices of fulfilling post-retirement activities. Notably, people retiring from well-fitting jobs were more prone to interest declines and may therefore benefit the most from repeated interest assessments and retirement counselling. Building on the notion that pre-retirement fit may hinder retirement adaptation (Venz & Wang, 2019), identifying these individuals and supporting alternative interest outlets might ease their transition into retirement.

Limitations and Directions for Future Research

Despite the unique contributions of the current dataset-the only one we know of with repeated interest assessments in a representative sample of older adults-several limitations of these data and our study should be considered. First, with a maximum of three interest assessments per person, spread out over a ten-year period, the sparse measurement schedule restricted the way that interest trajectories could be modelled or explained. That is, we could not include random (i.e., person-varying) slopes for all fixed effects in the piecewise models estimated for retirees or random effects for the smooth terms in the nonlinear models. Future research should also explore denser longitudinal designs that allow examination of shorter-term fluctuations and longer-term consequences (Roemer et al., 2025), non-linearities, and individual differences in interest trajectories in greater detail.

Second, we used data from a single country. Although the data provided a representative sample of the population in Germany, it is possible that the results would vary in other settings with different social norms, retirement policies, or labor-market structures.

Likewise, these contextual conditions might also vary over historical time, and it should be considered that results might, at least partly, reflect cohort-specific characteristics of the current participants. Therefore, cross-cultural and cross-temporal research is needed to test the generalizability of the observed patterns.

Third, our study focused on mean-level trajectories and a targeted set of potential moderators. Although we had access to participants' job titles, more detailed information about their work and leisure environments was not available. Likewise, we could not specify the types of environments participants encountered during retirement or determine the average interest profiles of this new context. To further explain interest change later in life, future studies should incorporate richer data about adults' work and leisure environments, ideally combining subjective (e.g., perceived opportunities for interest expression) and objective (e.g., work or volunteering tasks) contextual information to further investigate the role of environmental influences, interest-fit, and moderators of interest change.

Fourth, although our analyses targeted age-and event-related change, the estimated trajectories may be conflated with additional factors. While the age-graded models used age as a within-person predictor, the trajectories could also reflect between-person age differences. Robustness analyses suggested that such between-person influences were minor (see Footnote 3), which supports the within-person interpretation. In contrast, the eventrelated analyses directly captured within-person change. Nevertheless, the interest trajectories identified in our models could still conflate age-/event-related change with period or retest effects (Roemer, Bonner, Rammstedt, et al., 2026; Seifert et al., 2024). Thus, our results rest on the assumption that such effects are absent and no period effects affected the identified change. Future research should conduct more formal age-period-cohort analyses (Fosse & Winship, 2019) and explicitly examine such alternative explanations for interest change over time.

Conclusion

The current study examined age-graded and retirement-related change to clarify how interests develop in later adulthood. Our findings address a major empirical gap in interest research. By indicating that mean interest levels later in life tend to decline, the results help to refine theories of interest development and suggest that interest maintenance should not be assumed as the default. Importantly, retirement appeared to partially buffer against these declines, which suggests that interests can be effectively sustained and developed outside the work domain and later in life. Together, this study demonstrates that interest development continues in later adulthood and points to the need for additional research on the conditions under which interests are maintained, increase, or decline. Reassessing interests later in life could thus provide a fuller picture of individuals' interests and their development and could help to support ongoing career planning and retirement counseling.

Acknowledging that definitions for the different life phases vary, we use the term "later adulthood" for brevity to refer to ages 50-75, encompassing both late midlife and young-old adulthood (e.g.,Hutteman et al., 2014;Infurna et al., 2020; Settersten, 2003).

This partial retirement scheme involves an active phase during which one still works but receives less salary, typically half, while the other half is saved as credit for the subsequent passive phase. Employers often supplement the salary paid out. In the passive phase, retirees no longer work but receive the credit from the previous phase as well as the pensions.

Note that by coding time as age in the age-graded sample, the estimated age-graded trajectories reflect both withinperson differences (aging over the study period) and between-person differences in age (participants entered the study at different ages and did not cover the full age range individually). To evaluate the robustness of this approach, we conducted supplementary analyses using fixed effects modeling, which extracts within-person information that is separated from between-person variation in the data (e.g.,Allison, 2005). The results were highly similar (see file 5_robustness_WP_AgeGraded_OSF.html on the OSF), indicating that the partial confounding of within-and between-person age variance in the age-graded analyses did not affect substantive conclusions.

With a maximum of three timepoints per person, the models could include up to three random effects. Model comparisons using the Bayesian Information Criterion indicated that random effects for the two intercepts and the post-retirement slopes generally fit best for all interests, with minor exceptions for Realistic and Conventional interests. Specifying a different set of random effects for these interests (intercept, pre-and post-retirement slope) did not change the conclusions.

Results remained very similar when constraining the age-graded and non-retiree samples to participants who remained in their job for the full study period, ruling out that potential job discontinuities affected these results.
