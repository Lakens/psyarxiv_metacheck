What we found

Show details

Meta-scientific research has shown nonsignificant p values are commonly misinterpreted. It is incorrect to infer that there is ‘no effect’, ‘no difference’, or that groups are ‘the same’ after p > 0.05.

It is possible that there is a true non-zero effect, but that the study did not detect it. Make sure your inference acknowledges that it is possible that there is a non-zero effect. It is correct to include the effect is ‘not significantly’ different, although this just restates that p > 0.05.

The Power Analysis Check module uses regular expressions to identify sentences that contain a statistical power analysis. How Exact P-Values works

List any p-values reported with insufficient precision (e.g., p < .05 or p = n.s.) or reported as exactly zero (e.g., p = .000).

This module uses regular expressions to identify p-values. It will flag any values reported as p > ? or p < numbers greater than .001. It will also flag p-values reported as exactly zero (e.g., p = .000, p = 0.00), which are mathematically impossible — p-values are never exactly zero and should instead be reported as p < .001.

A p-value that is not the result of a test is not flagged: a table note (“* p < .05, ** p < .01”), a figure legend (“Asterisks indicate significant differences (p < .05)”, “Values in bold are significant at p < .05”) or a stated threshold (“p < .05 was considered significant”, “thresholded at p < .001”). GROBID often puts such notes into the running text, so each p-value is judged by the words in its own clause (the text up to a “;” or a full stop), and never left out when a test statistic belongs to it (“F(1, 7) = 8.03, # p < .05”). The column not_a_test of the table says why a p-value was left out (“marker”, “threshold” or “legend”). Notes in other forms, such as a marker after the p-value (“p < .05 (*)“), are still flagged.

This module sometimes flags false positives when sentences discuss how p-value thresholds were set. It can also miss an imprecise p-value that is reported against a threshold (“decreased at the p < .05 significance threshold”).

This module only checks p-values reported in the running text of the manuscript. It cannot (yet) process p-values reported only in tables (as opposed to a table’s footnote text, which the module does see and tries to exclude — see above).

How Codebook Check works

This module checks whether the data columns in a repository are documented in a codebook or README. How Code Check works

This module retrieves information from repositories checked by repo_check about code files (R, Python, SAS, SPSS, Stata, Mplus, MATLAB).

The Code Check module checks R (also R Markdown and Quarto), Python (also Jupyter notebooks), SAS, SPSS, Stata, Mplus, and MATLAB files, using regular expressions to check the code; JASP files are listed but not read. The language of a Quarto document or a notebook is read from the file itself (its engine or kernel), not from its extension. The regular expression search will detect the number of comments, the lines at which libraries/imports are loaded, attempts to detect absolute paths to files, setwd() and install.packages() calls, and lists files that are loaded, and checks if these files are in the repository; R code is also parsed. How Reproducibility Check works

This module assesses whether a paper’s R and Python code can be run on its data. It works in two phases. The static phase (always run) collects the package dependencies the code declares, rewrites the data-file paths that do not work in the repository as the authors organised it, works out the order the scripts must run in, and diagnoses why any referenced input file is unavailable — reporting what a reproduction attempt would involve and where it is likely to break. The execution phase (opt-in, execute = TRUE) then actually runs the code: it copies the repository into a throwaway directory, optionally installs the declared dependencies into a throwaway library, runs each script in order in an isolated subprocess with a per-script timeout, and captures the outcome and full output of each run.

By default (execute = FALSE) the module does not run any code — it performs only static analysis: reading dependencies with the same extractors as code_check, finding the files the code references in the repository, and building a run-order dependency graph. It reports what would be installed and run rather than doing it.

When execute = TRUE, the module additionally runs the downloaded code on your machine — a deliberate, opt-in action gated behind that argument (callr is required for R code). Each script runs in an isolated subprocess so a crash cannot take down the R session; note this isolates crashes, not the filesystem or network. Installs (when install_missing = TRUE) and the throwaway run library never touch your main R library. Each script’s outcome is one of ran_ok, errored, timed_out, dependency_unavailable, not_parsed, run_by_source (an R script another script runs with source(), which is run only inside that script, since on its own it lacks the packages and objects the sourcing script sets up first), run_by_import (a Python file other files import, a module rather than a script, unless it has an if __name__ == "__main__": block), jags_model (a JAGS or BUGS model saved with an R extension, which another script reads) or not_r_content (a file that is not R at all, such as a JSON or HTML dump); these last two are not run and are not failures. python2 marks Python 2 code that was not run. With sandbox = "docker" such code runs with Python 2.7 (option metacheck.docker_image_py2; FALSE turns this off), which modifications records; it is never converted, since that can change results. defines_functions is a file that only defines functions, which is used, not run (table$used_by names the scripts that use it), and not_analysis is a file of software rather than of the analysis: a package’s code, tests, documentation or setup.py, a copy of a tool, a web application, a script a program wrote (table$not_analysis_why says which); neither is run or counted as a script. docker_failed means the container never started, which says nothing about the script, so it keeps the light from being green but does not make it red. needs_a_person is a script that stopped because it asks a person to choose a file or answer a question, or that starts an app, and needs_internet one that stopped because the network is off in a Docker run, or, with internet = TRUE, could not reach what it asked for; download_too_large is a script stopped for downloading more than the limits allow (see internet), and out_of_memory one that, or a program it started (such as a compiler), ran out of the memory each script may use. Abstract

Return of fear after exposure poses a significant challenge for treatment of anxiety disorders. In this study, we used computational modeling to test competing mechanisms underlying spontaneous recovery of fear over time. We fit computational models of a novel theory of spontaneous recovery-selective maintenance of aversive memoriesto behavior from a fear conditioning and extinction task (N=316), and showed that they uniquely captured spontaneous recovery and quantitatively outperformed alternative models embodying theories from the literature. The results were supported across multiple datasets, including a preregistered replication (N=355) and a sample with internalizing symptoms (N=520). The selective maintenance modeling framework additionally offers mechanistic insights into overgeneralization and the development of anxiety. Indeed, in the sample with internalizing symptoms we found that symptoms of generalized anxiety disorder correlated with estimates of overgeneralization in the model. Through simulations, we further demonstrated that insights from our model can explain how targeted interventions such as retrieval cues and cognitive interventions can prevent the return of fear. These results highlight selective maintenance of aversive events in memory as a critical and testable target for improving anxiety treatments and preventing relapse.

Introduction

Exposure-based interventions are among the most effective treatments for many anxieties (Ougrin, 2011). During exposure, an individual confronts a feared stimulus or situation without experiencing the expected negative outcome. A common assumption is that learning from this experience leads to decreased prediction of the negative outcome, and thus a reduction of fear. However, fear often returns after some time, and up to 62% of individuals relapse (Craske & Mystkowski, 2006). To develop clinical methods that prevent relapse, it is critical that we understand why fear returns.

Exposure has been studied extensively with well established fear conditioning and extinction paradigms. In such paradigms, in the acquisition phase, a neutral stimulus, often called a CS+ (for conditional stimulus), is paired with an aversive stimulus (US; unconditional stimulus), leading to fear responses when confronted with the CS+. In the subsequent extinction phase, mimicking exposure therapy, the CS+ is presented without the US. This procedure leads to a reduction in fear of the CS+. Strikingly, after the passage of time and even without new exposure to the CS+ or US, fear of the CS+ often returns. This phenomenon of 'spontaneous recovery' is well established across species and seems to be time-dependent (Rescorla, 2004; Quirk, 2002; Robbins, 1990; Haberlandt, Hamsher, & Kennedy, 1978).

Fear can only return if the 'fear memory' (i.e., a memory that associates the CS+ and the US) still exists in the brain after the extinction phase. Indeed, theories of return of fear usually contain the notion that acquisition events and extinction events give rise to separate associations, and thus to separate memories (Bouton, 1993; Gershman, Jones, Norman, Monfils, & Niv, 2013; Craske et al., 2008). These two memories are assumed to compete for retrieval during subsequent presentations of the CS+. At the end of extinction, the extinction memory is stronger, hence the reduction of apparent fear. For spontaneous recovery to occur, the strength of the fear memory must increase relative to the strength of the extinction memory. As such, while separation of the representations of dangerous and safe latent causes (contexts; memories) is a necessary prerequisite for explaining spontaneous recovery, it alone is not sufficient. We still need to explain the change in relative strengths of the two competing associations. Inspired by evidence of decay of memory but better memory for emotionally charged events over time (Dalgleish & Hitchcock, 2023; Rouhani, Niv, Frank, & Schwabe, 2023), and neural evidence that reactivation can prevent memory decay processes (Wimmer, Liu, McNamee, & Dolan, 2023), we propose that spontaneous recovery can be explained through a mechanism we term 'selective maintenance' -maintenance of memories that counteracts their decay, and is specific to memories of negative experiences. According to the selective maintenance idea, as memories of dangerous and safe experiences decay over time, dangerous memories are spared some of this decay, perhaps because they are reactivated periodically or due to other processes that are selective to dangerous memories. This slower decay rate of dangerous but not safe memories changes the balance such that over time, the acquisition memory becomes relatively stronger compared to the extinction memory, explaining why responses to the CS+ change accordingly.

Here, we aim to investigate whether selective maintenance can explain the detailed pattern of and individual differences in spontaneous recovery, and whether it can do so better than a set of alternative theories from the literature (see Rescorla (2004) for a review of the key theories, which we will model). Specifically, we will contrast selective maintenance with recency weighting (Devenport, 1998), neural processing fatigue (Pavlov, 1927), and increased salience of aversive events (see Suppl. Subsec. 2.3 for a discussion of other alternative mechanisms).

To compare these theories quantitatively and qualitatively, we first formulate the selective maintenance hypothesis as a computational model using the latent cause framework (Gershman, Blei, & Niv, 2010). We use this same latent-cause framework to model reduced variants without selective maintenance, as well as the alternative theories from the literature introduced above. We fit each model to empirical data that we collected from individual participants who completed a fear conditioning and extinction paradigm. We then compare the models quantitatively in terms of how well they predict the empirical data, and qualitatively in terms of their ability to generate spontaneous recovery after extinction as well as all other features of the behavioral data.

In our exploration dataset, we show that models incorporating selective maintenance provide the best quantitative and qualitative fit to the data. We replicate this pattern of results in preregistered analyses of an unseen dataset from the same study, as well as in data from a separate study with individuals with internalizing symptoms. Based on these modeling results, we therefore hypothesize that selective maintenance may be related to the emergence and maintenance of specific anxiety-related symptoms after aversive events, while a tendency to group disparate events in a single latent cause (i.e., overgeneralization) may be associated with symptoms of generalized anxiety disorder. We therefore test for associations between model parameters and anxiety symptoms in both our our sample from the general population and our sample with internalizing symptoms. Finally, we use the insights gained from our model to propose modifications to exposure therapy that target mechanisms driving spontaneous recovery so as to prevent the return of fear and illustrate the potential effects of such interventions through simulations.

In latent cause inference (Gershman et al., 2010), on each trial the participant infers whether the current observation results from an old (previously inferred) latent cause or a new latent cause. This inference, which is probabilistic (i.e., due to uncertainty about the structure of the task, a trial can be assigned in part to several latent causes), is influenced by at least three factors: 1) the strength of old latent causes, formalized as counts N of how many trials (or fractions of trials) had been inferred to come from each latent cause in the past (the stronger the latent cause, the more likely it will be inferred again), 2) the a priori probability of a new latent cause, formalized through a "concentration parameter" α (the larger α the more likely is a new latent cause), and 3) the participant's belief about the variability of observations that each latent cause generates, formalized here (for binary observations) as a beta function with one free parameter a obs . The smaller a obs , the more deterministic (0 or 1) are the probabilities associating the latent cause with each observation, and therefore a new latent cause is more likely to be inferred if a previously observed stimulus is omitted, or vice versa (see Fig. 4A-D for an example).

Inference in this basic latent cause model is not sensitive to time or order of events (Aldous, Ibragimov, Jacod, & Aldous, 1985), and therefore the model cannot account for time-dependent phenomena such as spontaneous recovery. To capture the notion that past events are less relevant for present inferences, we decayed the counts of past events by γ ∈ [0, 1] on each trial (Blei & Frazier, 2011). However, simulations show that this decay is not sufficient to explain spontaneous recovery of fear over time, as it does not change the relative strength of different latent causes over time. To address this, we modeled relative strengthening over time of latent causes that predict the US, perhaps because they are reactivated in memory. We termed this mechanism "selective maintenance" and formalized it as an increase of the decay parameter γ (leading to less decay) by a selective maintenance parameter ω in proportion to the probability that the latent cause is assumed to lead to an aversive US (Fig. 4E). To summarize, in our selective maintenance models, all latent causes decay, however, latent causes associated with aversive outcomes decay less due to the effect of selective maintenance. This leads over time to a relative strengthening of aversive latent causes as compared to other causes.

Finally, to allow for individual differences in selective maintenance (i.e., some participants may reactivate memories throughout the task while others may do so only during the break), we introduced C low , a low-salience parameter that decreases the counts of events with aversive outcomes when they occur (e.g., during acquisition). During the task, low salience of US events effectively counteracts selective maintenance (which increases the relative strength of latent causes associated with aversive outcomes). However, low salience has no effect during the break, when the effect of selective maintenance can fully unfold. Note that this mechanism was not crucial for explaining spontaneous recovery, but it allowed our model to better capture behavior from a larger variety of individuals. Thus, our final model had four free parameters: prior a obs , decay γ, selective maintenance ω, and low salience C low . We quantitatively compared this model to four reduced versions of itself to test whether each component of the model is necessary.

We also evaluated several models that formalized alternative theoretical accounts of spontaneous recovery from the literature. These included a "Salience Model" that used a salience parameter C for the count for each trial with a US (i.e., in this model a trial with a scream US counts as C trials), to capture the notion that aversive events might be more strongly encoded. We modeled Devenport's (1998) proposal that spontaneous recovery might arise over time due to recency weighting of events in a "Temporal Weighting Model" with a power-law decay of latent-cause counts. Finally, we formalized Pavlov's (1927) suggestion that repeated stimulus presentations reduce processing over time and thus lead to less learning during extinction in a "Processing Loss Model" where the count of each trial was reduced according to the number of times its CS had already been observed. Each of these three alternative models had free parameters governing the processes of interest (see Methods). Overall, this led to eight models, which we also compared to a "Basic α Model" with vanilla latent cause inference and only the concentration parameter as a free parameter. The winning model was reliably recoverable from simulated data when compared to non-nested alternative models (see Suppl. Subsec. 2.5.)

Parameter comparison between the SR and No SR groups

We formalized three independent hypotheses based on simulations of the Selective Maintenance Model. First, participants who show spontaneous recovery (SR group) should have more selective maintenance of aversive events (as this is what leads to the relative strengthening of the dangerous latent cause during breaks, and therefore to spontaneous recovery of the prediction of the scream). Second, participants whose predictions of screams return to start-of-experiment levels after the long break (Return to Start group) should show a higher rate of decay of events in memory (as this promotes the creation of new latent causes after the break, with their initial prediction levels). Third, participants who fail to distinguish between the CS+ and CS-stimuli during acquisition (Generalizers group) should have more stochastic priors (thus they tend to infer a single latent cause that accounts for observations of both types of stimuli). Due to smaller sample sizes in the Return to Start and Generalizers group, we were not necessarily powered to test the second and third hypotheses and treated these analyses as exploratory.

All parameters of the Selective Maintenance and Low Salience Model were reliably recoverable (r = .75 -.99, see Suppl. Subsec. 2.6), and Wilcoxon rank-sum tests supported all three hypotheses. First, estimates of the selective maintenance parameter ω were higher in the SR group than in the No SR group (median (IQR): SR group = 0.49 (0.23-0.73), No SR group = 0.28 (0.01-0.72); Z = 3.19, p = .001, r = .20). This was even more evident when reparameterizing ω ′ = (1-γ)•ω (1-γ)•ω+γ , which quantifies the proportion of memory of counts due to selective maintenance, which we call 'effective selective maintenance' (median (IQR): SR group = 0.04 (0.02-0.06), No SR group = 0.01 (0.00-0.03); Z = 5.32, p < .001, r = .33, Fig. 6A). Thus, we used effective selective maintenance ω ′ in later analyses. Second, the Return to Start group had significantly lower decay parameter γ estimates (indicating faster decay; median (IQR): 0.78 (0.66-0.80)) than the SR (median (IQR): 0.91 (0.88-0.94)) and No SR groups (median (IQR): 0.94 (0.90-0.97); Z = -7.04, p < .001, r = .48 and Z = -6.87, p < .001, r = .61 respectively; Fig. 6D). Finally, as shown in Fig. 6G, the prior parameter estimates confirmed that the Generalizers group had more stochastic priors (higher a obs ; median (IQR): 0.6 (0-5.99)) than each of the SR group (median (IQR): 1.18 × 10 -7 (3 × 10 -9 -2.1 × 10 -6 ); Z = 2.83, p = .005, r = .21) and the No SR group (median (IQR): 5.21 × 10 -7 (0-3.5 × 10 -5 ); Z = 2.74, p = .006, r = .27), and marginally significantly more than the Return to Start group (median (IQR): 5.16 × 10 -5 (0-0.11); Z = 1.84, p = .07, r = .26). Note, however, that comparisons with the Generalizers group must be interpreted with great caution due to the small size of that group (N = 13).

We found further support for our hypotheses when inspecting the patterns of inferred latent causes for participants in each group. For participants in the SR group, for the most part, a 'dangerous' latent cause strongly associated with the scream US gained relative strength in the break compared to other, 'safe' latent causes (e.g., those predicting the CS+ but not the US). This accounted for spontaneous recovery of US expectations in the test phase (illustrated in Fig. 2F). Conversely, for participants in the No SR group, both 'safe' and 'dangerous' latent causes decayed over time to same degree (Fig. 2G; see below for a comparison of the strength of the 'dangerous' latent cause between the SR and No SR groups). Furthermore, latent causes inferred for participants in the Return to Start group decayed sufficiently over the long break such as to lead to inference of new latent causes in the spontaneous recovery test (Fig. 2H). Finally, the model suggested that participants in the Generalizers group were more likely to infer only one latent cause in the acquisition phase, which generated all observed features throughout the task (Fig. 2I).

Confirmatory analyses

Selective maintenance models captured all behavioral features. As can be seen in Fig. 7A, only models that included selective maintenance were able to capture all features of the behavior, in particular, the amount of spontaneous recovery observed in the data (note that all models were fit to the whole sequence of data, without special weighting of the first spontaneous recovery test estimate). Indeed, the Selective Maintenance and Low Salience Model captured all behavioral features of each of the different subgroups (Fig. 2A-E; pink curves), as well as the difference in these behavioral features between the SR and No SR group (Fig. 3F-J).

To verify that the model accounted for all the differences in the behavior of the groups, we analyzed data simulated from the Selective Maintenance and Low Salience Model using the parameters fit to each of the participants in two groups. When comparing data simulated for the SR and No SR groups, Wilcoxon rank-sum tests showed higher predictions of negative outcomes for the CS+ in acquisition (Z = 3.05, p = .002, r = .19; Fig. 3F), a larger increase in predictions of negative outcome for the CS+ after the first break between acquisition and extinction (Z = 2.46, p = .01, r = .16; Fig. 3G), a larger decrease of predictions of the negative outcome for the CS+ during extinction (Z = 4.08, p < .001, r = .25; Fig. 3H), more differential spontaneous recovery (Z = 3.78, p < .001, r = .23; Fig. 3I), and a stronger increase of predictions of the negative outcome for the CS+ in the relearning phase in the SR group as compared to the No SR group (Z = 4.86, p < .001, r = .30; Fig. 3J). There were no differences in the simulated predictions of outcomes for each of the CSs in the first trial of the task, before observing any outcomes (p > .16 for all comparisons). Thus, the pattern of results from the simulated data matched the pattern of results from the empirical data. Medians and interquartile ranges for these comparisons are displayed in Suppl. Tab. 2.

Importantly, no model without selective maintenance captured the significant differences in differential spontaneous recovery between the two groups (p > .24 for all comparisons). Moreover, across participants in both SR and No SR groups, the amount of empirically measured differential spontaneous recovery correlated positively with differential spontaneous recovery in data simulated using the Selective Maintenance and Low Salience Model (ρ = .30, p < .001, Fig. 8A) and with estimates of effective selective maintenance ω ′ (ρ = .44, p < .001, Fig. 8B).

Spontaneous recovery was driven by the return of the dangerous latent cause. We hypothesized that spontaneous recovery occurs because the strength of the dangerous latent cause becomes higher increases relative to that of the safe latent cause associated with the CS+ during the break before the spontaneous recovery test. To examine this, we computed the change in relative strength of each of the two latent causes between the end of extinction and the beginning of the spontaneous recovery test and computed the difference in that change between the two latent causes (dangerous latent cause minus safe CS+ latent cause). In line with the assumption that this effect is driven by selective maintenance, effective selective maintenance estimates (ω ′ ) correlated with the difference in change in strength between the two latent causes across participants in the SR and No SR groups (ρ = .76, p < .001; Fig. 9A). Furthermore, in line with the assumption that these latent cause changes drive spontaneous recovery, this metric of latent cause change also correlated with empirical differential spontaneous recovery (ρ = .49, p < .001; Fig. 9B). Supporting our hypothesis further, the difference in change in strength between the two latent causes was larger in the SR group (median (IQR): 0.30 (0.04-0.64)) than the No SR group (median (IQR): 0.01 (-0.01-0.21); Z = 6.40, p < .001, r = .40; Fig. 9C). The larger difference in the SR group was driven by a stronger reduction in the strength of the 'safe' latent cause than in the 'dangerous' latent cause, leading to a relative increase in the strength of the "dangerous" latent cause, although both latent causes decay overall (Suppl. Fig. 5). This resulted also in a relative increase of the probability of the 'dangerous' and decrease in the 'safe' latent cause (Fig. 9D).

Results were not driven by differences in response styles. To verify that the differences in ratings between the SR and No SR groups were not driven by differences in participants' response style or usage of the expectancy rating scale, we compared the means and variances of participants' ratings of several probability questions and vignettes. Wilcoxon rank-sum tests did not indicate differences between the groups on any of these measures (p > .35 for all comparisons).

Associations between symptoms of anxiety and model parameters

Anxiety disorders are highly prevalent. While effective treatments such as exposure therapy exist, symptoms often return even after successful therapy, and anxiety relapses (Craske, Hermans, & Vansteenwegen, 2006). Our model can, at least in principle, explain why and when different anxiety disorders will develop and return. If the mechanisms quantified by our model are causally involved in the development, maintenance, and return of anxiety symptoms, and assuming we can measure these mechanisms with sufficient precision through our task and model parameters, these parameters should be able to predict the course of anxiety in individuals. A randomized controlled study design is needed to fully test such hypotheses. Here, as a first pass, we examined whether these mechanisms are associated with self-reported symptoms of anxiety. Our exploratory analysis was guided by two hypotheses: first, stochastic priors over observations (high a obs ) can lead to a spread of fear to many stimuli, and therefore this parameter may be associated with symptoms of generalized anxiety disorder (GAD). Since we had self-reported GAD symptoms in all our datasets, for these analyses we included all participants from each dataset. Second, selective maintenance of aversive events might strengthen the memory or imagination of aversive events and thus drive the development and maintenance of specific anxiety disorders (such as phobias). As selective maintenance could only be reliably estimated in the SR and No SR groups, we only included these subgroups when examining the association between the effective amount of selective maintenance and symptoms of specific anxiety disorders. In these analyses, we took a dimensional approach and examined associations of symptoms of different anxiety disorders with model parameters regardless of formal diagnosis status of a participant. This is in line with the HiTOP consortium's recommendations to adopt a dimensional conceptualization of psychopathology (Kotov et al., 2021) and with the view that crossing the threshold to receive an anxiety disorder diagnosis does not result from or imply different underlying mechanisms from those causing subthreshold symptoms (e.g., Haslam (2003)).

Improving interventions using model-driven mechanistic insight

Considering that extinction and spontaneous recovery are models of exposure therapy and relapse in anxiety disorders, we propose that the mechanistic insight gained from modeling such behavior can be used to improve interventions of exposure therapy. Specifically, the model suggests that intervening in any of its building blocksdeterministic priors, memory decay, or selective maintenance of aversive memoriescould help prevent spontaneous recovery.

Two interventions proposed in the literature have already been empirically shown to reduce the amount of return of fear. These are: spreading extinction trials (exposure sessions) over longer time intervals (Laborda, McConnell, & Miller, 2011) or tagging the 'safe' (exposure) memory with a retrieval cue such as a wristband that clients can then wear and use as cue to recall that memory (Craske, Treanor, Conway, Zbozinek, & Vervliet, 2014). Our model can explain why these interventions work. Specifically, it suggests that these interventions strengthen the safe memory and thus counteract selective maintenance of 'dangerous' memories. While the model predicts these interventions prevent dangerous memories from spontaneously resurfacing over time, the 'dangerous' memory may still resurface if it is triggered directly.

The model's predictions also give rise to two novel interventions to eliminate the effect of selective maintenance altogether (and thus prevent relapse). First, cognitive restructuring focusing on reducing "black-and-white thinking" prior to exposure therapy may change deterministic beliefs (i.e., increase α obs ) and help prevent inference of a new latent cause during exposure therapy (Smith et al., 2021). Second, selective maintenance of aversive memories might result from negative self schemas (Dalgleish & Hitchcock, 2023), which may bias sampling from memories towards aversive events. Schema therapy (Young, Klosko, & Weishaar, 2006) offers a host of interventions to reduce negative self-schemas, including cognitive, emotional and behavioral techniques. Addressing negative self-schemas prior to (or even after) exposure might also prevent later return of fear.

To test our prediction that interfering with any of the mechanisms involved in spontaneous recovery (possibly through the above mentioned interventions) can causally reduce spontaneous recovery, we simulated the influence of each mechanism in turn by changing parameter values in line with the hypothesized effect of the intervention, and generated new data from the modified model to examine whether this change would, in fact, reduce spontaneous recovery. Figure 11 shows such simulations for one example participant from our exploratory dataset, demonstrating that spontaneous recovery could be prevented by all four interventions. Supplementary Figure 6 further elucidates the mechanism underlying the simulated behavior by showing that fear does not return after using a retrieval cue or spacing extinction trials due to relative strengthening of the "safe" memory, while the mechanism underlying the simulated effect of schema therapy is weakening of the acquisition memory.

We would like to note that we outline here a set of hypotheses on how interventions may be improved, which can serve to inform new empirical studies. However, empirical support of several of these ideas is still lacking and we do not recommend their implementation during treatment prior to rigorous testing (but see Craske, Treanor, Zbozinek, and Vervliet (2022) for an overview on how to improve exposure therapy).

Exposure is a key ingredient of successful therapies for several anxiety-related disorders, such as PTSD (Parker, Waller, Duhne, & Dawson, 2018). Unfortunately, even after successful treatment, symptoms often return over time (Craske & Mystkowski, 2006). Here, we developed and tested a suite of computational models to understand why fear returns with time, and to quantify individual differences that can differentiate those who go on to show spontaneous recovery of fear from those who do not. By fitting different computational models to a large dataset, we showed that spontaneous recovery requires a process that strengthens aversive memories over time -leading us to propose selective maintenance of aversive (from here "dangerous") latent causes as a mechanism for spontaneous recovery. Models that included such selective maintenance provided the best quantitative fit to three datasets, and were the only models that qualitatively captured the differential spontaneous recovery seen in our behavioral fear conditioning task. Other proposed mechanisms, such as temporal weighting (Devenport, 1998), increased salience of aversive events, or loss of processing of stimuli with repeated exposure (Pavlov, 1927), could not capture differential spontaneous recovery in our dataset. There were significant individual differences in our empirical data, with some participants showing spontaneous recovery of fear, and some showing other patterns of responses. In additional analyses, we showed that the Selective Maintenance and Low Salience Model-the model that best explained participants who showed spontaneous recovery-could also account for the behavior of the other subgroups of participants, including participants who did not show spontaneous recovery of expectations of the scream US over time, participants who generalized across CS+ and CS-stimuli during acquisition, and participants who over time went back to predicting a scream US for both CS+ and CS-as they did at the start of the task. We replicated these results across our exploratory dataset, our preregistered replication in a dataset from the general population, and a dataset from a separate study focusing on participants with symptoms of depression. Supporting our suggestion that the mechanisms identified by our model are relevant for anxiety disorder, we showed through exploratory analyses that that a model parameter quantifying the degree to which participants tend to generalize across the CS+ and CS-in our task correlated with symptoms of generalized anxiety disorder in the latter dataset and that the extent to which participants maintained aversive memories more was associated with traumarelated symptoms. We further illustrated that the model makes a set of predictions on how we can improve exposure interventions to prevent the return of fear.

Generalization of our results to affective ratings

In our experiment, we elicited both explicit expectation of the scream US (which were analyzed in the results presented here), as well as affective ratings for each of the CSs. We saw a similar pattern of responses for affective ratings as we did for expectancy across all four groups. This included not only spontaneous recovery after extinction, but also significant differences in affective ratings between the SR and No SR groups throughout the phases of the task (Suppl. Fig. 2), similar to what we found for expectancies (Fig. 3). As such, we believe our findings are not limited to explicitly elicited expectancies, but also to emotional processes such as fear.

The degree to which this pattern of results also generalizes to physiological measures in our specific paradigms remains to be investigated. Prior work has shown that automatic fear responses such as the skin conductance response (SCR) often correlate with individuals' subjective reports of fear (Constantinou et al., 2021). However, accumulating evidence suggests that these measures also reflect partially distinct neural processes. For example, objective physiological responses are primarily linked to activity within defensive survival circuits involving the amygdala and insula, whereas the conscious experience of fear is thought to rely more on higher-order cortical processes (Taschereau-Dumouchel, Kawato, & Lau, 2020). For the purposes of the present study, subjective ratings provided a particularly informative index as in extinction learning, US-expectancy ratings have been shown to predict post-extinction negative affect, a clinically relevant outcome associated with the return of fear, while SCR measures do not show this relationship (Constantinou et al., 2021). Given that a major goal of our research is to improve psychological interventions as measured by clinically relevant changes in fear-related cognitions and experiences, these findings support the use of explicit measures.

Clinical implications

A major burden of anxiety disorders comes from relapses and recurrences of symptoms even after remission (Batelaan et al., 2017; van Dis et al., 2020). Given our findings, we propose selective maintenance of aversive experiences in memory as a novel mechanism that might contribute to this phenomenon. To our knowledge, current psychological interventions do not explicitly or purposefully target this mechanism. Importantly, a mechanistic understanding of why fear might return with time allows us to derive interventions that can prevent this return. In particular, we proposed several methods that can mitigate the return of fear, each targeting one of the necessary components of spontaneous recovery of fear in our model: cognitive restructuring, using retrieval cues, spacing extinction/exposure sessions and schema therapy. Simulations of the hypothesized intervention effects confirmed a reduction of spontaneous recovery (at least in the model). Our next step is to test these predictions in a clinical trial. As such, our work might lay the foundation for psychological interventions derived from computational principles. In a recent perspective paper (Berwian, Hitchock, Pisupati, Schoen, & Niv, 2025), we provided an introduction to this approach, along with examples, for a broader audience that includes clinicians.

Mechanistic insights from the model explain phenomena of anxiety Next, we discuss how our hypothesised mechanism of selective maintenance of aversive events, which results in a relative strengthening of dangerous memories or context inferences compared to safe ones, may explain a range of phenomena related to anxiety, including overgeneralisation, the development of anxiety, and intolerance of uncertainty.

Overgeneralization in anxiety.

A commonly observed phenomenon in individuals with anxiety disorders is overgeneralization (Cooper et al., 2022), i.e., generalization of learned expectations from a few negative experiences to many (new) situations and contexts. Based on our computational framework, we propose that there are at least two possibly distinct types of overgeneralization. The first type involves a failure to distinguish between stimuli. This resembles the behavior observed in the Generalizers group, resulting from the inference of mainly a single latent cause that accounts for different observations. In a previous experiment in which we tested generalization of US predictions to (previously unseen) stimuli spanning the perceptual range between the CS+ and the CS-(Aitsahalia, 2022), we indeed showed that the behavior of participants from the Generalizers group in the generalization test closely resembles the pattern of 'overgeneralization' proposed by Cooper et al. (2022).

Inferring a single latent cause for distinct stimuli could lead to fear of many situations and stimuli also associated with that same latent cause. (In principle, this type of overgeneralization does not need to be biased to negative experience, but could be in case of increased salience of aversive events.) Interestingly, behavior resulting from the inference of a single latent cause (due to stochastic priors in the Generalizers group) aligns with the main criterion of generalized anxiety disorder according to the DSM-5: "Excessive anxiety and worry (apprehensive expectation), occurring more days than not for at least 6 months, about a number of events or activities" (emphasis ours). In line with the model's prediction that stochastic priors can drive generalized anxiety symptoms, in our sample with internalizing symptoms we found that participants who were fit with more stochastic priors tended to have more symptoms of generalized anxiety disorder.

We note that for people showing this type of generalization, extinction is expected to occur slowly but should eventually be successful. Although this extinction is likely to be resistant to the return of fear, its gradual pace may be misinterpreted as a lack of response to exposure therapy, thereby resulting in its premature termination. Our model predicts that exposure therapy will show its effects faster when latent causes are more distinctly separated. Thus, to facilitate separation, interventions can promote attention to differences between stimuli or situations, such as is done in interpersonal discrimination exercises (McCullough, Schramm, & Penberthy, 2014).

A second alternative type of overgeneralization that is specific to negative events can simply result from selective maintenance of such events. Selective maintenance would make the latent causes (memories) that involve aversive events stronger with time, such that they carry more weight when an individual is confronted with an even remotely similar situation. That is, due to the strength of the latent cause, it will be a priori likely to be inferred in many different situations.

The development of anxiety. In line with suggestions in the literature (e.g., Gagne, Dayan, & Bishop, 2018), selective maintenance of aversive experiences in memory can explain the development of anxiety disorders (including post traumatic stress disorder) after an exceptionally aversive event due to increased reactivation of the memory of the aversive ("dangerous") event. With time, the aversive memory overshadows "safe" memories of similar situations without aversive outcomes, even if the safe events had occurred more frequently than the dangerous event. Avoidance behavior further facilitates the memory imbalance in favor of the "dangerous" memory, as it prevents new non-aversive experiences that would strengthen the "safe" memory. As such, a vicious cycle of reactivation and avoidance can lead to the development of an anxiety disorder or post-traumatic stress disorder. This prediction aligns with our exploratory finding that symptoms of traumatic reactions were correlated with larger estimates of the effect of selective maintenance in our undifferentiated sample. Note, however, that this result needs to be interpreted with caution and further tested, ideally with a more symptomatic sample.

Intolerance of uncertainty in anxiety. Difficulties in tolerating uncertainty have recently been proposed as a theory of anxiety. Brown, Price, and Dombrovski (2023) reviewed a series of studies suggesting that deficits in dealing with uncertainty are more prevalent in anxiety than are exaggerated fear of aversive events. This aligns with the effect of selective maintenance of aversive memories, which can provide a causal explanation for how aberrant behavior in the face of uncertainty comes about in individuals with anxiety. The idea is that uncertainty about the occurrence of aversive outcomes will have led to forming both a "safe" and a "dangerous" latent cause. Selective maintenance then increases the relative strength of the "dangerous" latent cause, leading to higher estimates of aversive outcomes in such situations, similar to the overestimation of the probability of a scream in acquisition that we saw in the SR group. In contrast, in situations with certain aversive outcomes, selective maintenance would have no effect and would not predict different behavior for individuals with anxiety.

Limitations and potential extensions of our study

Alternative models. The potential model space and combination of mechanisms is, of course, endless. For clarity and comprehensibility, we reported here a set of models that represent either key distinct hypotheses from the literature or our own hypotheses that we considered biologically and psychologically plausible. In the Suppl. Subsec. 2.3, we provide an overview of further alternative modeling frameworks (reinforcement learning), theories (temporal context and response fatigue) and other versions of our own models and describe why they fail to account for our data. These alternative models were either unable to generate differential spontaneous recovery or they did not capture the empirical data better than the Selective Maintenance and Low Salience Model. Nevertheless, we cannot exclude that other formalizations or interpretations of these or other alternative mechanisms can account for spontaneous recovery of fear. For example, our current formalization and data cannot differentiate between selective maintenance of aversive events and faster decay rates of inhibitory associations as proposed by Paskewitz, Stoddard, and Jones (2022). Indeed, it is likely that different mechanisms are at play in different individuals and that the observed behavior results from a combination of mechanisms.

We note that our conclusions are also limited by the (relatively) small amount of data we had in two aspects: First, we had few data points (ratings) per participant and used only one data type (expectancy ratings). Because we used principles of parsimony that seek to identify the simplest model that explains the data (i.e., we penalized models for their free parameters; Wilson & Collins, 2019), we may have missed more complex processes (e.g., additional temporal organizations of context) that would only become visible when additional data, for instance from direct measurements of memory, are also assessed. Second, we had only one trial per participant to measure spontaneous recovery. This not only makes it challenging to estimate spontaneous recovery reliably, but also poses a challenge for model comparison because the single trial can only provide limited support for models that specifically capture spontaneous recovery. In this respect, the fact that models with selective maintenance won when penalized for extra parameters shows that this process was important not only for spontaneous recovery, but rather had signatures throughout the learning process.

Improving measurement accuracy. While our findings were robust and replicated across datasets, most effect sizes were small to medium. Additionally, model fits at the individual level revealed that our model did not fully capture the extent of spontaneous recovery in all participants. This may be due to different mechanisms underlying spontaneous recovery across individuals, as previously discussed. Alternatively, the variability could result from noise in the data or limitations in the fitting procedure, which may not always recover optimal parameter estimates given the stochastic nature of the model. Increasing the number of trials and applying hierarchical modeling approaches could improve the robustness of parameter estimation, thereby enhancing the precision of measuring these mechanisms in individuals. On a different note, Lonsdorf and Merz (2017) suggest that new advanced statistical approaches are needed to capture individual response trajectories and advance individual-difference research on fear conditioning. Our model captures entire trajectories of CS+ and CS-responses across four different phases and many individual trials with only 3-4 parameters (while avoiding noisy difference of differences scores), and, therefore, we hope it will be a useful tool for this type of research as well as for further mental health investigations.

Alternative task design. While our pre-registered replication and additional replication in a symptomatic sample give confidence that our model was not overfit to a specific dataset, the model could nevertheless be too specific to our task design and thus not generalize to other versions of this paradigm. For instance, the amount of spontaneous recovery in our paradigm could be triggered by the specific sequence of reinforced and non-reinforced trials, which was identical across participants. Reassuringly, we previously observed similar patterns of behavior in other versions of the task with different numbers and sequences of trials in acquisition and extinction. We specifically note that most fear conditioning paradigms test for spontaneous recovery after 24h or longer (Lonsdorf et al., 2017), to allow for memory consolidation prior to the test, which we did not do here. However, in several pilot studies and in a separate full experiment (N=441), we did test for spontaneous recovery in a separate session ˜24h after the acquisition and extinction session. In all these experiments, we found a similar pattern of behavior across all subgroups (data not shown as the full study is still in progress). Interestingly, and in line with the predictions of our selective maintenance model, with the longer delay before the spontaneous recovery test, we observed more differential spontaneous recovery in the SR group (which is predicted because the longer interval provides more time for the effect of selective maintenance to unfold). Furthermore, a greater proportion of participants showed behavior consistent with a "Return to Start" in the spontaneous recovery test, i.e., 50% expectation of a scream for both CS+ and CS-. This is predicted by our model due to more decay of existing memories over the long delay time, which leads to inference of new latent causes at test.

Formally, our model accounted for this phenomenon in the data from the Return to Start group either through the formation of new latent causes for the CS+ and the CSin the spontaneous recovery test, or through a return of the "dangerous" latent cause for the CS+ and the formation of a new latent cause for the CS-. Data from the present paradigm cannot tease these different latent cause inferences apart. Similarly, data from participants in the Generalizers group may not contain sufficient information to reliably estimate decay, selective maintenance and low salience parameters, as changes in the strength of different latent causes have no visible impact on behavior when only one latent cause is inferred. Thus, participants from these two groups were not included in analyses of the selective maintenance parameter.

Interpreting associations between parameter estimates and symptoms of anxiety. As mentioned above, and in line with our hypotheses that stochastic priors might underlie overgeneralisation in anxiety and that selective maintenance could drive the development of anxiety after aversive experiences, we found small positive correlations between the prior over observations and symptoms of generalised anxiety, as well as between selective maintenance and symptoms of traumatic reactions. As we carefully followed proposed procedures to avoid spurious correlations between task measures and symptoms, such as screening out inattentive responders in self-report and task measures (Zorowitz & Niv, 2023), and employed robust statistical approaches to prevent the influence of outliers, we likely avoided false positives. However, we would like to note that these were exploratory analyses and the effects we found are small and need to be interpreted with caution. Furthermore, for each study, we analysed the anxiety measures collected alongside the task data. However, depending on the goals of each study, those studies did not necessarily broadly assess anxiety and other psychopathology dimensions. The association between effective selective maintenance estimates (ω ′ ) and traumatic reaction symptoms survived after controlling for many other anxiety symptom scales, including generalised anxiety symptoms. This provides support for our hypothesis that selective maintenance is relevant for the development and maintenance of anxiety, and is specific to anxiety that is related to experiencing aversive events. However, because in the sample with internalizing symptoms we examined only bivariate associations between generalised anxiety symptoms (GAD7) and parameter estimates of the prior (a obs ), we cannot determine whether these results are specific to generalised anxiety symptoms.

While our two-stage modeling approach aligns with common practice and recommendations in the literature (Friston, Stephan, Lund, Morcom, & Kiebel, 2005) and is more computationally feasible than more sophisticated hierarchical methods, we may have missed relationships that the latter may have detected. Future work could, for example, follow the proposed HiTOP methods of deriving latent factors underlying psychopathology using the full HiTOP structure measure (Simms et al., 2022). These factors could then be related to parameter estimates to increase sensitivity to detecting relationships between model parameters and symptomology (Cooper, Perkins, Webler, Dunsmoor, & Krueger, 2024) and to assess whether model parameters are related to anxiety symptoms specifically or to internalizing symptoms more broadly (Watson, Levin-Aspenson, et al., 2022). This analytic method could be further improved by a joint model that simultaneously estimates parameters at the subject level and their association with psychopathology.

Extension to other return-of-fear phenomena. Two other return-of-fear phenomena are often observed after fear conditioning and extinction. These include the return of fear when returning to the acquisition context (if acquisition and extinction occurred in different contexts) or when switching to a completely new context ('renewal'), and after re-exposure to the US alone ('reinstatement'). Both phenomena have been proposed to result from the reactivation of the acquisition context (e.g., Bouton (1993)). Future research can empirically test predictions from context theories and the selective maintenance hypothesis to see which observed phenomena can be better explained either by context theories or by the selective maintenance hypothesis, or by a combination of both.

Conclusion

We propose selective maintenance of aversive memories as a key mechanism underlying spontaneous recovery of fear after extinction. Models incorporating this process explained the behavioral data across multiple datasets, outperforming alternative theories. These models also provided mechanistic insights into overgeneralization and the development of anxiety. These insights were empirically supported by correlations between parameter estimates quantifying the proposed mechanisms and symptoms of anxiety.

These results may have clinical implications: targeting mechanisms supporting selective maintenance, for example through cognitive interventions or spaced extinction, may help reduce the risk of relapse after successful treatment. While further research is needed to test these clinical predictions and the model's neural basis, selective maintenance of aversive memories offers a unified, testable account of the development, persistence and return of anxiety, and how the influence of selective maintenance might be effectively modified. upon request. Method Procedure and participants -Study 1

This study was approved by the Institutional Review Board of Princeton University (Protocol 11968), and all participants provided written informed consent. Participants were recruited from Prolific to complete a series of studies including online behavioral tasks and mental health questionnaires in spring 2023. All participants were compensated for their time at a rate of $13/hr. To qualify for the study, participants had to reside in the United States, Canada, Australia, or New Zealand, be fluent in English, and have headphones. We first report the analyses of the first half of that dataset with N = 376 participants, which were labeled an 'exploration dataset.' (Later, we will report replication of our findings in the second half of the dataset.) From the exploration dataset, 23 participants were excluded due to incomplete datasets and 37 participants were excluded due to failing more than two audio attention checks. The final dataset contained N = 316 participants. Information on the distribution of self-reported sex in this sample is presented in Suppl. Tab 1.

Behavioral Task

We designed an online-administered aversive conditioning and extinction task (Fig. 1). On each trial, participants saw a face-down card that then "flipped over" to reveal one of two stimuli: a moon with three stars (CS+) or three candles (CS-). Participants then had to press the space bar to reveal the trial's outcome, described in the instructions as "the sound associated with that stimulus". On some CS+ trials, this was an aversive but tolerable auditory scream (US; see below), and for all other trials there was no outcome. The task was completely Pavlovian; key pressing allowed reaction-time measurements and ensured continued attention to CSs, but did not otherwise affect the occurrence of the US.

The sequence of a trial was as follows: a card appeared face-down for 500 ms and then flipped over (this animation lasted 100 ms). An event listener was then activated and the participant had 6000 ms to press the space bar before the trial timed out. If the participant failed to respond in time, a warning message was displayed for 3000 ms, after which the trial was repeated. If the space bar was pressed and the stimulus had an associated sound, a delay of between 300-800 ms occurred before the audio was played. This jitter was randomly generated on each trial and was introduced to prevent participants from precisely anticipating the timing of the outcome. After the space bar was pressed, the card flipped back over and flew off the screen to indicate the end of the trial (this animation lasted 500 ms, regardless of whether a sound was played). We used three aversive audio clips across trials. They were edited to be of similar volume and duration (2000 ms).

Every three trials, on average, participants were asked to rate how likely they expected each of the two CSs would be followed by a scream on a scale of 0-100% using two horizontal slider bars. The sliders were initialized in a random location and each had to be moved to continue to the next trial. Participants completed 31 ratings for each CS. Within these, two sets of ratings that followed previous ratings without new trials or significant passage of time since the previous rating were excluded from analyses, leaving 29 ratings per CS per participant. One rating was always completed before each phase. In addition, about every 8-10 trials, participants rated their feeling when viewing each of the stimuli on a horizontal slider bar ranging from calm to alert ("affective ratings" hereafter).

The task consisted of 4 phases. In the acquisition phase (26 trials), 50% of 16 CS+ trials were followed by a US (total: 8 screams), and the CS-appeared on 10 trials. This phase was followed by a 3-5 minute break in which participants completed a filler questionnaire of no interest (the 20-item short form International Personality Item Pool-Five-Factor Model measure; Donnellan, Oswald, Baird, & Lucas, 2006). The extinction phase included 30 trials, 18 CS+, 12 CS-, with no US. Next, participants completed a separate task (a risky decision making task in which they made choices between a sure 5-point reward and a stimulus with an unknown but learnable chance of giving 10 points or 0 points; not analyzed here) for ∼15 minutes. This was followed by a spontaneous recovery test (16 trials, 10 CS+ and 6 CS-; no US), and then a relearning phase (10 CS+ with 4 USs; 6 CS-). All participants saw the same sequence of CSs and USs and were asked to provide ratings between the same trials (see Suppl. Sub. 1.1 for the order of trials and other technical details). We note that participants intentionally first encountered the CS+ stimulus without reinforcement in the acquisition phase. We chose this design to mimic the fact that in real life encounters with aversive outcomes often follow similar stimuli in non-aversive contexts, and to ensure the latent cause associated with the CS+ but no aversive outcome (often labeled the "inhibitory memory" in the literature) is inferred first and there is no "primacy advantage" to the aversive latent cause that could account for its spontaneous recovery over time. As participants were tested online and from remotely, to ensure they heard the US loudly enough and did not reduce the volume throughout the task, participants completed a set of volume calibration steps and six auditory attention checks were spread throughout the task (see Suppl. Subsec. 1.1). Including the two breaks, the task took approximately 50 min.

We used a partial reinforcement rate (50%) in line with other fear conditioning paradigms (as reviewed for example by Lonsdorf et al. (2017)) and to make our experimental setting more naturalistic, since it is unlikely that people who develop anxietyrelated disorders experienced a 100% rate of aversive experiences. Partial reinforcement also reduces working memory effects that can masquerade as learning (Collins & Frank, 2012) and introduces uncertainty about outcomes, which might be important for anxiety disorders (Brown et al., 2023).

Self-report measures Anxiety questionnaires

In two separate online sessions, participants completed the GAD7 questionnaire (prior to completing the task; Spitzer, Kroenke, Williams, and Löwe (2006); Löwe et al. (2008)), several subscales of the HiTOP questionnaire (several weeks after completing the task; Watson, Forbes, et al. (2022)), as well as other symptom self-report questionnaires not analyzed here. GAD7 is among the most commonly used self-report questionnaires for anxiety and recommended or required by many funding agencies to allow comparing or pooling of data from different studies. It primarily captures symptoms of generalized anxiety disorder with 7 questions rated on a scale from 0-3.

Hierarchical Taxonomy of Psychopathology (HiTOP) measures aim at assessing psychopathology with a dimensional approach (Kotov et al., 2021). As we were interested in many specific anxieties, for the analyses reported here, we examined data from the following HiTOP subscales: social anxiety subscale (15 items), the agoraphobia subscale (6 items), animal phobia (6 items), situational phobia (6 items), traumatic reactions subscale (8 items), depression/anxiety (15), compulsivity (15), situational phobia (5), blood-injection phobia (3), panic (6) and separation insecurity (6), as well as GAD7. These items were selected based on the recommendations of the HiTOP consortium based on preliminary testing (Watson, Forbes, et al., 2022) and to maximize content overlap with several standard anxiety scales. See Suppl. Subsec. 1.2 for further information and a list of items for each subscale. Participants were invited to complete the HiTOP questions up to several weeks after completing the task. However, we note that participants were instructed to indicate for each statement "Have there been significant times during the last 12 months in which the following statements applied to you?" which also covered the period of completing the task. Responses were recorded on the following scale: (0) Not at all, (1) A little, (2) Moderately, (3) A lot.

Response style assessments

To verify that behavioral differences in the task were not driven by different usage of the expectancy rating scale (i.e., differences in people's response style), we added two types of response style measures. First, we created five anchoring vignettes, in which we described the number of neutral and aversive stimuli observed by another person and asked participants to indicate how that person should rate the expectancy of negative outcomes (Hopkins & King, 2010). Second, we asked participants to rate the likelihood of four events such as "How likely is it that the sun will rise tomorrow?". The scenarios were chosen such that no expert knowledge was required or would influence the rating, and such that ratings would represent participants' responding across the range of probabilities. One goal was to test whether some participants did not use the whole scale even for expectations of "never" or "always". For both measures, we computed the mean and variance of each participant's ratings. All questions are available in Suppl. Subsec. 1.4.

Data categorization

In our pilot data, we observed that most participants showed distinct patterns of behavioral features that suggested they could be categorized into different groups. In parallel, simulations with our model prior to fitting it to any data also indicated that these behavioral features can arise from different mechanistic functions. To provide statistical evidence for the hypotheses emerging from simulations, we therefore decided on the below criteria to separate individuals into four subgroups a priori and included the same criteria in our preregistration of the replication dataset.

Specifically, we categorized participants into four subgroups: N = 13 participants who showed similar expectations for the CS+ and CS-at the end of acquisition (< 10 points difference on a scale from 0 to 100%) were categorized into the 'Generalizers' group. The remaining participants were then categorized into groups based on their behavior on the spontaneous recovery test, in particular, their first rating of expectation of a scream for both the CS+ and the CS-, which occurred immediately at the beginning of the spontaneous recovery test phase before any other exposure to the stimuli or screams or audio instructions. N = 175 participants who increased their expectation of the US by more than 10 points compared to the end of extinction for the CS+ but not for the CS-were categorized into the 'spontaneous recovery' ('SR') group-a group that includes participants who show differential spontaneous recovery, i.e., an increase in their CS+ rating without a substantial increase in their CS-rating in the spontaneous recovery test. N = 88 participants whose expectations for both stimuli increased by at most 10 points were categorized into the 'No SR' group (we used a change in expectation of 10 points as a cutoff for distinguishing between No SR and SR to account for random response noise), and N = 37 participants whose expectations increased by more than 10 points for both stimuli were categorized into the 'Return to Start' group. N = 3 participants who did not meet any of these criteria were not included in subgroup analyses.

Model-agnostic analyses

Most of our analyses focused on the SR and No SR groups, as differences between these groups were of main interest to understand the mechanism of spontaneous recovery, and these were also the largest groups, which allowed us to identify robust group differences. First, in a set of model-agnostic analyses, we tested whether the SR and No SR groups showed different behavioral features throughout the task (beyond the differences in the SR test phase, by which these groups were defined) by comparing 1) their a priori expectations of negative outcomes for the CS+ and CS-(i.e., their first expectancy ratings); 2) their acquisition learning, measured as the mean differential ratings for the CS+ minus CS-in the remaining ratings from the acquisition phase; 3) the effect of the first (short) break, by comparing the change in expectancy ratings for the CS+ minus CS-in the first rating after the break minus the last rating before the break; 4) the extent to which expectations of the US decreased during the extinction phase in each group, measured as the difference between the first and last ratings for the CS+ minus the CS-in the extinction phase; 5) their differential spontaneous recovery, by comparing the change in CS+ minus CS-ratings between the end of extinction and the beginning of the spontaneous recovery test; and 6) their rate of reacquisiton, by comparing the change in CS+ minus CS-ratings from the last rating of the spontaneous recovery test phase to the last rating of the relearning phase.

We repeated these analyses for the affective ratings with the exception of the effect of the first short break as we did not measure affective ratings immediately after that break. For a similar reason, we also used the affective rating after acquisition rather than the first rating of extinction to measure the effect of extinction (number 4 above).

Generative models

Next, we formalized learning of the latent structure of the task using Bayesian nonparametric models of latent cause inference (Gershman et al., 2015; Gershman & Blei, 2012). In the latent cause framework, observations (here, trials) are attributed to one of an unlimited number of latent causes L t ∈ [1, ..., j], each with its own unique set of parameters Φ j = {φ j,i } that determine probabilities of observing each of i ∈ [1 : 4] features. We set i=1 to indicate the CS-, i=2 the CS+, i=3 a 'break stimulus' (to model the time between acquisition and extinction and between extinction and spontaneous recovery test) and i=4 to indicate the US. Thus, in our models, each latent cause embodies a different association-different probabilities of observing the CSs and US.

(Note that there is some non-zero probability of a new latent cause on every trial, hence the number of previous latent causes on trial t + 1 is t. Also, while in some models Σ t m=1 N m,t = t, this is not the case in all our models below, hence we spell out the sum explicitly in the denominator.)

Prior over observations

Conditional on latent cause j having been drawn for trial t + 1, the generative model assumes that observations O t+1 are generated by independent Bernoulli processes with probability φ j,i for each feature i generated by latent cause j, p(O i,t+1 |L t+1 = j) = φ j,i (t + 1). When a new latent cause j is initialized, initial probabilities φ j,i are drawn from Beta priors with two parameters a obs > 0 and b obs > 0. Given that pilot data from the task showed that absent any data, participants' prior expections of a US before the start of the experiment are ∼ 50%, we assumed symmetric Beta priors (a obs = b obs ) whose mean is always 50%. Values of a obs > 1 imply initial φ j,i that are unimodal around 0.5, with higher a obs being more stochastic (that is, more tightly concentrated around φ j,i = 0.5; Fig. 4A), while smaller a obs result in bimodal φ j,i that are more deterministic (i.e., closer to 0 or 1; Fig. 4C). After every observation, φ j,i (t) are updated according to observed events weighted by the probability that the events were generated by latent cause j (see eq. 9 below).

Inference simulations

For each model, to infer a distribution over latent causes given observations, we approximated Bayesian latent cause inference using particle filtering (sequential importance resampling of 1000 particles; Speekenbrink, 2016). Each time participants were asked to make an expectation rating, the algorithm first inferred the posterior probability over possible partitions of trials into latent causes based on all previous observations plus a current observation of either the CS+ or the CS-and used this inference to generate a prediction of the probability of the US: p(O 4,t = 1|O 1:3,1:t , O 4,1:t-1 , Θ, M) = Σp(O 4,t = 1|L 1:t ) • p(L 1:t |O 1:3,1:t , O 4,1:t-1 , Θ, M) where the sum was over all possible latent cause assignments approximated by averaging across the 1000 particles.

This probability was used to compute the likelihoods of the participant's rating. No updating occured based on these inferences. After observing all stimuli in a trial (CSs and USs), the posterior distribution over latent causes was calculated taking all previous observations into account. This was then used to update the observation probabilities for each latent cause φ j,i . Throughout, the model observed the same stimuli as the participants. To simulate breaks, we presented the model with a dummy stimulus O 3 , simulating a short break between acquisition and extinction as 9 trials of O 3 and the long break between extinction and the spontaneous recovery test phase as 34 trials of O 3 . These numbers of trials were chosen as the approximate number of task trials that would have occurred in the breaks in the experiment, as per the average time it took participants to complete the task trials and the break activities.

Model comparison

To identify the winning model, we first computed AIC values for all subjects for all models. We then subtracted the AIC value of each model from the AIC value of the numerically winning model on a subject-by-subject level. If the distribution of these differences was significantly below 0, this indicated that the numerically winning model indeed explained the data better. If the distribution was significantly above 0, this indicated that the other model explained the data better. Because the distribution of AIC differences can be non-normal and/or skewed, we used bootstrapping to test whether it was significantly different from 0. Specifically, for each distribution, bootstrap resampling was performed by drawing with replacement samples of size n (equal to the number of participants) from the distribution. This procedure was repeated 10,000 times. For each bootstrap sample, we then computed the mean as well as a trimmed mean (the mean of the distribution less the upper and lower 2.5% of values (i.e., a 5% total trim), which provides a measure robust to outliers). Percentile confidence intervals (95%) for each statistic (mean and trimmed mean) were estimated using the percentile method, defined as the 2.5th and 97.5th percentiles of the corresponding bootstrap distributions. 95% confidence intervals that do not include 0 correspond to a significant result in a two-sided test, therefore, we considered AIC differences where the 95% confidence interval for the bootstrapped samples did not include 0 to indicate the differences were significantly different from zero. To compute a two-sided bootstrapped p-value that corresponds to the confidence intervals, we counted how many bootstrapped values were on the other side of the null-value (i.e., 0) than the bootstrapped mean and multiplied that count by 2 to mimic a 2-sided test.

Statistical analyses

As parameter estimates and data ratings were bounded, they could not follow a normal distribution. Hence, we used non-parametric significance tests for comparisons between subgroups. For all these tests, we report rank-biserial correlation r as effect size.

As several of our variables were zero-inflated or not normally distributed, we applied Spearman correlations in additional confirmatory analyses to reduce the influence of outliers.

Confirmatory analyses

We repeated the model-free analyses of the expectancy ratings (described above) on the simulated data from the winning model. We added response noise to the simulated data by replacing each simulated data point with a data point drawn from a normal distribution with the data point as µ and the empirically computed σ. Ratings below 0 and above 1 were assigned to be 0 or 1, respectively.

1.1.1 Audio setup and checks

We took a set of measures to ensure that remote participants listened to the aversive screams throughout the task and experienced them as unpleasant but not intolerable. Prior to acquisition, participants were instructed to put on headphones. They had to correctly complete an audio test where they heard a word and had to indicate what the word was, and the side (left or right) in which they heard it. The goal of the latter question was to ensure use of headphones. Next, to ensure the scream was not too loud, participants listened to a softly spoken audio clip and were instructed to turn down their volume if they could hear the speech clearly. The clip was calibrated to be quiet, so that if the participant could just barely hear it, the subsequent aversive screams would be loud enough to be effective, but not unbearably loud. This was followed by 6 practice trials with a different CS (a circle) and an emotionally-neutral sound. Finally, participants were presented with an audio clip of one of the aversive screams and were instructed that they could adjust the volume one last time to ensure that the sound was unpleasant, but not intolerable.

To ensure that participants did not lower the volume during the task, six auditory attention checks were embedded throughout. During each of these checks, participants saw a fixation cross on the screen and simultaneously heard a soft-spoken verbal instruction (e.g., "Press the letter F now."). The speech was intentionally quiet; designed to be inaudible if the participant had turned the volume down too far. While the fixation cross remained on screen, participants were expected to press the specified key in response. If no correct response was given, the task automatically continued after 10 seconds.

At the start of the second part of the study (the spontaneous recovery test phase) participants returned from a break during which they completed a different task. Before beginning the test phase, they were asked to rate their expectation of hearing a scream in response to each image. Following this, they were presented with the scream audio clip once more and instructed to readjust the volume, if necessary, so that it was unpleasant but not intolerable.

2.3.1 Reinforcement learning models

The most known and commonly applied model to explain conditioning phenomena is Rescorla and Wagner (1972). The Rescorla-Wagner model can be seen as a special case of the temporal difference algorithm in reinforcement learning without taking future outcomes into account. (Note that in our design, each trial involves at most one outcome so this is an accurate simplification.) According to the Rescorla-Wagner model, one learns the strength of the association between the CS and the US according to is the strength of the association between CS j and the US at the start of trial t (the value of the state defined by the CS j in reinforcement learning), η is the learning rate and r(t) is the outcome (US, in which case r(t) = 1 or no US, hence r(t) = 0) on trial t.

This model tracks average or expected US.

We fit such a model (as well as such a model with two learning rates, one for reinforced and one for non-reinforced trials) to our data. It captured the relearning phase well, and the main features of the acquisition and extinction phase. However, it (predictably) failed to capture spontaneous recovery. The reason that this standard model is incapable of capturing spontaneous recovery is that reinforced and non-reinforced observations of the CS+ both update the same V CS+ . Thus, these two types of events cannot be dissociated or have separate effects at a later time point. Put simply, no memory of aversive events or states can come back as this information is not stored anywhere separately.

We also tested a somewhat related model with a decay rule (Erev & Roth, 1998), which tracks cumulative outcomes according to V j (t + 1) = V j (t) * γ + r(t). A model with the decay learning rule (and especially a version of it that additionally scaled r(t) by the salience parameter C) captured acquisition and extinction very well, but completely failed to capture spontaneous recovery and relearning. Similar to the above delta rule model, the decay rule model fails to capture spontaneous recovery because it does not contain a mechanisms that stores information about aversive and non-aversive events separately.

In both models the 'states' that one learns about are predefined, here by the two CSs. The extension that the latent cause framework offers is that allows to infer which states (called latent causes, or causes for shorthand) a participant learns about. For example, some participants might infer that the moon and the candles belong to the same state, as they have the same color and a similar purpose, e.g., providing light in the dark. We observed these participants in our dataset and termed them the Generalizers. Other participants might infer one state per CS (as is assumed for all participants by standard reinforcement learning models). Their behavior would be similar to the No SR group (and is well predicted by the Rescorla-Wagner model). Note, however, that behavior of participants in the SR (which was the largest group in our sample comprising over half of the participants) was best explained by models inferring three states, one for the CS-, one for the CS+ in non-reinforced trials (that is, without a US) and one for the CS+ and the US. This indicates that it is important to not predefine the number of states participants can learn about but assess how many states they likely inferred and learned about.

2.3.2 Temporal context models

The prevailing theory explaining spontaneous recovery suggests that individuals infer different contexts during acquisition and extinction. During a spontaneous recovery test-or simply at a later time in life-it may be unclear which context is currently active. This ambiguity can lead to a prediction of aversive outcomes based on an average of the acquisition and extinction phases, or alternatively, the acquisition context may be retrieved, for instance, due to a visual cue indicating that an individual currently is in the acquisition context. In the former case, one would expect a modest level of spontaneous recovery, while in the latter, a more substantial amount of spontaneous recovery would be observed.

To ensure that context cues cannot account for spontaneous recovery in our dataset, we designed our experiment to tightly control for context cues. We ensured that no visual or auditory stimuli differentiated the task phases, making it unlikely that contextual inference could explain the observed spontaneous recovery. However, we still observed substantial amounts of spontaneous recovery.

How could spontaneous recovery be explained through context inference in the absence of any context cues? Bouton (1993 Bouton ( , 2004) ) proposed that temporal context may still play a role. Similar to visual cues, other contextual elements -such as bodily states, room temperature, or ambient lighting -might support the inference of different temporal contexts, even if these variables were not explicitly manipulated or assessed. As reviewed by DuBrow, Rouhani, Niv, and Norman (2017), neural evidence further suggests that we encode mental context that slowly drifts over time, possibly to bind events that occur in close temporal proximity together in memory. DuBrow et al. (2017) also proposed that mental context can shift abruptly due to surprising events (or boundaries) such that different mental contexts can be encoded separately to reduce interference in memory.

There are many ways to formalize the concept of temporal context, and we acknowledge that it is impossible to rule out every possible implementation. Nevertheless, we attempted to formalize temporal context inference by implementing a hierarchical inference model. This model not only infers latent causes but also allows for the inference of distinct temporal contexts (see Pisupati, Berwian, Chiu, Ren, & Niv, 2023). In this model, temporal contexts can contain several latent causes. However, the occurrence of dissimilar or previously unseen combinations of latent causes can prompt the inference of a new temporal context-akin to how new latent causes are inferred from dissimilar observations (and in line with shifts in mental context). We incorporated persistence into the model to formalize the assumption that contexts tend to remain stable over time. This also incorporates the idea that "invisible" cues like lighting, temperature, or bodily states change slowly and are more stable within a task phase than across phases.

For a mathematical formalization of the model, see Pisupati et al. (2023). We fit this hierarchical temporal context model, along with reduced variants of itself and a version that included a salience parameter C (increasing counts of reinforced events as in the Salience Model), to data from our exploratory dataset (Study 1). None of the models were able to simulate the amount of spontaneous recovery observed in our data given constraints of the overall data (such as unbiased priors over observations). Furthermore, none of the models captured the average magnitude of spontaneous recovery when fit to the data or provided better fits across the complete task. The main reason why these and related models failed to capture spontaneous recovery is because they can, on average, only predict spontaneous recovery up to the average of probability given all observations or the weighted average of the acquisition and extinction context, which in our task is p(US|CS+) = .235 at the beginning of the spontaneous recovery test. Indeed, this is exactly what the Temporal Weighting Model (see Fig. 7 in the main paper) and other models predicted. However, in our empirical data , the prediction of a US given the CS+ clearly exceeded .235 (see Fig. 2 and 7 and in the main text).

These results suggest that, at least in the form tested here, temporal contexts do not provide a sufficient explanation for the amount of spontaneous recovery observed in our data. Importantly, we do not claim that temporal contexts do not exist. Rather, without any additional mechanisms at play, they appear to be neither sufficient nor necessary to account for the behavioral effects observed during the spontaneous recovery test.

2.3.3 Response fatigue

Early experiments measuring spontaneous recovery were often conducted in animals. Fear responses were usually measured in terms of freezing (or flight) responses. Such responses are more effortful than no response. Hence, one plausible explanation brought forward for this behavior was response fatigue, which became more prevalent during extinction (see (Rescorla, 2004) for a review). Thus, no true extinction takes place: the lack of fear responses only appears as a result of response fatigue. However, once that fatigue has passed, fear responses re-occur, which could look like the return of fear with time, i.e., spontaneous recovery. However, response fatigue is not able to account for spontaneous recovery in our paradigm as responses of aversive outcome predictions or negative affect on the rating scales required the same amount of effort for all responses (i.e., independent of its valence or probability of a negative outcome).

2.3.4 Alternative model formalizations

In an attempt to reduce the probability that we missed alternative explanations for spontaneous recovery, we also tested models with additional free parameters (such as a free b obs which allows for biased starting priors), different priors over observations for features (CSs) and outcomes (US), additional combinations of free parameters such as the temporal weighting and salience or selective maintenance, and longer time intervals (e.g., double the number of break stimuli) in the Temporal Weighting, the Decay and the Salience Model. Furthermore, we tested a model that included no decay but rather strengthening of latent causes that predict the US (i.e., the "excitatory association" in theories of extinction), and a model that included only decay of latent causes that do not predict the US (i.e., the "inhibitory association" in theories of extinction). All these models either did not capture spontaneous recovery together with the entire dataset well or did not capture it to the same extent as models with selective maintenance.

We also tested alternative implementations of the Selective Maintenance and Low Salience Model, e.g., independent decay parameters for aversive and non-aversive latent causes and a model that only allowed selective maintenance during the break, or an additional free parameter that influenced the extent to which selective maintenance was applied during task phases in addition to the break. However, the Selective Maintenance and Low Salience Model was the best constraint and identifiable model given our dataset.

2.4 Modeling choices

Our goal was to find the best model that explains spontaneous recovery given the entire data without biasing our results to one specific model with our modeling choices while achieving parameter and model identifiability. Below, we briefly explain why we made a set of modeling choices and how we verified that they did not bias our results.

2.4.1 Fixed concentration parameter

We fixed the concentration parameter α to 0.03 for all models except the Basic Concentration Model. This decision was based on the fact that both α and the prior over observations a obs influence the number of latent causes that are generated, leading to potential parameter identifiability issues. Since the Basic Prior Model fit the data better than the Basic Concentration Model (see Fig. 5 in the main text), and a obs offers a more direct psychological interpretation, we opted to fix α rather than fit both parameters simultaneously, especially as doing so did not capture any additional meaningful patterns in the behavioral data.

The value of α = 0.03 was chosen based on simulations conducted before collecting the exploratory dataset. These simulations showed that this fixed value could reproduce the full range of behavioral patterns observed in pilot data. Model fits on the exploratory dataset further confirmed that setting α above zero but keeping it rather small yielded consistent qualitative results, though it could shift other parameter estimates in a uniform way.

2.4.2 Low salience constraint

The Selective Maintenance Model without a free salience parameter provided a better fit to the data than all alternative and reduced models, and reproduced the same pattern of results as the Selective Maintenance and Low Salience Model. This suggests that including a salience parameter is not necessary to mechanistically explain the data or the phenomenon of spontaneous recovery.

However, at the individual level, the Selective Maintenance Model failed to capture spontaneous recovery in approximately 40% of participants in the spontaneous recovery (SR) group. Comparing participants whose data were well fit by the Selective Maintenance Model to those whose data were not revealed a key difference: in the latter group, there was no evidence of selective maintenance during the task phases. One possibility that can explain their behavior is that these participants might use selective maintenance only during the break, resembling an 'offline' learning effect.

To differentiate between 'online' and 'offline' learning, we tested a model that included both selective maintenance and a free (unconstrained) salience parameter. While this model again reproduced the same overall pattern of results, it introduced a parameter identifiability issue in some participants, particularly those showing strong selective maintenance or salience effects during learning. This is because both parameters can influence behavior in similar ways during the learning phase. However, only selective maintenance can exert an effect during the break. To address this issue, we constrained the salience parameter to C low ≤ 1, limiting its influence and improving identifiability. Importantly, applying or removing this constraint did not affect the overall pattern of results or their interpretation in either the selective maintenance or decay models.

2.5 Model recovery

To ensure that our winning model was not selected simply because it can flexibly fit data generated by fundamentally different processes, we conducted a model recovery analysis. This analysis included only models based on processes that were distinct from each other (that is, we did not include nested models, as they are by design confusable given the setting of the nested parameters): the Basic Concentration Model, the Selective Maintenance and Low Salience Model, the Processing Loss Model, and the Temporal Weighting Model.

We first generated synthetic data using each model and the best-fitting parameter estimates obtained from participants in the SR group. (Note that we focused on the SR group, because our main research question focused on identifying the mechanisms that explain spontaneous recovery.) We added response noise to the simulated US predictions according to the empirically estimated standard deviation σ and truncated values below 0 or above 1 to 0 and 1, respectively.

Next, we fit all four models to the data generated by each model in turn. For each simulated dataset, we identified the model that best explained the data based on the lowest BIC (Bayesian Information Criterion) value. We then recorded the proportion of simulated 'participants' for whom each model was recovered as best-fitting.

As shown in Suppl. Fig. 3, the Selective Maintenance and Low Salience Model (second row and column) was reliably recovered and was almost never selected as the best-fitting model for data it did not generate. In contrast, the Processing Loss Model was frequently miss-identified as having been generated by the Temporal Weighting Model. This suggests that at least our task design does not allow us to tease apart whether data were generated by the Processing Loss Model or the Temporal Weighting Model. However, since neither of these two models were the winning model in any of our model comparison tests, and all models were compared statistically only to the models with selective maintenance (and not to each other), this finding does not affect our overall results and conclusions. The fact that the two models are confusable notwithstanding, we can conclude from our results that the theory that spontaneous recovery occurs due to lack of novelty or neural fatigue in the extinction phase (e.g., Pavlov (1927)) cannot account for spontaneous recovery in our empirical data. Similar to the above delta rule model, the decay rule model fails to capture spontaneous recovery because it does not contain a mechanisms that stores information about aversive and non-aversive events separately.

In both models the 'states' that one learns about are predefined, here by the two CSs. The extension that the latent cause framework offers is that allows to infer which states (called latent causes, or causes for shorthand) a participant learns about. For example, some participants might infer that the moon and the candles belong to the same state, as they have the same color and a similar purpose, e.g., providing light in the dark. We observed these participants in our dataset and termed them the Generalizers. Other participants might infer one state per CS (as is assumed for all participants by standard reinforcement learning models). Their behavior would be similar to the No SR group (and is well predicted by the Rescorla-Wagner model). Note, however, that behavior of participants in the SR (which was the largest group in our sample comprising over half of the participants) was best explained by models inferring three states, one for the CS-, one for the CS+ in non-reinforced trials (that is, without a US) and one for the CS+ and the US. This indicates that it is important to not predefine the number of states participants can learn about but assess how many states they likely inferred and learned about.

2.3.2 Temporal context models

The prevailing theory explaining spontaneous recovery suggests that individuals infer different contexts during acquisition and extinction. During a spontaneous recovery test-or simply at a later time in life-it may be unclear which context is currently active. This ambiguity can lead to a prediction of aversive outcomes based on an average of the acquisition and extinction phases, or alternatively, the acquisition context may be retrieved, for instance, due to a visual cue indicating that an individual currently is in the acquisition context. In the former case, one would expect a modest level of spontaneous recovery, while in the latter, a more substantial amount of spontaneous recovery would be observed.

To ensure that context cues cannot account for spontaneous recovery in our dataset, we designed our experiment to tightly control for context cues. We ensured that no visual or auditory stimuli differentiated the task phases, making it unlikely that contextual inference could explain the observed spontaneous recovery. However, we still observed substantial amounts of spontaneous recovery.

How could spontaneous recovery be explained through context inference in the absence of any context cues? Bouton (1993 Bouton ( , 2004) ) proposed that temporal context may still play a role. Similar to visual cues, other contextual elements -such as bodily states, room temperature, or ambient lighting -might support the inference of different temporal contexts, even if these variables were not explicitly manipulated or assessed. As reviewed by DuBrow, Rouhani, Niv, and Norman (2017), neural evidence further suggests that we encode mental context that slowly drifts over time, possibly to bind events that occur in close temporal proximity together in memory. DuBrow et al. (2017) also proposed that mental context can shift abruptly due to surprising events (or boundaries) such that different mental contexts can be encoded separately to reduce interference in memory.

There are many ways to formalize the concept of temporal context, and we acknowledge that it is impossible to rule out every possible implementation. Nevertheless, we attempted to formalize temporal context inference by implementing a hierarchical inference model. This model not only infers latent causes but also allows for the inference of distinct temporal contexts (see Pisupati, Berwian, Chiu, Ren, & Niv, 2023). In this model, temporal contexts can contain several latent causes. However, the occurrence of dissimilar or previously unseen combinations of latent causes can prompt the inference of a new temporal context-akin to how new latent causes are inferred from dissimilar observations (and in line with shifts in mental context). We incorporated persistence into the model to formalize the assumption that contexts tend to remain stable over time. This also incorporates the idea that "invisible" cues like lighting, temperature, or bodily states change slowly and are more stable within a task phase than across phases.

For a mathematical formalization of the model, see Pisupati et al. (2023). We fit this hierarchical temporal context model, along with reduced variants of itself and a version that included a salience parameter C (increasing counts of reinforced events as in the Salience Model), to data from our exploratory dataset (Study 1). None of the models were able to simulate the amount of spontaneous recovery observed in our data given constraints of the overall data (such as unbiased priors over observations). Furthermore, none of the models captured the average magnitude of spontaneous recovery when fit to the data or provided better fits across the complete task. The main reason why these and related models failed to capture spontaneous recovery is because they can, on average, only predict spontaneous recovery up to the average of probability given all observations or the weighted average of the acquisition and extinction context, which in our task is p(US|CS+) = .235 at the beginning of the spontaneous recovery test. Indeed, this is exactly what the Temporal Weighting Model (see Fig. 7 in the main paper) and other models predicted. However, in our empirical data , the prediction of a US given the CS+ clearly exceeded .235 (see Fig. 2 and 7 and in the main text).

These results suggest that, at least in the form tested here, temporal contexts do not provide a sufficient explanation for the amount of spontaneous recovery observed in our data. Importantly, we do not claim that temporal contexts do not exist. Rather, without any additional mechanisms at play, they appear to be neither sufficient nor necessary to account for the behavioral effects observed during the spontaneous recovery test.

2.3.3 Response fatigue

Early experiments measuring spontaneous recovery were often conducted in animals. Fear responses were usually measured in terms of freezing (or flight) responses. Such responses are more effortful than no response. Hence, one plausible explanation brought forward for this behavior was response fatigue, which became more prevalent during extinction (see (Rescorla, 2004) for a review). Thus, no true extinction takes place: the lack of fear responses only appears as a result of response fatigue. However, once that fatigue has passed, fear responses re-occur, which could look like the return of fear with time, i.e., spontaneous recovery. However, response fatigue is not able to account for spontaneous recovery in our paradigm as responses of aversive outcome predictions or negative affect on the rating scales required the same amount of effort for all responses (i.e., independent of its valence or probability of a negative outcome).

2.3.4 Alternative model formalizations

In an attempt to reduce the probability that we missed alternative explanations for spontaneous recovery, we also tested models with additional free parameters (such as a free b obs which allows for biased starting priors), different priors over observations for features (CSs) and outcomes (US), additional combinations of free parameters such as the temporal weighting and salience or selective maintenance, and longer time intervals (e.g., double the number of break stimuli) in the Temporal Weighting, the Decay and the Salience Model. Furthermore, we tested a model that included no decay but rather strengthening of latent causes that predict the US (i.e., the "excitatory association" in theories of extinction), and a model that included only decay of latent causes that do not predict the US (i.e., the "inhibitory association" in theories of extinction). All these models either did not capture spontaneous recovery together with the entire dataset well or did not capture it to the same extent as models with selective maintenance.

We also tested alternative implementations of the Selective Maintenance and Low Salience Model, e.g., independent decay parameters for aversive and non-aversive latent causes and a model that only allowed selective maintenance during the break, or an additional free parameter that influenced the extent to which selective maintenance was applied during task phases in addition to the break. However, the Selective Maintenance and Low Salience Model was the best constraint and identifiable model given our dataset.

2.4 Modeling choices

Our goal was to find the best model that explains spontaneous recovery given the entire data without biasing our results to one specific model with our modeling choices while achieving parameter and model identifiability. Below, we briefly explain why we made a set of modeling choices and how we verified that they did not bias our results.

2.4.1 Fixed concentration parameter

We fixed the concentration parameter α to 0.03 for all models except the Basic Concentration Model. This decision was based on the fact that both α and the prior over observations a obs influence the number of latent causes that are generated, leading to potential parameter identifiability issues. Since the Basic Prior Model fit the data better than the Basic Concentration Model (see Fig. 5 in the main text), and a obs offers a more direct psychological interpretation, we opted to fix α rather than fit both parameters simultaneously, especially as doing so did not capture any additional meaningful patterns in the behavioral data.

The value of α = 0.03 was chosen based on simulations conducted before collecting the exploratory dataset. These simulations showed that this fixed value could reproduce the full range of behavioral patterns observed in pilot data. Model fits on the exploratory dataset further confirmed that setting α above zero but keeping it rather small yielded consistent qualitative results, though it could shift other parameter estimates in a uniform way.

2.4.2 Low salience constraint

The Selective Maintenance Model without a free salience parameter provided a better fit to the data than all alternative and reduced models, and reproduced the same pattern of results as the Selective Maintenance and Low Salience Model. This suggests that including a salience parameter is not necessary to mechanistically explain the data or the phenomenon of spontaneous recovery.

However, at the individual level, the Selective Maintenance Model failed to capture spontaneous recovery in approximately 40% of participants in the spontaneous recovery (SR) group. Comparing participants whose data were well fit by the Selective Maintenance Model to those whose data were not revealed a key difference: in the latter group, there was no evidence of selective maintenance during the task phases. One possibility that can explain their behavior is that these participants might use selective maintenance only during the break, resembling an 'offline' learning effect.

2.5 Model recovery

To ensure that our winning model was not selected simply because it can flexibly fit data generated by fundamentally different processes, we conducted a model recovery analysis. This analysis included only models based on processes that were distinct from each other (that is, we did not include nested models, as they are by design confusable given the setting of the nested parameters): the Basic Concentration Model, the Selective Maintenance and Low Salience Model, the Processing Loss Model, and the Temporal Weighting Model.

We first generated synthetic data using each model and the best-fitting parameter estimates obtained from participants in the SR group. (Note that we focused on the SR group, because our main research question focused on identifying the mechanisms that explain spontaneous recovery.) We added response noise to the simulated US predictions according to the empirically estimated standard deviation σ and truncated values below 0 or above 1 to 0 and 1, respectively.

Next, we fit all four models to the data generated by each model in turn. For each simulated dataset, we identified the model that best explained the data based on the lowest BIC (Bayesian Information Criterion) value. We then recorded the proportion of simulated 'participants' for whom each model was recovered as best-fitting.

As shown in Suppl. Fig. 3, the Selective Maintenance and Low Salience Model (second row and column) was reliably recovered and was almost never selected as the best-fitting model for data it did not generate. In contrast, the Processing Loss Model was frequently miss-identified as having been generated by the Temporal Weighting Model. This suggests that at least our task design does not allow us to tease apart whether data were generated by the Processing Loss Model or the Temporal Weighting Model. However, since neither of these two models were the winning model in any of our model comparison tests, and all models were compared statistically only to the models with selective maintenance (and not to each other), this finding does not affect our overall results and conclusions. The fact that the two models are confusable notwithstanding, we can conclude from our results that the theory that spontaneous recovery occurs due to lack of novelty or neural fatigue in the extinction phase (e.g., Pavlov (1927)) cannot account for spontaneous recovery in our empirical data.

E) Schema therapy, implemented as a reduction of the selective maintenance results in stronger decay of the dangerous latent cause. F) Retrieval cues used after the end of extinction (therapy) decrease the decay of the safe latent cause, therefore leaving the relative strength of the safe and dangerous latent causes flat throughout the break, and preventing spontaneous recovery. We computed the strength of each latent cause by computing the posterior over the latent causes assuming observation of a CS+ (but no outcome yet). Relative strength difference was computed as the strength of the dangerous latent cause divided by the sum of the strengths of the safe and the dangerous latent causes, multiplied by 10 for better visualization.
