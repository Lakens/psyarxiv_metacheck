To check Non-Significant P Value Check

What we found

We found 1 non-significant p value that should be checked for appropriate interpretation.

Show details

Meta-scientific research has shown nonsignificant p values are commonly misinterpreted. It is incorrect to infer that there is ‘no effect’, ‘no difference’, or that groups are ‘the same’ after p > 0.05.

It is possible that there is a true non-zero effect, but that the study did not detect it. Make sure your inference acknowledges that it is possible that there is a non-zero effect. It is correct to include the effect is ‘not significantly’ different, although this just restates that p > 0.05.

How Power Analysis Check works

This module uses regular expressions to identify sentences that contain a statistical power analysis. If specified by the user, it also uses a large language model (LLM) to extract information reported in power analyses, including the statistical test, sample size, alpha level, desired level of power, and magnitude and type of effect size.

The Power Analysis Check module uses regular expressions to identify sentences that contain a statistical power analysis. Without the use of an LLM, the module uses regular expressions to classify the power analysis as a-priori, sensitivity or post-hoc. With the use of an LLM, it checks if the power analysis is reported with all required information.

The regular expressions can miss power analyses, or fail to classify them correctly. How Exact P-Values works

List any p-values reported with insufficient precision (e.g., p < .05 or p = n.s.), reported as exactly zero (e.g., p = .000), or impossible (below 0 or above 1, e.g., p = -.22).

This module uses regular expressions to identify p-values. It will flag any values reported as p > ? or p < numbers greater than .001. It will also flag p-values reported as exactly zero (e.g., p = .000, p = 0.00), which are mathematically impossible — p-values are never exactly zero and should instead be reported as p < .001.

A p-value that is not the result of a test is not flagged: a table note (“* p < .05, ** p < .01”), a figure legend (“Asterisks indicate significant differences (p < .05)”, “Values in bold are significant at p < .05”) or a stated threshold (“p < .05 was considered significant”, “thresholded at p < .001”). GROBID often puts such notes into the running text, so each p-value is judged by the words in its own clause (the text up to a “;” or a full stop), and never left out when a test statistic belongs to it (“F(1, 7) = 8.03, # p < .05”). The column not_a_test of the table says why a p-value was left out (“marker”, “threshold”, “legend” or “named”).

A p-value with the name of a correction or a test after the p (“pFWE < .05”, “padj < 0.05”, “p Wilcoxon = .02”) is flagged only when a test statistic comes before it in its clause (“t(37) = 7.17, p FWE < .05”). Without one it is mostly the rule that decided what was significant (“genes with padj < 0.05 were selected”); such a p-value is “named” in not_a_test. Notes in other forms, such as a marker after the p-value (“p < .05 (*)“), are still flagged.

A p-value below 0 or above 1 is impossible; it is listed apart and not also as imprecise. Often the statistic before it, or its minus sign, was copied into it (“t(134) = -2.32, p = -.13”, “Z = 3.091, P = 3.091”). A value above 1 is listed only after a test statistic in its clause: without one, a “P” above 1 was nearly always another quantity (a proportion, pH, a group’s mean, a model parameter). A number in scientific notation whose power of ten was lost when the PDF was read (“p = 2.4 x 10 -9” read as 2.4) is not listed. A “p” that is the subscript of another symbol (“r p = .64”, “²p = .02” for partial eta squared, “Δp = .33”), or a quantity with a unit, a logarithm or a ratio (“P = 2.9 µm”, “-log10 P = 7.5”, “Ca/P = 1.67”), is not read as a p-value at all (see extract_p_values()). Each p-value has its own row, also when the same one is written twice in a sentence.

This module sometimes flags false positives when sentences discuss how p-value thresholds were set. It can also miss an imprecise p-value that is reported against a threshold (“decreased at the p < .05 significance threshold”).

This module only checks p-values reported in the running text of the manuscript. It cannot (yet) process p-values reported only in tables (as opposed to a table’s footnote text, which the module does see and tries to exclude — see above).

This module was developed by Lisa DeBruine and Daniel Lakens

How Code Check works

This module retrieves information from repositories checked by repo_check about code files (R, Python, SAS, SPSS, Stata, Mplus, MATLAB).

The Code Check module checks R (also R Markdown and Quarto), Python (also Jupyter notebooks), SAS, SPSS, Stata, Mplus, and MATLAB files, using regular expressions to check the code; JASP files are listed but not read. The language of a Quarto document or a notebook is read from the file itself (its engine or kernel), not from its extension. The regular expression search will detect the number of comments, the lines at which libraries/imports are loaded, attempts to detect absolute paths to files, setwd() and install.packages() calls, and lists files that are loaded, and checks if these files are in the repository; R code is also parsed. The module will return suggestions to improve the code if there are no comments, if libraries/imports are loaded in lines further than 4 lines apart, if files that are loaded are not in the repository, if absolute file paths, setwd() or install.packages() are found, and if R code cannot be parsed.

The regular expressions can miss information in code files, or falsely detect parts of the code as a fixed file path. How Reproducibility Check works

This module assesses whether a paper’s R and Python code can be run on its data. It works in two phases. The static phase (always run) collects the package dependencies the code declares, rewrites the data-file paths that do not work in the repository as the authors organised it, works out the order the scripts must run in, and diagnoses why any referenced input file is unavailable — reporting what a reproduction attempt would involve and where it is likely to break. Full text

Abstract

Classifying whether an auditory signal is music or speech is important for both humans and computational systems. Although previous literature suggests that music and speech are easily separable categories, common experimental approaches may bias findings toward this distinction by relying on stimuli from different sound sources and predefined response labels. Here, we use stimulus material from the dùndún drum -a speech surrogate that can signal either speech-related or musical content. We first replicate standard speech-music categorization results (N = 108). Then, we depart from the typical experimental procedure by asking new participants (N = 180) to sort and label the stimulus material, without predefined categories. Hierarchical clustering of participants' stimulus groupings reveals multiple organizing dimensions, with the speech-music distinction reliably present but secondary under label-free conditions. By reverse-engineering the relationship between sorting behavior, acoustic features, and semantic labels, we characterize how speech-music categorization relates to other salient perceptual dimensions and how its behavioral prominence depends on task constraints. Public significance statement How people make sense of the sounds around them is a basic question in perception research, yet many studies assume that sounds naturally fall into categories such as speech or music. This study shows that whether listeners categorize sounds as speech-like or music-like depends strongly on how they are asked to perform the task, even when all sounds come from the same physical source. When listeners are not given category labels, other ways of organizing the sounds become more prominent.

Introduction

"Music begins where speech fails." This famous adage (often attributed to Hans Christian Andersen or Jean Sibelius) illustrates that music and speech are typically considered distinct signal categories. Whether the processing of each category develops in parallel or not is debated (Brandt et al., 2022), but differences have been described regarding their respective functions (Jackendoff, 2009; Patel, 2008) and the neural architecture underlying their processing (Albouy et al., 2020; Norman-Haignere et al., 2022). Researchers often treat music and speech as privileged or dominant categories that listeners readily identify when presented with auditory material; however, the conditions under which this distinction guides auditory categorization merit closer examination. Of course, human listeners can distinguish these acoustic categories when asked, but our approaches to studying them may bias findings in that direction. Accordingly, speech and music are treated here as a theoretically important test case for examining how task constraints shape which perceptual dimensions become behaviorally dominant, rather than as an assumed primary axis of auditory organization. Here, we examine task-and cue-dependence of the speech-music distinction by analyzing these categories through the lens of a label-free auditory categorization task, using speech surrogate stimuli.

Surrogate languages offer a unique opportunity to study aspects of phonetics, phonology, syntax, culture, and the neural substrates of language processing (James, 2021). Musical surrogate languages typically involve systematic replacement of aspects of spoken language with other sounds, for example, drumming or whistling (James, 2021). James et al. (2021) document over 200 surrogate languages in their online database, some of which imitate the pitch, rhythmic, and temporal structure of speech. While studying speech surrogates is interesting in its own right (e.g., to understand rich cultural traditions), it can also help to understand cognitive functions more generally. Importantly, many surrogate languages preserve suprasegmental features including timing, rhythmic patterning, and pitch contours while abstracting away segmental phonetic information, making them well suited for examining perceptual organization and categorization beyond lexical content. In our case, speech surrogates offer an enticing way to compare the perception of speech versus music using the same instrument and spectral range.

In a previous study employing the dùndún talking drum, a Nigerian instrument used in Yorùbá traditions to perform speech-like communication (Akinbo, 2019; Durojaye et al., 2021b), high classification accuracy of music versus speech audio samples was observed, even in listeners unfamiliar with this instrument (Durojaye et al., 2021a). The dùndún allows continuous modulation of membrane tension, producing dynamic pitch contours and temporally structured patterns that can function both musically and as speech surrogates. However, we question the role that provided category labels may play in shaping participants' categorization behavior. In the present study, we examine how listeners group the same dùndún stimuli under conditions without explicit category labels. While we focus here on general perceptual categorization mechanisms, we recognize that removing dùndún sequences from their performance context risks stripping away cultural meaning, ritual significance, and embedded communicative practices -an act that can unintentionally echo colonial extractivism (Sauvé et al., 2023). This decontextualization, even when well intentioned, mirrors broader epistemic processes whereby Western science absorbs cultural forms without regard for their embeddedness. We urge readers to interpret our findings with this in mind.

The role of category labels

Broadly, categorization helps humans to make sense of the world, for example, via equivalence classes and generalization (Ralston & Sloutsky, 2023; Sloutsky, 2010). It is thought that categorization increases learnability and fluency of processing, while reducing memory costs (Steinert-Threlkeld & Szymanik, 2020; Witzel & Gegenfurtner, 2015). To study the categorization of long sound sequences, such as music and speech, experimental designs often make use of experimenter-provided categories, such as "music/speech," or "song/speech" in the case of vocal stimuli (e.g., Vanden Bosch der Nederlanden et al., 2022). Labels are typically an integral part of the experimental procedure, with participants asked to rate how "music-" or "speech"-like a stimulus sounds (e.g., Tierney et al., 2018; Vanden Bosch der Nederlanden et al., 2015), or to choose one of the two options (e.g., Albouy et al., 2024; Chang et al., 2024). In such cases, the nature of the categories examined is explicit and presented as the primary distinction between the presented signals. Because labels affect categorization, even when participants are asked to not use them (Gervits et al., 2016), and because they increase perceived (dis)similarities between stimuli (Foroni & Rothbart, 2011), we argue that reliance on predefined category labels can obscure other perceptually relevant dimensions when studying speech and music categorization.

Semantic analysis

One approach to avoid the influence of labels is to directly ask people to describe what underlies their categorization behavior. For example, in a recent study assessing how speech and song categories emerge and change across development, Vanden Bosch der Nederlanden et al. (2022) analyzed the free responses of participants aged 4-24 years and found that, across all age groups, the highest percentage of responses tended to fall into an acoustic theme (e.g., "loud," "quiet"). In categorizing sound more generally, Bones et al. (2018) had participants freely sort and then label sound clips from Freesound.org. This strategy allowed them to explore emergent taxonomies of sound stimulus categories, ultimately revealing a soundscape hierarchy with people, nature, and manmade sounds comprising the top level. Each of these were divided into voices and music, animals and weather, and industrial and household, respectively. At these top and middle levels, participants tended to describe the sounds with words related to sound source (e.g., "synths," "thunder"), whereas at lower hierarchical levels, participants used words related to the acoustic signal (e.g., "high pitch," "sporadic") and its perceived qualities (e.g., "annoying," "harsh"). This primary emphasis on sound source is in line with many previous studies of environmental sounds and "everyday listening" (Gaver, 1993; Guastavino, 2007; Tardieu et al., 2008), and emphasizes the importance of controlling for sound source when comparing acoustic categories.

Semantic labels (sometimes referred to as tags) are also used to identify audio, optimize search results, and guide human-computer interactions. For example, some researchers have focused on defining tags associated with singing voices (Kim et al., 2020), others on defining musically meaningful vocabularies (i.e., the most unambiguous labels that agree with human ratings and acoustic features; Torres et al., 2007). Such approaches allow one to use the distance between semantic tags to search for audio (i.e., to find audio that meets specific criteria; see, e.g., Moore et al., 2012; Ragano et al., 2023; Sandouk & Chen, 2017). Collectively, then, these studies showcase the value of free sorting and free responses in studying acoustic categories, as well as the fact that semantic descriptions may provide an additional level of explanation beyond acoustic features.

Acoustic characterization

A complementary approach to categorizing speech and music consists of exploiting the mapping between semantic descriptors and extracted acoustic features. For example, Ding et al. (2017) show that the amplitude modulation spectrum of music (across genres) tends to peak around 2 Hz, whereas that of speech peaks around 5 Hz. Other features, like regularity and repetition (Chang et al., 2024; Margulis, 2013; Vanden Bosch der Nederlanden et al., 2022), pitch and/or melody (Vanden Bosch der Nederlanden et al., 2022; Zatorre & Baum, 2012), also play important roles in distinguishing the two signals. Such acoustic differences are particularly evident when speech and music come from different sound sources (e.g., piano vs. voice), which may have vastly different ranges and possibilities for acoustic variability. However, differences have also been found when sounds arise from the same sound source, as in speech and song (Albouy et al., 2024; Merrill & Larrouy-Maestri, 2017; Ozaki et al., 2024; Vanden Bosch der Nederlanden et al., 2022).

Researchers aiming to build computer systems to classify speech versus music have tended to use a large combination of spectrotemporal features. Such features often include Mel Frequency Cepstral Coefficient (MFCC), silent pauses, higherorder statistics, etc. (see, e.g., Bhattacharjee et al., 2023, for an overview). However, computational models trained specifically to distinguish speech and music cannot generalize well to other tasks (e.g., detecting environmental sounds, such as birdsong). An alternative approach to supervised feature selection is to learn the mapping between audio features and semantic labels in an unsupervised or self-supervised way (Elizalde et al., 2022; Saeed et al., 2021). However, such approaches require huge amounts of data and do not necessarily inform our understanding of the perceptual basis of these categories.

In the current study, we take an a priori, feature-based approach. Based on our prior study (Durojaye et al., 2021a), and the music-speech literature discussed above (e.g., Chang et al., 2024; Margulis, 2013; Vanden Bosch der Nederlanden et al., 2022), we extracted a variety of proven relevant acoustic features, ranging from those calculated on the tone level (e.g., pitch, intensity), between tones (e.g., inter-onset-intervals (IOIs)), and across the whole recording (e.g., pulse clarity, recurrence), including timing-related (spectrotemporal) properties. By relating these features to participants' unrestricted stimulus-grouping behavior and self-provided labels, we can deduce which acoustic features influence categorization.

The relationship between acoustic features and semantic labels

In this study, we depart from typical methodologies. Our task (Fig. 1) requires participants to sort stimuli into two boxes. To replicate Durojaye, et al.'s (2021a) speech-music categorization findings, using the new sorting paradigm, we first labeled these boxes "speech-like" and "music-like" (Fig. 1A, left column). In a second experiment, with a different set of participants, no such labels were provided. Participants sorted the stimuli into two boxes, labelled "Group 1" and "Group 2," and were subsequently asked to provide their own labels for the boxes and describe their strategy (Fig. 1B, right column). We analyze patterns in participants' sorting behavior, in combination with the acoustic features of the experimental stimuli and the participant-provided labels. This approach allows us to reverse-engineer the organization of auditory perceptual categorization under labeled and label-free conditions by linking participants' grouping behavior and descriptions to stimuli acoustic features. In essence, we ask: How do listeners organize unfamiliar sounds when meaningful categories are supplied (or not), and how does that organization relate to the acoustic dimensions of the stimuli and the labels provided by participants? By using speech-like and music-like signals produced by the same instrument, we examine categories without confounding evaluation with sound-source differences.

Method

Experimental design

The objectives of the study were to (1) replicate previous speech/music findings using a new sorting paradigm (Exp. 1), and (2) to reverse-engineer the salient concepts and acoustic features underlying stimulus categorization when no labels are provided to participants (Exp. 2). In both experiments, we used the same sorting task (see Fig. 1), in which participants could listen to each stimulus as often as they wanted and freely drag it into one of two boxes, with (Exp. 1) or without (Exp. 2) labels. In Experiment 2, participants had a subsequent task of labeling the two boxes, after they had finished sorting the stimuli. The two experiments used the same stimuli, but a different participant pool (sampled online, via Prolific, 2014). More details for each experiment are discussed below.

Transparency and openness

Material

We used 30 drum recordings performed by a professional dùndún drummer in Nigeria (6-10 s each, SHURE SM57 microphone, 44.1 kHz; see Durojaye et al. (2021a) for details). Fifteen recordings were intended as speech and the other 15 were intended as music. Following prior work, the distinction between speech-surrogate and music stimuli reflects the intended communicative function of the performer, rather than the presence of lexical or segmental linguistic content in the signal. For experimental consistency, our audio team at the Max Planck Institute for Empirical Aesthetics applied standard digital processing (Izotope RX 7 De-Noise, De-Clip, De-Reverb; Equalizer Pro Q2 by FabFilter; 1176 compressor from Native Instruments; SPL Transient Designer 9946; TC Electronic's M350 reverb; all within Cubase Pro 11) to reduce background sounds (speech, bells) and recording artifacts. Sauvé et al., 2023). We therefore urge readers to interpret our findings with this limitation in mind.

Acoustic features

We extracted a variety of potentially relevant features, ranging from those calculated on the tone level (e.g., pitch, intensity), between tones (e.g., IOIs), and across the whole recording (e.g., pulse clarity, recurrence). By relating these features to participants' unrestricted stimulus grouping behavior, we can deduce which acoustic features influence their categorization.

Acoustic features were extracted from the stimuli as follows: in MATLAB (2019) we first extracted the amplitude envelope using envelope()'s RMS method, with 50-ms windows. We then low-pass filtered the envelope at 50 Hz using a third-order Butterworth filter and normalized the signal. Subsequently, we detected peaks in this smoothed amplitude envelope, which were separated by at least 40 ms. The peak time points were used to define tone onsets. Note that tone onsets of a drum are quite clearly automatically detected in this manner.

In addition to the intensity (amplitude envelope), we extracted pitch and spectral entropy continuously, using MATLAB's pitch() pitch estimation filter and pentropy() functions, respectively. Subsequently, these feature values were cut relative to tone onset timings, within a 20-ms window. While 20 ms may seem short, bear in mind that this particular drum does not resonate for long and some grace notes or rhythmic subdivisions may not be much longer than 20 ms, depending on the mean IOIs between notes, which were also calculated via amplitude envelope-detected onsets. The ratio of onset differences between notes was defined as interval1/(interval1 + interval2), where a ratio > 0.5 represents a short interval following a longer one, and a ratio < 0.5 indicates the opposite (i.e., a value of precisely 0.5 stands for two consecutive intervals of the same length). The above characteristics were all evaluated at the tone level and/or between two consecutive tones, and then averaged per stimulus.

On the level of the whole stimulus, we calculated the pulse clarity via mirpulseclarity() from the MIR toolbox (Lartillot et al., 2008), the average spectral flux via spec-tralFlux() from the Audio toolbox, and the amplitude modulation spectra of the stimuli via the code of (Ding et al., 2017). On the spectral flux time series for each stimulus, we used recurrence quantification analysis to calculate the recurrence rate, mean and maximum recurrence lengths, and determinism. Using the MdRQA MATLAB toolbox (Wallot et al., 2016), recurrence-related features were calculated with an embedding dimension 2, a delay parameter of 10, and Euclidean phase space normalization.

This feature set is not exhaustive and does not directly quantify resonance or decay duration. The current features were chosen based on those purported to be relevant to the speech/music distinction (e.g., Chang et al., 2024; Durojaye et al., 2021a Durojaye et al., , 2021b)). After conducting a supplemental analysis (see Online Supplemental Material (OSM) Fig. S1) analyzing overall spectral power, particularly in the higher frequency range, we observed variability that may be relevant for future studies. In the current study -though differences in bandwidth between stimuli may not be ideal, as pointed out by a reviewer -participants in both experiments heard the same exact stimuli, meaning differences between experiments are due to the task differences (labelled vs. unlabeled boxes), rather than pre-existing differences between stimuli. Distinguishing the music-like from speech-like stimuli is arbitrarily easy, as shown in Durojaye et al., (2021a Durojaye et al., ( , 2021b)), using a single feature like pulse clarity. The goal here is to understand which features participants use in labelled versus label-free task paradigms.

Many of the extracted features from this small set showed high correlation with each other, as would be expected on a drum where changing the tension of the head results in altered resonance and pitch. As such, we conducted a principal component analysis (PCA) on the acoustic features to reduce dimensionality and co-linearity for future analyses. Inspection of eigen values and the scree plot suggested a cutoff at PC4, after which a clear elbow occurred in the plot and all eigen values were less than 1. The first four principal components explained a cumulative 80% of the variance. See Table 1 for full details regarding the contribution of each acoustic feature (in percentages) for each PC and the variance explained by each PC. As can be seen in the table, PC1 is dominated by pitch and spectral features. PC2 is dominated by mean timing-related features (IOI mean, IOI difference, intensity mean, and mean and max recurrence length). PC3 is composed of more dynamic timing-related features, such as recurrence, determinism, and the ratio and intensity differences between notes. Finally, PC4 is dominated by the amplitude modulation spectrum peak and the ratio mean.

Procedure

The experiment was implemented online in LabVanced (Finger et al., 2017). The experimental protocol was approved by the Ethics Council of the Max Planck Society (No. 2017_12); informed consent was obtained from all participants prior to the study. After becoming acquainted with the instructions through a picture, text, and two short videos, participants were asked to listen to the sounds displayed on the screen, and to drag and drop each sound symbol into one of two separate boxes, labeled "music-like" and "speechlike"; see Fig. 1. Both the order of the stimuli and the position of the box labels were randomized. Participants were in control of playing, pausing, and dragging the stimuli. After participants had sorted all of the stimulus buttons, they provided a brief description of their classification strategy; this was an open question, allowing up to 140 characters.

At the end of the experiment, participants were asked how difficult the task had been (on a 100-step slider from "Not at all" to "Very difficult") and how much they liked the sounds they had just heard (on a 100-step slider from "Not at all" to "Very much"). Finally, they were asked whether they spoke the Yorùbá language (on a 100-step slider from "No" to "Yes, fluently"), and if they were familiar with the dùndún talking drum (on a 100-step slider from "No" to "Yes, very"). If, for the latter question, the cursor was above 0, participants saw five additional questions about the dùndún. These questions concerned the origin and look of the drum, personal experiences in playing or attending a live session of someone else playing the dùndún, and participants' knowledge of other drums in a dùndún ensemble (see Durojaye, 2020). To characterize the musical expertise of our participants, we also had them complete the Goldsmith's Musical Sophistication Index (Gold-MSI; Müllensiefen et al., 2014).

Stimulus-sorting analyses

Participants had an overall tendency to place more stimuli in the music-like box, as opposed to the speech-like box (t(107) = 7.36, p <.001), but this bias had no impact on our subsequent analyses. To identify patterns in the way participants grouped stimuli, we analyzed the (dis)similarity of their groupings. A dissimilarity matrix was constructed by (1) counting the number of times each stimulus was grouped with each other stimulus, (2) normalizing by the total number of times each stimulus could have been grouped with each other stimulus, and (3) calculating the Euclidean distance between all stimulus pairwise co-assignment counts. We then applied hierarchical agglomerative clustering using Ward's minimum-variance linkage (hclust package in R; method = ward.D2). The optimal number of clusters was determined using the gap statistic with 500 Monte Carlo bootstrap samples. Finally, PCA was used to represent the relative positions of stimuli in a low-dimensional space defined by the first two principal components. Next, we constructed two separate linear regression models to predict the x and y coordinate of the stimuli in PCA space (i.e., dimensions 1 vs. 2), respectively. Coordinate was the dependent variable and acoustic PCs were the predictors. Model output is reported using APA recommendations via the apaTables package (Stanley, 2021) in R (R Core Team, 2018). To be sure the models were not overfit, we used the caret package (Kuhn, 2008) and fivefold cross-validation, repeated ten times, to calculate the mean absolute error (MAE) across all model iterations, with standardization and PCA fitted within each training fold. To assess the sensitivity of predictive performance to the number of retained acoustic components, we repeated the cross-validation procedure retaining three or five components. We also compared model performance against a baseline predicting the median behavioral coordinate of the training stimuli.

Classification accuracy

Matthews Correlation Coefficient (MCC) was calculated as a final metric of participants' ability to distinguish speech-like from music-like stimuli (i.e., comparing their responses to the "ground truth" of our dùndún recordings). MCC ranges between -1 and 1, with 0 indicating chance classification, 1 perfect classification, and -1 perfect misclassification. See Durojaye et al. (2021a) for more details about this metric. Importantly, note that this metric is robust to potential class imbalances (i.e., more instances of selecting one category vs. another), in a way that a metric such as accuracy is not (Chicco & Jurman, 2020).

Label analyses

Unique to this experiment is the possibility of analyzing the labels participants choose for the two boxes in which they grouped the stimuli. To do so, we cleaned the provided labels (e.g., removing punctuation, making all characters lowercase), manually combined similar words, and corrected misspellings. For example, "drums" and "drum" were all changed to "drum" and the various misspellings of "percussion" and "rhythm" were corrected.

Our analyses were conducted on the word (not phrase) level. First, we created a word cloud from all participant labels to get an overall sense of the words that tended to be used during the labeling task. To understand how word usage differed by stimulus cluster, we calculated comparison word clouds. Comparison clouds show words that differ in frequency between two or more documents. In this case our "documents" were our stimulus clusters. Word frequency was normalized by the total number of words in each cluster. R package wordcloud v. 2.6 (Fellows, 2018) was used for all cloud-based analyses. All analysis code is available in the repository associated with this paper.

Factorial approach for sorting task data

As an additional representation of the free-sorting data in Experiment 2, we applied the Factorial Approach for Sorting Task data (FAST; Cadoret et al., 2009), implemented in the SensoMineR package. The input matrix contained stimuli as rows and participants as columns, with each cell indicating the participant-specific box assignment of that stimulus. Box identifiers were treated as arbitrary within-participant group labels; thus, their spatial or numerical identity was not interpreted across participants. To relate participants' descriptions to the resulting stimulus configuration, label phrases were cleaned for spelling and clearly equivalent variants while otherwise preserving participants' wording. Label frequency was counted once per participant-defined box. The ten most frequently used phrases were projected onto the first two FAST dimensions by calculating the frequencyweighted centroid of the stimuli associated with each phrase.

Constraints on generalizability

The findings reported here are based on a limited set of stimuli produced by a single instrument and should not be assumed to generalize to all forms of speech or music. In addition, participants were primarily drawn from Western listener populations, and the task involved brief, decontextualized sound excerpts. Future work will be needed to assess how these results extend to other sound sources, cultural contexts, and listening situations.

Replication of previous speech-music classification results

The results of Experiment 1 (top row) and Experiment 2 (bottom row) are plotted in Fig. 2. The first column shows participants' raw groupings of the stimuli into the two boxes of the sorting task. In Experiment 1, participants sorted the stimuli into the speech-like and music-like boxes. Their average classification score (Matthews Correlation Coefficient, MCC) was 0.61 (SD = 0.30), significantly above the chance level of 0 (t(107) = 20.973, p <.001). These results directly replicate those of Durojaye et al. (2021a), who reported an average MCC of 0.61 (SD = 0.33). Also, as in Durojaye et al. Participant sorting reveals alternative salient categories

The stimulus-level dissimilarity matrices are plotted in Fig. 2, second column, with warmer colors indicating more similarity between stimuli (i.e., the stimuli were likely to be placed in the same box together). In Experiment 1, we see a clear division, with two large clusters and a few outlying stimuli, whereas in Experiment 2, there are more and smaller clusters. As can be seen, when participants are given labels (Exp. 1), the stimuli are consistently and accurately clustered into music-like (blue) and speech-like (red). In other words, participants' primary sorting dimension did not align with the intended speech-music contrast under these label-free task conditions. Accordingly, we next examine acoustic features associated with both the primary sorting dimension identified under label-free conditions and the lower-level partition that aligns with the intended speech-music contrast, allowing us to characterize the latent perceptual dimensions organizing participants' groupings at different hierarchical levels.

We used recordings of the dùndún talking drum, which can mimic "speaking" patterns (a speech surrogate) or perform music.

In a first experiment, to validate our sorting task paradigm, we replicated previous work (Durojaye et al., 2021a) by asking participants to sort dùndún recordings into two boxes labeled "Speech-like" and "Music-like," respectively. That experiment showed that though familiarity with the dùndún and/or Yoruba language aids performance, even naïve listeners could complete the task above chance level. The current results again confirmed that naïve listeners can reliably distinguish between stimuli intended as speech surrogate or music when primed with the corresponding category labels. In Experiment 2, the boxes were only labeled "Group 1" and "Group 2," allowing us to examine participants' spontaneous categorization of the stimuli, without the primes of "speech-like" and "music-like." After sorting, participants provided their own labels for the stimuli. Collectively, this design allowed us to examine the stimulus groupings, acoustic features, and semantic labels that organize auditory categorization under labeled and labelfree conditions.

When no labels were provided and sound-source cues were controlled, the speech-music distinction did not function as the primary organizing dimension in participants' spontaneous grouping behavior. Participants did not group the stimuli into the two boxes according to the "ground truth" speech surrogate/music division, consistent with the well-established role of labels in shaping participant behavior (Fulkerson & Haaf, 2003; Gervits et al., 2016; Johanson & Papafragou, 2016), and in contrast to the labeled sorting observed in Experiment 1. This pattern reinforces prior evidence that category labels strongly influence perceptual grouping.

These results should not be taken as evidence that category labels altered early sensory encoding; rather, they show that labels change listeners' categorization behavior and the relative weighting of acoustic dimensions on the resulting grouping structure. In Experiment 2 (without labels), we found that, at the highest hierarchical level, participants grouped stimuli according to sound source (i.e., what they thought caused the sound). While in line with previous studies (e.g., Bones et al., 2018; non-experts in Lemaitre et al., 2010; Yost, 1992), this finding is particularly interesting in the current context, given that all stimuli were in fact from the same sound source (the dùndún). It seems even within this uniform context, participants still created (imaginary) distinctions based on spectral features. For example, they used labels related to the material of the sound source, such as "metal drum" versus "wooden drum," or sound production, such as "touched with hand" versus "touched with sticks," despite no such ground truth alterations in the performances. The acoustic features contributing most to participants' groupings were pitch and spectral entropy.

Although the Experiment 2 task constrained participants' sorting to two groups, aggregating binary partitions across participants and applying hierarchical clustering enabled recovery of nested perceptual structure beyond a single dichotomy. Though participants did not organize the stimuli primarily according to the intended speech-music contrast, their sorting behavior nonetheless preserved structure aligned with that distinction, allowing it to be examined without having been explicitly cued. At a lower hierarchical level, stimuli clustered in a manner consistent with their intended speech-surrogate or music performances, with associated labels dominated by terms such as "fast" and "rhythmic" for the music-like category, and "slow" and "arrhythmic" for the speech-like one. These semantic patterns converge with the acoustic analyses, which identify timing-related (spectrotemporal) properties -particularly repetition-and regularity-based features -as key contributors to alignment with the speech-music contrast. Notably, this pattern differs from prior reports that speech is typically faster than music (e.g., Chang et al., 2024; Ding et al., 2017; Ozaki et al., 2024). In the present stimulus set, speech-like and music-like recordings had comparable average amplitude-modulation rates but differed in repetition-related structure (e.g., pulse clarity, recurrence, and IOI statistics). This dissociation highlights the contribution of temporal patterning beyond global modulation rate.

Limitations

A central limitation of the present design is that the stimuli should not be understood as stereotypical examples of speech and music. All stimuli were produced by a dùndún drum, and listeners likely perceived them primarily as drum sounds. Our claim is therefore not that listeners heard some stimuli as speech in the ordinary sense, but that some performances carried acoustic structure sufficient to support speech-like judgments (Akinbo, 2019; Durojaye et al., 2021b) when that dimension was made task relevant. The contrast between Experiments 1 and 2 suggests that such speech-like structure was perceptually available but not spontaneously dominant under label-free sorting conditions, though, interestingly, the speech-music distinction exists secondarily.

A second limitation relates to differences in task structure between the two experiments. Though our goal was to compare sorting under labelled and label-free conditions, it could be argued that Experiment 1 is not a sorting task in terms of cognitive demands. It might instead be understood as a labelling task where each individual sound is compared to the available labels, pseudo-independently of each other sound (though recall that all sounds were presented as buttons on the same page). On the other hand, the second experiment more clearly involves a comparison of each sound with each other sound for arranging all stimulus bubbles and eventually labelling each box. In the future, it would be interesting to do a truly free-sorting task, without limiting the number of classes via boxes (see, e.g., Berland et al., 2015; Dauban et al., 2019; Lavan et al., 2019a Lavan et al., , 2019b)). Such a design would further allow us to explore the nuanced (dis) similarities between these stimuli.

A third limitation involves the number of stimuli (30) used in the current experiments, as well as the (mostly Western) participant pools in each experiment. Future research might consider using methods that allow for sampling across large stimuli and participant pools. For example, "Gibbs Sampling with People" (Harrison et al., 2020) would allow us to converge on which features relate to speech versus music across audio corpora and participant samples. We chose to take a bottom-up approach to features of interest, based on previous studies. However, there are a variety of additional potentially relevant features to consider. Rather than determining such features a priori, they could be learned from stimulus data (see, e.g., van Rijn & Maestri, 2023, for an example of data-driven analyses of acoustic prosodic cues across languages and cultures).

Though our previous study (Durojaye et al., 2021a) involved a cross-cultural sample, the present sample was predominantly European and was not designed or balanced to test cultural differences. The current findings therefore establish how category labels affected sorting within this sample and do not demonstrate that the observed strategies are culturally universal. Because the experiments involved independent participant samples with unequal geographical distributions, we cannot exclude the possibility that differences in participants' cultural listening experiences contributed to the observed differences in categorization behavior. Involving larger samples from more countries across the globe may prove particularly informative (see, e.g., Marjieh et al., 2024, and Lee et al., 2025, for examples related to musical consonance and emotions, respectively). Using deliberately stratified samples across cultural and musical communities would allow us to directly examine how auditory culture shapes the weighting of acoustic and categorical cues.

Conclusion

Broadly, these findings illustrate how perceptual categories can be defined by acoustic features yet expressed with varying behavioral prominence depending on task constraints and available labels. Here, the prominence of the speech-music distinction in auditory categorization depends on task demands, rather than functioning as a uniformly dominant dimension across contexts. These results also speak to the utility of the reverse-engineering approach via sorting and labeling. Such tasks and analytic strategies allow researchers to characterize perceptually relevant dimensions and acoustic features that guide categorization behavior without presupposing which distinctions should dominate listeners' judgments, and may be particularly interesting to employ to study the emergence of broader sound categories across development (Berland et al., 2015) and clinical populations (Collett et al., 2016).
