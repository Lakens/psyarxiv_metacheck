Meta-scientific research has shown nonsignificant p values are commonly misinterpreted. It is incorrect to infer that there is ‘no effect’, ‘no difference’, or that groups are ‘the same’ after p > 0.05.

It is possible that there is a true non-zero effect, but that the study did not detect it. Make sure your inference acknowledges that it is possible that there is a non-zero effect. It is correct to include the effect is ‘not significantly’ different, although this just restates that p > 0.05.

This module searches for statements of ethics approval, IRB approval, institutional review board approval, and related terms.

Patterns are designed to capture:

Animal research committee names - Institutional Animal Care and Use Committee / IACUC (US standard) - Any sentence containing animal(s) and committee (or board/panel) within ~5 words of each other — catches Experimental Animal Care and Use Committee, Animal Ethics Committee, Animal Welfare Board, Animal Welfare Ethical Review Body, etc. - UK: Animal Welfare Ethical Review Body / AWERB - Dutch: Dierexperimentencommissie / DEC (see DEC constraint above); Instantie voor Dierenwelzijn / IvD - German: Tierversuchskommission / TvK (advisory committee under §15 Tierschutzgesetz) - French: Comité d'éthique en expérimentation animale / CEEA; Comité d'éthique animale - Spanish: Comité de ética en experimentación animal / CEEA

How Exact P-Values works

List any p-values reported with insufficient precision (e.g., p < .05 or p = n.s.) or reported as exactly zero (e.g., p = .000).

This module uses regular expressions to identify p-values. It will flag any values reported as p > ? or p < numbers greater than .001. It will also flag p-values reported as exactly zero (e.g., p = .000, p = 0.00), which are mathematically impossible — p-values are never exactly zero and should instead be reported as p < .001.

A p-value that is not the result of a test is not flagged: a table note (“* p < .05, ** p < .01”), a figure legend (“Asterisks indicate significant differences (p < .05)”, “Values in bold are significant at p < .05”) or a stated threshold (“p < .05 was considered significant”, “thresholded at p < .001”). GROBID often puts such notes into the running text, so each p-value is judged by the words in its own clause (the text up to a “;” or a full stop), and never left out when a test statistic belongs to it (“F(1, 7) = 8.03, # p < .05”). The column not_a_test of the table says why a p-value was left out (“marker”, “threshold” or “legend”). Notes in other forms, such as a marker after the p-value (“p < .05 (*)“), are still flagged.

This module sometimes flags false positives when sentences discuss how p-value thresholds were set. It can also miss an imprecise p-value that is reported against a threshold (“decreased at the p < .05 significance threshold”).

This module only checks p-values reported in the running text of the manuscript. It cannot (yet) process p-values reported only in tables (as opposed to a table’s footnote text, which the module does see and tries to exclude — see above).

How Code Check works

This module retrieves information from repositories checked by repo_check about code files (R, Python, SAS, SPSS, Stata, Mplus, MATLAB).

The Code Check module checks R (also R Markdown and Quarto), Python (also Jupyter notebooks), SAS, SPSS, Stata, Mplus, and MATLAB files, using regular expressions to check the code; JASP files are listed but not read. The language of a Quarto document or a notebook is read from the file itself (its engine or kernel), not from its extension. The regular expression search will detect the number of comments, the lines at which libraries/imports are loaded, attempts to detect absolute paths to files, setwd() and install.packages() calls, and lists files that are loaded, and checks if these files are in the repository; R code is also parsed. Libraries/imports might be loaded in one block, even if there are more than 3 intermittent lines. The module was tried out internally on papers published in Psychological Science, but has not been formally validated. There might be valid reasons why some loaded files can’t be shared, but the module can’t evaluate these reasons, and always gives a warning.

How Data Check works

This module classifies the files in a repository into semantic types (data, codebook, code, software, output, supplemental, readme, asset, other) and, for tabular data files, extracts each column’s type and summary statistics.

The Data Check module consumes the file list produced by repo_check (or any files added via local_path). Each file is classified with rule-based heuristics layered over metacheck’s file_category() and file_types: file names matching README / codebook patterns win first, then an extension crosswalk, then format-locked extension overrides. For every file classified as tabular data that is available locally, the module reads the file head, describes each column with data_col_facets() and computes summary statistics for numeric columns. Every sheet of a spreadsheet that holds a table is read: a file with several such sheets has its columns under source_file = "file.xlsx [sheet]", and the sheet column names the sheet of any spreadsheet with several sheets; a sheet of notes or a codebook is treated as documentation when the file has another table. Following DDI, a column is described by orthogonal facets rather than a single type: representation (numeric/text/datetime/code — how it is stored), measurement_level (Stevens: nominal/ordinal/interval/ratio), concept (what it measures: reaction_time/age/gender/likert/id/…), role (identifier/measure/condition/timestamp), unit, and a quality state (ok/empty/constant). Concepts are detected by name+value rules (the demographic concepts via data_check_demographic()); when llm_use(TRUE) the model fills concepts and measurement levels the rules left blank. Qualtrics survey exports are recognised (data_check_is_qualtrics()): their extra header rows are stripped so columns type correctly, and the reserved response-metadata columns (StartDate, Duration, Finished, …) are tagged.

The module defaults to rules-only when llm_use(FALSE): columns the rules cannot resolve (ambiguous 3–20-unique integers, ambiguous character columns) fall back to continuous / text respectively. When llm_use(TRUE), ambiguous columns and unresolved file types (other) are sent to llm() for optional refinement, and every file is assigned a study group (ex1, pilot2, shared, …) so that multi-study repositories can be recognised (used by psychds_check). Without an LLM the study group is left NA (unknown).

Column extraction requires files to be readable from disk. Files fetched by repo_check from OSF/GitHub/etc. without a local copy (file_location is NA) are classified but not column-extracted; pass local_path to point at a downloaded copy of the repository.

For a paper whose repository is on Dryad, this means column extraction never happens unless a Dryad API key is set: Dryad requires one to download file bytes, even from a fully public dataset (dataset listing and metadata do not need one). Without a key, every Dryad file stays classified but un-downloaded, column_n is 0, and a warning naming Dryad and ?dryad_pat/?dryad_auth is included among the download failures. A one-time session message is also shown (see repo_check) the first time a Dryad dataset is encountered with no key set.

Every downloaded text file the authors wrote (code, settings, survey definitions such as Qualtrics .qsf files, documentation, outputs) is searched for keys: API keys, access tokens and private keys, which let anyone who downloads the file use a paid service at the authors’ cost. Of a tabular data file only the column names and first 3 rows of the table as read are searched: its values come from participants, but a key the authors set for a whole survey (as embedded data in a Qualtrics survey flow) is exported in every response. The search uses the rules of the secret scanner betterleaks (https://github.com/betterleaks/betterleaks, MIT licence) of high and medium confidence. A key found turns the traffic light red; the report and the keys table give its file, line and type, and only its beginning. Other files over 25 MB and binary files are not searched. A key is never tested with its provider. Every module’s result has any whole key replaced by “keyremoved” (see module_run()).

How Reproducibility Check works

This module assesses whether a paper’s R and Python code can be run on its data. It works in two phases. The static phase (always run) collects the package dependencies the code declares, rewrites the data-file paths that do not work in the repository as the authors organised it, works out the order the scripts must run in, and diagnoses why any referenced input file is unavailable — reporting what a reproduction attempt would involve and where it is likely to break. The execution phase (opt-in, execute = TRUE) then actually runs the code: it copies the repository into a throwaway directory, optionally installs the declared dependencies into a throwaway library, runs each script in order in an isolated subprocess with a per-script timeout, and captures the outcome and full output of each run.

By default (execute = FALSE) the module does not run any code — it performs only static analysis: reading dependencies with the same extractors as code_check, finding the files the code references in the repository, and building a run-order dependency graph. It reports what would be installed and run rather than doing it.

When execute = TRUE, the module additionally runs the downloaded code on your machine — a deliberate, opt-in action gated behind that argument (callr is required for R code). Each script runs in an isolated subprocess so a crash cannot take down the R session; note this isolates crashes, not the filesystem or network. Installs (when install_missing = TRUE) and the throwaway run library never touch your main R library. Each script’s outcome is one of ran_ok, errored, timed_out, dependency_unavailable, not_parsed, run_by_source (an R script another script runs with source(), which is run only inside that script, since on its own it lacks the packages and objects the sourcing script sets up first), run_by_import (a Python file other files import, a module rather than a script, unless it has an if __name__ == "__main__": block), jags_model (a JAGS or BUGS model saved with an R extension, which another script reads) or not_r_content (a file that is not R at all, such as a JSON or HTML dump); these last two are not run and are not failures. python2 marks Python 2 code that was not run. With sandbox = "docker" such code runs with Python 2.7 (option metacheck.docker_image_py2; FALSE turns this off), which modifications records; it is never converted, since that can change results. defines_functions is a file that only defines functions, which is used, not run (table$used_by names the scripts that use it), and not_analysis is a file of software rather than of the analysis: a package’s code, tests, documentation or setup.py, a copy of a tool, a web application, a script a program wrote (table$not_analysis_why says which); neither is run or counted as a script. docker_failed means the container never started, which says nothing about the script, so it keeps the light from being green but does not make it red. needs_a_person is a script that stopped because it asks a person to choose a file or answer a question, or that starts an app, and needs_internet one that stopped because the network is off in a Docker run, or, with internet = TRUE, could not reach what it asked for; download_too_large is a script stopped for downloading more than the limits allow (see internet), and out_of_memory one that, or a program it started (such as a compiler), ran out of the memory each script may use. All four are treated the same way. not_downloaded is a script that stopped on a file the repository lists but that was not downloaded, such as one over max_file_size: it could not be tried, so it is not counted as a script that did not reproduce (summary_table$repro_not_downloaded_n counts them apart). not_read is a file metacheck could not read, so it was not run; the light is then not green, as the file may read and run on another computer, and table$error_message says why, naming a package that is installed but cannot be loaded on the computer that ran the check. empty is a file with nothing in it, which is not run or counted as a script. For a script that did not run through, table$error_message is its error, short (at most 300 characters): the error line of its output, which names a package that is not there, with the address it asked for when it needed the internet, or the time limit it reached; table$reason sorts it into a kind. A timeout means “still running at the cutoff”, not a failure, so raise timeout for legitimately long-running (e.g. Bayesian) scripts. dependency_unavailable means the script’s own package could not be installed from live CRAN, the CRAN Archive, or a named GitHub/URL source — an infrastructure limitation, not a defect in the paper’s code, so unlike errored/timed_out it does not force the traffic light red. The full stdout/stderr of every run is kept in the result’s run_results (the report shows it in per-script dropdowns, capped for readability). The traffic light reflects the STATIC readiness signals by default, but an execution error (errored/timed_out) does recolour it to red — a script that crashes on its own analysis is a genuine reproduction failure. A script that fails with could not find function is run once more with the library() calls the project’s other scripts make added at its top (or the one package that exports the function, or magrittr for %>%), and a script that then runs is reported as reproducible only after that repair.

Dependencies are reported name-only, with the source (CRAN, GitHub, or a base package already shipped with R) — static analysis of the code cannot know which version was used, and running against current package versions is itself informative: a break argues the authors should have pinned versions. When the repository does record versions, a run with recorded_versions = TRUE installs the packages the scripts load at those versions, but it does not change the R version, which remains a limitation of the check.

Run order is derived from read-after-write data dependencies (a script writing a file another reads must run first), source() edges, and numeric filename prefixes as a weak tie-breaker. Abstract

Background: Latvia has one of the highest suicide rates in the European Union, yet evidence on the psychosocial and mental health correlates of suicidality among Latvian adults remains limited. This preregistered study examined correlates of a composite suicidality outcome.

A cross-sectional nonprobability online survey of Latvian adults was conducted between May 2025 and February 2026. Of 1,018 participants in the analytic sample, 1,006 had an observed primary outcome. Measures included depression (PHQ-9), anxiety (GAD-7), workplace bullying (NAQ-R), alcohol use (AUDIT), and adapted UK Biobank items on trauma exposure, psychiatric symptoms, and substance use. The primary outcome was a binary composite of suicidal ideation or attempt in the past 12 months, or a lifetime suicide attempt.

Hypotheses were tested using multivariable and hierarchical logistic regression, with estimates pooled across 20 multiply imputed datasets and complete-case sensitivity analyses. The protocol was preregistered on the Open Science Framework (https://osf.io/8hjea).

Results: Lifetime suicide attempts were reported by 7.6% of participants (76/999), suicidal ideation by 61.9% (614/992), and self-harm by 21.4% (212/992). The composite outcome was present in 34.5% (347/1,006). Clinically significant depressive symptoms (PHQ-9 ≥ 10) were associated with higher odds of suicidality (OR = 5.33, 95% CI 3.97-7.16, p < .001). Compared with low perceived social support, strong support was associated with lower odds after adjustment for age, gender, and employment status (OR = 0.15, 95% CI 0.08-0.28, p < .001).

Adding mental health variables to the demographic model increased Nagelkerke's R² from .095 to .345. Participants with four or more prespecified risk factors had higher odds than those with zero or one (OR = 21.53, 95% CI 11.07-41.88, p < .001). Complete-case analyses yielded broadly consistent results.

Conclusions: Depressive symptoms, lower perceived social support, and cumulative psychosocial adversity were associated with suicidality. The cross-sectional design and nonprobability sampling limit generalisability to the Latvian adult population. Nationally representative longitudinal studies are needed to clarify temporal associations.

Background

Suicide represents a significant public health challenge globally, with approximately 727,000 deaths annually [1]. Latvia has historically maintained elevated suicide rates within the European Union; in 2023, the age-standardised suicide rate was 14.02 per 100,000 inhabitants compared with an EU average of approximately 10.37 [2]. Despite this public health burden, evidence of psychosocial and mental health correlates of suicide risk factors among adults in Latvia remains limited.

Voluntary online recruitment for mental health research may disproportionately engage individuals with prior contact with mental health services, greater interest in mental health topics, or personal experiences of psychological distress. Consequently, such samples may include many individuals with elevated mental health vulnerability and may not provide population-representative prevalence estimates [3]. However, socially mediated and institutionally linked digital recruitment channels may also facilitate access to individuals with elevated vulnerability who may be less likely to participate in conventional population-based research or engage with formal support services [4].

Suicide and suicide risk are complex, multifactorial phenomena that arise from dynamic interactions among psychological, psychiatric, social, interpersonal, and environmental factors.

Within contemporary ideation-to-action frameworks, the risk of suicide is conceptualised as multifactorial and involves psychological, clinical, social and environmental domains across biopsychosocial frameworks [5, 6]. These frameworks support the simultaneous consideration of clinical symptoms, psychosocial adversity, interpersonal resources, and substance use when examining suicide-related outcomes.

Suicide risk encompasses a spectrum of suicide-related thoughts and behaviours. Consistent with the Columbia-Suicide Severity Rating Scale framework, suicidal ideation refers to thoughts of death or suicide, whereas a suicide attempt is a non-fatal, potentially self-injurious act undertaken with at least some intent to die. Self-harm refers to intentional self-injury irrespective of suicidal intent and should not be considered synonymous with a suicide attempt.

Suicidal behaviour refers to suicide-related actions, including suicide attempts and preparatory, aborted, or interrupted attempts, while suicidal ideation is conceptually distinct from suicidal behaviour [7]. Because the primary outcome in the present study includes past 12-month suicidal ideation, lifetime suicide attempts, and past 12-month suicide attempts, it is hereafter referred to as a suicidality composite outcome.

Previous research has identified depressive and anxiety symptoms, trauma exposure, substance use, and social disconnection as important correlates of suicidal thoughts and behaviours.

Depressive and anxiety symptoms have been consistently associated with increased suicide risk across diverse populations, although these associations may vary according to the outcome definition, clinical context, and co-occurring psychosocial adversity [8]. Trauma exposure may be a suicide risk factor through pathways involving difficulties in affect regulation, interpersonal mistrust, and psychiatric comorbidity [9]. Perceived social support is associated with lower levels of suicide risk and may attenuate the associations among psychological distress, trauma exposure, and suicide-related outcomes [10]. Workplace adversity, including workplace bullying, is a potentially relevant but comparatively understudied psychosocial correlate that may co-occur with depressive symptoms and other forms of psychological distress [11]. Hazardous alcohol use is also a relevant domain in Latvia, where per capita alcohol consumption remains high relative to many other European countries [12].

Large-scale cohort studies, including studies using UK Biobank data, suggest that psychiatric symptoms and psychosocial characteristics provide information beyond demographic characteristics when modelling suicide-related outcomes [13]. However, evidence from Latvia remains limited, particularly with regard to the simultaneous contribution of mental health symptoms, trauma exposure, social support, alcohol use, workplace bullying, and cumulative psychosocial adversity.

In this preregistered cross-sectional study, we examined the associations among depressive and anxiety symptoms, trauma exposure, perceived social support, hazardous alcohol use, workplace bullying, and sociodemographic characteristics with a binary suicide risk composite in an online community sample of Latvian adults. We additionally examined the cumulative associations of co-occurring psychosocial and mental health adversities with the outcome.

Given the nonprobability recruitment strategy, the study was designed to examine associations between variables rather than to estimate population prevalence in Latvia. The protocol and analytical plan were preregistered on the Open Science Framework prior to data collection.

Methods

Study design and preregistration

This cross-sectional observational study used an online survey design. The study protocol, including all primary and secondary hypotheses, variable definitions, and analytical strategies, was preregistered on the Open Science Framework prior to data collection (OSF registration: https://osf.io/8hjea; [14]) [15]. The study was affiliated with the National Mental Health Centre, Latvia. The registration was updated on June 29, 2025, to correct typographical errors, but no analytical changes were made.

Participants and sampling

The target population comprised Latvian adults aged 18 years and older who had internet access and were able to read Latvian. A priori power analysis conducted in G*Power 3.1 indicated that a minimum sample of N = 800 would provide 80% power to detect an odds ratio of 1.50 using a two-sided α level of .05. To account for anticipated exclusions and incomplete responses, recruitment aimed to exceed this minimum by approximately 200 participants.

The survey was distributed through two channels: an open online link shared via social media platforms (Facebook, Instagram, and LinkedIn), email-based snowball sampling, and collaboration with nongovernmental and mental health organisations; and a separate link administered in a hospital setting. Responses from the hospital channel were identified by the distribution link and were not included in the present analyses (n = 135), which address the community sample. Recruitment took place between May 2025 and February 2026. Because a nonprobability recruitment strategy was used, the resulting sample should not be considered representative of the general Latvian population. Eligibility criteria were age 18 years or older, ability to read Latvian, internet access, and the provision of informed consent. Potential duplicate submissions were assessed using IP addresses and comparisons of response patterns. No duplicates were identified. Data quality exclusions were applied sequentially. Of the 1,951 respondents, 1,018 were suicidality composite outcome; these respondents were used as the source population for the model-specific complete case analysis. Measures

Primary and secondary outcomes

The primary outcome was a suicidality composite outcome as a binary composite variable that was coded as positive if participants reported any of the following: (a) suicidal ideation in the past 12 months, (b) a lifetime suicide attempt, or (c) a suicide attempt in the past 12 months.

Participants were classified as negative when all available component responses were negative.

The composite was coded as missing when all components were missing. This composite operationalisation was specified a priori in the preregistration.

Secondary outcomes included measures of self-harm behaviour and suicidal ideation, which were examined descriptively. Lifetime self-harm behaviour (binary) was coded as positive if participants reported any lifetime engagement in self-harm, and self-harm behaviour in the past 12 months (binary) was coded as positive if any self-harm occurred within the past year.

Lifetime suicidal ideation was assessed as an ordinal variable (0 = no ideation,1 = once,2 = more than once) with higher values indicating greater frequency. The number of lifetime selfharm episodes was also coded ordinally (1 = once,2 = twice,3 = three or more times) with higher values indicating greater cumulative exposure. All operationalisations were specified a priori in the preregistration.

Depression

The current severity of depression symptoms was assessed using the Patient Health Questionnaire-9 [16] with items scored 0-3 and total scores ranging from 0 to 27 (reported as M, SD). Depression history was assessed using adapted UK Biobank Mental Health Questionnaire items that captured core diagnostic features and characteristics of the worst depressive episode. Participants reported lifetime two-week periods of depressed mood and anhedonia (both binary). Characteristics of the worst episode included the duration of daily symptom intensity (less than half the day to the entire day), the frequency of symptoms (less often to every day), and functional impairment (not at all to a lot) with higher values indicating greater severity. These measures were included in the descriptive analyses or as auxiliary information in the multiple imputation procedure.

Anxiety

The current severity of anxiety symptoms was assessed using the Generalised Anxiety Disorder-7 scale (GAD-7) [17] with items scored 0-3 and total scores ranging from 0 to 21 (reported as M, SD). For H2, the GAD-7 total was standardised. The reported odds ratio therefore represents the change in odds associated with a one-standard-deviation increase in anxiety. A GAD-7 score of 10 or higher was used to define the anxiety domain in the cumulative risk analysis. The continuous total was also included in the hierarchical model.

Additional items related to anxiety history were assessed using items that captured core features of anxiety. Participants reported whether they had experienced a lifetime period of anxiety lasting one month or longer (binary) and whether their anxiety was perceived as excessive compared to others (binary). Functional impairment due to anxiety symptoms was assessed on a four-level scale (not at all, slightly, moderately, a lot) with higher values indicating greater impairment. These measures were included in the descriptive analyses or as auxiliary information in the multiple imputation procedure.

Mental health impairment and help-seeking

Participants reported whether they had experienced a period during which mental distress interfered with or prevented their usual activities. This binary indicator was the focal exposure in H3.

Psychotic experiences

Lifetime psychotic-like experiences were assessed across four domains: visual hallucinations, auditory hallucinations, experiences of receiving special messages, and paranoid experiences (all binary indicators). The frequency of psychotic-like experiences in the past 12 months was assessed on a five-point ordinal scale (never, once or twice, monthly or less, several times per month, almost daily or daily) with higher values indicating greater frequency.

Trauma and adversity

Trauma and adversity were assessed using 10 items that covered the domains of childhood and adulthood. Childhood items included perceived love and care, physical punishment, emotional rejection, sexual abuse, and medical neglect. Adult adversity included trust in relationships, intimate partner violence, psychological abuse, sexual coercion, and financial insecurity. All items were rated on a five-point Likert scale (0-4) with higher values indicating greater exposure.

Two variables for trauma and adversity were derived for confirmatory analyses. First, a continuous trauma total was calculated by summing all 10 items, which resulted in a possible range from 0 to 40. This score was used in the trauma and social support interaction analyses. Second, a traumatic event count was calculated as the number of items with values greater than zero, which produced a range of 0 to 10. This event count was used in H4 to estimate the change in odds associated with each additional traumatic experience.

Perceived social support

Perceived social support was assessed using a single item adapted from a UK Biobank questionnaire. Responses were recorded from 0 to 3, corresponding to no, weak, moderate, and strong support, respectively. Higher values indicated greater perceived support. For H5, social support was modelled categorically with no support as the reference category.

Numerical scores of 0-3 were used in the trauma and support interaction analysis. A lack of perceived support constituted the low-support domain in the cumulative risk analysis.

Workplace bullying

Workplace bullying among employed participants was assessed using the Negative Acts Questionnaire-Revised, 9-item version (NAQ-R) [11]. The items assess exposure to negative workplace behaviours over the past six months, including interpersonal and work-related acts. Responses were originally scored 1-5 (never to daily) and recoded to 0-4 for analysis, which yielded a total score ranging from 0 to 36. Higher scores indicated greater exposure to workplace bullying. The preregistered threshold of 33 on the original 1-5 scale was algebraically equivalent to a threshold of 24 on the recoded 0-4 scale. Consequently, a recoded NAQ-R score of 24 or higher defined high levels of bullying in H7 and H12. H7 also included a sensitivity analysis using continuous NAQ-R total scores. Because the NAQ-R was administered only to employed participants, analyses involving this measure were restricted to the employed subsample.

Alcohol use and addiction

Alcohol use was assessed using the Alcohol Use Disorders Identification Test (AUDIT) [18].

The AUDIT consists of 10 items that assess alcohol consumption, drinking behaviour, and alcohol-related problems. Items are scored 0-4 according to standard WHO guidelines, which yields a total score ranging from 0 to 40. Higher scores indicate greater alcohol-related risk.

Hazardous or harmful alcohol use was operationally defined as AUDIT ≥ 8. Participants reported whether they had ever experienced any addiction and whether they were currently experiencing any addiction (both binary). Lifetime history of specific types of addiction was assessed for alcohol, prescription medication (e.g., benzodiazepines, sleeping pills, and painkillers), illegal drugs, and behavioural addictions (e.g., gambling, gaming, and shopping), all of which were coded as binary indicators. For the cumulative risk analysis, substancerelated risk was defined as an AUDIT score of 8 or higher or a report of any current addiction.

Cannabis use was assessed using lifetime frequency categories (never used, used 1-2 times, 3-10 times, 11-100 times, or more than 100 times). The peak frequency of marijuana use was assessed on an ordinal scale (less than once per month, monthly or less, several times per month, daily) with higher values indicating greater intensity of use.

Cumulative risk index

For H15, five binary risk domains were constructed: clinically significant depressive symptoms (PHQ-9 ≥10), clinically significant anxiety symptoms (GAD-7 ≥10), any trauma exposure, no perceived social support, and substance-related risk defined by AUDIT ≥8 or any current addiction. The five indicators were summed to produce a cumulative risk score from 0 to 5. The participants were then classified into groups representing zero or one, two or three, or four or more concurrent risk factors. The group with zero or one risk factor served as the reference category.

Demographic and socioeconomic variables

The demographic covariates included age in years and gender. Gender was recorded as female, male, or other. Because the confirmatory regression models represented gender as a binary female/male factor, the four participants who selected "other" were not included in the multiply imputed analysis set.

For regression modelling, employment status was collapsed into four categories: employed, student, unemployed, and other not working. The latter category included participants on parental leave, retired participants, and recipients of a disability pension. Employed participants constituted the reference category.

For the hierarchical demographic model, housing was grouped into family-owned housing, rented housing, or other/unstable housing. Living arrangements were represented separately as living alone versus living with others. Income sources and caregiving responsibilities were represented by multiple binary indicators and were used descriptively or as auxiliary variables in the multiple-imputation procedure.

Additional auxiliary measures

Additional measures of manic or hypomanic symptoms, posttraumatic stress symptoms, substance use history, income sources, and caregiving responsibilities were included in the descriptive dataset and, where appropriate, as auxiliary variables in multiple imputation. They were not interpreted as focal exposures in the confirmatory hypothesis tests unless explicitly identified above.

Statistical analysis

The confirmatory hypothesis and overall analytical strategy were preregistered on the Open Science Framework prior to data collection. Statistical significance was set at α = .05 (twotailed). Bonferroni correction (p < .05/k) was applied for bivariate analyses separately within predefined variable families. Effect sizes are reported as Hedges' g for continuous variables, Cramér's V for categorical variables, and Somers' D for ordinal variables.

Descriptive statistics and bivariate group comparisons were conducted using the observed (nonimputed) dataset to reflect the raw distribution of the data. The suicidality composite was treated as a binary grouping variable. Categorical variables (nominal and binary) were summarised using frequencies and column percentages within the total sample and the groups with and without a suicidality composite outcome. Group differences were evaluated using Pearson's chi-square tests without continuity correction when the expected cell counts were adequate. Fisher's exact test was used for sparse 2 x 2 tables, and the Monte Carlo Fisher's exact test with 10,000 simulations was used for larger sparse tables. Effect sizes were quantified using Cramér's V for nominal variables and phi coefficients for binary variables.

When overall chi-square tests were statistically significant, post hoc cellwise analyses were conducted using standardised residuals (z scores) with corresponding two-tailed p values and Bonferroni correction applied. Ordinal variables were analysed using the Cochran-Armitage trend test to assess monotonic associations with the binary outcome. Effect sizes were reported using Somers' D. Continuous variables were summarised using means and standard deviations, and group differences were assessed using Welch's independent samples t tests. Effect sizes were calculated using Hedges' g with small-sample correction. Missing data patterns were assessed by calculating the proportion of missing values for each variable.

Missing predictor data for multivariable analyses were handled using multiple imputation by chained equations (MICE) implemented in the mice package in R. Analyses were restricted to participants with observed data on the primary suicidality composite and gender coded as male or female, resulting in a total sample of 1002 participants. The outcome variable was not imputed but was included as a predictor in the imputation models. Twenty imputed datasets were generated with 20 iterations each. Continuous variables were imputed using predictive mean matching, binary variables were imputed using logistic regression, unordered categorical variables were imputed using polytomous regression, and ordered categorical variables were imputed using proportional odds models. The imputation model included demographic, socioeconomic, mental health, trauma, social support, PTSD symptoms, substance use, and auxiliary variables. The number of imputations was increased from five as specified in the protocol to 20 to improve the stability of the Monte Carlo method.

Workplace bullying (NAQ-R) was not imputed because of structural missingness (available only for employed participants), and analyses involving the NAQ-R were conducted in the employed subsample using available data. A separate imputation object containing the derived trauma event count was used for H4 because the variable was not included in the principal imputation object. Parameter estimates from regression models were pooled across imputations using Rubin's rules.

Fourteen preregistered hypotheses (H1-H7, H9-H15) were evaluated. Most were tested using binary logistic regression models. Unless otherwise specified, the models were adjusted for age, gender, and employment status. The prespecified H5 social support model was supplemented by an additional model adjusted for continuous PHQ-9 and GAD-7 scores. H13 was evaluated using unadjusted gender-only logistic regression and the corresponding Pearson chi-square test. H14 used professional mental help seeking as the binary outcome.

The 1006 participants with an observed primary outcome constituted the source population for complete case sensitivity analyses. A separate complete case dataset was constructed for each hypothesis by retaining participants with complete data for all the variables required by the corresponding model. Therefore, complete case sample sizes varied across hypotheses. The same outcome, focal predictors, reference categories, and covariate structure were used in the imputed and complete case versions of each model.

Hypotheses involving workplace bullying (H7 and H12) were restricted to the employed subsample and adjusted for age and gender. H7 included both a preregistered categorical NAQ-R comparison and a sensitivity model using the continuous NAQ-R score. Interaction effects were tested for H10, H11, H12 and H14. Continuous variables involved in the interactions were mean centred where applicable. Interaction models were compared with corresponding main effects models using D1 pooled tests for the multiply imputed analyses and likelihood-ratio tests for complete case analyses. Age was mean-centred in the adjusted hypothesis-specific models with the exception of H9, which included age in years in the demographic block. For H9, hierarchical logistic regression was used to evaluate the incremental contribution of mental health variables. The demographic baseline model included age, gender, employment status, living conditions, and living alone. The second model added PHQ-9 and GAD-7 total scores and four lifetime psychotic-experience indicators. The two models were compared using a D1 pooled test in the multiple imputed analysis and a likelihood-ratio test in the complete-case analysis. Nagelkerke's R² was computed separately within each imputed dataset, and the change in R² between the two models was summarised as the mean across imputations rather than pooled using Rubin's rules. Lifetime suicidal ideation frequency showed a strong ordinal association with SC status (Cochran-Armitage trend test: z = -20.27, padj < .001; Somers' D = 0.72). Recurrent lifetime suicidal ideation was reported by 91.0% of participants with SC and 24.0% of those without SC with available data.

No evidence of an ordinal association was observed between the number of lifetime self-harm episodes and SC status (z = -1.79, padj = 1.000; Somers' D = 0.14). Estimates for past-12month suicide attempts and the number of lifetime self-harm episodes should nevertheless be interpreted cautiously because of substantial missingness.

Mental health characteristics

Mental health difficulties were common in the sample. Overall, 77% of participants reported lifetime mental health-related functional impairment, and 72% reported having sought professional help. Lifetime depressive episodes and periods of anxiety were reported by 80% and 67% of the participants, respectively. Psychotic-like experiences were less common (4-9%), whereas trauma-related symptoms and adversity were reported frequently. In addition, 21% of the participants reported a history of addiction.

Participants with SC had higher levels of depressive and anxiety symptoms than those without SC did. The mean PHQ-9 scores were 13.17 and 6.91, respectively (Welch's t (561.25) = 16.27, padj < .001; Hedges' g = 1.17), and the mean GAD-7 scores were 9.45 and 5.19, respectively (Welch's t (591.50) = 11.72, padj < .001; Hedges' g = 0.83). Participants with SC were also more likely to report a lifetime two-week period of depression (χ² (1) = 74.24, padj < .001, φ = 0.27) and excessive anxiety (χ² (1) = 56.25, padj < .001, φ = 0.26). Greater symptom duration, frequency, and functional impairment during both the worst depressive episode and the worst anxiety episode were associated with SC status (all padj < .01). Mania-and hypomania-related symptoms, including periods of elevated or irritable mood and severe irritability, were reported more frequently among participants with SC (both p < .001). Psychotic-like experiences, including hallucinations and paranoid experiences, were also more common among participants with SC (both padj < .001), although the corresponding associations were small (φ = 0.12-0.14) (all padj < .008). Detailed estimates are presented in the Supplementary Tables.

Trauma-related symptoms showed some of the strongest unadjusted associations with SC.

Participants with SC reported higher levels of intrusive memories, emotional distress, and avoidance (all padj < .001; Somers' D = 0.33-0.38). They also reported greater cumulative trauma exposure (Welch's t (544.26) = 7.69, padj < .001, Hedges' g = 0.57) and higher levels of several childhood and adult adversities. The greatest amount of childhood adversity was observed for emotional rejection (Hedges' g = 0.60). Several adult interpersonal and financial stressors were also reported more frequently among participants with SC.

Substance-related indicators also differed by SC status. Participants with SC had higher AUDIT scores (Welch's t (392.51)= 4.89, padj < .001; Hedges' g = 0.42), reported current addiction more frequently, and had higher frequencies of alcohol and behavioural addiction indicators. Lifetime alcohol-addiction and behavioural-addiction indicators were also more frequent among participants with SC (padj = .009 and .005, respectively). Current addiction was descriptively more frequent among participants with SC, but the difference was not statistically significant after adjustment (padj = .163) More frequent lifetime cannabis use was also associated with SC (padj < .001).

H9: Incremental predictive value of mental health variables

A hierarchical modelling approach was used to compare a demographic baseline model (Model 1) with a model that included additional mental health variables (Model 2). Nagelkerke R² values were calculated separately for each of the 20 imputed datasets and then averaged descriptively across imputations.

Adding mental health variables increased the mean Nagelkerke R² from .095 in Model 1 to .345 in Model 2 (mean ΔR² = .250, SD = .004; Figure 2C). The improvement in model fit was statistically significant with pooled D1 F(6, 949.32) = 25.53, p < .001). The increase exceeded the prespecified ΔR² threshold of .20; therefore, H9 was supported.

The complete case sensitivity analysis produced a consistent result (n = 911). The Nagelkerke R² increased from .097 in Model 1 to .368 in Model 2 (ΔR² = .271), and the corresponding likelihood-ratio test was statistically significant (χ²(6) = 215.23, p < .001). Thus, the conclusion for H9 was robust.

The interaction between depressive symptoms and gender was not statistically significant (OR = 1.06, 95% CI [0.97, 1.16], p = .215). H11: Social support as a buffer for trauma effects

The interaction between cumulative trauma and social support was not statistically significant (aOR = 0.99, 95% CI [0.96, 1.03], p = 0.717), and adding the interaction term did not improve model fit (pooled D1 F(1, 293.28) = 0.13, p = .717). Therefore, there was no evidence that perceived social support moderated the association between trauma exposure and the suicidality composite, and H11 was not supported. The complete case sensitivity analysis produced a consistent result (interaction aOR = 0.99, 95% CI [0.96, 1.02], p = 0.376; likelihood ratio χ²(1) = 0.79, p = .373; n = 880).

H12: Workplace stress and depression in relation to the suicidality composite outcome

Among employed participants, the interaction between depressive symptoms and high levels of workplace bullying was statistically significant (aOR = 0.84, 95% CI [0.71, 0.99], p = .037).

Adding the interaction term improved the model fit (D1, F(1, 645.98) = 4.35, p = .037).

However, the direction of the interaction indicated that the association between depression and the suicidality composite was slightly weaker rather than stronger at higher levels of workplace bullying. Therefore, the results were contrary to the prespecified direction, and H12 was not supported. The complete case sensitivity analysis produced a consistent interaction estimate (aOR = 0.83, 95% CI [0.70, 0.99], p = .035; likelihood ratio χ²(1) = 4.10, p = .043; n = 642).

The prevalence of the suicidality composite outcome did not differ significantly between male and female participants, χ²(1) = 1.30, p = .255. Consistent with this result, the unadjusted gender-only logistic model revealed no statistically significant difference in the odds of the outcome between male and female participants (OR = 1.24, 95% CI [0.86, 1.79], p = .255; n = 1,002). Therefore, H13 was not supported. Because all participants included in this comparison had complete data on gender and the outcome, the complete-case analysis produced the same substantive result.

H14: Gender differences in help-seeking associated with mental distress

The interaction between mental health impairment and gender in predicting professional helpseeking was not statistically significant (interaction aOR = 0.49, 95% CI [0.19, 1.23], p = .127).

Adding the interaction term did not improve model fit, with pooled D1 F(1, 479.56) = 2.33, p = .127. Although the estimate was in the predicted direction indicating a potentially weaker association among men than women, there was insufficient evidence that the association between mental health impairment and professional help-seeking differed by gender. Therefore, H14 was not supported. H15: Cumulative risk model

A greater number of co-occurring risk factors was associated with progressively higher adjusted odds of meeting the criteria for the suicidality composite outcome (Figure 2D).

Compared with participants who reported 0-1 risk factors, participants with 2-3 risk factors had nearly fivefold higher odds of the outcome (aOR = 4.79, 95% CI [2.81, 8.15], p < .001), whereas participants with four or more risk factors had substantially higher odds (aOR = 21.53, 95% CI [11.07, 41.88], p < .001). The risk group variable significantly improved model fit, with pooled D1 F(2, 264.58) = 43.79, p < .001. The estimate for four or more risk factors exceeded the prespecified threshold of OR ≥ 5.0; therefore, the preregistered exploratory criterion for H15 was met.

The complete-case sensitivity analysis revealed the same graded pattern, although the estimates were attenuated and less precise because of the smaller sample size (n = 245). Compared with participants who reported 0-1 risk factors, those with 2-3 risk factors (aOR = 3.37, 95% CI [1.28, 10.64], p = .022) and those with four or more risk factors (aOR = 11.49, 95% CI [3.96, 39.31], p < .001) had higher adjusted odds. The overall complete-case model comparison was also statistically significant (likelihood ratio χ²(2) = 25.81; p < .001).

Discussion

In this preregistered cross-sectional online study of Latvian adults, the suicidality composite outcome was associated with a broad range of mental health and psychosocial characteristics.

The most consistent associations were observed for depressive symptoms, anxiety symptoms, mental health-related functional impairment, trauma exposure, lower perceived social support, and addiction-related indicators. The hierarchical analyses revealed that mental health variables provided substantial additional explanatory value beyond demographic characteristics, whereas the cumulative-risk findings suggested higher odds of the outcome among participants who reported multiple co-occurring adversities. These findings should be interpreted in light of the cross-sectional design and nonprobability online sampling strategy. The composite should not be interpreted as a measure of prospective suicide risk because it captures selfreported indicators of suicidality assessed over different timeframes, including past 12-month suicidal ideation and lifetime or past 12-month suicide attempts.

The voluntary nonprobability recruitment strategy, including social media channels linked to the study investigators and a hospital-based platform, may have preferentially engaged individuals with greater interest in mental health, prior contact with mental health services, or personal experiences of psychological distress. Consequently, the sample may have included a greater proportion of participants with mental health difficulties than the general Latvian adult population, which may have introduced the possibility of selection and nonresponse bias and limited the generalisability of prevalence estimates. Compared with a Latvian population-based study conducted in 2023, the lifetime suicide attempt rate was higher in the present study (7.6% vs. 4.0%) [19]. Depression symptom levels were also elevated relative to estimates from traditional population-based studies. These findings likely reflect self-selection bias rather than causal processes, as individuals who are experiencing psychological distress may be more inclined to participate in voluntary online mental health research. Consistent with previous evidence, online research participants may report higher levels of depression and anxiety symptoms than nonparticipants or individuals without prior research participation [3]. The elevated prevalence of depression and the suicidality composite in this sample should be interpreted cautiously and may not be generalisable to the Latvian adult population. Moreover, socially mediated and institutionally linked digital channels may facilitate access to individuals with elevated mental health vulnerability who may be less likely to participate in conventional population-based research or engage with formal support services. These channels may therefore be potential settings for future research on outreach, psychoeducation, and the dissemination of low-threshold mental health support resources.

Clinically significant depressive symptoms and continuous depressive symptom severity were consistently associated with higher odds of the suicidality composite across the analyses. This finding confirms the theoretical connection between depression and suicide attempts [8], indicating that depressive symptoms are associated with increased odds of the suicidality composite. A recent meta-analysis revealed that compared with the general population, individuals with major depressive disorder had substantially greater odds of death by suicide [20]. These findings underscore the potential value of systematic depression screening and timely access to evidence-based care as core components of suicide prevention strategies, particularly in settings with a high suicide burden.

The findings support a cumulative vulnerability framework in which an elevated suicidality composite is associated not only with individual characteristics but also with the accumulation of trauma exposure and concurrent psychosocial adversities. In the present study, each additional type of trauma was associated with higher odds of the outcome, and participants who reported four or more concurrent adversities had markedly higher odds. Conceptually, this pattern is consistent with integrative models of traumatic stress and ideation-to-action theories of suicide, including the ADAPT [21] and Integrated Motivational-Volitional frameworks [6]. This pattern is also consistent with multifactorial and cumulative vulnerability frameworks in which trauma-related symptoms, depressive symptoms, interpersonal difficulties, and social adversity may co-occur. However, the cross-sectional design does not permit conclusions regarding temporal ordering, causal mechanisms, or transitions from thoughts about suicide to suicide attempts.

Greater perceived social support was associated with lower odds of the suicidality composite outcome after adjustment for demographic, mental health, trauma exposure, and substance use variables. This finding is consistent with the literature that identifies social connectedness as an important correlate of suicide-related outcomes [22]. However, the prespecified trauma × social support interaction was not statistically significant; therefore, the present findings do not provide evidence that perceived social support buffers the association between trauma exposure and the suicidality composite. In addition, social support was measured using a single-item indicator, which may not capture the multidimensional and time-varying nature of interpersonal support [23]. These findings suggest that perceived social support may be relevant to the assessment of suicide-related concerns. The question of whether interventions designed to strengthen interpersonal support reduce suicide risk requires evaluation in longitudinal and intervention studies.

Substance-related indicators were also associated with the suicidality composite. Hazardous alcohol use (AUDIT ≥ 8) was associated with higher adjusted odds of the outcome, and more frequent lifetime cannabis use was associated with the outcome in unadjusted comparisons. This pattern is broadly consistent with recent evidence suggesting associations of cannabis use and alcohol-related problems with suicide-related outcomes [24, 25], although the magnitude and nature of these associations vary by outcome definition, population, and adjustment for psychiatric comorbidity. In the present sample, the findings may indicate that broader addiction-related difficulties and lifetime cannabis exposure were more strongly associated with the outcome than alcohol use severity alone. However, because substance use, psychological distress, and the suicidality composite were assessed cross-sectionally, their temporal ordering and potential bidirectional relationships cannot be determined.

Workplace mobbing has a substantial impact on individual psychological well-being; however, mobbing may represent an important component of the cumulative pathway. It should also be noted that only one participant in the sample had an NAQ-R score ≥33, which limits the validity of the findings and underscores the need for further research with a larger sample size. The systematic review and meta-analysis show that the impact of workplace mobbing can be mediated through both depression and the Integrated Motivational-Volitional Model [26].

Taken together, these findings support the view that workplace mobbing may represent an important component of the cumulative pathway to the suicidality composite, which warrants further investigation in larger population-based studies.

Gender-related findings were not fully consistent across analyses. The preregistered analysis of gender differences was not supported, whereas male gender was associated with higher odds of the suicidality composite in some adjusted hierarchical models. These findings should be interpreted cautiously because the sample was predominantly female. The inconsistency across gender-related findings may also reflect the composite outcome, which combined suicidal ideation and nonfatal suicide attempts but did not include suicide mortality. This operationalisation may obscure established gender patterns as nonfatal suicidal behaviour is more frequently reported among women, whereas suicide deaths are substantially more common among men [27]. Future studies should examine suicidal ideation, suicide attempts, and suicide mortality separately in sufficiently large and more gender-balanced samples.

Compared with the UK Biobank study by Zhang et al. (2024) [13], the online Latvian sample in this study had a greater observed proportion of self-reported lifetime suicide attempts (7.6% vs. 2.3% in the reported UK Biobank case-control analytical dataset). However, these figures should not be interpreted as directly comparable prevalence estimates because the studies differed substantially in terms of sampling strategy, participant characteristics, outcome ascertainment, and analytic design. In particular, the present study used a nonprobability online recruitment strategy and may have been particularly attractive for individuals with elevated mental health vulnerability, whereas the UK Biobank study was based on a large UK cohort and focused specifically on suicide attempts. Despite these differences, both studies suggest that depressive symptoms and broader mental health characteristics are important correlates of suicide-related outcomes. In the present study, clinically significant depressive symptoms were associated with higher odds of the suicidality composite, whereas Zhang et al. reported associations of depression, mental distress, and behavioural characteristics with suicide attempts. Greater perceived social support was associated with lower odds of the outcome in the present sample. However, differences in the pattern of associated factors should be interpreted cautiously given the distinct outcome definitions and study populations.

From a clinical and public health perspective, the findings support the use of integrated suicide prevention strategies that address the clustering of mental health, trauma-related, and social risk factors rather than a focus on isolated predictors alone. Prevention efforts in Latvia should combine systematic depression screening, trauma-informed care, cumulative risk assessment, and interventions aimed at strengthening interpersonal and community support systems, particularly among socially and psychologically vulnerable groups. Although digital and social media recruitment may limit population-level generalisability, the present findings also suggest that social media channels linked to health professionals, hospitals, and mental health services may provide a valuable pathway to reach individuals with elevated psychological vulnerability.

These channels may therefore be used not only for public awareness campaigns but also for targeted prevention messaging, psychoeducation, early identification, and referral to lowthreshold mental health support.

Strengths and limitations

This study has several important strengths that enhance the credibility, transparency, and interpretability of the findings. First, the study protocol, hypotheses, and core analytical strategy were preregistered on the Open Science Framework, thereby reducing the risk of undisclosed analytical flexibility and strengthening the transparency of the research process. This allows for clear differentiation between supported, unsupported, and opposite direction findings. Second, the relatively large sample size provided adequate statistical power to examine a broad range of psychosocial correlates of the suicidality composite within a multivariable framework. Third, the use of established and psychometrically validated instruments increased the reliability and construct validity of the key measures. Finally, the explicit reporting of methodological limitations and deviations from the original preregistration further strengthened the reproducibility and scientific rigor of the study by enabling readers to assess the robustness of the analytic decisions and their potential implications for interpretation.

However, this study should be interpreted in relation to several limitations. First, the voluntary nonprobability recruitment strategy, which included social media channels linked to the study investigators, a hospital-based platform, and community-based dissemination, may have preferentially engaged individuals with greater interest in mental health, prior experiences of psychological distress, or prior contact with mental health services. Consequently, the sample may have included a greater proportion of participants with mental health difficulties than the general Latvian adult population, which may limit the generalisability of prevalence estimates and introduce the possibility of selection bias. Second, the cross-sectional design precludes inferences regarding causality or temporal ordering. Accordingly, the observed associations may reflect bidirectional, reciprocal, or otherwise nondirectional relationships rather than unidirectional effects. Third, all variables were assessed using self-report measures, which raises the possibility of recall bias, reporting inaccuracies, and socially desirable responding, particularly for sensitive constructs such as the suicidality composite, trauma exposure, and workplace bullying. Fourth, the primary outcome was operationalised as a composite indicator that included suicidal ideation in the past 12 months, lifetime suicide attempts, and recent suicide attempts. Although this approach increased sensitivity to a broader spectrum of suicidality, it may also have obscured clinically meaningful distinctions between suicidal thoughts and suicidal acts, which are known to have partially overlapping but nonidentical correlates. Finally, the interpretation of findings related to workplace mobbing is constrained by the extremely low prevalence of severe exposure in the present sample, with only one participant meeting the preregistered NAQ-R threshold of ≥33. Consequently, any conclusions regarding severe workplace bullying should be considered provisional and require replication in larger and more heterogeneous samples.

An additional limitation concerns the composition of the study sample, which was predominantly female (85.7%), thereby limiting the generalisability of the findings, particularly with respect to gender-specific patterns of the suicidality composite. Furthermore, social support was assessed using a single-item measure, which may not have fully captured the multidimensional nature of this construct. As a result, the observed protective association of social support should be interpreted cautiously, and future studies would benefit from the use of more comprehensive and psychometrically robust measures.
