Meta-scientific research has shown nonsignificant p values are commonly misinterpreted. It is incorrect to infer that there is ‘no effect’, ‘no difference’, or that groups are ‘the same’ after p > 0.05.

It is possible that there is a true non-zero effect, but that the study did not detect it. Make sure your inference acknowledges that it is possible that there is a non-zero effect. It is correct to include the effect is ‘not significantly’ different, although this just restates that p > 0.05.

This module searches for statements of ethics approval, IRB approval, institutional review board approval, and related terms.

Patterns are designed to capture:

How Exact P-Values works

List any p-values reported with insufficient precision (e.g., p < .05 or p = n.s.), reported as exactly zero (e.g., p = .000), or impossible (below 0 or above 1, e.g., p = -.22).

This module uses regular expressions to identify p-values. It will flag any values reported as p > ? or p < numbers greater than .001. It will also flag p-values reported as exactly zero (e.g., p = .000, p = 0.00), which are mathematically impossible — p-values are never exactly zero and should instead be reported as p < .001.

A p-value that is not the result of a test is not flagged: a table note (“* p < .05, ** p < .01”), a figure legend (“Asterisks indicate significant differences (p < .05)”, “Values in bold are significant at p < .05”) or a stated threshold (“p < .05 was considered significant”, “thresholded at p < .001”). GROBID often puts such notes into the running text, so each p-value is judged by the words in its own clause (the text up to a “;” or a full stop), and never left out when a test statistic belongs to it (“F(1, 7) = 8.03, # p < .05”). The column not_a_test of the table says why a p-value was left out (“marker”, “threshold”, “legend” or “named”).

A p-value with the name of a correction or a test after the p (“pFWE < .05”, “padj < 0.05”, “p Wilcoxon = .02”) is flagged only when a test statistic comes before it in its clause (“t(37) = 7.17, p FWE < .05”). Without one it is mostly the rule that decided what was significant (“genes with padj < 0.05 were selected”); such a p-value is “named” in not_a_test. Notes in other forms, such as a marker after the p-value (“p < .05 (*)“), are still flagged.

A p-value below 0 or above 1 is impossible; it is listed apart and not also as imprecise. Often the statistic before it, or its minus sign, was copied into it (“t(134) = -2.32, p = -.13”, “Z = 3.091, P = 3.091”). A value above 1 is listed only after a test statistic in its clause: without one, a “P” above 1 was nearly always another quantity (a proportion, pH, a group’s mean, a model parameter). A number in scientific notation whose power of ten was lost when the PDF was read (“p = 2.4 x 10 -9” read as 2.4) is not listed. A “p” that is the subscript of another symbol (“r p = .64”, “²p = .02” for partial eta squared, “Δp = .33”), or a quantity with a unit, a logarithm or a ratio (“P = 2.9 µm”, “-log10 P = 7.5”, “Ca/P = 1.67”), is not read as a p-value at all (see extract_p_values()). Each p-value has its own row, also when the same one is written twice in a sentence.

This module sometimes flags false positives when sentences discuss how p-value thresholds were set. It can also miss an imprecise p-value that is reported against a threshold (“decreased at the p < .05 significance threshold”).

This module only checks p-values reported in the running text of the manuscript. It cannot (yet) process p-values reported only in tables (as opposed to a table’s footnote text, which the module does see and tries to exclude — see above).

How Data Check works

This module classifies the files in a repository into semantic types (data, codebook, code, software, output, supplemental, readme, asset, other) and, for tabular data files, extracts each column’s type and summary statistics.

The Data Check module consumes the file list produced by repo_check (or any files added via local_path). Each file is classified with rule-based heuristics layered over metacheck’s file_category() and file_types: file names matching README / codebook patterns win first, then an extension crosswalk, then format-locked extension overrides. For every file classified as tabular data that is available locally, the module reads the file head, describes each column with data_col_facets() and computes summary statistics for numeric columns. Every sheet of a spreadsheet that holds a table is read: a file with several such sheets has its columns under source_file = "file.xlsx [sheet]", and the sheet column names the sheet of any spreadsheet with several sheets; a sheet of notes or a codebook is treated as documentation when the file has another table. Following DDI, a column is described by orthogonal facets rather than a single type: representation (numeric/text/datetime/code — how it is stored), measurement_level (Stevens: nominal/ordinal/interval/ratio), concept (what it measures: reaction_time/age/gender/likert/id/…), role (identifier/measure/condition/timestamp), unit, and a quality state (ok/empty/constant). Concepts are detected by name+value rules (the demographic concepts via data_check_demographic()); when llm_use(TRUE) the model fills concepts and measurement levels the rules left blank. Qualtrics survey exports are recognised (data_check_is_qualtrics()): their extra header rows are stripped so columns type correctly, and the reserved response-metadata columns (StartDate, Duration, Finished, …) are tagged.

The module defaults to rules-only when llm_use(FALSE): columns the rules cannot resolve (ambiguous 3–20-unique integers, ambiguous character columns) fall back to continuous / text respectively. When llm_use(TRUE), ambiguous columns and unresolved file types (other) are sent to llm() for optional refinement, and every file is assigned a study group (ex1, pilot2, shared, …) so that multi-study repositories can be recognised (used by psychds_check). Without an LLM the study group is left NA (unknown).

Column extraction requires files to be readable from disk. Files fetched by repo_check from OSF/GitHub/etc. without a local copy (file_location is NA) are classified but not column-extracted; pass local_path to point at a downloaded copy of the repository.

For a paper whose repository is on Dryad, this means column extraction never happens unless a Dryad API key is set: Dryad requires one to download file bytes, even from a fully public dataset (dataset listing and metadata do not need one). Without a key, every Dryad file stays classified but un-downloaded, column_n is 0, and a warning naming Dryad and ?dryad_pat/?dryad_auth is included among the download failures. A one-time session message is also shown (see repo_check) the first time a Dryad dataset is encountered with no key set.

Every downloaded text file the authors wrote (code, settings, survey definitions such as Qualtrics .qsf files, documentation, outputs) is searched for keys: API keys, access tokens and private keys, which let anyone who downloads the file use a paid service at the authors’ cost. How Reproducibility Check works

This module assesses whether a paper’s R and Python code can be run on its data. It works in two phases. By default (execute = FALSE) the module does not run any code — it performs only static analysis: reading dependencies with the same extractors as code_check, finding the files the code references in the repository, and building a run-order dependency graph. It reports what would be installed and run rather than doing it.

Full text

Abstract

Perceptual decisions are shaped not only by current sensory input but also by recent experience. Serial dependence exposes an internal brain process that biases current decisions toward previous ones, even in the absence of feedback about their correctness.

When available, feedback on one's choices is an external factor that also shapes subsequent decisions. However, how correct-and incorrect-choice feedback separately affect choicehistory biases relative to no feedback, and how these effects vary across individuals and modalities, remains unclear. Here, we compared the effects of serial dependence with or without trial-by-trial feedback on perceptual decisions regarding vestibular or visual selfmotion stimuli, and examined how they relate to autistic traits. Seventy healthy adults performed a two-alternative forced-choice heading discrimination task with visual or vestibular cues (separately), under two conditions: with feedback indicating whether each choice was correct or incorrect, and without feedback. Without feedback, significant choice repetition was seen in both modalities. Surprisingly, on average correct-choice feedback did not enhance the choice repetition effect; rather it remained similar in magnitude. By contrast, incorrect-choice feedback led to a large, opposite effect -choice switchingwhich was stronger for vestibular cues. Thus, only error signals, not confirmatory signals, substantially modulated serial dependence. Choice repetition in the no-feedback vestibular condition correlated significantly with autistic traits. This relationship was not observed when feedback was provided. The similarity in choice repetition following correct-choice feedback vs. no feedback was more pronounced in individuals with high autistic traits, and suggests that positive serial dependence (without feedback) may reflect an internal assumption that one's decisions were mostly correct.

Introduction

Our perceptual experiences might seem stable. However, this impression belies the complex adjustments that the brain needs to continuously make to maintain accurate function. When available, external feedback aids this process by providing an objective benchmark for assessing performance. Early studies showed that feedback shapes how past trials influence current perceptual judgments. In a loudness judgment task, responses were biased toward responses from several trials back without feedback, but away from those earlier responses when feedback was provided (Ward & Lockhead, 1971). In auditory identification tasks, feedback weakened the influence of the immediately preceding response and strengthened the influence of the immediately preceding stimulus (Mori & Ward, 1995). More recent work has shown that feedback can reduce systematic (Haddara & Rahnev, 2022) and even trial-by-trial (Fulvio et al., 2023) response biases in perceptual decisions. However, beyond reducing the overall response bias, the local effects of feedback on the immediately following trial may be more nuanced. Specifically, correctchoice feedback often leads to choice repetition (Fornaciai & Park, 2022); whereas incorrect-choice feedback often leads to choice switching on the next trial (Abrahamyan et al., 2016).

When feedback is not available, adjustments to perceptual decisions are still made based on recent history, a phenomenon called serial dependence (Fischer & Whitney, 2014; Cicchini et al., 2024). Serial dependence reflects an internal mechanism, presumably to promote perceptual stability by attracting one's current percept toward the immediately preceding experience (Bosch et al., 2020 Thus, sequential effects in perceptual decisions are driven both by external feedback and by internal processes of serial dependence without feedback. Previous studies that separated the effects of correct-and incorrect-choice feedback did not compare those to the no-feedback case (Abrahamyan et al., 2016; Little & Clifford, 2025). And studies that included a no-feedback condition either pooled feedback effects across correct and incorrect choices (Fulvio et al., 2023) or examined feedback in numerosity estimation (not binary choices), without separating the effects of previous stimuli from those of previous choices (Fornaciai & Park, 2022). Hence, how correct-and incorrect-choice feedback each change choice-history biases relative to no feedback in binary perceptual decisions remains unknown.

The first aim of this study was to examine how previous choices influence current perceptual decisions about self-motion, with and without feedback. We hypothesized that: i) correct-choice feedback would increase choice repetition compared to no feedback. ii) Incorrect-choice feedback would lead to choice switching. This was tested using a heading discrimination task, in two sensory modalities (vestibular and visual) in separate blocks.

Based on our previous work showing greater adaptation in the vestibular compared with the visual modality (Zaidel et al., 2011 (Zaidel et al., , 2013) ) and pilot data, we hypothesized that both effects would be larger for the vestibular (vs. visual) modality.

The influence of recent perceptual history and feedback on perceptual decisions varies substantially across individuals. In particular, individuals with autism spectrum disorder (ASD) often exhibit atypical sensory perception (American Psychiatric Association, 2022) and have been found to show increased choice repetition in perceptual decisions without feedback (Bosch et al., 2022; Feigin, Shalom-Sperber, et al., 2021), and weaker attraction toward the previous stimulus (Tsujita et al., 2025). Moreover, they demonstrate slower error correction and have difficulty tracking contextual changes when needing to rely on internal assessments (Lieder et al., 2019; Vishne et al., 2021). By contrast, when external feedback is provided no association is seen between choice repetition and autistic traits (Del Río et al., 2024). Additionally, individuals with ASD do not differ from controls in their neural responses to feedback, measured by feedbackrelated negativity (Larson et al., 2011). Taken together, these studies suggest that the difference in choice repetition between ASD and neurotypicals may be restricted to the case without feedback, while perceptual decision-making under external feedback appears more comparable between the two groups.

Consequently, the second aim of this study was to test whether choice repetition in the different feedback conditions correlates with autistic traits, as measured by the Autism-Spectrum Quotient (AQ) questionnaire (Baron- Cohen et al., 2001). We hypothesized that: i) in the absence of feedback, choice repetition would correlate positively with AQ. ii) No relationship would be seen between the two when feedback was provided. Although increased choice switching in individuals with autism was reported in reward-based tasks (Johnson et al., 2006; Zeif et al., 2023), it is important to distinguish between feedback and reward. In reward-based tasks, the primary goal is to maximize reward (O'Doherty et al., 2007; Glaze et al., 2015), which does not necessarily require accuracy (Maddox & Bohil, 1998). Recent work has demonstrated that humans do not treat corrective feedback as a form of reward but rather as information about the state of the world (Lee et al., 2023). In this study, we focused specifically on feedback in the absence of reward, to isolate feedback-related effects.

Methods

This study was approved by the institutional review board at Bar-Ilan University (approval number: ISU202008002). All participants signed informed consent. This study was pre-registered (please see details below in subsection Pre-registration).

Participants

To determine the required sample size, we conducted a power analysis (α = 0.05, power = 0.8), which yielded N = 55 for the vestibular modality and N = 68 for the visual modality (the limiting factor was the small expected effect size for the correlations with AQ in the second aim). We tested a total of 70 participants (36 females, 34 males; age range: 19-34 years) in both modalities. All the recruited participants were healthy, with no reported behavioral, attention, psychiatric, or neurological disorders. They all had normal or corrected-to-normal vision and normal hearing. Participants were recruited through online forums for students and were compensated with either monetary payment or course credit.

AQ questionnaire

To measure each individual's extent of autistic traits, all participants (neurotypical) completed the Autism Spectrum Quotient (AQ) questionnaire (Baron- Cohen et al., 2001) before performing the experiment. The AQ consists of 50 items, across five subscales: social skill, attention switching, attention to detail, communication, and imagination.

Participants responded to each item on a 4-point Likert scale ranging from "Definitely disagree" to "Definitely agree". Unlike the original AQ questionnaire which uses binary scoring, each response here was scored from 1 to 4 (Austin, 2005). Higher scores reflect a greater degree of alignment with autistic traits. Total scores were calculated by summing responses across all items, with possible scores ranging from 50 to 200. For each subscale, scores were calculated by summing responses across the 10 corresponding items, resulting in a range of 10 to 40.

Experimental setup and stimuli

Participants were seated comfortably in a car seat mounted on a motion platform (MB-E-6DOF/12/1000, Moog Inc.) and secured with a 4-point safety harness. Head movements were limited using a head support that was adjusted to each individual (Black Bear, Matrix Seating Ltd.). Participants wore a virtual-reality headset (Oculus Rift), with an 88-degree horizontal and 90-degree vertical field of view, and noise-canceling headphones, throughout the experiment. A green fixation point was positioned at the center of the participant's visual field. It was located 66 cm in front of the participant, and remained at this fixed distance relative to the participant during the experiment. Because the virtual-reality headset moved together with the participant on the motion platform, this distance did not change during the trial. Participants were instructed to keep their heads still and to focus on the fixation point throughout the experiment. A response box (Cedrus RB-540) was placed on each participant's lap, for initiating trials and reporting choices.

The self-motion stimuli were presented in one of two modalities: (1) vestibular selfmotion stimuli were delivered via inertial translations of the motion platform, on which the participant was seated (schematic in Figure 1). (2) Visual self-motion stimuli were presented via the virtual reality headset, and simulated self-motion through a 3D star field composed of 0.5 × 0.5 cm white triangles at a density of 0.00125/cm³. The star field measured 130 cm in width and height and 100 cm in depth, and was centered 66 cm in front of the participant prior to motion onset. The visual stimuli were generated with 100% motion coherence, whereby all stars moved in a manner consistent with the direction of the simulated self-motion. A clipping plane was set at 5 cm in front of the participant's eyes to prevent the stars from appearing too close. Self-motion stimuli for both modalities comprised a single-interval linear translation. This was primarily in the forward heading direction with slight deviations to the left or right of straight ahead. Straight-ahead was defined as heading = 0°, such that leftward headings were represented by negative values, and rightward headings were represented by positive values. All self-motion stimuli followed a Gaussian velocity profile lasting 1 second, with a total displacement of 13 cm, a peak velocity of 0.31 m/s, and a peak acceleration of 1.14 m/s².

Task and staircase procedure

Participants performed a two-alternative forced choice (2AFC) heading discrimination task, in which they reported whether the self-motion stimulus presented was to the right or left of straight ahead. The possible heading values were: ±16°, ±8°, ±4°, ±2°, ±1°, ±0.5°, ±0.25°, ±0.125°. The heading sign (negative or positive) was randomly selected on each trial (50% probability), and the heading magnitude followed a staircase procedure (Cornsweet, 1962). The staircase started at the largest heading magnitude (±16°) which was easiest to discriminate. The subsequent magnitudes were adjusted based on the participant's responses. Following a correct response, the heading magnitude was reduced (i.e., became more difficult) with 50% probability; otherwise, it remained unchanged. Conversely, after an incorrect response, the heading magnitude was increased (i.e., became easier) with 80% probability; otherwise, it remained unchanged. These staircase probabilities aimed for performance to converge at ~61% correct answers (Garcı́W a-Pérez, 1998; Leek, 2001). Because success rates are higher during convergence, the expected accuracy for an experimental block (via simulation) was 64%. The actual observed accuracy was slightly higher in practice (67.4% across participants and conditions) because some participants reached the lower heading magnitude bound (±0.125°) after which the task did not become more difficult. Before the main experiment, the participants completed a brief ~10-trial training session to ensure that they understood the task and were familiar with the auditory signals.

Experimental conditions

Each modality (vestibular and visual) was tested in a separate session, with session order counterbalanced across participants; half completed the vestibular session first, and the other half completed the visual session first. Most participants (N = 68) performed the two sessions within 2-11 days. However, due to a technical issue with the motion platform, two participants performed their two sessions three months apart.

Each session included two counterbalanced blocks with conditions: no-feedback and feedback. Participants could take a short break (5-10 minutes) between blocks if desired. In the no-feedback condition, participants completed 150 trials in which they made heading judgments without receiving any indication of whether their responses were correct or incorrect. The feedback condition consisted of 300 trials, each with auditory feedback indicating whether the response was correct or incorrect (see Auditory cues subsection).

Auditory signals

In the experiment auditory signals were used to guide participants through the task and to provide feedback. (1) A simple tone (beep) indicated that the system was ready for trial initiation, prompting participants to press the "start" button. (2) A different tone confirmed that a choice had been successfully registered (after the participant had reported a choice), and (3) a timeout buzzer was played if no choice was reported within 2 seconds after the stimulus had ended. Trials with timeouts were excluded from the analysis. In addition, trials immediately following timeout trials were also excluded from the analyses because they lacked a valid previous trial (although these trials were still used as the previous trial for the subsequent trial). Participants were instructed to avoid timeouts by making their best guess when uncertain. All participants included in the study had < 1.67% timeouts (mean ± SEM: 0.46 ± 0.05%).

In the feedback condition, after confirmation that a choice had been registered (tone #2 described above) an additional auditory signal was provided, to indicate whether the choice was correct or incorrect. For correct choices, two high-pitched notes of similar tone were played; for incorrect choices, a pair of low-pitched notes was played, with the second note lower than the first (see Figure 1). These were not presented in the no-feedback condition.

Data analysis

Data analysis and statistics were conducted using Matlab R2023a, the psignifit toolbox (Schütt et al., 2016) and RStudio (version 2024.04.2+764). The analysis code and data are available via the Open Science Framework at: https://osf.io/5zyex/.

Basic performance assessment and outlier exclusion

To assess basic performance on the task (for outlier exclusion) we fit separate psychometric functions for each participant, modality, and feedback condition, using a cumulative Gaussian distribution function (Klein, 2001; Schütt et al., 2016). This resulted in four curves per participant. To confirm that the participants were performing the task as instructed, we calculated the goodness of fit for each curve using Cohen's pseudo-R² (J. Cohen et al., 2002). We considered a pseudo-R² below 0.5 to indicate a poor psychometric fit, meaning questionable task performance. Accordingly, participants were excluded from further analysis if any one of their psychometric curves had a pseudo-R² below 0.5. A total of seven participants were excluded, all due to inadequate performance in the visual nofeedback condition. The final dataset thus included 63 participants (31 females, 32 males).

Generalized linear mixed-effects model (GLMM)

To examine how previous choices with/without feedback influenced current choices, we fit a generalized linear mixed-effects model (GLMM) with a logit link function and a binomial distribution. The model was fit separately for each modality (vestibular or visual). Trials from the feedback condition were sorted into those that followed correct choices and those that followed incorrect choices. This resulted in three groups of trials defined by the feedback type received on the previous trial: no-feedback, correct-choice feedback, incorrect-choice feedback.

Fixed effects in the GLMM included the following predictors: baseline bias, stimulus heading on the current trial t (S t ), stimulus heading on the previous trial (S t-1 ), previous choice (C t-1 ), and the interaction between the previous choice and the feedback type (FT). FT was modeled as a categorical factor with three levels (no-feedback, correctchoice feedback, and incorrect-choice feedback), where the no-feedback type served as the reference level (baseline). Choices were represented by -1 for leftward choices and +1 for rightward choices. Heading directions were normalized using the root mean square (RMS), such that both heading and choice predictors had RMS = 1. This normalization was done to make the predictors more comparable to one another. Random intercepts and slopes were modeled for each participant (P), allowing each participant to have their own baseline and individual effects for the predictors.

The mixed-effects model was specified as follows:

Choice ~ 1 + S t + S t-1 + C t-1 + C t-1 : FT + (1 + S t + S t-1 + C t-1 + C t-1 : FT | P) (Eq. 1)

The term C t-1 : FT denotes the interaction only, without including a main effect of feedback type for choosing left or right. To avoid attributing feedback-related effects to the previous stimulus, the model included a single previous-stimulus regressor across all feedback trials. We fitted the GLMM using the lme4 package in RStudio (Bates et al., 2015), with the bobyqa optimizer and Laplace approximation (nAGQ = 1).

Statistical analyses

The dependent variable for this study was the effect of the previous choice ( C t-1 ; f rom Eq. 1) on the current choice, estimated separately for each feedback type, within the same GLMM. Because the no-feedback type was the reference level (baseline) for the FT parameter, the main effect of C t-1 reflects the influence of the previous choice with no feedback, and the interaction terms β ( C t-1 : FT ) correct and β ( C t-1 : FT ) incorrect capture deviations from this baseline for correct-choice and incorrect-choice feedback. Accordingly, the effect of the previous choice for each feedback type was computed as follows:

No-feedback: β prev_choice_no_FB = β C t-1

Correct-choice feedback: β prev_choice_corr = β C t-1 + β ( C t-1 : FT ) correct

(Eq. 3)

Incorrect-choice feedback: β prev_choice_incorr = β C t-1 + β ( C t-1 : FT ) incorrect (Eq. 4)

These values quantify the magnitude and direction of the choice bias for each feedback type (no-feedback, correct-choice feedback, and incorrect-choice feedback) for comparison. Because GLMM inference relies on asymptotic normality of the estimates, and given the large number of trial-level observations, the fixed-effects results were evaluated using Wald z statistics (implemented in lme4).

First, to test whether and how current choices were affected by the previous choice, the respective parameters for each feedback type (i.e., β prev_choice_no_FB, β prev_choice_corr, β prev_choice_incorr ) were compared vs. zero using two-tailed Wald z-tests. Second, to test whether feedback following correct choices increased choice repetition relative to no-feedback (the repeat correct choice hypothesis), and whether feedback following incorrect choices led to choice switching (the switch incorrect choice hypothesis), the interaction terms β ( C t-1 : FT ) correct and β ( C t-1 : FT ) incorrect were compared vs. zero using one-tailed Wald z-tests.

Separate GLMMs were fit for the vestibular and visual modalities. As a result, the effects were estimated separately for each modality. Subject-level coefficients were computed by summing the subject-specific random effects for each parameter with the corresponding fixed effects value. With these, the subject level previous-choice effects were calculated for each feedback type (Equations 2-4). To compare the effects between the vestibular and visual modalities, planned analyses focused on the subject-level interaction coefficients for correct-choice and incorrect-choice feedback: β ( C t-1 : FT ) correct and β ( C t-1 : FT ) incorrect , respectively. Given that β ( C t-1 : FT ) correct was not significantly different from zero, only β ( C t-1 : FT ) incorrect was carried forward to the between-modality comparison (see Results,

Enhanced choice switching in the vestibular modality).

Accordingly, a one-tailed paired-samples t-test was performed on the subject-specific coefficients of β ( C t-1 : FT ) incorrect.

This allowed us to examine whether the influence of incorrect-choice feedback was more pronounced in the vestibular modality compared to visual (the vestibular enhancement hypothesis).

To test the increased choice repetition in autism hypothesis, we examined the correlations between subject-level coefficients for β prev_choice_no_FB and total AQ scores using Pearson correlations. To test the typical behavior with feedback in autism hypothesis, we examined the correlations between subject-level coefficients for β prev_choice_corr and total AQ scores, and between β prev_choice_incorr and total AQ scores.

Bayesian analyses were conducted to quantify evidence for the null versus alternative hypotheses. Bayes factors were reported as BF01 , representing the relative evidence for the null hypothesis over the alternative. Interpretation followed established conventions (Raftery, 1995; Wagenmakers, 2007; Jarosz & Wiley, 2014), whereby BF01 > 3 was considered substantial evidence and BF01 > 10 strong evidence for the null hypothesis. Conversely, BF01 < 1 3 was considered substantial evidence, and BF01 < 1 10 as strong evidence for the alternative hypothesis. Bayesian tests of the preregistered directional hypotheses were one-tailed; all other Bayesian tests were two-tailed.

Pre-registration

Pre-registration for this study can be found at: https://aspredicted.org/9BT_TNL.

The experiment and analysis procedures followed those specified in the pre-registration, apart from a minor deviation: The pre-registration specified that a standard generalized linear model (GLM) would be used to fit the data separately for each participant, modality (visual or vestibular), and feedback condition (no-feedback, feedback). In practice, we chose to rather use a mixed-effects model (GLMM), which is better because it fits the data across all participants and feedback conditions at once (per modality). Before adopting the GLMM approach, we verified that the effect of the previous stimulus did not differ across feedback conditions (feedback vs no-feedback). We compared the previous-stimulus coefficients obtained from the individual-subject GLMs. No effect of feedback on these coefficients was observed (F(1,62) = 0.073, p = 0.79), supporting the use of a single previous-stimulus term in the GLMM. The GLMM provided direct statistical inference for the fixed-effects parameters, obviating the need for the pre-registered ANOVA.

To confirm that the results were not sensitive to this change, we compared them with those of the preregistered GLM approach and got largely similar results.

Because the GLMM is more parsimonious and yields more stable subject-level estimates, and both approaches gave largely similar results, we report the GLMM.

Results

Feedback modulates the influence of prior choices

We first examined how previous choices influenced current decisions in the absence of feedback. In the no-feedback condition, the influence of the previous choice (β prev_choice_no_FB ) was significantly positive, for both modalities (Figure 2, left). The fixed effect estimate ± SEM was 0.16 ± 0.05 (p = 1.78•10 -3 , z = 3.13; two-tailed z-test) for the vestibular modality, and 0.23 ± 0.04 (p = 5.56•10 -8 , z = 5.43; two-tailed z-test) for the visual modality. Thus, with no choice feedback, a systematic attraction to prior choices was observed.

In the feedback condition, attraction to prior choices was also observed, but only for feedback that indicated that the previous trial was correct. Namely, after correct-choice feedback, the influence of the previous choice (β prev_choice_corr ) was significantly positive, for both modalities (Figure 2, middle). The fixed effect estimate ± SEM was 0.24 ± 0.05 ( p = 1.91•10 -6 , z = 4.76; two-tailed z-test) for the vestibular modality, and 0.19 ± 0.04 (p = 2.35•10 -6 , z = 4.72; two-tailed z-test) for the visual modality. By contrast, after incorrectchoice feedback, the influence of the previous choice (β prev_choice_incorr ) was significantly negative, for both modalities (Figure 2, right). The fixed effect estimate ± SEM was -0.43 ± 0.06 (p = 2.66•10 -12 , z = -6.99; two-tailed z-test) for the vestibular modality, and -0.19 ± 0.05 (p = 2.10•10 -4 , z = -3.71; two-tailed z-test) for the visual modality. Thus, feedback modulated the influence of prior choices, with choice repetition following correct-choice feedback and choice switching following incorrect-choice feedback.

Across both modalities, the other model coefficients behaved as expected (Supplementary Figure 1). Specifically, the β current_stimulus coefficients, which quantify perceptual sensitivity to stimulus heading on the current trial t (S t ), were large and significantly positive (Supplementary Figure 1, top; see Table 1 for further details). This confirms that participants performed the heading direction task appropriately and largely relied on the current stimulus when forming their perceptual judgments. The β prev_stimulus coefficients, which capture the influence of the previous trial's stimulus heading (S t-1 ), were significantly negative in both modalities (Supplementary Figure 1, middle; see Table 1 for further details), indicating a repulsive effect of the prior stimulus on current perceptual judgments, in line with previous studies (Bosch et al., 2020; Shalom-Sperber et al., 2022; Shamir-Bercovich et al., 2026). The β 0 coefficients, which quantify the participants' baseline bias, were not significantly different from zero in any modality (Supplementary Figure 1, bottom; see Table 1 for further details), confirming no systematic baseline bias. Correct-choice feedback did not increase choice repetition

Next, we examined whether correct-choice feedback increased choice repetition vs.

no-feedback. The interaction term β ( C t-1 : FT ) correct did not significantly differ from zero in either modality. The fixed-effect estimate ± SEM for the vestibular modality was 0.07 ± 0.05 (p = 0.07, z = 1.45; one-tailed z-test), and for the visual modality was -0.04 ± 0.05 (p = 0.79, z = -0.81; one-tailed z-test). Thus, choice repetition after correct-choice feedback was similar to that observed in the no-feedback condition. This was somewhat surprising, as we had expected correct-choice feedback to augment choice repetition (the repeat correct choice hypothesis). Given the nonsignificant results in both modalities, we conducted a follow-up Bayesian one-tailed paired-samples t-test, in line with the preregistered directional hypothesis. The results yielded BF01 = 0.28 for the vestibular modality, and BF01 = 15.27 for the visual modality. Thus, in the vestibular modality the Bayes factor favored an increase in choice repetition, but this increase was small compared with the effect of incorrect-choice feedback (see below) and did not reach statistical significance in the frequentist test, despite being one-tailed. In the visual modality, the Bayes factor favored the null hypothesis over the hypothesis of increased choice repetition.

The similarity of the previous-choice effect for correct-choice feedback and nofeedback suggests that this may reflect a stable individual characteristic. Hence, we tested whether the previous-choice effect showed within-individual consistency between the nofeedback and correct-choice feedback conditions. In the vestibular modality, individual differences in choice repetition were positively correlated between the no-feedback and correct-choice feedback conditions (r = 0.69, p = 3.30•10 -10 ; Supplementary Figure 2, left), consistent with an individual trait-like contribution. This relationship was not seen in the visual modality (r = 0.18, p = 0.15; Supplementary Figure 2, right). A broader distribution of values was seen in the vestibular compared to the visual modality, which may partly account for this difference.

We further verified this result using separate GLMs for each participant, modality, and feedback condition, as specified in the pre-registered analysis plan (see Methods, Preregistration subsection). The resulting across-subject correlations showed the same qualitative pattern as the GLMM analysis, revealing a significant association in the vestibular modality (r = 0.37, p = 0.003) but not in the visual modality (r = 0.05, p = 0.68).

Thus, choice repetition revealed a stable individual bias across these contexts (no-feedback and correct-choice feedback) for vestibular, but not visual, perception of self-motion.

No correlations in the feedback conditions with autistic traits

No significant correlations were seen between the subject-level correct-choice feedback effects (β prev_choice_corr ) and AQ scores, nor between the subject-level incorrectchoice feedback effects (β prev_choice_incorr ) and AQ scores, in either modality (Figure 5). This finding supports the typical behavior with feedback in autism hypothesis. To further evaluate the strength of evidence for the null hypothesis (i.e., of no correlation), we performed two-tailed Bayesian correlation analyses between the previous-choice effects and AQ scores, for both feedback types and modalities. This yielded BF01 = 3.38, BF01 = 2.13, BF01 = 2.78, and BF01 = 3.46 for vestibular correct-choice, visual correct-choice, vestibular incorrect-choice, and visual incorrect-choice feedback, respectively. These values provide substantial evidence in favor of the null hypothesis for vestibular correctchoice and visual incorrect-choice feedback, whereas the evidence remains inconclusive for visual correct-choice and vestibular incorrect-choice feedback. These results suggest that the influence of previous choices when feedback is given is not strongly associated with AQ scores, in either modality.

Feedback dampens the relationship between autistic traits and previous choices

To test whether the relationship between AQ scores and the previous-choice effect differed by feedback type, we applied the extended GLMM analysis that included the AQ score and its interaction with the previous-choice effect and feedback type. In the vestibular modality, the relationship between the previous-choice effect and AQ differed significantly by feedback type. Specifically, it was weaker for correct-choice feedback vs. no-feedback (interaction ± SEM = -0.12 ± 0.05; p = 0.02, z = -2.40, two-tailed z-test). Similarly, it was weaker for incorrect-choice feedback vs. no-feedback (interaction ± SEM = -0.13 ± 0.06; p = 0.05, z = -2.00, two-tailed z-test). This is seen by flatter regression slopes in the feedback vs. no-feedback conditions (Figure 5 left column, blue vs. black lines). This is in line with the finding above that higher AQ is associated with higher β prev_choice values specifically in the vestibular no-feedback condition. Interestingly, the regression line for correct-choice feedback in the vestibular condition (Figure 5, top left, blue) is generally above that for no-feedback (black). These lines intersect only at high AQ.

This might suggest that the finding above that correct-choice feedback did not increase choice repetition (beyond no feedback) may be mainly driven by participants with high AQ. Whereas, for participants with low AQ, correct-choice feedback might actually increase choice repetition vs. no-feedback. Hence, this interaction suggests that whether or not correct-choice feedback increases choice repetition depends on autistic traits.

In the visual modality, no significant interaction between AQ, feedback type, and previous choice was observed. The interaction ± SEM for correct-choice feedback was 0.05 ± 0.05 (p = 0.34, z = 0.96; two-tailed z-test), and for incorrect-choice feedback, it was 0.04 ± 0.05 (p =0.41, z = 0.82; two-tailed z-test). This is consistent with the lack of significant correlations in the visual condition between AQ and previous-choice effects across all feedback types (no-feedback, correct-choice feedback, and incorrect-choice feedback).

Discussion

This study investigated how recent history affects current decisions regarding selfmotion, in two sensory modalities: vestibular or visual. Specifically, it examined how feedback on prior decisions influenced current perceptual choices, and whether this influence varied with individual differences in autistic traits. The study provided three key findings. First, correct-choice feedback did not enhance choice repetition beyond the baseline levels observed in the absence of feedback. Second, incorrect-choice feedback flipped the tendency from repeating choices to switching choices on subsequent trials. This choice switching effect was stronger for vestibular cues. Third, we found a selective relationship between autistic traits and choice repetition in the vestibular modality without feedback, which was eliminated by feedback.

Feedback indicating correct choices did not augment choice repetition

Our first aim was to investigate how feedback regarding prior choices affects current self-motion perceptual decisions. The repeat correct choice hypothesis proposed that correct-choice feedback would enhance choice repetition, leading participants to repeat their previous choices to a greater extent compared to no-feedback. Surprisingly, in both the vestibular and visual modalities, the tendency to repeat the previous choice following correct-choice feedback was not significantly larger compared to the no-feedback condition. However, this lack of difference between correct-choice feedback and nofeedback may be more pronounced in individuals with higher autistic traits (see discussion in subsection Feedback mitigates the relationship between autistic traits and choice repetition below).

Overall similarity in choice repetition following no feedback and correct-choice feedback might suggest that in the absence of external feedback, people may adopt a default assumption that their choices are mostly correct, as serial dependence scales with decision confidence (Braun et al., 2018; Samaha et al., 2019). This interpretation aligns with models of perceptual learning, which propose that internal signals can guide learning in the absence of explicit feedback (Petrov et al., 2005 (Petrov et al., , 2006)). Under such conditions, behavior may effectively proceed as if the prior choices were correct when no corrective feedback is available. This is consistent with the proposal that, without feedback, observers update an internal estimate of their choice tendency based on their own previous choices (Akaishi et al., 2014), and with criterion-setting accounts in which the decision criterion tracks one's own previous responses (Treisman & Williams, 1984). If this internal signal already treats the previous choice as correct, confirmatory feedback is largely redundant and adds little, whereas incorrect-choice feedback contradicts it and thus reverses the choice-history bias, as observed here.

Measures of confidence might be useful to test this interpretation, but confidence reports may themselves alter perceptual judgments, judgments of correctness, and/or serial dependence. Moreover, measures of confidence may not directly map to assumed correctness.

An alternative explanation is that the participants may have disregarded correct-choice feedback, treating it as if no feedback had been provided. But this seems less likely as they were strongly affected by incorrect-choice feedback, hence they would have needed to selectively disregard feedback following correct choices.

Feedback indicating incorrect choices promotes choice switching

The switch incorrect choice hypothesis predicted that feedback indicating incorrect choices would promote choice switching, and indeed our results support this prediction.

When participants were given feedback indicating that their previous choice was incorrect, they were significantly more likely to switch responses on the subsequent trial. This effect was observed in both modalities and was stronger in the vestibular modality.

A similar pattern of choice repetition following correct-choice feedback and choice switching following incorrect-choice feedback was previously reported by Abrahamyan et al. (2016). However, because feedback was provided on every trial in that study, these effects were not compared with choice-history biases in the absence of feedback. By including a no-feedback condition, the present study extends this previous work and shows that correct-choice feedback did not significantly increase choice repetition beyond the nofeedback baseline, whereas incorrect-choice feedback reversed the influence of the previous choice from repetition to switching.

More recently, Little and Clifford (2025) also found that feedback valence modulated response-history effects, with a greater tendency to repeat previous responses following feedback indicating a correct rather than an incorrect choice. However, unlike in the present study, feedback indicating an incorrect choice was associated with a weaker response-history effect but did not produce a significant reversal toward choice switching.

Their design likewise did not include a no-feedback condition, making it difficult to determine how each feedback type changed response-history effects relative to baseline.

Lak et al. (2020) reported that the outcome of a choice biases the next choice mainly when the previous decision was difficult. Because the staircase in the present study kept most trials near threshold, this account would predict strong choice repetition after correctchoice feedback. Yet, choice repetition after correct-choice feedback did not significantly exceed the no-feedback baseline. Lak et al. (2020) likewise did not include a no-feedback condition, so the choice repetition they observed after correct choices may partly reflect choice-history biases that are present even without feedback. In contrast to the studies mentioned above, Fulvio et al. (2023) directly compared feedback with a no-feedback condition. In their study, performance feedback abolished serial dependence relative to no feedback. Although those findings may appear to be at odds with our results, this discrepancy likely stems from methodological differences. In particular, Fulvio et al. (2023) employed a graded visuomotor response and a betweengroups feedback manipulation, whereas our study utilized a binary 2AFC perceptual decision in a within-participant design. Furthermore, in that study the effect of feedback was not analyzed separately depending on whether the feedback followed correct or incorrect choices.

Rather, the effect of feedback, collapsed across correct and incorrect choices, was compared to no-feedback. This is important because opposing effects following correct-choice versus incorrect-choice feedback may cancel each other out when combined.

To demonstrate this, we applied a similar analysis to the data from this study, i.e., comparing feedback versus no-feedback without dissociating correct and incorrect choices.

With this approach, serial dependence was likewise no longer apparent in the feedback condition: In the vestibular modality, the fixed effect estimate ± SEM of β prev_choice in the feedback condition was -0.05 ± 0.04 (z = -1.33, p = 0.18; two-tailed z-test). In the visual modality, the fixed effect estimate ± SEM of β prev_choice in the feedback condition was 0.03 ± 0.03 (z = 1.04, p = 0.30; two-tailed z-test). This suggests that the apparent reduction in serial dependence under feedback may reflect the averaging of opposing effects. Therefore, it is important to dissociate the effects following correct and incorrect choices, which can otherwise cancel out.

Like the present study, Fornaciai and Park (2022) examined both whether serial dependence differed between feedback and no-feedback conditions and whether it varied with the type of feedback received. In their numerosity estimation task, attractive serial dependence was stronger in blocks with feedback than in blocks without feedback.

Within the feedback blocks, attraction was stronger after feedback indicating a correct estimate than after feedback indicating an underestimate. The difference between correct estimates and overestimates was not significant. Fornaciai and Park (2022) and the present study quantified different history effects. They quantified serial dependence based on the influence of the previous stimulus on current estimates. The present study examined the influence of the previous choice on current decisions, while accounting for the previous stimulus in the statistical model. Here, correct-choice feedback did not enhance choice repetition relative to no-feedback, whereas incorrect-choice feedback reversed it into choice switching. Thus, the effects of feedback may differ depending on whether serial dependence is measured relative to the previous stimulus or the previous choice.

Increased choice switching in the vestibular modality

The vestibular enhancement hypothesis predicted that both choice repetition and choice switching would be stronger in the vestibular compared to the visual modality.

Because choice repetition following correct-choice feedback was not significantly increased vs. that observed in the no-feedback condition for both modalities, we were unable to test this hypothesis for correct-choice feedback. However, it was tested and confirmed for choice switching -which was significantly greater for the vestibular vs.

visual modality. This finding is consistent with prior work showing that vestibular perception demonstrates a higher degree of adaptation compared to vision, and more rapid recalibration (Zaidel et al., 2011 (Zaidel et al., , 2013)).

Internal and external modulators of perceptual decisions

The present results can be considered within a broader continuum of mechanisms that support perceptual adjustment. At one end lies external feedback, which serves as a clear, trial-by-trial teaching signal. In our study, feedback about incorrect choices promoted choice switching, highlighting the brain's sensitivity to explicit external correction (Zaidel et al., 2013). At the other end lies serial dependence, an internal process that stabilizes perception by biasing current judgments toward previous choices (Feigin, Baror, et In the middle of this continuum is cross-sensory recalibration, in which one sensory system is adjusted based on the input from another. This mechanism reflects the brain's ability to internally align its estimates across modalities to construct coherent and accurate perception (Zaidel et al., 2011; Zeng et al., 2023). Together, these mechanisms form a functional continuum -from feedback-driven correction to internally maintained stability -supporting the brain's ability to adapt while preserving coherence.

Limitations

One limitation of the study has to do with the lower frequency of trials with incorrect-choice compared to correct-choice feedback. In 2AFC paradigms, when a signal is present, performance is expected to exceed chance level (50%), inherently leading to more correct than incorrect trials. This may have amplified the effect of incorrect-choice feedback, as these trials were rarer and potentially more salient (Ranganath & Rainer, 2003; Itti & Baldi, 2009) and arousal can boost the tendency to alternate choices (Urai et al., 2017), possibly exaggerating the observed choice-switching behavior.

Another possible limitation is that objective correctness differed across the three feedback types. With no feedback, participants were correct on 67.9% of trials on average across modalities, due to the staircase procedure. Whereas, they were correct on all of the trials with correct-choice feedback, and none of the trials with incorrect-choice feedback.

Thus, some of the observed effects could potentially be related to correctness rather than feedback itself. Indeed, response correctness itself can exhibit sequential dependence, with correct responses being more likely following correct than incorrect responses (Shipley, 1961). However, if correctness alone were driving the results, we would expect stronger choice repetition following correct-choice feedback, where all previous responses were correct, than in the no-feedback condition, where only approximately 68% of responses were correct. However, no difference was observed, suggesting that correctness alone is unlikely to explain the observed results.

Another potential confound is a possible association between feedback type and trial difficulty. Because of the staircase, trials following incorrect choices might tend to be easier on average, whereas trials following correct choices might tend to be more difficult on average. However, this difference is expected to be minor because step-sizes were small and the staircase was designed to be close to perceptual threshold. Moreover, with this association, larger history effects would be expected following correct responses.

However, that was not observed. The history effects were not larger following correctchoice feedback vs. no-feedback or incorrect-choice feedback. To the contrary, the largest history effect was observed following incorrect-choice feedback, despite those trials being possibly easier on average.

In terms of the autism results, this sample consisted of neurotypical individuals and relied on AQ scores rather than a clinical ASD diagnosis (such as ADOS), which may limit the generalizability of our findings to clinically diagnosed populations.

Summary

In the absence of feedback, perceptual decisions were biased toward the previous choice, reflecting a stable tendency for choice repetition. This bias changed little with correct-choice feedback, suggesting that observers may, by default, assume their previous decisions were mostly correct even without external confirmation. In contrast, incorrectchoice feedback induced strong choice switching, highlighting the dominant role of error signals in updating perceptual decisions, with a stronger effect observed in the vestibular modality. Choice repetition without feedback in the vestibular modality was positively associated with autistic traits, an effect that was eliminated by feedback. An interaction between previous choice effects, feedback type, and autistic traits indicated that the similarity in choice repetition following correct-choice and no feedback was primarily driven by individuals with higher autistic traits.
